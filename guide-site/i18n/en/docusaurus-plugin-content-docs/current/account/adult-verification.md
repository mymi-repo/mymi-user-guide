# Age and identity verification

MYMI uses **identity or phone verification** and **age confirmation** for different purposes. When a feature asks you to verify, follow the instructions on that screen.

| Type | What it checks | When you may see it |
| --- | --- | --- |
| Identity or phone verification | Your identity information or access to a phone number | Features requiring verification, such as attendance rewards or friend invitations |
| Age confirmation | Whether your account meets the requirements for adult content | When turning off the Safety Filter or enabling Show Sensitive Content |

Korean identity verification also checks adult eligibility using the verified date of birth. For international accounts, complete **phone verification** and **age self-confirmation** separately when prompted.

## 1. Check the verification method for your account

Your verification flow depends on the policy assigned to your account and its verification history. Follow the verification screen shown for your account.

The standard flows are listed below. Follow the instructions on the verification screen that opens for you.

| Account verification policy | Identity or phone check | Age check |
| --- | --- | --- |
| Korean service | Mobile identity verification | Eligibility calculated from the verified date of birth |
| Japanese, Taiwanese, or English service | SMS verification with a supported phone number | Self-confirmation that you meet the age shown on screen |

If the screen is unexpected or you see an account-country error, see [Getting help](#getting-help).

## 2. Where to start

First, [sign in to MYMI](/account/login-profile.md). Open the feature you want to use, and it will show any required verification steps.

- **Attendance Check or Invite Friends**: Open the menu in Profile and follow the verification prompt.
- **Safety Filter**: If age confirmation is needed, a prompt appears when you try to turn the filter off.
- **Show Sensitive Content**: Enabling this under **Profile → Settings & Support** may require age confirmation.

On the website, the Safety Filter is on Home. In the app, it may appear on **Home** or under **Profile → Settings & Support**, depending on the interface available to you. If Profile contains **Safety Filter**, use that setting.

**Turning the filter OFF** and **turning Show Sensitive Content ON** use opposite toggle directions. Check the setting's name and current state.

## 3. Complete Korean identity verification

If your account is directed to Korean identity verification:

1. Select **Verify Now** or **Verify Age** in the prompt.
2. Enter the information requested on the identity verification screen.
3. Complete verification with a **mobile phone registered in your own name**.
4. Return to MYMI and check the completion message.
5. Return to the feature you wanted to use, such as attendance or filter settings.

| Platform | How verification opens |
| --- | --- |
| Desktop website | In a pop-up window |
| Mobile website | On a verification page, followed by a return to MYMI |
| Android or iOS app | On a verification screen inside the app |

### Adult eligibility under the Korean policy

For accounts under the Korean policy, adult-content eligibility begins on **January 1 of the year you turn 19**. For example, in **2026 this includes people born in 2007 or earlier**, without waiting for their birthday that year.

MYMI uses the **date of birth confirmed through identity verification** to determine adult eligibility. If the verified age meets the requirement, you can turn off the filter.

## 4. Verify an international phone number

If you see **Phone Verification**, enter the code sent by SMS. This checks that you have access to the number.

1. Select your phone number's country. Current choices are **Japan (+81), Taiwan (+886), and United States (+1)**.
2. Enter your own mobile number for that country. The number must match the selected country.
3. Select **Send code**.
4. Check the destination number shown on screen and enter the code you received.
5. Select **Verify** before the displayed expiry time.
6. Check the completion message, then return to the feature you were using.

If the message does not arrive, use **Resend code** after the displayed waiting period. If you entered the wrong number, select **Change number**. If the code expires or you exceed the attempt limit, follow the instructions to start again.

Select a phone country to receive the verification SMS at a number from that country. If your phone country is unsupported or verification is temporarily unavailable, check the error message and contact support.

## 5. Confirm your age

If **Age Confirmation** shows an age checkbox, follow these steps. The current self-confirmation threshold for the Japanese, Taiwanese, and English services is **18 or older**.

1. Read the age requirement and notice on screen.
2. Only if you meet the requirement, check **I confirm that I am 18 years of age or older.**
3. Select **Confirm**.
4. When the completion message appears, return to the previous screen.

You can complete this confirmation separately from phone verification. Other features, such as attendance rewards, may still require phone verification afterward.

If you do not meet the requirement or do not want to proceed, select **Maybe later**. Once you meet the requirement and confirm your age, continue to the filter settings in step 6.

## 6. Check your filter settings afterward

After verification, return to Home or Profile and **change the filter setting yourself**.

1. Return to Home or Profile, where you started verification.
2. Check the setting again. Set **Safety Filter to OFF** to disable it, or **Show Sensitive Content to ON** to enable that setting.
3. If you keep seeing a verification prompt, refresh the page or reopen the app.

To use adult features, complete the age confirmation required for your account and meet the verified age threshold.

## 7. If another account already used the verification details

If your identity details or phone number are linked to another account, check that you [signed in with the social account you originally used](/account/login-profile.md).

Verification details from a recently deleted account may be subject to a **30-day waiting period after deletion**. If you see a duplicate-link or waiting-period message, check the original account and the error before contacting support.

## Troubleshooting

| Situation | What to check |
| --- | --- |
| I am asked to log in | Sign in with your registered social account, then reopen the feature |
| The identity-verification window will not open on desktop | Check for a pop-up blocker notice and allow MYMI's verification pop-up |
| Mobile web verification does not return to MYMI | Return to the original page and refresh. If you used another app's built-in browser, try an external browser |
| The SMS code does not arrive | Check the country, number, SMS reception, and spam blocking. Resend after the waiting period |
| The code is incorrect or expired | Check the received code and the expiry time. If expired, resend or restart from phone-number entry |
| Too many requests or attempts | Stop repeating the request and follow the displayed waiting or restart instructions |
| The details are linked to another account | Check that you signed in to the account originally verified. Contact support if needed |
| The details were used by a recently deleted account | Check the notice about the 30-day waiting period after deletion |
| Changing the language does not change verification | The display language does not change your account's verification policy |
| I live overseas but see Korean identity verification | The screen follows your account's policy. Contact support if you cannot complete it |
| The age-confirmation button is disabled | Check the age affirmation only if you meet the requirement |
| Verification is complete, but the filter is still on | Confirm that age verification is complete, then change the filter on the original screen |
| I see an unsupported-country, account-country, or unavailable-service error | Record the error, try again later, or contact support |

## Getting help

Use **Profile → Discord → Contact Us** or [email support](mailto:contact@mymi.live). Include your MYMI ID, the feature where verification started, the error text, and whether you are using the web, Android, or iOS.

If you cannot complete the assigned flow, including while living overseas, contact support first. **Do not send identity-document copies or verification codes in advance.** Follow the procedure provided by support.
