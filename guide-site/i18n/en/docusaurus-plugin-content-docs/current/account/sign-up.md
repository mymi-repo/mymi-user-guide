# Sign up

To join MYMI, **sign in with a social account, then fill in your basic information**. You do not need to create a separate MYMI password.

If you already have an account, choose the same sign-in method and social account you used before. Use that account when moving between the website and app as well.

## 1. Choose a social account

1. Open the [MYMI website](https://www.mymi.live) or app.
2. Open the sign-in screen from **Profile** in the bottom menu. You can also start from a sign-in prompt shown while using MYMI.
3. Choose a social account and complete sign-in with that service.
4. If this is a new account, you will reach the MYMI sign-up form.

The available buttons depend on the website language and the app platform.

| Where you sign in | Sign-in methods |
| --- | --- |
| Website in English | Google, X, Apple |
| Website in Korean | Kakao, Google, Apple |
| Website in Japanese or Traditional Chinese | LINE, Google, X, Apple |
| Android app | Kakao, Google |
| iOS app | Apple, Kakao, Google |

Choose one of the buttons displayed on your screen. If the app does not offer the method you used before, use the website with the appropriate language setting.

> **To return to an existing account**
>
> If you already have an account but see the sign-up form, check the sign-in method and social account you selected. For example, if you have several Google accounts, choose the one you originally used for MYMI.

## 2. Fill in your basic information

Complete these four fields. If any value is already filled in, check that it is the one you want to use.

| Field | What it is used for | Requirements |
| --- | --- | --- |
| Display Name | The name characters use for you in a story; used for your default persona after sign-up | Up to 20 characters |
| Gender setting | The gender for your default persona | Female, Male, or Other |
| User ID | Your account identifier, such as `@moon_reader` | 3–20 characters; must pass format and availability checks |
| Nickname | The name shown to other users | Up to 30 characters |

For example, your display name could be `Haru`, your user ID `moon_reader`, and your nickname `Moonlight Reader`. Characters would call you Haru, while other users would see the nickname Moonlight Reader.

Your user ID does not replace social sign-in. Next time, sign in with the social account you used to register.

The current form does not ask for your date of birth. If a feature requires identity or adult verification, follow that feature's separate instructions after sign-up.

### User ID rules

- Use lowercase English letters, numbers, hyphens (`-`), and underscores (`_`).
- Use **3–20 characters**.
- Do not start or end with a hyphen or underscore.
- Do not use two or more hyphens or underscores in a row, including mixed combinations.
- Your ID must not already belong to another user.

| Example | Format check |
| --- | --- |
| `moon_reader`, `reader-123` | Valid formats; availability still needs to be checked |
| `ab` | Fewer than 3 characters |
| `_reader`, `reader-` | Starts or ends with an underscore or hyphen |
| `moon__reader`, `moon-_reader` | Consecutive underscores or hyphens |

Availability is checked automatically after you type your ID. Wait for **Available** before continuing. If the check fails, use **Check** next to the field to try again.

## 3. Review the agreements

Read each item and choose whether to agree.

| Item | Required to sign up? |
| --- | --- |
| Agree to Terms of Service | Required |
| Agree to collection and use of personal information | Required |
| Service guidelines | Required |
| Agree to receive marketing information | Optional |

**You can sign up without agreeing to receive marketing information.** Choosing Agree to all also selects this optional item, so check that the selection matches your preference.

## 4. Complete sign-up

You can select **Complete Sign Up** once all four fields are filled in, your user ID is available, and the three required agreements are selected.

MYMI creates a default persona from the display name and gender you entered. Choose a story on Home, or use [Persona settings](/account/persona.md) to describe your role in more detail.

## If you cannot sign up

| Problem | What to check |
| --- | --- |
| Complete Sign Up is unavailable | Check all four fields, the Available status for your ID, and the three required agreements |
| The ID has an invalid format | Check its length, first and last characters, and consecutive hyphens or underscores |
| The ID is already taken | Choose another ID and check again |
| The availability check fails | Check your connection and select Check again |
| Social sign-in fails or does not return to MYMI | Return to sign-in and try again; if you opened MYMI inside another app, try an external browser |
| The app is missing my sign-in method | Use the website; Apple sign-in is available there even on Android |
| I already registered, but MYMI asks for basic information again | Check that you selected your original sign-in method and social account |

See [Access MYMI](/getting-started/how-to-access.md) for connection problems. If the issue continues, include the error message and your device, app, or browser when contacting support.
