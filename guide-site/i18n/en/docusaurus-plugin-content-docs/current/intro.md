MYMI is an AI service where **you chat with the characters in a work, take part in its story, and create works of your own**. You can use it on the web and in the Android and iPhone apps.

If you're new, start with accessing MYMI and signing up. If you already use it, go straight to the feature you need. If you're stuck, look up the message on your screen in the [FAQ](/faq/faq.md).

</GuideHero>
