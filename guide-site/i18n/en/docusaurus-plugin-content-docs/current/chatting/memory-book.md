# Long-term memory & memory fragments

As a conversation grows, MYMI summarizes its history as **Long-term Memory** and records significant moments as **Memory Fragments**. You can view them separately under **Memory Management** in a chat room's ⋮ menu. The chat features work the same way for V1 and V2 stories.

> **Story settings are separate.** A creator edits V1 world and character settings or a V2 prompt and lorebook in the story editor. The memories on this page come from the **conversation you have had** inside the story.

## What is the difference?

- **Long-term Memory:** A short summary of the conversation's overall flow, relationships, and events. It is not a word-for-word archive of past messages.
- **Memory Fragments:** Separate cards for important moments. A card may show a title, related characters, and the range of conversation turns. Select it to expand the details.
- **User Note:** A memo that **you write and save**. Use it to state a name, relationship, promise, or speaking style that the AI should keep in mind.

Long-term memory and fragments are created automatically. A short chat, or one that is still being processed, may have neither yet. Automatic memory cannot reproduce every old sentence and detail perfectly.

## 1. View long-term memory

1. Select ⋮ at the top right of the chat screen.
2. Under **Memory Management**, select **Long-term Memory**.
3. Read the summary. If the screen says **No long-term memory yet**, continue chatting and check again later.

This screen is for reading. It has no field or Save button for editing the summary. If a new summary does not appear immediately, continue the conversation and reopen the room to check it.

> **About Extend Memory:** The screen shows an **Extend Memory · 500 → 2,000 characters** switch. In the current web and app versions, this switch is not connected to a saved setting or the actual summary length. Turning it on does not confirm that your summary has expanded to 2,000 characters.

## 2. Find memory fragments

1. Select ⋮ at the top right, then **Memory Management → Memory Fragments**.
2. Look through the cards by title, related characters, and turn range. A label such as **T10–T20** identifies the range of conversation turns.
3. Select a card to expand its content; select it again to collapse it.
4. Enter an event, character, or situation in the search field to find **related fragments**. Clear the search to return to the full list.
5. Scroll to see more. In the app, select **Load more** when it appears.

Search looks for similar meaning, so a result may appear even if it does not contain your exact words. It may also miss the fragment you wanted. If the list says **No memory fragments**, continue chatting and check again later.

## 3. Turn fragment use on or off

At the top of the Memory Fragments screen, the web switch is labeled **Use Memory Fragments**. In the app it is labeled **Use Memory**. When it is on, later responses can look up relevant fragments. Turning it off omits those fragment search results from later responses.

- Turning the switch off **does not delete existing fragments**. You can turn it on again.
- It **does not disable or delete Long-term Memory**. The conversation summary is handled separately.
- The switch is not saved as a permanent account setting. Check its state when you reopen a room, browser, or app.
- During a guest trial, the server does not use fragment recall even if the switch appears on. Sign in to use it.

## Help the AI keep important details straight

For example, **two characters reconciling** may be part of the overall long-term memory, while **a particular promise they made** may appear as a fragment. If that promise must guide future replies, write it explicitly in **User Note**. You can open and save the note from [Chat room settings](/chatting/chat-room-settings.md).

If the AI gets an earlier event wrong, check this room's summary and fragments first. You cannot edit them directly on these screens; put essential information in User Note or state it clearly in your next message.
