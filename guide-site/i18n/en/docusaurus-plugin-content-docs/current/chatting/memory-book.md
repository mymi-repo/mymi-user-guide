# Long-term memory & memory fragments

As a conversation gets longer, the AI may lose track of earlier parts. Here's where to check and how to fix it when a character forgets what happened.

## When a character forgets

1. In the ⋮ menu, open **Memory Management → Memory Fragments** and check that **Use Memory Fragments** is on.
2. Open **Memory Management → Long-term Memory** to see how the story so far has been summarized.
3. If something was summarized wrong, select **Edit** and fix it yourself. See [Edit or delete memories](#edit-or-delete-memories).
4. For missing details or settings that must hold to the end, write them in **Chat Settings → User Note** in the ⋮ menu and select **Save**.
5. It can also help to bring it up in your next message. For example: "Do you remember the place we promised to meet?"

## Three kinds of memory

| Type | What it is | Who makes it |
| --- | --- | --- |
| **Long-term Memory** | A short summary of the overall flow of the conversation so far | Created automatically as the conversation grows |
| **Memory Fragments** | Cards that each summarize one important moment | Created automatically as the conversation grows |
| **User Note** | A note with things you want remembered | You |

For example, the big picture that two characters made up goes into long-term memory, and the promise they made while making up becomes a memory fragment. If you want that promise kept, write it in your user note.

## View long-term memory

1. In the ⋮ menu, select **Memory Management → Long-term Memory**. The **Long-term Memory** tab of the **Memory** screen opens.
2. Read the summarized flow under **Story summary**.

At the top, you can see how many exchanges are left until the next summary. The AI reads this story with every reply and adds what happened next every 10 exchanges. When the story gets very long, the oldest lines are shortened and merged first, and some are removed if it's still too long, so put anything that must hold to the end in your **User Note**.

If you see "No story written yet", keep chatting. The first summary is written after 10 exchanges.

## Find memory fragments

1. In the ⋮ menu, select **Memory Management → Memory Fragments**. The **Memory Fragments** tab of the **Memory** screen opens.
2. On the **Map**, circles are characters and small diamonds are memory fragments. Select a fragment to open its card. Select a character to see only their memories. Your persona is marked **Me**.
3. Spread two fingers or select **＋** to zoom in, and fragment titles appear next to them. Drag to move around, and select **Show all** to go back to the full view. On a PC, you can also zoom with the mouse wheel.
4. **Recently recalled** shows the fragments the AI recalled for its last reply.
5. The map shows only the latest 24. To see them all, select **List**, and select **Load more** if there are many.
6. Type a scene or name in the search box at the top to find related fragments. It also finds fragments with a similar meaning.

## Edit or delete memories

Long-term memory and memory fragments are created automatically from the conversation, but you can edit them yourself on the **Memory** screen. You can also delete memory fragments. Your changes are used from the next reply.

**Edit long-term memory**

1. On the **Long-term Memory** tab, select **Edit** to the right of **Story summary**.
2. Rewrite it with one event per line, and delete lines you don't need. You can write up to 1,500 characters.
3. Select **Save**. At the next summary, the new story continues after this text.

**Edit or delete a memory fragment**

1. On the **Memory Fragments** tab, select a fragment to open its card.
2. Select **Edit** at the bottom of the card, change the title (up to 50 characters) and content (up to 400 characters), and select **Save**.
3. To delete it, select **Delete**, then select **Delete** again in the confirmation.

- In a branched chat room, edits and deletions apply only to that chat room. The original chat room's memories stay the same.
- If you delete messages to go back to an earlier point, your edited memories may go back to how they were before you edited them.

## Turn off memory fragments

**Use Memory Fragments** at the top of the **Memory Fragments** tab is on by default. When you turn it off, replies leave out memory fragments while you're in that chat room. Long-term memory and the user note are still used.

- Try turning it off for a while if the AI keeps bringing up the wrong memory fragment.
- It turns back on when you leave the chat room and come back.
- Memory fragments aren't used during the free trial without logging in.

## If you get stuck

<details>
<summary>It says "No story written yet"</summary>

The conversation is still short. The first summary is written after 10 exchanges. You can see how many exchanges are left at the top of the **Long-term Memory** tab.

</details>

<details>
<summary>Searching memory fragments finds nothing</summary>

Try searching with another character's name or an event. The most recent part of the conversation may not have been turned into fragments yet.

</details>

<details>
<summary>I want to delete a wrong memory</summary>

You can delete it on the **Memory** screen. For a memory fragment, select **Delete** at the bottom of its card. For long-term memory, select **Edit**, delete the line, and select **Save**. See [Edit or delete memories](#edit-or-delete-memories) for details.

</details>

<details>
<summary>Saving long-term memory says it was just updated</summary>

The story was summarized again while you were editing. Your text is still in the box. If you select **Save**, your text replaces the update. If you select **Cancel**, you'll see the newly updated story, and your text is discarded. If it says the memory is being updated, wait a moment and select **Save** again.

</details>

<details>
<summary>Memory fragments turned back on after I turned them off</summary>

They turn back on each time you enter the chat room. Turn them off again whenever you need to.

</details>
