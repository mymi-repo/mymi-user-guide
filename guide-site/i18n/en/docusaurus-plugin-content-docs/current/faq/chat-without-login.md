# Can I chat with AI without logging in?

Yes. On MYMI, you can chat with AI characters up to 5 times without signing up.

Open a work and select **Start chatting**, and a chat room opens right away without a login screen. The only works that need you to log in are adult works. This page reflects MYMI as of November 4, 2026.

## How the 5 trial chats are counted

- Each AI reply you get counts as one. Switching works doesn't start a new count: all works share the same 5.
- You can see how many you have left at the top of the ⋮ menu in the upper right of the chat room.

:::info[You may have none left from the start]
If the trial was used on the same internet connection (the same Wi-Fi, for example) in the last 7 days, a browser or app you open for the first time may start with none left. On a connection many people share, such as office, school, or café Wi-Fi, someone else's trial can cause this too. The same can happen in a browser or app where you logged in and then logged out, or when other conditions that prevent repeated trials apply. In that case, sign up or log in to chat.
:::

## What changes when you log in

| | Without logging in | After you sign up and log in |
| --- | --- | --- |
| Chatting with characters | Up to 5 times | You chat with Sparks. Each model uses a different number of Sparks per reply |
| Choosing a model | Not available. The trial model (currently **Gemini 3.8 Flash**) replies | Choose one with the ⚡ button to the left of the message box |
| User note and persona | No user note. For persona, you can only pick one from **Recommended personas** on the work page | Set them for each chat room |
| Adult works | Not available | Available after age confirmation (18 or older) |
| Creating works | You only see a login prompt | Create them from **Create** at the bottom |
| Your trial chat | When the 5 are used up, the message box locks and you're asked to sign up or log in | Moves to your new account if you sign up in the browser or app where you tried it |

You can buy Sparks, or get them once a day from Attendance Check after phone verification. See [Buying Sparks](/payment/payment-methods.md). To get a new reply or edit one in a chat room, see [Chatting](/chatting/chat-with-character.md).

## If you get stuck

<details>

<summary>What happens when I've used all 5?</summary>

The message box is locked, and a notice that the trial has ended appears at the top of the chat room. Once the last reply has finished, a login window opens too. If you closed it, select **Log in** on the notice to open it again. After you sign up or log in, you keep chatting with Sparks. A new account starts with no Sparks, so buy some or get them from Attendance Check after phone verification first.

</details>

<details>

<summary>Do Continue and Regenerate count too?</summary>

Yes. A reply you get from the ≫ button with an empty message box, a new reply from **Regenerate**, and a reply the model declined each count as one. Swiping through earlier replies with ‹ › doesn't count.

</details>

<details>

<summary>Can I chat without logging in on the app too?</summary>

Yes. From the first time you open the Android or iPhone app, you can pick a work and chat without logging in. The count and the notice after you've used all 5 work the same way as on the website. But if you used the trial on the website over the same internet connection (the same Wi-Fi, for example) in the last 7 days, the app may start with none left.

</details>

<details>

<summary>Will my trial chats be kept if I sign up?</summary>

Yes, if you select a login button in the browser or app where you tried MYMI and sign up with a social account you haven't used on MYMI before. All your trial chat rooms move to the new account, and if you signed up from the login window in a chat room, you return to that chat room afterward. They don't move if you log in to an account you already have, or sign up in a different browser or app. See [Sign up](/account/sign-up.md) for how to sign up.

</details>
