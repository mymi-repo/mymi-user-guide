# Create a story

Sign in and select **Create** in the bottom navigation to open the story editor. Prepare Basic info and a cover, fill in Prompt, Openings, and Settings, then select **Publish**.

Follow [Create a new story](create-work.md) from **Save draft → add a cover → write the prompt and openings → choose settings → Publish**.

## Edit a story you have made

Open **My Page → Story Management → Edit** on your story. MYMI opens the editor used to make it. Select **Apply changes** in the current editor, or **Done** in the last step of the legacy editor, to apply your edits.

A story made in the **legacy editor (1.0)** opens in its older seven-step editor. See [Legacy editor: edit an existing story](edit-existing-work.md) for those steps and how its fields map to the current editor. The legacy editor is **retired for new story creation**.
