# Create a new story

Sign in and select **Create** in the bottom navigation. The tabs appear in this order: **Basic info → Assets → Components → Prompt → Openings → Lorebook → Settings**. You can work in any tab.

For a first story, try **fill in Basic info → Save draft → add a cover → write a prompt and an opening → choose Settings → Publish**. Add assets, components, and lorebook entries when your story needs them.

## 1. Basic information and cover

**Basic info** contains what readers see when they find and open your story.

| Field | What to enter |
| --- | --- |
| Story title | Up to 30 characters. |
| One-line description | Introduce the mood in up to 40 characters. |
| Cover | Add 1–10 images by uploading them or choosing from Assets. Set the transition interval for multiple covers. |
| Description | Describe the plot, characters, and how to play for readers. |
| Genres | Choose one or two. |
| Hashtags | Add at least one tag that describes the story. |

Enter a title and one-line description, then select **Save draft** at the top right. This creates a draft and lets you upload cover and asset images or generate assets. Use **Creator guide** for play tips, and **Recommended models** to suggest up to five chat models. Both are optional.

Put **reader-facing descriptions in Basic info** and **instructions the AI reads when replying in Prompt**.

## 2. Write the story rules in Prompt

Open **Prompt** to tell the AI how to use your world, characters, and story rules. Choose a writing mode:

| Mode | How to use it |
| --- | --- |
| **Write it myself** | Write the world, characters, hidden facts, and progression rules together. If you use images, explain which image codes belong in which scenes. |
| **Basic** | Write the world, characters, and rules in **Work info**. When you add assets or components, fill in the meanings and usage rules that appear here. Review the assembled prompt below the fields. |

Separating character names, relationships, speech styles, the reader's role, and progression rules makes later edits easier.

For example, you can divide **Work info** into short sections like this. Replace the details with your own story:

```text
#### World
- **Place**: A library that guards a secret
#### Characters
- **Name**: Yoonseo
- **Role**: The librarian who welcomes the reader
#### Story rules
- **Reader's role**: A newly appointed librarian
- **First scene**: The reader meets Yoonseo at the locked shelves
```

## 3. Create the first message in Openings

In **Openings**, create at least one opening and fill in its **title** and **message**. Readers can choose a starting scene when you add more than one. Use **Preview** to check how it appears in chat.

To use an asset image, add the image and assign a code in **Assets**, then choose **Insert asset image** in Openings.

## 4. Use assets, components, and the lorebook

| Tab | When to use it | What to do |
| --- | --- | --- |
| **Assets** | Show images for particular scenes | Upload or generate images and give each an alphanumeric code. Create folders to organize characters. Copy the displayed image Markdown into a prompt or opening. |
| **Components** | Show a stat panel, inventory, or another on-screen element | Add component code. With the Basic prompt mode, also explain when the component should appear. |
| **Lorebook** | Supply extra information when a keyword appears | Add an entry name, trigger keywords, and the information for the AI. |

For example, a character folder named `A` with an image coded `1` produces the path `A/1`. Copy the Markdown shown in **Assets** into a prompt or opening to use that image.

These tabs are optional. If you add an item, check its required fields, image generation status, and codes before finishing.

## 5. Choose settings

In **Settings**, choose visibility, publishing scope (Original or General), monetization limits, image source, audience, content rating, and marketing consent. Choosing **Original** means publishing only on MYMI and keeping that setting for three months.

To suggest a role that readers can use in chat, add a **Recommended persona** with a name, gender, birth date, and description.

## Save and finish your story

Select **Save draft** at the top right as you work. Open the saved draft later from **My Page → Story Management**.

Select **Publish** when ready. If a required field is missing, the page opens its tab and shows what to fill in. Complete it and select the button again to reach the completion screen.

To edit a finished story, open it from **My Page → Story Management → Edit** and select **Apply changes** when done.
