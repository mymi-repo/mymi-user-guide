# Edit a work

You edit a work made in Simple mode on the same seven-step screen you made it on. It opens in the mode the work was made in, so editing a work made in Expert mode is in [Publish and edit](/create/publish#edit-a-published-work).

## How to open it and move around

1. In **Profile → Content Management**, select **Edit** on the work.
2. It opens in Simple mode. The **Creation mode** field at the very top is locked, and you see the **Basic Info** step first.
3. Go to the step you want to change and change it. You can jump straight there by selecting a tab at the top.
4. When you're done, use the next button to go to the last step, **Optional**, and select **Done**. It checks every step again and takes you to the **Work complete** screen.

Moving and saving work like this.

| Move | What's checked | What's saved |
| --- | --- | --- |
| Next button | The required items in this step | Everything you've changed so far |
| Select a tab to go **forward** | Every step before it | Everything you've changed so far |
| Select a tab to go **back** | Nothing | Nothing. It's saved together the next time you go forward |
| **Done** | Every step | Everything you've changed so far |

Uploading and deleting images in Assets, **saving** a situation description, and changing the ★ profile image reach the work right away, without the next button.

:::warning[A published work changes each time you move on]
In Simple mode, each time you select the next button or go forward by selecting a tab, your edits are saved to the work. If the work is already public, other users see the change from that moment. It doesn't wait the way **Apply changes** does in Expert mode. For a big rewrite, write the new text in a notepad first, then paste it in and move on.
:::

:::warning[Be careful when you delete images]
If you delete an asset image from a published work, it disappears from the work at once. If you put that image in the intro or it was being used in chats, it may no longer show. Before you delete, check the image lines in the intro too.
:::

## The first time you open an older work

Some fields didn't exist in works made earlier. When you first open one, the fields below may be empty, and you have to choose them before you can move past **Settings**.

- 1–2 **Genres**
- At least 1 of the **Hashtags** (**Audience** is chosen in the Audience card, not as a hashtag)
- **Monetization limits**
- **Marketing consent**

The cards and wording in Settings are now the same as in Expert mode. What each card means is in [Choose your work settings](/create/settings). The title can be up to 30 characters.

## What to change in each step

How to write in each step is the same as when you made the work.

| Step | What you can change | Guide |
| --- | --- | --- |
| **Basic Info** | Title, one-line description, worldview, characters, secrets | [Write the settings and the intro](/create/simple/write) |
| **Assets** | Adding and deleting images, situation descriptions, character links, the profile image, Unlock required | [Assets and AI images](/create/simple/assets) |
| **Intro** | Adding and deleting openings, titles, the first message | [Write the settings and the intro](/create/simple/write#the-intro) |
| **Settings** | Genres, hashtags, visibility, publishing scope, and more | [Choose your work settings](/create/settings) |
| **Lorebook · Components · Optional** | Lore entries, components, the description, recommended personas, Creator's Note | [Lorebook, components, and optional items](/create/simple/extras) |

## Change the visibility

- **To take the work down for a while**, choose **Private** in **Settings → Visibility** and select the next button to save.
- **To make a private work public**, choose **Public** on the same card and save. A work you change to public goes through review before other users see it. ([Publish and edit](/create/publish#make-a-private-work-public))
- A work whose **Publishing scope** is set to Original can't be changed for 3 months. The days left show on the card.

## If you get stuck

<details>
<summary>I selected Edit and the Creation mode field shows a lock</summary>

A work opened from Content Management opens in the mode it was made in, and you can't change the mode. To start a new work, select <strong>↺</strong> to clear the editor, then choose a mode. ([Before you start](/create/before-you-start#a-work-opened-from-content-management-keeps-its-mode))

</details>

<details>
<summary>It won't go to the next step</summary>

A required item is missing in an earlier step. Check the message at the top. In Assets, see whether there's at least 1 image, every image has a situation description, and a profile image is set. In Settings, see whether you chose the genres, hashtags, **Audience**, **Publishing scope**, **Monetization limits**, **Image source**, and **Marketing consent**.

</details>

<details>
<summary>A "You have unsaved changes" window appears</summary>

The Simple mode editor still holds unsaved content from another work or a new one. Select **Open** and that content is lost and the work you chose opens. To keep it, select **Cancel** and save first with the next button in the editor.

</details>

<details>
<summary>It says "Work not found."</summary>

The work was deleted on another device, or it isn't yours. The editor is cleared, so check in **Content Management** whether the work is still there.

</details>

<details>
<summary>There's no Prompt tab</summary>

Simple mode has no Prompt tab. If you want to write the prompt yourself, you have to make a new work in Expert mode. There's no button to change an existing work to Expert mode. ([Move to Expert mode](/create/simple/to-expert))

</details>

<details>
<summary>I want to undo a change I made by mistake</summary>

There's no undo button. Change the field again and save it with the next button. On a public work, a change you've already saved shows right away, so make a note first before a big rewrite.

</details>

<details>
<summary>I have the same work open on a PC and a phone and I'm editing both</summary>

Whichever you save last is what's kept. To continue on another device, select the next button where you were editing to save, then open the work on the other device from **Content Management** by selecting **Edit**. If you leave the editor for more than 5 minutes and come back with no unsaved changes on this device, it switches to the latest content on the server.

</details>
