# Publish and edit

When you select **Publish**, your work is made, and a work set to public goes through review before other users see it. You can edit your works any time from **Profile → Content Management**.

## From Publish to public

| Stage | What happens |
| --- | --- |
| Publish | Checks the required items and saves the work. If something is missing, it takes you to that tab and tells you. |
| Review | Checks safety rules and quality. We notify you when it's done. |
| Public | Other users can find the work and chat with it. |

You can chat with your own work right away, even during review. How long review takes can vary by work. **Adults only** works are shown only to users who have completed age confirmation.

The complete screen shows different guidance depending on the state of the work.

<ScreenStep>

- A new work set to **Public**: It's shown as **Under Review**, and becomes public to other users when the review is done. (The complete screen in [Create your first work](/create/first-work#5-publish))
- A work set to **Private**: Only you can see it. To make it public, change the visibility in Content Management. Review starts from then.

</ScreenStep>

<ScreenStep>

- If you edit a work that is already **Approved**: your changes show to other users right away. It doesn't go through review again every time you edit.
- However, if you change **Content rating** from Adults only to All ages, it goes through review again.

</ScreenStep>

## Content Management

<ScreenStep>

The works you made are gathered in **Profile → Content Management**.

1. **Edit**: Opens the work in the creation screen.
2. **⋮**: Opens a menu. It has **Delete**, and for a rejected work, **Request Re-review**.
3. A public work shows **Under Review**, **Approved**, or **Rejected**.

A draft you haven't published yet shows as **In progress**. Select **Profile** to open the work page.

</ScreenStep>

Use the search field and **Filter** (sort, visibility, approval status) at the top to find works. In **Dashboard**, see how a work is doing, such as message counts and Leaves earned.

## Edit a published work

<ScreenStep>

1. Select **Edit** in **Content Management**.
2. Make your changes.
3. Select **Apply changes** in the top bar.

A published work has no **Save draft**. So that a half-edited state is never made public, text and settings take effect only when you select **Apply changes**.

</ScreenStep>

:::warning[Assets take effect right away]
Adding, replacing, or deleting images in the Assets tab, and changing codes, reach the work right away, without waiting for **Apply changes**.

- If you change a code or delete an image, the image also disappears from existing chats that used it. To swap an image, keep the code and replace only the image.
- On a published work, you can't change folder names (character codes).
- You can't move an image to another character folder. You can move it out of the folder.
:::

:::tip[Apply changes before you close the screen]
Edits to a public work aren't saved automatically when you switch tabs. After you edit, select **Apply changes** before you close the screen.
:::

## Ask for a re-review of a rejected work

<ScreenStep src="/img/screens/en/manage-menu.webp" device="part" alt="Two work cards with the Rejected label. On the top card the ⋮ button is marked 1; on the bottom card, Request Re-review in the opened ⋮ menu is marked 2" caption="⋮ → Request Re-review">

If a review rejects your work, its card shows **Rejected**.

1. Select the **⋮** button on that work. When the menu opens, it covers the Rejected label.
2. Select **Request Re-review**.
3. Read the **Rejection Reason**.

</ScreenStep>

<ScreenStep>

4. Fix the work to match the reason, then select **Apply changes**. The steps are the same as in [Edit a published work](#edit-a-published-work).
5. Select **⋮ → Request Re-review** again.
6. If you like, write what you changed in the message field and send the request. On the web, select **Request Re-review** in the Rejection Reason window and then **Submit**. In the app, select **Request Re-review** at the bottom of the window. An administrator reviews the request and handles it.

</ScreenStep>

## Make a private work public

1. Select **Edit** in **Content Management**.
2. In **Settings → Visibility**, choose **Public**.
3. Select **Apply changes**, and review starts.

## Delete a work

In **Content Management**, select **⋮ → Delete** on the work, and select **Delete** once more in the confirmation window to delete it. A deleted work disappears from Content Management and from the work lists.

:::danger[A deleted work can't be restored]
There is no menu for bringing a deleted work back. If you only want to take it down for a while, open it with **Edit**, change **Settings → Visibility** to **Private**, and select **Apply changes**.
:::

:::info
The **↺** (Reset creation content) in the creation screen only clears the screen you're entering. Your saved draft stays in Content Management.
:::

## Recommended personas

<ScreenStep>

**Recommended personas** let you prepare personas that users can pick when they start a chat. Use them to suggest a protagonist that suits the world of your work. You don't have to make any.

If you make one, you need to fill in all four fields to publish.

- **Name**: Up to 20 characters
- **Gender**: Female or Male
- **Birth date**: Must be at least 14 years old
- **Details**: Describe the personality, background, and way of speaking so the AI knows how to treat a user playing this persona. Up to 1,000 characters

</ScreenStep>

## If you get stuck

<details>
<summary>I selected Apply changes, but other people don't see it right away</summary>

If the work is still under review, it becomes public after the review is done. If it's already approved, the change takes effect as soon as you apply it. Try refreshing the work page.

</details>

<details>
<summary>The Save draft button disappeared from my public work</summary>

A work you've already published is saved with one button, **Apply changes**. It's so that half-finished edits never go public.

</details>

<details>
<summary>I have the same work twice in Content Management</summary>

If you reset the creation screen and started over, the draft you made first stays as **In progress**. Open it with **Edit** to check, and delete drafts you don't need with **⋮ → Delete**.

</details>
