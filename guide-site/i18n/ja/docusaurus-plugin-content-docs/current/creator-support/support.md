# クリエイターになる・リーフ

自分の作品で他の利用者がたくさん会話すると、クリエイターに応募できます。クリエイターになると、自分の作品で使われた有料スパークの一部を**リーフ**として受け取り、リーフをスパークに変換して使えます。

好きなクリエイターを応援したいときは、[クリエイターを応援する](#クリエイターを応援する)へ進んでください。

## クリエイターに応募する

**マイページ → クリエイター**で、条件をどれくらい満たしているか確認できます。

| 条件 | 基準 |
| --- | --- |
| 会話量 | 他の利用者が自分の作品でした会話が5,000回以上。自分が自分の作品でした会話は数えません |
| 作品数 | 承認されて公開されている作品が3つ以上 |

1. 2つの条件の両方に**達成**と表示されたら、**クリエイター規約に同意します**の左にある四角いチェック欄を押してチェックします。文字を押すと規約が開きます。
2. **クリエイターに応募する**を押します。
3. 条件が確認されるとすぐにクリエイターになり、同じ画面にリーフと会話量が表示されます。

規約は[MYMIクリエイター規約](https://www.mymi.live/ja/legal/creator-terms)にあります。

## リーフをためる

クリエイターになると、他の利用者が自分の作品で**有料スパーク**を使って会話したときに使われたスパークの一部が、リーフとしてたまります。承認されて公開されている作品だけが対象で、無料スパークでした会話や、自分が自分の作品でした会話にはたまりません。

割合は、作品制作画面の**その他の設定**で選んだ**作品の公開範囲**と**画像の出典**によって変わります。

| 作品の公開範囲 | 画像の出典 | リーフの割合 |
| --- | --- | ---: |
| オリジナル | どちらでも | 5% |
| 一般 | 外部で制作 | 3% |
| 一般 | MYMIで生成 | たまりません |

たとえば、オリジナルの作品で他の利用者が有料スパークを100個使うと、リーフが5たまります。公式クリエイターは、オリジナルの作品の割合が7%です。

オリジナルは、MYMIだけで公開する作品です。オリジナルにすると、3か月間は解除できません。

**収益化の制限**で**収益化を制限**を選んだ作品には、リーフがたまりません。他作品のキャラクターや世界観を使った二次創作など、権利が自分のものでない作品のための設定です。オリジナルの作品でも、公式クリエイターでも同じです。制限を選んだあとの会話から適用され、すでにたまったリーフはそのままです。

:::warning[リーフは30日たつと失効します]
もらったリーフは、30日以内にスパークに変換しておきましょう。
:::

## リーフをスパークに変換する

1. **マイページ → クリエイター**で**保有リーフ**を確認し、**スパークに変換**を押します。
2. <strong>変換数量（100単位）</strong>を入力します。**全部**を押すと、変換できる分が自動で入ります。
3. もらえるスパークを確認して、**変換する**を押します。

| 区分 | 変換の割合 |
| --- | --- |
| クリエイター | 100リーフ = 80スパーク |
| 公式クリエイター | 100リーフ = 100スパーク |

- 100リーフから、100単位で変換できます。
- 手数料なしですぐに変換され、元には戻せません。
- 変換したスパークは、もらった日から1年間使えます。

## 作品の成果を見る

**マイページ → 作品管理 → ダッシュボード**を押すと、**クリエイターダッシュボード**が開きます。

- **総メッセージ**、**自分のメッセージ**、**獲得リーフ**をひと目で確認できます。
- 期間を**今日**や**7日**に切り替えて、日ごとの推移と人気作品のランキングを見られます。
- **作品別成果**で作品を押すと、くわしい数字を見られます。

ダッシュボードのメッセージ数は、応募条件の会話量とは数え方が違います。応募条件は**マイページ → クリエイター**で確認してください。

## 公式クリエイターになる

会話量が**50,000回以上**になると、**マイページ → クリエイター**の**公式クリエイター申請**の欄に**申請書を作成する**が表示されます。押すと申請書が開き、運営チームの審査を経て公式クリエイターになります。

公式クリエイターになると、次のように変わります。

- オリジナルの作品のリーフの割合が7%になります。
- 自分が自分の作品でした会話にもリーフがたまります。
- 100リーフを100スパークに変換できます。

:::info[日本のアカウントでは、リーフを現金にできません]
韓国に住んでいないクリエイターは、現在リーフの現金出金を利用できません。リーフはスパークへの変換だけに使えます。クリエイターの画面に、韓国ウォンの限度額が付いた**現金引き出し**が表示されることがありますが、日本のアカウントには当てはまりません。くわしくは[MYMIクリエイター規約](https://www.mymi.live/ja/legal/creator-terms)の第4条の2に書かれています。
:::

:::info[公式クリエイターの資格について]
公式クリエイターの承認は、作品の品質、利用状況、ポリシーの遵守状況などを総合して判断されます。承認されたあとも、運営の判断で変更または取り消されることがあります。くわしくは[MYMIクリエイター規約](https://www.mymi.live/ja/legal/creator-terms)の第3条に書かれています。
:::

## クリエイターを応援する

作品の詳細でクリエイターの名前を押すと、クリエイターのプロフィールが開きます。そのクリエイターの作品、**お知らせ**、**コメント**を見られます。

- **フォロー**を押すとボタンが**フォロー中**に変わり、そのクリエイターが新しい作品やお知らせを投稿すると通知が届きます。もう一度**フォロー中**を押すと、フォローを外せます。
- **コメント**に応援のメッセージを残せます。他のコメントに返信でき、自分のコメントは編集や削除ができます。
- **秘密コメント**にすると、自分とクリエイターだけが見られます。秘密の返信は、返信を受けた人にも見えます。
- クリエイターは、自分のプロフィールに付いたコメントを削除できます。元のコメントが削除されると、その下の返信も表示されなくなります。

フォローしたクリエイターと自分が書いたコメントは、**マイページ → マイアクティビティ**の**フォロー中**と**コメント**のタブでまとめて見られます。

## つまずいたときは

<details>
<summary>クリエイターに応募するが押せない</summary>

- 2つの条件の両方に**達成**と表示されている必要があります。
- **クリエイター規約に同意します**は、文字ではなく左の四角いチェック欄を押すとチェックされます。

</details>

<details>
<summary>作品を3つより多く作ったのに、作品数が変わらない</summary>

承認されて公開されている作品だけを数えます。審査中の作品や、非公開に変えた作品は含まれません。承認されたあとも、数字はすぐには変わらず、少し遅れて反映されます。

</details>

<details>
<summary>リーフがたまらない</summary>

次の会話にはリーフがたまりません。

- 他の利用者が無料スパークでした会話
- 自分が自分の作品でした会話（公式クリエイターはたまります）
- **作品の公開範囲**が一般で、**画像の出典**がMYMIで生成の作品
- 非公開の作品や、まだ承認されていない作品

</details>

<details>
<summary>スパークに変換が押せない</summary>

「リーフ100枚以上必要」と表示されているときは、リーフが100より少ない状態です。100リーフたまると変換できます。

</details>

<details>
<summary>現金引き出しを押しても何も起きない</summary>

韓国に住んでいない方は、現金引き出しを利用できません。リーフをスパークに変換してお使いください。

</details>

そのほかの困りごとは、[お問い合わせ](/faq/faq.md#お問い合わせ)からお知らせください。
