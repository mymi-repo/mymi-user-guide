# クリエイターを応援する

気に入った作品のクリエイターは、フォローやコメントで応援できます。自分で作品を作っているなら、クリエイターに応募して**リーフ**を受け取れます。

## 1. クリエイターのプロフィールを見る

作品の詳細でクリエイター名を押すと、クリエイターのプロフィールが開きます。そのクリエイターの作品、**お知らせ**、**コメント**を見られます。

## 2. フォローする

プロフィールの**フォロー**を押すと、そのクリエイターが新しい作品を公開したときにお知らせを受け取れます。もう一度押すとフォローを解除します。フォロー中のクリエイターは**マイページ → マイアクティビティ → フォロー中**で確認できます。

## 3. コメントを書く

クリエイターのプロフィールの**コメント**タブから応援のコメントを書けます。

- 自分のコメントは編集・削除できます。ほかのコメントに返信することもできます。
- **秘密コメント**にすると、自分とクリエイターだけが見られます。秘密の返信は、返信を受けた人も見られます。
- クリエイターは、自分のプロフィールに書かれたコメントを削除できます。元のコメントが削除されると、その下の返信も表示されなくなります。

自分が書いたコメントは**マイページ → マイアクティビティ → コメント**で確認できます。

## 4. クリエイターに応募する

**マイページ → クリエイター**で、応募条件の達成状況を確認します。

| 条件 | 基準 |
| --- | --- |
| 会話量 | ほかのユーザーが自分の作品で行った会話が5,000回以上 |
| 作品数 | 承認された作品が3つ以上 |

1. 2つの条件を満たしたら、**クリエイター規約に同意します**を選びます。
2. **クリエイターに応募する**を押します。
3. 条件が確認されると、クリエイターになります。

自分の作品で自分が行った会話は、会話量に含まれません。規約は[MYMIクリエイター規約](https://www.mymi.live/ja/legal/creator-terms)をご覧ください。

## 5. リーフを受け取る

クリエイターになると、ほかのユーザーが公開・承認済みの自分の作品で**有料スパーク**を使って会話したときに、使われたスパークの一部がリーフとして貯まります。無料スパークでの会話では貯まりません。

割合は、作品の**その他の設定**で選んだ**作品の公開範囲**と**画像の出典**によって変わります。

| 作品の公開範囲 | 画像の出典 | リーフの割合 |
| --- | --- | ---: |
| オリジナル | 問わない | 5% |
| 一般 | 外部で制作 | 3% |
| 一般 | MYMIで生成 | 貯まらない |

- 公式クリエイターは、オリジナル作品の割合が7%です。そのほかは同じです。
- 例えば、オリジナル作品で有料スパーク100個が使われると、5リーフが貯まります。
- 自分の作品で自分が行った会話では、リーフは貯まりません。公式クリエイターは自分の作品での会話も対象です。
- 制作画面で**収益化を制限**を選んだ作品は、リーフを受け取れない作品として案内されます。
- 受け取ったリーフは**30日以内**に使う必要があります。期限が切れる前にスパークに変換してください。

## 6. リーフをスパークに変換する

1. **マイページ → クリエイター**で**保有リーフ**を確認し、**スパークに変換**を押します。
2. <strong>変換数量（100単位）</strong>を入力します。**全部**を押すと、変換できる数量が入ります。
3. 受け取るスパークを確認し、**変換する**を押します。

| 区分 | 変換レート |
| --- | --- |
| クリエイター | 100リーフ = 80スパーク |
| 公式クリエイター | 100リーフ = 100スパーク |

- 100リーフ以上から、100単位でのみ変換できます。
- 手数料なしですぐに変換され、元に戻せません。
- リーフから変換したスパークは、受け取った日から1年間使えます。

## 7. クリエイターダッシュボードを見る

**マイページ → 作品管理 → ダッシュボード**を押すと、**クリエイターダッシュボード**が開きます。

- **総メッセージ**、**自分のメッセージ**、**獲得リーフ**をひと目で確認できます。
- 期間を**今日**または**7日**に切り替えて、日別推移と人気作品のランキングを確認できます。
- **作品別成果**で作品を押すと、詳しい数値を確認できます。

ダッシュボードのメッセージ数は、応募条件の会話量とは数える範囲が異なります。応募条件は**マイページ → クリエイター**で確認してください。

## 8. 公式クリエイター

会話量が**50,000回**を超えると、**マイページ → クリエイター**の**公式クリエイター申請**が使えるようになります。**申請書を作成する**を押すと申請書に移動し、運営チームの審査を経て公式クリエイターになります。

公式クリエイターには、次のような違いがあります。

- オリジナル作品のリーフの割合が7%になります。
- 自分の作品での会話でもリーフが貯まります。
- 100リーフを100スパークに変換できます。
- 収益分配の条件は、[MYMIクリエイター規約](https://www.mymi.live/ja/legal/creator-terms)と個別にご案内する条件に従います。収益分配は18歳以上の方が対象です。
