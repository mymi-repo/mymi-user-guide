# スパークのチャージ

**スパーク**は、MYMIでAIの返信を受け取るときに消費するものです。返信を1回受け取るたびに、選んだAIモデルの価格ぶんが引かれます。モデルごとの価格は[AIモデルガイド](/chatting/ai-models.md)で確認できます。

スパークが足りなくなったら、チャージするか、出席チェックと友達招待で無料でもらえます。

## チャージ画面を開く

1. ログインして、**マイページ**の**マイスパーク**を押します。
2. **スパーク管理**で**スパークをチャージ**を押します。

会話中にスパークが足りないという案内が出たときは、その案内の**チャージする**を押しても開けます。チャットルーム右上の⋮メニューのいちばん上に表示されている残りのスパークを押しても、チャージ画面が開きます。

## ウェブでチャージする

ウェブでは**PayPal**を使い、日本円（JPY）で支払います。PayPalに対応したクレジットカードやデビットカードなども使えます。

1. チャージ画面でパッケージを選びます。
2. **商品**と**合計金額**を確認し、その下の支払時期・方法、提供時期、返品・返金の説明を読みます。販売事業者などの表示は**特定商取引法に基づく表記を見る**で確認できます。
3. PayPalのボタンを押して、PayPalの画面で支払いを完了します。
4. MYMIに戻り、チャージが完了した案内を確認します。

未成年の方は、法定代理人の同意を得たうえでスパークを購入してください。

| ¥600 | 5,000 | |

## アプリでチャージする

アプリでは、iPhoneは**App Store**、Androidは**Google Play**で支払います。

1. チャージ画面で商品を選び、**購入する**を押します。
2. ストアの支払い画面で支払いを完了します。
3. チャージが完了した案内を確認します。

アプリの価格はストアに登録された価格で、ウェブとは異なります。2026年10月4日時点の価格です。支払う前に、画面とストアの支払い画面の金額を確認してください。

| もらえるスパーク | App Store・Google Play |
| ---: | ---: |
| 5,000（初回チャージ商品） | ¥360 |
| 5,000 | ¥710 |
| 10,000 | ¥1,420 |
| 31,500 | ¥4,280 |
| 55,000 | ¥7,080 |
| 115,000 | ¥14,200 |

アプリの初回チャージ商品も、認証なしで買えます。ウェブとアプリを合わせてアカウントにつき1回なので、ウェブの¥300の商品をすでに買っている場合は、アプリでは買えません。

## 無料でスパークをもらう

### 出席チェック

**マイページ → 出席チェック**で**今日の報酬を受け取る**を押すと、1日に1回スパークがもらえます。電話番号認証を済ませたアカウントだけが受け取れます。まだ認証していないときは、ボタンを押すと認証の画面が開きます。

| 連続出席 | もらえるスパーク |
| --- | --- |
| 1〜9日目 | 200から始まり、1日ごとに20ずつ増えます（200、220、240、260、280、300、320、340、360） |
| 10日目 | 400 |

- 10日続けると、合計2,920スパークがもらえます。次の日からは1日目に戻ります。
- 1日でも休むと、1日目からやり直しです。
- 日付は毎日午前0時（日本時間）に切り替わります。

### 友達招待

1. **マイページ → 友達招待**で**マイ推薦コード**をコピーして友達に送るか、**友達にシェアする**で招待リンクを送ります。
2. 友達は登録してから**7日以内**に電話番号認証を済ませ、自分の**マイページ → 友達招待**の**推薦コード入力**にコードを入れて**推薦コードを登録**を押します。招待リンクから登録した場合は、電話番号認証が終わるとコードが自動で登録されます。
3. コードを登録した日から**30日以内**に友達が初めて有料のチャージをすると、あなたと友達の二人がそれぞれ**1,500スパーク**をもらえます。

:::info[友達がMYMIで初めて購入する場合だけです]
報酬が出るのは、友達アカウントの最初の有料チャージだけです。ウェブとアプリを合わせて一度でもチャージしたことがある友達を招待しても、二人とも報酬はもらえません。自分の推薦コードは自分では登録できません。
:::

### イベント

イベントやコンテストでスパークをもらえることもあります。もらえる条件と使える期間は、各イベントのお知らせで確認してください。

## スパークの有効期間

スパークは、もらった方法によって使える期間が違います。期間が過ぎると自動的になくなります。会話では、**期間が先に終わるスパークから**使われます。

| もらった方法 | 使える期間 |
| --- | --- |
| チャージ（決済）、リーフの変換 | もらった日から1年 |
| 出席チェック | もらった日から14日 |
| 友達招待の報酬 | もらった日から30日 |
| イベント | お知らせに書かれた期間（指定がなければ14日） |
| コンテストの報酬 | もらった日から180日 |

**マイページ → マイスパーク**を押すと、**スパーク管理**で**有料スパーク**と**無料スパーク**を分けて見られます。24時間以内に失効するスパークがあると、「⏰ 300個まもなく失効」のように表示されます。

## 履歴を見る

**マイページ → マイスパーク → 利用履歴を見る**を押すと、**スパーク使用履歴**が開きます。

- **使用**タブ：会話で使ったスパークと、期間が過ぎて失効したスパーク
- **チャージ**タブ：決済、出席チェック、友達招待、リーフの変換でもらったスパーク。返信を作れなくて戻ってきたスパークもここにあります

## つまずいたときは

<details>
<summary>初回チャージ商品を買えない</summary>

- 「既にご利用済みのプロモーション商品です。」や「そのプロモーション製品は既に使用しています。」と表示されたときは、すでに買っています。アカウントにつき1回だけ買えます。

</details>

<details>
<summary>支払ったのにスパークが入らない</summary>

もう一度支払わないでください。ウェブはチャージ画面を再読み込みし、アプリは完全に閉じてから開き直します。それでも入らないときは、[スパークが入らないとき](/payment/refund.md#スパークが入らないとき)に沿ってご連絡ください。

</details>

<details>
<summary>「決済がキャンセルされました。」と表示される</summary>

支払いを最後まで終える前に支払い画面を閉じると、こう表示されます。パッケージを選ぶところからやり直してください。それでもPayPalや銀行から支払いの通知が届いたときは、[スパークが入らないとき](/payment/refund.md#スパークが入らないとき)に沿ってご連絡ください。

</details>

<details>
<summary>PayPalのボタンが表示されない</summary>

ページを再読み込みして、パッケージを選び直してください。

</details>

<details>
<summary>支払い画面が開かない、または支払ったあとMYMIに戻らない</summary>

LINEやInstagramなどのアプリの中でMYMIを開いている場合は、ChromeやSafariで[www.mymi.live](https://www.mymi.live)を開いて、もう一度試してください。

</details>

<details>
<summary>アプリとウェブで価格が違う</summary>

アプリはストアに登録された価格で支払うので、ウェブの価格とは異なります。ウェブとアプリは同じアカウントなので、どちらで買ったスパークも一緒に使えます。

</details>

<details>
<summary>出席チェックの報酬を受け取れない</summary>

- 電話番号認証を済ませたアカウントだけが受け取れます。**今日の報酬を受け取る**を押すと認証の画面が開きます。
- 「既にチェックイン済みです。」と表示されたときは、今日の報酬はすでに受け取っています。午前0時（日本時間）を過ぎると、また受け取れます。

</details>

<details>
<summary>友達招待の報酬が入らない</summary>

- 友達が登録から7日以内に電話番号認証を済ませてコードを登録したか確認してください。「推薦コードの入力期限が過ぎました。」と表示されたときは、7日が過ぎています。
- コードを登録した日から30日以内に、友達が初めて有料のチャージをする必要があります。コードを登録する前にチャージしたことがある場合は、報酬が出ません。

</details>

<details>
<summary>スパークが減った</summary>

期間が過ぎたスパークは自動的になくなります。**スパーク使用履歴**の**使用**タブで、会話で使ったスパークと失効したスパークを見られます。それぞれの使える期間は[スパークの有効期間](#スパークの有効期間)にまとめています。

</details>

決済についてのお問い合わせは、[contact@mymi.live](mailto:contact@mymi.live)までお送りください。決済日、決済方法、決済金額、MYMIのID（**マイページ**のニックネームの下の`@ID`）、PayPalの取引IDを書いていただくと、早く確認できます。
