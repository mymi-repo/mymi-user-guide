# スパークのチャージ

**スパーク**は、作品の登場人物と会話するときに使うアイテムです。メッセージを送るたびに、選んだAIモデルと返答の長さに応じてスパークが消費されます。モデルごとの消費量は[AIモデルガイド](/chatting/ai-models.md)をご覧ください。

| 種類 | 説明 |
| --- | --- |
| スパーク | 会話に使います。チャージするか、出席チェック・友達招待・イベントで受け取れます |
| リーフ | クリエイターが作品の利用に応じて受け取る報酬です。スパークに変換して使えます。[クリエイターを応援する](/creator-support/support.md)をご覧ください |

スパークの購入は、利用規約により18歳以上の方のみご利用いただけます。

## 1. チャージ画面を開く

1. **マイページ**で**マイスパーク**を押します。
2. **スパーク管理**で**スパークをチャージ**を押します。

会話中にスパークが足りないという案内が出たときや、チャットルームの<strong>⋮</strong>メニュー上部の残高を押したときも、チャージ画面に移動します。チャージにはログインが必要です。

## 2. ウェブでチャージする

ウェブでは**PayPal**で、日本円（JPY）でお支払いいただきます。PayPalが対応するクレジットカードなども使えます。

1. チャージ画面で商品を選びます。
2. 商品の下に表示される**商品**、**合計金額**、**最終確認事項**（販売事業者、価格、支払時期、提供時期、返品・返金）を確認します。
3. 年齢確認がまだの場合は**年齢確認をする**を押し、18歳以上であることを確認します。
4. 表示されたPayPalのボタンを押し、PayPalの画面で支払いを完了します。
5. MYMIに戻り、チャージ完了の案内を確認します。

| 価格（税込） | 受け取るスパーク | 案内 |
| ---: | ---: | --- |
| ¥280 | 5,000 | **初回割引**。アカウントにつき1回限り |
| ¥550 | 5,000 | |
| ¥1,080 | 10,000 | |
| ¥3,280 | 31,500 | ボーナス1,500を含む |
| ¥5,480 | 55,000 | ボーナス5,000を含む |
| ¥10,800 | 115,000 | ボーナス15,000を含む |

表示価格がお支払いいただく総額です。ご利用のカード会社や決済事業者の規約により、海外利用手数料などがかかる場合があります。初回割引の商品は、**ウェブとアプリを合わせてアカウントにつき1回**購入できます。

販売事業者や返品・返金の条件は[特定商取引法に基づく表記](https://www.mymi.live/ja/legal/transaction-info-refund-policy)をご覧ください。

## 3. アプリでチャージする

アプリでは**App Store**（iOS）または**Google Play**（Android）のアプリ内課金でチャージします。

1. チャージ画面で商品を選び、**購入する**を押します。
2. ストアの支払い画面で支払いを完了します。
3. チャージ完了の案内を確認します。

アプリの価格はストアに登録された価格で、ウェブの価格とは異なります。2026年9月時点の価格は次のとおりです。ストアの事情で変わる場合があるため、購入前に画面とストアの支払い画面の金額を確認してください。

| 受け取るスパーク | App Store・Google Play |
| ---: | ---: |
| 5,000（初回割引） | ¥380 |
| 5,000 | ¥680 |
| 10,000 | ¥1,380 |
| 31,500 | ¥4,180 |
| 55,000 | ¥7,000 |
| 115,000 | ¥13,800 |

アプリの初回割引の商品は、[電話番号認証](/account/adult-verification.md)を完了したアカウントのみ購入できます。

## 4. 無料でスパークをもらう

### 出席チェック

**マイページ → 出席チェック**で**今日の報酬を受け取る**を押すと、1日1回スパークを受け取れます。電話番号認証を完了したアカウントが対象です。

| 連続出席 | 受け取るスパーク |
| --- | --- |
| 1〜9日目 | 200から1日ごとに20ずつ増えます（200、220、240、260、280、300、320、340、360） |
| 10日目 | 400 |

- 10日間続けると合計2,920スパークを受け取れます。11日目からは再び1日目の報酬になります。
- 1日でも出席しないと、1日目からやり直しになります。
- 日付は日本時間の午前0時に切り替わります。

### 友達招待

**マイページ → 友達招待**で、**マイ推薦コード**を友達に送るか、**友達にシェアする**で招待リンクを送ります。

1. 友達は登録から**7日以内**に電話番号認証を完了し、推薦コードを登録します。招待リンクから登録した場合は、電話番号認証が終わるとコードが自動で登録されます。
2. 友達がコードを登録した日から**30日以内**に初めて有料決済を行うと、あなたと友達にそれぞれ**1,500スパーク**が付与されます。

コードを登録しただけでは付与されません。自分のコードは登録できません。

### イベント

運営のイベントやコンテストでスパークを受け取れることもあります。条件は各イベントのお知らせをご確認ください。

## 5. 有効期限を確認する

スパークは受け取り方によって使える期間が異なり、期限を過ぎると自動で失効します。会話では、**期限が早く切れるスパークから**消費されます。

| 受け取り方 | 使える期間 |
| --- | --- |
| チャージ（購入）、リーフからの変換 | 受け取った日から1年 |
| 出席チェック、イベント | 受け取った日から14日 |
| 友達招待の報酬 | 受け取った日から30日 |
| コンテストの報酬 | 受け取った日から180日 |

**スパーク管理**では**有料スパーク**と**無料スパーク**を分けて確認できます。24時間以内に失効するスパークがあると、⏰マークとともに「まもなく失効」と表示されます。

## 6. 利用履歴を見る

**マイページ → マイスパーク → 利用履歴を見る**を押すと、**スパーク使用履歴**が開きます。

- **使用**タブ：会話に使ったスパークと、期限切れで失効したスパーク
- **チャージ**タブ：購入、出席チェック、友達招待、リーフからの変換で受け取ったスパーク。返答の生成に失敗して戻ったスパークもここに表示されます

## チャージがうまくいかないとき

| 状況 | 確認すること |
| --- | --- |
| PayPalのボタンが表示されない | 年齢確認が完了しているか確認します。**年齢確認をする**が表示されていれば、先に年齢確認を行います |
| 初回割引の商品を購入できない | ウェブまたはアプリですでに購入していないか確認します。アプリでは電話番号認証も必要です |
| 支払ったのにスパークが増えない | ウェブはチャージ画面を再読み込みし、アプリは再起動します。それでも反映されない場合は、もう一度支払わずに[キャンセル・返金](/payment/refund.md)の案内に沿ってお問い合わせください |
| 支払い画面が開かない、支払い後にMYMIに戻らない | ほかのアプリ内のブラウザーで開いている場合は、普段使うブラウザーで開き直します |
| アプリとウェブで価格が違う | アプリはストアに登録された価格で決済されます |
| 出席チェックの報酬を受け取れない | ログインと電話番号認証を確認します。報酬は1日1回です |
| 友達招待の報酬が届かない | 友達が登録から7日以内にコードを登録したか、登録から30日以内に初めての有料決済をしたか確認します |

## お問い合わせ

決済に関するお問い合わせは[contact@mymi.live](mailto:contact@mymi.live)までお送りください。決済日、決済方法、決済金額、アカウントID、PayPal取引ID（アプリの場合はストアと注文番号）を添えると、確認がスムーズです。
