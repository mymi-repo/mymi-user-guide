# キャンセル・返金

返金の窓口は、**どこで支払ったか**によって異なります。ウェブで支払った場合はMYMIに、アプリで支払った場合はApp StoreまたはGoogle Playにお問い合わせください。

| 支払った場所 | 問い合わせ先 |
| --- | --- |
| ウェブ（PayPal） | MYMI（[contact@mymi.live](mailto:contact@mymi.live)） |
| iOSアプリ | Apple（App Store） |
| Androidアプリ | Google Play |

## 1. ウェブで購入したスパーク

ウェブでの購入は、[特定商取引法に基づく表記](https://www.mymi.live/ja/legal/transaction-info-refund-policy)と[利用規約](https://www.mymi.live/ja/legal/terms-of-service)第7条に従って対応します。

スパークはデジタルサービスの利用権利で、決済が完了するとすぐに付与されます。その性質上、**購入完了後の返品・キャンセル・返金は原則としてお受けしていません**。

ただし、次のような場合はお問い合わせください。

- 決済が完了したのに、スパークが正しく付与されない
- MYMIの重大な不具合で、購入したスパークを使えない
- 購入画面の表示と実際の提供内容が著しく異なる
- 法令や決済事業者の規則により返金が必要な場合

返金の可否、方法、処理期間は、当社の確認結果とPayPalなど決済事業者の規則に従って判断します。無料で付与されたスパーク、ボーナス、出席チェックやイベントの報酬は返金の対象外です。

18歳未満の方による決済が確認された場合は、法令と決済事業者の規則に従って必要な措置を行います。

### 問い合わせ方法

[contact@mymi.live](mailto:contact@mymi.live)に、次の情報を添えてメールでお送りください。

- 決済日
- 決済方法
- 決済金額
- アカウントID
- PayPal取引ID

## 2. アプリ内課金の返金

アプリで購入した場合は、ご利用のストアの購入履歴から返金をリクエストします。ストアの返金ポリシーと審査に従うため、MYMIが承認の可否を決めることはできません。

- **iOS**：Appleサポートの[返金をリクエストする](https://support.apple.com/ja-jp/118223)
- **Android**：Google Playヘルプの[返金ポリシー](https://support.google.com/googleplay/answer/2479637?hl=ja)

ストアで返金が承認されると、その購入で付与されたスパークは回収される場合があります。

## 3. 支払ったのにスパークが反映されないとき

返金をリクエストしたり、もう一度支払ったりする前に確認してください。

1. ウェブはチャージ画面を再読み込みし、アプリは完全に終了してから開き直します。
2. **マイページ → マイスパーク → 利用履歴を見る**の**チャージ**タブに記録があるか確認します。
3. それでも反映されない場合は、[contact@mymi.live](mailto:contact@mymi.live)にお問い合わせください。

| 支払った場所 | お問い合わせに添える情報 |
| --- | --- |
| ウェブ | 決済日、決済方法、決済金額、アカウントID、PayPal取引ID |
| アプリ | ストア（App Store・Google Play）、決済日、注文番号またはトランザクションID、アカウントID |

## お問い合わせ

決済・返金のお問い合わせは[contact@mymi.live](mailto:contact@mymi.live)で受け付けています。商品と価格は[スパークのチャージ](/payment/payment-methods.md)をご覧ください。
