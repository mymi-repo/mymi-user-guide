# キャンセル・返金

返金は、**どこで支払ったか**によって依頼する先が変わります。

| 支払った場所 | 依頼する先 |
| --- | --- |
| ウェブ（PayPal） | MYMIのメール [contact@mymi.live](mailto:contact@mymi.live) |
| iPhoneアプリ | Apple（App Store） |
| Androidアプリ | Google Play |

支払ったのにスパークが入らないときは、返金を依頼したり、もう一度支払ったりする前に、[この手順](#スパークが入らないとき)から確認してください。

## ウェブで支払った場合

### 返金してもらえる場合

ウェブでの購入は、[特定商取引法に基づく表記](https://www.mymi.live/ja/legal/transaction-info-refund-policy)と[利用規約](https://www.mymi.live/ja/legal/terms-of-service)第7条に従います。

スパークは、支払い完了後すぐにアカウントに反映され、すぐに使えます。そのため、**購入が完了したあとの返品・キャンセル・返金は原則としてお受けしていません**。ただし、次の場合は返金の依頼を確認します。

- 支払いが完了したのに、スパークがアカウントに入らない
- MYMIの重大な不具合で、購入したスパークを使えない
- 購入画面の表示と、実際に受け取った内容が大きく違う
- 二重に請求された、または自分以外の人が購入した
- 法令やPayPalの規則により、返金が必要になる

返金するかどうか、返金の方法と時期は、当社の確認結果とPayPalの規則に従って判断します。その購入のスパークを一部でも使っている場合は、使っていない分だけが対象になることがあります。出席チェック、イベント、友達招待で無料でもらったスパークは返金できません。

お住まいの地域の法令で認められている権利は、このガイドの説明によって制限されません。

### 返金を依頼する

1. [contact@mymi.live](mailto:contact@mymi.live)にメールを送ります。
2. MYMIのID（**マイページ**のニックネームの下の`@ID`）、決済日と決済金額、PayPalの取引ID、困っている内容を書きます。取引IDは、PayPalから届く領収のメールや、PayPalの取引履歴の詳細で確認できます。
3. 依頼の内容を確認して、メールで返信します。返金が承認された場合は、支払いに使った方法に戻ります。かかる期間は、PayPalやカード会社によって変わります。

## アプリで支払った場合

アプリでの支払いは、ストアの購入履歴から返金を依頼します。ストアの返金ポリシーと審査に従うため、MYMIが承認するかどうかを決めることはできません。

- **iPhone**：Appleサポートの[Appleで購入したAppやコンテンツの返金をリクエストする](https://support.apple.com/ja-jp/118223)に沿って進めます。
- **Android**：Google Playヘルプの[払い戻しに関するポリシー](https://support.google.com/googleplay/answer/2479637?hl=ja)に沿って進めます。

ストアで返金が承認されると、その支払いでもらったスパークは回収されることがあります。

## スパークが入らないとき

もう一度支払う前に、次の順に確認してください。

1. ウェブはチャージ画面を再読み込みし、アプリは完全に閉じてから開き直します。Androidアプリは、完了していない支払いをもう一度確認し、スパークが届くと「以前の購入を復元しました」と表示されます。
2. **マイページ → マイスパーク → 利用履歴を見る**の**チャージ**タブに、購入の履歴があるか確認します。
3. それでもなければ、下の情報を添えて[contact@mymi.live](mailto:contact@mymi.live)までご連絡ください。iPhoneアプリで開き直しても入らないときは、待たずにすぐにご連絡ください。

| 支払った場所 | 送る情報 |
| --- | --- |
| ウェブ | 決済日、決済金額、MYMIのID、PayPalの取引ID |
| アプリ | ストア（App StoreまたはGoogle Play）、決済日、注文番号または取引ID、MYMIのID |

## つまずいたときは

<details>
<summary>アプリで支払ったのですが、MYMIに返金を依頼してもいいですか？</summary>

アプリでの支払いの返金は、MYMIでは処理できません。App StoreまたはGoogle Playの購入履歴から依頼してください。支払いは済んだのにスパークが入らないときは、MYMIにご連絡ください。

</details>

<details>
<summary>スパークを少し使ったのですが、返金してもらえますか？</summary>

ウェブでの購入は、使っていない分だけが返金の対象になることがあります。MYMI側の不具合で正しく使えなかったなど事情がある場合は、[contact@mymi.live](mailto:contact@mymi.live)に状況を書いて送ってください。

</details>

<details>
<summary>PayPalや銀行に支払いの異議を申し立てました</summary>

異議の審査中は、その購入のスパークを保留することがあります。請求が取り消されたときは、そのスパークはアカウントから回収されます。できれば、異議を申し立てる前にご連絡ください。

</details>

<details>
<summary>退会する前に返金してほしい</summary>

退会すると残りのスパークがなくなるので、返金は退会する前に依頼してください。すでに退会している場合は、[contact@mymi.live](mailto:contact@mymi.live)に、退会したアカウントのMYMIのIDと決済の情報を送ってください。

</details>
