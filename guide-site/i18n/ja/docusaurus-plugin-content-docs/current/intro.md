# MYMI ユーザーガイド

MYMIは、**作品の登場人物と会話しながら物語に参加し、自分だけの作品も作れるAIサービス**です。Webとモバイルアプリで利用できます。

初めての方はアクセス方法とアカウント設定から、すでに利用している方は必要な機能からご覧ください。

## 初めて利用する方へ

1. **[MYMIとは？](getting-started/what-is-mymi.md)** — 作品の中でできることを知りましょう。
2. **[アクセス方法](getting-started/how-to-access.md)** — Webにアクセスするか、Android・iOSアプリをインストールします。
3. **[新規登録](account/sign-up.md)** — アカウントを作成してプロフィールを設定します。
4. **[会話を始める](chatting/chat-with-character.md)** — 気になる作品を選び、最初の会話を始めましょう。

## 会話を自分好みにしたい

| やりたいこと | ガイド |
| --- | --- |
| 作品の中で使う名前や役割を決める | [ペルソナ設定](account/persona.md) |
| 会話の進め方や画面の設定を変える | [チャットルーム設定](chatting/chat-room-settings.md) |
| 過去の出来事や重要な設定を管理する | [長期記憶と記憶のかけら](chatting/memory-book.md) |
| 会話に使えるAIモデルを知る | [AIモデル案内](chatting/ai-models.md) |

## 自分の作品を作りたい

作品を作るときは、世界観、登場人物、ユーザーが最初に出会う場面を用意します。会話用の画像、特定の設定を呼び出すロアブック、ステータス表示などのコンポーネントも追加できます。

現在、画面下部の**制作**から新しい作品を作ると、**作品制作2.0（V2）** のエディターが開きます。V2ではプロンプトに作品の設定を書き、画像やコンポーネントの使用ルールを結び付けます。V1で世界観・登場人物・秘密の各欄に書いていた内容も、このプロンプトで構成します。

既存のV1作品は、作品管理で作品を選んで**修正**するとV1エディターが開きます。編集方法は[既存のV1作品制作ガイド](character-creation/create-character.md)をご覧ください。
