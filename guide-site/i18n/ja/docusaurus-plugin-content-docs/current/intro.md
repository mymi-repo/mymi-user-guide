MYMIは、**作品の登場人物と会話しながら物語に参加し、自分だけの作品も作れるAIサービス**です。Webとモバイルアプリで利用できます。

初めての方はアクセス方法とアカウント設定から、すでに利用している方は必要な機能からご覧ください。

</GuideHero>

<Card to="/getting-started/how-to-access" icon="device" title="MYMIへのアクセス方法">Webにアクセスするか、Android・iOSアプリをインストールします。</Card>

## 自分の作品を作りたい

新しい**制作ガイド**では、例の作品をひとつ最初から最後まで作りながら作品制作画面をご案内します。ページは現在韓国語のみで、日本語訳を準備しています。

<CardGrid>
<Card to="/create/before-you-start" icon="compass" title="始める前に">作品制作画面の7つのタブと保存のしくみを確認します。</Card>
<Card to="/create/first-work" icon="pen" title="初めての作品を作る">表紙1枚と文章だけで制作完了まで進めます。</Card>
<Card to="/create/images" icon="image" title="画像を用意する">会話に表示する人物・背景の画像を作ります。</Card>
<Card to="/create/prompt" icon="book" title="プロンプトを書く">AIが読む設定を書きます。</Card>
</CardGrid>
