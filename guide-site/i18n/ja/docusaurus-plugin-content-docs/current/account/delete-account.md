# アカウントの退会

退会は、**MYMIアカウントの利用を終了する手続き**です。ログアウトやアプリの削除とは異なります。退会後は、そのアカウントの会話、作品管理、保有残高などを利用できなくなり、再登録しても以前のデータは新しいアカウントに引き継がれません。

> **最後の確認ボタンを押す前に確認してください。** 完了した退会を取り消したり、以前のアカウントを復元したりする機能はありません。しばらく利用を休みたい場合は、[ログアウト](/account/login-profile.md)を利用できます。

## 1. 退会前に確認すること

| 確認する項目 | 先に行うこと |
| --- | --- |
| ログイン中のアカウント | マイページのニックネーム・IDと、登録に使ったソーシャルアカウントを確認します。別のアカウントにログインしていないか確認してください |
| スパークなどの残高 | 残高と利用履歴を確認します。退会は、残高の移行や自動返金の手続きではありません |
| 決済の取り消し・返金 | 購入経路、領収書、注文番号を確認し、対応が必要な取引があれば退会前にお問い合わせください |
| 制作した作品・必要な内容 | 引き続き管理したい作品があるか確認し、残しておきたい自分の文章は事前に保管します |
| クリエイターの精算・対応中の問い合わせ | 精算、決済、トラブルに関する確認が残っている場合は、先に案内を受けてください |
| 削除したいコメント・公開投稿 | 退会だけですべての公開投稿がすぐに削除されるわけではありません。退会前に確認し、必要に応じてお問い合わせください |

ログインするアカウントを間違えた場合や、プロフィールだけを変更したい場合は、先に [ログイン・プロフィール設定](/account/login-profile.md) を確認してください。

## 2. ウェブ・アプリで退会する

ウェブとAndroid・iOSアプリで、退会画面への入り方は共通です。

1. 退会したいMYMIアカウントにログインします。
2. **マイページ**を開きます。
3. 上部の**プロフィール画像・ニックネーム・IDがある部分**を押し、**マイ情報の編集**を開きます。
4. **マイ情報**タブを選びます。**クリエイター**タブではありません。
5. 下へスクロールし、**詳細情報の入力欄の下にある「退会する」** を押します。
6. **本当に退会しますか？** の確認画面を読み、退会するアカウントが正しいか確認します。
7. 進める場合は、下の表にある最終確認ボタンを押します。
8. 処理が終わるまで待ちます。成功するとログアウトし、ホーム画面に戻ります。

| 利用環境 | 確認画面の最終ボタン | 送信前にやめる場合 |
| --- | --- | --- |
| PC・モバイルウェブ | **削除** | **キャンセル** |
| Android・iOSアプリ | **退会する** | **キャンセル** |

**確認画面を開くだけでは退会しません。** 最終ボタンを押す前ならキャンセルできます。最後のリクエストを送信した後は、画面を閉じても退会の取り消しにはなりません。

## 3. 退会後はどうなりますか？

| 項目 | 退会後の取り扱い |
| --- | --- |
| MYMIアカウント | 以前のアカウントの利用が終了します。同じソーシャルアカウントで再登録しても、新しいアカウントとして始まります |
| 会話・ペルソナ・個人の利用情報 | 以前のアカウントでアクセスしたり使い続けたりできません。再登録したアカウントには引き継がれません |
| 制作した作品 | 削除処理の対象となり、以前のアカウントで管理できなくなります。関連情報の整理は順次反映される場合があります |
| 保有残高 | 退会したアカウントのスパークなどの残高は利用できなくなり、新しいアカウントへ自動で移行されません。返金には別の手続きが必要です |
| 本人確認・電話番号認証 | 以前の認証状態は新しいアカウントに引き継がれません。認証情報の再利用制限も適用されます |
| コメント・公開投稿 | 退会だけですべての投稿がすぐに削除されるわけではありません。残っている投稿の対応や削除が必要な場合はお問い合わせください |

退会手続きの完了と、すべての関連記録がすぐに消去されることは別です。決済、返金、紛争対応、不正利用防止などに必要な記録は、所定の基準に従って保管される場合があります。保管・削除の基準や個人情報の削除請求については [プライバシーポリシー](https://mymi.live/ja/legal/privacy-policy) を確認してください。

この手続きは**MYMIからの退会**です。ログインに使ったGoogle・Appleなど、外部サービスのアカウント自体を削除するものではありません。

## 4. 再登録・認証情報の再利用に関する30日間の制限

| 種類 | 現在の制限 |
| --- | --- |
| 同じソーシャルアカウントでの再登録 | 退会後 **30日間** は制限されます。たとえば、登録に使っていた同じGoogleアカウントですぐに再登録することはできません |
| 退会したアカウントに紐づいていた本人確認情報・電話番号 | 退会後 **30日間** は、別のアカウントでの再利用が制限されます |

再登録と認証情報の再利用は、それぞれ別に確認されます。別のログイン方法を選んでも、最近退会したアカウントの本人確認情報や電話番号をすぐに移せるわけではありません。

**30日間は、退会を取り消せる猶予期間ではありません。** 制限が終了してから再登録しても、以前の会話、作品、残高、認証状態は自動で復元されません。

期間が過ぎても制限の案内が続く場合は、退会した時期、ログイン方法、エラーメッセージを添えてお問い合わせください。認証手順は [年齢確認・本人確認](/account/adult-verification.md) を参照できます。

## 5. 決済や返金の確認が残っている場合

**退会しても、決済の取り消しや返金が自動で申請されることはありません。** 残高が自動的に現金で返金されるわけでもありません。

- **ウェブで購入した場合：** 購入履歴、領収書、注文番号を確認してMYMIにお問い合わせください。
- **アプリで購入した場合：** 領収書でApp Store・Google Playなど実際の購入経路を確認し、その経路の返金手続きに従ってください。購入経路が分からない場合はMYMIにお問い合わせください。
- **返金やクリエイターの精算が進行中の場合：** アカウントと取引を確認しやすいよう、退会前にお問い合わせください。
- **すでに退会した場合：** 決済やアカウントについてメールで問い合わせできます。以前のMYMI ID、ログイン方法、該当する注文番号と決済日をご用意ください。

返金の可否と処理方法は、購入条件、利用状況、決済経路によって確認します。[利用規約](https://mymi.live/ja/legal/terms-of-service) と購入時の案内を参照してください。

## 6. 退会がうまくいかないとき

| 状況 | 確認すること |
| --- | --- |
| 退会ボタンが見つかりません | **マイ情報の編集 → マイ情報** タブの一番下を確認してください。クリエイタープロフィールの編集画面にはありません |
| ボタンを押すと確認画面だけが開きました | まだ最終リクエストは送信されていません。退会したい場合のみ、ウェブの **削除**、アプリの **退会する** を押してください |
| 処理中の表示が長く続きます | 少し待って接続状態を確認してください。反応がない場合はページやアプリを開き直し、状態が不明ならお問い合わせください |
| エラーが出て、退会できたか分かりません | エラー内容と発生時刻を記録してください。エラーだけで結果を判断せず、ログアウトの有無を確認し、アカウントの状態をお問い合わせください |
| 退会後にログインすると再登録の制限が表示されます | 同じソーシャルアカウントには退会後30日間の再登録制限が適用されます |
| 別のアカウントで電話番号・本人情報を認証できません | 最近退会したアカウントの認証情報であれば、30日間の再利用制限を確認してください |
| アプリを削除したのにアカウントが残っています | アプリの削除は退会ではありません。ウェブまたはアプリで上記の手続きを行ってください |
| 退会したアカウントに戻りたいです | サービス画面に退会の取り消し・復元機能はありません。再登録しても以前の情報は引き継がれません |

## お問い合わせ

退会前は **マイページ → Discord → お問い合わせ**、または [contact@mymi.live](mailto:contact@mymi.live) をご利用ください。退会後もメールでお問い合わせできます。

**MYMI ID、登録に使ったログイン方法、退会を試みた時期、ウェブ・Android・iOSのどれを使ったか、エラーメッセージ**をお知らせください。決済に関する問い合わせでは、該当する注文番号と決済日もご用意ください。

個人情報の開示・削除などを別途請求する場合は、[プライバシーポリシーのお問い合わせ案内](https://mymi.live/ja/legal/privacy-policy) に従ってください。
