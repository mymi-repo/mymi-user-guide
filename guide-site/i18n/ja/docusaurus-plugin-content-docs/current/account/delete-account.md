# アカウントの退会

:::danger[退会すると元に戻せません]
退会すると、会話やペルソナ、残っているスパークとリーフは使えなくなり、作った作品は削除されます。同じソーシャルアカウントでは30日間もう一度登録できず、再登録すると新しいアカウントとして始まります。しばらく休みたいだけなら、**マイページ → 設定とサポート → ログアウト**を使ってください。
:::

## 退会する前にすること

- **返金してほしい支払いがあれば、先に依頼してください。** ウェブでの支払いはPayPalの取引IDを添えて[contact@mymi.live](mailto:contact@mymi.live)へ、アプリでの支払いはApp StoreかGoogle Playに依頼します。方法は[キャンセル・返金](/payment/refund.md)にあります。
- **残っているスパークとリーフを確認してください。** 退会すると消え、新しいアカウントには移せません。
- **残したくないコメントは削除してください。** 退会してもアカウントが消えるだけで、書いたコメントは残ります。自分のコメントは**マイページ → マイアクティビティ → コメント**で探し、**開く**で移動してから、コメントのゴミ箱アイコンで削除します。
- **退会するアカウントか確認してください。** **マイページ**のいちばん上のニックネームと`@ID`を見ます。

## 退会する

1. **マイページ**のいちばん上、プロフィール写真とニックネームの行を押して**マイ情報の編集**を開きます。
2. **マイ情報**タブをいちばん下までスクロールします。
3. **詳細情報**欄のすぐ下、右側にある灰色の小さな文字の**退会する**を押します。
4. 「**本当に退会しますか？**」と表示されたら、退会するアカウントかもう一度確認します。
5. ウェブは**削除**、アプリは**退会する**を押すと退会します。やめるときは**キャンセル**を押します。
6. 退会が終わるとログアウトされ、ホームに移動します。

## 退会すると自分の情報はどうなりますか？

| 項目 | 退会すると |
| --- | --- |
| 会話、ペルソナ | もう見られません |
| スパーク、リーフ | 消えます。新しいアカウントには移せません |
| 作った作品 | 削除されます |
| 書いたコメント | そのまま残ります |
| 同じソーシャルアカウント | 30日間、もう一度登録できません |
| 認証した電話番号 | 30日間、ほかのアカウントで使えません |

30日たって再登録すると、新しいアカウントとして始まります。支払いや紛争の処理に必要な記録は、決められた期間保管されることがあります。どの情報をいつまで保管するかは[プライバシーポリシー](https://www.mymi.live/ja/legal/privacy-policy)にあります。

## つまずいたときは

<details>
<summary>退会するボタンが見当たらない</summary>

**マイ情報の編集**の**マイ情報**タブを開いているか確認してください。**クリエイター**タブにはありません。**詳細情報**欄の下の右側に、灰色の小さな文字であります。

</details>

<details>
<summary>退会できたかわからない</summary>

同じソーシャルアカウントでログインしてみてください。「再登録制限」と表示されれば退会は完了しています。いつもどおりログインできた場合はまだ退会していないので、もう一度試してください。

</details>

<details>
<summary>アプリを削除したのに、アカウントが残っている</summary>

アプリを削除しても、端末から消えるだけでアカウントは残ります。アカウントをなくしたい場合は、上の手順で退会してください。

</details>

<details>
<summary>退会を取り消したい</summary>

退会したアカウントは元に戻せません。30日たつと、同じソーシャルアカウントで新しく登録できます。

</details>

<details>
<summary>「再登録制限」として「退会後30日間は再登録できません。」と表示される</summary>

退会してから30日たっていません。30日たってからもう一度登録してください。別のソーシャルアカウントならすぐに登録できますが、認証した電話番号は退会から30日たつまで使えません。

</details>

<details>
<summary>退会したあとに支払いや返金について問い合わせたい</summary>

[contact@mymi.live](mailto:contact@mymi.live)までお送りください。退会したアカウントのMYMIのID、ログインに使ったソーシャルアカウント、支払日、PayPalの取引IDを書いてください。

</details>

そのほかの問題は、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)までお知らせください。退会したあとはメールでお問い合わせください。
