# ログイン・プロフィール設定

**マイページ**からログインし、自分の情報を管理できます。プロフィールを編集するときは、**会話で使う情報**と**ほかのユーザーに見せる情報**のどちらを変えたいか確認しましょう。

## 1. 既存のアカウントでログインする

1. [MYMIのウェブサイト](https://www.mymi.live/ja)またはMYMIアプリを開きます。
2. 画面下部の**マイページ**を選択します。ログインしていない場合は、ソーシャルログインのボタンが表示されます。
3. 登録時に使ったログイン方法とソーシャルアカウントを選びます。
4. ログイン後、上部のニックネームと`@ID`を見て、自分のアカウントか確認します。

ウェブとアプリで同じMYMIアカウントを使うには、登録時に使ったソーシャルアカウントを選んでください。Googleで登録した場合は、同じGoogleアカウントでログインします。

表示されるログインボタンは、ウェブサイトの言語や利用環境によって異なります。対応するログイン方法は[会員登録の案内](/account/sign-up.md)で確認できます。

> **登録済みなのに会員登録画面が表示される場合**
>
> 基本情報をもう一度入力する前に、ログイン方法とソーシャルアカウントを確認してください。Googleアカウントが複数ある場合、別のアカウントを選んでいる可能性があります。Appleで登録したのにAndroidアプリにボタンがない場合は、モバイルウェブでAppleログインを利用できます。

## 2. 変更したい項目を探す

マイページ上部の**プロフィール画像・ニックネーム・IDが表示されている部分**を押すと、**マイ情報の編集**が開きます。この画面には**マイ情報**と**クリエイター**の2つのタブがあります。

| 変更したい内容 | 操作する場所 |
| --- | --- |
| 名前・性別・生年月日・詳細情報 | マイ情報の編集 → **マイ情報** |
| ほかのユーザーに表示するニックネームと`@ID` | マイ情報の編集 → **マイ情報** |
| プロフィール画像・ウェブサイト・公開する紹介文 | マイ情報の編集 → **クリエイター → プロフィール編集** |
| 作品内で使う別の名前や役割 | マイページ → **ペルソナ設定** |

プロフィール画像は**クリエイター**タブで変更します。まだ作品を制作していないユーザーも、ここで公開プロフィールを編集できます。

## 3. マイ情報を編集する

**マイ情報**タブで項目を編集し、タブ上部の**変更を保存**を押すとプロフィールに反映されます。

| 項目 | 用途と確認事項 |
| --- | --- |
| 名前 | デフォルトのペルソナが会話で使う名前です |
| 性別 | デフォルトのペルソナにも反映されます。本人認証済みのアカウントでは変更できません |
| ニックネーム | ほかのユーザーに表示される名前で、クリエイター名にも使われます |
| ID | `@moon_reader`のようにアカウントを識別し、公開プロフィールのURLにも使われます |
| 生年月日 | デフォルトのペルソナにも反映されます。本人認証済みのアカウントでは変更できません |
| 詳細情報 | デフォルトのペルソナで会話するときに、キャラクターが参考にする情報です。**1,000文字以内**で入力します |

例えば、**名前**を`ハル`、**ニックネーム**を`月明かりの読者`にすると、デフォルトのペルソナは「ハル」という名前を使い、ほかのユーザーには「月明かりの読者」と表示されます。

### IDを変更するとき

IDは**3〜20文字**で、英小文字・数字・アンダースコア（`_`）・ハイフン（`-`）を使用できます。アンダースコアやハイフンを先頭・末尾に使うことはできません。また、この2つの記号は、組み合わせを変えた場合も連続して使用できません。

入力すると自動で重複を確認します。**使用可能**になったことを確認してから保存してください。確認に失敗した場合は、入力欄の横にある**確認**から再試行できます。IDを変更したら、以前共有したプロフィールのリンクも確認しましょう。

### 詳細情報とペルソナの関係

マイ情報で名前・性別・生年月日・詳細情報を保存すると、**アカウント情報とデフォルトのペルソナ**に反映されます。追加したペルソナを編集するには、[ペルソナ設定](/account/persona.md)からその項目を選んでください。

デフォルトの名前を変えても会話で別の名前が使われる場合は、使用中のペルソナを確認してください。作品ごとに異なる役割で会話したいときは、[ペルソナ設定](/account/persona.md)を利用します。

## 4. プロフィール画像と公開する紹介文を変更する

1. **マイページ → 上部のプロフィール部分 → クリエイター**タブを開きます。
2. **プロフィール編集**を押します。
3. 以下の項目を編集します。
4. 画像を選んだ場合は、アップロードが終わってから**保存**を押します。
5. 保存後、クリエイタータブで画像や紹介文が変わったことを確認します。

| 項目 | 設定方法 |
| --- | --- |
| プロフィール画像 | 画像部分の**追加する**または**変更する**を押し、端末の画像を選択します |
| ウェブサイト | ほかのユーザーに見せたいウェブサイトのURLを入力します |
| 紹介 | 公開プロフィールに載せる自己紹介や創作活動の紹介を、**10,000文字以内**で入力します |

画像のアップロードが終わってから**保存**を押すと、公開プロフィールに反映されます。アプリで写真へのアクセスを求められた場合は、使いたい写真へのアクセスを許可してください。

**クリエイター**タブでは、自分の公開紹介文、お知らせ・コメント、作品一覧も確認できます。制作中の作品を続けて編集する場合は、マイページの**作品管理**を開きます。

### ほかのユーザーに見える情報

公開クリエイタープロフィールには、**ニックネーム・ID・プロフィール画像・ウェブサイト・紹介**などが表示されます。**マイ情報の詳細情報**はこの公開紹介欄には表示されず、デフォルトのペルソナが会話で参考にする情報として使われます。

キャラクターに伝えたい設定は**詳細情報またはペルソナ**に、読者に向けた自己紹介は**クリエイター → プロフィール編集 → 紹介**に入力してください。

## 5. マイページからできること

| メニュー | できること |
| --- | --- |
| マイスパーク | 保有スパークや期限が近いスパークの確認、チャージ、利用履歴の確認 |
| 作品管理 | 制作した作品の状態確認と編集 |
| ブロック管理 | ブロックした作品・クリエイターの確認と解除 |
| ペルソナ設定 | 会話で使う役割の追加・編集・選択 |
| マイアクティビティ | フォロー中のクリエイターと自分が投稿したコメントの確認 |
| 出席チェック | 出席状況と報酬の確認 |

センシティブコンテンツに関する設定は、[成人認証の案内](/account/adult-verification.md)を参照してください。表示されるメニューや利用条件は、利用環境やアカウントの状態によって異なる場合があります。

## 6. ログアウトする

**マイページ → 設定とサポート → ログアウト**を押します。再び利用するときは、登録時と同じソーシャルアカウントでログインしてください。

ログアウトは、現在の端末でのログイン状態を終了する操作です。アカウント自体を削除する場合は、別の手続きである[退会](/account/delete-account.md)の案内を確認してください。

## 変更がうまくいかないとき

| 状況 | 確認すること |
| --- | --- |
| 「変更を保存」を押せない | 変更した項目があるか、必須項目に空欄やエラーがないか、変更したIDが使用可能か確認します |
| IDが確認中のまま、またはエラーになる | 確認が終わるまで待ちます。失敗した場合は通信状態を確認し、「確認」から再試行します |
| 性別や生年月日を変更できない | 本人認証済みのアカウントでは、この項目は変更できません |
| マイ情報に画像を変更するボタンがない | クリエイタータブの「プロフィール編集」から変更します |
| 写真を選んだのに反映されない | アップロードエラーやアクセス許可の案内を確認し、アップロード後に「保存」まで押したか確認します |
| 詳細情報を変えても公開紹介文が変わらない | 公開紹介文は「クリエイター → プロフィール編集 → 紹介」で別に編集します |
| 名前を変えても会話では別の名前が使われる | 使用中のペルソナを確認します。マイ情報の変更はデフォルトのペルソナに反映されます |
| 保存エラーになる、または変更が消える | 通信状態を確認し、画面を開き直して保存された内容を確認します。解決しない場合は、エラーメッセージと利用環境を添えてお問い合わせください |
