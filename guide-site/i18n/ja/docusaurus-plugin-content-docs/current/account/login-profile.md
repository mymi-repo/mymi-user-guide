# ログイン・プロフィール設定

登録したアカウントでログインし直し、自分の情報とプロフィール写真を変え、ログアウトする方法です。

## ログインする

1. 下のメニューの**マイページ**を押します。ウェブでは、ホーム右上の**ログイン**を押してもかまいません。
2. 登録したときのソーシャルアカウントのボタン（**LINEで続ける**、**Googleで続ける**、**Xで続ける**、**Appleで続ける**）を押してログインします。
3. ウェブでは、ログインが終わるとホームに移動します。**マイページ**のいちばん上にあるニックネームと`@ID`で、自分のアカウントか確認してください。

:::warning[登録したソーシャルアカウントでログインしてください]
MYMIのアカウントはソーシャルアカウントごとに別々です。別のソーシャルアカウントでログインすると**新規登録**画面が出ます。ここで登録すると会話もスパークもない新しいアカウントができるので、戻って最初に登録したソーシャルアカウントでログインしてください。
:::

## 変えたい項目を探す

**マイページ**のいちばん上、プロフィール写真とニックネームの行を押すと**マイ情報の編集**が開きます。ここに**マイ情報**と**クリエイター**のタブがあります。

| 変えたいもの | 開く場所 |
| --- | --- |
| キャラクターが呼ぶ名前、性別、生年月日、詳細情報 | **マイ情報の編集 → マイ情報** |
| ニックネーム、`@ID` | **マイ情報の編集 → マイ情報** |
| プロフィール写真、ウェブサイト、公開する紹介 | **マイ情報の編集 → クリエイター → プロフィール編集** |
| 作品ごとに違う名前や役割 | **マイページ → ペルソナ設定** |
| 表示言語 | **マイページ**のいちばん下の**言語設定** |

## 名前・ニックネーム・IDを変える

1. **マイ情報の編集**の**マイ情報**タブを開きます。
2. 直したい項目を変えます。
3. 上の**変更を保存**を押します。このボタンを押すと、直した内容が保存されます。

| 項目 | 何に使われるか |
| --- | --- |
| **名前** | キャラクターが自分をこう呼びます |
| **性別**、**生年月日** | キャラクターが参考にする自分の情報です。電話番号認証を済ませると変えられません |
| **ニックネーム** | ほかの利用者に表示される名前で、作品の制作者名にもなります |
| **ID** | `@ID`です。公開プロフィールのアドレスに使われます |
| **詳細情報** | 会話でキャラクターが参考にする自分の情報です。1,000文字まで書けます |

性別と生年月日は、電話番号認証の前に正しく設定しておいてください。認証したあとは変えられません。

IDのルールは[新規登録](/account/sign-up.md#idのルール)と同じです。入力するとすぐに重複を確認するので、**使用可能**と表示されてから保存してください。IDを変えると、公開プロフィールのアドレスも変わります。以前にプロフィールのリンクを共有していた場合は、新しいアドレスを共有し直してください。

## プロフィール写真と紹介を変える

1. **マイ情報の編集**で**クリエイター**タブを押します。
2. **プロフィール編集**を押します。
3. プロフィール写真の部分を押し、端末から写真を選びます。アップロードが終わるまで待ちます。
4. 必要なら**ウェブサイト**と**紹介**（10,000文字まで）を直します。
5. **保存**を押します。

作品を作っていなくても、公開プロフィールは編集できます。公開プロフィールには、ニックネーム、ID、プロフィール写真、ウェブサイト、紹介が表示されます。**マイ情報**の詳細情報は会話にだけ使われます。

:::tip[マイページのクリエイターボタンとは別です]
**マイページ**の最初の画面で**マイスパーク**の下にある**クリエイター**ボタンは、クリエイターの申請とダッシュボードを開きます。プロフィール写真は、**マイ情報の編集**の中の**クリエイター**タブで変えます。
:::

## 表示言語を変える

**マイページ**のいちばん下の**言語設定**を押し、**한국어**・**日本語**・**English**・**繁體中文**から選んで**確認**を押します。

言語を変えると、画面の文字が変わります。電話番号認証・年齢確認の方法と支払い方法は、登録したときのままです。

## ログアウトする

**マイページ → 設定とサポート → ログアウト**を押します。また使うときは、登録したソーシャルアカウントでログインしてください。アカウントそのものをなくしたい場合は、[アカウントの退会](/account/delete-account.md)をご覧ください。

## マイページでメニューを探す

| こんなとき | 開くメニュー |
| --- | --- |
| 残りのスパークと有効期限を見たい、チャージしたい | **マイスパーク** |
| クリエイター申請の条件と進み具合を見たい | **クリエイター** |
| 作りかけの作品の続きを直したい | **作品管理** |
| ブロックした作品やクリエイターをまた見たい | **ブロック管理** |
| 作品ごとに違う名前と役割で会話したい | **ペルソナ設定** |
| フォローしたクリエイターや自分のコメントを見たい | **マイアクティビティ** |
| 毎日無料でスパークをもらいたい | **出席チェック** |
| 友達を招待したい、もらった推薦コードを入れたい | **友達招待** |
| お知らせを見たい、問い合わせたい | **Discord** |
| センシティブコンテンツに分類された作品も見たい | **設定とサポート → センシティブコンテンツの表示**。[年齢確認・電話番号認証](/account/adult-verification.md)を参照 |
| アプリで問い合わせるときに利用環境を送りたい | **設定とサポート → バージョン情報 → お問い合わせ情報をコピー** |

## つまずいたときは

<details>
<summary>LINEのボタンが見当たらない</summary>

ウェブでは、画面が日本語か繁體中文のときだけLINEのボタンが表示されます。ログインボタンの下にある言語のリンク（언어 설정、Language Settings、語言設定）から**日本語**に切り替えてください。アプリにはLINEのボタンがないので、LINEで登録した場合はウェブでログインしてください。

</details>

<details>
<summary>ログインしたら新規登録画面が出た</summary>

最初に登録したときとは別のソーシャルアカウントでログインしています。登録せずに戻り、最初に登録したソーシャルアカウントでログインしてください。Googleアカウントが複数ある場合は、MYMIに登録したアカウントを選んだか確認してください。

</details>

<details>
<summary>前の会話とスパークが見当たらない</summary>

別のソーシャルアカウントでログインして、新しいアカウントができた可能性があります。**マイページ → 設定とサポート → ログアウト**を押してから、最初に登録したソーシャルアカウントでログインし直してください。

</details>

<details>
<summary>アプリにXのボタンがない、AndroidアプリにAppleのボタンがない</summary>

アプリにはLINEとXのログインがなく、AndroidアプリにはAppleのログインもありません。ChromeやSafariで[www.mymi.live/ja](https://www.mymi.live/ja)を開き、登録したときのボタンでログインしてください。

</details>

<details>
<summary>変更を保存が押せない</summary>

直した項目がないか、入力にエラーがあります。欄の下の案内を見て直してください。IDを変えた場合は、**使用可能**と表示されているか確認してください。

</details>

<details>
<summary>性別や生年月日を変えられない</summary>

電話番号認証を済ませたアカウントは、性別と生年月日を変えられません。作品ごとに違う設定で会話したい場合は、[ペルソナ設定](/account/persona.md)でペルソナを作って使ってください。ペルソナごとに性別と生年月日を別々に決められます。

</details>

<details>
<summary>名前を変えたのに、キャラクターが前の名前で呼ぶ</summary>

変えた名前は、新しく始める会話から使われます。すでに会話中のチャットルームでは、右上の⋮メニューの**チャット設定 → ペルソナ**で、**読み込み**からデフォルトのペルソナを選んで**保存**してください。

</details>

<details>
<summary>プロフィール写真が変わらない</summary>

写真を選んだあと、アップロードが終わってから**保存**まで押すと変わります。アプリが写真へのアクセスを求めたら許可してください。

</details>

それでも解決しないときは、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)までお知らせください。
