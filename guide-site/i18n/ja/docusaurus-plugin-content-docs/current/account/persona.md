# ペルソナ設定

ペルソナは、**作品の中で自分が使う名前と役割**です。同じ作品でも「記憶をなくした生存者」や「ミヌの古い友人」のように、違う役割で会話できます。ペルソナは会話にだけ使われます。作品の制作者名や公開プロフィールには、自分のニックネームが表示されます。

:::tip[すでに会話中のチャットルームで役割を変えたいときは]
チャットルーム右上の⋮メニューの**チャット設定 → ペルソナ**で変えます。手順は[会話中のチャットルームで変える](#会話中のチャットルームで変える)にあります。
:::

## デフォルト・メイン・おすすめとは？

| 種類 | 意味 |
| --- | --- |
| **デフォルト** | 登録したときの名前と性別で作られます。**マイ情報の編集 → マイ情報**を直すと一緒に変わり、削除はできません |
| **メイン** | 新しい会話を始めるときに最初から選ばれているペルソナです。作品詳細の選択画面では**代表**と表示されます。最初はデフォルトのペルソナがメインです |
| **おすすめペルソナ** | クリエイターがその作品に合わせて用意した役割です。作品詳細で選びます |

**マイページ → ペルソナ設定**のカードに、**デフォルト**・**メイン**の表示が付いています。1枚のカードに両方が付くこともあります。

## ペルソナを作る

1. **マイページ → ペルソナ設定**を開きます。
2. **ペルソナ追加**を押します。
3. 次の項目を入力して、上の**保存**を押します。

| 項目 | 書き方 |
| --- | --- |
| **名前** | キャラクターが自分を呼ぶ名前です。必須で、20文字まで書けます |
| **生年月日** | 入力する場合は、年・月・日をすべて入れます。14歳以上になる日付だけ保存できます |
| **性別** | **女性**・**男性**から選びます |
| **詳細情報** | 自分の役割、性格、話し方、登場人物との関係を1,000文字まで書けます |

名前だけでも保存できます。新しく作ったペルソナをよく使うなら、[メインに設定してください](#メインのペルソナを決める)。

### 詳細情報の例

> 名前はハル。25歳。地下都市の検疫所で目覚め、地上で配達の仕事をしていたことしか覚えていない。初対面の人には敬語を使い、気になることはすぐに聞く。ミヌとは今日初めて会った。

役割、話し方、登場人物との関係、今しようとしていることを短く書くと、キャラクターに伝わりやすくなります。

## メインのペルソナを決める

**マイページ → ペルソナ設定**で、使いたいペルソナのカードを押します。カードに**メイン**と表示されると、次に新しい会話を始めるときにこのペルソナが選ばれています。

## 会話を始めるときに選ぶ

1. 作品詳細の画面下にある**会話を始める**の右の小さなプロフィールアイコンを押します。
2. **マイペルソナ**か**おすすめペルソナ**のタブで1つ選び、**選択完了**を押します。
3. **会話を始める**を押します。すでに会話したことのある作品なら、**新しい会話を始める**を押します。

選択画面では、カードの鉛筆ボタンで内容を直すこともできます。

- **マイペルソナ**を直して保存すると、自分の一覧のそのペルソナが変わります。
- **おすすめペルソナ**を直した内容は、今回の会話にだけ使われます。続けて使いたい場合は、自分のペルソナとして別に作っておいてください。

**前の会話を続ける**を押すと、そのチャットルームで使っていたペルソナのまま続きます。

## 会話中のチャットルームで変える

一覧でペルソナを直すと、新しく始める会話から変わります。すでに会話中のチャットルームは、そのルームの中で変えます。

1. チャットルーム右上の⋮ボタンを押します。
2. **チャット設定**の**ペルソナ**を押します。
3. **ペルソナ編集**の画面で名前と詳細情報を直接直すか、**読み込み**で自分のペルソナを1つ選びます。
4. **保存**を押します。次の返信から、変えたペルソナで会話します。

会話の履歴はそのまま続きます。新しい役割で最初からやり直したい場合は、作品詳細でペルソナを選んでから**新しい会話を始める**を押します。

## 直す・削除する

**マイページ → ペルソナ設定**で、カード右の⋮ボタンを押します。

- **編集**：内容を変えて**保存**を押します。デフォルトのペルソナの**編集**は、**マイ情報の編集**の画面を開きます。
- **削除**：追加したペルソナだけ削除できます。

:::danger[削除は確認なしですぐに実行されます]
**削除**を押すと、確認画面なしですぐに削除され、元に戻せません。メインのペルソナを削除すると、デフォルトのペルソナがメインになります。そのペルソナで会話していたチャットルームは、そのまま続けて使えます。
:::

## どこで変えればいいですか？

| 変えたいもの | 変える場所 |
| --- | --- |
| これから始める会話で使う名前と役割 | **ペルソナ設定**で直すか、メインにする |
| 今会話中のチャットルームの名前と役割 | チャットルームの⋮メニューの**チャット設定 → ペルソナ** |
| 今回始める会話だけで使う役割 | 会話を始める前にプロフィールアイコンから選ぶ |
| 登録したときの名前と性別（デフォルトのペルソナ） | **マイ情報の編集 → マイ情報** |

## つまずいたときは

<details>
<summary>名前を変えたのに、キャラクターが前の名前で呼ぶ</summary>

すでに会話中のチャットルームは、そのルームの中で変える必要があります。チャットルームの⋮メニューの**チャット設定 → ペルソナ**で、**読み込み**から変えたペルソナを選んで**保存**してください。

</details>

<details>
<summary>新しく作ったペルソナで会話が始まらない</summary>

新しく作ったペルソナはメインではありません。一覧でそのカードを押してメインにするか、会話を始めるときにプロフィールアイコンから選んでください。

</details>

<details>
<summary>生年月日を入れたら保存できない</summary>

年・月・日をすべて入れたか、実際にある日付かを確認してください。「14歳未満は保存できません。」と表示されたら、14歳以上になる日付に変えてください。生年月日は空欄のままでも保存できます。

</details>

<details>
<summary>デフォルトのペルソナに削除がない</summary>

デフォルトのペルソナは削除できません。**編集**を押すと**マイ情報の編集**が開き、そこで名前と詳細情報を変えられます。

</details>

<details>
<summary>おすすめペルソナのタブが表示されない</summary>

クリエイターがおすすめペルソナを用意していない作品です。**マイペルソナ**から選んでください。

</details>

<details>
<summary>ペルソナを間違えて削除した</summary>

削除したペルソナは元に戻せません。同じ内容でもう一度作ってください。そのペルソナで会話していたチャットルームは残っています。

</details>

それでも解決しないときは、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)までお知らせください。
