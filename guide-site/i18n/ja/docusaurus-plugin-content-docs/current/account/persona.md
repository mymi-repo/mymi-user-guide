# ペルソナ設定

ペルソナは、**作品の中で自分がどのような人物として会話するかを決める設定**です。名前、性別、生年月日、詳細情報を通じて、キャラクターが参照する自分の情報を設定できます。

たとえば、同じ作品でも「初めて町を訪れた旅人」と「主人公と長く付き合いのある仲間」として、それぞれ会話できます。作品の登場人物を作る設定とは別のもので、**クリエイター名と公開プロフィールにはデフォルトプロフィールのニックネーム**が使われます。

> **すでに会話しているチャットの設定を変えるには：** そのチャットで **メニュー → ペルソナ → 読み込み → ペルソナを選択 → 保存** と進みます。マイページでメインのペルソナを変更するだけでは、既存のチャットには反映されません。

## 1. デフォルト・メイン・おすすめの違い

| 種類 | 意味 | 知っておきたいこと |
| --- | --- | --- |
| デフォルトペルソナ | アカウント情報をもとに自動で用意されるペルソナ | 一覧から編集すると **マイ情報の編集** 画面が開きます。一覧に削除メニューはありません |
| メインのペルソナ | 新しい会話を準備するとき、最初に選択される自分のペルソナ | カードに **メイン** と表示されます。デフォルトペルソナもメインに指定できます |
| おすすめペルソナ | クリエイターがその作品に合わせて用意した、利用者用の役割 | 作品詳細のペルソナ選択画面から選びます。用意されていない作品もあります |
| チャットのペルソナ | チャット作成時に選び、そのチャットに保存した役割 | チャット内で個別に編集します。マイページの一覧とは自動で同期しません |

**「デフォルト」と「メイン」は同じ意味ではありません。** デフォルトはアカウント情報と連動するペルソナ、メインは新しい会話で優先して使うペルソナです。1枚のカードに両方が表示されることもあります。

新しく追加しなくても、デフォルトペルソナで会話を始められます。作品や役割ごとに使い分けたいときに追加してください。

## 2. 自分のペルソナを追加する

1. ログインして **マイページ → ペルソナ設定** を開きます。
2. **ペルソナ追加** を押します。
3. 名前と必要な情報を入力します。
4. 画面上部の **保存** を押し、一覧に追加されたことを確認します。

| 項目 | 必須かどうか | 入力方法 |
| --- | --- | --- |
| 名前 | 必須 | キャラクターが自分を呼ぶ名前です。**20文字以内**で入力します |
| 生年月日 | 任意 | 入力する場合は年・月・日をすべて入力します。現在の入力画面では、**14歳以上に相当する有効な日付**のみ保存できます |
| 性別 | 任意 | 追加・編集画面では **女性 / 男性** から選べます |
| 詳細情報 | 任意 | 役割、性格、話し方、職業、登場人物との関係などを **1,000文字以内**で入力します |

名前だけでも保存できます。生年月日には未来の日付や実在しない日付を使えません。年・月・日の一部だけを入力した場合、生年月日は保存されません。

ペルソナの生年月日は役割の設定です。変更してもアカウントの年齢確認の状態は変わりません。成人向けコンテンツの利用条件は [年齢確認・本人確認](/account/adult-verification.md) を確認してください。

## 3. メインのペルソナを指定する

1. **マイページ → ペルソナ設定** で、使いたい **カード自体を押します**。
2. そのカードに **メイン** と表示されたことを確認します。
3. 作品詳細を開き直し、会話開始ボタン横のペルソナ選択ボタンで選択中の役割を確認します。

**追加・編集して保存する操作と、メインに指定する操作は別です。** 新しく追加したペルソナを主に使う場合は、一覧でそのカードを選んでください。

メインの変更は、新しい会話を準備するときの初期選択に使われます。すでに開いている作品詳細で選んだ役割や、既存のチャットの設定までは変更しません。

## 4. 作品で会話を始める前に選ぶ

1. 会話したい作品の詳細画面を開きます。
2. 下部にある **会話開始ボタン横の小さなプロフィールアイコン** を押します。
3. **マイペルソナ** または **おすすめペルソナ** からカードを選びます。
4. **選択完了** を押します。
5. **会話を始める** または **新しい会話を始める** を押して、新しいチャットを作成します。

**おすすめペルソナ** タブは、クリエイターが役割を用意した作品でのみ表示されます。おすすめを選んでも、マイページのメインのペルソナは変わりません。

### 選択画面の鉛筆ボタンで編集するとき

- **マイペルソナ** を編集して保存すると、マイページの一覧に保存されている同じペルソナも更新されます。既存のチャットには自動で反映されません。
- **おすすめペルソナ** を編集すると、その選択画面で使う内容を調整できます。クリエイターの元の設定は変わらず、マイペルソナにも自動追加されません。
- 編集後も **選択完了 → 新しい会話を始める** まで進むと、選んだ役割で新しいチャットが作られます。おすすめの役割をほかの作品でも使いたい場合は、マイページで自分のペルソナとして別途追加してください。

> **前の会話を続ける** は既存のチャットを開きます。作品詳細で別のペルソナを選んでも、開いたチャットには以前の設定が残ります。既存のチャットの役割を変える場合は、次の手順で設定してください。

## 5. 会話中のチャットのペルソナを変更する

1. 変更したい **チャットを開きます**。
2. チャット上部のメニューから **ペルソナ** を選びます。
3. **ペルソナ編集** 画面で、現在のチャットの名前と詳細情報を確認します。
4. 直接編集するか、**読み込み** を押して自分のペルソナ一覧から1つ選びます。
5. 読み込んだ情報を確認し、このチャットだけで使いたい内容があれば編集します。
6. **保存** を押します。

**「ペルソナを読み込みました」は、入力欄に情報を取り込んだという意味です。** 最後に保存すると、そのチャットに反映されます。

ここで保存した内容は **現在のチャットだけ** に適用されます。マイページの元のペルソナや、ほかのチャットの設定は変わりません。複数のチャットで同じ変更を使う場合は、それぞれで読み込んで保存してください。

ペルソナを変更しても、会話履歴は初期化されません。新しい役割で物語を最初から始めたい場合は、作品詳細でペルソナを選び、**新しい会話を始める** を使ってください。

## 6. 一覧のペルソナを編集・削除する

**マイページ → ペルソナ設定** で、カードの **その他メニュー（⋮）** を開きます。

- **追加したペルソナの編集：** **編集** を選び、内容を変えて **保存** します。
- **デフォルトペルソナの編集：** **編集** を押すと **マイ情報の編集** が開きます。名前・性別・生年月日・詳細情報との関係は [ログイン・プロフィール設定](/account/login-profile.md) を参照してください。
- **追加したペルソナの削除：** **削除** を選ぶと自分の一覧から削除されます。メインに指定していた場合は、デフォルトペルソナがメインになります。
- **デフォルトペルソナの削除：** 一覧からは削除できません。

一覧で編集・削除しても、すでにチャットに保存されたペルソナと会話履歴は残ります。既存のチャットを変更したい場合は、そのチャット内でペルソナを編集してください。

## 7. どこを変更すると、どこに反映されますか？

| 操作 | 反映される場所 | 既存のチャットに自動反映されますか？ |
| --- | --- | --- |
| マイ情報で名前・性別・生年月日・詳細情報を保存 | アカウント情報とデフォルトペルソナ | いいえ |
| マイページで追加したペルソナを編集 | 自分の一覧にある該当ペルソナ | いいえ |
| メインのペルソナを変更 | 新しい会話を準備するときの初期選択 | いいえ |
| 作品詳細でペルソナを選び、新しい会話を開始 | 新しく作ったチャット | 既存のチャットには反映されません |
| チャット内でペルソナを読み込んで保存 | 設定中のチャット | そのチャットに直接反映されます |

## 8. 詳細情報には何を書けばよいですか？

キャラクターが参照できるように、**自分の役割と関係**を短く具体的に書いてみましょう。設定をたくさん並べるより、今回の会話に必要な背景から決めると始めやすくなります。

**例 — 初めて町を訪れた旅人**

> 名前はハル。成人の地図職人で、古い地図を探しにこの町に来た。初対面の人には丁寧な言葉を使い、慎重に質問する。主人公とは今日初めて会う。まずは町を案内してもらうよう頼みたい。

この例には、背景、話し方、関係、最初の目的が含まれています。望む展開が変わったら、そのチャットの詳細情報を編集できます。ただし、ペルソナはAIが参照する情報なので、すべての応答や展開を保証するものではありません。

## よくあるつまずき

| 状況 | 確認すること |
| --- | --- |
| メインを変えたのに、既存のチャットでは前の名前で呼ばれます | そのチャットで **ペルソナ → 読み込み → 選択 → 保存** まで進んだか確認してください |
| 読み込んだのに反映されません | 入力欄に読み込んだ後、**保存** を押したか確認してください |
| 作品詳細で変えたのに、会話が変わりません | **前の会話を続ける** を押したか確認してください。新しい役割で最初から始めるには **新しい会話を始める** を選びます |
| おすすめペルソナのタブがありません | クリエイターがおすすめの役割を登録していない場合があります。マイペルソナから選んでください |
| デフォルトペルソナを削除できません | 一覧からは削除できません。別のペルソナを追加してメインに指定できます |
| 生年月日を保存できません | 年・月・日、実在する日付かどうか、未来の日付でないか、14歳以上に相当するかを確認してください |
| ペルソナ名を変えたのにクリエイター名が変わりません | クリエイター名にはデフォルトプロフィールの **ニックネーム** が使われます。[ログイン・プロフィール設定](/account/login-profile.md) から変更してください |
