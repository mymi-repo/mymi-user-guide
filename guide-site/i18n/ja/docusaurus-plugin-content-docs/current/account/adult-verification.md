# 年齢確認・本人確認

MYMIの**本人確認・電話番号認証**と**年齢確認**は、目的が異なります。利用したい機能で認証の案内が表示されたら、その画面に沿って手続きを進めてください。

| 種類 | 確認すること | 案内が表示される場面 |
| --- | --- | --- |
| 本人確認・電話番号認証 | 本人情報、または電話番号を利用できること | 出席チェックや友達招待など、認証が必要な機能を使うとき |
| 年齢確認 | アカウントに適用される成人向けコンテンツの利用条件を満たしていること | セーフティフィルターを解除するときや、センシティブコンテンツの表示をオンにするとき |

韓国の本人確認では、確認済みの生年月日から成人向けコンテンツの利用資格も判定します。海外の電話番号認証と年齢の自己申告は別の手続きです。**SMS認証を終えても、年齢確認まで完了するわけではありません。**

## 1. アカウントの認証方法を確認する

認証方法は、アカウントに適用されている方針と認証履歴によって決まります。**表示言語を変えても、アカウントの認証方針は変わりません。** 日本語で利用していても、既存のアカウントでは韓国の本人確認が案内される場合があります。

現在の基本的な手続きは以下のとおりです。実際に開いた認証画面の案内に従ってください。

| アカウントの認証方針 | 本人・電話番号の確認 | 年齢確認 |
| --- | --- | --- |
| 韓国サービス | PortOneを通じた携帯電話の本人確認 | 本人確認で取得した生年月日から判定 |
| 日本・台湾・英語サービス | 対応する電話番号へのSMS認証 | 画面に表示された年齢以上であることを自己申告 |

旅行先の国や現在の表示言語だけで、認証方法が決まるわけではありません。想定と違う画面が表示されたり、アカウントの国・地域に関するエラーが出たりする場合は、[お問い合わせ](#お問い合わせ)を参照してください。

## 2. 認証を始める場所

まず[MYMIにログイン](/account/login-profile.md)し、利用したい機能を開きます。必要な認証があれば、その場で案内されます。

- **出席チェック・友達招待**：マイページで該当するメニューを開き、認証の案内に従います。
- **セーフティフィルター**：フィルターをオフにするとき、年齢確認が必要であれば案内が表示されます。
- **センシティブコンテンツの表示**：**マイページ → 設定とサポート**でオンにするとき、年齢確認を求められる場合があります。

ウェブではホーム画面にセーフティフィルターがあります。アプリでは利用中の画面構成により、**ホーム**または**マイページ → 設定とサポート**に表示されます。マイページに**セーフティフィルター**がある場合は、その項目を使ってください。

**フィルターをオフにする操作（OFF）**と、**センシティブコンテンツの表示をオンにする操作（ON）**では、切り替える方向が異なります。項目名と現在の状態を確認しましょう。

## 3. 韓国の本人確認を行う

韓国の本人確認が案内された場合は、次の順序で進めます。

1. 案内画面の**今すぐ認証する**または**年齢確認をする**を押します。
2. PortOneの本人確認画面で、求められた情報を入力します。
3. **本人名義の携帯電話**で認証を完了します。
4. MYMIに戻り、完了の案内を確認します。
5. 出席チェックやフィルター設定など、もともと利用しようとしていた機能に戻ります。

| 利用環境 | 認証画面の開き方 |
| --- | --- |
| PCウェブ | ポップアップ画面で進行 |
| モバイルウェブ | 認証ページに移動し、完了後にMYMIへ戻る |
| Android・iOSアプリ | アプリ内の認証画面で進行 |

### 韓国の方針における年齢基準

韓国の方針が適用されるアカウントでは、**19歳になる年の1月1日から**成人向けコンテンツの利用対象となります。例えば、**2026年は2007年以前に生まれた方**が該当し、その年の誕生日を待つ必要はありません。

MYMIは本人確認で確認された生年月日を使って判定します。**マイ情報やペルソナの生年月日を自分で変更しても、年齢確認の代わりにはなりません。** 本人確認が完了していても、年齢基準に達していないアカウントはフィルターを解除できません。

## 4. 海外の電話番号を認証する

**電話番号認証**が表示されたら、SMSで届く認証コードを入力します。この手続きでは、その番号を利用できることを確認します。

1. 電話番号の国・地域を選択します。現在は**日本（+81）・台湾（+886）・アメリカ（+1）**に対応しています。
2. 選んだ国・地域の自分の携帯電話番号を入力します。選択した国・地域と番号が一致している必要があります。
3. **認証コードを受け取る**を押します。
4. 画面に表示された送信先番号を確認し、SMSで受け取ったコードを入力します。
5. 表示された有効時間内に**認証する**を押します。
6. 完了の案内を確認してから、利用していた機能に戻ります。

SMSが届かない場合は、画面の待機時間が過ぎてから**認証コードを再送信**できます。番号を間違えた場合は**番号を変更**を選択してください。コードの期限切れや入力回数の上限が案内された場合は、画面に従ってやり直します。

番号の国・地域を選ぶ操作は、SMSの送信先を指定するためのものです。アカウントの年齢確認方針は変わりません。未対応の番号を使う場合や、認証サービスが準備中と表示される場合は、エラー内容を確認してお問い合わせください。

## 5. 年齢を自己申告する

**年齢確認**画面にチェック項目が表示された場合は、次の順序で進めます。日本・台湾・英語サービスの現在の自己申告基準は、**満18歳以上**です。

1. 画面に表示された年齢基準と案内文を読みます。
2. 実際に条件を満たす場合のみ、**私は18歳以上です。**にチェックします。
3. **確認する**を押します。
4. 年齢確認の完了が案内されたら、元の画面に戻ります。

この確認は、電話番号認証とは別に進められます。年齢確認の完了後でも、出席チェックなどの機能では電話番号認証を求められる場合があります。

条件を満たしていない場合や確認を進めたくない場合は、**あとにする**を選択してください。年齢確認をしていない状態では、フィルターを解除できません。

## 6. 認証後にフィルター設定を確認する

**認証の完了とフィルター設定の変更は別の操作です。** 認証画面が閉じても、以前のフィルター状態が維持される場合があります。

1. 認証を開始したホームまたはマイページに戻ります。
2. 設定を再度確認します。セーフティフィルターを解除するには**OFF**、センシティブコンテンツを表示するには該当項目を**ON**にします。
3. 認証の案内が繰り返し表示される場合は、ページを再読み込みするか、アプリを開き直します。

本人・電話番号認証が済んでいても、年齢確認が未完了であったり、確認された年齢が基準に達していなかったりする場合、成人向け機能は引き続き制限されます。プロフィールやペルソナの年齢設定と、成人向け機能の利用資格は異なります。

## 7. 別のアカウントで認証済みの場合

本人確認情報や電話番号が別のアカウントに紐づいている場合、新しいアカウントでは重複して認証できません。まず[登録時に使ったソーシャルアカウントでログインしているか](/account/login-profile.md)を確認してください。

最近退会したアカウントの認証情報には、**退会後30日間の再利用制限**が適用される場合があります。退会しても、すぐに別のアカウントへ認証を移せるわけではありません。重複や待機期間の案内が出た場合は、元のアカウントとエラー内容を確認してお問い合わせください。

## 認証がうまくいかないとき

| 状況 | 確認すること |
| --- | --- |
| ログインを求められる | 登録したソーシャルアカウントでログインし、機能を開き直します |
| PCで本人確認画面が開かない | ポップアップのブロック通知を確認し、MYMIの認証ポップアップを許可します |
| モバイルウェブで認証後にMYMIへ戻れない | 元のページに戻って再読み込みします。ほかのアプリ内のブラウザーを使っていた場合は、外部ブラウザーで再試行します |
| SMSが届かない | 国・地域、番号、SMSの受信状態や迷惑メッセージ設定を確認し、待機時間後に再送信します |
| コードが一致しない・期限切れと表示される | 届いたコードと有効時間を確認します。期限切れなら再送信するか、番号入力からやり直します |
| リクエストや入力回数の上限に達した | 繰り返し送信せず、画面の待機時間や再開の案内に従います |
| 別のアカウントに登録済みと表示される | もともと認証したアカウントにログインしているか確認します。解決しない場合はお問い合わせください |
| 最近退会したアカウントの情報と表示される | 退会後30日間の再利用制限の案内を確認します |
| 言語を変えても認証方法が変わらない | 表示言語を変更しても、アカウントの認証方針は変わりません |
| 海外に住んでいるのに韓国の本人確認が表示される | アカウントに適用された方針によるものです。手続きできない場合はお問い合わせください |
| 年齢確認のボタンを押せない | 年齢条件を満たす場合のみ、確認項目にチェックします |
| 認証済みなのにフィルターを解除できない | 年齢確認まで完了しているか確認し、元の画面でフィルターを操作し直します |
| 未対応の国・地域、アカウントの国・地域、準備中のエラーが出る | エラー内容を記録し、時間をおいて再試行するかお問い合わせください |

## お問い合わせ

**マイページ → Discord → お問い合わせ**、または[メール](mailto:contact@mymi.live)でご連絡ください。MYMIのID、認証を始めたメニュー、エラーメッセージ、ウェブ・Android・iOSのどれを使っているかを添えると、確認に役立ちます。

海外在住などで案内された認証を進められない場合も、まずサポートにお問い合わせください。**身分証明書の写しや認証コードを先に送らず**、案内された手順に従ってください。
