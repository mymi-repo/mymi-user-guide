# 年齢確認・電話番号認証

MYMIでは、**電話番号認証**と**年齢確認**を別々に行います。利用したい機能で案内が表示されたら、その画面に沿って進めてください。

| 種類 | 確認すること | 案内が表示される場面 |
| --- | --- | --- |
| 電話番号認証 | 自分の携帯電話番号でSMSを受け取れること | 出席チェック、友達招待、作品制作でのAI画像の生成、アプリでの初回割引の商品の購入 |
| 年齢確認 | 18歳以上であること（自己申告） | セーフティフィルターの解除、センシティブコンテンツの表示、ウェブでのスパークの購入 |

一方を終えても、もう一方は完了になりません。例えば電話番号認証を終えても、セーフティフィルターを解除するには年齢確認が必要です。

## 1. 認証を始める場所

まず[MYMIにログイン](/account/login-profile.md)し、利用したい機能を開きます。必要な認証があれば、その場で案内されます。

- **出席チェック・友達招待**：マイページで該当するメニューを開き、電話番号認証の案内に従います。
- **AI画像の生成**：作品制作で画像を生成・再生成するとき、電話番号認証が案内されます。持っている画像をアップロードするだけなら認証は不要です。
- **スパークの購入**：ウェブではどの商品も年齢確認が必要です。アプリでは**初回割引**の商品を選ぶと電話番号認証が案内されます。
- **セーフティフィルター**：フィルターをオフにするとき、年齢確認が案内されます。
- **センシティブコンテンツの表示**：**マイページ → 設定とサポート**でオンにするとき、年齢確認が案内されます。

案内に「本人認証」と表示される場合も、手続きは電話番号認証の画面で行います。

セーフティフィルターは、**ホーム**の**おすすめ・ランキング・タグ・検索**タブの右端にある、文字のない盾マークの小さなスイッチです。ウェブでもアプリでも同じ場所にあります。緑ならオンで成人向け作品は表示されず、グレーならオフです。この設定は端末ごとに保存されるため、別の端末やブラウザで初めて開いたときやログアウトした後は、再びオンになっています。

**センシティブコンテンツの表示**（**マイページ → 設定とサポート**）は別の設定です。オンにすると、センシティブコンテンツに分類された作品も表示されます。この設定はアカウントに保存されるため、どの端末でも同じです。セーフティフィルターをオフにしても探している作品が見つからない場合は、こちらもオンにしてください。

## 2. 電話番号認証を行う

**電話番号認証**の画面が表示されたら、SMSで届く認証コードを入力します。

1. 番号の国・地域を確認します。最初から<strong>日本 (+81)</strong>が選ばれています。ほかの国・地域の番号を使う場合は、その国・地域のボタンを選びます。
2. 自分の携帯電話番号を入力します。選んだ国・地域と番号が一致している必要があります。
3. **認証コードを受け取る**を押します。
4. 画面に表示された送信先の番号を確認し、SMSで届いたコードを入力します。
5. 表示された時間内に**認証する**を押します。
6. 「電話番号認証が完了しました。」と表示されたら、利用していた機能に戻ります。

SMSが届かない場合は、待機時間が過ぎてから**認証コードを再送信**を押します。番号を間違えた場合は**番号を変更**を選びます。コードの期限切れや入力回数の上限が案内された場合は、番号の入力からやり直してください。

## 3. 年齢確認を行う

**年齢確認**の画面では、18歳以上であることを自分で確認します。

1. 画面の年齢基準と注意事項を読みます。
2. 実際に18歳以上の場合のみ、<strong>私は18歳以上です。</strong>にチェックします。
3. **確認する**を押します。
4. 「年齢確認が完了しました。」と表示されたら、元の画面に戻ります。

虚偽の申告をすると、サービスの利用が制限されることがあります。条件を満たしていない場合や、今は確認しない場合は**あとにする**を選んでください。

## 4. 認証後にフィルター設定を確認する

年齢確認を終えたらホームまたはマイページに戻り、**フィルター設定を変更**してください。

1. 認証を開始したホームまたはマイページに戻ります。
2. 設定を再度確認します。セーフティフィルターを解除するには**OFF**、センシティブコンテンツを表示するには該当項目を**ON**にします。
3. 認証の案内が繰り返し表示される場合は、ページを再読み込みするか、アプリを開き直します。

## 5. 別のアカウントで認証済みの場合

電話番号が別のアカウントに登録されているという案内が出たら、[登録時に使ったソーシャルアカウントでログインしているか](/account/login-profile.md)を確認してください。

最近退会したアカウントなどで登録が解除された番号は、**30日後**から再登録できます。急ぎの場合や解決しない場合は、エラー内容を添えてお問い合わせください。

## 認証がうまくいかないとき

| 状況 | 確認すること |
| --- | --- |
| ログインを求められる | 登録したソーシャルアカウントでログインし、機能を開き直します |
| SMSが届かない | 選んだ国・地域と番号、SMSの受信設定や迷惑メッセージのブロックを確認します。待機時間が過ぎたら再送信します |
| 認証コードが一致しないと表示される | 最後に届いたコードを入力しているか確認します |
| 認証コードの有効期限が切れた | 再送信するか、番号の入力からやり直します |
| リクエストが多すぎる・入力回数の上限を超えた | 繰り返し送信せず、時間をおいて最初からやり直します |
| すでに進行中の認証があると表示される | しばらく待ってから再試行します |
| 別のアカウントに登録済みと表示される | もともと認証したアカウントにログインしているか確認します。解決しない場合はお問い合わせください |
| 30日後に再登録できると表示される | 最近登録が解除された番号です。30日が過ぎてから再試行するか、お問い合わせください |
| 対応していない国・地域と表示される | 選んだ国・地域のボタンと入力した番号が合っているか確認します。解決しない場合はお問い合わせください |
| 認証サービスは準備中と表示される | しばらくしてから再試行します |
| 年齢確認の「確認する」を押しても進まない | <strong>私は18歳以上です。</strong>にチェックしたか確認します |
| 電話番号認証をしたのにフィルターを解除できない | 電話番号認証とは別に、年齢確認が必要です |
| 年齢確認をしたのに出席チェックで認証を求められる | 年齢確認とは別に、電話番号認証が必要です |
| 以前に年齢確認をしたのに、もう一度求められる | 同意内容が更新された場合などは、もう一度確認します |
| 言語を変えても認証方法が変わらない、またはこのページと違う認証画面が表示される | 認証方法は登録したときの表示言語で決まり、あとから表示言語を変えても変わりません。手続きを進められない場合はお問い合わせください |
| その他のエラーが表示される | エラー文を記録し、時間をおいて再試行します。続く場合はお問い合わせください |

## お問い合わせ

**マイページ → Discord → お問い合わせ**、または[メール](mailto:contact@mymi.live)でご連絡ください。MYMIのID、認証を始めたメニュー、エラーメッセージ、ウェブ・Android・iOSのどれを使っているかを添えると、確認に役立ちます。

**認証コードや身分証明書の写しは先に送らないでください。** 必要な手続きはサポートからご案内します。
