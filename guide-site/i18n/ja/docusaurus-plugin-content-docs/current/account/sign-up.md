# 新規登録

LINE・Google・X・Appleのいずれかのアカウントでログインし、名前・ID・ニックネームを決めると登録が完了します。MYMIは14歳以上の方が利用できるサービスです。

:::warning[登録する前に、画面が日本語になっているか確認してください]
登録したときの表示言語でアカウントの国が決まり、電話番号認証・年齢確認の方法や支払い方法が変わります。登録したあとは変更できません。

日本語になっていない場合は、次の手順で切り替えてから登録してください。

1. 下のメニューのいちばん右（マイページ）を押します。
2. ログインボタンの下にある言語のリンク（언어 설정、Language Settings、語言設定）を押します。
3. **日本語**を選び、確認ボタン（확인、Confirm、確認）を押します。
:::

## ログインボタンを選ぶ

1. [www.mymi.live/ja](https://www.mymi.live/ja)かMYMIアプリを開き、下のメニューの**マイページ**を押します。会話中に出るログイン画面から始めてもかまいません。
2. 登録に使うソーシャルアカウントのボタンを押します。表示されるボタンは、利用環境によって次のとおりです。
3. そのサービスのログインが終わると、MYMIの**新規登録**画面が開きます。

| 利用環境 | ログインボタン |
| --- | --- |
| パソコン・スマートフォンのウェブ | **LINEで続ける**、**Googleで続ける**、**Xで続ける**、**Appleで続ける** |
| Androidアプリ | **カカオで続ける**、**Googleで続ける** |
| iPhoneアプリ | **Appleで続ける**、**カカオで続ける**、**Googleで続ける** |

:::tip[どのソーシャルアカウントで登録するか先に決めましょう]
MYMIのアカウントはソーシャルアカウントごとに別々に作られます。次からも登録したソーシャルアカウントでログインしないと、会話やスパークが引き継がれません。アプリも使うなら、Google（iPhoneだけならAppleも可）で登録してください。LINEとXはウェブでしか使えず、AndroidアプリにはAppleのログインがありません。
:::

## 名前・ID・ニックネームを決める

| 項目 | 何に使われるか | 入力 |
| --- | --- | --- |
| **名前** | キャラクターが自分を呼ぶ名前です | 20文字まで |
| **性別** | キャラクターが参考にする自分の性別です | **女性**・**男性**・**その他**から1つ |
| **ユーザーID** | `@moon_reader`のように自分を区別するアドレスです | 3〜20文字。下のルールに従います |
| **ニックネーム** | ほかの利用者に表示される名前です | 30文字まで |

たとえば名前を`ハル`、ニックネームを`月夜の読書家`にすると、キャラクターからは「ハル」と呼ばれ、ほかの利用者には「月夜の読書家」と表示されます。作品ごとに別の名前で会話したい場合は、登録後に[ペルソナ設定](/account/persona.md)で追加できます。名前・ID・ニックネームは、登録後も[ログイン・プロフィール設定](/account/login-profile.md)で変えられます。

アプリでは、ソーシャルアカウントの名前が**名前**欄にあらかじめ入っていることがあります。会話で呼ばれたい名前に直してかまいません。

### IDのルール

- 半角の英小文字、数字、アンダースコア（`_`）、ハイフン（`-`）だけが使えます。大文字は小文字に変わり、それ以外の文字は入力されません。
- 3〜20文字で入力します。
- `_`や`-`で始めたり終えたりはできません。
- `_`と`-`は続けて使えません。`__`、`--`、`_-`はどれも使えません。

| 例 | 結果 |
| --- | --- |
| `moon_reader`、`reader-123` | 使えます |
| `ab` | 3文字より短い |
| `_reader`、`reader-` | `_`や`-`で始まるか終わっている |
| `moon__reader`、`moon-_reader` | `_`と`-`が続いている |

IDを入力すると、欄の右にすぐ結果が表示されます。**使用可能**と表示されたら次に進みます。**使用不可**はほかの人が使っているIDなので、別のIDに変えてください。**形式エラー**の場合は、上のルールをもう一度確認してください。

## 規約に同意する

| 項目 | 必須かどうか |
| --- | --- |
| **利用規約に同意** | 必須 |
| **個人情報の収集および利用に同意** | 必須 |
| **サービス注意事項** | 必須 |
| **マーケティング情報の受信に同意** | 任意 |

- 同意は、各項目の**左のチェックボックス**を押してチェックします。項目名を押すと全文が開きます。
- **全て同意**を押すと、任意のマーケティング情報の受信までチェックされます。受け取りたくない場合は、そのボックスだけもう一度押して外してください。

## 登録を完了する

画面下のボタンは、条件をすべて満たすまで灰色の矢印のままです。4つの項目を入力し、IDが**使用可能**になり、必須の同意3つをチェックすると、ボタンが**登録完了**に変わります。押すと登録が終わり、ホームに移動します。

会話にはスパークが必要です。電話番号認証を済ませると、**マイページ → 出席チェック**で毎日無料でもらえます。方法は[年齢確認・電話番号認証](/account/adult-verification.md)と[スパークのチャージ](/payment/payment-methods.md#出席チェック)にあります。

## つまずいたときは

<details>
<summary>登録完了ボタンが灰色の矢印のまま</summary>

まだ満たしていない条件があります。

- 名前・性別・ユーザーID・ニックネームをすべて入力しましたか？
- ユーザーID欄の右に**使用可能**と表示されていますか？
- 必須の同意3つをチェックしましたか？項目名ではなく、左のチェックボックスを押すとチェックされます。

</details>

<details>
<summary>項目を押したら規約のページが開いた</summary>

項目名を押すと全文が開きます。読み終わったら登録画面に戻り、項目名の左のチェックボックスを押してチェックしてください。

</details>

<details>
<summary>「すでに使用中のIDです。」と表示される</summary>

ほかの人が使っているIDです。数字や`_`を付けて、別のIDにしてみてください。

</details>

<details>
<summary>「重複確認中にエラーが発生しました。もう一度お試しください。」と表示される</summary>

インターネット接続を確認し、ユーザーID欄の右の**確認**を押してもう一度確認してください。

</details>

<details>
<summary>「再登録制限」として「退会後30日間は再登録できません。」と表示される</summary>

このソーシャルアカウントで作ったMYMIアカウントを退会してから、まだ30日たっていません。30日たつと同じソーシャルアカウントでもう一度登録でき、新しいアカウントとして始まります。別のソーシャルアカウントならすぐに登録できますが、退会したアカウントで認証した電話番号は、退会から30日たつまで使えません。

</details>

<details>
<summary>「会員登録中に問題が発生しました。」や「ログイン中に問題が発生しました。」と表示される</summary>

<strong>もう一度お試しください！</strong>ボタンを押すとホームに戻ります。最初からログインし直してください。LINEやInstagramなどのアプリの中で開いた場合は、ChromeやSafariで[www.mymi.live/ja](https://www.mymi.live/ja)を開いてもう一度試してください。

</details>

<details>
<summary>登録したはずなのに新規登録画面が出る</summary>

最初に登録したときとは別のソーシャルアカウントでログインしています。ここで登録すると新しいアカウントが作られるので、戻って最初に登録したソーシャルアカウントでログインしてください。Googleアカウントが複数ある場合は、MYMIに登録したアカウントを選んだか確認してください。

</details>

<details>
<summary>LINEやXで登録したアカウントでアプリにログインできない</summary>

アプリにはLINEとXのログインがなく、AndroidアプリにはAppleのログインもありません。ウェブでログインしてください。スマートフォンでもChromeやSafariで[www.mymi.live/ja](https://www.mymi.live/ja)を開き、登録したときと同じボタンを押せば使えます。

</details>

それでも解決しないときは、画面に表示された文言と一緒に、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)までお知らせください。
