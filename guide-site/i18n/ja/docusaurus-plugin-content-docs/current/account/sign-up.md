# 新規登録

MYMIは、**ソーシャルアカウントでログインし、基本情報を入力する**と登録できます。MYMI専用のパスワードを作る必要はありません。

すでに登録している場合は、最初に使ったログイン方法とアカウントを選んでください。Webとアプリを切り替えるときも、同じアカウントを使います。

## 1. ソーシャルアカウントを選ぶ

1. [MYMIのWebサイト](https://www.mymi.live)またはアプリを開きます。
2. 画面下部の**マイページ**からログイン画面を開きます。利用中に表示されるログイン案内からも始められます。
3. ソーシャルアカウントを選び、そのサービスでログインします。
4. 初めて利用するアカウントなら、MYMIの新規登録画面に進みます。

表示されるボタンは、Webサイトの言語とアプリのプラットフォームによって異なります。

| 利用環境 | ログイン方法 |
| --- | --- |
| 日本語・繁体字中国語のWeb | LINE、Google、X、Apple |
| 韓国語のWeb | カカオ、Google、Apple |
| 英語のWeb | Google、X、Apple |
| Androidアプリ | カカオ、Google |
| iOSアプリ | Apple、カカオ、Google |

画面に表示されるボタンから選んでください。以前使った方法がアプリにない場合は、対応する言語のWebサイトからログインできます。

> **既存のアカウントを使い続けるには**
>
> 登録済みなのに新規登録画面が出る場合は、ログイン方法とソーシャルアカウントを確認してください。例えばGoogleアカウントが複数ある場合は、MYMIの登録に使ったものを選びます。

## 2. 基本情報を入力する

次の四つの項目を入力します。値がすでに入っている場合も、その内容を使うか確認してください。

| 項目 | 用途 | 入力条件 |
| --- | --- | --- |
| 名前 | 作品の登場人物があなたを呼ぶ名前。登録後に作られる基本ペルソナに使います | 20文字以内 |
| 性別 | 基本ペルソナに使う性別 | 女性・男性・その他から選択 |
| ユーザーID | `@moon_reader`のようにアカウントを識別するID | 3〜20文字。形式と重複の確認が必要 |
| ニックネーム | ほかのユーザーに表示される名前 | 30文字以内 |

例えば、名前を`ハル`、ユーザーIDを`moon_reader`、ニックネームを`月明かりの読者`にできます。作品の中では「ハル」として会話し、ほかのユーザーには「月明かりの読者」と表示されます。

ユーザーIDはソーシャルログインの代わりにはなりません。次回も登録に使ったソーシャルアカウントでログインします。

現在の登録画面では生年月日は入力しません。本人確認や成人確認が必要な機能は、登録後にその機能の案内に沿って別途手続きします。

### ユーザーIDのルール

- 英小文字、数字、ハイフン（`-`）、アンダースコア（`_`）を使えます。
- 長さは**3〜20文字**です。
- ハイフンやアンダースコアで始めたり終わったりできません。
- ハイフンやアンダースコアを二つ以上続けて使えません。両方を混ぜて続けることもできません。
- ほかのユーザーが使っているIDは選べません。

| 入力例 | 形式の確認 |
| --- | --- |
| `moon_reader`、`reader-123` | 使える形式です。実際に空いているかは重複確認が必要です |
| `ab` | 3文字未満です |
| `_reader`、`reader-` | アンダースコアやハイフンで始まる、または終わっています |
| `moon__reader`、`moon-_reader` | アンダースコア・ハイフンが連続しています |

入力後、自動で重複が確認されます。**使用可能**と表示されたら進んでください。確認に失敗した場合は、入力欄の横の**確認**ボタンでやり直せます。

## 3. 規約を確認する

各項目の内容を読み、同意するか選びます。

| 項目 | 登録に必要ですか？ |
| --- | --- |
| 利用規約に同意 | 必須 |
| 個人情報の収集および利用に同意 | 必須 |
| サービス注意事項 | 必須 |
| マーケティング情報の受信に同意 | 任意 |

**マーケティング情報の受信に同意しなくても登録できます。**「全て同意」を選ぶと任意項目も選択されるため、希望どおりの状態か確認してください。

## 4. 登録を完了する

名前・性別・ユーザーID・ニックネームを入力し、IDが使用可能で、必須の三項目に同意すると、**登録完了**ボタンを押せます。

入力した名前と性別を基に基本ペルソナが作られます。ホームで作品を選んで会話を始めるか、[ペルソナ設定](/account/persona.md)で作品の中での役割を詳しく決めてみましょう。

## 登録できないとき

| 状況 | 確認すること |
| --- | --- |
| 登録完了を押せない | 四項目の入力、IDの「使用可能」表示、必須三項目への同意を確認します |
| IDの形式エラーが出る | 長さ、先頭と末尾、ハイフン・アンダースコアの連続を確認します |
| IDが使用中と表示される | 別のIDに変えて重複確認します |
| 重複確認でエラーが出る | 接続を確認して「確認」を押し直します |
| ソーシャルログインで失敗する、MYMIに戻らない | ログイン画面からやり直します。別のアプリ内で開いている場合は外部ブラウザーを試します |
| アプリに以前使ったログイン方法がない | Webサイトを使います。Android端末でもWebならAppleでログインできます |
| 登録済みなのに基本情報の入力を求められる | 最初に使ったログイン方法とソーシャルアカウントか確認します |

接続環境の問題は[MYMIへのアクセス方法](/getting-started/how-to-access.md)をご覧ください。解決しない場合は、エラーメッセージと利用環境を添えてお問い合わせください。
