# MYMIとは？

MYMIは、**AIが演じる作品の登場人物と会話しながら、物語を作っていくサービス**です。ほかの人が作った作品で会話したり、自分の作品を作って公開したりできます。

たとえば作品**地下都市ソウル**では、記憶をなくして検疫所で目覚めた自分が、案内人のカン・ミヌや検疫所の医師イ・ソヨンと話します。何を言い、どこへ行くかによって、次の場面が変わります。

## 知っておくと便利な言葉

| 言葉 | 意味 | 地下都市ソウルでは |
| --- | --- | --- |
| 作品 | 世界観、登場人物、最初の場面をまとめた物語 | 2031年、封鎖された地下都市ソウル |
| 登場人物 | AIが演じる人物 | 案内人のミヌ、検疫所の医師ソヨン |
| ペルソナ | 作品の中で自分が使う名前と役割 | 検疫所で目覚めた「ハル」 |
| イントロ | 会話を始めると最初に表示される場面 | ミヌが懐中電灯を回しながら話しかけてくる場面 |

**登場人物はAIが、ペルソナは自分が演じる役割**です。ペルソナを別に作らなくても、登録したときに決めた名前ですぐに会話できます。

## 作品で会話する

1. 下のメニューの**ホーム**で、**おすすめ**・**ランキング**・**ジャンル**・**検索**タブから作品を選びます。
2. 作品の紹介を読んで、**会話を始める**を押します。
3. イントロの場面を読み、自分のセリフや行動を書いて送ります。キャラクターが返信し、物語が続きます。
4. 次からは、下のメニューの**チャット**から続きを話します。

同じ会話を、**小説**・**チャット**・**1:1**・**ストーリー**の4つの画面に切り替えて読めます。詳しくは[会話する](/chatting/chat-with-character.md)にあります。

:::info[会話にはスパークを使います]
AIの返信を1回受け取るたびに、選んだAIモデルの価格分のスパークが消費されます。ログインしていない場合は、最大5回まで会話を試せます。スパークはチャージして手に入れます。チャージの方法と、**出席チェック**などでもらえる報酬は[スパークのチャージ](/payment/payment-methods.md)にまとめています。
:::

## 自分の作品を作る

ログインして下のメニューの**制作**を押すと、**作品制作**画面が開きます。作品は2つの方式で作れます。**かんたんモード**は、項目を埋めるとAI設定が自動で作られ、**エキスパートモード**は、AIが読む設定と出力ルールを自分で書きます。最初はかんたんモードで開きます。画像1枚と文章だけでも作れます。

初めての方は、[始める前に](/create/start/before-you-start.md)で2つのモードの違いを確認し、[かんたんモードで初めての作品を作る](/create/simple/first-work.md)に沿って作ってみてください。

## つまずいたときは

<details>
<summary>成人向け作品が表示されない</summary>

ホームのセーフティフィルターがオンのあいだは、成人向け作品は一覧に表示されません。ログインして年齢確認（18歳以上）を済ませてから、セーフティフィルターをオフにしてください。電話番号認証だけでは表示されません。方法は[年齢確認・電話番号認証](/account/adult-verification.md)にあります。

</details>

<details>
<summary>制作を押したらログインするように言われた</summary>

作品を作るにはログインが必要です。[新規登録](/account/sign-up.md)するか、登録したアカウントでログインしてください。

</details>

<details>
<summary>アプリはありますか？</summary>

AndroidとiPhoneのアプリがあり、ウェブと同じアカウントで使えます。ただし、LINEとXのログインはウェブでしか使えません。インストール方法は[MYMIへのアクセス方法](/getting-started/how-to-access.md)にあります。

</details>
