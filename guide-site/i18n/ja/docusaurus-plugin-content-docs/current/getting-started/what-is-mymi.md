# MYMIとは？

MYMIは、**AIが演じる作品の登場人物と会話しながら物語を進めるサービス**です。気になる作品を選び、登場人物に話しかけたり、状況に合った行動を入力したりできます。

例えば「真夜中だけ開く書庫」という作品では、夜勤の助手になって司書に話しかけたり、不審な返却台帳を調べたりして物語を進められます。何を話し、何を調べるかによって、次の場面が変わります。

## 作品・登場人物・ペルソナの違い

| 用語 | 意味 | 書庫の作品での例 |
| --- | --- | --- |
| 作品 | 世界観、登場人物、開始時の状況を含む物語 | 真夜中だけ開く書庫の物語 |
| 登場人物 | AIが作品の設定に沿って演じる人物 | 書庫を管理する司書ソヨン |
| ペルソナ | 作品の中で使う自分の名前や役割などのプロフィール | 初出勤の夜勤助手 |
| 導入部 | 会話を始めたときに最初に表示されるメッセージ | ソヨンが返却台帳を渡す最初の場面 |

一つの作品に複数の登場人物がいる場合もあります。**登場人物はAIが演じる役、ペルソナは自分が演じる役**と考えると分かりやすくなります。

詳しくは[ペルソナ設定](/account/persona.md)をご覧ください。

## ほかの制作者の作品で会話する

1. **ホーム**で作品を探します。
2. 作品紹介を読み、気に入った作品で会話を始めます。
3. 導入部を読んでから、登場人物に伝えたい言葉や自分の行動を入力します。
4. 続きの会話は**チャット**の一覧から開きます。

会話に使うAIモデルやチャットルームの設定も変更できます。作品に画像やコンポーネントが用意されていれば、会話中に人物の姿やステータス表示などが現れることもあります。

最初は短い一言からで大丈夫です。操作方法は[会話を始める](/chatting/chat-with-character.md)をご覧ください。

## 自分の作品を作る

画面下部の**制作**から、**作品制作2.0（V2）** のエディターで新しい作品を作れます。タブを自由に移動して、必要な部分から書き始められます。

| 用意するもの | 役割 |
| --- | --- |
| 作品紹介と表紙 | 読者にどのような作品かを伝えます |
| プロンプト | 世界観、人物の性格や話し方、秘密、物語の進行ルールをAIに伝えます |
| 導入部 | ユーザーが最初に出会う場面を書きます |
| 画像とコンポーネント | 会話中に表示する画像や画面要素を用意し、使用条件を決めます |
| ロアブック | 会話に特定の単語が出てきたときに参照する追加設定を書きます |

最初からすべての機能を使う必要はありません。一人の登場人物と最初の場面を決め、必要な画像や設定を順に追加してみましょう。

V1を使っていた方にとっての大きな違いは、世界観・登場人物・秘密を個別の欄ではなく**プロンプト**で構成することです。画像を登録した後は、会話でいつ使うかも結び付けます。既存のV1作品は、作品管理からその作品のV1エディターで編集します。

## どこで利用できますか？

PC・スマートフォンのWebと、Android・iOSアプリで利用できます。URLとインストール先は[MYMIへのアクセス方法](/getting-started/how-to-access.md)をご覧ください。
