# MYMIへのアクセス方法

MYMIは、ウェブサイトとAndroid・iPhoneアプリで同じアカウントを使います。パソコンではウェブから、スマートフォンではアプリかスマートフォンのブラウザーから始めてください。

## ウェブで開く

1. ChromeやSafariなどのブラウザーで[www.mymi.live/ja](https://www.mymi.live/ja)を開きます。インストールは必要ありません。
2. 初めて開くと「主に見たいキャラクターを選んでください」という画面が出ます。**女性キャラクター**、**男性キャラクター**、**すべて見たい**から選ぶと、そのキャラクターが登場する作品を中心にホームを表示します。選んだ内容は、あとでホームの絞り込みから変えられます。
3. 気に入った作品を開いて会話してみてください。ログインしなくても5回まで無料で会話できます。

無料体験を使い切るとログイン画面が出ます。その場で新規登録すると、体験した会話を新しいアカウントで続けられます。登録方法は[新規登録](/account/sign-up.md)にあります。成人向け作品は、ログインして年齢確認（18歳以上）を済ませると開けます。

## アプリをインストールする

| 端末 | インストール |
| --- | --- |
| Android | [Google PlayでMYMIをインストール](https://play.google.com/store/apps/details?id=live.mymi.app) |
| iPhone | [App StoreでMYMIをインストール](https://apps.apple.com/app/id6794338974) |

スマートフォンのブラウザーでMYMIを開いている場合は、ホーム右上の**アプリ**を押してもストアが開きます。インストールしたアプリを開き、下のメニューの**マイページ**からログインまたは新規登録します。

## ウェブとアプリを一緒に使う

ウェブとアプリは同じアカウントを使います。登録したソーシャルアカウントでログインすれば、会話もスパークもそのまま表示されます。

:::warning[LINE・X・Appleで登録した場合]
アプリにはLINEとXのログインがなく、AndroidアプリにはAppleのログインもありません。この場合はウェブでログインしてください。スマートフォンでもChromeやSafariで[www.mymi.live/ja](https://www.mymi.live/ja)を開き、登録したときと同じボタンを押せば使えます。
:::

## 画面下のメニュー

| メニュー | できること |
| --- | --- |
| **ホーム** | 作品を探す |
| **チャット** | 会話していた作品を開いて続きを話す |
| **制作** | 自分の作品を作る |
| **マイページ** | ログイン、自分の情報とスパーク、出席チェック、作品管理 |

## つまずいたときは

<details>
<summary>LINEやInstagramでリンクを開いたらログインできない</summary>

ほかのアプリの中でリンクを開くと、そのアプリ内のブラウザーで開くため、ログインできないことがあります。画面の上か下にあるメニュー（⋮ や …）から「ブラウザで開く」などの項目を選び、ChromeやSafariで開いてください。メニューがない場合は、アドレスをコピーしてブラウザーに貼り付けてください。

</details>

<details>
<summary>「より快適な環境でご利用ください！」という画面が出る</summary>

TikTokアプリの中でリンクを開いたときに出る案内です。TikTokの画面右上の「…」メニューから「ブラウザで開く」を選んでください。画面の**リンクをコピー**を押して、ブラウザーに貼り付けてもかまいません。

</details>

<details>
<summary>画面が開かない、または読み込みが終わらない</summary>

1. インターネット接続を確認して再読み込みするか、アプリを閉じてもう一度開きます。
2. ブラウザーやMYMIアプリにアップデートがあればインストールします。
3. 別のブラウザーで開いてみます。
4. 特定のブラウザーだけで起きる場合は、[Cookieの削除](/faq/cookie-clear.md)を試してください。削除したあとは、もう一度ログインが必要です。

</details>

<details>
<summary>アプリでログインしたら、前の会話がない</summary>

ウェブで登録したときとは別のソーシャルアカウントでログインした可能性があります。MYMIのアカウントはソーシャルアカウントごとに別々です。**マイページ → 設定とサポート → ログアウト**を押し、最初に登録したソーシャルアカウントでログインし直してください。

</details>

それでも解決しないときは、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)までお知らせください。アプリでは、**マイページ → 設定とサポート → バージョン情報**の**お問い合わせ情報をコピー**で利用環境をコピーし、一緒に送ってください。
