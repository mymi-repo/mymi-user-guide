# MYMIへのアクセス方法

MYMIは**WebブラウザーとAndroid・iOSアプリ**で利用できます。PCではWeb、スマートフォンではアプリかモバイルWebから始めましょう。

## Webで利用する

1. PCまたはスマートフォンでWebブラウザーを開きます。
2. [**MYMIのWebサイト**](https://www.mymi.live)にアクセスします。
3. 作品を探し、会話を始めるときに画面の案内に沿ってログインします。

専用のプログラムをインストールせずに利用できます。

## アプリで利用する

| 端末 | インストール先 |
| --- | --- |
| Android | [Google PlayでMYMIをインストール](https://play.google.com/store/apps/details?id=live.mymi.app) |
| iOS | [App StoreでMYMIをインストール](https://apps.apple.com/app/id6794338974) |

1. 端末に合ったストアのリンクを開きます。
2. MYMIをインストールして起動します。
3. 初めての方は新規登録、すでに利用している方はいつものアカウントでログインします。

Webとアプリは同じMYMIサービスです。別の端末で続けて利用するときは、**以前と同じログイン方法とアカウント**を選んでください。詳しくは[新規登録](/account/sign-up.md)と[ログイン・プロフィール設定](/account/login-profile.md)をご覧ください。

## 画面下部のメニュー

| メニュー | できること |
| --- | --- |
| ホーム | 作品を見て、気になる作品を探す |
| チャット | 始めた会話を探し、続きを話す |
| 制作 | 新しい作品を作る |
| マイページ | プロフィール、アカウント、作品管理などを確認する |

作品制作や会話の画面では、それぞれの操作に必要なメニューが表示されます。まずはホームで気になる作品を一つ選んでみましょう。

## リンクを開いてもログインや画面表示がうまくいかない

カカオトークやInstagramなどのアプリ内でリンクを開くと、そのアプリの内蔵ブラウザーが使われる場合があります。ログインできない、画面が動かないときは、メニューの**外部ブラウザーで開く**を選ぶか、URLをコピーして普段使うブラウザーで開いてください。

メニューの名前や場所はアプリによって異なります。

## 接続できないとき

1. インターネット接続を確認し、ページを再読み込みするかアプリを開き直します。
2. ブラウザーやMYMIアプリに更新がないか確認します。
3. Webでは別のブラウザーでも試します。
4. 特定のブラウザーでだけ問題が続く場合は、[Cookieの削除](/faq/cookie-clear.md)をご覧ください。削除後は再ログインが必要になることがあります。

解決しない場合は[よくある質問](/faq/faq.md)を確認するか、問題が起きた画面と利用環境を添えてお問い合わせください。
