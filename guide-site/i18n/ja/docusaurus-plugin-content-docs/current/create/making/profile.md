# 作品紹介を整える

ユーザーが作品を選ぶ前に目にするのは、**基本情報**タブの内容です。表紙、詳細説明、クリエイターガイド、おすすめモデルを埋めて、作品紹介画面を仕上げます。ここに書いた文章はAIには渡されません。

:::info
エキスパートモードの案内です。かんたんモードは、[アセットとAI画像](/create/simple/assets#代表画像を決める)と[オプション](/create/simple/extras#オプション)をご覧ください。
:::

## 表紙

表紙は1〜10枚入れられます。複数枚の場合は、決めた間隔で次の1枚に切り替わります。

<ScreenStep src="/img/screens/ja/profile-cover.webp" device="part" alt="表紙を2枚入れて、切り替え間隔を2秒にした画面" caption="表紙2枚と切り替え間隔">

- **画像をアップロード**: 持っている画像をアップロードします。JPG、PNG、WEBP、GIF、HEICファイルを5MBまで使えます。
- **アセットから取り込む**: **アセット**タブで作った画像を表紙に使います。
- **切り替え間隔**: 次の1枚に切り替わるまでの時間です。ボタンを押すたびに0.5秒ずつ変わり、直接入力するときは0.5秒〜60秒の間で入力します。

サムネイルの<strong>×</strong>ボタンを押すと、その表紙を外します。

</ScreenStep>

<ScreenStep src="/img/screens/ja/profile-cover-picker.webp" alt="アセットから取り込む窓。アセットタブの画像が格子状に表示されている" caption="アセットから取り込む">

**アセットから取り込む**を押すと、アセットタブの完成した画像がすべて表示されます。表紙にする画像を選んで、**N枚を表紙に追加**を押します。

アセットタブにまだ画像がなければ、一覧は空です。先に[画像を用意する](/create/images)で作ってください。

</ScreenStep>

:::tip[表紙の選び方]
表紙は、作品一覧でいちばん最初に目に入る画像です。主人公の顔がよく見える縦長の画像を1枚目に置きましょう。複数枚なら、人物ごとに1枚ずつ入れて登場人物を紹介する方法もあります。
:::

## 詳細説明

**詳細説明**は、作品紹介画面の本文です。最大50,000文字で、通常の文章・マークダウン・HTMLを混ぜて書けます。

- **プレビュー**: ユーザーに表示される見た目を確認します。
- **Google AI Studioで作る**: 入力欄の下にあります。Geminiと会話しながら、HTMLの紹介ページを作ります。手順は[下記](#ai-studioで紹介ページを作る)をご覧ください。

<ScreenStep src="/img/screens/ja/profile-description-preview.webp" alt="詳細説明のプレビュー窓に、タイトル・登場人物・楽しみ方が書式どおりに表示されている" caption="詳細説明のプレビュー">

プレビューでは、マークダウンの見出し・箇条書き・太字が書式どおりに表示されます。

紹介は、次の順に書くと読みやすくなります。

1. 一、二文の作品の要約
2. 世界観と始まりの状況
3. 登場人物の紹介
4. 楽しみ方（何をしてみるとよいか）

</ScreenStep>

### AI Studioで紹介ページを作る

詳細説明欄の下にある**Google AI Studioで作る**から始めます。Geminiと会話しながら、キャラクターのイラストと作品紹介を入れたHTMLページを作ります。

1. **作品情報をコピー**を押します。作品の設定、画像のアドレス、今書いている詳細説明がまとめてコピーされます。
2. **Google AI Studioを開く**を押します。初めてなら、**Remix**で自分の作業スペースを作ります。
3. 入力欄に作品情報を貼り付け、その下に希望を1〜2行書いて送ります。
4. 完成したら、上部で**프로필 HTML**（プロフィールHTML）が選ばれているか確認して、**MYMI에 붙여넣을 코드 복사**（MYMI用コードをコピー）を押します。
5. MYMIの**詳細説明**欄に貼り付け、**プレビュー**で確認してから**下書き保存**を押します。

**使い方**を押すと、手順ごとの案内が開きます。実際のAI Studioの画面は、[Google AI Studioの画面を見ながら進める](/create/ai-studio)で確認できます。

:::info
Googleアカウントの無料リクエストの上限内で使えます。支払いやAPIキーは不要です。イラストを入れるには、アセットタブに完成した画像が必要です。成人向けに設定した画像は使いません。
:::

:::warning[画像を削除する前に]
作品情報で作ったHTMLには、画像の実際のアドレスが入ります。アセットタブでその画像を削除すると、紹介ページの画像も表示されなくなります。
:::

## クリエイターガイド

<ScreenStep src="/img/screens/ja/profile-guide.webp" device="part" alt="クリエイターガイドの欄に利用のヒントを書いた画面" caption="クリエイターガイド">

**クリエイターガイド**には、作品の楽しみ方や新しく追加した内容を書きます。作品紹介画面に別枠で表示されます。1つの文章に5,000文字まで書けます。

今の文章を直すと、その文章が変わります。**新しく書く**を押すと、今の文章がバージョン番号（V1、V2…）と日付を付けて下の一覧に移り、新しい文章を書けます。

</ScreenStep>

> 例: 最初はミヌに「ここはどこ？」と聞いてみてください。記憶に関する質問をソヨンにすると、手がかりを一つずつ得られます。

## おすすめモデル

<ScreenStep src="/img/screens/ja/profile-models.webp" device="part" alt="おすすめモデル0/5と選択するボタン" caption="おすすめモデル">

作品に合うチャットモデルを、最大5個選んでおけます。作品紹介画面とチャットのモデル一覧に**おすすめ**と表示され、ユーザーはほかのモデルも選べます。

**選択する**を押すと、チャット画面と同じモデル一覧が開きます。

</ScreenStep>

## ジャンルとハッシュタグ

- **ジャンル**: 1〜2個を選びます。ロマンス、BL、GL、ファンタジー、武侠、SF、アクション・冒険、日常、ドラマ、コメディ、ミステリー・スリラー、ホラー、歴史・時代劇から選びます。
- **ハッシュタグ**: 1個以上入れます。作品の題材や雰囲気を短く書きます。例: `地下都市`、`記憶喪失`、`ディストピア`
- **読者層**（男性向け・女性向け）は、**その他の設定**タブで別に選びます。

## つまずいたときは

<details>
<summary>コピーした作品情報に画像のアドレスがない</summary>

アセットタブに完成した画像があるときだけ、画像のアドレスが入ります。画像をアップロードまたは生成してから、もう一度**作品情報をコピー**を押してください。

</details>

<details>
<summary>HTMLを貼り付けたのに、プレビューが思っていたのと違う</summary>

作業スペースの**프로필 HTML**（プロフィールHTML）タブで**MYMI에 붙여넣을 코드 복사**（MYMI用コードをコピー）を押し、全体をもう一度貼り付けてみてください。それでも見た目が崩れる場合は、Geminiに直してもらいます。

</details>

<details>
<summary>表紙は何枚まで入れられる？</summary>

10枚までです。もっと入れたいときは、先に1枚外してください。

</details>
