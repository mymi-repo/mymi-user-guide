# 会話に画像を表示する

会話の中の画像は、AIが返信を書きながら`![]({{URL}}/A/1.webp)`のような行を入れたときに表示されます。AIがどの場面でどの画像を入れるかは、**プロンプト**に書いたルールを見て決めます。このページは、[画像を用意する](/create/images)でアセットを作ったあとの段階です。

:::info
エキスパートモードの案内です。かんたんモードでは、状況説明で画像を選ばせます。[アセットとAI画像](/create/simple/assets)と[入力項目と制限](/create/simple/reference#画像の書き方)をご覧ください。
:::

## どうつながるか

| どこで | 何を | 例 |
| --- | --- | --- |
| **アセット**タブ | フォルダとコードで画像のパスを決めます | フォルダ`A` + コード`1` → `A/1` |
| **プロンプト**タブ | コードごとに意味を書き、いつ画像を入れるかを伝えます | `A`=カン・ミヌ、`1`=笑い |
| チャット | AIが場面に合うコードを選んで、返信に入れます | ミヌが笑いながら話すとき`A/1` |

`{{URL}}`は、実際の画像のアドレスに置き換わる場所です。自分でアドレスを書く必要はありません。

## 基本型: コードごとに意味を書く

<ScreenStep src="/img/screens/ja/prompt-basic-codes.webp" device="part" alt="基本型の画像出力ルール。キャラクターコードA=カン・ミヌ、B=イ・ソヨン、状況コード1=笑い・2=悲しみ・3=怒り、その他コードBG1=検疫所の廊下、例外としてB/3なし" caption="基本型 · 画像出力ルール">

基本型なら、アセットタブのコードが**画像出力ルール**に表として表示されます。意味を短く書くだけで大丈夫です。

- **キャラクターコード**: 人物の名前。例: `カン・ミヌ`
- **状況コード**: いつ出る画像か。例: `笑い`
- **その他コード**: 何の画像か。例: `検疫所の廊下`
- **例外**: ある人物にない場面。例: `B/3 なし`

</ScreenStep>

書いた意味は、次のようなルールの文とコード表にまとめられてAIに渡されます。タブの一番下の**組み立てたプロンプト**で確認できます。

```text
### 画像出力ルール
場面に実際に登場する人物・背景を下のコード表から選び、画像で見せる。応答ごとに1枚以上 — …
形式: `![]({{URL}}/キャラクターコード/状況コード.webp)`、その他コードは `![]({{URL}}/その他コード.webp)`。…
キャラクターコード:
A=カン・ミヌ
B=イ・ソヨン
状況コード:
1=笑い
2=悲しみ
3=怒り
その他コード:
BG1=検疫所の廊下
例外: B/3 なし
例: キャラクターコード A + 状況コード 1 → `![]({{URL}}/A/1.webp)`
```

:::tip[意味を書くときは]
- **キャラクターコードの意味は、名前だけを短く書きます。** 基本型では、この意味がチャット画面で人物の名前としても使われます。性格や関係のような説明は、作品情報に書きます。
- **状況コードは、すべての人物に同じ意味で使います。** `1`がミヌでは笑い、ソヨンでは怒りになると、AIが混乱します。同じコードには、人物ごとに同じ場面の画像を入れてください。
- **ない組み合わせは例外に書きます。** ソヨンに怒りの画像がないなら、`B/3 なし`のように書いて、AIがないパスを呼び出さないようにします。
:::

## 自分で書く: ルールを自分で書く

自分で書く方式では、ルールの文が自動では付きません。次の3つをプロンプトに自分で書きます。

1. **どんな画像があるか**: コードと意味の一覧
2. **いつ入れるか**: どの場面でどのコードを使うか
3. **どんな形式で入れるか**: `![]({{URL}}/A/1.webp)`のように1行で、ないパスは作らないこと

いちばん短く書くと、こうなります。

```text
ソヨンが笑って挨拶するとき、下の画像を独立した1行で出力する。
![]({{URL}}/B/1.webp)
登録されていない画像パスは作らない。
```

基本型が作るルールの全体を真似して書いても構いません。[プロンプトを書く](/create/prompt#自分で書く方式で書く)の**自分で書く例を全部見る**を参考にしてください。

## 導入部に入れる

導入部は自分で前もって書いておく最初のメッセージなので、画像を入れる位置も自分で決めます。**アセット画像を挿入**で入れて、プレビューで確認します。方法は[導入部を書く](/create/greetings#画像を入れる)にあります。

## ロックしておいて会話で解放する: 解放が必要

<ScreenStep src="/img/screens/ja/assets-image-sheet.webp" alt="画像設定の窓にある解放が必要スイッチ" caption="画像設定の窓 · 解放が必要">

1. アセットタブで、ロックする画像のサムネイルを押します。
2. 設定ウィンドウで**解放が必要**をオンにします。
3. **保存**を押します。保存するとロックされます。

ロックした画像は、作品紹介画面の画像一覧ではぼかして隠されます。会話にその画像が出ると、そのユーザーにだけ解放されます。

特別な場面の画像を取っておきたいときに使います。表紙と導入部は最初から見える場所なので、そこに使った画像はロックしてもそのまま見えます。

</ScreenStep>

## つまずいたときは

<details>
<summary>AIが画像を入れない、またはたまにしか入れない</summary>

- 基本型: コードごとに意味があるか、画像が完成しているか確認します。意味のないコードはAIが使えません。
- 自分で書く: 画像出力ルールをプロンプトに書いたか確認します。
- AIの返信は毎回変わるので、ルールを書いてもたまに抜けることがあります。会話しながら、ルールの文を整えていきます。

</details>

<details>
<summary>会話で画像が表示されない、または壊れて見える</summary>

AIがないパスを呼び出したのかもしれません。アセットタブのコードとプロンプトに書いたコードが同じか、ない組み合わせを**例外**に書いたか確認します。フォルダ名やコードを変えたなら、プロンプトと導入部のパスもあわせて直します。

</details>

<details>
<summary>人物の名前がおかしく表示される</summary>

基本型では、キャラクターコードの意味がチャット画面の人物名として使われます。意味に長い説明を書いたなら名前だけを残し、説明は作品情報に移します。

</details>
