# コンポーネントを入れる

コンポーネントは、**チャット中にAIが表示するUI**です。ステータスウィンドウ、インベントリ、選択肢のように見せたいものを作っておくと、AIが必要なときに呼び出します。コードがわからなくても、**AI Studioで作る**で作れます。

:::info
エキスパートモードの案内です。かんたんモードは、[ロアブック・コンポーネント・オプション](/create/simple/extras#コンポーネント)をご覧ください。
:::

## コンポーネントを追加する

1. **コンポーネントを追加**を押します。
2. **JSXコード**欄にコードを貼り付けます。**貼り付け**を押すと、クリップボードのコードが入ります。
3. プレビューで、チャットでの見た目を確認します。

コンポーネント名と変数は、コードから自動で読み取ります。

<ScreenStep src="/img/screens/ja/components-editor.webp" device="part" alt="StatusWindowコンポーネントを開いた画面。プレビュー、JSXコード、変数のデフォルト値hp・mp、呼び出しタグとコピーボタン" caption="コンポーネントの編集">

- **JSXコード**: `function 名前({ 変数 = デフォルト値 })`の形のコードです。コードフェンスとimport文は自動で整理されます。20,000文字まで書けます。
- **変数のデフォルト値**: コードから読み取った変数とデフォルト値が表示されます。デフォルト値はAIが埋める値の例になり、プレビューにも使われます。
- **呼び出しタグ**: 「AIはチャットでこのように呼び出します」の下にあるタグです。**コピー**を押して、プロンプトタブに貼り付けて使います。

</ScreenStep>

例の作品のステータスウィンドウのコードです。関数名（`StatusWindow`）と、1つ以上の変数（`hp`、`mp`）が必要です。

```jsx
function StatusWindow({ hp = 100, mp = 40 }) {
  const bar = (value, color) => (
    <div className="h-2 w-full rounded-full bg-slate-700">
      <div className={`h-2 rounded-full ${color}`} style={{ width: `${Math.max(0, Math.min(100, value))}%` }} />
    </div>
  );
  return (
    <div className="my-2 w-full max-w-sm rounded-xl border border-cyan-400/40 bg-slate-900/90 p-3 text-slate-100">
      <div className="mb-2 flex items-center justify-between text-[11px] font-bold tracking-widest text-cyan-300">
        <span>STATUS</span>
        <span>検疫所 B-3</span>
      </div>
      <div className="space-y-2 text-sm">
        <div>
          <div className="mb-1 flex justify-between"><span>体力</span><span>{hp}/100</span></div>
          {bar(hp, "bg-rose-400")}
        </div>
        <div>
          <div className="mb-1 flex justify-between"><span>魔力</span><span>{mp}/100</span></div>
          {bar(mp, "bg-sky-400")}
        </div>
      </div>
    </div>
  );
}
```

## プロンプトにつなげる

コンポーネントを追加しただけでは、AIはいつ呼び出せばよいかわかりません。**プロンプト**タブに、いつ呼び出すかを書きます。

- **基本型**: **コンポーネント出力ルール**に、コンポーネントごとに登場するタイミングを書きます。タグは、コンポーネントタブに表示されるとおり（`<StatusWindow hp={100} mp={40} />`）に、ルールの文と一緒に自動で付きます。
  例: `戦闘が始まる時と体力が変わる時。hp = 体力、mp = 魔力。`
- **自分で書く**: 呼び出しタグ、登場するタイミング、変数の意味をすべて自分で書きます。コンポーネントタブで**コピー**したタグをそのまま貼り付けても、値の位置を`{value}`に変えて書いても構いません。

自分で書く方式なら、次のように書きます。

```text
### コンポーネント出力ルール
ルールに当たる瞬間に、下のタグをそのまま1行で出力する。
- `<StatusWindow hp={value} mp={value} />`: 戦闘が始まる時と体力が変わる時。hp = 体力、mp = 魔力。
```

:::info[コンポーネントは見せるための道具です]
コンポーネントは、AIが入れた値を見やすく描くだけです。体力の計算のように、値が正しいかどうかはAIの返信しだいです。ルールを書いても、AIがときどきタグを抜かしたり、値を違う形で入れたりすることがあります。
:::

## AI Studioで作る

[AI Studioを開く](https://aistudio.google.com/apps/5e37a6ef-b980-4613-9c34-38b888e1bd1e?showPreview=true&showAssistant=true)

画像を使う場合は**アセット情報をコピー**を押します。画像がなくても制作を始められます。

1. **作業スペースのテンプレートを開く** — 「AI Studioを開く」からGoogleでログインします。別の開発者が作ったアプリという案内が出たら「Continue to the app」を選びます。MYMIアプリでは外部ブラウザが開きます。
2. **Remixで自分の作業スペースを作る** — テンプレートの読み込み後、上部の「Remix（Copy app）」を押し、名前を決めて「Remix app」を押します。自分の作業スペースが開いたら制作を始めます。
3. **Geminiに希望を伝える** — 左側のGemini入力欄に「MYMI用コンポーネントとして体力と好感度を表示するステータス画面を作って」のように入力します。コピーした作品・アセット情報があれば一緒に貼り付けます。
4. **Previewで確認して調整する** — ビルド完了後、右側のPreviewでコンポーネントまたはプロフィールHTMLタブを選びます。Launchが表示されたら押して起動します。Geminiに色・内容・配置の調整を依頼します。
5. **完成したMYMI用コードをコピーする** — コンポーネントタブで検証結果を確認し、「MYMI에 붙여넣을 코드 복사（MYMI用コードをコピー）」を押します。自動コピーできない場合は、表示されたコード全体を選択してコピーします。
6. **MYMIに戻って貼り付ける** — コンポーネント → コンポーネントを追加 → 貼り付けに入れます。変数の初期値とプレビューを確認し、Geminiが示す呼び出しタグと使用指示もプロンプトに入れて作品を保存します。
7. Geminiが示す呼び出しタグと使用指示を**プロンプト**タブに入れます。

:::info
Googleアカウントで無料リクエストの上限内で作成できます。この手順では有料APIキーの接続やデプロイは不要です。
:::

:::tip
Remix中に権限エラーが出たら、Googleアカウントを確認し、再読み込みしてRemixをやり直してください。プレビューが空白ならビルド完了後に再読み込みします。無料枠を使い切った場合は、上限がリセットされてから続けられます。
:::

## 画像を使うコンポーネント

- 場面ごとにAIに画像を選ばせたいなら、画像を**変数**として受け取るようにして、プロンプトには`img="{{URL}}/A/1.webp"`のように、値全体をアセットのパスで書きます。`url({{URL}}/…)`のようにほかの文章の間に入れると、アドレスに置き換わりません。
- ないパスを書くと、空の値が入ります。コンポーネントは、画像の値があるときだけ描くように作ってください。
- 変数の**デフォルト値**には`{{URL}}`を使わず、実際の画像アドレス（httpsで始まるもの）か空の値を入れます。
- コードの中に固定で入れた画像アドレスは、そのアセットを削除すると表示されなくなります。

## つまずいたときは

<details>
<summary>「function名が見つからないコンポーネントがあります。」と表示される</summary>

コードが`function 名前(...)`の形で始まっているか確認します。アロー関数や名前のない関数は、名前を読み取れません。

</details>

<details>
<summary>「変数のないコンポーネントがあります。変数を1つ以上宣言してください。」と表示される</summary>

関数が受け取る変数を、1つ以上宣言する必要があります。例: `function StatusWindow({ hp = 100 })`

</details>

<details>
<summary>コードを変えたのに、変数のデフォルト値がそのまま</summary>

**貼り付け**ボタンでコードを丸ごと入れ替えると、デフォルト値を読み取り直します。コード欄を少しずつ直すときは以前のデフォルト値が残るので、直したあとに**変数のデフォルト値**を確認してください。

</details>

<details>
<summary>プレビューのボタンを押しても、会話が送られない</summary>

作品制作画面のプレビューは見た目を確認する場所なので、実際の会話には送られません。制作完了したあと、完了画面の**作品を見る**から会話を始めて確認します。ほかのユーザーに見せる前に試したいときは、**公開設定**を**非公開**にして制作完了します。

</details>
