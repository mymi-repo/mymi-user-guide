# 初めての作品を作る

画像やコンポーネントがなくても、作品は完成させられます。このページでは、例の作品**地下都市ソウル**を見ながら、必要な欄だけを埋めて**制作完了**まで進みます。

:::tip[準備するもの]
- 表紙にする画像1枚（JPG、PNG、WEBP、GIF、HEIC · 最大5MB）
- 世界観と登場人物を書いたメモ。なければ、下の例をそのまま写して書いても構いません。
:::

| 順番 | タブ | 埋めるもの |
| --- | --- | --- |
| 1 | **基本情報** | 作品タイトル、一行紹介、表紙、詳細説明、ジャンル、ハッシュタグ |
| 2 | **プロンプト** | 基本型を選んで作品情報を書く |
| 3 | **導入部** | 導入部のタイトルと最初のメッセージ |
| 4 | **その他の設定** | 必須項目を5つ選ぶ |
| 5 | 画面上部 | **制作完了** |

## 1. 基本情報を埋める

下部メニューの**制作**を押すと、まず**基本情報**タブが開きます。

<ScreenStep src="/img/screens/ja/first-basic-top.webp" alt="基本情報タブに作品タイトルと一行紹介を書き、表紙を1枚追加した画面" caption="基本情報タブの上部">

1. **作品タイトル**を書きます。最大30文字です。
2. **一行紹介**を書きます。作品カードにタイトルと一緒に表示される文章です。最大40文字です。
3. **表紙**の**画像をアップロード**を押して、画像を1枚入れます。表紙は1枚以上必要です。

</ScreenStep>

> 例 — 作品タイトル: `地下都市ソウル` · 一行紹介: `記憶を失って目覚めた場所は、封鎖された地下都市の検疫所だった。`

<ScreenStep src="/img/screens/ja/first-basic-description.webp" device="part" alt="詳細説明の欄にマークダウンで書いた作品紹介" caption="詳細説明">

**詳細説明**には、作品紹介画面に表示される文章を書きます。あらすじ、登場人物、楽しみ方を書けば十分です。通常の文章・マークダウン・HTMLが使え、最大50,000文字です。

右上の**プレビュー**を押すと、ユーザーに表示される見た目を確認できます。

</ScreenStep>

詳細説明の例です。`##`は大見出し、`-`は箇条書き、`**`で囲んだ文字は太字で表示されます。

```md
## 2031年、封鎖された地下都市ソウル

地上が汚染されたあと、人々は地下鉄の駅と地下街をつないで作った都市へ降りてきた。
あなたは記憶をすべて失ったまま、検疫所のベッドで目を覚ます。

### 登場人物
- **カン・ミヌ** — 地下都市の案内人。いつも冗談を言うが、あなたについて何か知っているようだ。
- **イ・ソヨン** — 検疫所の医師。あなたの記憶喪失は事故ではないと疑っている。

### こんなふうに楽しんでください
- ミヌについて検疫所の外に出て、地下都市を見て回りましょう。
- 記憶を取り戻したいなら、ソヨンに手がかりを尋ねてみましょう。
```

<ScreenStep src="/img/screens/ja/first-basic-genres.webp" device="part" alt="ジャンルでSFとミステリー・スリラーを選び、ハッシュタグを3つ入れた画面" caption="ジャンルとハッシュタグ">

**ジャンル**は1〜2個選びます。例では**SF**と**ミステリー・スリラー**です。

**ハッシュタグ**は1個以上入れます。欄に書いて**追加**を押すか、Enterキーを押すと入ります。スペースやカンマで区切って、いくつか一度に入れることもできます。

</ScreenStep>

**クリエイターガイド**と**おすすめモデル**は空のままで構いません。埋め方は[作品紹介を整える](/create/profile)にあります。

## 2. プロンプトを書く

**プロンプト**タブに書いた文章は、AIが返信を作るたびに読む設定です。最初は、欄を埋めるだけでよい**基本型**が楽です。

<ScreenStep src="/img/screens/ja/first-prompt.webp" alt="プロンプトプリセットで基本型を選び、作品情報の欄に世界観と登場人物を書いた画面" caption="プロンプトタブ · 基本型">

1. **プロンプトプリセット**を押して**基本型**を選びます。最初は**自分で書く**が選ばれています。
2. **作品情報**欄に、世界観、登場人物、隠し設定、進行ルールを書きます。欄が空のときに表示される灰色の例と同じ形で書けば大丈夫です。

右側の**合計 N / 10,000**は、このタブに書いた文章の合計です。

</ScreenStep>

作品情報の例です。`####`でテーマを分け、項目は`- **項目**: 値`の形で書きます。ユーザーを指すときは`{{user}}`と書きます。

```md
#### 世界観
- **背景**: 2031年、封鎖された地下都市ソウル。地上は汚染され、見捨てられた。
- **始まり**: {{user}}は記憶を失ったまま検疫所で目を覚ます。

#### 登場人物
**カン・ミヌ**
- **役割**: 地下都市の案内人、32歳
- **性格**: のんびりしていて冗談が多い
- **話し方**: タメ口。語尾を伸ばす
- **関係**: {{user}}の正体を知っているが、知らないふりをする

**イ・ソヨン**
- **役割**: 検疫所の医師、28歳
- **性格**: 事務的で冷静
- **話し方**: 短い敬語
- **関係**: {{user}}の記憶喪失は事故ではないと疑っている

#### 隠し設定
- ミヌは{{user}}を監視するよう命令を受けている。ユーザーに自分から明かさない。
- {{user}}の記憶は管理局が消した。

#### 進行ルール
- 最初の会話でミヌが{{user}}を検疫所の外へ案内する。
- {{user}}が記憶を取り戻そうとすると、ソヨンが手がかりを一つずつ渡す。
```

<ScreenStep src="/img/screens/ja/first-prompt-composed.webp" device="part" alt="組み立てたプロンプトの欄に、作品情報がまとめられて表示されている画面" caption="タブ下部の組み立てたプロンプト">

タブの一番下の**組み立てたプロンプト**には、欄に書いた文章をまとめてAIに渡す形が表示されます。欄を直すと、それに合わせて変わります。

アセットとコンポーネントを追加すると、**画像出力ルール**と**コンポーネント出力ルール**に意味を書く欄ができ、書いた内容もここにまとまります。

</ScreenStep>

:::tip[設定は短くはっきりと]
人物ごとに役割・性格・話し方・関係を1行ずつ分けて書くと、AIが人物を取り違えにくくなります。ユーザーに自分から明かしてはいけないことは**隠し設定**に置き、話をどう導くかは**進行ルール**に書きます。詳しい方法は[プロンプトを書く](/create/prompt)にあります。
:::

## 3. 導入部を書く

導入部は、会話を始めるときにAIが最初に送るメッセージです。

<ScreenStep src="/img/screens/ja/first-greeting.webp" alt="導入部タブにタイトルと最初のメッセージを書いた画面" caption="導入部タブ">

1. **導入部のタイトル**を書きます。ユーザーが開始の場面を選ぶときに見る名前です。
2. 下の欄に最初のメッセージを書きます。最大2,000文字です。行動と描写は`*アスタリスク*`の間に、セリフは`"二重引用符"`の中に書くと、チャットと同じ見た目で表示されます。

</ScreenStep>

```md
*蛍光灯がちらつく検疫所。消毒薬の匂いのなか、誰かがカーテンを開ける。*

"お、やっと目が覚めたか〜。三日間ずっと寝てたぞ？"

*古いミリタリージャケットを羽織った男が、懐中電灯をくるくる回して笑う。彼は自分を案内人のカン・ミヌだと名乗った。*

"ここはソウルだ。正確にはソウルの下だけどな〜。で、{{user}}。名前のほかに覚えてることはあるか？"
```

<ScreenStep src="/img/screens/ja/first-greeting-preview.webp" device="part" alt="導入部のプレビュー。地の文は斜体、セリフは強調色で表示される" caption="導入部のプレビュー">

欄の下の**プレビュー**で、チャットでの見た目を確認します。

導入部の`{{user}}`は、会話するときにユーザーの名前に置き換わります。プレビューではそのまま表示されます。

</ScreenStep>

## 4. その他の設定を選ぶ

**その他の設定**タブで、赤い`*`が付いた項目をすべて選びます。**公開設定**（公開）と**コンテンツのレーティング**（全年齢）は、最初から選ばれています。

<ScreenStep src="/img/screens/ja/first-settings-1.webp" alt="その他の設定タブの上部。公開設定、作品の公開範囲、収益化の制限" caption="その他の設定タブの上部">

- **公開設定**: **公開**はすべてのユーザーが、**非公開**は自分だけが見られます。
- **作品の公開範囲**: **オリジナル**はMYMIでのみ公開する作品です。ほかのプラットフォームにも載せるなら**一般**を選びます。オリジナルを選ぶと「オリジナルに設定すると3か月間解除できません。」という案内が表示されます。
- **収益化の制限**: 他作品のキャラクターや世界観を使った二次創作など、権利が自分のものでない作品なら**収益化を制限**を選びます。

</ScreenStep>

<ScreenStep src="/img/screens/ja/first-settings-2.webp" alt="その他の設定タブの下部。画像の出典、読者層、コンテンツのレーティング、マーケティング利用への同意" caption="その他の設定タブの下部">

- **画像の出典**: MYMIで作った画像なら**MYMIで生成**、ほかのAIで作ったか自分で描いたなら**外部で制作**です。
- **読者層**: 作品が主に向けた読者を**男性向け**・**女性向け**から選びます。
- **コンテンツのレーティング**: **成人向け**は、年齢確認を済ませたユーザーだけが利用できます。会話の内容と生成される画像にも影響します。
- **マーケティング利用への同意**: 同意すると、MYMIがこの作品を広告やSNSの素材に使えます。

</ScreenStep>

一番下の**おすすめペルソナ**は任意です。[公開と編集](/create/publish#おすすめペルソナ)で説明します。

## 5. 制作完了

画面上部の**制作完了**を押します。足りない項目があれば、そのタブに移動して、上部に案内が表示されます。

<ScreenStep src="/img/screens/ja/create-publish-check.webp" alt="作品のタイトルが空のため、‘作品のタイトルを入力してください。’という案内が表示された画面" caption="足りない項目があるとき">

案内は一度に1つずつ表示されます。案内のとおりに埋めてから、もう一度**制作完了**を押します。

確認する順番は、基本情報 → アセット → コンポーネント → プロンプト → 導入部 → ロアブック → その他の設定です。全項目の一覧は[制限とルールの一覧](/create/limits#制作完了のときに確認される項目)にあります。

</ScreenStep>

<ScreenStep src="/img/screens/ja/first-complete.webp" alt="作品の制作完了画面。作品カードの下に審査中の表示と、作品を見る・作品管理のボタンがある" caption="作品の制作完了画面">

すべて埋まっていれば、**作品の制作が完了しました**画面が開きます。

- 公開にした作品は**審査中**です。自分はすぐに会話できますが、ほかのユーザーには審査が終わると公開されます。
- **作品を見る**でその場で会話を試し、直したいところがあれば**作品管理**で**編集**を押します。

</ScreenStep>

## つまずいたときは

<details>
<summary>制作完了を押したら、別のタブに移動する</summary>

足りない項目があるタブに移動したのです。上部に表示された案内を確認して埋めてください。基本情報では表紙・詳細説明・ハッシュタグが、その他の設定では**作品の公開範囲**・**収益化の制限**・**画像の出典**・**読者層**・**マーケティング利用への同意**が抜けやすい項目です。

</details>

<details>
<summary>ハッシュタグを書いたのに「ハッシュタグを1つ以上追加してください。」と表示される</summary>

欄に書いただけでは入りません。**追加**を押すかEnterキーを押して、タグが欄の下に表示されるようにしてください。

</details>

<details>
<summary>「作品情報を入力してください。」と表示される</summary>

基本型の**作品情報**欄が空です。灰色の例は入力した文章ではありません。欄に直接書いてください。

</details>

<details>
<summary>AIが詳細説明に書いた人物設定を知らない</summary>

詳細説明はユーザーに見せる紹介なので、AIには渡されません。AIが知っておくべき設定は、**プロンプト**タブの作品情報に書いてください。

</details>
