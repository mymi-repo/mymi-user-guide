# 制限とルールの一覧

作品制作画面の制限とルールをまとめました。詳しい使い方は、それぞれの項目の案内ページにあります。

## 文字数と個数

| タブ | 項目 | 制限 |
| --- | --- | --- |
| 基本情報 | 作品タイトル | 必須 · 30文字 |
| | 一行紹介 | 必須 · 40文字 |
| | 表紙 | 必須 · 1〜10枚。ファイルはJPG、PNG、WEBP、GIF、HEIC · 5MBまで。切り替え間隔は0.5〜60秒（ボタン1回で0.5秒） |
| | 詳細説明 | 必須 · 50,000文字 |
| | ジャンル | 必須 · 1〜2個 |
| | ハッシュタグ | 必須 · 1個以上、1つにつき30文字。読者層と合わせて30個まで |
| | クリエイターガイド | 任意 · 文章1つにつき5,000文字 |
| | おすすめモデル | 任意 · 5個まで |
| アセット | 画像ファイル | JPG、PNG、WEBP、GIF、HEIC · 5MBまで |
| | コード・フォルダ名 | 英数字で30文字まで |
| | 一度に生成をリクエストできる数 | 50枚まで |
| コンポーネント | JSXコード | 20,000文字。関数名と変数1つ以上が必要 |
| プロンプト | 自分で書く | 必須 · 10,000文字 |
| | 基本型 | 必須 · 作品情報・コードの意味・例外・コンポーネントのルールに書いた文章の合計で10,000文字 |
| 導入部 | 導入部 | 必須 · 1つ以上、タイトルと内容の両方 |
| | タイトル | 100文字 |
| | 内容 | 2,000文字 |
| ロアブック | ロア | 100件まで |
| | 名前 | 50文字 |
| | キーワード | ロア1つにつき5個、1つにつき10文字 |
| | 内容 | 400文字 |
| | 一度に渡される量 | 直近10件のメッセージから探して最大3件 · 1,500文字 |
| その他の設定 | おすすめペルソナ | 任意。作る場合は、名前（20文字）・性別・生年月日（14歳以上）・詳細情報（1,000文字）がすべて必要 |

## 制作完了のときに確認される項目

**制作完了**（公開した作品は**変更を反映**）を押すと、次の順に確認し、最初に引っかかった項目のタブに移動して案内を表示します。

| 順番 | タブ | 確認されること |
| --- | --- | --- |
| 1 | 基本情報 | 作品タイトル、一行紹介、表紙1枚以上、詳細説明、ジャンル1〜2個、ハッシュタグ1個以上 |
| 2 | アセット | すべての画像にコードがあるか、コードが英数字か、同じフォルダに同じコードがないか、空き枠・生成待ちの行がないか、基本ルックが完成しているか |
| 3 | コンポーネント | コード、関数名、変数1つ以上 |
| 4 | プロンプト | 自分で書く: プロンプト。基本型: 作品情報、キャラクター・状況・その他コードの意味、コンポーネントが登場するタイミング、合計10,000文字以下 |
| 5 | 導入部 | 1つ以上あるか、すべてにタイトルと内容があるか |
| 6 | ロアブック | 追加したロアごとのキーワード・内容・名前 |
| 7 | その他の設定 | 作品の公開範囲、収益化の制限、画像の出典、読者層、マーケティング利用への同意、追加したおすすめペルソナの4つの欄 |

公開設定（公開）とコンテンツのレーティング（全年齢）は、最初から選ばれています。

## コードのルール

- 画像のコードとキャラクターフォルダ名には、**英数字だけ**を使えます。スペースや特殊文字は使えません。
- 同じフォルダの中でコードが重複してはいけません。別のフォルダ同士なら、同じコードを使えます（`A/1`、`B/1`）。
- フォルダは1階層だけ作れます。
- パスは、フォルダの中なら`フォルダ/コード`、フォルダの外なら`コード`です。会話や導入部では、`![]({{URL}}/A/1.webp)`、`![]({{URL}}/BG1.webp)`のように書きます。
- 画像を別のキャラクターフォルダに移すことはできません。フォルダの外に出すことはできます。
- 制作完了した作品は、フォルダ名を変更できません。

## `{{user}}`と`{{char}}`

| 使う場所 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 導入部 | 会話するときにユーザーの名前に置き換わります | 会話するときに**作品のタイトル**に置き換わります |
| プロンプト | ユーザーを指す場所として使います | 自動では置き換わりません。人物の名前を直接書きます |
| ロアブック | ユーザーを指す場所として使います | 人物の名前を直接書きます |

## 保存

| 状況 | 保存されるとき |
| --- | --- |
| 制作中の作品 | 変更があるときにタブを移動すると自動保存。表紙・アセットの画像を初めてアップロードまたは生成するとき。**下書き保存**を押すとき。下書きができたあとは、アセットタブの変更がすぐ保存されます |
| 制作完了した作品 | 文章と設定は**変更を反映**を押すとき。アセットの変更はすぐ反映されます |

## 無料と認証

- 作品制作での画像生成・再生成は無料です。生成するには、電話番号認証が必要です。
- 成人向けの作品は、年齢確認を済ませたユーザーだけが利用できます。
- 画像生成のタグのステップにあるセーフティフィルターは、年齢確認を済ませたアカウントだけがオフにできます。

## つまずいたときは

<details>
<summary>制作完了を押したら、別のタブに移動する</summary>

足りない項目があるタブに移動して、その項目を知らせたのです。案内に書かれた欄を埋めて、もう一度**制作完了**を押します。タブごとに何を確認するかは、[制作完了のときに確認される項目](#制作完了のときに確認される項目)にあります。

</details>

<details>
<summary>保存や制作完了がエラーになるが、すべて入力したように見える</summary>

入力するときは止められないのに、保存するときに引っかかる制限を超えた欄があるのかもしれません。次の欄を先に確認してください。

- **基本情報**のハッシュタグ: 1つにつき30文字、読者層と合わせて30個まで
- **基本情報**の表紙の切り替え間隔: 60秒まで
- **導入部**のタイトル: 100文字まで
- **アセット**のコードとフォルダ名: 30文字まで

直してから、もう一度保存します。それでも同じエラーが出るときは、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)へ、どの作品のどの欄を直したかを添えてお知らせください。

</details>
