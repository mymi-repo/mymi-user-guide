# 始める前に

MYMIの作品は、**AIが読む設定**と**ユーザーが見る画面**でできています。作品制作画面の7つのタブが、この2つを分担しています。このページで全体像をつかんでから、[初めての作品を作る](/create/first-work)に進んでください。

## 作品制作画面を開く

ログインしたら、下部メニューの**制作**を押すと**作品制作**画面が開きます。ウェブとアプリで画面の構成は同じです。

<ScreenStep src="/img/screens/ja/create-overview.webp" device="part" alt="作品制作画面の上部。タブの列と、初期化・下書き保存・制作完了ボタンに番号が付いている" caption="作品制作画面の上部">

1. **タブの列**: 基本情報 · アセット · コンポーネント · プロンプト · 導入部 · ロアブック · その他の設定。順番は決まっていないので、書きたいタブから始めて構いません。
2. **↺（制作内容を初期化）**: 入力中の内容を空にして、最初からやり直します。すでに保存した下書きは**作品管理**に残ります。
3. **下書き保存**: ここまで書いた内容を下書きとして保存します。
4. **制作完了**: 足りない項目がないか確認して、作品を完成させます。足りない項目があれば、そのタブに移動して知らせます。

</ScreenStep>

## 7つのタブの役割

| タブ | 何を書くか | 誰が読むか |
| --- | --- | --- |
| **基本情報** | 作品タイトル、一行紹介、表紙、詳細説明、ジャンル、ハッシュタグ | ユーザー（作品紹介画面） |
| **アセット** | 会話に表示する画像と、画像ごとに付けるコード | ユーザー（会話画面） |
| **コンポーネント** | ステータスウィンドウや選択肢など、会話の中に表示されるUI | ユーザー（会話画面） |
| **プロンプト** | 世界観・登場人物・隠し設定・進行ルール、画像とコンポーネントをいつ使うか | AI（返信のたびに） |
| **導入部** | 会話を始めるときにAIが最初に送るメッセージ | ユーザーとAI（会話の最初の場面） |
| **ロアブック** | 会話に特定の言葉が出たときだけAIに伝える設定 | AI（キーワードが出たとき） |
| **その他の設定** | 公開設定、作品の公開範囲、読者層、コンテンツのレーティングなどの運営項目 | MYMI（分類と公開範囲） |

:::info[基本情報に書いた文章はAIに届きません]
詳細説明に登場人物の紹介を細かく書いても、AIはその文章を読みません。AIに知っておいてほしい設定は**プロンプト**タブに書きます。作品紹介画面に見せる文章とAIに渡す文章は別々に用意する、と考えると分かりやすいです。
:::

## いちばん小さい作品に必要なもの

画像・コンポーネント・ロアブックがなくても、作品は完成させられます。必要なのは次のものだけです。

- **基本情報**: 作品タイトル、一行紹介、表紙1枚、詳細説明、ジャンル1〜2個、ハッシュタグ1個以上
- **プロンプト**: 基本型の作品情報、または自分で書いたプロンプト
- **導入部**: タイトルと内容がある導入部1つ
- **その他の設定**: 作品の公開範囲、収益化の制限、画像の出典、読者層、マーケティング利用への同意。公開設定とコンテンツのレーティングは、最初から公開と全年齢が選ばれています。

表紙は、持っている画像をアップロードするか、**アセット**タブで作った画像を持ってきて使います。アセットはあとから追加しても構いません。

## 保存はいつ行われるか

- 下書きに変更があれば、**タブを移動するとき**に自動で保存されます。
- 表紙やアセットの画像を初めてアップロードまたは生成するときは、必要な下書きが先に保存されます。先に**下書き保存**を押さなくても構いません。
- 下書きが一度保存されたあとは、**アセット**タブで画像を追加・削除したり、移動したり、コードを変えたりすると、すぐに保存されます。
- 文字を入力するたびに保存されるわけではありません。1つのタブで長く書いたときは、**下書き保存**を押しておきましょう。
- 同じ作品をPCとスマホのように2か所で開いたまま一緒に直すと、あとで保存した側の内容が残ります。別の端末で続きを直すには、今使っている端末で**下書き保存**（制作完了した作品は**変更を反映**）を押してから、もう一方の端末の**マイページ → 作品管理**で**編集**を押して開きます。
- 制作完了した作品には**下書き保存**がありません。直した内容は**変更を反映**を押して初めて適用されます。詳しくは[公開と編集](/create/publish)をご覧ください。

:::warning[画面を閉じる前に]
自動保存は、タブを移動するときと画像の作業を始めるときに行われます。1つのタブで書いている途中で画面を閉じると、最後に書いた内容が残らないことがあります。
:::

## 旧方式（1.0）で作った作品がある場合

以前の方式で作った作品を**作品管理 → 編集**で開くと、以前の7段階の画面が開きます。現在の方式に自動で切り替わることはありません。先に[旧方式（1.0）について](/create/legacy/overview)をお読みください。

## つまずいたときは

<details>
<summary>画像を作ろうとすると「AI画像の生成には本人認証が必要です。」と表示される</summary>

作品制作の画像生成は無料ですが、電話番号認証を済ませたアカウントだけが使えます。作品制作画面からは認証を始められないので、次の順に進めます。

1. 右上の**下書き保存**（制作完了した作品は**変更を反映**）を押して作業を保存します。
2. **マイページ → 出席チェック**で**今日の報酬を受け取る**を押し、電話番号認証を済ませます。
3. **マイページ → 作品管理**から作品を開き直し、画像を生成します。

持っている画像をアップロードするだけなら、認証は要りません。認証の方法は[年齢確認・電話番号認証](/account/adult-verification)にあります。

</details>

<details>
<summary>初期化を押したら、作っていた作品が消えた</summary>

初期化は作品制作画面を空にするだけです。保存した下書きは**マイページ → 作品管理**に**制作中**として残っています。**編集**を押してもう一度開いてください。

</details>

<details>
<summary>タブを順番にすべて埋めないといけないか</summary>

いいえ。タブはどれから書いても構いません。必須項目は、**制作完了**を押したときにまとめて確認されます。

</details>
