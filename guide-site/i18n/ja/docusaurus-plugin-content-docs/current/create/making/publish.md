# 公開と編集

**制作完了**を押すと作品が作られ、公開にした作品は審査を経てほかのユーザーに公開されます。作った作品は、**マイページ → 作品管理**からいつでも直せます。

## 制作完了から公開まで

| 段階 | 何が起こるか |
| --- | --- |
| 制作完了 | 必須項目を確認して、作品を保存します。足りない項目があれば、そのタブに移動して知らせます。 |
| 審査 | セーフティ規定と作品の品質を確認します。終わったら通知します。 |
| 公開 | ほかのユーザーが作品を見つけて、会話できます。 |

審査中でも、作った本人はすぐに会話できます。審査にかかる時間は作品によって違うことがあります。**成人向け**の作品は、年齢確認を済ませたユーザーにだけ表示されます。

完了画面は、作品の状態によって案内が変わります。

<ScreenStep src="/img/screens/ja/complete-private.webp" alt="非公開の作品の制作完了画面。非公開の表示と、公開するにはの案内" caption="非公開で作った作品">

- **公開**で作った新しい作品: **審査中**と表示され、審査が終わるとほかのユーザーに公開されます。（[初めての作品を作る](/create/first-work#5-制作完了)の完了画面）
- **非公開**で作った作品: 自分だけが見られます。公開するには、作品管理で公開設定を変えます。そこから審査が始まります。

</ScreenStep>

<ScreenStep src="/img/screens/ja/complete-approved.webp" alt="すでに公開されている作品を直したあとの完了画面。承認済みの表示と、修正した内容が反映されたという案内" caption="すでに公開中の作品を直したとき">

- すでに**承認済み**の作品を直したときは、直した内容がすぐにほかのユーザーにも表示されます。直すたびに審査をやり直すことはありません。
- ただし、**コンテンツのレーティング**を成人向けから全年齢に変えると、もう一度審査を受けます。

</ScreenStep>

## 作品管理

<ScreenStep src="/img/screens/ja/manage-list.webp" alt="作品管理の画面。作品4つがカードで表示され、編集ボタン、⋮メニュー、審査中の表示に番号が付いている" caption="マイページ → 作品管理">

**マイページ → 作品管理**に、自分が作った作品が集まっています。

1. **編集**: 作品を作品制作画面で開きます。
2. **⋮**: メニューを開きます。**削除**と、却下された作品なら**再審査リクエスト**があります。
3. 公開した作品には、**審査中**・**承認済み**・**却下**が表示されます。

まだ制作完了していない下書きは、**制作中**と表示されます。**プロフィール**を押すと、作品紹介画面が開きます。

</ScreenStep>

上部の検索欄と**フィルター**（並び替え・公開状態・承認状態）で、作品を探せます。**ダッシュボード**では、メッセージ数や獲得リーフのような作品の成果を確認します。

## 公開した作品を直す

<ScreenStep src="/img/screens/ja/released-header.webp" alt="制作完了した作品を開いた制作画面。ヘッダーに下書き保存の代わりに変更を反映ボタンがあり、アセットタブにフォルダ名を変更できないという案内がある" caption="制作完了した作品の制作画面">

1. **作品管理**で**編集**を押します。
2. 直したいところを直します。
3. 画面上部の**変更を反映**を押します。

制作完了した作品には、**下書き保存**がありません。直している途中の状態が公開されないように、文章と設定は**変更を反映**を押して初めて適用されます。

</ScreenStep>

:::warning[アセットはすぐ反映されます]
アセットタブでの画像の追加・差し替え・削除とコードの変更は、**変更を反映**を待たずに、すぐ作品に反映されます。

- コードを変えたり画像を削除したりすると、その画像を使っていた既存の会話でも画像が表示されなくなります。画像を差し替えるときは、コードはそのままにして画像だけを入れ替えてください。
- 制作完了した作品は、フォルダ名（キャラクターコード）を変更できません。
- 画像を別のキャラクターフォルダに移すことはできません。フォルダの外に出すことはできます。
:::

:::tip[画面を閉じる前に変更を反映]
公開した作品は、タブを移動しても自動では保存されません。直したあとは、画面を閉じる前に**変更を反映**を押してください。
:::

## 却下された作品の再審査リクエスト

<ScreenStep src="/img/screens/ja/manage-menu.webp" device="part" alt="却下の表示がある作品カード2枚。上のカードは⋮ボタンに1番、下のカードは⋮を押して開いたメニューの再審査リクエストに2番が付いている" caption="⋮ → 再審査リクエスト">

審査で却下されると、作品カードに**却下**と表示されます。

1. その作品の<strong>⋮</strong>ボタンを押します。メニューが開くと、却下の表示はメニューに隠れます。
2. **再審査リクエスト**を押します。
3. **却下理由**を確認します。

</ScreenStep>

<ScreenStep src="/img/screens/ja/manage-appeal.webp" alt="却下理由の窓。却下理由の下に審査チームへのメッセージ欄と提出するボタン" caption="却下理由と再審査リクエスト（ウェブ）">

4. 理由に合わせて作品を直し、**変更を反映**を押します。直し方は[公開した作品を直す](#公開した作品を直す)と同じです。
5. もう一度<strong>⋮ → 再審査リクエスト</strong>を押します。
6. 必要なら、メッセージ欄に直した内容を書いてリクエストを送ります。ウェブでは、却下理由のウィンドウで**再審査リクエスト**を押してから**提出する**を、アプリではウィンドウの下にある**再審査リクエスト**を押します。再審査は、管理者が確認したうえで処理します。

</ScreenStep>

## 非公開で作った作品を公開する

1. **作品管理**で**編集**を押します。
2. **その他の設定 → 公開設定**で**公開**を選びます。
3. **変更を反映**を押すと、審査が始まります。

## 作品を削除する

**作品管理**で作品の<strong>⋮ → 削除</strong>を押し、確認ウィンドウでもう一度**削除**を押すと、削除されます。削除した作品は、作品管理と作品一覧から消えます。

:::danger[削除すると元に戻せません]
削除した作品を復活させるメニューはありません。しばらく下げておきたいだけなら、**編集**で開いて**その他の設定 → 公開設定**を**非公開**に変え、**変更を反映**を押してください。
:::

:::info
作品制作画面の<strong>↺</strong>（制作内容を初期化）は、入力中の画面を空にするだけです。保存した下書きは作品管理に残ります。
:::

## おすすめペルソナ

<ScreenStep src="/img/screens/ja/settings-persona.webp" device="part" alt="その他の設定のおすすめペルソナ。名前ハン・ジウ、性別、生年月日、詳細情報が入力されている" caption="その他の設定 → おすすめペルソナ">

**おすすめペルソナ**は、ユーザーが会話を始めるときに選べるペルソナを、あらかじめ作っておく機能です。作品世界に合う主人公を提案するときに使います。作らなくても構いません。

作った場合は、4つの欄をすべて埋めないと制作完了できません。

- **名前**: 20文字まで
- **性別**: 女性・男性
- **生年月日**: 14歳以上である必要があります
- **詳細情報**: AIがこのペルソナで会話するユーザーにどう接するか分かるように、性格・背景・話し方を書きます。1,000文字まで

</ScreenStep>

## つまずいたときは

<details>
<summary>変更を反映を押したのに、ほかの人の画面にすぐ表示されない</summary>

まだ審査中の作品なら、審査が終わったあとに公開されます。すでに承認済みの作品なら、変更を反映した時点ですぐ適用されます。作品の画面を更新してみてください。

</details>

<details>
<summary>公開した作品から下書き保存のボタンがなくなった</summary>

制作完了した作品は、**変更を反映**1つで保存します。直した内容が中途半端に公開されないようにするためです。

</details>

<details>
<summary>作品管理に同じ作品が2つある</summary>

作品制作画面を初期化してから作り直した場合、先に作った下書きが**制作中**として残っています。**編集**で開いて確認し、不要な下書きは<strong>⋮ → 削除</strong>で削除します。

</details>
