# ロアブックを書く

ロアブックは、**会話にキーワードが出ると、そのロアの内容がAIに渡される設定集**です。いつも知っている必要はないけれど、名前が出たときには知っておくべきこと ― たとえば世界観の用語・場所・組織・人物の秘密 ― を書きます。

:::info
エキスパートモードの案内です。かんたんモードは、[ロアブック・コンポーネント・オプション](/create/simple/extras#ロアブック)をご覧ください。ロアを探す仕組みは、2つのモードで同じです。
:::

## プロンプトとの違い

| | プロンプト | ロアブック |
| --- | --- | --- |
| いつ渡されるか | AIが返信するたびに、常に | 会話にキーワードが出たときだけ |
| 何を書くか | 世界観の骨組み、主な人物、進行ルール | ときどき出てくる場所・組織・物・過去の出来事 |
| どれくらい書けるか | 10,000文字まで | ロア1つにつき400文字、100件まで |

主人公のように毎回必要な設定はプロンプトに、名前が出たときだけ必要な設定はロアブックに置くと、プロンプトを短く保てます。

## ロアを作る

<ScreenStep src="/img/screens/ja/lorebook.webp" alt="ロアブックタブ。管理局と7番出口の2つのロアが閉じた状態で表示されている" caption="ロアブックタブ">

1. **ロアを追加**を押します。
2. **名前**、**キーワード**、**内容**を埋めます。
3. **閉じる**を押すと、一覧には名前とキーワードだけが表示されます。もう一度開くには、そのロアのカードを押します。

</ScreenStep>

<ScreenStep src="/img/screens/ja/lorebook-editor.webp" device="part" alt="管理局のロアを開いた画面。名前は管理局、キーワードは管理局・局長、内容欄とロアを削除・閉じるボタン" caption="ロアの編集">

- **名前**: ロアの名前です。50文字まで。内容と一緒にAIに渡されます。
- **キーワード**: 会話にこの言葉が出ると、内容が渡されます。5個まで、1つにつき10文字までです。10文字を超えて書くと、最初の10文字だけが入ります。書いてからEnterキーかカンマを押すか、**追加**を押して入れます。大文字と小文字は区別しません。
- **内容**: キーワードが出たときにAIが知っておくべきことだけを書きます。400文字までです。

</ScreenStep>

例の作品のロアです。

| 名前 | キーワード | 内容 |
| --- | --- | --- |
| 管理局 | 管理局、局長 | 地下都市を治める機関。検疫所と出入口を管理し、地上から降りてきた人の記録を消すという噂がある。ミヌは管理局の命令を受けて動いている。 |
| 7番出口 | 7番出口、七番出口 | 地上へ続く唯一の出口。2031年の封鎖以降は閉ざされており、管理局の許可証がなければ近づけない。 |

## どのように探して渡すか

- ユーザーが送ったメッセージと、**直近10件のメッセージ**からキーワードを探します。AIが返信で最初に使ったキーワードも、次のターンから探す範囲に入ります。
- キーワードが**ほかの言葉の中に含まれていても**見つけます。たとえばキーワード`管理局`は、「管理局長が来た」の中でも見つかります。
- **表記の違いは区別します。** キーワード`7番出口`は、「七番出口」や、全角の「７番出口」では見つかりません。
- 複数のロアが当てはまったときは、**いちばん最近出たもの**から選びます。
- 一度に**最大3件、合わせて1,500文字**まで渡されます。ロアを100件作っても、毎回すべてが渡されるわけではありません。

## キーワードを選ぶコツ

- **会話に実際に出てくる言葉を書きます。** 正式名称に含まれない略称や通称も一緒に入れます。例: `管理局`と`局長`
- **重なる長いキーワードは入れなくても構いません。** `管理局`を入れたなら「管理局長」はすでに見つかるので、その枠にはほかの言葉を入れます。
- **表記のゆれがある名前は、両方入れます。** 例: `7番出口`と`七番出口`
- **ありふれた言葉は避けます。** 1文字やよく使う言葉はほとんどの会話に当てはまってしまい、本当に必要なロアが3件に入れなくなることがあります。たとえば地下都市の話では、`地上`や`出口`はほぼ毎回出てきます。
- **内容は短く、事実だけを書きます。** 400文字の中に、「この名前が出たときにAIが知っておくべきこと」だけを書きます。話し方や進行ルールはプロンプトに置きます。
- **人物の名前は直接書きます。** ロアの内容にも`{{char}}`の代わりに、「カン・ミヌ」のように名前を書きます。

## つまずいたときは

<details>
<summary>「キーワードのないロアがあります。」と表示される</summary>

キーワードを書いて、Enterキーかカンマ、または**追加**を押して入れたか確認します。欄の下にキーワードが表示されていれば、入っています。作りかけのロアは**ロアを削除**で削除します。

</details>

<details>
<summary>キーワードをこれ以上入れられない</summary>

キーワードは、ロア1つにつき5個、1つにつき10文字までです。もっと必要なら、同じ内容を別のキーワードに分けて、ロアをもう1つ作ります。

</details>

<details>
<summary>キーワードを言ったのに、AIがロアの内容を知らないようだ</summary>

キーワードが会話で使った言葉と少し違うか、別のロアが先に選ばれたのかもしれません。一度に渡されるロアは3件までです。次の順に確認します。

1. 会話で使った言葉が、キーワードと表記まで同じか確認します。別の書き方もできる言葉なら、その書き方もキーワードに入れます。
2. 別のロアにありふれたキーワードがあれば、減らします。
3. 必ず知っておくべき設定なら、プロンプトに移します。

ロアが渡されたあとでも、AIの返信は毎回変わることがあります。

</details>
