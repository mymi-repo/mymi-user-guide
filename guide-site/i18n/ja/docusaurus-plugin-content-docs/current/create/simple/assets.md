# アセットとAI画像

会話に表示する画像は、**アセット**ステップで用意します。持っている画像をアップロードするか、MYMIで無料で作れます。画像ごとに**状況説明**を書くと、AIがその説明を見て、どの場面でどの画像を見せるかを選びます。

:::info[画像生成は無料ですが、本人認証が必要です]
作品制作の画像生成と再生成は無料です。生成するには、[電話番号認証](/account/adult-verification)を済ませたアカウントである必要があります。画像のアップロードは、認証なしでもできます。
:::

## アセットステップの見た目

<ScreenStep src="/img/screens/ja/simple-assets-overview.webp" alt="アセットステップ。上に案内文とAI画像ボタン、下にアセット追加の欄と画像カードが2列で並んでいる。カードごとに星、削除ボタン、画像の名前、人物の名前、状況説明がある" caption="アセットステップ">

1. **AI画像**: MYMIで画像を作るウィンドウを開きます。
2. **アセット追加**: 画像をアップロードするか、AIで作った画像を持ってきます。
3. 画像カード: 左上の<strong>★</strong>は代表画像、右上の<strong>×</strong>は削除です。下に、画像の名前（`img:AB3K9X`）と、結び付けた人物の名前、状況説明が表示されます。

</ScreenStep>

- 画像は200枚まで入れられます。
- 画像の名前（`img:AB3K9X`）は、MYMIが英大文字と数字の6文字で決めます。変更はできません。
- 状況説明が空のカードは、説明の欄が赤い枠で表示されます。

## 持っている画像をアップロードする

1. **アセット追加**を押します。
2. **ファイルアップロード**を押して、画像を選びます。JPG、PNG、WEBP、GIF、HEICのファイルを5MBまで使えます。
3. アップロードされたカードを押して、状況説明を書きます。

画像は一度に1枚ずつアップロードされます。アップロード中はカードに回転する表示が出て、終わると画像が表示されます。最初にアップロードした画像は、自動で作品の代表画像になります。

## 状況説明を書く

状況説明は、**AIが画像を選ぶ基準**です。ユーザーには表示されません。

<ScreenStep src="/img/screens/ja/simple-asset-sheet.webp" alt="状況説明を入力のウィンドウ。画像のプレビューの横にキャラクター選択の一覧があり、下に解放が必要のスイッチと説明の欄、保存ボタンがある" caption="状況説明の入力">

1. 画像を押して、**状況説明を入力**のウィンドウを開きます。
2. **キャラクター選択**で、画像に写っている人物を選びます。基本情報ステップに書いたキャラクターが一覧に出ます。人物のいない背景や、全員に使う画像は**共用**です。
3. 説明の欄に、どんな場面かを60文字まで書きます。
4. **保存**を押します。押して初めて、説明と人物の結び付けが保存されます。

</ScreenStep>

説明の欄には、人物の名前を入れるようにという案内があります。名前がないと、AIが画像を正しく表示できません。例の画像は、次のように書きました。

| 画像 | キャラクター | 状況説明 |
| --- | --- | --- |
| ミヌ 笑い | カン・ミヌ | `カン・ミヌが明るく笑っている。` |
| ミヌ 悲しみ | カン・ミヌ | `カン・ミヌが悲しい表情でうつむく。` |
| ミヌ 怒り | カン・ミヌ | `カン・ミヌが腹を立てて眉間にしわを寄せる。` |
| ソヨン 笑い | イ・ソヨン | `イ・ソヨンが淡く微笑む。` |
| ソヨン 悲しみ | イ・ソヨン | `イ・ソヨンが悲しい表情で視線を落とす。` |
| 廊下 | 共用 | `青い照明がともる検疫所の廊下。` |

:::tip[同じ人物の画像は、違う書き方で説明します]
ミヌの画像が何枚もあるなら、「笑っている」「うつむく」のように、表情や動きが分かるように書きます。説明が似ていると、AIはどの画像を選べばよいか迷います。逆に、説明がなかったり短すぎたりすると、その画像を選ぶ理由がありません。
:::

画像の名前（`img:AB3K9X`）は状況説明と一緒にAIに渡され、AIが返信にその名前を入れると、その位置に画像が表示されます。

## 会話での画像の出方

**内部画像**（最初の値）では、AIは返信を書くとき、**話す人物ごとに**、その人物に結び付けた画像の中から、今の場面にいちばん近いものを選びます。選ぶ基準が状況説明です。他の人物の画像を借りて使うことはありません。

- **チャット**と**1:1**の表示では、返信の各部分がその人物の画像で始まります。
- **小説**の表示では、場面に登場する人物の画像を、文章の間に自然に差し込みます。

（チャットルームの表示は、チャットルームの右上のパレットアイコンの**UI設定 → UIモード**で変えます。（[会話する](/chatting/chat-with-character)））

そのため、次のように用意するとよいです。

- **人物ごとに画像を1枚以上結び付けます。** 画像を結び付けていない人物は、話すときに見せる画像がありません。
- **同じ人物の画像は、表情や動きが違うものを何枚か用意します。** 場面に合うものをAIが選びます。
- **背景のように特定の人物に属さない画像は、共用にしておきます。**

## 代表画像を決める

代表画像は、作品を代表する1枚です。画像カードの左上の<strong>★</strong>を押すと、その画像が代表になります。今の代表画像は、★が黄色く点灯しています。代表画像は必ず必要です。

- 最初にアップロードまたは持ってきた画像は、自動で代表になります。
- 代表画像を消すと、残りの画像のうち、最初に追加したものが代表になります。
- エキスパートモードのように、表紙を複数入れる機能はありません。

## AIで画像を作る

<ScreenStep src="/img/screens/ja/simple-ai-panel.webp" alt="AI画像生成のウィンドウ。新しいベース画像を作成する欄と、背景・人物ごとのベース画像のカードが並び、人物のカードごとにシチュエーション画像を作成するボタンがある" caption="AI画像生成のウィンドウ">

アセットステップの右上の**AI画像**を押すと、**AI画像生成**のウィンドウが開きます。AIで**ベース画像**を作り、その上に**シチュエーション画像**を続けて作れます。

- **ベース画像**: 1人の人物（または1つの背景）の土台になる画像です。
- **シチュエーション画像**: ベース画像の画風と印象はそのままに、表情、動作、背景、衣装、小道具、構図だけを変えた画像です。

</ScreenStep>

### ベース画像を作る

1. ウィンドウで**新しいベース画像を作成**を押します。
2. 最初の画面で、**画像タイプを選択**の**人物**か**背景**を選びます。背景は、人物のいない、場所が中心の画像です。
3. 人物を選んだなら、**所属キャラクター選択**と**性別選択**が続きます。所属キャラクターは、基本情報ステップに書いたキャラクターから選びます。選ばないと、共用の画像として保存されます。性別は**女性**か**男性**を選びます。**次へ**を押します。
4. **画風選択**で、画風を選びます。**おすすめ画風**はMYMIが用意した画風なので、最初はここから選びます。保存しておいた**マイ画風**や**直接作成**もあります。
5. **背景 → 身体 - 髪 → 身体 - 目 → 身体 - 顔の特徴 → 身体 - 肌 → 身体 - 体型 → 衣装 → 小道具 → その他**の順にタグを選びます。要らないステップは**次へ**で飛ばします。背景の画像なら、背景のタグだけを選べば大丈夫です。
6. **確認して生成**で、選んだタグを確認して**画像を生成**を押します。

最後のステップで**エキスパートモード**を開くと、入れない要素と生成の設定を変えられます。この**エキスパートモード**は、作品を作る制作モードとは別のものです。よく分からなければ、そのままにしておきます。

作っている間、カードに**リクエスト中...**、**待機中...**、<strong>生成中...</strong>が順に表示されます。ベース画像は同時に2枚まで、シチュエーション画像は一度に1枚ずつ作れます。いっぱいのときは、**ベース生成が待機中**、**シチュエーション生成が待機中**に変わります。失敗するとカードに**生成失敗**と表示されます。しばらくしてからやり直すか、**失敗した画像カードを削除**で片付けます。

### シチュエーション画像を作る

1. ベース画像のカードを押します。そのベースから作ったシチュエーション画像の一覧が開きます。
2. **新しいシチュエーション画像を作成**を押します。
3. **どんな表情をしますか？**、**どんなポーズを取りますか？**のようなステップで、**表情**、**動作**と、変えたい**背景**、**衣装**、**小道具**、**構図**を選びます。選ばなかったものは、ベースと同じです。（**ベースと同じ**）
4. **画像を生成**を押します。

画像カードで、**プロンプト修正後に再生成**でもう一度作ったり、**AI画像を削除**で消したりできます。ベース画像を消すと、その下のシチュエーション画像も一緒に消えます。

### 作った画像をアセットに持ってくる

AIで作った画像は、すぐにはアセットになりません。持ってくる必要があります。

<ScreenStep src="/img/screens/ja/simple-ai-picker.webp" alt="AI画像から選択のウィンドウ。ベース画像とシチュエーション画像がグリッドで表示され、下に選択完了のボタンがある" caption="AI画像から選択">

1. アセットステップで**アセット追加**を押し、**AI画像から選択**を押します。
2. ベース画像を押すと、そのシチュエーション画像の一覧が表示されます。
3. アセットとして持ってくる画像を選びます。何枚かを一度に選べます。
4. 下の、選んだ枚数が表示されたボタン（たとえば**3枚を選択完了**）を押します。

</ScreenStep>

持ってきた画像には、AI画像を作るときに選んだ所属キャラクターが引き継がれます。状況説明が空なら、カードを押して書きます。アセットは200枚までなので、残りの枠より多くは選べません。

## 解放が必要: ロックしておいて、会話で解除する

特別な場面の画像を取っておきたいときに使います。

1. 画像を押して、**状況説明を入力**のウィンドウを開きます。
2. **解放が必要**のスイッチをオンにします。
3. **保存**を押します。保存して初めてロックされます。

ロックした画像はユーザーに隠されていて、会話にその画像が出たときに、そのユーザーにだけ解除されます。ロックされた画像カードには、鍵のマークが表示されます。

## 導入部に画像を入れる

導入部は自分で先に書いておく最初のメッセージなので、画像を入れる位置も自分で決めます。

<ScreenStep src="/img/screens/ja/simple-intro-insert.webp" alt="導入部ステップのアセット画像の挿入ウィンドウ。アセット画像がグリッドで表示されている" caption="アセット画像の挿入">

1. 導入部の最初のメッセージの欄で、画像を入れる位置を押してカーソルを置きます。
2. 上の**画像**ボタンを押します。アセットが1つもないと、このボタンは表示されません。
3. **アセット画像の挿入**のウィンドウで入れる画像を押すと、カーソルの位置に`img:[AB3K9X]`のような行が入ります。

</ScreenStep>

**プレビュー**で、画像が正しい位置に表示されるか確認します。画像の行の名前に合うアセットがないと、「画像が見つかりません」と表示されます。名前を自分で入力せず、その行を消してから**画像**ボタンで入れ直せば、間違えません。

```md
*蛍光灯がちらつく検疫所。消毒薬の匂いのなか、誰かがカーテンを開ける。*

img:[AB3K9X]
"お、やっと目が覚めたか〜。三日間ずっと寝てたぞ？"
```

## 画像出力指示

**その他の設定**ステップの**画像出力指示**のカードが、AIが画像をどのように出すかを決めます。使うのは一方だけです。

| 方式 | 意味 | AIが画像を選ぶ基準 |
| --- | --- | --- |
| **内部画像** | アセットにアップロードした画像を`img:[名前]`で出します。最初から選ばれています | アセットごとに書いた状況説明と、結び付けた人物 |
| **外部画像** | 設定に書いておいた画像のアドレス（URL）を`![](アドレス)`で出します | 世界観・キャラクターの説明などの設定に書いたアドレスやアドレスの規則。アドレスが分からなければ、画像を入れません。状況説明はAIに渡されません |

アセットステップでアップロードした画像を使う作品なら、**内部画像**のままにしておきます。

## つまずいたときは

<details>
<summary>画像を作ろうとすると「AI画像の生成には本人認証が必要です。」と表示される</summary>

作品制作の画像生成は無料ですが、電話番号認証を済ませたアカウントだけが使えます。作品制作画面からは認証を始められないので、次の順に進めます。

1. 書いた内容を次へボタンで保存します。
2. **マイページ → 出席チェック**で**今日の報酬を受け取る**を押し、電話番号認証を済ませます。
3. **マイページ → 作品管理**から作品を開き直し、画像を作ります。

持っている画像をアップロードするだけなら、認証は要りません。認証の方法は[年齢確認・電話番号認証](/account/adult-verification)にあります。

</details>

<details>
<summary>AIで作った画像がアセットにない</summary>

作った画像は、自動ではアセットに入りません。アセットステップの**アセット追加 → AI画像から選択**で選んで、持ってきてください。

</details>

<details>
<summary>「アセットの説明を入力してください。」と表示される</summary>

状況説明が空の画像があります。説明の欄が赤い枠になっているカードを押して書き、**保存**を押します。

</details>

<details>
<summary>会話で、AIがほとんど画像を見せてくれない</summary>

**その他の設定**の**画像出力指示**が**内部画像**になっているか確認します。**外部画像**だと状況説明がAIに渡されず、設定に画像のアドレスがなければ、画像を入れません。

内部画像なのに少ししか出ないときは、次を確認します。

1. 話す人物に画像が**結び付けられている**か見ます。AIは、その人物に結び付けた画像だけを選びます。
2. 同じ人物の画像が1枚だけだと、いつも同じ画像が出ます。表情の違う画像を足して、状況説明をはっきり書きます。
3. チャットルームのUIモードによって、画像の出方が変わります。（[会話する](/chatting/chat-with-character)）

AIの返信は毎回変わるので、ときどき合う画像を選べないことがあります。

</details>

<details>
<summary>iPhoneアプリで「ギャラリーへのアクセス権限が必要です。」と表示される</summary>

画像をアップロードするには、MYMIが写真にアクセスできる必要があります。iPhoneの**設定 → MYMI**で写真へのアクセスを許可してから、もう一度**ファイルアップロード**を押します。

</details>

<details>
<summary>アップロードに失敗したと表示される</summary>

ファイル形式（JPG、PNG、WEBP、GIF、HEIC）とサイズ（5MB）を確認します。それでもだめなら、しばらくしてからもう一度アップロードしてみてください。

</details>

<details>
<summary>導入部のプレビューに「画像が見つかりません」と表示される</summary>

`img:[…]`のかっこの中の名前と同じ画像が、アセットにありません。アセットステップでその画像を消していないか、かっこの中の名前が画像カードに付いている名前と同じかを確認します。名前を自分で入力せず、その行を消してから**画像**ボタンで入れ直せば、間違えません。

</details>
