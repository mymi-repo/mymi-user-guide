# エキスパートモードに移す

かんたんモードで作った作品を、エキスパートモードに変える機能はありません。2つのモードの内容が、自動で移ることもありません。エキスパートモードでプロンプトを自分で書いてみたいなら、**新しい作品**を作って、設定を書き写します。

## 移す前に知っておくこと

- 新しい作品は**別の作品**です。元の作品の会話、いいね、コメントは、新しい作品には移りません。
- 新しい作品を作っても、**元の作品はそのまま**残ります。これ以上見せたくないなら、**マイページ → 作品管理 → 編集**で開いて、**その他の設定 → 公開設定**を**非公開**に変え、次へボタンを押して保存します。
- 移している間は、元の作品の文章が必要です。世界観、キャラクターの説明、秘密、状況説明をメモ帳などにコピーしておくか、別の端末で元の作品を開いて見ながら移すと楽です。

## 移す順番

1. 元の作品の文章をコピーしておきます。
2. 下部メニューの**制作**を押します。作品管理から開いた作品が編集画面に開いているなら、<strong>↺</strong>を押して編集画面を空にします。作品管理の元の作品はそのまま残ります。
3. **基本情報**タブのいちばん上の**制作モード**で、**エキスパートモード**を押します。初めてなら、ウィンドウで**エキスパートモードに切り替え**を押します。
4. 下の表を見ながら書き写します。
5. **制作完了**を押します。

## 項目ごとにどこへ移すか

| かんたんモードで書いていた場所 | エキスパートモードで書く場所 | 移すときにすること |
| --- | --- | --- |
| 基本情報 → 作品タイトル · 一行紹介 | 基本情報 → 作品タイトル · 一行紹介 | そのまま移します |
| 基本情報 → 世界観 | プロンプト → 作品情報（基本型）または本文（自分で書く） | 時代・場所・ルールを書き写します |
| 基本情報 → キャラクター | プロンプト → 作品情報の登場人物 | 名前の行の下に、役割・性格・話し方・関係を書きます |
| 基本情報 → 秘密 | プロンプト → 作品情報の隠し設定 | 明かす条件も一緒に書きます。詳細説明には移しません |
| アセット → 人物の結び付け | アセットのキャラクターフォルダ + プロンプトのキャラクターコードの意味 | 人物ごとにフォルダを作り、フォルダのコードと名前を合わせます |
| アセット → 状況説明 | アセットの画像コード + プロンプトの状況コード・その他コードの意味 | 同じ場面は、すべての人物で同じコードに揃えます |
| アセット → 代表画像（★） | 基本情報 → 表紙 | 表紙は1〜10枚です。アセットから持ってこられます |
| 導入部の`img:[名前]` | 導入部の`![]({{URL}}/A/1.webp)` | **アセット画像を挿入**で入れ直します |
| その他の設定 → ジャンル · ハッシュタグ | 基本情報 → ジャンル · ハッシュタグ | エキスパートモードでは基本情報タブにあります |
| その他の設定 → 残りのカード | その他の設定 | カードと選択肢は同じです。選び直します |
| コンポーネント → 用途の説明 | プロンプト → コンポーネント出力ルール（基本型）または本文（自分で書く） | いつ、どんな値で呼び出すかを書き写します |
| オプション → 詳細説明（HTML） | 基本情報 → 詳細説明 | 詳細説明は必須です。HTMLも使えます |
| オプション → 制作者からのひとこと | 基本情報 → クリエイターガイド | そのまま移します |
| オプション → おすすめペルソナ | その他の設定 → おすすめペルソナ | そのまま移します |
| ロアブック | ロアブック | 名前・キーワード・内容をそのまま移します |

## 見落としやすいもの

世界観と人物の説明だけを移して終わりにしないでください。次のものも一緒に確認する必要があります。

1. **画像の状況説明** → アセットのコードと、プロンプトのコードの意味。かんたんモードでは、MYMIが状況説明をまとめてAIに渡していましたが、エキスパートモードでは、画像をいつ入れるかをプロンプトに自分で書く必要があります。
2. **コンポーネントの用途説明** → プロンプトのコンポーネント出力ルール。
3. **導入部の`img:[名前]`** → 新しいアセットのコードで入れた画像の行。エキスパートモードは`img:[…]`を読みません。
4. **詳細説明（HTML）と制作者からのひとこと** → 詳細説明、クリエイターガイド。
5. **以前に入れた会話例** → プロンプト。今のかんたんモード画面には表示されませんが、以前に会話例を入れた作品では、それがAIに渡されています。新しい作品には移らないので、必要な話し方や例をプロンプトに自分で書きます。

### 例: 画像1枚を移す

かんたんモードで、人物**カン・ミヌ**に結び付け、状況説明を「カン・ミヌが明るく笑っている。」と書いた画像（`img:[AB3K9X]`）があるなら、エキスパートモードでは次のように移します。

1. **プロンプト**の作品情報に、ミヌの役割・性格・話し方を書きます。
2. **アセット**にキャラクターフォルダ`A`を作り、その画像をコード`1`で入れます。
3. 基本型なら、**画像出力ルール**に、キャラクターコード`A` = `カン・ミヌ`、状況コード`1` = `笑い`を書きます。
4. 自分で書くなら、画像の意味と一緒に、いつ、どんな形式で入れるかも本文に書きます。
5. 導入部で使っていた`img:[AB3K9X]`は消して、**アセット画像を挿入**で`A/1`を入れます。

エキスパートモードの画像の仕組みは、[画像を用意する](/create/images)と[会話に画像を表示する](/create/images-in-chat)に詳しくあります。

## つまずいたときは

<details>
<summary>かんたんモードの作品を開いたら、エキスパートモードのボタンを押せない</summary>

作品管理から開いた作品は、作ったモードにロックされます。<strong>↺</strong>を押して編集画面を空にすると、ロックが外れて、モードを選び直せます。作品管理の元の作品は消えません。（[始める前に](/create/before-you-start#作品管理から開いた作品はモードが固定されます)）

</details>

<details>
<summary>かんたんモードの導入部をエキスパートモードに貼り付けたら、画像が表示されない</summary>

エキスパートモードは`img:[…]`を読みません。導入部のプレビューにも、その位置に「画像を読み込めません」と表示されます。その行を消して、最初のメッセージの欄の**アセット画像を挿入**で入れ直します。

</details>

<details>
<summary>移した作品の会話に画像が表示されない</summary>

かんたんモードでは、MYMIが状況説明をまとめてAIに渡していましたが、エキスパートモードでは、画像をいつ入れるかをプロンプトに書く必要があります。基本型なら**画像出力ルール**のコードの意味を埋め、自分で書くなら画像のルールを本文に書きます。方法は[会話に画像を表示する](/create/images-in-chat)にあります。

</details>

<details>
<summary>かんたんモードで書いていた内容が、エキスパートモードの画面にない</summary>

2つのモードは下書きが別々です。かんたんモードの内容は、エキスパートモードには移りません。上の表を見ながら、自分で書き写してください。

</details>
