# かんたんモードで初めての作品を作る

ロアブック、コンポーネント、オプションがなくても、作品は完成させられます。このページでは、例の作品**地下都市ソウル**に沿って、必要な項目だけを埋めて**完了**まで進みます。

:::tip[用意するもの]
- 会話に表示する画像1枚（JPG、PNG、WEBP、GIF、HEIC · 最大5MB）
- 世界観とキャラクターを書いたメモ。なければ、下の例をそのまま書き写しても構いません。
:::

| 順番 | ステップ | 埋めるもの |
| --- | --- | --- |
| 1 | **基本情報** | 作品タイトル、一行紹介、世界観、キャラクター |
| 2 | **アセット** | 画像1枚と状況説明 |
| 3 | **導入部** | 導入部のタイトルと最初のメッセージ |
| 4 | **その他の設定** | ジャンル、ハッシュタグ、必須項目5つ |
| 5 | **ロアブック · コンポーネント · オプション** | 空のまま進む |
| 6 | **完了** | 作品を作る |

## 1. 基本情報を埋める

下部メニューの**制作**を押すと、**基本情報**ステップが最初に開きます。いちばん上の**制作モード**で**かんたん**が選ばれているか確認してください。

<ScreenStep src="/img/screens/ja/simple-basic-top.webp" alt="基本情報ステップの上部。制作モードの欄の下に、作品タイトルと一行紹介の欄がある" caption="基本情報ステップの上部">

1. **作品タイトル**を書きます。最大30文字です。
2. **一行紹介**を書きます。作品カードにタイトルと一緒に表示される文です。最大40文字です。

</ScreenStep>

> 例 — 作品タイトル: `地下都市ソウル` · 一行紹介: `記憶を失って目覚めた場所は、封鎖された地下都市の検疫所だった。`

<ScreenStep src="/img/screens/ja/simple-basic-worldview.webp" device="part" alt="世界観の欄に例の文章を書いた画面。下にキャラクターの欄が続く" caption="世界観">

**世界観**には、作品の背景と、物語が始まるときの様子を書きます。AIが読む設定で、詳細説明を書いていないと作品紹介画面にもそのまま表示されます。そのため、ユーザーが知ってよい内容だけを書いてください。

</ScreenStep>

```md
2031年、地上は汚染されて見捨てられた。人々は地下鉄の駅と地下街をつないで作った地下都市ソウルに降りてきて暮らしている。
都市は管理局が統制していて、地上へ出る通路は封鎖されている。新しく入ってきた人は、まず検疫所に滞在する。

ユーザーは記憶をすべて失ったまま、検疫所のベッドで目を覚ます。物語はミヌがユーザーを検疫所の外へ案内するところから始まり、ユーザーが記憶を取り戻そうとすると、ソヨンが手がかりを一つずつ渡す。
```

<ScreenStep src="/img/screens/ja/simple-basic-characters.webp" device="part" alt="キャラクターの欄にカン・ミヌとイ・ソヨンの2人を書いた画面と、秘密の欄" caption="キャラクターと秘密">

**キャラクター**は1人以上必要です。**キャラクター追加**を押して、人物ごとに名前と説明を書きます。名前はそれぞれ違うものにして、説明には性格、背景、特徴を書きます。

**秘密**は、ユーザーに見えてはいけない設定です。任意ですが、AIが知っておくべきどんでん返しや隠された事情があるなら、ここに書きます。秘密は作品紹介画面には表示されません。

世界観、キャラクターの説明、秘密を合わせて10,000文字まで書けます。世界観の欄の上のバーに、使った量が表示されます。

</ScreenStep>

例として使う人物です。説明は作品紹介画面にも表示されることがあるので、ユーザーに隠すべきことは入れていません。

| 名前 | 説明 |
| --- | --- |
| カン・ミヌ | `地下都市の案内人、32歳。いつも冗談を言うのんびりした性格で、タメ口を使い、語尾を伸ばす。ユーザーについて何か知っているようだ。` |
| イ・ソヨン | `検疫所の医師、28歳。事務的で冷静で、短い敬語を使う。ユーザーの記憶喪失は事故ではないと疑っている。` |

ユーザーに明かしてはいけないことは、**秘密**に書きます。

```md
- ミヌはユーザーを監視するよう命令を受けている。ユーザーのほうから問い詰めてくるまでは明かさない。
- ユーザーの記憶は管理局が消した。
```

すべて書けたら、右下の<strong>&gt;</strong>（次へ）ボタンを押します。このとき、作品が初めて保存されます。

## 2. アセットを入れる

**アセット**ステップでは、会話に表示する画像を用意します。最初の作品は1枚で十分です。

<ScreenStep src="/img/screens/ja/simple-assets-add.webp" alt="アセットステップ。アセット追加から開いたウィンドウに、ファイルアップロードとAI画像から選択のボタンがある" caption="アセット追加">

1. **アセット追加**を押します。
2. **ファイルアップロード**を押して、画像を選びます。

アップロードした最初の画像は、自動で作品の代表画像になります。MYMIで画像を自分で作るには、[アセットとAI画像](/create/simple/assets)をご覧ください。

</ScreenStep>

<ScreenStep src="/img/screens/ja/simple-asset-sheet.webp" alt="状況説明を入力のウィンドウ。画像のプレビューの横にキャラクター選択の一覧があり、下に解放が必要のスイッチと説明の欄、保存ボタンがある" caption="状況説明の入力">

3. 画像を押して、**状況説明を入力**のウィンドウを開きます。
4. **キャラクター選択**で、画像に写っている人物を選びます。人物がいない背景の画像は**共用**です。
5. 説明の欄に、どんな場面の画像かを書いて（60文字まで）**保存**を押します。説明には、人物の名前を必ず入れてください。

</ScreenStep>

> 例 — キャラクター: `カン・ミヌ` · 状況説明: `カン・ミヌが明るく笑っている。`

AIは、この状況説明を見て、会話中にどの画像を見せるかを選びます。すべての画像に説明があって初めて、次へボタンで先に進めます。

## 3. 導入部を書く

導入部は、会話を始めるときにAIが最初に送るメッセージです。

<ScreenStep src="/img/screens/ja/simple-intro.webp" alt="導入部ステップ。導入部1のチップと追加ボタン、タイトルの入力欄、画像ボタン、最初のメッセージの欄とプレビューが見える" caption="導入部ステップ">

1. **導入部のタイトル**を書きます。ユーザーが開始シーンを選ぶときに見る名前です。
2. 下の欄に最初のメッセージを書きます。最大2,000文字です。行動と描写は`*アスタリスク*`の間に、セリフは`"二重引用符"`の中に書くと、チャットと同じ見た目で表示されます。
3. 欄の下の**プレビュー**で、チャットでの見え方を確認します。

</ScreenStep>

> 例 — 導入部のタイトル: `検疫所で目を覚ます`

```md
*蛍光灯がちらつく検疫所。消毒薬の匂いのなか、誰かがカーテンを開ける。*

"お、やっと目が覚めたか〜。三日間ずっと寝てたぞ？"

*古いミリタリージャケットを羽織った男が、懐中電灯をくるくる回して笑う。彼は自分を案内人のカン・ミヌだと名乗った。*

"ここはソウルだ。正確にはソウルの下だけどな〜。で、{{user}}。名前のほかに覚えてることはあるか？"
```

導入部の`{{user}}`は、会話するときにユーザーの名前に置き換わります。プレビューではそのまま表示されます。導入部に画像を入れる方法は、[アセットとAI画像](/create/simple/assets#導入部に画像を入れる)にあります。

## 4. その他の設定を選ぶ

**その他の設定**ステップで、赤い`*`が付いた項目をすべて選びます。上の**ジャンル**と**ハッシュタグ**から始めます。

<ScreenStep src="/img/screens/ja/simple-settings-1.webp" alt="その他の設定ステップの上部。ジャンルでSFとミステリー・スリラーが選ばれていて、その下にハッシュタグの欄がある" caption="ジャンルとハッシュタグ">

1. **ジャンル**を1〜2個選びます。例では**SF**と**ミステリー・スリラー**です。
2. **ハッシュタグ**を押してシートを開きます。一覧から選ぶか、**直接入力**の欄に書いて**追加**を押します。1個以上必要です。すべて選べたら、**完了**を押します。

</ScreenStep>

> 例 — ハッシュタグ: `地下都市`、`記憶喪失`、`ディストピア`

:::info[AIおすすめは、選んだタグをすべて置き換えます]
ハッシュタグのシートにある**AIおすすめ**は、作品タイトル、世界観、キャラクター、秘密を読んで、タグを選んでくれます。すでに選んだタグはおすすめの結果に置き換わり、読者層も一緒に変わることがあります。押したあとは、タグと**読者層**をもう一度確認してください。作品タイトルと世界観を先に書かないと押せません。
:::

<ScreenStep src="/img/screens/ja/simple-settings-2.webp" alt="その他の設定ステップの下のほう。公開設定、作品の公開範囲、収益化の制限、画像の出典のカード" caption="公開設定から画像の出典まで">

- **公開設定**: 最初から**公開**が選ばれています。自分だけで見るなら**非公開**を選びます。
- **作品の公開範囲**: **オリジナル**は、MYMIでのみ公開する作品です。他のプラットフォームにも載せるなら**一般**を選びます。
- **収益化の制限**: 他の作品のキャラクターや世界観を使った二次創作のように、権利が自分のものではない作品なら**収益化を制限**を選びます。例では**制限なし**です。
- **画像の出典**: MYMIで作った画像なら**MYMIで生成**、他のAIで作ったか自分で描いたなら**外部で制作**です。

</ScreenStep>

<ScreenStep src="/img/screens/ja/simple-settings-3.webp" alt="その他の設定ステップのいちばん下。画像出力指示、読者層、コンテンツのレーティング、マーケティング利用への同意のカード" caption="画像出力指示からマーケティング利用への同意まで">

- **画像出力指示**: 最初から**内部画像**が選ばれています。アセットステップでアップロードした画像を使うので、そのままにします。
- **読者層**: 作品が主に向かう読者を、**男性向け**・**女性向け**から選びます。
- **コンテンツのレーティング**: 最初から**全年齢**が選ばれています。**成人向け**は、成人認証を済ませたユーザーだけが利用できます。
- **マーケティング利用への同意**: 同意すると、MYMIがこの作品を広告やSNSの素材として使えます。

</ScreenStep>

それぞれの選択肢が何を意味するかは、[作品の設定を選ぶ](/create/settings)で詳しく説明します。

## 5. 残りのステップを飛ばして完了する

**ロアブック**、**コンポーネント**、**オプション**は任意のステップです。今は空のままにして、次へボタンを押して最後まで進みます。

<ScreenStep src="/img/screens/ja/simple-finish.webp" device="part" alt="オプションステップの下にある完了ボタン" caption="最後のステップの完了ボタン">

最後の**オプション**ステップでは、ボタンが**完了**に変わります。押すと、すべてのステップをもう一度確認して、作品を作ります。足りない項目があれば案内が表示されます。案内のとおりにそのステップに戻って埋め、もう一度**完了**を押します。

</ScreenStep>

<ScreenStep src="/img/screens/ja/first-complete.webp" alt="作品の制作が完了しました画面。作品カードの下に審査中の表示と、作品を見る・作品管理のボタンがある" caption="作品の制作が完了しました画面">

すべて埋められたら、**作品の制作が完了しました**画面が開きます。

- 公開で作った作品は**審査中**です。自分は今すぐ会話でき、他のユーザーには審査が終わると公開されます。
- **作品を見る**でそのまま会話してみて、直したいところが見つかったら、**作品管理**で**編集**を押します。

</ScreenStep>

審査と公開、作品管理については、[公開と編集](/create/publish)にあります。

## つまずいたときは

<details>
<summary>次へを押したら「アセットの説明を入力してください。」と表示される</summary>

状況説明が空の画像があります。アセットカードのいちばん下に、赤い枠で**状況説明を入力**と表示されている画像を押して、説明を書き、**保存**を押します。

</details>

<details>
<summary>「代表画像を選択してください。」と表示される</summary>

画像カードの左上の<strong>★</strong>を押して、代表画像を決めます。最初にアップロードした画像は自動で代表になりますが、以前に作った作品や、代表が空の作品は、自分で決める必要があります。

</details>

<details>
<summary>ハッシュタグを書いたのに「ハッシュタグを1つ以上追加してください。」と表示される</summary>

欄に書くだけでは入りません。**追加**を押して、タグがシートに表示されるようにしてから、**完了**を押してシートを閉じます。

</details>

<details>
<summary>「読者層を選んでください。」と表示される</summary>

**その他の設定**の**読者層**で、**男性向け**か**女性向け**を選びます。ハッシュタグのシートで**AIおすすめ**を使ったあとに、空になっていることがあります。

</details>

<details>
<summary>世界観に書いた内容が、作品紹介にも表示される</summary>

詳細説明を書いていないと、世界観とキャラクターの説明が作品紹介にそのまま表示されるのが、本来の動作です。ユーザーに隠すべき設定は、**秘密**の欄に移してください。

</details>

<details>
<summary>作品はどこから開き直せるか</summary>

**マイページ → 作品管理**で**編集**を押します。次へボタンを一度でも押していれば、**制作中**として作品管理にあります。編集のしかたは[作品を編集する](/create/simple/edit)にあります。

</details>
