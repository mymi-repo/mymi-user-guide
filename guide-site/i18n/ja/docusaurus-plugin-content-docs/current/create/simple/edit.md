# 作品を編集する

かんたんモードで作った作品は、作ったときと同じ7ステップの画面で直します。作品を作ったモードで開くので、エキスパートモードで作った作品の編集は、[公開と編集](/create/publish#公開した作品を直す)にあります。

## 開き方と移動

1. **マイページ → 作品管理**で、作品の**編集**を押します。
2. かんたんモードで開きます。いちばん上の**制作モード**の欄はロックされていて、**基本情報**ステップから表示されます。
3. 直したいステップに行って直します。上のタブを押して、直接移動できます。
4. 直し終わったら、最後の**オプション**ステップまで次へボタンで進んで、**完了**を押します。すべてのステップをもう一度確認して、**作品の制作が完了しました**画面に進みます。

移動と保存は、次のようになります。

| 移動 | 確認 | 保存 |
| --- | --- | --- |
| 次へボタン | 今のステップの必須項目 | ここまで直した内容 |
| タブを押して**先へ** | そのステップの手前まで | ここまで直した内容 |
| タブを押して**前へ** | しません | しません。次に先へ進むときにまとめて保存されます |
| **完了** | すべてのステップ | ここまで直した内容 |

アセットの画像のアップロードと削除、状況説明の**保存**、★代表画像の変更は、次へボタンを押さなくてもすぐに作品に反映されます。

:::warning[公開された作品は、先に進むたびにすぐ変わります]
かんたんモードは、次へボタンを押すたび、またはタブで先のステップに進むたびに、直した内容を作品に保存します。すでに公開されている作品なら、その瞬間から他のユーザーにも変更後の内容が見えます。エキスパートモードの**変更を反映**のように、待ってくれません。大きく直すときは、変える文章を先にメモ帳などに書いておき、貼り付けてから先に進んでください。
:::

:::warning[画像を消すときは注意してください]
公開した作品でアセットの画像を消すと、すぐに作品から消えます。その画像を導入部に入れていたり、会話で使っていたりすると、表示されなくなることがあります。消す前に、導入部の画像の行も一緒に確認してください。
:::

## 以前に作った作品を初めて開くとき

以前に作った作品にはなかった欄が増えました。初めて開くと、下の欄が空になっていることがあり、選ばないと**その他の設定**から先に進めません。

- **ジャンル** 1〜2個
- **ハッシュタグ** 1個以上（**読者層**はハッシュタグではなく、読者層のカードで選びます）
- **収益化の制限**
- **マーケティング利用への同意**

その他の設定のカードの見た目と文言は、エキスパートモードと同じになりました。カードがそれぞれ何を意味するかは、[作品の設定を選ぶ](/create/settings)にあります。作品タイトルは30文字までです。

## ステップごとに直すもの

各ステップの書き方は、作ったときと同じです。

| ステップ | 直せるもの | 案内 |
| --- | --- | --- |
| **基本情報** | タイトル、一行紹介、世界観、キャラクター、秘密 | [設定と導入部を書く](/create/simple/write) |
| **アセット** | 画像の追加と削除、状況説明、人物の結び付け、代表画像、解放が必要 | [アセットとAI画像](/create/simple/assets) |
| **導入部** | 導入部の追加と削除、タイトル、最初のメッセージ | [設定と導入部を書く](/create/simple/write#導入部) |
| **その他の設定** | ジャンル、ハッシュタグ、公開設定、作品の公開範囲など | [作品の設定を選ぶ](/create/settings) |
| **ロアブック · コンポーネント · オプション** | ロア、コンポーネント、詳細説明、おすすめペルソナ、制作者からのひとこと | [ロアブック・コンポーネント・オプション](/create/simple/extras) |

## 公開設定を変える

- **作品をしばらく隠したいとき**は、**その他の設定 → 公開設定**で**非公開**を選び、次へボタンを押して保存します。
- **非公開の作品を公開するとき**は、同じカードで**公開**を選んで保存します。公開に変えた作品は、審査を経てから他のユーザーに表示されます。（[公開と編集](/create/publish#非公開で作った作品を公開する)）
- **作品の公開範囲**をオリジナルにした作品は、3か月間変えられません。残りの日数がカードに表示されます。

## つまずいたときは

<details>
<summary>編集を押したら、制作モードの欄に鍵のマークが表示される</summary>

作品管理から開いた作品は、作ったモードで開き、モードを変えられません。新しい作品を作るには、<strong>↺</strong>を押して編集画面を空にしてから、モードを選んでください。（[始める前に](/create/before-you-start#作品管理から開いた作品はモードが固定されます)）

</details>

<details>
<summary>次のステップに進めない</summary>

手前のステップに、足りない必須項目があります。上に表示された案内を確認します。アセットステップなら、画像が1枚以上あるか、画像ごとに状況説明があるか、代表画像が決まっているかを見ます。その他の設定なら、ジャンル、ハッシュタグ、**読者層**、**作品の公開範囲**、**収益化の制限**、**画像の出典**、**マーケティング利用への同意**を選んだかを見ます。

</details>

<details>
<summary>「保存していない内容があります」というウィンドウが表示される</summary>

かんたんモードの編集画面に、別の作品や新しい作品の保存していない内容が残っています。**開く**を押すと、その内容は消えて、選んだ作品が開きます。残しておきたいときは**キャンセル**を押して、編集画面で先に次へボタンを押して保存してください。

</details>

<details>
<summary>「作品が見つかりません。」と表示される</summary>

別の端末で削除した作品か、自分の作品ではありません。編集画面が空になるので、**作品管理**で作品が残っているか確認してください。

</details>

<details>
<summary>プロンプトのタブがない</summary>

かんたんモードにはプロンプトのタブがありません。プロンプトを自分で書きたいなら、エキスパートモードで新しい作品を作る必要があります。既存の作品をエキスパートモードに変えるボタンはありません。（[エキスパートモードに移す](/create/simple/to-expert)）

</details>

<details>
<summary>間違って直した内容を元に戻したい</summary>

元に戻すボタンはありません。変わった欄をもう一度直して、次へボタンで保存します。公開作品では、すでに保存した内容がすぐ表示されるので、大きく直すときは事前にメモしておいてください。

</details>

<details>
<summary>同じ作品をPCとスマホで開いたまま直している</summary>

あとで保存した側の内容が残ります。別の端末で続きを直すには、今使っている端末で次へボタンを押して保存してから、もう一方の端末の**作品管理**で**編集**を押して開きます。編集画面を5分以上離れて戻ったとき、この端末に保存していない内容がなければ、サーバーの最新の内容に切り替わります。

</details>
