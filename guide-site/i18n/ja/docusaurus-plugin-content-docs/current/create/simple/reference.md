# 入力項目と制限

かんたんモード画面の制限とルールをまとめました。詳しい使い方は、各項目の案内ページにあります。

## 文字数と個数

| ステップ | 項目 | 制限 |
| --- | --- | --- |
| 基本情報 | 作品タイトル | 必須 · 30文字 |
| | 一行紹介 | 必須 · 40文字 |
| | 世界観 · キャラクターの説明 · 秘密 | 3つの欄を合わせて10,000文字。世界観とキャラクター1人以上（名前と説明）は必須、秘密は任意 |
| | キャラクターの名前 | 50文字。人物同士で重ならないように |
| アセット | 画像 | 必須 · 1〜200枚。JPG、PNG、WEBP、GIF、HEIC · 5MBまで |
| | 状況説明 | 画像ごとに必須 · 60文字 |
| | 代表画像 | 必須 · ★で1枚 |
| | 一度に作るAI画像 | ベース画像2枚、シチュエーション画像1枚まで |
| 導入部 | 導入部 | 必須 · 1つ以上、タイトルと内容の両方 |
| | 内容 | 2,000文字 |
| その他の設定 | ジャンル | 必須 · 1〜2個 |
| | ハッシュタグ | 必須 · 1個以上（読者層は除く） |
| | 作品の公開範囲 · 収益化の制限 · 画像の出典 · 読者層 · マーケティング利用への同意 | 必須 |
| ロアブック | ロア | 100件まで |
| | 名前 | 50文字 |
| | キーワード | ロア1つにつき5個、1つにつき10文字 |
| | 内容 | 400文字 |
| | 一度に渡される量 | 直近の10件のメッセージから探して、最大3件 · 1,500文字 |
| コンポーネント | 用途の説明 | コンポーネントごとに必須 · 500文字 |
| | JSXコード | 必須 · 10,000文字。関数名と変数1つ以上が必要 |
| オプション | 詳細説明（HTML） | 任意 · 50,000文字 |
| | おすすめペルソナ | 任意。作るなら、名前（20文字）・性別・生年月日（14歳以上）・詳細情報（1,000文字）がすべて必要 |
| | 制作者からのひとこと | 任意 · 3,000文字 |

**公開設定**（公開）、**コンテンツのレーティング**（全年齢）、**画像出力指示**（内部画像）は、最初から選ばれています。

## 次へ・完了で確認されること

次へボタンや**完了**ボタンを押すと、下の順番で確認して、最初に引っかかった項目の案内を表示します。**完了**は、7つのステップをすべてもう一度確認します。

| 順番 | ステップ | 確認すること |
| --- | --- | --- |
| 1 | 基本情報 | 作品タイトル、一行紹介、世界観、キャラクター1人以上、人物の名前と説明、名前の重複 |
| 2 | アセット | 画像1枚以上、代表画像、すべての画像の状況説明 |
| 3 | 導入部 | 1つ以上、すべてにタイトルと内容があるか |
| 4 | その他の設定 | ジャンル → ハッシュタグ → 作品の公開範囲 → 収益化の制限 → 画像の出典 → 読者層 → コンテンツのレーティング → マーケティング利用への同意の順 |
| 5 | ロアブック | 追加したロアごとの名前・キーワード・内容 |
| 6 | コンポーネント | 追加したコンポーネントごとの用途説明・コード・関数名・変数1つ以上 |
| 7 | オプション | 追加したおすすめペルソナごとの名前・性別・生年月日・詳細情報 |

## 画像の書き方

かんたんモードは、**その他の設定 → 画像出力指示**で選んだ方式で画像を出します。使うのは一方だけです。

| 方式 | 書き方 | 使う場所 |
| --- | --- | --- |
| 内部画像 | `img:[名前]` | アセットにアップロードした画像。アセットカードに`img:AB3K9X`のように名前が表示されます |
| 外部画像 | `![](画像のアドレス)` | 設定に書いておいた外部画像のアドレス |

導入部では`img:[AB3K9X]`のように書きます。名前は、MYMIが決めた英大文字と数字の6文字です。内部画像の方式なら、AIはアセットごとに書いた**状況説明**と結び付けた人物を見て、どの画像を入れるかを選びます。外部画像の方式では、状況説明はAIに渡されず、設定に書いた画像のアドレスやアドレスの規則を見て画像を入れます。アドレスが分からなければ、画像を入れません。

:::warning[エキスパートモードでは使いません]
`img:[名前]`は、かんたんモードの書き方です。エキスパートモードの作品では、アセットタブのコードと`![]({{URL}}/A/1.webp)`を使います。
:::

## `{{user}}`と`{{char}}`

| 使う場所 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 導入部 | 会話するときにユーザーの名前に置き換わります | 会話するときに**作品タイトル**に置き換わります |

導入部のプレビューでは置き換わらず、そのまま表示されます。`{{char}}`には人物の名前ではなく作品タイトルが入るので、人物の名前は直接書きます。

## 保存

| 状況 | 保存されるタイミング |
| --- | --- |
| すべての作品 | 次へボタンを押すとき、タブを押して先へ進むとき、**完了**を押すとき。それまでに直した内容がまとめて保存されます |
| アセット | 画像のアップロードと削除、状況説明の**保存**、★代表画像の変更は、すぐに作品に反映されます |
| 公開した作品 | 保存された瞬間に、他のユーザーにも変更後の内容が見えます |

## 無料と認証

- 作品制作の画像生成・再生成は無料です。生成するには、電話番号認証が必要です。
- 成人向けの作品は、成人認証を済ませたユーザーだけが利用できます。
- 画像生成のタグのステップにあるセーフティフィルターは、成人認証を済ませたアカウントだけがオフにできます。

## つまずいたときは

<details>
<summary>「保存に失敗しました」と表示される</summary>

保存中に接続が切れたか、サーバーが一時的に混み合っていた可能性があります。しばらくしてから、もう一度次へボタンを押します。同じ案内が出続けるときは、**マイページ → Discord**のお問い合わせチャンネルか[contact@mymi.live](mailto:contact@mymi.live)へ、どの作品のどのステップで起きたかをお知らせください。

</details>

<details>
<summary>文字がこれ以上入力できない</summary>

欄ごとに決まった文字数を超えると、入力できません。基本情報ステップは、世界観、キャラクターの説明、秘密を合わせて10,000文字が上限なので、ほかの欄で書いた量も確認してください。

</details>
