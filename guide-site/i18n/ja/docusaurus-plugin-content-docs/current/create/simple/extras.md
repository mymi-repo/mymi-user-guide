# ロアブック・コンポーネント・オプション

**ロアブック**、**コンポーネント**、**オプション**は任意のステップです。空のままでも作品を完成させられ、追加したいときに埋めます。追加したなら、その中の必須の欄をすべて埋めないと、次へボタンで先に進めません。

## ロアブック

ロアブックは、**会話にキーワードが出たときだけ、そのロアの内容がAIに渡される設定集**です。いつも知っている必要はないけれど、名前が出たときには知っておくべきこと、たとえば世界観の用語・場所・組織・人物の秘密を書きます。

世界観に書いた文章はAIが毎回読みますが、ロアはキーワードが出たときだけ読みます。毎回必要な設定は基本情報ステップの世界観・キャラクターに置き、ときどき出る設定をロアブックに置くと、世界観を短く保てます。

<ScreenStep src="/img/screens/ja/simple-lorebook.webp" alt="ロアブックステップ。2/100の表示と案内文の下に、管理局と7番出口の2つのロアが折りたたまれた状態で表示され、ロアを追加ボタンがある" caption="ロアブックステップ">

1. **ロアを追加**を押します。100件まで作れます。
2. カードを開いて、**名前**、**キーワード**、**内容**を埋めます。
3. カードをもう一度押すと折りたたまれて、名前とキーワードだけが表示されます。カードのゴミ箱アイコンで消せます。

</ScreenStep>

- **名前**: ロアの名前です。50文字まで。内容と一緒にAIに渡されます。
- **キーワード**: 会話にこの言葉が出ると、内容が渡されます。5個まで、1つにつき10文字までです。書いてEnterかカンマを押すと入ります。大文字と小文字は区別しません。
- **内容**: キーワードが出たときにAIが知っておくべきことだけを書きます。400文字までです。

例の作品のロアです。

| 名前 | キーワード | 内容 |
| --- | --- | --- |
| 管理局 | 管理局、局長 | 地下都市を治める機関。検疫所と出入口を管理し、地上から降りてきた人の記録を消すという噂がある。ミヌは管理局の命令を受けて動いている。 |
| 7番出口 | 7番出口、七番出口 | 地上へ続く唯一の出口。2031年の封鎖以降は閉ざされており、管理局の許可証がなければ近づけない。 |

**どうやって探して渡すか**

- ユーザーが送ったメッセージと、**直近の10件のメッセージ**からキーワードを探します。
- キーワードが別の言葉の中に入っていても見つかります。キーワード`管理局`は「管理局長が来た」でも見つかります。スペースは区別するので、`7番出口`は「7番 出口」では見つかりません。
- 複数のロアに当てはまると、いちばん最近出たものから選んで、一度に**最大3件、合わせて1,500文字**まで渡されます。

**キーワードを選ぶコツ**

- 会話で実際に出る言葉を書きます。略語や愛称も一緒に入れます。スペースを入れても入れなくても書ける名前は、両方入れます。
- ありふれすぎた言葉は避けます。ほとんどの会話に当てはまって、本当に必要なロアが3件に入れないことがあります。
- 内容は、短く事実だけを書きます。話し方や進行の方向は、世界観とキャラクターの説明に書きます。

## コンポーネント

コンポーネントは、**チャット中にAIが表示するUI**です。ステータスウィンドウ、インベントリ、選択肢のように見せたいものを作っておくと、AIが必要なときに呼び出します。コードが分からなくても、Gemで作れます。

<ScreenStep src="/img/screens/ja/simple-components.webp" alt="コンポーネントステップ。上部にガイドと作品情報をコピーのボタン、StatusWindowコンポーネントのカードとプレビュー、コンポーネントを追加ボタンが見える" caption="コンポーネントステップ">

1. **コンポーネントを追加**を押して、カードを作ります。
2. カードを開いて、**JSXコード**の欄にコードを貼り付けます。関数名と変数は、コードから自動で読み取ります。
3. **用途の説明**に、このコンポーネントをいつ使うかを書きます。
4. カードの中のプレビューで、チャットでの見え方を確認します。カードの目のアイコンで、プレビューを折りたたんだり開いたりします。

</ScreenStep>

- **JSXコード**: `function 名前({ 変数 = デフォルト値 })`の形のコードです。10,000文字まで書けます。コードフェンスやimport文は自動で整理されます。
- **変数のデフォルト値**: コードから読み取った変数とデフォルト値が表示されます。デフォルト値はプレビューで使われ、AIが入れる値の例になります。
- **用途の説明**: 500文字までです。AIがこのコンポーネントをいつ使うかを判断する基準です。

例の作品のステータスウィンドウのコードです。関数名（`StatusWindow`）と、1つ以上の変数（`hp`、`mp`）が必要です。

```jsx
function StatusWindow({ hp = 100, mp = 40 }) {
  const bar = (value, color) => (
    <div className="h-2 w-full rounded-full bg-slate-700">
      <div className={`h-2 rounded-full ${color}`} style={{ width: `${Math.max(0, Math.min(100, value))}%` }} />
    </div>
  );
  return (
    <div className="my-2 w-full max-w-sm rounded-xl border border-cyan-400/40 bg-slate-900/90 p-3 text-slate-100">
      <div className="mb-2 flex items-center justify-between text-[11px] font-bold tracking-widest text-cyan-300">
        <span>STATUS</span>
        <span>検疫所 B-3</span>
      </div>
      <div className="space-y-2 text-sm">
        <div>
          <div className="mb-1 flex justify-between"><span>体力</span><span>{hp}/100</span></div>
          {bar(hp, "bg-rose-400")}
        </div>
        <div>
          <div className="mb-1 flex justify-between"><span>魔力</span><span>{mp}/100</span></div>
          {bar(mp, "bg-sky-400")}
        </div>
      </div>
    </div>
  );
}
```

> 例 — 用途の説明: `戦闘が始まる時と体力が変わる時に見せる。hp = 体力、mp = 魔力。`

AIは、コンポーネントの名前、用途の説明、変数とデフォルト値を読み、適切なタイミングで`<StatusWindow hp={100} mp={40} />`のようなタグを返信に入れます。用途の説明に**いつ使うか**と**変数の意味**を書いておくと、AIが値を適切に埋めます。

:::info[コンポーネントは見せるための道具です]
コンポーネントは、AIが入れた値を見やすく描くだけです。体力の計算のように、値が合っているかどうかは、AIの返信次第です。説明を書いても、AIがときどきタグを入れ忘れたり、値を違うものにしたりすることがあります。
:::

**Gemで作る**

コードを自分で書かなくても構いません。ステップの上にある2つのボタンを使います。

1. **ガイド**を押して、Gemの案内を見ます。このステップを初めて開くと、自動で表示されます。
2. **作品情報をコピー**を押します。作品の紹介がコピーされて、**Gemini Gemを開く**が表示されます。
3. Gemを開いて、コピーした作品情報を貼り付け、作りたいUIを書きます。Gemの質問に答えると、コードを作ってくれます。
4. 完成したコードを、コンポーネントカードの**JSXコード**の欄に貼り付けます。

## オプション

**オプション**ステップには、詳細説明、おすすめペルソナ、制作者からのひとことがあります。最後のステップなので、ボタンが**完了**に変わります。

### 詳細説明

作品紹介画面に表示する文章を、HTMLで飾ります。使わないと、作品紹介に世界観とキャラクターの説明がそのまま表示されます。

<ScreenStep src="/img/screens/ja/simple-optional.webp" alt="オプションステップ。詳細説明で使用と不使用のうち使用が選ばれていて、HTMLの入力欄とプレビューが見える" caption="オプションステップ · 詳細説明">

1. **使用**と**不使用**から選びます。**不使用**は、通常のプロフィールだけを使います。
2. **使用**を選ぶと、HTMLの入力欄が表示されます。50,000文字までです。
3. 入力欄の下に、チェック結果が表示されます。「安全なHTMLです」なら、そのまま使えます。「安全でないタグが含まれています」の横の**自動クリーンアップ**を押すと、そのタグを取り除きます。「HTMLではないテキストです」は、HTMLのコードではない文章という意味です。
4. HTMLなら、下に**プレビュー**が表示されます。ユーザーに見える様子を確認します。

</ScreenStep>

コードが分からなくても大丈夫です。**作品情報をコピー**を押し、**Gemini Gemを開く**でGemに紹介ページを作ってもらいます。**ガイド**を押すと、使い方を確認できます。

:::info[詳細説明はAIが読みません]
詳細説明は、作品紹介画面に表示される文章です。AIが知っておくべき設定は、基本情報ステップに書きます。
:::

### おすすめペルソナ

ユーザーが会話を始めるときに選べるペルソナを、あらかじめ作っておく機能です。作品の世界に合う主人公を提案するときに使います。作らなくても構いません。

**ペルソナを追加**を押して作ります。作ったなら、4つの欄をすべて埋めないと、次へボタンや**完了**ボタンで先に進めません。

- **名前**: 20文字まで
- **性別**: 女性・男性
- **生年月日**: 年・月・日を書きます。14歳以上である必要があります。
- **詳細情報**: AIがこのペルソナで会話するユーザーをどう扱えばよいか分かるように、性格・背景・話し方を書きます。1,000文字まで

### 制作者からのひとこと

作品についてのメッセージを残します。3,000文字までです。作品紹介画面に表示され、AIは読みません。**クリア**を押すと、文章が消えます。

## つまずいたときは

<details>
<summary>「キーワードのないロアがあります。」と表示される</summary>

キーワードを書いて、Enterかカンマを押して追加したか確認します。カードにキーワードが表示されていれば、追加されています。作りかけのロアは、ゴミ箱アイコンで消します。名前や内容が空のロアも、同じ案内が表示されます。

</details>

<details>
<summary>「コンポーネントコードはfunctionコンポーネント形式で記述してください。」と表示される</summary>

コードが`function 名前(...)`の形で始まっているか確認します。アロー関数や名前のない関数は、名前を読み取れません。

</details>

<details>
<summary>「コンポーネントに変数名を1つ以上追加してください。」と表示される</summary>

関数が受け取る変数を、1つ以上宣言する必要があります。例: `function StatusWindow({ hp = 100 })`

</details>

<details>
<summary>「コンポーネントの用途説明を入力してください。」と表示される</summary>

コンポーネントカードを開いて、**用途の説明**を書きます。カードに赤い文字で「用途説明が必要です」「JSXコードが必要です」のような表示があるコンポーネントがないか確認します。

</details>

<details>
<summary>「おすすめペルソナ情報を完成させてください。」と表示される</summary>

作ったペルソナのうち、名前、性別、生年月日、詳細情報のどれかが空です。生年月日は、存在しない日付や未来の日付、14歳未満の日付ではいけません。使わないペルソナは消します。

</details>

<details>
<summary>作品紹介に世界観が表示されず、HTMLの文章だけが表示される</summary>

**詳細説明**を**使用**にしているからです。HTMLで紹介文を書くと、世界観とキャラクターの代わりにその文章が表示されます。世界観とキャラクターの説明を見せたいなら、**不使用**に変えます。

</details>
