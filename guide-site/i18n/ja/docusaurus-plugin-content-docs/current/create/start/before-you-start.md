# 始める前に

MYMIの作品は、**AIが読む設定**と**ユーザーが見る画面**でできています。この2つを作る方法は2つあります。項目を埋めるだけで作れる**かんたんモード**と、AIが読む設定を自分で書く**エキスパートモード**です。新しい作品は、かんたんモードから始まります。

## 制作モードを選ぶ

下部メニューの**制作**を押すと、**作品制作**画面が開きます。最初のタブである**基本情報**のいちばん上が**制作モード**の欄です。ウェブとアプリで画面の構成は同じです。

<ScreenStep src="/img/screens/ja/mode-card.webp" alt="基本情報タブの一番上にある制作モードの欄。かんたんモードとエキスパートモードの2つのボタンがあり、かんたんモードが選ばれている" caption="制作モードの欄">

1. **かんたんモード**: 項目を埋めるとAI設定が自動で作られます。
2. **エキスパートモード**: AIが読む設定と出力ルールを自分で書きます。

押すとモードが切り替わり、選んだモードの**基本情報**タブが開きます。最初はかんたんモードが選ばれていて、その後はこの端末で最後に使ったモードで開きます。

</ScreenStep>

## 2つのモードの違い

| | かんたんモード | エキスパートモード |
| --- | --- | --- |
| AI設定を書く場所 | **基本情報**の世界観・登場人物・秘密の欄。MYMIがまとめてAIに渡します | **プロンプト**タブ。項目に分けて書く**基本型**か、まるごと書く**自分で書く** |
| 画像 | 画像ごとに**状況説明**を書き、人物を結び付けます。AIが説明を見て合う画像を選びます | フォルダとコードで整理し、いつ見せるかをプロンプトに書きます |
| ステータスウィンドウなどのコンポーネント | コンポーネントごとに**用途の説明**にいつ使うかを書きます | プロンプトの**コンポーネント出力ルール**に書きます |
| 画面 | 7つのステップ。次へボタンを押して順に進みます | 7つのタブ。好きなタブから書けます |
| 保存 | 次へボタンを押すたびに作品に保存されます | タブを移動するときに自動で保存されます。**下書き保存**と**制作完了**があります |
| 公開した作品を直すとき | 直した内容は、次へボタンで先に進んだ瞬間に反映されます | **変更を反映**を押して初めて反映されます |
| 必ず必要な画像 | **アセット**1枚以上と、★で選んだ代表画像1枚 | **表紙**1〜10枚。アセットはなくても構いません |

2つのモードで同じものもあります。公開前の審査と作品管理は同じで、リーフの割合を決める**作品の公開範囲**・**画像の出典**・**収益化の制限**などの設定も同じです。設定の選び方は[作品の設定を選ぶ](/create/settings)にあります。

## どのモードを選ぶか

**かんたんモード**が向いているのは、次のような場合です。

- 初めて作品を作る。
- 世界観と人物を項目に書くだけで始めたい。
- 画像は「この場面にはこの画像」と伝えれば十分。

**エキスパートモード**が向いているのは、次のような場合です。

- AIに渡す設定と進行ルールを自分で設計したい。
- 画像とコンポーネントが出るタイミングを、ルールで正確に決めたい。
- 表紙を複数入れたい、またはタブを自由に行き来しながら作業したい。

どちらが優れているということではありません。作品をどう作りたいかに合わせて選びます。作品紹介画面は、モードによって構成が少し変わります。

## モードを切り替えると書いた内容はどうなるか

- 2つのモードは**下書きが別々**です。モードを切り替えても、書いた内容はそのモードに残り、もう一方のモードには移りません。戻ってくれば続きを書けます。
- **↺**（制作内容を初期化）は、今のモードの下書きだけを空にします。確認ウィンドウに、どのモードの下書きを空にするかが書かれています。
- サーバーに保存した下書きは、**マイページ → 作品管理**に**制作中**として残ります。初期化しても消えません。

<ScreenStep src="/img/screens/ja/mode-intro.webp" alt="エキスパートモードに切り替えますか？のウィンドウ。プロンプトを自分で書きます、画像はコードで呼び出します、タブを自由に行き来できます、の3項目と、キャンセル・エキスパートモードに切り替えのボタンがある" caption="エキスパートモードを初めて選ぶとき">

エキスパートモードを**初めて**選ぶときは、ウィンドウが表示されます。どういう方式かを読んで**エキスパートモードに切り替え**を押すと切り替わります。**キャンセル**を押すと、モードはそのままです。このウィンドウは一度見ると、もう表示されません。

ウィンドウの下には「かんたんモードで書いた内容はそのまま残ります。エキスパートモードには移りません。」と書かれています。

</ScreenStep>

:::tip[書いた内容を守るには、まず保存]
入力中の内容は、サーバーに保存されるまでこの端末にしかありません。ログアウトしたり別のアカウントでログインしたりすると、保存していない内容は消えます。かんたんモードでは次へボタンを、エキスパートモードではタブの移動か**下書き保存**を押して保存しておきましょう。保存されるタイミングはモードごとに違うので、各モードの案内で詳しく説明します。
:::

## 作品管理から開いた作品はモードが固定されます

**マイページ → 作品管理**で作品の**編集**を押すと、その作品を作ったモードで開きます。このとき制作モードの欄はロックされています。

<ScreenStep src="/img/screens/ja/mode-locked.webp" device="part" alt="ロックされた制作モードの欄。エキスパートモードのボタンに鍵のマークがあり、下に作品管理から開いた作品はモードを変更できないという案内がある" caption="作品管理から開いた作品の制作モードの欄">

- 作った作品のモードを変える機能はありません。別のモードで作り直すには、新しい作品を作って設定を書き写します。かんたんモードの作品は、[エキスパートモードに移す](/create/simple/to-expert)に移し方があります。
- 新しい作品を作りたいときは、<strong>↺</strong>を押して編集画面を空にします。するとロックが外れて、モードを選び直せます。作品管理の作品はそのまま残ります。

</ScreenStep>

今のモードの編集画面に**保存していない内容**がある状態で、作品管理から別の作品を開こうとすると、確認ウィンドウが表示されます。**開く**を押すと、保存していない内容が消えて、その作品が開きます。**キャンセル**を押すと、何も変わりません。

## つまずいたときは

<details>
<summary>制作モードの欄のもう一方のボタンに鍵のマークが出ていて、押せない</summary>

作品管理から開いた作品だからです。作った作品のモードは変えられません。新しい作品を作るには、<strong>↺</strong>を押して編集画面を空にしてから、モードを選んでください。作品管理の作品は消えません。

</details>

<details>
<summary>エキスパートモードに切り替えたら、書いていた内容がない</summary>

2つのモードは下書きが別々です。かんたんモードで書いた内容はエキスパートモードには移りませんが、消えてもいません。制作モードの欄で**かんたんモード**をもう一度押せば、そのまま残っています。内容を移したいときは、[エキスパートモードに移す](/create/simple/to-expert)に沿って手で書き写します。

</details>

<details>
<summary>「エキスパートモードに切り替えますか？」というウィンドウが表示される</summary>

エキスパートモードを初めて選ぶときに、一度だけ表示される案内ウィンドウです。どういう方式かを読んで、**エキスパートモードに切り替え**を押してください。まだ決められないときは**キャンセル**を押せば、モードはそのままです。

</details>

<details>
<summary>作品管理で編集を押したら「保存していない内容があります」と表示される</summary>

そのモードの編集画面に、別の作品や新しい作品の保存していない内容が残っているからです。**開く**を押すとその内容は消えて、選んだ作品が開きます。残しておきたいときは**キャンセル**を押して編集画面に戻り、先に保存してください。保存した下書きは、作品管理に**制作中**としてあります。

</details>

<details>
<summary>画像作成ウィンドウにも「エキスパートモード」がある</summary>

画像を生成する最後のステップで開く**エキスパートモード**は、制作モードとは別の機能です。画像生成の設定（`negative_prompt`、guidanceなど）を変える欄で、作品の作り方とは関係ありません。どちらのモードでも、同じ画像生成ウィンドウを使います。

</details>

<details>
<summary>「基本型」「自分で書く」は、かんたんモード・エキスパートモードとは別のものか</summary>

別のものです。**基本型**と**自分で書く**は、エキスパートモードの**プロンプト**タブで選ぶ2つの書き方です。かんたんモードにはプロンプトタブがありません。詳しくは[プロンプトを書く](/create/prompt)にあります。

</details>

<details>
<summary>初期化を押したら、作っていた作品が消えた</summary>

初期化は作品制作画面を空にするだけです。保存した下書きは**マイページ → 作品管理**に**制作中**として残っています。**編集**を押してもう一度開いてください。

</details>
