# 作品の設定を選ぶ

作品の公開のしかたと、リーフを受け取る条件を決める設定です。**その他の設定**で選び、かんたんモードとエキスパートモードは同じカードを使います。

- かんたんモード: **その他の設定**ステップ。上に**ジャンル**と**ハッシュタグ**があり、その下にこのページのカードが続きます。
- エキスパートモード: **その他の設定**タブ。**ジャンル**と**ハッシュタグ**は**基本情報**タブにあります。

赤い`*`が付いたカードは必ず選ぶ必要があります。**公開設定**と**コンテンツのレーティング**は最初から選ばれていて、残りは自分で選ばないと作品を完成させられません。

## 一目でわかる一覧

| カード | 選択肢 | 最初の値 |
| --- | --- | --- |
| **公開設定** | 公開 · 非公開 | 公開 |
| **作品の公開範囲** | オリジナル · 一般 | 未選択 |
| **収益化の制限** | 制限なし · 収益化を制限 | 未選択 |
| **画像の出典** | MYMIで生成 · 外部で制作 | 未選択 |
| **読者層** | 男性向け · 女性向け | 未選択 |
| **コンテンツのレーティング** | 全年齢 · 成人向け | 全年齢 |
| **マーケティング利用への同意** | 同意する · 同意しない | 未選択 |

## 公開設定

作品を誰に見せるかを決めます。

- **公開**: すべてのユーザーが見られます。公開で作った新しい作品は、審査を経てから他のユーザーに表示されます。
- **非公開**: 自分だけが見られます。公開する前に会話を試すときに使います。

あとから**マイページ → 作品管理 → 編集**の**その他の設定**で変えられます。非公開の作品を公開に変えると、そこから審査が始まります。（[公開と編集](/create/publish#非公開で作った作品を公開する)）

## 作品の公開範囲

- **オリジナル**: MYMIでのみ公開する作品です。より高いリーフの割合を受け取れます。
- **一般**: 他のプラットフォームでも公開できる作品です。

:::warning[オリジナルは3か月間解除できません]
オリジナルを選ぶと、「オリジナルに設定すると3か月間解除できません。」という案内が表示されます。設定した日から3か月間は、**一般**に戻さないというルールです。他のプラットフォームにも載せる予定があるなら、**一般**を選んでください。

かんたんモードでは、設定してから3か月間はカードがロックされ、解除までの残り日数が表示されます。
:::

## 収益化の制限

- **制限なし**: 自分が権利を持つ創作物です。
- **収益化を制限**: 他の作品のキャラクターや世界観を使った二次創作のように、権利が自分のものではない作品です。

**収益化を制限**を選んだ作品は、リーフがたまりません。オリジナルでも、公式クリエイターでも同じです。変更すると、次の会話から適用されます。

## 画像の出典

作品の画像をどのように作ったかを選びます。

- **MYMIで生成**: MYMIの画像生成で作った画像です。
- **外部で制作**: 他のAIで作ったか、自分で描いた画像です。

**一般**の作品では、リーフの割合が画像の出典によって変わります。割合は[クリエイターになる・リーフ](/creator-support/support#リーフをためる)にあります。画像を使わない作品は、実際に使っているほうを選びます。

## 読者層

作品が主にどの読者に向けたものかを、**男性向け**か**女性向け**で選びます。

## コンテンツのレーティング

会話の内容と、生成される画像に影響します。

- **全年齢**: 誰でも利用できます。
- **成人向け**: 成人認証を済ませたユーザーだけが利用できます。（[年齢確認・電話番号認証](/account/adult-verification)）

すでに公開された作品のレーティングを、成人向けから全年齢に変えると、もう一度審査を受けます。

## マーケティング利用への同意

- **同意する**: MYMIがこの作品を広告やSNSなどのマーケティングに使えます。露出が増えると会話量が自然に増え、リーフの獲得も増える可能性があります。
- **同意しない**: マーケティングには使いません。

## かんたんモードだけにあるカード: 画像出力指示

かんたんモードの**その他の設定**には、**画像出力指示**のカードがもう1つあります。AIが会話で画像をどのように出すかを決めます。

- **内部画像**: アセットにアップロードした画像を使います。最初から選ばれています。
- **外部画像**: 設定に書いた画像のアドレス（URL）を使います。

使うのは一方だけです。詳しくは[アセットとAI画像](/create/simple/assets#画像出力指示)にあります。エキスパートモードにはこのカードがなく、プロンプトに画像のルールを自分で書きます。

## つまずいたときは

<details>
<summary>オリジナルを選んだけれど、一般に変えたい</summary>

オリジナルに設定してから3か月間は解除できないルールです。かんたんモードでは、カードがロックされ、解除までの残り日数が表示されます。3か月が過ぎたら**一般**に変えられます。

</details>

<details>
<summary>収益化の制限を選ぶべきか分からない</summary>

自分で作った人物と世界観で書いた作品なら、**制限なし**です。他の作品のキャラクターや世界観を借りた二次創作のように、権利が自分にないなら**収益化を制限**を選びます。判断が難しいときは、[お問い合わせ](/faq#お問い合わせ)で聞いてください。

</details>

<details>
<summary>「作品の公開範囲を選んでください。」のような案内が表示される</summary>

選んでいないカードがあるという意味です。案内は一度に1つずつ表示され、かんたんモードでは次へボタンか**完了**ボタンを、エキスパートモードでは**制作完了**を押したときに確認されます。案内の文に書かれているカードを選んでください。ほかにも残っているカードがあるかもしれません。

</details>

<details>
<summary>成人向けで作ったのに、他のユーザーに表示されない</summary>

成人向けの作品は、成人認証を済ませたユーザーにだけ表示されます。自分のアカウントが認証されているかも確認してください。（[年齢確認・電話番号認証](/account/adult-verification)）

</details>
