# 1.0の入力項目と書き方

旧方式（1.0）の画面の項目と制限、画像の書き方をまとめました。1.0の作品を現在の方式の新しい作品へ移すときに使う対応表もあります。

## 1.0の項目と制限

| ステップ | 項目 | 制限 |
| --- | --- | --- |
| 基本情報 | 作品名 | 必須 · 50文字（現在は作品タイトル30文字） |
| | 一行紹介 | 必須 · 40文字 |
| | 世界観 · キャラクターの説明 · 秘密 | 3つの欄を合わせて10,000文字。世界観とキャラクター1人以上は必須 |
| | キャラクター名 | 50文字。人物同士で重複しないこと |
| アセット | 画像 | 1〜200枚 |
| | 状況説明 | 画像ごとに必須 · 60文字 |
| | 代表画像 | ★で1枚 |
| 導入部 | 導入部 | 1つ以上、タイトルと内容 |
| その他の設定 | ターゲット読者層 | 必須 · **ハッシュタグ**ウィンドウで男性向け・女性向けのどちらか |
| | 作品の公開範囲 · 画像出典 | 必須 |
| ロアブック | エントリー | 100件まで。エントリー名50文字、トリガーキーワード5個（各10文字）、内容400文字 |
| コンポーネント | 用途の説明 | コンポーネントごとに必須 · 500文字 |
| | コード | 10,000文字（現在は20,000文字） |
| オプション | 制作者からのひとこと | 3,000文字（現在はクリエイターガイドの文章1つにつき5,000文字） |
| | おすすめペルソナ | 任意 · ニックネーム20文字、詳細情報1,000文字 |

## 1.0の画像の書き方

1.0は、**その他の設定 → 画像出力指示**で選んだ方式で画像を入れます。画面の案内どおり、どちらか一方の方式だけを使います。

| 方式 | 書き方 | 使う場所 |
| --- | --- | --- |
| 内部画像 | `img:[slug]` | アセットにアップロードした画像。アセットカードに`img:AB3K9X`のように名前が表示されます |
| 外部画像 | `![](画像のアドレス)` | 設定に書いておいた外部画像のアドレス |

導入部では`img:[AB3K9X]`のように書きます。名前はMYMIが決めた英大文字・数字の6文字です。内部画像の方式では、AIはアセットごとに書いた**状況説明**と紐付けたキャラクターを見て、どの画像を入れるかを選びます。外部画像の方式では、状況説明はAIに渡されません。

:::warning[現在の方式では使いません]
`img:[slug]`は、1.0の作品だけで使う書き方です。現在の方式の作品には、アセットタブのコードと`![]({{URL}}/A/1.webp)`を使います。
:::

## 現在の方式へ移す

1.0の作品を現在の方式で作り直すときの、項目ごとの移し先です。既存の作品が自動で変わるのではなく、新しい作品に自分で書き写す作業です。

| 1.0で使っていた場所 | 現在使う場所 | 移すときにすること |
| --- | --- | --- |
| 基本情報 → 世界観 | プロンプト → 作品情報（基本型）または本文（自分で書く） | 時代・場所・ルールを書き写します |
| 基本情報 → キャラクター | プロンプト → 作品情報の登場人物 | 名前の行の下に、役割・性格・話し方・関係を書きます |
| 基本情報 → 秘密 | プロンプト → 作品情報の隠し設定 | 明かす条件も一緒に書きます。詳細説明には移しません |
| アセット → キャラクターとの紐付け | アセットのキャラクターフォルダ + プロンプトのキャラクターコードの意味 | 人物ごとにフォルダを作り、フォルダのコードと名前を合わせます |
| アセット → 状況説明 | アセットの画像コード + プロンプトの状況コード・その他コードの意味 | 同じ場面は、すべての人物で同じコードにそろえます |
| アセット → 代表画像 | 基本情報 → 表紙 | 表紙は1〜10枚。アセットから取り込めます |
| 導入部の`img:[slug]` | 導入部の`![]({{URL}}/A/1.webp)` | **アセット画像を挿入**で入れ直します |
| その他の設定 → ハッシュタグ（ターゲット読者層を含む） | 基本情報 → ジャンル・ハッシュタグ、その他の設定 → 読者層 | ジャンル1〜2個とハッシュタグを新しく書きます |
| コンポーネント → 用途の説明 | プロンプト → コンポーネント出力ルール（基本型）または本文（自分で書く） | いつどんな値で呼び出すかを書き写します |
| オプション → HTMLプロフィール | 基本情報 → 詳細説明 | 詳細説明は必須です。プレビューで確認します |
| オプション → 制作者からのひとこと | 基本情報 → クリエイターガイド | |
| オプション → おすすめペルソナ | その他の設定 → おすすめペルソナ | |
| ロアブック | ロアブック | 名前・キーワード・内容をそのまま移します |

### 例: 画像を1枚移す

1.0で、キャラクター**カン・ミヌ**に紐付けて、状況説明を「ミヌが笑っている様子」と書いた画像（`img:[AB3K9X]`）があるなら、現在の方式では次のように移します。

1. **プロンプト**の作品情報に、ミヌの役割・性格・話し方を書きます。
2. **アセット**にキャラクターフォルダ`A`を作り、その画像をコード`1`で入れます。
3. 基本型なら、**画像出力ルール**にキャラクターコード`A` = `カン・ミヌ`、状況コード`1` = `笑い`を書きます。
4. 自分で書く方式なら、画像の意味と一緒に、いつどんな形式で入れるかも本文に書きます。
5. 導入部に書いていた`img:[AB3K9X]`は削除して、**アセット画像を挿入**で`A/1`を入れます。

## つまずいたときは

<details>
<summary>1.0の導入部を新しい作品に貼り付けたら、画像が表示されない</summary>

現在の方式は、`img:[…]`を読み取りません。導入部のプレビューにも、その位置に「画像を読み込めません」と表示されます。その行を削除して、最初のメッセージ欄の**アセット画像を挿入**で入れ直してください。

</details>

<details>
<summary>移した作品の会話に画像が出ない</summary>

1.0では、MYMIが状況説明をまとめてAIに渡していましたが、現在は画像をいつ入れるかをプロンプトに書く必要があります。基本型なら**画像出力ルール**のコードの意味を埋め、自分で書く方式なら画像のルールを本文に書きます。方法は[会話に画像を表示する](/create/images-in-chat)にあります。

</details>
