# 旧方式（1.0）について

以前は、作品を7段階の制作画面で作っていました。この方式を<strong>旧方式（1.0）</strong>と呼びます。新しい作品は、下部メニューの**制作**から現在の作品制作画面で作ります。1.0で作った作品は、編集するときに以前の画面が開きます。

## 自分の作品が1.0か見分ける

<ScreenStep src="/img/screens/ja/legacy-editor.webp" alt="旧方式の制作画面。タブの列に基本情報・アセット・導入部・その他の設定・ロアブック・コンポーネントが並び、右下に次へボタンがある" caption="1.0の作品を修正するときに開く画面">

**マイページ → 作品管理**で、作品の**編集**を押してみてください。

- タブの列が**基本情報 · アセット · 導入部 · その他の設定 · ロアブック · コンポーネント · オプション**で、右下に<strong>></strong>（次へ）ボタンがあれば、1.0の作品です。
- タブに**プロンプト**があり、上部に**下書き保存**・**制作完了**（または**変更を反映**）があれば、現在の方式の作品です。

</ScreenStep>

1.0の作品は、自動では現在の方式に変わりません。編集のしかたは[1.0の作品を編集する](/create/legacy/edit)にあります。

## 何が変わったか

いちばん大きな違いは、**AIに渡す設定を書く場所**です。1.0では欄ごとに分けて書くとMYMIがまとめて渡していましたが、現在は**プロンプト**タブで自分で組み立てます。

| | 1.0 | 現在 |
| --- | --- | --- |
| 世界観・キャラクター・秘密 | **基本情報**の欄にそれぞれ | **プロンプト**の作品情報（基本型）またはプロンプト本文（自分で書く） |
| 画像が表す場面 | アセットごとの**状況説明**、キャラクターとの紐付け | アセットのフォルダ・コード + プロンプトのコードの意味（基本型）または画像ルール（自分で書く） |
| 会話に画像を入れる | `img:[slug]` | `![]({{URL}}/A/1.webp)` |
| 作品の代表画像 | アセットで★を付けた1枚 | **基本情報**の**表紙** 1〜10枚 |
| 作品紹介 | **オプション**のHTMLプロフィール | **基本情報**の**詳細説明**（必須） |
| 制作者が残す文章 | **オプション**の制作者からのひとこと | **基本情報**の**クリエイターガイド** |
| コンポーネントをいつ使うか | コンポーネントの**用途の説明** | プロンプトのコンポーネント出力ルール（基本型）または本文（自分で書く） |
| 分類 | **その他の設定**の**ハッシュタグ**（ターゲット読者層を含む） | **基本情報**のジャンル・ハッシュタグ + **その他の設定**の読者層 |
| おすすめペルソナ | **オプション** | **その他の設定** |
| ステップの移動 | 前のステップの必須項目を埋めてから次へ | 好きなタブから。必須項目は**制作完了**のときに確認 |

導入部とロアブックは、どちらの方式にもあります。

## 1.0の作品を現在の方式で作り直したいとき

既存の作品を変換する機能はありません。下部メニューの**制作**で新しい作品を作り、設定を書き写します。新しい作品は別の作品なので、既存の作品の会話・いいね・コメントは移りません。

新しい作品を作っても、既存の1.0の作品はそのまま残ります。既存の作品をこれ以上見せたくないなら、**編集**で開いて**その他の設定**ステップの**公開設定**を**非公開**に変え、**>**（次へ）を押して保存します。

移すときは、世界観と人物の説明だけを移して終わりにしないでください。次のものも一緒に忘れずに移します。

1. **画像の状況説明** → アセットのコードと、プロンプトのコードの意味
2. **コンポーネントの用途の説明** → プロンプトのコンポーネント出力ルール
3. **導入部の`img:[slug]`** → 新しいアセットのコードで入れた画像の行
4. **HTMLプロフィール、制作者からのひとこと** → 詳細説明、クリエイターガイド
5. **以前に入れた会話の例** → プロンプト。今の1.0の画面には表示されませんが、AIには渡されています。新しい作品には移らないので、必要な話し方や例をプロンプトに直接書きます。

項目ごとにどこへ移すかは、[1.0の入力項目と書き方](/create/legacy/reference#現在の方式へ移す)に表でまとめました。

<summary>新しい作品を作ろうとしたのに、以前の7段階の画面が開く</summary>

**作品管理**の**編集**は、その作品を作った方式の画面で開きます。新しい作品は、下部メニューの**制作**で作ります。

</details>

<details>
<summary>1.0の作品を現在の方式に変えるボタンが見つからない</summary>

変えるボタンはありません。新しい作品を作って、設定を書き写す必要があります。[1.0の作品を現在の方式で作り直したいとき](#10の作品を現在の方式で作り直したいとき)に沿って進めてください。

</details>
