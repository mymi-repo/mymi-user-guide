# 1.0の作品を編集する

旧方式（1.0）で作った作品は、以前の7段階の画面で直します。現在の作品制作画面とは項目の場所が違うので、このページに沿って直してください。

## 開き方と移動

1. **マイページ → 作品管理**で、作品の**編集**を押します。
2. **基本情報 → アセット → 導入部 → その他の設定 → ロアブック → コンポーネント → オプション**の順に進みます。
3. 右下の<strong>></strong>（次へ）ボタンを押すと、前のステップの必須項目を確認します。足りないものがあれば案内が表示され、なければここまで直した内容を保存して次のステップへ進みます。
4. タブを押して、直接移動することもできます。先へ進むときは、そのステップの手前までを確認して保存します。前に戻るときは、確認も保存もしません。直した内容は、次に先へ進むときにまとめて保存されます。
5. 最後の**オプション**ステップで**完了**を押すと、すべてのステップをもう一度確認して、完了画面に進みます。

:::warning[公開中の1.0の作品は、先へ進むたびにすぐ変わります]
1.0の画面は、**>**（次へ）やタブで先のステップに進むたびに、直した内容を作品に保存します。すでに公開されている作品なら、その瞬間からほかのユーザーにも変更後の内容が表示されます。現在の方式のように**変更を反映**を押すまで待ってはくれません。大きく直すときは、変える文章を先にメモ帳などに書いておき、貼り付けてから進んでください。
:::

## ステップごとに直すこと

### 1. 基本情報

<ScreenStep>

| 項目 | 書き方 |
| --- | --- |
| 作品名 | 50文字まで |
| 一行紹介 | 40文字まで |
| 世界観 | 時代・場所・状況のような背景 |
| キャラクター | 1人以上。名前と説明。名前は互いに違うものにします |
| 秘密 | 人物が知っておくべき隠し設定（任意） |

世界観・キャラクターの説明・秘密を合わせて、10,000文字まで書けます。これらの欄がAIの読む設定です。

</ScreenStep>

### 2. アセット

<ScreenStep src="/img/screens/ja/legacy-assets.webp" alt="旧方式の制作画面のアセットステップ。画像ごとにimg:AB3K9Xのような名前と状況説明があり、カン・ミヌの画像の星が代表画像としてオンになっている" caption="1.0 · アセット">

- 画像をアップロードするか、**AI画像**で作ります。次のステップに進むには、画像が1枚以上必要です。200枚まで入れられます。
- 画像を押すと**状況説明を入力**ウィンドウが開きます。**キャラクター選択**で画像の中の人物を選び（人物のいない背景のような画像は**共用**）、その人物の名前を入れて状況説明を60文字以内で書いてから、**保存**を押します。AIがどの場面でこの画像を使うかを判断する基準です。
- 画像の左上の<strong>★</strong>ボタンで、作品の代表画像を1枚選びます。
- 画像に付いた`img:AB3K9X`のような表示が、その画像の名前です。名前はMYMIが英大文字と数字の6文字で決めるもので、変更できません。

</ScreenStep>

### 3. 導入部

導入部を1つ以上作り、導入部のタイトルと最初のメッセージを書きます。画像を入れるには、最初のメッセージ欄で入れたい位置にカーソルを置いて、**画像**ボタンを押します。**アセット画像の挿入**ウィンドウで画像を選ぶと、カーソルの位置に`img:[AB3K9X]`のような表示が入ります。**導入部プレビュー**で、画像が正しい位置に表示されるか確認します。

### 4. その他の設定

- **ハッシュタグ**: 作品を説明するタグを選びます。ウィンドウの中の**ターゲット読者層**（男性向け・女性向け）は、必ず選びます。
- **公開設定**: 公開か非公開を選びます。
- **作品の公開範囲**: **オリジナル**（MYMI独占公開）か**一般**を必ず選びます。オリジナルにした作品は、3か月間この項目がロックされ、解除できるまでの残り日数が表示されます。
- **画像出典**: **MYMI生成**か**外部制作**を必ず選びます。
- **画像出力指示**: **内部画像**は、アップロードした画像を`img:[slug]`で出力し、**外部画像**は、設定に書いた画像のアドレスで出力します。画面の案内どおり、どちらか一方の方式だけを使います。
- **コンテンツレーティング**: **成人向け**か**全年齢対象**を選びます。

### 5〜7. ロアブック · コンポーネント · オプション

| ステップ | 書き方 |
| --- | --- |
| **ロアブック** | **エントリー追加**で、エントリー名・トリガーキーワード・内容を埋めます。現在の方式の[ロアブック](/create/lorebook)と同じやり方で探して渡します。 |
| **コンポーネント** | コードと**用途の説明**を埋めます。用途の説明には、いつどんな値で呼び出すかを書きます。 |
| **オプション** | プロフィールデザイン（HTML）、おすすめペルソナ、制作者からのひとことを設定します。おすすめペルソナを追加したなら、**ニックネーム**（20文字）・**性別**・**生年月日**・**詳細情報**（1,000文字）を埋めます。 |

## つまずいたときは

<details>
<summary>次のステップに進めない</summary>

前のステップに、足りない必須項目があります。上部に表示された案内を確認してください。アセットステップなら、画像が1枚以上あるか、画像ごとに状況説明があるかを見ます。その他の設定なら、**ターゲット読者層**・**作品の公開範囲**・**画像出典**を選んだかを見ます。

</details>

<details>
<summary>導入部プレビューに「画像が見つかりません」と表示される</summary>

`img:[…]`のかっこの中の名前と同じ画像が、アセットにありません。アセットステップでその画像を削除していないか、かっこの中の名前が画像に付いた表示と同じか確認します。名前を直接入力せず、その行を削除してから**画像**ボタンでもう一度入れれば、間違えません。

</details>

<details>
<summary>編集画面にプロンプトタブがない</summary>

1.0の作品だからです。1.0の作品は、現在の方式の画面では開きません。現在の方式で作りたいときは、[旧方式（1.0）について](/create/legacy/overview#10の作品を現在の方式で作り直したいとき)をお読みください。

</details>
