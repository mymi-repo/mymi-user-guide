# チャットルームの設定

チャットルームでAIの返信のしかたと画面の表示を変える方法と、これまでの会話を読み直したり探したりする方法を説明します。

## ボタンの場所

チャットルームの右上にアイコンが3つあります。

| アイコン | 押すと |
| --- | --- |
| 目 | 会話の文字を隠して画像だけを見ます。もう一度押すと戻ります |
| パレット | **UI設定**が開きます。表示方法、文字の大きさ、色を変えます |
| ⋮ | **チャットルーム管理**が開きます。このページの設定はほとんどここにあります |

**チャットルーム管理**のいちばん上には、残りのスパークが表示されます。ログインしていない場合は**残り無料体験回数**が表示されます。押すとチャージ画面かログイン画面に進みます。

## AIの返信のしかたを変える

⋮メニューの**チャット設定**で変えます。変えた設定は次の返信から反映されます。

| 設定 | できること |
| --- | --- |
| **文体スタイル** | **小説型**は描写や地の文が豊かで、**ラノベ型**は軽快でセリフが中心です |
| **ストーリーブースター** | オンにすると、AIが積極的に出来事を起こし、展開が速くなります |
| **なりすまし許可** | オンにすると、AIが自分の行動やセリフまで書きます。自分の行動は自分で書きたい場合はオフにしてください |
| **ワンカット** | オンにすると、画像が出る作品で返信ごとに画像が1枚だけ表示されます。文章の量は変わりません |
| **最大出力量** | より長い返信を受け取れます。スパークが多くかかることがあるので、[長い返信を受け取る](/chatting/ai-models.md#長い返信を受け取る)に別にまとめました |

:::info[この設定はすべてのチャットルームに適用されます]
上の5つは、今使っているブラウザーやアプリに保存され、ほかのチャットルームにも同じように適用されます。別の端末では選び直す必要があります。チャットルームごとに保存されるのは、下の**ユーザーノート**と**ペルソナ**です。
:::

## ユーザーノートとペルソナ

このチャットルームにだけ保存される設定です。別の端末で開いてもそのままです。

**ユーザーノート**には、キャラクターとの関係、背景、必ず覚えておいてほしい設定を2,000文字まで書けます。⋮メニューの**チャット設定 → ユーザーノート**で書いて**保存**を押すと、AIはこのチャットルームで返信するたびに参考にします。

```text
私はソヨンの幼なじみで、お互いタメ口で話す。
先週大げんかをして、まだ気まずい。
```

**ペルソナ**は、このチャットルームで使う自分の名前と役割です。⋮メニューの**チャット設定 → ペルソナ**でその場で直すか、**読み込み**で自分のペルソナ一覧から1つ選んで**保存**します。

一覧でペルソナを直しても、すでにあるチャットルームには反映されません。そのチャットルームでもう一度読み込んで**保存**してください。ペルソナの作り方は[ペルソナ設定](/account/persona.md)にあります。

## 最初から読み直す

1. ⋮メニューで**最初から読む**を押します。
2. 最初の場面から順に読みます。読んでいるあいだは入力欄の場所に**最初から読んでいます**と表示され、メッセージを送ったり直したりはできません。
3. 読み終わったら**会話に戻る**を押します。書きかけの文章はそのまま残っています。

## 以前のチャットルームを探す

同じ作品で新しい会話を始めた場合、以前のチャットルームはここにあります。

1. ⋮メニューで**過去のチャットを見る**を押します。
2. チャットルームを押すと、**最後の会話**と一緒に**続ける**、**非表示にする**、**削除**が表示されます。
3. **続ける**を押すと、そのチャットルームに移動します。

非表示にしたチャットルームは、**過去のチャット**画面の右上にある目の形のアイコンを押して、**非表示のチャット**で探します。チャットルームを押して**非表示を解除**を押すと、また表示されます。

:::danger[削除したチャットルームは元に戻せません]
削除する前に、画面に表示される**最後の会話**で、どのチャットルームか確認してください。
:::

## ブックマークと分岐

気に入った地点を保存しておき、あとからその地点の続きを新しいチャットルームで別の展開にできます。

1. AIの返信の下にあるしおりのアイコン（**ブックマークを追加**）を押します。
2. 必要なら名前を入力して**保存**します。名前は50文字まで書けて、空欄のままでもかまいません。
3. あとで⋮メニューの**ブックマーク一覧**から、保存した地点を探します。
4. その地点からやり直すには、枝分かれの形のアイコン（**この時点から分岐する**）を押し、**確認**を押します。その地点までの会話が入った新しいチャットルームが開き、元のチャットルームはそのまま残ります。ユーザーノートとペルソナも新しいチャットルームに引き継がれます。

:::warning[ブックマークした返信は直せなくなります]
ブックマークを保存すると、その返信とそれより前のメッセージは、再生成・編集・削除ができなくなります。ブックマークを消しても元には戻りません。最後の返信を直すつもりなら、先に直してからブックマークしてください。
:::

ブックマーク一覧のゴミ箱アイコン（**ブックマーク削除**）は、ブックマークだけを消します。消したブックマークは元に戻せません。

## 会話をキャプチャする

1. ⋮メニューで**会話キャプチャ**を押します。
2. 含めたい最初のメッセージを押します。複数入れる場合は、最後のメッセージも押して範囲を決めます。
3. 自分のメッセージを除くには、**自分のセリフを除いてキャプチャ**（アプリは**自分のセリフを除外**）をオンにします。
4. ウェブは**画像をダウンロード**、アプリは**画像を保存**を押します。

アプリでは、写真へのアクセス許可を求められたり、共有画面が開いたりすることがあります。画面の案内に従って保存先を選んでください。やめるときは**キャンセル**を押します。

## 文字と表示を変える

チャットルーム右上のパレットアイコンを押すと、**UI設定**が開きます。

| まとまり | 変えられるもの |
| --- | --- |
| 表示 | **UIモード**：**小説**、**チャット**、**1:1** |
| 読みやすさ | **文字サイズ**、**行間**、**フォント**、**ストリーミング速度**（文字が表示される速さ） |
| 色 | **文字の色**：キャラクターのセリフ、ユーザーのセリフ、キャラクターのト書き、ユーザーのト書き |
| 画面 | **チャットの高さ**、**チャット欄の透明度**、**画像の高さ**（小説）、**キャラクター名を表示**（チャット） |
| 動画 | **動画のループ再生**、動画の代わりに画像を表示する**画像モード** |

- 設定は表示方法ごとに別々に保存されます。**リセット**は、今の表示方法だけを初期値に戻します。
- 今使っているブラウザーやアプリに保存され、すべてのチャットルームに適用されます。

## つまずいたときは

<details>
<summary>会話の文字が消えて画像だけが表示される</summary>

チャットルーム右上の目のアイコンをもう一度押すと、文字が戻ります。

</details>

<details>
<summary>設定を変えたら、ほかのチャットルームも変わった</summary>

**チャット設定**の文体スタイル・ストーリーブースター・なりすまし許可・ワンカット・最大出力量と、**UI設定**は、この端末のすべてのチャットルームに適用されます。チャットルームごとに変えたい内容は**ユーザーノート**に書いてください。

</details>

<details>
<summary>読み込んだペルソナが反映されない</summary>

**読み込み**でペルソナを選んだあと、**保存**まで押すと、このチャットルームに反映されます。

</details>

<details>
<summary>返信を再生成したり直したりできない</summary>

ボタンは、いちばん最後のAIの返信にだけあります。ブックマークした返信とそれより前のメッセージも直せません。「分岐した会話が参照しているため、編集・削除できません。」と表示される場合は、ブックマークが原因です。

</details>

<details>
<summary>以前のチャットルームが見つからない</summary>

⋮メニューの**過去のチャットを見る**で探します。非表示にしたチャットルームは、その画面の右上にある目の形のアイコンを押して**非表示のチャット**で探します。作品ごと非表示にした場合は、[よくある質問](/faq/faq.md)の「チャットルームが消えました」を確認してください。

</details>

<details>
<summary>このチャットルームの問題を問い合わせたい</summary>

⋮メニューの**チャットルームIDをコピー**でIDをコピーし、何が起きたかと一緒に、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)へお送りください。

</details>
