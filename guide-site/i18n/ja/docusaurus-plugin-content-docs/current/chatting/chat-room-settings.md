# チャットルームの設定

チャット画面**右上の⋮ボタン**を押すと、ルーム管理と会話設定が開きます。隣の**パレットアイコン**を押すと、文字、色、表示方法を変えるUI設定が開きます。

## 1. チャットルーム管理を開く

会話中に右上の⋮を押すと、横からチャットルーム管理メニューが開きます。上部には、ログイン中のアカウントのスパーク残高、またはゲストの体験残り回数が表示されます。この部分を押すと、アカウントの状態に応じてチャージ画面またはログイン案内に進みます。

**チャット管理**には次の項目があります。

- **新しいチャットを開始：** 現在の作品の詳細画面に移動します。そこでイントロとペルソナを選び、**新しい会話を始める**を押すと別のルームが作られます。
- **過去のチャットを見る：** 同じ作品のチャットルーム一覧を開きます。ルームを選ぶと最後のメッセージを確認し、**続ける**を選べます。一覧から**非表示にする**、**削除**もできます。
- **チャットルームIDをコピー：** 現在のルームIDをクリップボードにコピーします。特定のルームについて問い合わせるときに使ってください。
- **会話キャプチャ：** 選択したメッセージ範囲を画像にします。手順は下の6番を参照してください。
- **ブックマーク一覧：** 保存したブックマークを確認し、分岐の作成やブックマークの削除を行います。

ルームを**非表示にすると**、非表示のチャット一覧から再表示できます。**削除すると**会話は完全に削除されます。確認画面で対象のルームを確認してください。

## 2. 会話の設定を変更する

**⋮ → チャット設定**を開いて変更すると、今後の会話に反映されます。

### ユーザーノートとペルソナ

- **ユーザーノート：** キャラクターとの関係、背景、話し方、覚えてほしい状況などを**2,000文字以内**で書き、**保存**すると、このルームでAIが参照します。
- **ペルソナ：** このルームで使う自分の名前と役割を編集します。自分の一覧にある設定を使う場合は、**読み込み → ペルソナを選択 → 保存**の順に進むと、このルームに適用されます。詳しくは[ペルソナ設定](/account/persona.md)を参照してください。

### 文体と応答方法

- **文体スタイル：** **小説型**は描写と叙述が豊かな文体、**ラノベ型**は会話が中心の軽快な文体です。下記の**UIの小説モード**は画面の表示方法なので、文体スタイルとは別の設定です。
- **ストーリーブースター：** オンにすると、AIが出来事や展開をより積極的に提案します。
- **なりすまし許可：** オンにすると、AIが自分の行動やセリフも描写できるようになります。自分の行動は自分で書きたい場合はオフにしてください。
- **ワンカット：** オンにすると、1回の応答で1つの場面ずつ進めます。
- **最大出力量：** ログイン中のアカウントでは、モデルごとの応答の最大長を選べます。追加の使用量に関する案内が表示される場合は、画面の条件を確認してください。


## 3. 長期記憶と記憶の断片を見る

**⋮ → 記憶管理**には、役割の異なる2つの画面があります。

- **長期記憶：** 会話全体の流れをまとめた内容を確認します。会話が十分に蓄積されていない場合、まだ内容がないという案内が表示されることがあります。
- **記憶の断片：** 会話で記録された重要な瞬間を一覧で見たり、検索したりします。この画面上部の**記憶の断片を使用**で、今後の会話に記憶の断片を使うか選びます。

## 4. 文字と画面表示を変更する

チャット画面右上の**パレットアイコン → UI設定**を開きます。

- **UIモード：** **チャット / 1:1 / 小説**から選びます。どのモードでも、同じ会話履歴を違う形式で読めます。
- **読みやすさ：** 文字サイズ、行間、チャットの高さ、チャット欄の透明度、ストリーミング速度を調整します。ストリーミング速度は操作が有効な場合に変更できます。
- **フォント・色：** フォントと、キャラクター・ユーザーのセリフやト書きの色を選びます。**キャラクター名を表示**はチャットモード、**画像の高さ**は小説モードで設定できます。
- **動画設定：** **動画のループ再生**と、動画の代わりに画像を表示する**画像モード**を選びます。
- **リセット：** 現在選択中のUIモードの表示設定を初期値に戻します。

UI設定は**現在使用しているブラウザーまたはアプリに保存**され、別のルームにも適用されます。別の端末では表示設定をもう一度選んでください。

## 5. ブックマークと分岐を作る

1. 会話中、残したい地点のメッセージ操作から**ブックマークアイコン**を押します。
2. 必要なら**50文字以内**でラベルを付けます。ラベルは任意です。
3. 注意書きを読んで**保存**します。
4. 後から「⋮ → ブックマーク一覧」を開き、保存した地点を探します。
5. 別の展開を試す場合は、そのブックマークの**分岐アイコン → 確認**を押します。その地点から新しいルームが開き、元の会話は残ります。

> **保存前に確認してください。** ブックマークを保存すると、**その地点より前のメッセージ**は編集・削除・再生成できなくなります。修正したい内容があれば、先に直してください。

ブックマーク一覧の削除アイコンは、**ブックマークを削除する操作**です。分岐と取り違えないように確認してください。

## 6. 会話をキャプチャする

1. **⋮ → 会話キャプチャ**を選びます。
2. キャプチャする最初のメッセージを押します。複数を含める場合は最後のメッセージも押して範囲を指定します。1件だけなら1回の選択で十分です。
3. 自分のメッセージを除く場合は、画面下部の**自分のセリフを除いてキャプチャ**（ウェブ）または**自分のセリフを除外**（アプリ）をオンにします。
4. 選択件数を確認し、ウェブでは**画像をダウンロード**、アプリでは**画像を保存**を押します。

ウェブでは画像ファイルがダウンロードされます。アプリではOSによって写真へのアクセス許可や共有画面が表示される場合があるため、画面の案内に従ってください。キャプチャするメッセージを1件以上選び、やめる場合は**キャンセル**を押します。

## 思った結果にならないとき

- 別のルームを作るには、**新しいチャットを開始 → 作品詳細でイントロとペルソナを選択 → 新しい会話を始める**の順に進みます。
- 読み込んだペルソナをこのルームに適用するには、**保存**を押します。
- 記憶の画面が空なら、会話を続けてからもう一度確認します。
- 応答の文体を変えるには、**⋮ → 文体スタイル**を選びます。
- 過去のルームが見つからない場合は、**過去のチャットを見る**にある非表示のチャット一覧も確認します。

最初の会話を始める手順は[会話する](/chatting/chat-with-character.md)を参照してください。
