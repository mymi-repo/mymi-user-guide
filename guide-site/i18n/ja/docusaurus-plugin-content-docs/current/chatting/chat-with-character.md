# 会話する

MYMIでは、気になる作品を見つけてから、どの場面から始めるか（イントロ）と、作品の中で自分が誰になるか（ペルソナ）を決めて会話できます。一人のキャラクターと話す作品でも、複数の登場人物がいる作品でも、基本的な開始手順は同じです。

> **以前に会話した作品なら：** **前の会話を続ける**は既存のチャットルームに戻ります。**新しい会話を始める**は、現在選んでいるイントロとペルソナで別のルームを作ります。違う始まり方を試すときは、**新しい会話を始める**を選んでください。

## 1. 会話する作品を探す

ホームでは、次のタブから作品を探せます。

- **おすすめ：** 自分に合ったおすすめ、新作、人気作品などを見ます。
- **ランキング：** リアルタイム・日間・週間・月間の順位から探します。
- **タグ：** ジャンル・関係・設定・性格・種族などのタグを最大3個組み合わせて探します。
- **検索：** キーワードで探すか、**@クリエイター名**を入力してクリエイターを検索します。関連度・新着・人気順などに並べ替えられます。

作品の性別フィルターには**すべての性別 / 女性/その他 / 男性/その他**があります。表示する作品を絞る機能であり、自分のペルソナを変えるものではありません。作品が見つからないときは、検索語、タグの組み合わせ、性別フィルターを変えてみてください。

成人向け作品の表示や利用可否は、セーフティフィルターとアカウントの確認状態によって変わります。アクセスの案内が出た場合は、[成人・本人確認](/account/adult-verification.md)を確認してください。

## 2. 作品詳細で開始地点を確認する

作品カードを押すと、詳細画面で紹介、登場人物、クリエイターが提供した情報などを見られます。**イントロ**欄が表示されている場合は、現在選択されている最初の場面を読んでください。複数のイントロがあれば、選択欄を開いて別の開始場面を選べます。変更しなければ、最初に表示されたイントロが使われます。

| 選択項目 | 決めること |
| --- | --- |
| **イントロ** | 新しい会話の開始場面と最初に表示される内容 |
| **ペルソナ** | キャラクターと会話する**自分の名前と役割** |

イントロは作品の開始地点、ペルソナは自分の役割です。どちらも**新しいチャットルームの作成時**に反映されます。詳細画面で選択だけを変えても、作成済みのルームは変わりません。

## 3. 自分の役割（ペルソナ）を選ぶ

1. 作品詳細の下部で、**会話開始ボタンの横にある小さなプロフィールボタン**を押します。
2. **マイペルソナ**から使う役割を選びます。クリエイターが用意している場合は、**おすすめペルソナ**も選べます。
3. **選択完了**を押し、会話開始ボタンの横に表示された役割を確認します。

メインのペルソナがある場合は、最初に優先して選択されます。おすすめペルソナがない作品では、その選択肢が表示されないことがあります。役割の追加や既存ルームでの変更は、[ペルソナ設定](/account/persona.md)を参照してください。

## 4. 初めての会話を始める

1. 作品詳細で**イントロ**と**ペルソナ**を確認します。
2. 下部の**会話を始める**を押します。
3. 新しいルームに、選んだイントロの開始場面が表示されているか確認します。
4. 画面下部の入力欄に行動やセリフを書き、**送信**ボタンを押します。

たとえば「ドアを開けて中に入る」と行動を書いたり、「ここで何があったのですか？」と話しかけたりできます。作品の設定と最初の場面を読んでから始めると、状況に合った会話を続けやすくなります。

> 成人向け作品にはログインや年齢確認が必要な場合があります。送信時に、選択中のモデル、利用可能回数、保有スパークについて案内が出たら、その内容を確認してください。

## 5. 前の会話を続けるか、新しく始めるか

すでに会話した作品の詳細画面には、2つのボタンが表示されます。

- **前の会話を続ける：** 既存のルームに戻り、その会話履歴を続けます。詳細画面で新たに選んだイントロやペルソナで既存ルームは変わりません。
- **新しい会話を始める：** 同じ作品で別のルームを作ります。現在選んでいるイントロとペルソナで始まります。

**新しい会話を始めても、前の履歴は削除されません。** 別のイントロや役割で同じ作品を体験したいときに利用してください。既存ルームのペルソナだけを変える場合は、そのルームの中で編集して保存します。

## 6. チャット画面を読む・操作する

チャット画面の UI 設定（パレットアイコン）で表示方法を切り替えられます。表示を変えても会話履歴はそのままです。

| 表示方法 | 特徴 |
| --- | --- |
| **チャット** | メッセージを吹き出し形式で読む |
| **1:1** | メッセージを一つずつ大きく表示し、前後に移動する |
| **小説** | 地の文とセリフを続き物の文章として読む |

操作可能なメッセージには、**再生成**、**編集**、**削除**などが表示されます。再生成で別の返答を求められ、候補が複数ある場合は矢印で確認できます。編集した内容は保存して反映し、削除は確認してから実行します。最初の場面や保護されたメッセージでは、一部の操作が表示されないことがあります。

表示方法、モデル、ペルソナなど、ルーム内の設定については[チャットルームの設定](/chatting/chat-room-settings.md)を参照してください。

## 会話を始められないとき

| 状況 | 確認すること |
| --- | --- |
| 開始ボタンを押せない | ペルソナの読み込み中でないか確認し、プロフィールボタンから役割を選んでみてください |
| 成人向け作品を開けない | ログイン状態と[成人・本人確認](/account/adult-verification.md)の状態を確認してください |
| メッセージを送信できない | 接続状態、入力内容、モデル・利用可能回数・スパークに関する画面の案内を確認してください |
| 作品が見つからない | 検索語を変え、タグ・性別・セーフティフィルターを確認してください |
