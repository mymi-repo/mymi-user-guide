# 会話する

作品を選んで最初の会話を始め、返信が気に入らないときに作り直し、あとで会話を続ける方法を順に説明します。

:::info[会話にはスパークを使います]
AIの返信を1回受け取るたびに、選んだモデルの価格分のスパークが消費されます。最初は**Gemini 3.1 Pro**が選ばれていて、入力欄の左にある⚡ボタンで別のモデルに変えられます。モデルごとの価格は[AIモデルガイド](/chatting/ai-models.md)にあります。

ログインしていない場合は、5回まで無料で会話を試せます。
:::

## 作品を選ぶ

**ホーム**上部のタブで作品を探します。

| タブ | 探し方 |
| --- | --- |
| **おすすめ** | おすすめの作品をまとめて見ます |
| **ランキング** | リアルタイム・日間・週間・月間の順位から選びます |
| **タグ** | ジャンル・関係・設定・性向・種族のうち1つの分類で、タグを3個まで選んで探します |
| **検索** | 雰囲気やキーワードで探します。`@ニックネーム`または`@ID`を正確に入力すると、そのクリエイターの作品が表示されます |

- 初めて開くと「主に見たいキャラクターを選んでください」という画面が出ます。**女性キャラクター**、**男性キャラクター**、**すべて見たい**から選ぶと、そのキャラクターが登場する作品を中心に表示します。選んだ内容は、各タブの性別設定からいつでも変えられます。
- セーフティフィルターがオンのあいだは、成人向け作品は表示されません。セーフティフィルターは、ホームのタブ列の右端にある盾の形のスイッチです。オフにするには年齢確認（18歳以上）が必要です。[年齢確認・電話番号認証](/account/adult-verification.md)を確認してください。

## 始まりの場面と自分の役を決める

作品カードを押すと作品詳細が開きます。

1. 紹介と登場人物を読みます。
2. **イントロ**で始める場面を選びます。イントロが複数ある場合は、押して別の場面に切り替えられます。選ばなければ最初のイントロから始まります。
3. 画面下の**会話を始める**の右にある小さなプロフィールアイコンを押します。
4. **マイペルソナ**か、クリエイターが用意した**おすすめペルソナ**から1つ選び、**選択完了**を押します。アイコンが選んだペルソナの画像（画像がなければ名前の最初の文字）に変わります。

ペルソナは、作品の中で使う自分の名前と役割です。最初はメインのペルソナが選ばれています。作成や編集の方法は[ペルソナ設定](/account/persona.md)にあります。

## 最初のメッセージを送る

1. **会話を始める**を押すと新しいチャットルームが開き、イントロの場面が表示されます。
2. 画面下の入力欄に、自分のセリフや行動を書きます。1回に1,000文字まで書けます。
3. 入力欄の右端にある↑ボタンを押して送信します。パソコンではEnterで送信、Shift+Enterで改行します。
4. 少し待つと、キャラクターが返信します。

行動をアスタリスク（`*`）で囲むと、セリフとは別の色で表示されます。入力欄の右にある✱ボタンを押すと、アスタリスクが入ります。

```text
*ドアを開けて中に入る* ここで何があったんですか？
```

:::tip[言うことが思いつかないとき]
入力欄を空にしたまま↑ボタンを押し、「空メッセージを送信」の画面で**進む**を押してください。キャラクターが話を進めます。この場合も返信1回分のスパークを使います。
:::

## 返信が気に入らないとき

いちばん最後のAIの返信の下に、ボタンが3つあります。

| ボタン | できること |
| --- | --- |
| 丸い矢印（**再生成**） | 同じメッセージで新しい返信を受け取ります。スパークをもう一度使います |
| 鉛筆（**メッセージを編集**） | 返信の内容を自分で直して**保存**します |
| ゴミ箱（**メッセージを削除**） | 返信を削除します。その返信のもとになった自分のメッセージも一緒に削除されます |

- 再生成して返信が複数になったら、‹ › で切り替えて気に入った返信を選べます。切り替えるだけならスパークは使いません。
- これらのボタンは、いちばん最後のAIの返信にだけあります。それより前の返信や自分が送ったメッセージは直せないので、流れを変えたいときは次のメッセージで伝えてください。
- ブックマークした返信も直せません。詳しくは[ブックマークと分岐](/chatting/chat-room-settings.md#ブックマークと分岐)にあります。
- **1:1**表示では、同じボタンが**再生成**、**内容を編集**、**削除**という文字で表示されます。

:::warning[削除は元に戻せません]
返信を削除すると、その返信のもとになった自分のメッセージも一緒に削除され、復元できません。返信だけを変えたい場合は**再生成**を使ってください。
:::

## 表示方法を変える

最初は**小説**表示で開きます。チャットルーム右上のパレットアイコンを押し、**UI設定**の**UIモード**で切り替えます。どの表示を選んでも同じ会話です。

| 表示 | 見え方 |
| --- | --- |
| **小説** | 地の文とセリフをひと続きの文章として読みます |
| **チャット** | 吹き出しでやりとりします |
| **1:1** | 画像を背景に1段落ずつ進めます（**前へ**・**次へ**） |

文字の大きさや色は[チャットルームの設定](/chatting/chat-room-settings.md#文字と表示を変える)で変えます。

## あとで会話を続ける

- 下のメニューの**チャット**を押すと、会話した作品が表示されます。作品を押すと、いちばん最近会話したチャットルームが開きます。
- 作品詳細の**前の会話を続ける**も、いちばん最近会話したチャットルームを開きます。
- 最初からやり直したいときは、作品詳細でイントロとペルソナを選んでから**新しい会話を始める**を押します。新しいチャットルームができ、元のチャットルームはそのまま残ります。
- 同じ作品の以前のチャットルームは、チャットルーム右上の⋮メニューの**過去のチャットを見る**から選びます。方法は[以前のチャットルームを探す](/chatting/chat-room-settings.md#以前のチャットルームを探す)にあります。

## つまずいたときは

<details>
<summary>入力欄がロックされ「スパークが不足しています」と表示される</summary>

残りのスパークが、今のモデルの価格より少なくなっています。画面の**チャージする**を押すか、入力欄の左にある⚡ボタンで安いモデルに変えてみてください。無料でもらう方法は[スパークのチャージ](/payment/payment-methods.md#4-無料でスパークをもらう)にあります。

</details>

<details>
<summary>「クレジットが不足しています」と表示されて送信できない</summary>

最大出力量を基本より高くしている場合、送信時にその分を先に消費します。⋮メニューの**最大出力量**を**基本**に下げると送信できます。詳しくは[長い返信を受け取る](/chatting/ai-models.md#長い返信を受け取る)にあります。

</details>

<details>
<summary>「無料体験が終了しました！」と表示される</summary>

ログインせずに使える5回を使い切りました。**再生成**も1回に数えます。ログインすると会話を続けられます。体験していた画面からそのまま新規登録すると、体験した会話を新しいアカウントで続けられます。

</details>

<details>
<summary>「モデルが応答を拒否しました」と表示される</summary>

これまでの会話や記憶に不適切な内容がたまると、直前のメッセージに問題がなくてもモデルが返信を拒否することがあります。**削除して続ける**を押してから、表現を変えるか内容を控えめにして送り直してください。拒否された返信は、基本価格の20%だけが消費されます。

</details>

<details>
<summary>「現在選択されているモデルは利用できません。」と表示される</summary>

**モデルを選択**を押して別のモデルを選ぶと、会話を続けられます。

</details>

<details>
<summary>会話を始めるボタンが押せない</summary>

まだペルソナが選ばれていません。ボタンの右にあるプロフィールアイコンを押して、ペルソナを選んでください。

</details>

<details>
<summary>成人向け作品に入れない</summary>

ログインして、年齢確認（18歳以上）を済ませる必要があります。電話番号認証だけでは成人向け作品は開けません。[年齢確認・電話番号認証](/account/adult-verification.md)を確認してください。

</details>

それでも解決しないときは、チャットルームの⋮メニューの**チャットルームIDをコピー**でIDをコピーし、何が起きたかと一緒に、**マイページ → Discord**からDiscordのお問い合わせチャンネルで、または[contact@mymi.live](mailto:contact@mymi.live)へお送りください。
