# 長期記憶と記憶の断片

会話が長くなると、MYMIはこれまでの流れを**長期記憶**に要約し、重要な出来事を**記憶の断片**にまとめます。チャットルームの「⋮ → 記憶管理」から別々に確認できます。

## 何が違いますか？

- **長期記憶：** 会話全体の流れや関係・出来事を短くまとめたものです。
- **記憶の断片：** 大切な瞬間を個別のカードにまとめたものです。タイトル、関連人物、会話のターン範囲が表示されることがあります。カードを押すと詳しい内容を開けます。
- **ユーザーノート：** **自分で書いて保存する**メモです。AIに覚えておいてほしい名前、関係、約束、話し方などを書いておきましょう。

長期記憶と記憶の断片は、会話が進むにつれて自動で作られます。まだ表示されない場合は、会話を続けてからもう一度確認してください。

## 1. 長期記憶を確認する

1. チャット画面右上の⋮を押します。
2. **記憶管理 → 長期記憶**を選びます。
3. 会話の要約を読みます。**まだ長期記憶がありません**と表示されたら、会話を続けてからもう一度確認してください。

## 2. 記憶の断片を探す

1. チャット画面右上の⋮から**記憶管理 → 記憶の断片**を選びます。
2. タイトル、関連人物、ターン範囲を見ながらカードを探します。**T10–T20**のような数字は会話のターン範囲です。
3. カードを押すと内容が開き、もう一度押すと閉じます。
4. 上部の検索欄に出来事・人物・状況を入力すると、**関連する断片**を探せます。検索語を消すと全件表示に戻ります。
5. 下にスクロールして続きを確認します。アプリでは**さらに読み込む**が表示されたら押してください。

検索では意味が近い内容も探せます。別の結果を探す場合は、人物や出来事を変えて検索するか、会話を続けてからもう一度試してください。

## 3. 記憶の断片の使用を切り替える

ログイン後、記憶の断片画面の上部にある**記憶の断片を使用**をオンにすると、以降の返答で関連する断片を参照します。アプリでは同じスイッチが**記憶を使用**と表示されます。オフにすると、断片を使わずに返答を作ります。

- すでに作られた断片は一覧に残り、再びオンにすると使えます。
- 長期記憶は別に会話の流れを要約します。
- ルームやアプリ・ブラウザーを開き直したときは、スイッチの状態を確認してください。

## 大切な設定を覚えてもらうには

例えば、**2人が仲直りしたという大きな流れ**は長期記憶に、**そのとき交わした具体的な約束**は記憶の断片に現れることがあります。その約束を今後も守ってほしい場合は、**ユーザーノート**に明記するほうが確実です。[チャットルームの設定](/chatting/chat-room-settings.md)からノートを開いて保存できます。

AIが以前の出来事を取り違えたら、このルームの長期記憶と記憶の断片を確認してください。大切な設定はユーザーノートに書くか、次のメッセージではっきり伝えてください。
