# 長期記憶と記憶の断片

会話が長くなると、AIが前の部分を見落とすことがあります。キャラクターが前のことを忘れたときに確認する場所と、直し方を説明します。

## キャラクターが前のことを忘れたとき

1. ⋮メニューの**記憶管理 → 記憶の断片**で、**記憶の断片を使用**がオンになっているか確認します。
2. **記憶管理 → 長期記憶**で、これまでの流れがどうまとめられているか見ます。
3. 間違って覚えている内容や抜けている内容は、⋮メニューの**チャット設定 → ユーザーノート**に正しい内容を書いて**保存**します。
4. 次のメッセージで一度触れるのも効果的です。例：「前に約束した場所、覚えてる？」

:::info[記憶は直接編集できません]
長期記憶と記憶の断片は会話から自動で作られ、自分で編集したり削除したりはできません。直したい内容はユーザーノートに書いてください。
:::

## 3種類の記憶

| 種類 | 内容 | 作るのは |
| --- | --- | --- |
| **長期記憶** | これまでの会話の大きな流れを短くまとめた文章 | 会話がたまると自動で |
| **記憶の断片** | 大切な瞬間を1つずつまとめたカード | 会話がたまると自動で |
| **ユーザーノート** | 必ず覚えておいてほしい設定を書いたメモ | 自分 |

たとえば、2人が仲直りしたという大きな流れは長期記憶に、仲直りしたときの約束は記憶の断片に残ります。その約束を必ず守ってほしいなら、ユーザーノートに書いておいてください。

## 長期記憶を見る

1. ⋮メニューで**記憶管理 → 長期記憶**を押します。**メモリー**画面の**長期記憶**タブが開きます。
2. **これまでの物語**で、まとめられた流れを読みます。

いちばん上で、次のあらすじ整理まであと何回会話するかを確認できます。AIは返信のたびにこのあらすじを読み、会話10回ごとに続きをまとめ直します。

「まだ書かれた物語がありません」と表示されたら、もう少し会話してみてください。会話を10回交わすと、最初のあらすじが作られます。

## 記憶の断片を探す

1. ⋮メニューで**記憶管理 → 記憶の断片**を押します。**メモリー**画面の**記憶の断片**タブが開きます。
2. **相関図**の円は人物、小さなひし形は記憶の断片です。断片を押すと、内容がカードで開きます。人物を押すと、その人物の記憶だけが表示されます。自分のペルソナには**自分**が付きます。
3. 2本の指で広げるか、**＋ボタン**を押して拡大すると、断片の横にタイトルが表示されます。ドラッグで動かし、**全体を表示**を押すと元の大きさに戻ります。PCではマウスホイールでも拡大できます。
4. **最近思い出した記憶**には、AIが最後の返信で思い出した断片が表示されます。
5. 相関図には最新の24件だけが表示されます。すべて見るには**リスト**を押し、断片が多いときは**さらに読み込む**を押します。
6. 上の検索欄に場面や名前を入力すると、関係する断片を探せます。意味が近い内容も見つけます。

## 記憶の断片をオフにする

**記憶の断片**タブのいちばん上にある**記憶の断片を使用**は、最初からオンになっています。オフにすると、そのチャットルームにいるあいだは記憶の断片を使わずに返信します。長期記憶とユーザーノートは引き続き参考にします。

- AIが的外れな記憶の断片を何度も持ち出すときは、しばらくオフにしてみてください。
- チャットルームを出てまた入ると、オンに戻っています。
- ログインしていない体験中は、記憶の断片を使いません。

## つまずいたときは

<details>
<summary>「まだ書かれた物語がありません」と表示される</summary>

まだ会話が少ないためです。会話を10回交わすと、最初のあらすじが作られます。**長期記憶**タブのいちばん上で、あと何回会話するかを確認できます。

</details>

<details>
<summary>記憶の断片を検索しても出てこない</summary>

別の人物の名前や出来事で検索し直してみてください。最近の会話は、まだ断片にまとめられていないことがあります。

</details>

<details>
<summary>間違った記憶を消したい</summary>

記憶は消せません。正しい内容を**ユーザーノート**に書いて**保存**してください。間違った記憶の断片をAIが何度も持ち出すなら、**記憶の断片を使用**をしばらくオフにしてみてください。

</details>

<details>
<summary>オフにした記憶の断片がまたオンになっている</summary>

チャットルームに入るたびにオンに戻ります。必要なときに、そのつどオフにしてください。

</details>
