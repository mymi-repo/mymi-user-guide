# 長期記憶と記憶の断片

会話が長くなると、MYMIはこれまでの流れを**長期記憶**に要約し、重要な出来事を**記憶の断片**にまとめます。チャットルームの「⋮ → 記憶管理」から別々に確認できます。V1作品とV2作品でチャットの記憶機能は同じです。

> **作品の設定とは別です。** V1の世界観・キャラクター設定やV2のプロンプト・ロアブックは、制作者が作品の編集画面で管理します。このページの記憶は、読者が作品内で進めた**会話の内容**から作られます。

## 何が違いますか？

- **長期記憶：** 会話全体の流れや関係・出来事を短くまとめたものです。過去のメッセージを一文ずつそのまま残す記録ではありません。
- **記憶の断片：** 大切な瞬間を個別のカードにまとめたものです。タイトル、関連人物、会話のターン範囲が表示されることがあります。カードを押すと詳しい内容を開けます。
- **ユーザーノート：** 上の2つと違い、**自分で書いて保存する**メモです。AIに覚えておいてほしい名前、関係、約束、話し方などを明記するときに使います。

長期記憶と記憶の断片は自動で作られます。会話が短い場合や処理中の場合は、まだ何も表示されないことがあります。自動記憶で昔の文章や細部をすべて正確に再現できるわけではありません。

## 1. 長期記憶を確認する

1. チャット画面右上の⋮を押します。
2. **記憶管理 → 長期記憶**を選びます。
3. 会話の要約を読みます。**まだ長期記憶がありません**と表示されたら、会話を続けてからもう一度確認してください。

この画面は閲覧用です。要約を直接編集する入力欄や保存ボタンはありません。新しい要約がすぐに表示されない場合は、会話を進めてルームを開き直してみてください。

> **「長期記憶を拡張」について：** 画面には**長期記憶を拡張 · 500文字 → 2,000文字**のスイッチが表示されます。現在のウェブ・アプリでは、このスイッチは要約の長さの変更や設定の保存につながっていません。オンにしても、要約が2,000文字に拡張されたとは判断しないでください。

## 2. 記憶の断片を探す

1. チャット画面右上の⋮から**記憶管理 → 記憶の断片**を選びます。
2. タイトル、関連人物、ターン範囲を見ながらカードを探します。**T10–T20**のような数字は会話のターン範囲です。
3. カードを押すと内容が開き、もう一度押すと閉じます。
4. 上部の検索欄に出来事・人物・状況を入力すると、**関連する断片**を探せます。検索語を消すと全件表示に戻ります。
5. 下にスクロールして続きを確認します。アプリでは**さらに読み込む**が表示されたら押してください。

検索では意味が近い内容を探すため、入力した語がそのまま書かれていなくても結果が出ることがあります。探している断片が見つからない場合もあります。**記憶の断片がありません**と表示されたら、会話を続けてからもう一度確認してください。

## 3. 記憶の断片の使用を切り替える

記憶の断片画面の上部にあるスイッチは、ウェブでは**記憶の断片を使用**、アプリでは**記憶を使用**と表示されます。オンの場合、以降の応答を作る際に関連する断片を探して参照します。オフにすると、以降の応答に断片の検索結果を含めません。

- オフにしても、**すでに作られた断片は削除されません。** 再びオンにできます。
- **長期記憶の要約を無効にしたり削除したりするスイッチではありません。** 要約は別に扱われます。
- スイッチの状態はアカウントの恒久的な設定として保存されません。ルームやアプリ・ブラウザーを開き直したときは状態を確認してください。
- ゲスト体験中は、スイッチがオンに見えてもサーバーは断片の参照を使用しません。利用するにはログインしてください。

## 大切な設定を覚えてもらうには

例えば、**2人が仲直りしたという大きな流れ**は長期記憶に、**そのとき交わした具体的な約束**は記憶の断片に現れることがあります。その約束を今後も守ってほしい場合は、**ユーザーノート**に明記するほうが確実です。[チャットルームの設定](/chatting/chat-room-settings.md)からノートを開いて保存できます。

AIが以前の出来事を取り違えたら、まずこのルームの長期記憶と記憶の断片を確認してください。これらの画面で内容を直接編集することはできないため、大切な設定はユーザーノートに書くか、次のメッセージではっきり伝えてください。
