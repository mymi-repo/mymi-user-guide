# AIモデルガイド

チャットの返信を作るAIモデルの選び方、モデルごとのスパーク価格、長い返信を受け取るときに必要なスパークを説明します。

## モデルを変える

1. チャットルームの入力欄の左にある⚡ボタンを押します。ログインしているときだけ表示されます。
2. **モデル選択**画面で、**MYMIモデル**、**Geminiモデル**、**Claudeモデル**、**xAIモデル**、**OpenAIモデル**のどれかを開きます。今使っているモデルは、提供元の名前の横に表示されます。
3. 紹介と価格を見て、使いたいモデルを押します。次の返信からそのモデルで会話します。

- 最初は**Gemini 3.1 Pro**が選ばれています。
- モデル名の前の点は、今の状態です。緑は**快適**、オレンジは**普通**（返信が遅め）、赤は**混雑**（失敗が多め）です。返信が何度も失敗するときは、緑の点のモデルに変えてみてください。
- **50%OFF**のバッジがあるモデルは、割引後の価格が表示されます。**一時無効化**と表示されたモデルは、今は選べません。
- 選んだモデルは今使っているブラウザーやアプリに保存され、ほかのチャットルームでもそのまま使われます。別の端末では選び直します。
- 作品詳細の**クリエイターおすすめモデル**は、クリエイターのおすすめです。会話に使うモデルは⚡ボタンで選びます。
- ログインしていない場合は、**Gemini 3.8 Flash**で5回まで体験できます。

## モデル別の価格

**2026年10月1日時点の定価**です。単位はスパークです。

- **基本価格**：返信1回の価格です。基本の長さまでを含みます。
- **追加100トークンあたり**：最大出力量を上げて基本の長さを超えた分にかかる価格です。トークンは、AIが文章の量を数える単位です。

## 長い返信を受け取る

返信の長さには、モデルごとに上限があります。もっと長い返信がほしいときは、最大出力量を上げます。

1. ⋮メニューの**チャット設定**で**最大出力量**を押します。ログインしているときだけ表示されます。
2. **最大出力量の調整**画面で、モデルごとに長さを選びます。**基本**より上げると、「メッセージごとに最大+Nスパーク」も表示されます。
3. 選んだ長さは、今使っているブラウザーやアプリに保存されます。

- 選べる長さは1,500 / 2,000 / 3,000 / 4,500 / 6,000トークンです。基本はほとんどのモデルが1,500トークンで、MYMI Plus v2は3,000トークンです。
- 上げても、実際に使った分だけが消費されます。送信時に選んだ長さの分を先に消費し、返信が終わると実際の長さで計算し直して、残りのスパークを戻します。

**計算例：** MYMI Plus v2を4,500トークンにした場合、送信時に**120スパーク**を先に消費します。実際の返信が3,240トークンなら、基本の3,000トークンを超えた240トークンを100トークン単位で切り上げて3単位になり、**60 + 3 × 4 = 72スパーク**だけが消費されます。残りの**48スパーク**は戻ります。

:::warning[先に消費する分のスパークがないと送信できません]
最大出力量を高くしていると、送信時にその分を先に消費します。残りのスパークがそれより少ないと「クレジットが不足しています」と表示され、送信できません。最大出力量を**基本**に下げるか、チャージしてください。
:::

返信が長さの上限で途中で切れると、「最大出力量の上限に達しました」という画面が出ます。**調整する**を押して、もっと長い長さを選んでください。

## 返信が失敗・拒否されたとき

| 状況 | 消費されるスパーク |
| --- | --- |
| 返信を正常に受け取った | 実際の返信の長さで計算します |
| 「モデルが応答を拒否しました」 | 基本価格の20%だけを消費し、残りは戻します |
| 返信を作る途中でエラーが起きた | 先に消費したスパークをすべて戻します |
| 「推論で出力量を使い切りました」 | すべて戻します。送った文章は入力欄に残っているので、もう一度送ってください |

消費されたスパークは、**マイページ → マイスパーク → 利用履歴を見る**の**使用**タブで確認できます。

## つまずいたときは

<details>
<summary>⚡ボタンが表示されない</summary>

ログインしていないとモデルは選べず、体験用のモデル**Gemini 3.8 Flash**で会話します。ログインすると⚡ボタンが表示されます。

</details>

<details>
<summary>「現在選択されているモデルは利用できません。」と表示される</summary>

選んだモデルが今は使えない状態です。**モデルを選択**を押して、別のモデルを選んでください。

</details>

<details>
<summary>返信が遅い、または何度も失敗する</summary>

モデル選択画面で、モデル名の前の点を確認してください。オレンジ（**普通**）や赤（**混雑**）なら、緑（**快適**）の点のモデルに変えてみてください。

</details>

<details>
<summary>「クレジットが不足しています」と表示されて送信できない</summary>

最大出力量を上げている場合、送信時にその分を先に消費します。**最大出力量**を**基本**に下げるか、チャージしてください。

</details>

<details>
<summary>別の端末ではモデルが違う</summary>

モデルと最大出力量は端末ごとに別々に保存されます。その端末で選び直してください。

</details>
