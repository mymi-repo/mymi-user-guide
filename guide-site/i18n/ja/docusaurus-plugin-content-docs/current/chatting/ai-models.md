# AIモデルガイド

AIモデルは、チャットの**次の返答を生成する仕組み**です。作品の世界観や登場人物を変更する設定ではありません。途中でモデルを変えても、それまでのメッセージは残ります。

## V1作品とV2作品では何が違いますか？

**チャットで選べるモデルと消費の仕組みは、V1・V2作品で共通です。** V2の制作者は、作品に合うモデルを最大5つまでおすすめできます。選んだモデルは作品詳細の**クリエイターおすすめモデル**に表示されます。これは読者への案内であり、モデルが自動で選ばれたり、ほかのモデルが使えなくなったりするわけではありません。V1作品にはこのおすすめ表示がありません。

**MYMI Plus v2 / MYMI Lite v2の「v2」はAIモデルのバージョン**です。作品をV1・V2のどちらの編集画面で作ったかに関係なく利用できます。

## 1. チャットでモデルを変更する

1. ログインして、**入力欄の左側にある⚡ボタン**を押します。
2. **モデル選択**で、MYMI・Gemini・Claude・xAI・OpenAIの提供元グループを開きます。
3. モデルの説明と表示価格を読み、割引バッジがある場合は割引後の価格を確認します。
4. モデルを選ぶと、**次の返答から**使われます。以前の返答や会話履歴は変わりません。

選んだモデルは**現在のブラウザーまたはアプリを使う端末に保存され、ほかのチャットルームでも引き継がれます。** ルームごとに固定される設定でも、ウェブとアプリで自動同期される設定でもありません。以前選んだMYMI Plus/Lite v1は同じグレードのv2に、Gemini 3.5/3.6 Flashは3.8 Flashに移行します。そのほかの保存済みモデルが提供終了になった場合は、利用可能なモデルを選び直す案内が出ることがあります。

ゲスト体験ではモデル選択ボタンは表示されず、**Gemini 3.8 Flash**が使われます。ログインすると自分で選べます。

## 2. 提供中のモデルと定価

以下は**2026年9月23日時点の定価**です。「基本」は1回のメッセージで、そのモデルの基本出力量までを含みます。「追加」は基本出力量を超えた**実際の出力・推論の合計100トークンごと**の価格です。単位はスパーク相当です。期間限定の割引では**基本価格と追加単価の両方**が変わることがあるため、送信前にモデル選択と最大出力量の画面で表示価格を確認してください。

### MYMIモデル

- **MYMI Plus v2：** 基本60 · 追加100トークンごとに4。豊かな描写と深みのある会話に向いた上位モデルです。
- **MYMI Lite v2：** 基本20 · 追加100トークンごとに1。気軽な日常会話に向いた基本モデルです。

### Geminiモデル

- **Gemini 3.1 Pro：** 基本120 · 追加100トークンごとに8。文脈の把握を重視する場合の選択肢です。
- **Gemini 2.5 Pro：** 基本80 · 追加100トークンごとに5。繊細な表現や没入感を重視する場合の選択肢です。
- **Gemini 3.8 Flash：** 基本100 · 追加100トークンごとに6。物語の流れを保つ新しいFlashモデルです。
- **Gemini 3.7 Flash：** 基本100 · 追加100トークンごとに6。作品の設定を丁寧に守るFlashモデルです。
- **Gemini 3 Flash：** 基本50 · 追加100トークンごとに3。速度と表現のバランスを比べたい場合の選択肢です。
- **Gemini 2.5 Flash：** 基本40 · 追加100トークンごとに2。速い返答を比較的低い価格で試せます。

### Claudeモデル

- **Claude Opus 4.6 / Opus 4.5：** それぞれ基本300 · 追加100トークンごとに20。深い推論や創作を重視する場合の選択肢です。
- **Claude Sonnet 4.6 / Sonnet 4.5：** それぞれ基本100 · 追加100トークンごとに6。繊細な感情表現やバランスのよい会話を求める場合の選択肢です。

### xAI・OpenAIモデル

- **Grok 4.3 / Grok 4.20：** それぞれ基本60 · 追加100トークンごとに4。速い会話や創造的な返答を比べられます。
- **GPT-5.4：** 基本120 · 追加100トークンごとに8。正確な理解と安定した返答を重視する場合の選択肢です。

これらの特徴は**モデル選択画面の紹介**を要約したものです。実際の長さや文体は作品・会話・設定によって変わります。モデルの提供状況と定価も変更される場合があります。

## 3. 最大出力量と実際の消費

ログイン中は**チャット画面右上の⋮ → チャット設定 → 最大出力量**から、モデルごとに返答の上限を選べます。場所は[チャットルームの設定](/chatting/chat-room-settings.md)でも説明しています。

- 基本価格に含まれるのは通常**1,500トークン**、**MYMI Plus v2は3,000トークン**です。初期値のままなら追加出力料金は発生しません。
- 選択肢は**1,500 / 2,000 / 3,000 / 4,500 / 6,000トークン**のうち、そのモデルの基本提供量以上です。上限を上げても、返答が必ずその長さになるわけではありません。
- 基本提供量を超えた**実際の出力トークンと推論トークンの合計**を、100トークン単位で切り上げて追加料金を計算します。
- 送信時には設定した上限に応じた最大額を先に消費し、通常の返答が完了すると実際の使用量で精算して残額が戻ります。応答の拒否や生成失敗には別の精算規則が適用されます。
- 最大出力量は**モデルごとに現在のブラウザー・アプリ端末に保存**され、別の端末とは自動同期されません。

**定価での計算例：** MYMI Plus v2の上限を4,500トークンにすると、基本の3,000トークンを超える最大1,500トークン分を含めて**120スパークを先に消費**します。通常の返答で出力と推論の合計が3,240トークンなら、超過240トークンを100トークン単位で3つに切り上げ、最終的な消費は**60 + 3 × 4 = 72スパーク**、**48スパークが戻ります**。割引中は画面に表示される割引価格と単価で計算されます。

Geminiモデルでは**Gemini専用スパークが先に**使われ、不足分は通常のスパークで補えます。ほかの提供元のモデルには通常のスパークを使います。最終的な消費はプロフィールの**スパーク利用履歴**で確認してください。

返答が出力量の上限に達して途中で切れた場合は、案内から最大出力量を調整できます。選択中のモデルが一覧から消えて送信できない場合は、入力欄左の⚡ボタンから利用可能なモデルを選び直してください。
