# AIモデルガイド

AIモデルは、チャットの**次の返答を生成する仕組み**です。

## 1. チャットでモデルを変更する

1. ログインして、**入力欄の左側にある⚡ボタン**を押します。
2. **モデル選択**で、MYMI・Gemini・Claude・xAI・OpenAIの提供元グループを開きます。
3. モデルの説明と表示価格を読み、割引バッジがある場合は割引後の価格を確認します。
4. モデルを選ぶと、**次の返答から**そのモデルで会話できます。

作品詳細の**クリエイターおすすめモデル**は制作者からの提案です。チャットで使うモデルは入力欄の⚡ボタンから自分で選んでください。

選んだモデルは**現在のブラウザーまたはアプリを使う端末に保存され、ほかのチャットルームでも引き継がれます。** 別の端末ではモデルを選び直してください。

ゲスト体験では**Gemini 3.8 Flash**を使います。自分でモデルを選ぶにはログインしてください。

## 3. 最大出力量と実際の消費

ログイン中は**チャット画面右上の⋮ → チャット設定 → 最大出力量**から、モデルごとに返答の上限を選べます。場所は[チャットルームの設定](/chatting/chat-room-settings.md)でも説明しています。

- 基本価格に含まれるのは通常**1,500トークン**、**MYMI Plus v2は3,000トークン**です。基本提供量を選ぶと基本価格が適用されます。
- 選択肢は**1,500 / 2,000 / 3,000 / 4,500 / 6,000トークン**のうち、そのモデルの基本提供量以上です。上限を上げると長い返答を受け取れるようになり、最終的な料金は実際の使用量で決まります。
- 基本提供量を超えた**実際の出力トークンと推論トークンの合計**を、100トークン単位で切り上げて追加料金を計算します。
- 送信時には設定した上限に応じた最大額を先に消費し、通常の返答が完了すると実際の使用量で精算して残額が戻ります。
- 最大出力量は**モデルごとに現在のブラウザー・アプリ端末に保存**されます。別の端末では上限を選び直してください。

**定価での計算例：** MYMI Plus v2の上限を4,500トークンにすると、基本の3,000トークンを超える最大1,500トークン分を含めて**120スパークを先に消費**します。通常の返答で出力と推論の合計が3,240トークンなら、超過240トークンを100トークン単位で3つに切り上げ、最終的な消費は**60 + 3 × 4 = 72スパーク**、**48スパークが戻ります**。割引中は画面に表示される割引価格と単価で計算されます。

Geminiモデルでは**Gemini専用スパークが先に**使われ、不足分は通常のスパークで補えます。ほかの提供元のモデルには通常のスパークを使います。最終的な消費はプロフィールの**スパーク利用履歴**で確認してください。

返答が出力量の上限に達して途中で切れた場合は、案内から**最大出力量を調整**してください。
