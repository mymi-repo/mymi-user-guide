# 旧エディター（1.0）：既存作品の編集

**旧エディターでの新規制作は終了しています。** **マイページ → 作品管理**で旧エディターで作った作品の **編集** を押すと、7段階の画面が開きます。新しい作品は下部の **制作** タブから[新しい作品を作る](create-work.md)に沿って制作してください。

順序は **基本情報 → アセット → 導入部 → その他の設定 → ロアブック → コンポーネント → 任意項目** です。次へ進むときに、それまでの必須項目が確認されます。

## 1. 基本情報：AIが読む作品設定

| 項目 | 入力方法 |
| --- | --- |
| 作品名 | 50文字以内。 |
| 一行紹介 | 40文字以内。 |
| 世界観 | 時代・場所・状況など、物語の背景。 |
| 登場人物 | 1人以上追加し、それぞれ異なる名前と説明を入力。 |
| 秘密 | 人物が知っておくべき隠された設定があれば入力。 |

世界観・人物の説明・秘密は合計 **10,000文字以内** に収めます。AIは会話中に世界観と人物情報を使います。現在の作品制作画面では、この内容を **プロンプト** に書きます。

## 2. アセット：画像と代表画像

**アセット**でチャット用の画像をアップロードまたは生成します。各画像に **状況説明** を付け、いつ使う画像かAIに伝えます。作品の **代表画像** も選びます。次へ進むには画像が1枚以上必要です。

## 3. 導入部：最初の場面

**導入部**を1個以上作り、それぞれの **タイトル** と **本文** を入力します。複数あると読者が開始場面を選べます。登録した画像は画面に表示される `img:[slug]` 形式で本文に入れ、**プレビュー**で確認します。

## 4. その他の設定：分類と公開

対象読者を **男性向け・女性向け** から選び、公開状態・オリジナル設定・画像の出典・年齢区分を設定します。作品を表すタグも追加できます。**オリジナル**にするとMYMIのみで公開し、3か月間その設定を維持します。

## 5～7. 必要な設定を追加する

| 段階 | 入力方法 |
| --- | --- |
| **ロアブック** | 特定のキーワードで呼び出す追加設定です。項目を追加したら名前・キーワード・内容を入力します。 |
| **コンポーネント** | ステータスや持ち物などの表示要素です。追加したら用途の説明と動作するコードを入力します。 |
| **任意項目** | プロフィールデザイン、おすすめペルソナ、クリエイターからのメッセージを設定します。ペルソナを追加したら名前・性別・生年月日・詳細を入力します。 |

内容を確認し、最後の段階で **完了** を押すと変更が反映されます。

## 現在の作品制作画面ではどこに書く？

| 旧エディター | 現在の作品制作画面 |
| --- | --- |
| 基本情報の **世界観・登場人物・秘密** | **プロンプト**の「自分で書く」、または基本型の作品情報 |
| アセットの **代表画像** | 基本情報の **表紙** |
| 画像の **状況説明** | アセットの **画像コード**とプロンプトの画像使用ルール |
| 導入部の最初のメッセージ | **導入部**のタイトルと本文 |
| その他の設定の対象読者・タグ | **その他の設定**の対象読者、**基本情報**のハッシュタグ |
| 任意項目のプロフィールデザイン・メッセージ | **基本情報**の詳細説明・クリエイターガイド |

新しい作品は[新しい作品を作る](create-work.md)に沿って作成してください。
