# 新しい作品を作る

ログイン後、下部の **制作** タブを押すと作品制作画面が開きます。タブは **基本情報 → アセット → コンポーネント → プロンプト → 導入部 → ロアブック → その他の設定** の順に並びますが、好きなタブから作業できます。

初めて作る場合は **基本情報を入力 → 下書き保存 → 表紙を追加 → プロンプトと導入部を書く → その他の設定を選ぶ → 制作完了** の順がおすすめです。アセット・コンポーネント・ロアブックは作品に必要なときに追加します。

## 1. 基本情報と表紙

**基本情報**には、読者が作品を探したり紹介ページを開いたりしたときに見る内容を書きます。

| 項目 | 入力方法 |
| --- | --- |
| 作品タイトル | 30文字以内。 |
| 一行紹介 | 作品の雰囲気を40文字以内で紹介。 |
| 表紙 | 1～10枚をアップロードするか、アセットから選択。複数枚なら切り替え間隔を設定できます。 |
| 詳細説明 | あらすじ・登場人物・遊び方など、読者向けの説明。 |
| ジャンル | 1～2個選択。 |
| ハッシュタグ | 作品を表すタグを1個以上追加。 |

タイトルと一行紹介を入力し、右上の **下書き保存** を押します。下書きができると、表紙やアセット画像のアップロード・生成を進められます。**クリエイターガイド**には遊び方のヒントを書けます。**おすすめモデル**ではチャットモデルを最大5個提案できます。どちらも任意です。

**読者に見せる紹介は基本情報に、AIが返答時に読む設定はプロンプトに**書きます。

## 2. プロンプトに作品のルールを書く

**プロンプト**では、AIが世界観・人物・物語のルールをどう使うか決めます。書き方は2種類あります。

| 書き方 | 入力方法 |
| --- | --- |
| **自分で書く** | 世界観・登場人物・隠された設定・進行ルールを一つの文章にまとめます。画像を使う場合は、場面ごとに使う画像コードも書きます。 |
| **基本形** | **作品情報**に世界観・登場人物・進行ルールを書きます。アセットやコンポーネントを追加したら、表示されるコードの意味や使用ルールも埋めます。下に表示される完成形のプロンプトを確認します。 |

人物名、関係、話し方、読者の役割、進行ルールを分けて書くと、後から編集しやすくなります。

例えば **作品情報**を次のような見出しに分けて書けます。内容は自分の作品に合わせてください。

```text
#### 世界観
- **場所**: 秘密を守る図書館
#### 登場人物
- **名前**: ユンソ
- **役割**: 読者を迎える司書
#### 進行ルール
- **読者の役割**: 新しく赴任した司書
- **最初の場面**: 鍵のかかった書架の前でユンソに会う
```

## 3. 導入部に最初のメッセージを作る

**導入部**を1個以上作り、それぞれに **タイトル** と **本文** を入力します。複数作ると読者が開始場面を選べます。**プレビュー**でチャット画面での表示を確かめてください。

画像を入れる場合は、先に **アセット**で画像を追加してコードを決め、導入部の **アセット画像を挿入** を使います。

## 4. アセット・コンポーネント・ロアブックを使う

| タブ | 使う場面 | 入力方法 |
| --- | --- | --- |
| **アセット** | 場面に合った画像をチャットに表示する | 画像をアップロード・生成し、英数字のコードを付けます。人物ごとに管理するならフォルダーを作ります。表示された画像のMarkdownをプロンプトや導入部に入れます。 |
| **コンポーネント** | ステータスや持ち物などを画面に表示する | コンポーネントのコードを追加します。基本形プロンプトでは表示するタイミングも書きます。 |
| **ロアブック** | 特定の言葉が出たときに追加設定を伝える | 項目名、トリガーとなるキーワード、AIに伝える内容を入力します。 |

例えばキャラクターフォルダーを `A`、その中の画像コードを `1` にすると、画像のパスは `A/1` です。**アセット**に表示されるMarkdownをプロンプトや導入部にコピーして使います。

この3つのタブは任意です。項目を追加した場合は、制作完了前に必須欄、画像の生成状態、コードを確認してください。

## 5. その他の設定を選ぶ

**その他の設定**で公開・非公開、公開範囲（オリジナル・一般）、収益化制限、画像の出典、対象読者、コンテンツの年齢区分、マーケティング利用への同意を選びます。**オリジナル**を選ぶとMYMIのみで公開し、その設定を3か月間維持します。

読者がチャットで使える役割を提案したい場合は、**おすすめペルソナ**を追加し、名前・性別・生年月日・詳細を入力します。

## 保存して制作を完了する

作業中は右上の **下書き保存** を押して保存します。保存した下書きは **マイページ → 作品管理** から開いて続きを書けます。

完成したら **制作完了** を押します。必須項目が残っていれば、そのタブが開いて入力箇所が案内されます。入力後にもう一度押すと完了画面に進みます。

完成した作品を直すときは **マイページ → 作品管理 → 編集** から開き、編集後に **変更を反映** を押します。
