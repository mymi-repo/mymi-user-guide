# 新しい作品を作る

新しい作品を作る案内は、**制作ガイド**に移しました。作品の作り方（かんたんモード、エキスパートモード）ごとに、詳しい案内ページが別にあります。

<Card to="/create/prompt" icon="book" title="プロンプトを書く">エキスパートモードで、AIが読む設定を書きます。</Card>
