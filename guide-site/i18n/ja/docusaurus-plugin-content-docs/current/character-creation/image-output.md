# 画像出力方式

画像の案内は、**制作ガイド**に移しました。かんたんモードとエキスパートモードでは、画像の書き方が違います。かんたんモードの作品なら最初の2枚のカードを、エキスパートモードの作品なら残りの2枚のカードをご覧ください。

<Card to="/create/simple/reference" icon="list" title="入力項目と制限">かんたんモードのimg:[名前]の書き方を確認します。</Card>
