# 作品を作る

ログイン後、下部の **制作** タブを押すと作品の編集画面が開きます。基本情報と表紙を用意し、プロンプト・導入部・その他の設定を入力して **制作完了** を押します。

初めて作る場合は[新しい作品を作る](create-work.md)を開き、**下書き保存 → 表紙を追加 → プロンプトと導入部を書く → その他の設定 → 制作完了**の順に進めてください。

## 制作済みの作品を編集する

**マイページ → 作品管理**で作品の **編集** を押します。その作品を作ったときの編集画面が開きます。現在の編集画面では **変更を反映**、旧エディターでは最後の段階の **完了** を押して変更を適用します。

**旧エディター（1.0）**で作った作品は、以前の7段階の画面で編集します。操作方法と現在の作品制作画面との違いは[旧エディター：既存作品の編集](edit-existing-work.md)を確認してください。旧エディターでの**新規制作は終了しています**。
