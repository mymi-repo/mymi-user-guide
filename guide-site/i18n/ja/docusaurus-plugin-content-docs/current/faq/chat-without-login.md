# ログインなしでAIチャットできますか？

はい。MYMIは登録しなくても、AIキャラクターと最大5回まで会話できます。

作品を開いて**会話を始める**を押すと、ログイン画面を通らずにすぐチャットルームが開きます。作品のうち、ログインが必要なのは成人向け作品だけです。このページは2026年11月4日時点の内容です。

## 5回の体験の数え方

- AIの返信を1つ受け取るごとに1回です。作品を変えても数え直しにはならず、すべての作品を合わせて5回です。
- 残りの回数は、チャットルーム右上の⋮メニューのいちばん上に表示されます。

:::info[最初から残りがないことがあります]
同じインターネット接続（同じWi-Fiなど）で最近7日以内に体験が使われていると、初めて開いたブラウザーやアプリでも、残り0回から始まることがあります。会社・学校・カフェのWi-Fiのように大勢で使う接続では、ほかの人の体験が原因になることもあります。ログインして使ったあとログアウトしたブラウザーやアプリも、そうなることがあります。体験を繰り返し使うことを防ぐほかの条件に当てはまった場合も同じです。そのときは新規登録するか、ログインして会話してください。
:::

## ログインすると変わること

| | ログインなし | 登録してログインすると |
| --- | --- | --- |
| キャラクターとの会話 | 最大5回 | スパークで会話します。返信1回にかかるスパークはモデルごとに違います |
| モデルを選ぶ | 選べません。体験用モデル（現在は**Gemini 3.8 Flash**）が返信します | 入力欄の左の⚡ボタンで選びます |
| ユーザーノート・ペルソナ | ユーザーノートは書けません。ペルソナは作品画面の**おすすめペルソナ**から選ぶことだけできます | チャットルームごとに決められます |
| 成人向け作品 | 開けません | 年齢確認（18歳以上）を済ませると開けます |
| 作品づくり | ログインの案内だけが表示されます | 下の**制作**から作ります |
| 体験した会話 | 5回使い切ると入力欄がロックされ、新規登録かログインを案内します | 体験したブラウザーやアプリで新規登録すると、新しいアカウントに移ります |

スパークはチャージして手に入れます。チャージの方法と、ほかにもらえる報酬は[スパークのチャージ](/payment/payment-methods.md)にまとめています。チャットルームで返信を再生成したり編集したりする方法は[会話する](/chatting/chat-with-character.md)にあります。

## つまずいたときは

<details>

<summary>5回使い切るとどうなりますか？</summary>

入力欄がロックされ、チャットルームの上のほうに体験が終わったという案内が出ます。最後の返信が表示し終わると、少ししてログインの画面も開きます。閉じてしまったときは、案内の**ログインする**を押すともう一度開けます。新規登録かログインをしたあとは、スパークで会話を続けます。新しいアカウントはスパークがない状態から始まるので、先にチャージしてください。

</details>

<details>

<summary>再生成や「続きを進める」も回数に入りますか？</summary>

はい。入力欄が空のときに≫ボタンで受け取った返信、**再生成**で受け取り直した返信、モデルが応答を拒否した返信も、それぞれ1回と数えます。‹ ›で前の返信をめくって見るのは数えません。

</details>

<details>

<summary>アプリでもログインなしで会話できますか？</summary>

はい。Android・iPhoneアプリも、初めて開いたときからログインせずに作品を選んで会話できます。回数の数え方と、使い切ったあとの案内もウェブと同じです。ただし、同じインターネット接続（同じWi-Fiなど）で最近7日以内にウェブで体験していると、アプリは残り0回から始まることがあります。

</details>

<details>

<summary>新規登録すると体験した会話は残りますか？</summary>

体験したブラウザーやアプリでログインボタンを押し、MYMIでまだ使っていないソーシャルアカウントで新規登録すると残ります。体験したチャットルームはすべて新しいアカウントに移り、チャットルームで開いたログイン画面から登録したときは、登録後にそのチャットルームに戻ります。すでに登録済みのアカウントでログインしたときや、別のブラウザー・アプリで登録したときは移りません。登録の方法は[新規登録](/account/sign-up.md)にあります。

</details>
