# Cookieの削除

ウェブでログインが何度も外れる、ログインしたのにまたログイン画面が出る、**マイページ**が開かないときは、次の順に試してください。

アプリでは、Cookieを削除する必要はありません。**マイページ → 設定とサポート → ログアウト**を押して、登録したソーシャルアカウントでもう一度ログインしてください。

## まずログインし直す

**マイページ**にログアウトのボタンが表示されているときは、**マイページ → 設定とサポート → ログアウト**を押して、登録したソーシャルアカウントでもう一度ログインします。

ログアウトのボタンが表示されないときや、ログインし直しても同じ問題が起きるときは、使っているブラウザーでMYMI（mymi.live）のCookieとサイトデータを削除します。削除したあとは、もう一度ログインが必要です。

## ブラウザーのCookieを削除する

手順はブラウザーやバージョンによって異なるので、ご利用のブラウザーの公式ヘルプをご覧ください。サイトごとにデータを削除できる場合は、mymi.liveのデータだけを削除してください。

| ブラウザー | 公式ヘルプ |
| --- | --- |
| Chrome（パソコン・Android・iPhone） | [Chrome で Cookie を削除、許可、管理する](https://support.google.com/chrome/answer/95647?hl=ja) |
| Safari（iPhone・iPad） | [iPhoneでSafariの閲覧履歴、キャッシュ、Cookieを消去する](https://support.apple.com/ja-jp/105082) |
| Safari（Mac） | [MacのSafariでキャッシュとCookieを消去する](https://support.apple.com/ja-jp/guide/safari/sfri11471/mac) |
| Microsoft Edge | [Microsoft Edge で Cookie を管理する](https://support.microsoft.com/ja-jp/microsoft-edge/delete-cookies-in-microsoft-edge-63947406-40ac-c3b8-57b9-2a946a29ae09) |

:::warning[ほかのサイトからもログアウトされることがあります]
すべてのCookieを削除すると、MYMI以外のサイトからもログアウトされることがあります。
:::

## つまずいたときは

<details>
<summary>Cookieを削除したのに、ログインできない</summary>

- LINEやInstagramなどのアプリの中でMYMIを開いている場合は、ChromeやSafariで[www.mymi.live](https://www.mymi.live)を直接開いてください。
- 別のブラウザーでもログインしてみてください。別のブラウザーでは入れるなら、使っていたブラウザーの設定が原因かもしれません。

</details>

<details>
<summary>ほかのサイトからもログアウトされた</summary>

ブラウザーの履歴全体からCookieを削除すると、ほかのサイトのログインも外れます。それらのサイトに、もう一度ログインしてください。

</details>

<details>
<summary>ログインしたのに、以前の会話やスパークが見えない</summary>

Cookieの問題ではなく、別のソーシャルアカウントでログインしているのかもしれません。ソーシャルアカウントごとに、MYMIのアカウントが別々にあります。ログアウトしてから、最初に登録したソーシャルアカウントでもう一度ログインしてください。

</details>

それでも解決しないときは、使っている端末とブラウザーを書いて、[お問い合わせ](/faq/faq.md#お問い合わせ)からお知らせください。
