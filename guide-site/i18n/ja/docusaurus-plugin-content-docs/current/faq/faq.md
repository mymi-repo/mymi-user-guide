# よくある質問（FAQ）

<details>

<summary>MYMIはどこで使えますか？</summary>

パソコン・スマートフォンのWebブラウザーと、Android・iOSアプリで利用できます。Webサイトは[https://www.mymi.live](https://www.mymi.live)です。アプリの入手方法は[MYMIへのアクセス方法](/getting-started/how-to-access.md)をご覧ください。

</details>

<details>

<summary>スパークとは何ですか？</summary>

作品の登場人物と会話するときに使うアイテムです。メッセージを送るたびに、選んだAIモデルと返答の長さに応じて消費されます。チャージするか、出席チェック・友達招待・イベントで受け取れます。詳しくは[スパークのチャージ](/payment/payment-methods.md)をご覧ください。

</details>

<details>

<summary>スパークが足りないと表示されます</summary>

**マイページ → マイスパーク → スパークをチャージ**からチャージできます。会話中の案内からもチャージ画面に移動できます。毎日の**出席チェック**でも無料のスパークを受け取れます。

</details>

<details>

<summary>購入をキャンセルしたいです</summary>

ウェブで購入した場合はMYMIに、アプリで購入した場合はApp StoreまたはGoogle Playにお問い合わせください。条件と方法は[キャンセル・返金](/payment/refund.md)をご覧ください。

</details>

<details>

<summary>セーフティフィルターをオフにするには？</summary>

18歳以上であることの**年齢確認**を完了したアカウントだけが、フィルターをオフにできます。ホームの**セーフティフィルター**をオフにするか、**マイページ → 設定とサポート**の**センシティブコンテンツの表示**をオンにすると、年齢確認が案内されます。電話番号認証だけではオフにできません。詳しくは[年齢確認・電話番号認証](/account/adult-verification.md)をご覧ください。

</details>

<details>

<summary>画面の表示方法を変えるには？</summary>

チャット画面右上の**パレットアイコン → UI設定**で、**UIモード**を**チャット / 1:1 / 小説**から選びます。どのモードでも、同じ会話履歴を違う形式で読めます。詳しくは[チャットルームの設定](/chatting/chat-room-settings.md)をご覧ください。

</details>

<details>

<summary>登場人物が以前の会話を覚えていません</summary>

AIモデルが一度に参照できる量には限りがあるため、会話が長くなると前の内容を見落とすことがあります。次の点を確認してください。

1. チャットルームの<strong>⋮ → 記憶管理 → 記憶の断片</strong>で、**記憶の断片を使用**がオンになっているか確認します。
2. **⋮ → 記憶管理 → 長期記憶**で、まとめられた会話の流れを確認します。
3. 必ず覚えてほしい関係や設定は、**⋮ → チャット設定**の**ユーザーノート**（2,000文字以内）に書いて保存します。

詳しくは[長期記憶と記憶の断片](/chatting/memory-book.md)をご覧ください。

</details>

<details>

<summary>チャットルームが消えました</summary>

チャット一覧には、作品ごとに最新のチャットルームが1つだけ表示されます。次の点を確認してください。

1. **新しい会話を始めた場合**：以前のルームは残っています。その作品のチャットルームで ⋮ メニューを開き、**過去のチャットを見る**を押します。
2. **チャット一覧で作品を非表示にした場合**：**チャット**の**作品**タブで**非表示 N**を押して非表示の作品を開き、作品カードのその他メニューから**非表示を解除**を選びます。
3. **ルームを1つ非表示にした場合**：**過去のチャットを見る**で目のアイコンを押して**非表示のチャット**を開き、ルームを選んで**非表示を解除**を押します。

チャット一覧から作品を**削除**すると、その作品の会話はすべて削除され、元に戻せません。

当てはまらない場合は、作品名、ルームが消えた時期、利用している端末とOSを添えてお問い合わせください。

</details>

<details>

<summary>AI作品はどのような基準で審査されますか？</summary>

作品生成ポリシーとコミュニティガイドラインに基づいて審査します。詳しくは[規約・ポリシー](/policy/terms.md)をご覧ください。

</details>

<details>

<summary>リーフとは何ですか？</summary>

クリエイターが受け取る報酬です。クリエイターになると、ほかのユーザーが公開中の自分の作品で有料スパークを使って会話したときに貯まり、スパークに変換して使えます。詳しくは[クリエイターを応援する](/creator-support/support.md)をご覧ください。

</details>

<details>

<summary>問い合わせ先はどこですか？</summary>

**マイページ → Discord → お問い合わせ**、または[contact@mymi.live](mailto:contact@mymi.live)までご連絡ください。MYMIのID、問題が起きた画面、ウェブ・Android・iOSのどれを使っているかを添えると、確認がスムーズです。

</details>
