# 聊天室设置

说明如何在聊天室调整 AI 的回复方式与画面显示，以及重读或找到过去的对话。

## 按钮位置

聊天室右上角有三个图标。

| 图标 | 点击后 |
| --- | --- |
| 眼睛 | 隐藏对话文字，只看图片。再点一次就会恢复 |
| 调色盘 | 打开 **UI 设置**，调整显示方式、字体大小与颜色 |
| ⋮ | 打开**房间管理**。本页的设置大多在这里 |

**房间管理**最上方会显示剩余的 Spark。未登录时则显示**剩余免费试用**。点击后会前往充值画面或登录窗口。

## 调整 AI 的回复方式

在 ⋮ 菜单的**聊天设置**中调整。调整后的设置从下一则回复开始套用。

| 设置 | 作用 |
| --- | --- |
| **写作风格** | **依照作品**不另外加入文体指示，沿用作品本身的文体。**小说**的描写与叙述较丰富，**轻小说**较轻快、以台词为主。**网络小说**段落简短、节奏明快，**言情**跟随角色的内心与情感变化 |
| **剧情推进** | 打开后，AI 会主动制造事件，剧情推进得更快 |
| **允许 AI 描写我的行动** | 打开后，AI 在推进场景需要时，也可以写你的动作和台词，但不会每次都写。一开始是关闭的，想自己写动作时请保持关闭 |
| **一次一幕** | 打开后，在会出现图片的作品中，每则回复只出现一张图片。文字分量不变 |
| **最大输出量** | 可以取得更长的回复。可能会多扣 Spark，所以另外整理在[取得更长的回复](/chatting/ai-models.md#取得更长的回复) |

即使打开了**允许 AI 描写我的行动**，在输入框留空、点击 ≫ 按钮跳过的回合，也会请 AI 不要写你角色的台词、动作和决定。想让 AI 也能写你的动作时，请在输入框写下至少一行再送出。

:::info[这些设置会套用到所有聊天室]
上面五项会保存在你目前使用的浏览器或 App 中，其他聊天室也会套用相同设置。在其他浏览器或 App 打开时需要重新选择（同一台设备上的 App 和浏览器也是分开的）。每个聊天室分开保存的是下方的**用户备注**和**人设**。
:::

## 用户备注与人设

这些设置只会保存在这个聊天室，在其他设备打开也不会改变。只有登录时才能打开，未登录时点击会出现登录窗口。

**用户备注**可以写下你与角色的关系、背景，以及希望对方一定要记住的设置，最多 3,000 字。在 ⋮ 菜单的**聊天设置 → 用户备注**中写好并点击**保存**，AI 在这个聊天室每次回复时都会参考。 备注较长时，每次回复可能额外使用Spark，费用以画面显示为准。

```text
我是书妍的青梅竹马，我们说话很随意。
上周大吵一架，现在还有点尴尬。
```

**人设**是你在这个聊天室使用的名字与身份。在 ⋮ 菜单的**聊天设置 → 人设**中直接修改，或点击**加载**从你的人设清单中选一个，再点击**保存**。

在清单中修改人设后，已经存在的聊天室不会跟着更新。请在该聊天室重新加载并**保存**。创建人设的方法请见 [人设设置](/account/persona.md)。

## 从头重读

1. 在 ⋮ 菜单点击**从头阅读**。
2. 从第一个场景依序阅读。阅读期间，输入框的位置会显示**从头阅读中**，无法发送或修改消息。
3. 读完后点击**返回对话**。原本写到一半的文字仍会保留。

## 找到先前的聊天室

如果你在同一部作品开始了新的聊天，先前的聊天室都在这里。

1. 在 ⋮ 菜单点击**查看先前聊天**。
2. 点击聊天室后，会显示**最后消息**以及**继续**、**隐藏**、**删除**。
3. 点击**继续**就会前往该聊天室。

隐藏的聊天室，请点击**先前聊天**窗口右上角的眼睛图标，在**已隐藏聊天**中寻找。点击聊天室再点击**取消隐藏**，就会重新显示。

:::danger[删除的聊天室无法复原]
删除前，请先用窗口中的**最后消息**确认是哪一个聊天室。
:::

## 书签与分支

可以把喜欢的时间点存起来，之后在新的聊天室从那个时间点尝试不同的剧情。

1. 点击 AI 回复下方的书签图标（**添加书签**）。
2. 需要的话输入名称并点击**保存**。名称最多 50 字，也可以留空。
3. 之后在 ⋮ 菜单的**书签**中找到保存的时间点。
4. 想从那个时间点重来时，点击分支图标（**从这里创建分支**）再点击**确认**。会打开包含到那个时间点为止对话的新聊天室，原本的聊天室会保留下来。用户备注与人设也会带到新的聊天室。

:::warning[加入书签的回复将无法再修改]
保存书签后，那则回复和它之前的消息都无法再重新生成、编辑或删除。删除书签也不会解除。如果打算修改最后一则回复，请先改好再加入书签。
:::

书签清单中的垃圾桶图标（**删除书签**）只会删除书签。删除的书签无法复原。

## 截取对话

1. 在 ⋮ 菜单点击**截取聊天**。
2. 点击要截取的第一则消息。要截取多则时，再点击最后一则消息决定范围。
3. 想排除自己的消息时，打开**排除我的消息**（App 为**排除我的台词**）。
4. 网页点击**下载图片**，App 点击**保存图片**。

在 App 中，可能会询问照片访问权限或打开分享画面。请依画面指示选择保存位置。想中止时点击**取消**。

## 调整文字与画面显示

点击聊天室右上角的调色盘图标，会打开 **UI 设置**。

| 分类 | 可以调整的项目 |
| --- | --- |
| 显示 | **UI 模式**：**小说**、**聊天**、**1:1**、**故事** |
| 阅读 | **字体大小**、**行高**、**字体**、**串流速度**（文字出现的速度） |
| 颜色 | **文字颜色**：角色对白、用户对白、角色叙事、用户叙事 |
| 画面 | **聊天高度**、**聊天透明度**（故事模式下为背景的暗度）、**图片高度**（小说）、**显示角色名称**（聊天） |
| 视频 | **循环播放视频**，以及用图片取代视频的**图片模式** |

- 每种显示方式的设置分开保存。**重设**只会把目前的显示方式恢复成默认值。
- 设置会保存在你目前使用的浏览器或 App 中，并套用到所有聊天室。

## 遇到问题时

<details>
<summary>对话文字不见了，只看得到图片</summary>

再点一次聊天室右上角的眼睛图标，文字就会恢复。

</details>

<details>
<summary>改了设置之后，其他聊天室也跟着变了</summary>

**聊天设置**中的写作风格、剧情推进、允许 AI 描写我的行动、一次一幕、最大输出量，以及 **UI 设置**，会套用到你目前使用的浏览器或 App 中的所有聊天室。想让每个聊天室不同的内容，请写在**用户备注**中。

</details>

<details>
<summary>加载的人设没有套用</summary>

用**加载**选好人设后，还要点击**保存**，才会套用到这个聊天室。

</details>

<details>
<summary>无法重新生成或修改回复</summary>

按钮只出现在最后一则 AI 回复。已加入书签的回复和它之前的消息也无法修改。如果出现「此消息已被分支对话引用，无法编辑或删除。」，原因就是书签。

</details>

<details>
<summary>找不到先前的聊天室</summary>

请到 ⋮ 菜单的**查看先前聊天**中寻找。隐藏的聊天室，请点击该窗口右上角的眼睛图标，在**已隐藏聊天**中寻找。如果隐藏的是整部作品，请查看[常见问题](/faq/faq.md)中的「聊天室不见了」。

</details>

<details>
<summary>想询问这个聊天室的问题</summary>

点击 ⋮ 菜单的**复制房间 ID** 复制 ID，再连同发生的状况，从**个人资料 → Discord** 前往 Discord 的询问频道告诉我们，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。

</details>
