# 聊天

依序说明如何选择作品并开始第一次聊天、不满意回复时重新取得，以及之后继续聊天的方法。

:::info[聊天会使用 Spark]
每收到一次 AI 回复，就会依所选模型的价格扣除 Spark。一开始选的是 **Gemini 3.1 Pro**，可以用输入框左侧的 ⚡ 按钮换成其他模型。各模型的价格请见 [AI 模型指南](/chatting/ai-models.md)。

未登录时无法选择模型，会用固定的试用模型，最多试聊 5 次。
:::

## 选择作品

用**首页**上方的分页寻找作品。

| 分页 | 寻找方式 |
| --- | --- |
| **推荐** | 浏览推荐的作品合集 |
| **排行** | 从实时、每日、每周、每月排名中挑选 |
| **类型** | 从浪漫、奇幻、武侠等 13 种类型中选一种或**全部**，依热门、每周热门、最新排序浏览 |
| **搜索** | 用氛围或关键字寻找。准确输入 `@昵称` 或 `@ID`，就会显示该创作者的作品 |

- 第一次进入时，会出现「选择你最想看的角色」窗口。从**女性角色**、**男性角色**、**全部都想看**中选一个，就会优先显示有该类角色登场的作品。之后随时可以在各分页的性别筛选中更改。
- 打开安全筛选时，不会显示成人作品。安全筛选是首页分页列最右侧的盾牌形状开关。要关闭它，必须完成年龄确认（年满 18 岁）。请参阅[年龄确认与手机号码验证](/account/adult-verification.md)。

## 决定开场场景与你的角色

点击作品卡片会打开作品详情。

1. 阅读介绍与登场角色。
2. 在**开场白**中选择要开始的场景。如果有多个开场白，点击即可切换成其他场景。没有选择时，会从第一个开场白开始。
3. 点击画面下方**开始聊天**右侧的小型个人资料图标。
4. 从**我的人设**或创作者准备的**推荐人设**中选一个，再点击**确认选择**。图标会换成所选人设的图片（没有图片时显示名称的第一个字）。

人设是你在作品中使用的名字与身份。一开始选的是你的主要人设。添加或修改的方法请见 [人设设置](/account/persona.md)。

## 发送第一则消息

1. 点击**开始聊天**，会打开新的聊天室并显示开场场景。
2. 在画面下方的输入框写下你的台词或动作。一次最多可以写 1,000 字。
3. 点击输入框最右侧的 ↑ 按钮送出。在电脑上按 Enter 送出，按 Shift+Enter 换行。
4. 稍等一下，角色就会回复。

用星号（`*`）把动作包起来，就会以和台词不同的颜色显示。点击输入框右侧的 ✱ 按钮会自动加入星号。

```text
*打开门走进去* 这里发生了什么事？
```

:::tip[想不到要说什么时]
输入框留空时，↑ 按钮会变成 ≫ 按钮。点击 ≫ 按钮会打开**继续推进**窗口。

- **直接继续**：角色会照目前的走向继续故事。
- **时间流逝**、**场景转换**、**事件发生**、**新角色登场**：把选项下方写的方向只加在这一轮，继续推进故事。

不论选哪一项，都会扣除一次回复的 Spark。
:::

## 不满意回复时

用最后一则 AI 回复下方的按钮，重新取得或修改回复。

| 按钮 | 作用 |
| --- | --- |
| 圆形箭头（**重新生成**） | 打开**重新生成**窗口。依你的选择取得新的回复，会再扣一次 Spark |
| 铅笔（**编辑消息**） | 自己修改回复内容后**保存** |
| 垃圾桶（**删除消息**） | 删除这则回复。引发这则回复的你的消息也会一起删除 |

在**重新生成**窗口中，选择你希望新回复怎么写。选的内容只会用在这次重新生成。

| 选项 | 新的回复 |
| --- | --- |
| **直接重新生成** | 不加其他指示，重新取得 |
| **依照角色设置**、**依照用户备注**、**不要重复**、**不写我的行动** | 加上选项下方写的指示，再重新取得 |
| 最下方的输入框 | 自己写下希望的内容（最多 150 字）再送出 |

- 用 ≫ 按钮选择方向取得的回复，重新生成时也会再加上当初选的方向。
- 重新生成后有多则回复时，可以用 ‹ › 切换，留下喜欢的那一则。切换查看不会扣 Spark。
- 这些按钮只出现在最后一则 AI 回复。更早的回复和你送出的消息都无法修改，想改变剧情走向时，请在下一则消息中说明。
- 已加入书签的回复也无法修改。详情请见[书签与分支](/chatting/chat-room-settings.md#书签与分支)。
- 在 **1:1** 显示中，翻到最后一则回复的结尾，就会出现同样的图标按钮。在电脑上把鼠标移到按钮上，会显示**重新生成**、**编辑内容**、**删除**等名称。

:::warning[删除后无法复原]
删除回复时，引发这则回复的你的消息也会一起删除，而且无法复原。只想换一则回复时，请使用**重新生成**。
:::

## 切换显示方式

一开始会以**小说**显示打开。点击聊天室右上角的调色盘图标，在 **UI 设置**的 **UI 模式**中切换。不论选哪一种，都是同一段对话。

| 显示 | 呈现方式 |
| --- | --- |
| **小说** | 把叙述和台词当作连续的文章阅读 |
| **聊天** | 以对话气泡一来一往 |
| **1:1** | 以图片为背景，一次看一段（**上一个**・**下一个**） |
| **故事** | 以图片作为整个画面的背景，只连续阅读文字；文字进行到图片的位置时，背景就会换成那张图片 |

字体大小和颜色请在[聊天室设置](/chatting/chat-room-settings.md#调整文字与画面显示)中更改。

## 之后继续聊天

- 点击下方菜单的**聊天**，会显示你聊过的作品。点击作品会打开最近一次聊天的聊天室。
- 作品详情的**继续先前聊天**也会打开最近一次聊天的聊天室。
- 想从头开始时，在作品详情选好开场白和人设，再点击**开始新聊天**。会创建新的聊天室，原本的聊天室会保留下来。
- 同一部作品先前的聊天室，可以从聊天室右上角 ⋮ 菜单的**查看先前聊天**中选择。方法请见[找到先前的聊天室](/chatting/chat-room-settings.md#找到先前的聊天室)。

## 遇到问题时

<details>
<summary>输入框被锁住，显示「Spark 不足」</summary>

剩余的 Spark 比目前模型的价格少。点击画面上的**充值**，或用输入框左侧的 ⚡ 按钮换成较便宜的模型。免费获得的方法请见[充值 Spark](/payment/payment-methods.md#免费领取-spark)。

</details>

<details>
<summary>显示「点数不足」，消息送不出去</summary>

如果把最大输出量设得比基本高，送出时会先扣除那部分。把 ⋮ 菜单的**最大输出量**调回**基本**就能送出。详情请见[取得更长的回复](/chatting/ai-models.md#取得更长的回复)。

</details>

<details>
<summary>显示「免费试用已结束！」</summary>

不登录能聊天的次数（最多 **5 次**）已经用完，或是一开始就没有剩余次数。用 ≫ 按钮继续推进的回复、重新生成的回复，以及被模型拒绝的回复，都各算一次。登录后就能继续聊天。在试用时的浏览器或 App，用没在 MYMI 用过的社区账号注册新账号，试用时的对话就会移到新账号。详细条件请看[不登录也能和 AI 聊天吗？](/faq/chat-without-login.md)。

</details>

<details>
<summary>显示「模型拒绝回复」</summary>

先前的对话或记忆累积了不适当的内容时，即使刚送出的消息没有问题，模型也可能拒绝回复。点击**删除并继续**后，换个说法或降低尺度再送出。被拒绝的回复只会扣除基本价格的 20%。

</details>

<details>
<summary>显示「目前选取的模型暂时无法使用。」</summary>

点击**选择模型**换成其他模型，就能继续聊天。

</details>

<details>
<summary>开始聊天按钮按不下去</summary>

还没有选择人设。点击按钮右侧的个人资料图标，选择一个人设。

</details>

<details>
<summary>进不去成人作品</summary>

需要登录并完成年龄确认（年满 18 岁）。只完成手机号码验证无法打开成人作品。请参阅[年龄确认与手机号码验证](/account/adult-verification.md)。

</details>

如果还是无法解决，请用聊天室 ⋮ 菜单的**复制房间 ID** 复制 ID，连同发生的状况，从**个人资料 → Discord** 前往 Discord 的询问频道告诉我们，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
