# AI 模型指南

说明如何选择产生聊天回复的 AI 模型、各模型的 Spark 价格，以及取得较长回复时需要的 Spark。

## 更换模型

1. 点击聊天室输入框左侧的 ⚡ 按钮。只有登录时才会显示。
2. 在**选择模型**窗口中，展开 **MYMI 模型**、**Gemini 模型**、**Claude 模型**、**xAI 模型**、**OpenAI 模型**其中一个。目前使用的模型会显示在提供者名称旁。
3. 看过介绍和价格后，点击想用的模型。从下一则回复开始就会使用该模型。

- 一开始选的是 **Gemini 3.1 Pro**。
- 模型名称前的圆点代表目前状态：绿色是**顺畅**，橘色是**普通**（回复偏慢），红色是**拥挤**（较常失败）。回复一直失败时，请换成绿点的模型。
- 有 **5 折**标签的模型会显示折扣后的价格。标示**暂时禁用**的模型目前无法选择。
- 选好的模型会保存在你目前使用的浏览器或 App 中，其他聊天室也会沿用。在其他浏览器或 App 上需要重新选择。
- 作品详情的**创作者推荐模型**是创作者的建议。聊天要用的模型请用 ⚡ 按钮选择。
- 未登录时，可以用固定的试用模型（目前是 **Gemini 3.8 Flash**）试聊 5 次。

## 取得更长的回复

每个模型的回复长度都有上限。想取得更长的回复时，请调高最大输出量。

1. 在 ⋮ 菜单的**聊天设置**中点击**最大输出量**。只有登录时才会显示。
2. 在**调整最大输出量**窗口中，为每个模型选择长度。调得比**基本**高时，会一并显示「每则消息最多 +N Spark」。
3. 选好的长度会保存在你目前使用的浏览器或 App 中。

- 可以选择 1,500 / 2,000 / 3,000 / 4,500 / 6,000 tokens。大多数模型的基本是 1,500 tokens，MYMI Plus v2 是 3,000 tokens。
- 即使调高，也只会扣除实际使用的部分。送出时会先扣除所选长度的分量，回复结束后再依实际长度重新计算，退回剩余的 Spark。

**计算范例：** 把 MYMI Plus v2 设为 4,500 tokens 时，送出时会先扣除 **120 Spark**。如果实际回复是 3,240 tokens，超过基本 3,000 tokens 的 240 tokens 会以 100 tokens 为单位无条件进位成 3 个单位，只扣除 **60 + 3 × 4 = 72 Spark**。其余的 **48 Spark** 会退回。

:::warning[要有足够先扣的 Spark 才能送出]
把最大输出量调高时，送出时会先扣除那部分。剩余的 Spark 比那部分少时，会显示「点数不足」而无法送出。请把最大输出量调回**基本**，或先充值。
:::

回复在长度上限处被截断时，会出现「已达最大输出量上限」窗口。点击**调整**，选择更长的长度。

## 回复失败或被拒绝时

| 状况 | 扣除的 Spark |
| --- | --- |
| 正常收到回复 | 依实际回复长度计算 |
| 「模型拒绝回复」 | 只扣除基本价格的 20%，其余退回 |
| 产生回复时发生错误 | 先扣的 Spark 全部退回 |
| 「推理用尽了输出量」 | 全部退回。送出的文字还留在输入框中，请再送一次 |

扣除的 Spark 可以在**个人资料 → 我的 Spark → 查看使用纪录**的**使用**分页中查看。

## 遇到问题时

<details>
<summary>看不到 ⚡ 按钮</summary>

未登录时无法选择模型，会用固定的试用模型（目前是 **Gemini 3.8 Flash**）聊天。登录后就会出现 ⚡ 按钮。

</details>

<details>
<summary>显示「目前选取的模型暂时无法使用。」</summary>

你选的模型目前无法使用。请点击**选择模型**，换成其他模型。

</details>

<details>
<summary>回复很慢或一直失败</summary>

请在选择模型窗口中确认模型名称前的圆点。如果是橘色（**普通**）或红色（**拥挤**），请换成绿色（**顺畅**）圆点的模型。

</details>

<details>
<summary>显示「点数不足」，消息送不出去</summary>

如果调高了最大输出量，送出时会先扣除那部分。请把**最大输出量**调回**基本**，或先充值。

</details>

<details>
<summary>在其他设备上模型不一样</summary>

模型和最大输出量是依浏览器和 App 分开保存的。即使在同一台设备上，App 和浏览器也会各自记住，请在目前使用的地方重新选择。

</details>
