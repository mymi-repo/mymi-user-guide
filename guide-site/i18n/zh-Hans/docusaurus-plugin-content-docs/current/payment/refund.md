# 取消与退款

要向哪里申请退款，取决于你**在哪里付款**。

| 付款的地方 | 申请的地方 |
| --- | --- |
| 网页版（PayPal） | MYMI 信箱 [contact@mymi.live](mailto:contact@mymi.live) |
| iPhone App | Apple（App Store） |
| Android App | Google Play |

付款后没收到 Spark 的话，在申请退款或再次付款之前，请先照[这些步骤](#付款后没收到-spark-时)确认。

## 在网页版付款时

### 可以退款的情况

网页版的购买，依照[交易信息与退款政策](https://www.mymi.live/zh-Hans/legal/transaction-info-refund-policy)和[服务条款](https://www.mymi.live/zh-Hans/legal/terms-of-service)第 7 条。

Spark 在付款后会立即入帐，而且马上就能使用，所以**购买完成后，原则上不接受取消、退货或退款**。不过，下列情况请联系我们，我们会确认你的申请：

- 已经付款，但 Spark 没有入帐
- 因为 MYMI 的重大故障，无法使用你买的 Spark
- 购买画面上的内容，和实际收到的内容有很大差异
- 被重复扣款，或有人未经你同意就购买
- 依法令或 PayPal 的规则需要退款

是否退款，以及退款的方式和时间，会依付款纪录、使用纪录、错误纪录、PayPal 的规则和适用法令来判断。如果那笔购买的 Spark 已经用了一部分，可能只有没用到的部分能退。用签到、活动或邀请朋友免费获得的 Spark 不能退款。

退款会依适用法律、PayPal 及商店规则处理。你依法享有的权利不会因为本指南而受到限制。

### 申请退款

1. 寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
2. 写上你的 MYMI ID（**个人资料**昵称下方的 `@ID`）、付款日期与金额、PayPal 交易 ID，以及发生了什么事。交易 ID 可以在 PayPal 寄来的收据信，或 PayPal 活动纪录里该笔付款的详细数据中找到。
3. 我们会确认你的申请并用电子邮件回复。如果核准退款，款项会退回你付款时使用的方式。需要多久，取决于 PayPal 和发卡银行。

## 在 App 付款时

App 内的付款，要在商店的购买纪录申请退款。这要依商店的退款政策和审核，MYMI 无法决定商店是否核准。

- **iPhone**：依照 Apple 支持的[针对向 Apple 购买的 App 或内容要求退款](https://support.apple.com/zh-cn/118223)操作。
- **Android**：依照 Google Play 说明中心的[退款政策](https://support.google.com/googleplay/answer/2479637?hl=zh-Hans)操作。

商店核准退款后，那笔付款获得的 Spark 可能会被收回。

## 付款后没收到 Spark 时

再次付款之前，请依序确认。

1. 网页版请刷新充值画面；App 请完全关闭后再重新打开。Android App 会重新确认未完成的付款，Spark 入帐后会显示「已复原先前的购买」。
2. 在**个人资料 → 我的 Spark → 查看使用纪录**的**充值**分页，看有没有这笔购买纪录。
3. 还是没有的话，请附上下列数据，寄信到 [contact@mymi.live](mailto:contact@mymi.live)。iPhone App 重新打开后仍没入帐的话，请不要等待，直接联系我们。

| 付款的地方 | 要提供的数据 |
| --- | --- |
| 网页版 | 付款日期、付款金额、MYMI ID、PayPal 交易 ID |
| App | 商店（App Store 或 Google Play）、付款日期、订单编号或交易 ID、MYMI ID |

## 遇到问题时

<details>
<summary>我在 App 付款的，可以向 MYMI 申请退款吗？</summary>

App 内付款的退款，MYMI 无法处理。请在 App Store 或 Google Play 的购买纪录申请。如果已经付款但 Spark 没有入帐，请联系 MYMI。

</details>

<details>
<summary>我用掉一部分 Spark 了，还能退款吗？</summary>

网页版的购买，可能只有没用到的 Spark 能退款。如果是 MYMI 这边的问题，让你没办法正常使用，请寄信到 [contact@mymi.live](mailto:contact@mymi.live) 说明状况。

</details>

<details>
<summary>我向 PayPal 或银行提出了付款争议</summary>

争议审查期间，我们可能会先保留那笔购买的 Spark。如果款项被撤销，这些 Spark 会从你的账号收回。可以的话，提出争议之前请先联系我们。

</details>

<details>
<summary>我想在删除账号之前先退款</summary>

删除账号后，剩下的 Spark 会消失，所以要退款请在删除之前申请。如果已经删除账号，请寄信到 [contact@mymi.live](mailto:contact@mymi.live)，附上已删除账号的 MYMI ID 和付款数据。

</details>
