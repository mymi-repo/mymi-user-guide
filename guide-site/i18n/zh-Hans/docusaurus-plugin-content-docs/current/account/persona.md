# 人设设置

人设是**你在作品中使用的名字与身份**。同一部作品也可以用「失去记忆的幸存者」或「民宇的老朋友」等不同身份聊天。人设只会用在聊天中。作品的创作者名称和公开个人资料显示的是你的昵称。

:::tip[想更换已经在聊天中的聊天室的身份时]
请在聊天室右上角 ⋮ 菜单的**聊天设置 → 人设**中更换。步骤请见[在聊天中的聊天室更换](#在聊天中的聊天室更换)。
:::

## 预设、主要、推荐是什么意思？

| 种类 | 意思 |
| --- | --- |
| **预设** | 用注册时设置的名称和性别创建。修改**编辑个人资料 → 我的信息**时会一起改变，而且无法删除 |
| **主要** | 开始新聊天时一开始就选好的人设。一开始预设人设就是主要人设 |
| **推荐人设** | 创作者为该作品准备的身份。在作品详情中选择 |

**个人资料 → 人设设置**的卡片上会标示**预设**、**主要**。一张卡片也可能同时有两个标示。

## 创建人设

1. 打开**个人资料 → 人设设置**。
2. 点击**添加人设**。
3. 填好下列项目后，点击上方的**保存**。

| 项目 | 填写方式 |
| --- | --- |
| **名称** | 角色称呼你的名字。必填，最多 20 字 |
| **出生日期** | 要填的话，请填完年、月、日。只能保存年满 14 岁的日期 |
| **性别** | 从**女性**、**男性**中选择 |
| **详细信息** | 你的身份、个性、说话方式、与角色的关系，最多 1,000 字 |

只填名称也可以保存。如果主要会使用新创建的人设，请[设为主要人设](#设置主要人设)。

### 详细信息范例

> 我叫小晴，25 岁。在地下城市的检疫所醒来，只记得自己在地面上做过送货的工作。对陌生人说话会用敬语，有疑问就会立刻问。今天第一次见到民宇。

简短写下你的身份、说话方式、与角色的关系，以及现在想做的事，角色会比较容易理解。

## 设置主要人设

在**个人资料 → 人设设置**中，点击要使用的人设卡片。卡片上出现**主要**标示后，下次开始新聊天时就会选好这个人设。

## 开始聊天时选择

1. 点击作品详情画面下方**开始聊天**右侧的小型个人资料图标。
2. 在**我的人设**或**推荐人设**分页中选一个，再点击**确认选择**。
3. 点击**开始聊天**。如果这部作品已经聊过，请点击**开始新聊天**。

在选择窗口中，也可以用卡片上的铅笔按钮修改内容。

- 修改并保存**我的人设**后，你清单中的那个人设也会改变。
- 修改**推荐人设**的内容只会用在这次聊天。想继续使用的话，请另外创建成自己的人设。

点击**继续先前聊天**时，会沿用该聊天室中使用的人设。

## 在聊天中的聊天室更换

在清单中修改人设后，会从新开始的聊天起生效。已经在聊天中的聊天室，请在该聊天室中更换。

1. 点击聊天室右上角的 ⋮ 按钮。
2. 点击**聊天设置**中的**人设**。
3. 在**编辑人设**窗口中直接修改名称和详细信息，或用**加载**选择一个自己的人设。
4. 点击**保存**。从下一则回复开始，就会用更换后的人设聊天。

聊天纪录会照原样延续。想用新身份从头开始的话，请在作品详情选好人设后点击**开始新聊天**。

## 修改与删除

在**个人资料 → 人设设置**中，点击卡片右侧的 ⋮ 按钮。

- **编辑**：修改内容后点击**保存**。预设人设的**编辑**会打开**编辑个人资料**画面。
- **删除**：只能删除自己添加的人设。

:::danger[删除不会再次确认]
点击**删除**会立刻删除，不会出现确认窗口，而且无法复原。删除主要人设后，预设人设会成为主要人设。用那个人设聊天的聊天室仍然可以继续使用。
:::

## 要在哪里更换？

| 想更换的内容 | 更换的位置 |
| --- | --- |
| 之后开始的聊天要用的名字与身份 | 在**人设设置**中修改，或设为主要 |
| 目前聊天中的聊天室的名字与身份 | 聊天室 ⋮ 菜单的**聊天设置 → 人设** |
| 只用在这次要开始的聊天的身份 | 开始聊天前，用个人资料图标选择 |
| 注册时设置的名称和性别（预设人设） | **编辑个人资料 → 我的信息** |

## 遇到问题时

<details>
<summary>改了名称，角色却还用旧名字叫我</summary>

已经在聊天中的聊天室，必须在该聊天室中更换。请在聊天室 ⋮ 菜单的**聊天设置 → 人设**中，用**加载**选择修改后的人设，再点击**保存**。

</details>

<details>
<summary>新创建的人设没有用在聊天中</summary>

新创建的人设不是主要人设。请在清单中点击那张卡片设为主要，或在开始聊天时用个人资料图标选择。

</details>

<details>
<summary>填了出生日期后无法保存</summary>

请确认年、月、日都已填写，而且是实际存在的日期。显示「需满14岁才能保存。」时，请改成年满 14 岁的日期。出生日期也可以留空直接保存。

</details>

<details>
<summary>预设人设没有删除选项</summary>

预设人设无法删除。点击**编辑**会打开**编辑个人资料**，可以在那里修改名称和详细信息。

</details>

<details>
<summary>看不到推荐人设分页</summary>

这是创作者没有准备推荐人设的作品。请从**我的人设**中选择。

</details>

<details>
<summary>不小心删除了人设</summary>

删除的人设无法复原。请用相同内容重新创建。用那个人设聊天的聊天室都还在。

</details>

如果还是无法解决，请从**个人资料 → Discord** 前往 Discord 的询问频道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
