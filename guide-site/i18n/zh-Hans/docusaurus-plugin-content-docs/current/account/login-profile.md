# 登录与个人资料设置

说明如何用注册的账号重新登录、修改个人信息与个人资料照片，以及注销。

## 登录

1. 点击下方菜单的**个人资料**。在网页版，也可以点击首页右上角的**登录**。
2. 点击注册时使用的社区账号按钮（**使用 LINE 继续**、**使用 Google 继续**、**使用 X 继续**、**使用 Apple 继续**）并完成登录。
3. 在网页版，登录完成后会前往首页。请用**个人资料**最上方的昵称和 `@ID` 确认是不是自己的账号。

:::warning[请用注册时的社区账号登录]
每个社区账号都有各自的 MYMI 账号。用其他社区账号登录时，会出现**注册**画面。在这里注册会创建一个没有聊天纪录和 Spark 的新账号，请返回并用最初注册的社区账号登录。
:::

## 找到要修改的项目

点击**个人资料**最上方有个人资料照片和昵称的那一列，会打开**编辑个人资料**。这里有**我的信息**和**创作者**两个分页。

| 要修改的内容 | 前往的位置 |
| --- | --- |
| 角色称呼你的名称、性别、出生日期、详细信息 | **编辑个人资料 → 我的信息** |
| 昵称、`@ID` | **编辑个人资料 → 我的信息** |
| 个人资料照片、网站、公开介绍 | **编辑个人资料 → 创作者 → 编辑个人资料** |
| 每部作品不同的名字或身份 | **个人资料 → 人设设置** |
| 显示语言 | **个人资料**最下方的**语言设置** |

## 修改名称、昵称与 ID

1. 打开**编辑个人资料**的**我的信息**分页。
2. 修改想改的项目。
3. 点击上方的**保存变更**。按下这个按钮，修改的内容才会保存。

| 项目 | 用途 |
| --- | --- |
| **名称** | 角色会这样称呼你 |
| **性别**、**出生日期** | 角色会参考的你的信息 |
| **昵称** | 其他用户看到的名字，也是作品的创作者名称 |
| **ID** | 你的 `@ID`，用在公开个人资料的网址 |
| **详细信息** | 角色在聊天中会参考的你的信息，最多 1,000 字 |

ID 规则和[注册](/account/sign-up.md#id-规则)相同。输入后会立即检查是否重复，请在看到**可使用**后再保存。修改 ID 后，公开个人资料的网址也会改变。如果之前分享过个人资料链接，请重新分享新的网址。

## 修改个人资料照片与公开介绍

1. 在**编辑个人资料**中点击**创作者**分页。
2. 点击**编辑个人资料**。
3. 点击个人资料照片的位置，从设备中选择照片。等待上传完成。
4. 需要的话，修改**网站**和**介绍**（最多 10,000 字）。
5. 点击**保存**。

即使没有制作作品，也可以编辑公开个人资料。公开个人资料会显示昵称、ID、个人资料照片、网站和介绍。**我的信息**中的详细信息只会用在聊天中。

:::tip[这和个人资料的创作者按钮不同]
**个人资料**首页中位于**我的 Spark** 下方的**创作者**按钮，会打开创作者申请与仪表板。个人资料照片要在**编辑个人资料**里的**创作者**分页修改。
:::

## 切换显示语言

点击**个人资料**最下方的**语言设置**，选择**简体中文**或其他已提供的语言，再点击**确认**。

切换语言后，画面上的文字会改变。手机号码验证、年龄确认的方式与付款方式，仍会维持注册时的设置。

## 注销

点击**个人资料 → 设置与支持 → 注销**。要再次使用时，请用注册时的社区账号登录。如果想删除整个账号，请参阅[删除账号](/account/delete-account.md)。

## 在个人资料中找到菜单

| 想做的事 | 打开的菜单 |
| --- | --- |
| 查看剩余的 Spark 和到期日，或充值 | **我的 Spark** |
| 查看创作者申请条件与进度 | **创作者** |
| 继续修改制作中的作品 | **内容管理** |
| 重新查看封锁的作品或创作者 | **封锁管理** |
| 在每部作品用不同的名字与身份聊天 | **人设设置** |
| 查看追踪的创作者或自己写的留言 | **我的活动** |
| 每天免费领取 Spark | **签到** |
| 邀请朋友，或输入收到的推荐码 | **邀请朋友** |
| 查看消息或询问问题 | **Discord** |
| 也想看到被归类为敏感内容的作品 | **设置与支持 → 显示敏感内容**。请参阅[年龄确认与手机号码验证](/account/adult-verification.md) |
| 在 App 中询问时想提供使用环境 | **设置与支持 → 版本信息 → 复制客服信息** |

## 遇到问题时

<details>
<summary>找不到 LINE 按钮</summary>

在网页版，日文、繁体中文和简体中文画面会显示 LINE 按钮。请点击登录按钮下方的语言链接（언어 설정、Language Settings、言語設定、語言設定），切换成**简体中文**。App 没有 LINE 按钮，用 LINE 注册的话请在网页版登录。

</details>

<details>
<summary>登录后出现了注册画面</summary>

你用了和最初注册时不同的社区账号登录。请不要注册，返回后用最初注册的社区账号登录。如果有多个 Google 账号，请确认选的是注册 MYMI 时用的那一个。

</details>

<details>
<summary>看不到先前的聊天纪录和 Spark</summary>

可能是用其他社区账号登录，创建了新账号。请点击**个人资料 → 设置与支持 → 注销**，再用最初注册的社区账号重新登录。

</details>

<details>
<summary>App 没有 X 按钮，或 Android App 没有 Apple 按钮</summary>

App 没有 LINE 和 X 登录，Android App 也没有 Apple 登录。请用 Chrome 或 Safari 打开 [www.mymi.live/zh-Hans](https://www.mymi.live/zh-Hans)，用注册时的按钮登录。

</details>

<details>
<summary>保存变更按不下去</summary>

没有修改任何项目，或输入内容有错误。请看字段下方的提示修正。如果修改了 ID，请确认是否显示**可使用**。

</details>

<details>
<summary>改了名称，角色却还用旧名字叫我</summary>

修改后的名称会从新开始的聊天起使用。已经在聊天中的聊天室，请在右上角 ⋮ 菜单的**聊天设置 → 人设**中，用**加载**选择预设人设后点击**保存**。

</details>

<details>
<summary>个人资料照片没有改变</summary>

选好照片后，要等上传完成并点击**保存**才会改变。App 询问照片访问权限时，请允许。

</details>

如果还是无法解决，请从**个人资料 → Discord** 前往 Discord 的询问频道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
