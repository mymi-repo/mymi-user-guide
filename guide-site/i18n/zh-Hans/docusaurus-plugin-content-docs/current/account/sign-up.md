# 注册

用 LINE、Google、X、Apple 其中一个账号登录后，设置名称、ID 与昵称就完成注册了。使用前请阅读适用于账号的服务条款；简体中文海外服务按年满 18 岁的国际服务条件提供。

:::warning[注册前，请确认显示语言]
简体中文注册使用现有国际服务的认证与支付规则，网页充值使用 USD／PayPal。注册时选择的语言会影响账号适用的服务规则；这不代表你的实际所在地，也不会改变应用商店的销售国家。

如果希望使用简体中文，请依下列步骤切换后再注册。已有账号切换显示语言，不会更改原本的认证政策、余额或购买记录。

1. 点击下方菜单最右边（个人资料）。
2. 点击登录按钮下方的语言链接（언어 설정、Language Settings、言語設定、語言設定）。
3. 选择**简体中文**，再点击确认按钮（확인、Confirm、确认）。
:::

## 选择登录按钮

1. 打开 [www.mymi.live/zh-Hans](https://www.mymi.live/zh-Hans)，点击下方菜单的**个人资料**。也可以从聊天时出现的登录窗口开始。简体中文目前先提供网页版；App 更新前可使用繁体中文等现有语言。
2. 点击要用来注册的社区账号按钮。依使用环境，看到的按钮如下表。
3. 在该服务完成登录后，会打开 MYMI 的**注册**画面。

| 使用环境 | 登录按钮 |
| --- | --- |
| 电脑・手机网页版 | **使用 LINE 继续**、**使用 Google 继续**、**使用 X 继续**、**使用 Apple 继续** |
| Android App | **使用 Kakao 继续**、**使用 Google 继续** |
| iPhone App | **使用 Apple 继续**、**使用 Kakao 继续**、**使用 Google 继续** |

:::tip[先决定要用哪个社区账号注册]
每个社区账号都会创建各自的 MYMI 账号。之后也必须用注册时的社区账号登录，聊天纪录和 Spark 才会接续。如果也要使用 App，请用 Google（只用 iPhone 的话也可以用 Apple）注册。LINE 和 X 只能在网页版使用，Android App 也没有 Apple 登录。
:::

## 设置名称、ID 与昵称

| 项目 | 用途 | 输入 |
| --- | --- | --- |
| **显示名称** | 角色称呼你的名字 | 最多 20 字 |
| **性别设置** | 角色会参考的你的性别 | 从**女性**、**男性**、**其他**中选一个 |
| **用户 ID** | 像 `@moon_reader` 这样用来辨识你的地址 | 3～20 字，需符合下方规则 |
| **昵称** | 其他用户看到的名字 | 最多 30 字 |

例如把显示名称设为 `小晴`、昵称设为 `月光读者`，角色会叫你「小晴」，其他用户则会看到「月光读者」。想在不同作品中用不同名字聊天，注册后可以在 [人设设置](/account/persona.md)中添加。显示名称、ID 与昵称在注册后也能到[登录与个人资料设置](/account/login-profile.md)中修改。

在 App 中，**显示名称**字段可能已经预先填入社区账号的名字。可以改成你希望在聊天中被称呼的名字。

### ID 规则

- 只能使用英文小写字母、数字、底线（`_`）和连字号（`-`）。大写字母会变成小写，其他字符无法输入。
- 长度为 3～20 字。
- 不能以 `_` 或 `-` 开头或结尾。
- `_` 和 `-` 不能连续使用。`__`、`--`、`_-` 都不行。

| 例子 | 结果 |
| --- | --- |
| `moon_reader`、`reader-123` | 可以使用 |
| `ab` | 少于 3 个字 |
| `_reader`、`reader-` | 以 `_` 或 `-` 开头或结尾 |
| `moon__reader`、`moon-_reader` | `_` 和 `-` 连续使用 |

输入 ID 后，字段右侧会立即显示结果。看到**可使用**就能继续下一步。显示**不可使用**表示已经有人在用，请换一个 ID；显示**格式无效**时，请再确认上方的规则。

## 同意条款

| 项目 | 是否必要 |
| --- | --- |
| **同意服务条款** | 必要 |
| **同意搜集与使用个人数据** | 必要 |
| **服务准则** | 必要 |
| **同意接收行销信息** | 选填 |

- 点击各项目**左侧的方框**即可勾选同意。点击项目名称会打开全文。
- 点击**全部同意**，连选填的行销信息也会一起勾选。不想收到的话，再点一次那个方框取消勾选。

## 完成注册

在条件全部满足前，画面下方的按钮会显示为灰色箭头。填好四个项目、ID 显示**可使用**，并勾选三个必要项目后，按钮就会变成**完成注册**。点击后就完成注册并前往首页。如果是从聊天室打开的登录窗口注册，会回到那个聊天室，而不是首页。

聊天需要 Spark，可以充值取得。目前签到等奖励需要完成手机号码验证。若账号画面明确提示「请在 App 中领取」，请按该提示操作。具体条件以账号页面为准，方法请见[年龄确认与手机号码验证](/account/adult-verification.md)与[充值 Spark](/payment/payment-methods.md#签到)。

## 遇到问题时

<details>
<summary>完成注册按钮一直是灰色箭头</summary>

还有没完成的条件。

- 显示名称、性别设置、用户 ID、昵称都填好了吗？
- 用户 ID 字段右侧有显示**可使用**吗？
- 三个必要项目都勾选了吗？要点击左侧的方框，不是点项目名称。

</details>

<details>
<summary>点击项目后打开了条款页面</summary>

点击项目名称会打开全文。读完后请回到注册画面，点击名称左侧的方框勾选。

</details>

<details>
<summary>显示「此 ID 已被使用。」</summary>

这个 ID 已经有人在用。请加上数字或 `_`，换一个 ID 试试。

</details>

<details>
<summary>显示「检查时发生错误，请再试一次。」</summary>

请确认网络连接，再点击用户 ID 字段右侧的**检查**重新确认。

</details>

<details>
<summary>显示「重新加入受限」与「删除账号后 30 天内无法重新加入。」</summary>

用这个社区账号创建的 MYMI 账号删除后还不到 30 天。30 天后就能用同一个社区账号重新注册，并以新账号开始。现在也可以改用其他社区账号注册，但在删除的账号中验证过的手机号码，要等删除后满 30 天才能再次使用。

</details>

<details>
<summary>显示「注册期间发生问题。」或「登录期间发生问题。」</summary>

点击<strong>请再试一次！</strong>按钮会回到首页。请从头重新登录。如果是在 LINE、Instagram 等 App 里打开，请改用 Chrome 或 Safari 打开 [www.mymi.live/zh-Hans](https://www.mymi.live/zh-Hans) 再试一次。

</details>

<details>
<summary>明明注册过了，却出现注册画面</summary>

你用了和最初注册时不同的社区账号登录。在这里注册会创建新账号，请返回并用最初注册的社区账号登录。如果有多个 Google 账号，请确认选的是注册 MYMI 时用的那一个。

</details>

<details>
<summary>用 LINE 或 X 注册的账号无法登录 App</summary>

App 没有 LINE 和 X 登录，Android App 也没有 Apple 登录。请在网页版登录：在手机上也可以用 Chrome 或 Safari 打开 [www.mymi.live/zh-Hans](https://www.mymi.live/zh-Hans)，点击和注册时相同的按钮。

</details>

如果还是无法解决，请附上画面上出现的文字，从**个人资料 → Discord** 前往 Discord 的询问频道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
