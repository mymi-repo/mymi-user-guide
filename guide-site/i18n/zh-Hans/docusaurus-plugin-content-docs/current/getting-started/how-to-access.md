# 如何使用 MYMI

MYMI 的网页版与 Android、iPhone App 使用同一个账号。在电脑上请从网页版开始，在手机上可以用 App 或手机浏览器。

## 用网页版打开

1. 用 Chrome 或 Safari 等浏览器打开 [www.mymi.live/zh-Hans](https://www.mymi.live/zh-Hans)。不需要安装任何东西。
2. 第一次进入时，会出现「选择你最想看的角色」窗口。从**女性角色**、**男性角色**、**全部都想看**中选一个，首页就会优先显示有该类角色登场的作品。之后可以在首页的筛选中更改。
3. 打开喜欢的作品聊聊看。不登录也能聊天，最多 5 次。次数的算法和条件请看[不登录也能和 AI 聊天吗？](/faq/chat-without-login.md)。

试用用完后会出现登录窗口。在试用时的浏览器或 App，用没在 MYMI 用过的社区账号注册新账号，试用时的对话就会移到新账号。注册方法请见[注册](/account/sign-up.md)。成人作品需要登录并完成年龄确认（年满 18 岁）才能打开。

## 安装 App

| 设备 | 安装 |
| --- | --- |
| Android | [在 Google Play 安装 MYMI](https://play.google.com/store/apps/details?id=live.mymi.app&hl=zh_CN) |
| iPhone | [在 App Store 安装 MYMI](https://apps.apple.com/app/id6794338974) |

如果是用手机浏览器打开 MYMI，也可以点击首页右上角的**安装 App**前往商店。打开安装好的 App 后，从下方菜单的**个人资料**登录或注册。

## 同时使用网页版与 App

网页版与 App 使用同一个账号。用注册时的社区账号登录，聊天纪录和 Spark 都会一样。

:::warning[如果你是用 LINE、X 或 Apple 注册]
App 没有 LINE 和 X 登录，Android App 也没有 Apple 登录。这种情况请在网页版登录：在手机上也可以用 Chrome 或 Safari 打开 [www.mymi.live/zh-Hans](https://www.mymi.live/zh-Hans)，点击和注册时相同的按钮。
:::

## 画面下方的菜单

| 菜单 | 可以做的事 |
| --- | --- |
| **首页** | 寻找作品 |
| **聊天** | 打开聊过的作品，接着聊下去 |
| **创建** | 创作自己的作品 |
| **个人资料** | 登录、查看个人信息与 Spark、签到、内容管理 |

## 遇到问题时

<details>
<summary>在 LINE 或 Instagram 打开链接后无法登录</summary>

在其他 App 里打开链接时，会用该 App 内置的浏览器打开，可能因此无法登录。请从画面上方或下方的菜单（⋮ 或 …）选择「用浏览器打开」之类的项目，改用 Chrome 或 Safari 打开。如果没有这种菜单，请复制网址贴到浏览器。

</details>

<details>
<summary>出现「试试更好的浏览体验！」窗口</summary>

这是在 TikTok App 里打开链接时出现的提示。请从 TikTok 画面右上角的「…」菜单选择「在浏览器中打开」。也可以点击窗口中的**复制链接**，再贴到浏览器。

</details>

<details>
<summary>画面打不开，或一直在加载</summary>

1. 确认网络连接后刷新，或关闭 App 再重新打开。
2. 如果浏览器或 MYMI App 有更新，请先安装。
3. 改用其他浏览器打开看看。
4. 只有某个浏览器有问题时，请照着[清除 Cookie](/faq/cookie-clear.md) 操作。清除后需要重新登录。

</details>

<details>
<summary>在 App 登录后，先前的对话不见了</summary>

可能是用了和网页版注册时不同的社区账号登录。每个社区账号都有各自的 MYMI 账号。请点击**个人资料 → 设置与支持 → 注销**，再用最初注册的社区账号重新登录。

</details>

如果还是无法解决，请从**个人资料 → Discord** 前往 Discord 的询问频道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。在 App 中，可以用**个人资料 → 设置与支持 → 版本信息**的**复制客服信息**复制使用环境，一并提供给我们。
