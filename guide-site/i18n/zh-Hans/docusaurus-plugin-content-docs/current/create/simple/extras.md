# 设定集、组件与选填

**设定集**、**组件**、**选填**是选填步骤。空着也可以完成作品，想加入时再填写即可。如果加入了，里面的必填字段都要填好，才能用下一步按钮往下走。

## 设定集 {/* #lorebook */}

设定集是**对话中出现关键字时，才把该条目的内容传给 AI 的设置**。写下不必随时知道、但名称一出现就必须知道的内容，例如世界观的用语、地点、组织、角色的秘密。

写在世界观的文字，AI 每次都会读，但条目只有在关键字出现时才会读。把每次都需要的设置放在基本信息步骤的世界观和角色，偶尔才出现的设置放在设定集，就能让世界观保持简短。

<ScreenStep src="/img/screens/zh-Hans/simple-lorebook.png" alt="简易模式的设定集清单与添加操作" caption="设定集步骤">

1. 点击**添加设置**。最多可以创建 100 个。
2. 展开卡片，填写**名称**、**关键字**、**内容**。
3. 再点一次卡片就会收合，只显示名称和关键字。卡片上的垃圾桶图标可以删除。

</ScreenStep>

- **名称**：条目的名称。最多 50 字。会和内容一起传给 AI。
- **关键字**：对话中出现这些词语时，就会传出内容。最多 5 个，每个最多 10 字。写好后按 Enter 或逗号加入。不区分大小写。
- **内容**：只写关键字出现时 AI 必须知道的事。最多 400 字。

这是范例作品的条目。

| 名称 | 关键字 | 内容 |
| --- | --- | --- |
| 管理局 | 管理局、局长 | 统治地下城市的机关。管理检疫所与出入口，传闻会抹除从地表下来的人的纪录。民宇是接到管理局的命令才行动的。 |
| 7号出口 | 7号出口、七号出口 | 通往地表的唯一出口。自 2031 年封锁后一直关闭，没有管理局的许可证就无法靠近。 |

**怎么找出并传出**

- 会在用户传的消息，以及**最近 10 则消息**中寻找关键字。
- 关键字即使出现在其他词语里面也找得到。关键字 `管理局` 在「管理局长来了」中也找得到。空格有区别，所以 `7号出口` 在「7 号出口」中找不到。
- 符合的条目有好几个时，会从最近出现的开始挑，一次最多传出 **3 个，合计 1,500 字**。

**挑选关键字的诀窍**

- 写对话中真的会出现的词语。缩写和昵称也一并放入。可以空格也可以不空格的名称，两种都放入。
- 避免太常见的词。几乎每次对话都会符合，真正需要的条目反而可能挤不进那 3 个。
- 内容简短，只写事实。说话方式与进行方向，写在世界观和角色描述里。

## 组件 {/* #components */}

组件是 **AI 在聊天中显示的 UI**。把想显示的东西做好，例如状态窗口、道具栏、选项，AI 就会在需要时调用。不懂代码，也可以通过**用 Google AI Studio 制作**来做。

<ScreenStep src="/img/screens/zh-Hans/simple-components.png" alt="简易模式的组件预览与代码编辑入口" caption="组件步骤">

1. 点击**添加组件**，创建卡片。
2. 展开卡片，把代码贴到 **JSX 代码**字段。函数名称和变量会自动从代码读取。
3. 在**使用描述**写下何时使用这个组件。
4. 在卡片里的预览确认在聊天中会是什么样子。卡片上的眼睛图标可以收合、展开预览。

</ScreenStep>

- **JSX 代码**：`function 名称({ 变量 = 默认值 })` 形式的代码。最多可以写 10,000 字。代码围栏和 import 语句会自动整理。
- **变量默认值**：显示从代码读到的变量与默认值。默认值会用在预览，也会成为 AI 填入值的范例。
- **使用描述**：最多 500 字。这是 AI 判断何时使用这个组件的依据。

这是范例作品的状态窗口代码。必须有函数名称（`StatusWindow`）和至少一个变量（`hp`、`mp`）。

```jsx
function StatusWindow({ hp = 100, mp = 40 }) {
  const bar = (value, color) => (
    <div className="h-2 w-full rounded-full bg-slate-700">
      <div className={`h-2 rounded-full ${color}`} style={{ width: `${Math.max(0, Math.min(100, value))}%` }} />
    </div>
  );
  return (
    <div className="my-2 w-full max-w-sm rounded-xl border border-cyan-400/40 bg-slate-900/90 p-3 text-slate-100">
      <div className="mb-2 flex items-center justify-between text-[11px] font-bold tracking-widest text-cyan-300">
        <span>STATUS</span>
        <span>检疫所 B-3</span>
      </div>
      <div className="space-y-2 text-sm">
        <div>
          <div className="mb-1 flex justify-between"><span>体力</span><span>{hp}/100</span></div>
          {bar(hp, "bg-rose-400")}
        </div>
        <div>
          <div className="mb-1 flex justify-between"><span>魔力</span><span>{mp}/100</span></div>
          {bar(mp, "bg-sky-400")}
        </div>
      </div>
    </div>
  );
}
```

> 范例 — 使用描述：`战斗开始时与体力变化时显示。hp = 体力，mp = 魔力。`

AI 会读取组件的名称、使用描述、变量与默认值，并在适当的时机，把像 `<StatusWindow hp={100} mp={40} />` 这样的标记放进回复。如果在使用描述中写下**何时使用**和**变量的意思**，AI 就会把值填得比较恰当。

:::info[组件是用来显示的工具]
组件只是把 AI 放入的值画得好看。像体力计算这样，值对不对要看 AI 的回复。就算写了说明，AI 偶尔也可能漏掉标记，或是放入不同的值。
:::

**用 AI Studio 制作**

不懂代码，也可以和 Gemini 对话来制作组件。从组件步骤上方的**用 Google AI Studio 制作**开始。

1. 点击**复制作品信息**。作品设置和图片网址会一起复制。
2. 点击**打开 Google AI Studio**。第一次使用时，用 **Remix** 创建自己的工作室。
3. 在输入框粘贴作品信息，再在下方写一两行想要的样子后送出。
4. 完成后点击 **MYMI에 붙여넣을 코드 복사**（复制 MYMI 代码），再贴到 MYMI 的**添加组件** → **JSX 代码**字段。
5. 复制 Gemini 回复中写着何时显示的句子，贴到**使用描述**字段。没有这句话，组件就不会出现在聊天中。

点击**使用指南**，会打开分步骤的说明。实际的 AI Studio 画面请见[跟着 Google AI Studio 画面操作](/create/ai-studio)。

:::info
可在 Google 账号的免费请求额度内使用。不需要付款或 API 密钥。
:::

## 选填

**选填**步骤有详细说明、推荐人设、创作者备注。因为是最后一个步骤，按钮会变成**完成**。

### 详细说明

用 HTML 美化要显示在作品介绍画面的文字。不使用的话，作品介绍会原封不动显示世界观和角色描述。

<ScreenStep src="/img/screens/zh-Hans/simple-optional.png" alt="简易模式的详细说明、推荐人设与创作者备注" caption="选填步骤 · 详细说明">

1. 在**使用**与**不使用**之间选择。**不使用**是只使用标准文件。
2. 选了**使用**，就会出现 HTML 输入栏。最多 50,000 字。
3. 输入栏下方会显示检查结果。显示「安全 HTML」就可以直接使用。点击「包含不安全标签」旁边的**自动清理**，就会去除那些标签。「非 HTML 文字」表示那不是 HTML 代码的文字。
4. 如果是 HTML，下方会出现**预览**。确认用户看到的样子。

</ScreenStep>

**用 AI Studio 制作**

不懂 HTML，也可以和 Gemini 对话来制作介绍页。从详细说明标题下方的**用 Google AI Studio 制作**开始。

1. 点击**复制作品信息**。作品设置、图片网址和目前写的详细说明会一起复制。
2. 点击**打开 Google AI Studio**。第一次使用时，用 **Remix** 创建自己的工作室。
3. 在输入框粘贴作品信息，再在下方写一两行想要的样子后送出。
4. 完成后，在上方确认已选择**프로필 HTML**（个人介绍 HTML），再点击 **MYMI에 붙여넣을 코드 복사**（复制 MYMI 代码）。
5. 在 MYMI 的详细说明选择**使用**，贴到 HTML 输入栏。用预览确认后点击**完成**。

点击**使用指南**，会打开分步骤的说明。实际的 AI Studio 画面请见[跟着 Google AI Studio 画面操作](/create/ai-studio)。

:::info
可在 Google 账号的免费请求额度内使用。不需要付款或 API 密钥。
:::

:::info[AI 不会读详细说明]
详细说明是显示在作品介绍画面的文字。AI 需要知道的设置，请写在基本信息步骤。
:::

### 推荐人设

这个功能让你事先做好用户开始聊天时可以选择的人设。想提出适合作品世界的主角时使用。不做也可以。

点击**添加人设**来创建。如果创建了，四个字段都要填好，才能用下一步按钮或**完成**按钮往下走。

- **名称**：最多 20 字
- **性别**：女性・男性
- **出生日期**：写下年、月、日。必须年满 14 岁。
- **详细信息**：写下个性、背景、说话方式，让 AI 知道该如何对待扮演这个人设的用户。最多 1,000 字

### 创作者备注

留下关于作品的消息。最多 3,000 字。会显示在作品介绍画面，AI 不会读。点击**清除**会清掉文字。

## 遇到问题时

<details>
<summary>显示「有设置条目没有关键字。」</summary>

请确认有没有写下关键字并按 Enter 或逗号加入。卡片上看得到关键字才算加入。做到一半的条目，用垃圾桶图标删除。名称或内容是空的条目，也会出现同样的提示。

</details>

<details>
<summary>显示「请将组件代码撰写为 function component。」</summary>

请确认代码是不是以 `function 名称(...)` 的形式开头。箭头函数或没有名称的函数，读不到名称。

</details>

<details>
<summary>显示「请至少添加一个组件变量名称。」</summary>

函数必须声明至少一个接收的变量。例：`function StatusWindow({ hp = 100 })`

</details>

<details>
<summary>显示「请输入组件使用描述。」</summary>

展开组件卡片，写下**使用描述**。请确认有没有组件的卡片上出现红字标示，例如「需要使用描述」、「需要 JSX 代码」。

</details>

<details>
<summary>显示「请完成推荐人设信息。」</summary>

你创建的人设中，名称、性别、出生日期、详细信息有空的字段。出生日期不能是不存在的日期、未来的日期，或未满 14 岁。不打算使用的人设，请删除。

</details>

<details>
<summary>作品介绍没有显示世界观，只显示 HTML 文字</summary>

因为你把**详细说明**选成了**使用**。写了 HTML 介绍的话，会显示那段文字，而不是世界观和角色。想显示世界观和角色描述的话，请改成**不使用**。

</details>
