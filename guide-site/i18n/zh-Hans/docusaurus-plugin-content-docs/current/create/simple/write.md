# 撰写设置与介绍

在简易模式中，AI 每次聊天都会读取的文字，是**基本信息**步骤的世界观、角色、秘密。对话的第一个场景，则在**介绍**步骤决定。这一页说明这些文字该怎么写比较好。

## 作品标题与一句话简介

- **作品标题**最多 30 字。AI 也会把它当作作品的名称来读。开场中的 `{{char}}` 在聊天时会换成这个标题。
- **一句话简介**最多 40 字。这是和标题一起显示在作品卡片上的句子。AI 不会读。

## 世界观

在**世界观**写下作品的背景与规则，以及故事如何开始。简易模式没有另外写进行规则的字段，所以故事的开始与方向也写在世界观里。

```md
2031 年，地表受到污染而遭弃置。人们搬进了由地铁站与地下商街相连而成的地下城市首尔生活。
城市由管理局控管，通往地表的通道已被封锁。新进入的人会先在检疫所停留。

用户失去所有记忆，在检疫所的病床上醒来。故事从民宇带用户走出检疫所开始，当用户试图找回记忆时，书妍会一次给一条线索。
```

- **只写用户可以知道的内容。** 没有写详细说明的话，世界观会原封不动显示在作品介绍画面。反转或隐藏的内情请写在**秘密**。
- **写得简短明确。** AI 每次聊天都会读世界观。不是越长越好。
- **只在出现特定词语时才需要的设置，交给设定集。** 组织名称、地点、用语这类不必随时知道的设置，写在 [设定集](/create/simple/extras#lorebook) 里，只有那个词语出现时才会传给 AI。
- **可以使用 Markdown。** `##` 标题、`-` 清单、`**粗体**` 会在作品介绍画面以那样的样式显示。

## 角色

<ScreenStep src="/img/screens/zh-Hans/simple-basic-characters.png" device="part" alt="简易模式中的多位角色信息编辑" caption="角色">

点击**添加角色**来增加角色。为每个角色写下**名称**（最多 50 字）和**描述**。角色卡片上的**收合**与**编辑**可以收起、展开卡片，**删除**可以移除。

至少要有 1 个，而且名称不能重复。名称重复时，会跳出「发现重复的角色名称」的提示。

</ScreenStep>

- **为每个角色写下定位、个性、说话方式、关系。** 说话方式 AI 会原样模仿，所以写得具体一点比较好，例如「不用敬语」、「简短的敬语」。
- **描述也会显示在作品介绍画面。** 角色有两个以上时，名称与描述会出现在**角色**清单中。不能让用户知道的内情，写在**秘密**。
- **名称在素材步骤也会用到。** 每张图片都要链接到某个角色，所以先写好角色，再进入素材步骤。

这是范例角色的描述。

| 名称 | 描述 |
| --- | --- |
| 姜民宇 | `地下城市的引路人，32 岁。总爱开玩笑、个性悠哉，说话不用敬语，句尾拖长。似乎知道一些关于用户的事。` |
| 李书妍 | `检疫所医师，28 岁。公事公办、冷静，说话用简短的敬语。怀疑用户的失忆并非意外。` |

## 秘密

**秘密**是 AI 知道、但用户看不到的设置。这是选填字段，不会显示在作品介绍画面。

```md
- 民宇接到监视用户的命令。在用户主动追问之前，不会透露。
- 用户的记忆是管理局抹除的。
```

**也要一并写下何时揭露。** 如果没有条件，只写「民宇正在监视」，AI 可能太早就揭露。像「在用户主动追问之前，不会透露」这样写下条件，AI 比较容易遵守。

## 字数总计

世界观、角色描述、秘密**合计最多 10,000 字**。世界观字段上方的**世界观 + 角色描述 + 秘密总用量**，会用数字和进度条显示已经用了多少、还剩几字。字数越多颜色越会改变，到了 10,000 字就无法再输入。角色名称不计入这个总计。

## 介绍

介绍是聊天开始时 AI 先传出的第一则消息。它是用户最先遇到的场景，决定了作品给人的第一印象。至少要有 1 个开场。

<ScreenStep src="/img/screens/zh-Hans/simple-intro.png" alt="简易模式的开场文字与即时预览" caption="介绍步骤">

1. 写下**开场标题**。这是用户挑选开始场景时看到的名称。
2. 在下方字段写下第一则消息。最多 2,000 字。字段下方的数字是已经写的字数。
3. 点击**清除**，会清掉这个开场的文字。其他开场与标题维持原样。
4. 在**预览**确认在聊天中会是什么样子。

点击开场标签旁的**添加**，可以再创建开场。创建多个的话，用户开始聊天时会选其中一个。可以用标签上的垃圾桶图标删除，但只剩一个开场时不能删除。

</ScreenStep>

第一则消息要用和聊天相同的格式来写。

| 写法 | 显示的样子 |
| --- | --- |
| `*日光灯闪烁的检疫所。*` | 动作与叙述（斜体） |
| `"哦，终于醒了～"` | 对话（强调色） |
| `{{user}}` | 聊天时会换成用户的名称 |
| `{{char}}` | 聊天时会换成**作品标题**。不是角色的名称 |

```md
*日光灯闪烁的检疫所。消毒水的气味之中，有人拉开了帘子。*

"哦，终于醒了～你整整睡了三天耶？"

*一名穿着旧军装外套的男子转着手电筒笑了起来。他自称是引路人姜民宇。*

"这里是首尔。更正确地说，是首尔的地底～所以，{{user}}。除了名字，你还记得什么吗？"
```

:::tip[角色名称请直接写出来]
在角色很多的作品里使用 `{{char}}`，放进去的会是作品标题，而不是角色名称。开场中请直接写下「姜民宇」这样的名称。
:::

在开场放入素材图片的方法，请见[素材与 AI 图片](/create/simple/assets#在开场放入图片)。

### 写出好的第一个场景的诀窍

- **在第一则消息的结尾，把要做的事交给用户。** 范例以「除了名字，你还记得什么吗？」这个问题结尾，用户可以马上回答。
- **让角色的说话方式和描述一致。** 如果角色描述写了「不用敬语、句尾拖长」，开场的对话也要那样写。AI 比较容易从第一则消息延续说话方式。
- **试着创建多个开始场景。** 在同一个世界里，放入起点不同的开场，用户就能挑选后开始。

## 遇到问题时

<details>
<summary>想在世界观或角色描述多写一点，却打不进去</summary>

世界观、角色描述、秘密加起来已经到 10,000 字了。请删减不是必要的部分，或是把只在出现特定词语时才需要的设置移到**设定集**。

</details>

<details>
<summary>跳出「发现重复的角色名称」</summary>

有两个以上的角色名称相同。英文名称不区分大小写与前后空格，会视为相同的名称。请把名称改成互不相同。

</details>

<details>
<summary>显示开场的标题或内容是空的</summary>

你创建的开场中，有标题或内容是空的。请逐一点击开场标签来确认。不打算使用的开场，请用标签上的垃圾桶图标删除。

</details>

<details>
<summary>预览中 `{{user}}` 原样显示</summary>

预览中不会替换，在实际聊天时才会换成用户的名称。

</details>
