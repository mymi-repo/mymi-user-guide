# 编辑作品

用简易模式创建的作品，在和创建时相同的七步骤画面中修改。作品会以创建时的模式打开，所以用专家模式创建的作品要怎么修改，请见[公开与修改](/create/publish#修改已公开的作品)。

## 打开方式与移动

1. 在**个人资料 → 内容管理**，点击作品的**编辑**。
2. 会以简易模式打开。最上方的**创作模式**字段是锁定的，而且会先显示**基本信息**步骤。
3. 前往要修改的步骤并修改。可以点击上方的分页直接移动。
4. 都改好之后，用下一步按钮走到最后的**选填**步骤，点击**完成**。会再检查所有步骤，并前往**作品制作完成**画面。

移动与保存是这样运作的。

| 移动 | 检查 | 保存 |
| --- | --- | --- |
| 下一步按钮 | 目前步骤的必填项目 | 到目前为止修改的内容 |
| 点击分页**往前** | 到那个步骤之前的所有步骤 | 到目前为止修改的内容 |
| 点击分页**往回** | 不检查 | 不保存。下次往前走时会一并保存 |
| **完成** | 所有步骤 | 到目前为止修改的内容 |

在素材中上传、删除图片、**保存**情境说明、更换 ★ 个人资料图片，不必按下一步按钮就会立刻反映到作品。

:::warning[已公开的作品，每次往下走都会立刻改变]
简易模式每次按下一步按钮，或用分页往前走，都会把改过的内容保存到作品。如果作品已经公开，从那一刻起其他用户也会看到改过的内容。它不会像专家模式的**套用变更**那样等你确认。要大幅修改时，请先把要改的文字写在记事本之类的地方，粘贴之后再往下走。
:::

:::warning[删除图片时要小心]
在已公开的作品删除素材图片，会立刻从作品中消失。如果你把那张图片放在开场，或是对话中正在使用，可能就不会再显示了。删除之前，请一并确认开场里的图片那一行。
:::

## 第一次打开以前做的作品时

以前做的作品没有的字段增加了。第一次打开时，下列字段可能是空的，要选好才能从**设置**步骤往下走。

- **类型** 1～2 个
- **标签**至少 1 个（**读者群**不是标签，要在读者群卡片中选择）
- **收益限制**
- **同意行销使用**

设置步骤的卡片样式和文字，已经和专家模式相同。每张卡片代表什么，请见[选择作品设置](/create/settings)。作品标题最多 30 字。

## 各步骤可以修改的内容

各步骤的写法和创建时相同。

| 步骤 | 可以修改的内容 | 说明 |
| --- | --- | --- |
| **基本信息** | 标题、一句话简介、世界观、角色、秘密 | [撰写设置与介绍](/create/simple/write) |
| **素材** | 添加、删除图片，情境说明，角色链接，个人资料图片，需要解锁 | [素材与 AI 图片](/create/simple/assets) |
| **介绍** | 添加、删除开场，标题，第一则消息 | [撰写设置与介绍](/create/simple/write#介绍) |
| **设置** | 类型、标签、公开设置、作品公开范围等 | [选择作品设置](/create/settings) |
| **设定集 · 组件 · 选填** | 条目、组件、详细说明、推荐人设、创作者备注 | [设定集、组件与选填](/create/simple/extras) |

## 更改公开设置

- **想暂时下架作品**，请在**设置 → 公开设置**选**不公开**，再按下一步按钮保存。
- **想把不公开的作品改成公开**，请在同一张卡片选**公开**并保存。改成公开的作品要经过审查，其他用户才看得到。（[公开与修改](/create/publish#把不公开的作品改成公开)）
- **作品公开范围**设为原创的作品，3 个月内无法更改。剩余天数会显示在卡片上。

## 遇到问题时

<details>
<summary>点击编辑后，创作模式字段出现锁头</summary>

从内容管理打开的作品，会以创建时的模式打开，而且无法更改模式。想创建新作品，请点击 <strong>↺</strong> 清空编辑画面，再选择模式。（[开始之前](/create/before-you-start#从内容管理打开的作品模式会被锁定)）

</details>

<details>
<summary>无法前往下一步</summary>

前面的步骤有缺少的必填项目。请确认上方跳出的提示。如果是素材步骤，请看是否至少有 1 张图片、每张图片都有情境说明，以及有没有设置个人资料图片。如果是设置步骤，请看是否选了类型、标签、**读者群**、**作品公开范围**、**收益限制**、**图片来源**、**同意行销使用**。

</details>

<details>
<summary>跳出「有尚未保存的内容」窗口</summary>

简易模式的编辑画面还留着其他作品或新作品尚未保存的内容。点击**打开**，那些内容会消失，并打开你选的作品。想保留的话，请点击**取消**，先在编辑画面用下一步按钮保存。

</details>

<details>
<summary>显示「找不到作品。」</summary>

这是在其他设备上删除的作品，或不是你的作品。编辑画面会被清空，请在**内容管理**确认作品是否还在。

</details>

<details>
<summary>没有提示词分页</summary>

简易模式没有提示词分页。想自己撰写提示词，就必须用专家模式创建新作品。没有把既有作品改成专家模式的按钮。（[移到专家模式](/create/simple/to-expert)）

</details>

<details>
<summary>想把改错的内容还原</summary>

没有还原按钮。请把改变的字段再改一次，用下一步按钮保存。已公开的作品，保存过的内容会立刻被看到，所以大幅修改前请先做笔记。

</details>

<details>
<summary>同一部作品在电脑和手机上同时开着修改</summary>

会保留后保存的那一边的内容。想换到另一台设备继续修改，请先在原本的设备按下一步按钮保存，再到另一台设备的**内容管理**点击**编辑**打开。离开编辑画面超过 5 分钟再回来时，如果这台设备没有尚未保存的内容，画面会换成服务器上的最新内容。

</details>
