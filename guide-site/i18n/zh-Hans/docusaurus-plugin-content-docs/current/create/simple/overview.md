# 认识简易模式

简易模式是**填写字段，MYMI 就会把内容汇整成 AI 设置**的方式。用右下角的 **>**（下一步）按钮，依序走过八个步骤来制作。如果是第一次制作，请先从[用简易模式创建第一个作品](/create/simple/first-work)开始。


截图中的作品、账号和内容均为说明用的虚构示例。简体中文先提供网页版，App 更新前可使用繁体中文等现有语言。

## 用简易模式打开

- 新作品预设是简易模式。只要点击下方菜单的**创建**即可。如果打开的是其他模式，请在**基本信息**分页最上方的**创作模式**点击**简易模式**。（[开始之前](/create/before-you-start#选择创作模式)）
- 在**个人资料 → 内容管理**点击用简易模式创建的作品的**编辑**，就会以简易模式打开。

## 画面与八个步骤

<ScreenStep src="/img/screens/zh-Hans/simple-overview.png" alt="简易模式的分页导航与基本信息" caption="简易模式画面">

1. **↺**（重设创建内容）：清空正在输入的画面，从头重新开始。已经保存的草稿会留在**内容管理**。
2. **分页列**：基本信息 · 素材 · 介绍 · 设置 · 设定集 · 组件 · 选填。目前的步骤会以紫色显示。
3. **>**（下一步）按钮：确认这个步骤并保存后，前往下一步。最后一个步骤会变成**完成**。

</ScreenStep>

:::info[分页名称和专家模式略有不同]
**介绍**是对话开始时 AI 先传出的第一则消息，专家模式称为**开场**。
:::

| 步骤 | 要写什么 | 一定要填吗 |
| --- | --- | --- |
| **基本信息** | 作品标题、一句话简介、世界观、角色、秘密 | 只有秘密可以不填 |
| **素材** | 要显示在对话中的图片、每张图片的情境说明、个人资料图片（作品的代表图片） | 必填 |
| **介绍** | 对话开始时 AI 先传出的第一则消息 | 必填 |
| **设置** | 类型、标签、公开设置、作品公开范围等管理项目 | 必填 |
| **设定集** | 只在出现特定词语时才传给 AI 的设置 | 选填 |
| **组件** | 状态窗口、选项等在对话中弹出的 UI | 选填 |
| **选填** | 详细说明、推荐人设、创作者备注 | 选填 |

设定集、组件、选填都空着，也可以完成作品。各步骤的写法请见[撰写设置与介绍](/create/simple/write)、[素材与 AI 图片](/create/simple/assets)、[设定集、组件与选填](/create/simple/extras)。

## AI 读取的内容与用户看到的内容

在简易模式中，要知道哪个字段的文字由 AI 读取、哪个字段的文字由用户看到，写起来才有把握。

| 字段 | AI 聊天时 | 用户看到的地方 |
| --- | --- | --- |
| 作品标题 | 会读 | 作品卡片、作品介绍 |
| 一句话简介 | 不会读 | 作品卡片 |
| 世界观 | 会读 | 作品介绍（没有写详细说明时） |
| 角色名称与描述 | 会读 | 作品介绍（没有写详细说明时） |
| 秘密 | 会读 | 不会显示 |
| 素材的情境说明 | 会读（图片输出指示为**内部图片**时） | 不会显示 |
| 组件的使用描述与变量 | 会读 | 不会显示 |
| 设定集 | 只有出现关键字时才会读 | 不会显示 |
| 详细说明（选填） | 不会读 | 作品介绍 |
| 创作者备注 | 不会读 | 作品介绍 |

:::warning[世界观与角色描述，用户也看得到]
如果没有写**详细说明**，作品介绍画面的**详细说明**区域，就会直接显示世界观，以及角色的名称与描述。不想让用户知道的设置，请写在**秘密**字段，不要写在世界观或角色描述里。秘密只有 AI 会读，用户看不到。
:::

## 何时会保存

- 按下一步按钮时，会检查该步骤的必填项目，全部填好的话，就把目前为止写的内容保存到作品，再前往下一步。第一次在**基本信息**按下一步按钮时，作品会被创建，并以**制作中**的状态出现在**个人资料 → 内容管理**。
- 点击上方分页**往前**走时也一样。会检查并保存到那个步骤之前的每一个步骤。**往回**走时不会检查，也不会保存，改过的内容会在下次往前走时一并保存。
- 素材不一样。上传、删除图片、**保存**情境说明、更换 ★ 个人资料图片，不必按下一步按钮就会立刻反映到作品。
- 在最后一个步骤按**完成**，会再检查所有步骤并创建作品。接着会打开**作品制作完成**画面。

:::warning[已公开的作品，每次往下走都会立刻改变]
简易模式每次按下一步按钮，或用分页往前走，都会把改过的内容保存到作品。如果作品已经公开，从那一刻起其他用户也会看到改过的内容。它不会像专家模式的**套用变更**那样等你确认。要大幅修改时，请先把要改的文字写在记事本之类的地方，粘贴之后再往下走。
:::

:::tip[关闭画面之前]
在按下一步按钮之前关闭画面，该步骤改过的内容不会保存到服务器。注销或改用其他账号登录时，尚未保存的内容也会被清除。如果写到一半要停下来，请先按下一步按钮保存。
:::

## 一定要填写的项目

按下一步按钮时，如果下列项目是空的，就会出现提示而无法往下走。提示一次只会出现一个。

| 步骤 | 检查的项目 |
| --- | --- |
| 基本信息 | 作品标题、一句话简介、世界观、至少 1 个角色（名称与描述）、名称是否互不相同 |
| 素材 | 至少 1 张图片、个人资料图片、所有图片的情境说明 |
| 介绍 | 至少 1 个开场，且每一个都有标题和内容 |
| 设置 | 1～2 个类型、至少 1 个标签、作品公开范围、收益限制、图片来源、读者群、同意行销使用 |
| 设定集 | 每个添加的设置条目的名称、关键字、内容 |
| 组件 | 每个添加的组件的使用描述、代码、函数名称、至少 1 个变量 |
| 选填 | 每个添加的推荐人设的名称、性别、生日、详细信息 |

**公开设置**（公开）、**内容分级**（全年龄）、**图片输出指示**（内部图片）一开始就选好了。各字段的字数限制整理在[输入项目与限制](/create/simple/reference)。

## 遇到问题时

<details>
<summary>按了下一步却没有往下走，只跳出提示</summary>

表示这个步骤或前面的步骤缺少必填项目。提示文字会告诉你是哪个字段。

- 基本信息：「请输入作品标题。」「请输入世界观。」「请至少添加一个角色。」
- 素材：「请至少添加一个素材。」「请选择个人资料图片。」「请输入素材描述。」
- 介绍：「请输入开场白标题。」「请输入开场白内容。」
- 设置：「请选择1～2个类型。」「请添加至少一个标签。」「请选择读者群。」

照提示填好后，再按一次下一步按钮。

</details>

<details>
<summary>写在世界观的内容，原封不动显示在作品介绍画面</summary>

没有写详细说明时，作品介绍会显示世界观和角色描述，这是正常的运作方式。需要对用户隐藏的设置，请移到**秘密**字段。想自己美化作品介绍的话，请在**选填**把**详细说明**改成**使用**，再用 HTML 写介绍文字。这样就会显示那段文字，而不是世界观和角色。（[设定集、组件与选填](/create/simple/extras#详细说明)）

</details>

<details>
<summary>没有提示词分页</summary>

简易模式没有提示词分页。MYMI 会把你写在世界观、角色、秘密字段的内容汇整后交给 AI。想自己撰写提示词，请把创作模式改成**专家模式**，再创建新作品。（[移到专家模式](/create/simple/to-expert)）

</details>

<details>
<summary>同一部作品在两台设备上同时开着修改</summary>

会保留后保存的那一边的内容。想换到另一台设备继续修改，请先在原本的设备按下一步按钮保存，再到另一台设备的**个人资料 → 内容管理**点击**编辑**打开。离开编辑画面超过 5 分钟再回来时，如果这台设备没有尚未保存的内容，画面会换成服务器上的最新内容。

</details>
