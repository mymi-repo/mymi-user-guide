# 移到专家模式

没有把用简易模式创建的作品改成专家模式的功能。两种模式的内容也不会自动转移。如果想在专家模式自己写写看提示词，请创建**新作品**，再把设置抄过去。

## 移动之前要知道的事

- 新作品是**另一部作品**。原本作品的对话、按赞、留言，都不会转移到新作品。
- 创建新作品之后，**原本的作品会保留**。如果不想再让人看到，请从**个人资料 → 内容管理 → 编辑**打开，把**设置 → 公开设置**改成**不公开**，再按下一步按钮保存。
- 移动的过程中需要原本作品的文字。先把世界观、角色描述、秘密、情境说明复制到记事本之类的地方，或是在另一台设备上开着原本的作品，边看边抄会比较方便。

## 移动的顺序

1. 先把原本作品的文字复制起来。
2. 点击下方菜单的**创建**。如果编辑画面开着从内容管理打开的作品，请点击 <strong>↺</strong> 清空编辑画面。内容管理中的原本作品会保留。
3. 在**基本信息**分页最上方的**创作模式**，点击**专家模式**。如果是第一次，请在窗口中点击**切换到专家模式**。
4. 对照下面的表格抄写。
5. 点击**完成制作**。

## 各项目要抄到哪里

| 在简易模式写的地方 | 在专家模式要写的地方 | 抄的时候要做什么 |
| --- | --- | --- |
| 基本信息 → 作品标题 · 一句话简介 | 基本信息 → 作品标题 · 一句话简介 | 原样抄过去 |
| 基本信息 → 世界观 | 提示词 → 作品信息（基本型）或本文（自行撰写） | 抄写时代、地点、规则 |
| 基本信息 → 角色 | 提示词 → 作品信息的角色 | 在名称那一行下面，写下定位、个性、说话方式、关系 |
| 基本信息 → 秘密 | 提示词 → 作品信息的隐藏设置 | 也要一并写下揭露的条件。不要抄到详细说明 |
| 素材 → 角色链接 | 素材的角色文件夹 + 提示词中角色代码的含义 | 为每个角色创建文件夹，并让文件夹代码和名称对应 |
| 素材 → 情境说明 | 素材的图片代码 + 提示词中情境代码、其他代码的含义 | 相同的情境，所有角色都用相同的代码 |
| 素材 → 个人资料图片（★） | 基本信息 → 封面 | 封面是 1～10 张。可以从素材带入 |
| 开场的 `img:[名称]` | 开场的 `![]({{URL}}/A/1.webp)` | 用**插入素材图片**重新放入 |
| 设置 → 类型 · 标签 | 基本信息 → 类型 · 标签 | 专家模式在基本信息分页 |
| 设置 → 其余卡片 | 其他设置 | 卡片和选项都相同。重新选择 |
| 组件 → 使用描述 | 提示词 → 组件输出规则（基本型）或本文（自行撰写） | 抄写何时、用什么值来调用 |
| 选填 → 详细说明（HTML） | 基本信息 → 详细说明 | 详细说明是必填。也可以使用 HTML |
| 选填 → 创作者备注 | 基本信息 → 创作者指南 | 原样抄过去 |
| 选填 → 推荐人设 | 其他设置 → 推荐人设 | 原样抄过去 |
| 设定集 | 设定集 | 原样抄过去名称、关键字、内容 |

## 容易漏掉的东西

不要只抄世界观和角色描述就结束。下面这些也要一并处理。

1. **图片的情境说明** → 素材的代码与提示词中代码的含义。在简易模式，是 MYMI 汇整情境说明传给 AI，但在专家模式，必须自己在提示词中写下何时放图片。
2. **组件的使用描述** → 提示词的组件输出规则。
3. **开场的 `img:[名称]`** → 用新的素材代码放入的图片那一行。专家模式不会读 `img:[…]`。
4. **详细说明（HTML）与创作者备注** → 详细说明、创作者指南。
5. **以前放入的对话范例** → 提示词。现在的简易模式画面看不到，但以前放过对话范例的作品，那些范例仍然会传给 AI。它们不会转移到新作品，所以需要的说话方式或范例，请自己写进提示词。

### 范例：移动一张图片

假设在简易模式有一张链接到角色**姜民宇**、情境说明写「姜民宇笑得很开朗。」的图片（`img:[AB3K9X]`），在专家模式要这样移。

1. 在**提示词**的作品信息中，写下民宇的定位、个性、说话方式。
2. 在**素材**创建角色文件夹 `A`，并以代码 `1` 放入那张图片。
3. 如果是基本型，在**图片输出规则**写下角色代码 `A` = `姜民宇`、情境代码 `1` = `笑`。
4. 如果是自行撰写，请在本文中写下图片的含义，以及何时、以什么形式放入。
5. 删除开场里用的 `img:[AB3K9X]`，再用**插入素材图片**放入 `A/1`。

专家模式的图片架构，在[准备图片](/create/images)和[在对话中显示图片](/create/images-in-chat)有详细说明。

## 遇到问题时

<details>
<summary>打开简易模式的作品后，专家模式按钮按不下去</summary>

从内容管理打开的作品，会锁定在创建时的模式。点击 <strong>↺</strong> 清空编辑画面，锁定就会解除，可以重新选择模式。内容管理中的原本作品不会被删除。（[开始之前](/create/before-you-start#从内容管理打开的作品模式会被锁定)）

</details>

<details>
<summary>把简易模式的开场贴到专家模式，图片却没有显示</summary>

专家模式不会读 `img:[…]`。开场预览在那个位置也会显示「无法加载图片」。请删掉那一行，再用第一则消息字段的**插入素材图片**重新放入。

</details>

<details>
<summary>移过去的作品，聊天中没有显示图片</summary>

在简易模式，是 MYMI 汇整情境说明传给 AI，但在专家模式，必须在提示词中写下何时放图片。如果是基本型，请填好**图片输出规则**中代码的含义；如果是自行撰写，请把图片规则写在本文。做法请见[在对话中显示图片](/create/images-in-chat)。

</details>

<details>
<summary>在简易模式写的内容，专家模式的画面上没有</summary>

两种模式的草稿是分开的。简易模式的内容不会转移到专家模式。请对照上面的表格，自己抄写过去。

</details>
