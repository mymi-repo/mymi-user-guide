# 输入项目与限制

这里整理了简易模式画面的限制与规则。详细的使用方法，请见各项目的说明页面。

## 字数与数量

| 步骤 | 项目 | 限制 |
| --- | --- | --- |
| 基本信息 | 作品标题 | 必填 · 30 字 |
| | 一句话简介 | 必填 · 40 字 |
| | 世界观 · 角色描述 · 秘密 | 三个字段合计 10,000 字。世界观与至少 1 个角色（名称与描述）为必填，秘密为选填 |
| | 角色名称 | 50 字。角色之间不能重复 |
| 素材 | 图片 | 必填 · 1～200 张。JPG、PNG、WEBP、GIF、HEIC · 最大 5MB |
| | 情境说明 | 每张图片都必填 · 60 字 |
| | 个人资料图片 | 必填 · 用 ★ 选一张 |
| | 一次制作的 AI 图片 | 基础图片 2 张、变体图片 1 张 |
| 介绍 | 开场 | 必填 · 至少 1 个，标题和内容都要有 |
| | 内容 | 2,000 字 |
| 设置 | 类型 | 必填 · 1～2 个 |
| | 标签 | 必填 · 至少 1 个（不含读者群） |
| | 作品公开范围 · 收益限制 · 图片来源 · 读者群 · 同意行销使用 | 必填 |
| 设定集 | 条目 | 最多 100 个 |
| | 名称 | 50 字 |
| | 关键字 | 每个条目 5 个，每个 10 字 |
| | 内容 | 400 字 |
| | 一次传出的量 | 从最近 10 则消息中寻找，最多 3 个 · 1,500 字 |
| 组件 | 使用描述 | 每个组件都必填 · 500 字 |
| | JSX 代码 | 必填 · 10,000 字。需要函数名称与至少 1 个变量 |
| 选填 | 详细说明（HTML） | 选填 · 50,000 字 |
| | 推荐人设 | 选填。创建的话，名称（20 字）、性别、出生日期（满 14 岁）、详细信息（1,000 字）都要有 |
| | 创作者备注 | 选填 · 3,000 字 |

**公开设置**（公开）、**内容分级**（全年龄）、**图片输出指示**（内部图片）一开始就选好了。

## 下一步与完成时会检查的项目

按下一步按钮或**完成**按钮时，会依照下列顺序检查，并显示第一个被拦下的项目的提示。**完成**会再检查全部八个步骤。

| 顺序 | 步骤 | 检查的项目 |
| --- | --- | --- |
| 1 | 基本信息 | 作品标题、一句话简介、世界观、至少 1 个角色、角色的名称与描述、名称是否重复 |
| 2 | 素材 | 至少 1 张图片、个人资料图片、所有图片的情境说明 |
| 3 | 介绍 | 至少 1 个，且每一个都有标题和内容 |
| 4 | 设置 | 依照 类型 → 标签 → 作品公开范围 → 收益限制 → 图片来源 → 读者群 → 内容分级 → 同意行销使用 的顺序 |
| 5 | 设定集 | 每个添加的条目的名称、关键字、内容 |
| 6 | 组件 | 每个添加的组件的使用描述、代码、函数名称、至少 1 个变量 |
| 7 | 选填 | 每个添加的推荐人设的名称、性别、出生日期、详细信息 |

## 图词组法

简易模式会用你在**设置 → 图片输出指示**选的方式输出图片。只能使用一种方式。

| 方式 | 语法 | 使用的地方 |
| --- | --- | --- |
| 内部图片 | `img:[名称]` | 上传到素材的图片。素材卡片上会显示像 `img:AB3K9X` 这样的名称 |
| 外部图片 | `![](图片网址)` | 写在设置里的外部图片网址 |

在开场中要写成像 `img:[AB3K9X]` 这样。名称是 MYMI 决定的 6 个英文大写字母与数字。使用内部图片时，AI 会依据你为每个素材写的**情境说明**与链接的角色，决定要放哪张图片。使用外部图片时，情境说明不会传给 AI，它会依据设置里写的图片网址或网址规则来放图片。如果不知道网址，就不会放图片。

:::warning[专家模式不使用]
`img:[名称]` 是简易模式的语法。专家模式的作品，请使用素材分页的代码和 `![]({{URL}}/A/1.webp)`。
:::

## `{{user}}` 与 `{{char}}`

| 使用的地方 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 开场 | 聊天时会换成用户的名称 | 聊天时会换成**作品标题** |

开场的预览中不会替换，会原样显示。`{{char}}` 放进去的是作品标题，而不是角色名称，所以角色名称要自己写出来。

## 保存

| 情况 | 何时保存 |
| --- | --- |
| 所有作品 | 按下一步按钮时、点击分页往前走时、按**完成**时。在那之前修改的内容会一并保存 |
| 素材 | 上传、删除图片、**保存**情境说明、更换 ★ 个人资料图片，会立刻反映到作品 |
| 已公开的作品 | 保存的那一刻，其他用户也会看到改过的内容 |

## 免费与验证

- 图片生成、重新生成有每周免费额度，超出后需要 Spark 并先确认。当前需要手机号码验证；具体以账号画面为准。
- 成人限定的作品，只有完成成人验证的用户才能使用。
- 图片生成的标签步骤中的安全过滤器，只有完成成人验证的账号才能关闭。

## 遇到问题时

<details>
<summary>显示「保存失败。」</summary>

可能是保存时连接中断，或服务器暂时忙碌。请稍后再按一次下一步按钮。如果一直出现相同的提示，请从**个人资料 → Discord** 前往询问频道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)，告诉我们是在哪个作品的哪个步骤发生的。

</details>

<details>
<summary>字打不进去了</summary>

超过各字段规定的字数就无法输入。基本信息步骤的上限是世界观、角色描述、秘密合计 10,000 字，所以也请确认其他字段写了多少。

</details>
