# 开始之前

MYMI 的作品由 **AI 读取的设置**和**用户看到的画面**组成。制作这两部分的方式有两种。只要填写字段就能完成的**简易模式**，以及由你自己撰写 AI 读取设置的**专家模式**。新作品会从简易模式开始。

## 选择创作模式

点击下方菜单的**创建**，就会打开**创建作品**画面。第一个分页**基本信息**的最上方，就是**创作模式**字段。网页版与 App 的画面配置相同。

<ScreenStep src="/img/screens/zh-Hans/mode-card.png" alt="创建作品前选择简易模式或专家模式" caption="创作模式字段">

1. **简易模式**：填好字段，AI 设置就会自动产生。
2. **专家模式**：自己撰写 AI 读取的设置与输出规则。

点击后模式会切换，并打开所选模式的**基本信息**分页。第一次会选在简易模式，之后则会以这台设备上最后使用的模式打开。

</ScreenStep>

## 两种模式有什么不同

| | 简易模式 | 专家模式 |
| --- | --- | --- |
| 撰写 AI 设置的地方 | **基本信息**里的世界观、角色、秘密字段。MYMI 会汇整后交给 AI | **提示词**分页。分栏撰写的**基本型**，或整段写下的**自行撰写** |
| 图片 | 为每张图片写下**情境说明**，并链接角色。AI 会看说明挑选合适的图片 | 用文件夹与代码整理，并在提示词中写下何时显示 |
| 状态窗口等组件 | 在每个组件的**使用描述**中写下何时使用 | 写在提示词的**组件输出规则**中 |
| 画面 | 八个步骤。按下一步按钮依序前进 | 八个分页。想从哪个分页开始写都可以 |
| 保存 | 每按一次下一步按钮，就会保存到作品 | 切换分页时会自动保存。有**保存草稿**与**完成制作** |
| 修改已公开的作品 | 修改的内容在用下一步按钮前往下一步的瞬间生效 | 要点击**套用变更**才会生效 |
| 一定要有的图片 | 至少 1 张**素材**，以及用 ★ 选好的个人资料图片 1 张 | **封面** 1～10 张。素材可以没有 |

两种模式也有相同的地方。公开前的审查和内容管理都一样，决定 Leaf 比率的**作品公开范围**、**图片来源**、**收益限制**等设置也一样。选择设置的方法请见[选择作品设置](/create/settings)。

## 该选哪一种模式

适合**简易模式**的情况：

- 第一次制作作品。
- 想从只把世界观和角色写进字段开始。
- 图片只要告诉 AI「这个场景用这张图片」就够了。

适合**专家模式**的情况：

- 想自己设计要交给 AI 的设置和进行规则。
- 想用规则精确决定图片与组件何时出现。
- 想放入多张封面，或想在分页之间自由来回作业。

这并不是说哪一种比较好。请依照你想怎么制作作品来选择。作品介绍画面的配置会依模式而略有不同。

## 切换模式后，写过的内容会怎么样

- 两种模式的**草稿是分开的**。切换模式后，写过的内容会留在原本的模式，不会移到另一个模式。再切换回来就能接着写。
- **↺**（重设创建内容）只会清空目前模式的草稿。确认窗口会写明要清空的是哪一个模式的草稿。
- 已保存到服务器的草稿，会以**制作中**的状态留在**个人资料 → 内容管理**。重设也不会删除。

<ScreenStep src="/img/screens/zh-Hans/mode-intro.png" alt="第一次切换到专家模式时的说明与确认" caption="第一次选择专家模式时">

**第一次**选择专家模式时，会跳出一个窗口。阅读说明后点击**切换到专家模式**就会切换。点击**取消**，模式维持不变。这个窗口只会看到一次。

窗口下方写着「在简易模式写的内容会保留，不会移到专家模式。」

</ScreenStep>

:::tip[想保住写过的内容，先保存]
正在输入的内容，在保存到服务器之前只存在这台设备上。注销或改用其他账号登录时，尚未保存的内容会被清除。简易模式请按下一步按钮，专家模式请切换分页或点击**保存草稿**。保存的时机依模式而不同，各模式的说明会再详细介绍。
:::

## 从内容管理打开的作品，模式会被锁定

在**个人资料 → 内容管理**点击作品的**编辑**，会以创建该作品时的模式打开。这时创作模式字段是锁定的。

<ScreenStep src="/img/screens/zh-Hans/mode-locked.png" device="part" alt="从内容管理打开作品后显示不能切换模式的提示" caption="从内容管理打开的作品的创作模式字段">

- 没有更改已创建作品模式的功能。想用另一种模式重做，请创建新作品，再把设置抄过去。简易模式的作品，可以参考[移到专家模式](/create/simple/to-expert)的做法。
- 想创建新作品时，点击 <strong>↺</strong> 清空编辑画面。锁定就会解除，可以重新选择模式。内容管理中的作品会保留。

</ScreenStep>

如果目前模式的编辑画面有**尚未保存的内容**，又从内容管理打开其他作品，会跳出确认窗口。点击**打开**，尚未保存的内容会消失，并打开该作品。点击**取消**则什么都不会改变。

## 本指南的范例作品

创作指南会从头到尾制作一部范例作品**地下城市首尔**，一边做一边说明。两种模式的说明都使用同一部作品，所以你可以比较用两种方式制作同一部作品时有什么不同。

## 遇到问题时

<details>
<summary>创作模式字段的另一个按钮出现锁头，按不下去</summary>

因为这是从内容管理打开的作品。已创建作品的模式无法更改。想创建新作品，请点击 <strong>↺</strong> 清空编辑画面，再选择模式。内容管理中的作品不会被删除。

</details>

<details>
<summary>切换到专家模式后，写过的内容不见了</summary>

两种模式的草稿是分开的。在简易模式写的内容不会移到专家模式，但也没有消失。在创作模式字段再点击一次**简易模式**，内容还在。想把内容带过去，请依照[移到专家模式](/create/simple/to-expert)自己抄写过去。

</details>

<details>
<summary>跳出「要切换到专家模式吗？」的窗口</summary>

这是第一次选择专家模式时，只会出现一次的说明窗口。阅读说明后点击**切换到专家模式**即可。如果还没决定，点击**取消**，模式维持不变。

</details>

<details>
<summary>在内容管理点击编辑后，显示「有尚未保存的内容」</summary>

因为该模式的编辑画面还留着其他作品或新作品尚未保存的内容。点击**打开**，那些内容会消失，并打开你选的作品。想保留的话，请点击**取消**回到编辑画面，先保存。已保存的草稿会以**制作中**的状态在内容管理里。

</details>

<details>
<summary>图片创建窗口里也有「专家模式」</summary>

生成图片最后一步展开的**专家模式**，和创作模式是不同的功能。那是用来更改图片生成设置（`negative_prompt`、guidance 等）的字段，与作品的制作方式无关。两种模式用的是同一个图片生成窗口。

</details>

<details>
<summary>「基本型」与「自行撰写」和简易模式、专家模式不一样吗？</summary>

不一样。**基本型**与**自行撰写**是在专家模式的**提示词**分页中选择的两种撰写方式。简易模式没有提示词分页。详情请见[撰写提示词](/create/prompt)。

</details>

<details>
<summary>点了重设，制作到一半的作品不见了</summary>

重设只会清空作品制作画面。已保存的草稿会以**制作中**的状态留在**个人资料 → 内容管理**。点击**编辑**就能重新打开。

</details>
