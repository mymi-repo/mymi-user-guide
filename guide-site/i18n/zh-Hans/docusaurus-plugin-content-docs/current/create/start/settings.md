# 选择作品设置

这些设置决定作品如何公开，以及获得 Leaf 的条件。在**其他设置**中选择，简易模式与专家模式使用相同的卡片。

- 简易模式：**设置**步骤。上方有**类型**与**标签**，下方接着本页的卡片。
- 专家模式：**其他设置**分页。**类型**与**标签**在**基本信息**分页。

标有红色 `*` 的卡片一定要选。**公开设置**与**内容分级**一开始就选好了，其余的要自己选，才能完成作品。

## 一览

| 卡片 | 选项 | 初始值 |
| --- | --- | --- |
| **公开设置** | 公开 · 不公开 | 公开 |
| **作品公开范围** | 原创 · 一般 | 未选择 |
| **收益限制** | 无限制 · 限制收益 | 未选择 |
| **图片来源** | MYMI 生成 · 外部制作 | 未选择 |
| **读者群** | 男性向 · 女性向 | 未选择 |
| **内容分级** | 全年龄 · 成人限定 | 全年龄 |
| **同意行销使用** | 同意 · 不同意 | 未选择 |

## 公开设置

决定要让谁看到作品。

- **公开**：所有用户都能看到。设为公开的新作品，要经过审查，其他用户才看得到。
- **不公开**：只有你自己能看到。公开之前，想先试聊时使用。

之后可以在**个人资料 → 内容管理 → 编辑**的**其他设置**中更改。把不公开的作品改成公开，从那时起开始审查。（[公开与修改](/create/publish#把不公开的作品改成公开)）

## 作品公开范围

- **原创**：仅在 MYMI 公开的作品。可以获得较高的 Leaf 比率。
- **一般**：也可以在其他平台公开的作品。

:::warning[原创在 3 个月内无法解除]
选择原创时，会出现「设置为原创后，3个月内无法解除。」的提示。规则是从设置的那天起 3 个月内，不能改回**一般**。如果打算也在其他平台发布，请选择**一般**。

在简易模式中，设置后的 3 个月内卡片会被锁定，并显示距离解除还剩几天。
:::

## 收益限制

- **无限制**：你拥有权利的创作。
- **限制收益**：像使用其他作品的角色或世界观的二次创作这样，权利不属于你的作品。

选了**限制收益**的作品，不会累积 Leaf。就算是原创作品，或官方创作者的作品也一样。更改后，从下一次聊天开始套用。

## 图片来源

选择作品的图片是怎么制作的。

- **MYMI 生成**：用 MYMI 的图片生成制作的图片。
- **外部制作**：用其他 AI 制作，或亲自绘制的图片。

**一般**作品的 Leaf 比率，会依图片来源而不同。比率请见[成为创作者与 Leaf](/creator-support/support#获得-leaf)。如果作品不使用图片，请选择实际使用的那一种。

## 读者群

选择作品主要面向哪种读者，**男性向**或**女性向**。

## 内容分级

会影响对话内容与生成的图片。

- **全年龄**：任何人都可以使用。
- **成人限定**：只有完成成人验证的用户才能使用。（[年龄确认与手机号码验证](/account/adult-verification)）

已经公开的作品，如果把分级从成人限定改成全年龄，会再次接受审查。

## 同意行销使用

- **同意**：MYMI 可以把这部作品用于广告、社区等行销。曝光增加，对话量自然增加，Leaf 收益也可能增加。
- **不同意**：不会用于行销。

## 只有简易模式才有的卡片：图片输出指示

简易模式的**设置**步骤里还有一张**图片输出指示**卡片。它决定 AI 在对话中如何输出图片。

- **内部图片**：使用上传到素材的图片。一开始就选好了。
- **外部图片**：使用你写在设置里的图片网址（URL）。

只能使用其中一种。详情请见[素材与 AI 图片](/create/simple/assets#图片输出指示)。专家模式没有这张卡片，图片规则要自己写在提示词里。

## 遇到问题时

<details>
<summary>选了原创，现在想改成一般</summary>

规则是设置为原创之后，3 个月内无法解除。在简易模式中，卡片会被锁定，并显示距离解除还剩几天。3 个月过后就能改成**一般**。

</details>

<details>
<summary>不知道该不该选限制收益</summary>

如果作品是用你自己创作的角色与世界观写成，请选**无限制**。如果像拿其他作品的角色或世界观来写的二次创作这样，权利不在你身上，请选**限制收益**。难以判断时，请通过[联系我们](/faq#联系我们)询问。

</details>

<details>
<summary>出现「请选择作品公开范围。」之类的提示</summary>

表示有卡片还没选。提示一次只会出现一个，简易模式在按下一步按钮或**完成**按钮时检查，专家模式在点击**完成制作**时检查。请选择提示文字里写到的卡片。可能还有其他卡片没选。

</details>

<details>
<summary>设成成人限定，其他用户却看不到</summary>

成人限定的作品，只会显示给完成成人验证的用户。也请确认自己的账号是否已通过验证。（[年龄确认与手机号码验证](/account/adult-verification)）

</details>
