# 公开与修改

完成作品后，设为公开的作品会经过审查，才向其他用户公开。简易模式是点击最后一个步骤的**完成**，专家模式是点击标头的**完成制作**来创建作品。做好的作品随时都可以在**个人资料 → 内容管理**修改。

## 从完成制作到公开

| 阶段 | 会发生什么 |
| --- | --- |
| 完成制作 | 检查必填项目并保存作品。如果有缺漏，会跳出提示。专家模式会切换到该分页。 |
| 审查 | 检查安全规范与作品品质。完成后会通知你。 |
| 公开 | 其他用户可以找到作品并开始聊天。 |

审查期间，作者本人也可以直接聊天。审查所需的时间会因作品而异。**成人限定**的作品，只会显示给完成年龄确认的用户。

完成画面会依作品的状态显示不同的说明。

<ScreenStep src="/img/screens/zh-Hans/complete-private.png" alt="非公开作品的完成画面与公开方法提示" caption="设为不公开的作品">

- 设为**公开**的新作品：会显示为**审查中**，审查完成后向其他用户公开。（创建第一个作品的完成画面：[简易模式](/create/simple/first-work#5-略过其余步骤并完成)・[专家模式](/create/first-work#5-完成制作)）
- 设为**不公开**的作品：只有你自己看得到。要公开的话，请在内容管理变更公开设置，审查会从那时开始。

</ScreenStep>

<ScreenStep src="/img/screens/zh-Hans/complete-approved.png" alt="修改已通过作品后的完成画面与继续操作" caption="修改已公开的作品时">

- 如果修改的是**已通过**的作品：修改的内容会立刻显示给其他用户。不会每次修改都重新接受审查。
- 不过，如果把**内容分级**从成人限定改成全年龄，就会重新接受审查。

</ScreenStep>

## 内容管理

<ScreenStep src="/img/screens/zh-Hans/manage-list.png" alt="内容管理清单显示已通过、审核中与退回的示例作品" caption="个人资料 → 内容管理">

你做的作品都集中在**个人资料 → 内容管理**。

1. **编辑**：在作品创建时的模式的制作画面打开作品。
2. **⋮**：打开菜单。有**删除**，如果是被退回的作品，还有**申请重新审查**。
3. 公开的作品会显示**审查中**・**已通过**・**已退回**。

还没完成制作的草稿会显示为**制作中**。点击**个人资料**，会打开作品介绍画面。

</ScreenStep>

可以用上方的搜索栏和**筛选**（排序・公开状态・审核状态）来找作品。在**仪表板**可以查看消息数、已获得 Leaf 这类作品的成绩。

## 修改已公开的作品

在**内容管理**点击**编辑**，会以作品创建时的模式打开。修改的方法依模式而不同。

### 专家模式的作品

<ScreenStep src="/img/screens/zh-Hans/released-header.png" alt="已发布作品编辑时显示套用变更与素材限制提示" caption="已完成制作作品的制作画面">

1. 在**内容管理**点击**编辑**。
2. 修改想改的地方。
3. 点击画面上方的**套用变更**。

已完成制作的作品没有**保存草稿**。为了避免改到一半的状态被公开，文字和设置要点击**套用变更**才会生效。

</ScreenStep>

:::warning[素材会立刻反映]
在素材分页添加、替换、删除图片和更改代码，不必等**套用变更**，会立刻反映到作品上。

- 更改代码或删除图片后，使用过那张图片的既有对话也会无法显示该图片。要替换图片时，请保留代码，只替换图片。
- 已完成制作的作品无法更改文件夹名称（角色代码）。
- 图片无法移到其他角色文件夹。可以移出文件夹。
:::

:::tip[关闭画面前先套用变更]
已公开的作品就算切换分页也不会自动保存。修改之后，关闭画面前请先点击**套用变更**。
:::

### 简易模式的作品

简易模式没有**保存草稿**，也没有**套用变更**。每次按下一步按钮，或用分页往前走，改过的内容就会保存到作品，如果是已通过的作品，其他用户马上就会看到。在素材上传、删除图片也会立刻反映。详情请见[编辑作品](/create/simple/edit)。

## 被退回的作品申请重新审查

<ScreenStep src="/img/screens/zh-Hans/manage-menu.png" device="part" alt="退回作品的更多菜单中显示申请重新审查" caption="⋮ → 申请重新审查">

审查被退回时，作品卡片会显示**已退回**。

1. 点击该作品的 **⋮** 按钮。菜单打开后，已退回的标示会被菜单遮住。
2. 点击**申请重新审查**。
3. 确认**退回原因**。

</ScreenStep>

<ScreenStep src="/img/screens/zh-Hans/manage-appeal.png" alt="退回原因说明与申请重新审查按钮" caption="退回原因与重新审查申请（网页）">

4. 依照原因修改作品，专家模式的作品点击**套用变更**，简易模式的作品则按下一步按钮保存。修改的方法和[修改已公开的作品](#修改已公开的作品)相同。
5. 再次点击 **⋮ → 申请重新审查**。
6. 需要的话，在消息栏写下修改的内容并送出申请。网页版是在退回原因窗口点击**申请重新审查**后，再点击**提交**；App 则是点击窗口下方的**申请重新审查**。重新审查由管理员查看后处理。

</ScreenStep>

## 把不公开的作品改成公开

1. 在**内容管理**点击**编辑**。
2. 在**其他设置 → 公开设置**选择**公开**。
3. 专家模式的作品点击**套用变更**，简易模式的作品按下一步按钮保存，审查就会开始。简易模式也可以用最后一个步骤的**完成**来保存。

## 删除作品

在**内容管理**点击作品的 **⋮ → 删除**，并在确认窗口再点击一次**删除**，就会删掉。删除的作品会从内容管理和作品列表消失。

:::danger[删除后无法复原]
没有让已删除作品复活的菜单。如果只是想暂时下架，请用**编辑**打开，把**其他设置 → 公开设置**改成**不公开**，专家模式的作品点击**套用变更**，简易模式的作品按下一步按钮保存。
:::

:::info
作品制作画面的 **↺**（重设创建内容）只会清空正在输入的画面。已保存的草稿会留在内容管理。
:::

## 推荐人设

<ScreenStep src="/img/screens/zh-Hans/settings-persona.png" device="part" alt="推荐人设的添加入口与说明" caption="其他设置 → 推荐人设">

**推荐人设**是事先创建用户开始对话时可以选择的人设的功能。想提议适合作品世界的主角时使用。不创建也没关系。在专家模式位于**其他设置**分页的最下方，在简易模式则位于**选填**步骤。

如果创建了，四个字段都要填满才能完成制作。

- **名称**：最多 20 字
- **性别**：女性、男性
- **出生日期**：必须年满 14 岁
- **详细信息**：写下性格、背景、说话方式，让 AI 知道如何对待使用这个人设对话的用户。最多 1,000 字

</ScreenStep>

## 遇到问题时

<details>
<summary>点了套用变更，其他人的画面却没有马上更新</summary>

如果作品还在审查中，要等审查完成后才会公开。如果是已经通过的作品，套用变更后会立刻生效。请试着刷新作品画面。

</details>

<details>
<summary>已公开的作品里，保存草稿按钮不见了</summary>

已完成制作的作品只用**套用变更**一个按钮来保存。这是为了避免修改到一半的内容被公开。

</details>

<details>
<summary>内容管理里有两个相同的作品</summary>

如果重设作品制作画面后又重新做了一次，先前做的草稿会以**制作中**的状态留着。用**编辑**打开确认，不需要的草稿用 **⋮ → 删除**删掉。

</details>
