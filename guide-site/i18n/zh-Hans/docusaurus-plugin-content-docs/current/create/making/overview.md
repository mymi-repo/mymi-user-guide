# 认识专家模式

专家模式是**自己撰写 AI 读取的设置与输出规则**的方式。作品制作画面的八个分页，分别负责 **AI 读取的设置**和**用户看到的画面**。先在这一页掌握整体样貌，再前往[创建第一个作品](/create/first-work)。

和简易模式有什么不同、该选哪一种，请见[开始之前](/create/before-you-start)。


截图中的作品、账号和内容均为说明用的虚构示例。简体中文先提供网页版，App 更新前可使用繁体中文等现有语言。

## 用专家模式打开

点击下方菜单的**创建**，再在**基本信息**分页最上方的**创作模式**点击**专家模式**。第一次选择时会跳出说明窗口。网页版与 App 的画面配置相同。

<ScreenStep src="/img/screens/zh-Hans/create-overview.png" alt="专家模式的基本信息与分页导航" caption="作品制作画面的上方">

1. **分页列**：基本信息 · 素材 · 组件 · 提示词 · 开场 · 设定集 · 快捷指令 · 其他设置。顺序没有限制，想从哪个分页开始写都可以。
2. **↺（重设创建内容）**：清空正在输入的内容，从头重新开始。已经保存的草稿会留在**内容管理**。
3. **保存草稿**：把目前写的内容存成草稿。
4. **完成制作**：检查有没有缺漏的项目，完成作品。如果有缺漏，会切换到该分页告诉你。

</ScreenStep>

## 八个分页的作用

| 分页 | 要写什么 | 谁会读 |
| --- | --- | --- |
| **基本信息** | 作品标题、一句话简介、封面、详细说明、类型、标签 | 用户（作品介绍画面） |
| **素材** | 要显示在对话中的图片，以及为每张图片加上的代码 | 用户（对话画面） |
| **组件** | 状态窗口、选项等在对话中弹出的 UI | 用户（对话画面） |
| **提示词** | 世界观、角色、隐藏设置、进行规则，以及何时使用图片与组件 | AI（每次回复时） |
| **开场** | 对话开始时 AI 先传出的第一则消息 | 用户与 AI（对话的第一个场景） |
| **设定集** | 只在对话中出现特定词语时才传给 AI 的设置 | AI（出现关键字时） |
| **其他设置** | 公开设置、作品公开范围、读者群、内容分级等管理项目 | MYMI（分类与公开范围） |

:::info[写在基本信息的文字不会传给 AI]
就算在详细说明里把角色介绍写得很仔细，AI 也不会读。AI 需要知道的设置，请写在**提示词**分页。可以把「给作品介绍画面看的文字」和「给 AI 的文字」想成分开准备的两份内容。
:::

## 最小的作品需要什么

没有图片、组件、设定集，也可以完成作品。必要的只有下面这些。

- **基本信息**：作品标题、一句话简介、1 张封面、详细说明、1～2 个类型、至少 1 个标签
- **提示词**：基本型的作品信息，或自行撰写的提示词
- **开场**：1 个有标题和内容的开场
- **其他设置**：作品公开范围、收益限制、图片来源、读者群、同意行销使用。公开设置和内容分级一开始就选好了公开与全年龄。

封面可以上传你已有的图片，或是把在**素材**分页做好的图片带过来使用。素材之后再加也可以。

## 何时会保存

- 草稿有变更时，会在**切换分页时**自动保存。
- 第一次上传或生成封面、素材图片时，会先保存需要的草稿。不必先点击**保存草稿**。
- 草稿保存过一次之后，在**素材**分页添加、删除、移动图片或更改代码，都会立刻保存。
- 打字时不会每打一个字就保存。在同一个分页写很久的话，请点击**保存草稿**。
- 如果同一部作品同时在电脑和手机两个地方打开并修改，会保留后保存的那一边的内容。想换到其他设备继续修改，请先在原本的设备点击**保存草稿**（已完成制作的作品是**套用变更**），再到另一台设备的**个人资料 → 内容管理**点击**编辑**打开。
- 已完成制作的作品没有**保存草稿**。修改的内容必须点击**套用变更**才会生效。详情请见[公开与修改](/create/publish)。

:::warning[关闭画面之前]
自动保存会在切换分页和开始处理图片时进行。如果在同一个分页写到一半就关闭画面，最后写的内容可能不会保留。注销或改用其他账号登录时，尚未保存的内容会被清除。
:::

## 如果你有用简易模式创建的作品

用简易模式创建的作品，从**内容管理 → 编辑**打开时，会以简易模式打开。作品创建时的模式无法更改，所以不会变成专家模式。想把设置移到新作品，请见[移到专家模式](/create/simple/to-expert)。

## 本指南的范例作品

专家模式的说明会跟着范例作品**地下城市首尔**进行。它的设置与作品制作画面中的作品信息范例相同。作品的介绍和图片在[开始之前](/create/before-you-start#本指南的范例作品)。范例图片的制作方法请见[准备图片](/create/images)。

## 遇到问题时

<details>
<summary>要生成图片时显示「需要身份验证才能生成 AI 图片。」</summary>

图片生成有每周免费额度，超出后使用 Spark 并先确认。当前需要手机号码验证；具体以账号画面为准。无法在作品制作画面开始验证，请这样做：

1. 点击右上角的**保存草稿**（已完成制作的作品是**套用变更**）保存作业。
2. 在**个人资料 → 签到**点击**签到并领取 Sparks**，完成手机号码验证。
3. 从**个人资料 → 内容管理**重新打开作品，再生成图片。

只是上传自己已有的图片，不需要验证。验证方法请见[年龄确认与手机号码验证](/account/adult-verification)。

</details>

<details>
<summary>一定要依序把每个分页都填完吗？</summary>

不用。分页想从哪个开始写都可以，必填项目会在你点击**完成制作**时一次检查。

</details>

<details>
<summary>用专家模式创建的作品，可以改成简易模式吗？</summary>

没有这个功能。作品创建时的模式不会改变。想用简易模式重做，请把创作模式选为**简易模式**并创建新作品，再把写在提示词里的设置抄到世界观、角色、秘密字段。图片也需要重新用情境说明整理。（[认识简易模式](/create/simple/overview)）

</details>

<details>
<summary>提示词分页的「基本型」与「自行撰写」，和创作模式不一样吗？</summary>

不一样。**基本型**与**自行撰写**是在提示词分页里选择的撰写方式，而**简易模式**与**专家模式**是制作作品的整体方式。在专家模式中，两种撰写方式都可以使用。（[撰写提示词](/create/prompt)）

</details>
