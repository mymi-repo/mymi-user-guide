# 限制与规则一览

这里整理了专家模式作品制作画面的限制与规则。详细的用法，请见各项目的说明页面。

:::info
这是专家模式的说明。简易模式请见[输入项目与限制](/create/simple/reference)。
:::

## 字数与数量

| 分页 | 项目 | 限制 |
| --- | --- | --- |
| 基本信息 | 作品标题 | 必填 · 30 字 |
| | 一句话简介 | 必填 · 40 字 |
| | 封面 | 必填 · 1～10 张。文件为 JPG、PNG、WEBP、GIF、HEIC · 最大 5MB。切换间隔为 0.5～60 秒（每按一次按钮 0.5 秒） |
| | 详细说明 | 必填 · 50,000 字 |
| | 类型 | 必填 · 1～2 个 |
| | 标签 | 必填 · 至少 1 个，每个 30 字。与读者群合计最多 30 个 |
| | 创作者指南 | 选填 · 每则 5,000 字 |
| | 推荐模型 | 选填 · 最多 5 个 |
| 素材 | 图片档 | JPG、PNG、WEBP、GIF、HEIC · 最大 5MB |
| | 代码・文件夹名称 | 英文与数字，最多 30 字 |
| | 一次生成要求 | 最多 50 张 |
| 组件 | JSX 代码 | 20,000 字。需要函数名称与至少 1 个变量 |
| 提示词 | 自行撰写 | 必填 · 10,000 字 |
| | 基本型 | 必填 · 作品信息・代码含义・例外・组件规则所写的文字合计 10,000 字 |

| | 标题 | 100 字 |

| 设定集 | 设置 | 最多 100 条 |
| | 名称 | 50 字 |
| | 关键字 | 每条设置 5 个，每个 10 字 |
| | 内容 | 400 字 |
| | 一次发送的量 | 从最近 10 则消息中搜索，最多 3 条 · 1,500 字 |
| 其他设置 | 推荐人设 | 选填。创建的话，名称（20 字）・性别・出生日期（年满 14 岁）・详细信息（1,000 字）都要有 |

## 完成制作时检查的项目

点击**完成制作**（已公开的作品是**套用变更**）后，会依照下面的顺序检查，并切换到第一个被拦下的项目所在的分页显示说明。

| 顺序 | 分页 | 检查的内容 |
| --- | --- | --- |
| 1 | 基本信息 | 作品标题、一句话简介、至少 1 张封面、详细说明、1～2 个类型、至少 1 个标签 |
| 2 | 素材 | 所有图片是否都有代码、代码是否为英文与数字、同一个文件夹内是否没有相同代码、是否没有空白格与等待生成的列、基本形象是否已完成 |
| 3 | 组件 | 代码、函数名称、至少 1 个变量 |
| 4 | 提示词 | 自行撰写：提示词。基本型：作品信息、角色・情境・其他代码的含义、组件出现的时机、合计 10,000 字以下 |
| 5 | 开场 | 是否至少有 1 个，且全部都有标题与内容 |
| 6 | 设定集 | 每条添加的设置的关键字・内容・名称 |
| 7 | 其他设置 | 作品公开范围、收益限制、图片来源、读者群、同意行销使用，以及添加的推荐人设的四个字段 |

公开设置（公开）和内容分级（全年龄）一开始就已选好。

## 代码规则

- 图片代码与角色文件夹名称，只能使用**英文与数字**。不能有空格或特殊符号。
- 同一个文件夹内，代码不能重复。不同文件夹之间可以使用相同的代码（`A/1`、`B/1`）。
- 文件夹只能创建一层。
- 路径在文件夹内是 `文件夹/代码`，在文件夹外是 `代码`。在对话和开场中，要写成 `![]({{URL}}/A/1.webp)`、`![]({{URL}}/BG1.webp)` 这样。
- 图片无法移到其他角色文件夹。可以移出文件夹。
- 已完成制作的作品无法更改文件夹名称。

## `{{user}}` 与 `{{char}}`

| 使用的地方 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 开场 | 对话时会换成用户的名字 | 对话时会换成**作品标题** |
| 提示词 | 用来指称用户 | 不会自动替换。请直接写出人物名称 |
| 设定集 | 用来指称用户 | 请直接写出人物名称 |

## 保存

| 情况 | 保存的时机 |
| --- | --- |
| 制作中的作品 | 有变更时切换分页会自动保存；第一次上传或生成封面、素材图片时；点击**保存草稿**时。草稿创建之后，素材分页的变更会立刻保存 |
| 已完成制作的作品 | 文字与设置在点击**套用变更**时保存。素材的变更会立刻反映 |

## 免费与验证

- 图片生成、重新生成有每周免费额度，超出后需要 Spark 并先确认。当前需要手机号码验证；其他认证提示以账号画面为准。
- 成人限定的作品，只有完成年龄确认的用户才能使用。
- 图片生成标签步骤中的安全筛选，只有完成年龄确认的账号才能关闭。

## 遇到问题时

<details>
<summary>点了完成制作，却跳到其他分页</summary>

这表示系统切换到有缺漏项目的分页，并告诉你是哪个项目。请把说明中提到的字段填好，再点击一次**完成制作**。每个分页检查什么，请见[完成制作时检查的项目](#完成制作时检查的项目)。

</details>

<details>
<summary>保存或完成制作出现错误，但看起来都已经填好了</summary>

可能有字段超过了「输入时不会挡，保存时才会被拦下」的限制。请先确认这些字段：

- **基本信息**的标签：每个 30 字，与读者群合计最多 30 个
- **基本信息**的封面切换间隔：最多 60 秒
- **开场**标题：最多 100 字
- **素材**的代码与文件夹名称：最多 30 字

修改后再保存一次。如果仍然出现相同的错误，请附上是哪个作品的哪个字段，从**个人资料 → Discord** 前往 Discord 的询问频道告诉我们，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。

</details>
