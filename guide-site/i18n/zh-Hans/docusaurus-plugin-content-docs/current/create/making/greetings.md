# 撰写开场

开场是开始聊天时 AI 先传出的第一则消息。这是用户最先遇到的场景，决定了作品的第一印象。开场至少要有 1 个。

:::info
这是专家模式的说明。简易模式请见[撰写设置与介绍](/create/simple/write#介绍)。
:::

## 创建开场

<ScreenStep src="/img/screens/zh-Hans/first-greeting.png" alt="专家模式的开场编辑与即时预览" caption="开场分页">

1. 写下**开场标题**。这是用户选择开始场景时看到的名称。最多可写 100 字。
2. 在下方字段写下第一则消息。最多 2,000 字。

点击开场清单那一列的**添加**，可以再创建开场。创建多个时，用户开始对话时可以选其中一个。要删除的话，先在清单中选取该开场，再点击名称旁的<strong>×</strong>。只有一个开场时无法删除。

</ScreenStep>

第一则消息要写成与聊天相同的样式。

| 写法 | 显示的样子 |
| --- | --- |
| `*日光灯闪烁的检疫所。*` | 动作与叙述（斜体） |
| `"哦，终于醒了～"` | 对话（强调色） |
| `{{user}}` | 对话时会换成用户的名字 |
| `{{char}}` | 对话时会换成**作品标题**。不是人物名称 |

:::tip[人物名称请直接写]
在有多位登场人物的作品里使用 `{{char}}`，放进去的是作品标题，而不是人物名称。开场里请直接写出「民宇」这样的名字。
:::

## 插入图片

素材分页有图片的话，就可以插入开场。在聊天中，插入的位置会显示图片。

<ScreenStep src="/img/screens/zh-Hans/greeting-insert-image.png" alt="专家模式从素材清单选择要插入开场的图片" caption="插入素材图片">

1. 在第一则消息栏，点击想插入图片的位置，放置光标。
2. 点击**插入素材图片**。
3. 点击要插入的图片，光标位置就会加入像 `![]({{URL}}/A/1.webp)` 这样的一行。

要在素材分页上传图片并设置代码，才会出现在清单里。

</ScreenStep>

<ScreenStep src="/img/screens/zh-Hans/greeting-preview-images.png" device="part" alt="开场编辑区与下方的即时预览" caption="放入图片的开场预览">

在**预览**确认图片会显示在哪里。如果没有符合代码的图片，该处会出现「素材分页没有这个代码的图片」的提示。

范例把走廊背景放在最上面，把民宇微笑的图片放在民宇第一句对话之前。

</ScreenStep>

```md
![]({{URL}}/BG1.webp)
*日光灯闪烁的检疫所。消毒水的气味之中，有人拉开了帘子。*

![]({{URL}}/A/1.webp)
"哦，终于醒了～你整整睡了三天耶？"
```

:::info[锁定的图片在开场也看得到]
在素材中打开**需要解锁**的图片，在开场和封面里一开始也看得到。因为那是用户一开始就会看到的地方。想隐藏的图片，请不要放进开场。
:::

## 写出好的第一个场景的诀窍

- <strong>在第一则消息的结尾，把事情交给用户。</strong>范例以「除了名字，你还记得什么吗？」这个问题结尾，用户可以马上回答。
- <strong>让开场的语气和提示词一致。</strong>如果提示词写了「不用敬语，句尾拖长」，开场的对话也要这样写。AI 比较容易延续第一则消息的语气。
- <strong>试着做出多个开始场景。</strong>在同一个世界观中准备起点不同的开场，用户就能挑选开始。例：「在检疫所醒来」、「在 7 号出口前」

## 遇到问题时

<details>
<summary>显示「有开场没有标题。」或「有开场没有内容。」</summary>

创建好的开场中，有标题或内容是空的。请在开场清单中一个一个点开确认。不会用到的开场，先选取再点击名称旁的<strong>×</strong>删除。

</details>

<details>
<summary>点击插入素材图片后显示「在素材分页上传图片并设置代码后即可插入。」</summary>

目前还没有可以插入的图片。在素材分页上传或生成图片并完成，再为该图片设置代码，就会出现在清单里。

</details>

<details>
<summary>预览里的 `{{user}}` 没有被替换</summary>

预览不会替换，实际对话时才会换成用户的名字。

</details>
