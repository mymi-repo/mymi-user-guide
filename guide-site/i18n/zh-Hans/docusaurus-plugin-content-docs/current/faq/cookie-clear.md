# 清除 Cookie

在网页版一直被注销、登录后又出现登录画面，或**个人资料**打不开时，请依下面的顺序尝试。

App 不需要清除 Cookie。请点击**个人资料 → 设置与支持 → 注销**，再用注册时的社区账号重新登录。

## 先重新登录

如果在**个人资料**看得到注销按钮，请点击**个人资料 → 设置与支持 → 注销**，再用注册时的社区账号重新登录。

如果看不到注销按钮，或重新登录后还是出现同样的问题，请在你使用的浏览器中，清除 MYMI（mymi.live）的 Cookie 与网站数据。清除之后需要重新登录。

## 清除浏览器的 Cookie

步骤会依浏览器和版本而不同，请参考你使用的浏览器的官方说明。如果可以只删除单一网站的数据，请只删除 mymi.live 的数据。

| 浏览器 | 官方说明 |
| --- | --- |
| Chrome（电脑・Android・iPhone） | [Google Chrome 说明：删除及管理 Cookie](https://support.google.com/chrome/answer/95647?hl=zh-Hans) |
| Safari（iPhone・iPad） | [Apple 支持：清除 iPhone 上 Safari 的记录、缓存与 Cookie](https://support.apple.com/zh-cn/105082) |
| Safari（Mac） | [Apple 支持：清除 Mac 上 Safari 的缓存与 Cookie](https://support.apple.com/zh-cn/guide/safari/sfri11471/mac) |
| Microsoft Edge | [Microsoft 支持：在 Microsoft Edge 中管理 Cookie](https://support.microsoft.com/zh-cn/microsoft-edge/delete-cookies-in-microsoft-edge-63947406-40ac-c3b8-57b9-2a946a29ae09) |

:::warning[其他网站也可能被注销]
清除所有 Cookie 后，除了 MYMI，其他网站也可能会被注销。
:::

## 遇到问题时

<details>
<summary>清除了 Cookie，还是无法登录</summary>

- 如果你是在 LINE 或 Instagram 等 App 里打开 MYMI，请改用 Chrome 或 Safari 直接打开 [www.mymi.live](https://www.mymi.live)。
- 也请用其他浏览器登录看看。如果其他浏览器可以，问题可能出在你原本使用的浏览器的设置。

</details>

<details>
<summary>其他网站也被注销了</summary>

从浏览器的整个浏览纪录清除 Cookie，其他网站的登录也会被注销。请重新登录那些网站。

</details>

<details>
<summary>登录了，却看不到之前的聊天或 Spark</summary>

这不是 Cookie 的问题，可能是你用了不同的社区账号登录。每个社区账号都有各自的 MYMI 账号。请先注销，再用最初注册的社区账号重新登录。

</details>

如果还是没有解决，请附上你使用的设备和浏览器，从[联系我们](/faq/faq.md#联系我们)告诉我们。
