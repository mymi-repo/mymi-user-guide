## 不能做的事

以下是[作品生成政策](https://www.mymi.live/zh-Hans/legal/content-creation-policy)和[服务条款](https://www.mymi.live/zh-Hans/legal/terms-of-service)禁止的主要行为。

- **未成年人相关的性内容**：对未满 18 岁的人物，或看起来未满 18 岁的人物、角色进行性化描写。任何情况下都禁止
- **真人的性化描写**：把真人性化、做成 deepfake，或制作、散布未经同意的性图像
- **违法内容**：违反法令的内容、教唆犯罪手法、鼓励自伤自杀或毒品滥用的内容
- **仇恨与骚扰**：歧视、威胁、骚扰
- **侵害个资**：未经许可公开他人的个人数据
- **侵害权利**：未经许可使用他人的作品或肖像
- **露骨的性表现**：性器官露出，或露骨性行为的详细描写
- **公开范围设置错误**：敏感内容的作品没有正确设置就公开
- **在 MYMI 之外使用生成图片**：下载或截屏 MYMI 生成的图片，拿到 MYMI 之外发布或贩售
- **规避安全机制**：规避年龄确认或安全筛选等，使用 Bot、自动化或大量生成

## 违规的话会怎么样？

依违规的内容和次数等，可能被警告、作品被设为不公开或删除、功能被限制、账号被暂停或永久停权。

- 未成年人相关的性内容、性剥削、真人色情 deepfake、重大权利侵害、付款盗用、恶意规避安全机制，可能不经事前警告就永久停权。
- 图片生成功能的目的外使用、生成图片的外部使用或销售、自动化或大量生成，可能导致图片生成功能被限制、Spark 使用被限制，或账号被暂停。
- 详细的处理方式请看[作品生成政策](https://www.mymi.live/zh-Hans/legal/content-creation-policy)的「违规处理」。

:::warning[可能不事先通知就被删除]
违反政策的作品或内容，可能不经事前通知就被删除或设为不公开。
:::

## 检举

1. 打开要检举的作品的详细画面。
2. 点击右上角的盾牌图标，选择**检举**。检举需要先登录。
3. 选择检举原因，需要的话补充说明，再点击**提交检举**。

在同一个菜单选择**封锁创作者**或**封锁内容**，该创作者或作品就不会再出现在你的首页和推荐中。

也可以用电子邮件检举或询问。

| 这种情况 | 寄到 |
| --- | --- |
| 要检举有害内容 | [safety@mymi.live](mailto:safety@mymi.live) |
| 你的著作或肖像被未经许可使用 | [copyright@mymi.live](mailto:copyright@mymi.live) |
| 对收到的处分有异议 | [safety_appeal@mymi.live](mailto:safety_appeal@mymi.live) |
| 想询问个人数据相关问题 | [privacy@mymi.live](mailto:privacy@mymi.live) |
| 其他问题 | [contact@mymi.live](mailto:contact@mymi.live) |

## 遇到问题时

<details>
<summary>我的作品突然被设为不公开，或被删除了</summary>

被判断违反作品生成政策的作品，可能不经事先通知就被设为不公开或删除。对处分有异议的话，请寄信到 [safety_appeal@mymi.live](mailto:safety_appeal@mymi.live)，附上作品标题和你的 MYMI ID。审核被退回的作品，请看[公开与修改](/create/start/publish.md)。

</details>

<details>
<summary>想再看到我封锁的作品或创作者</summary>

在**个人资料 → 封锁管理**可以解除封锁。

</details>

<details>
<summary>找不到检举菜单</summary>

点击作品详细画面右上角的盾牌图标，才会打开菜单。还没登录的话，点击检举时会先出现登录窗口。

</details>
