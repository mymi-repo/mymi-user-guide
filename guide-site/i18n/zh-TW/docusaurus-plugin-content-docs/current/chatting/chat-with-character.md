# 聊天

在 MYMI，你可以先找到喜歡的作品，再決定**從哪個場景開始（開場白）**，以及**自己在作品中扮演誰（Persona）**。無論作品以單一角色為主，還是有多位登場人物，開始聊天的基本步驟都相同。

> **曾經聊過這部作品嗎？** **繼續先前聊天**會返回既有聊天室；**開始新聊天**則會用目前選擇的開場白與 Persona 建立另一個聊天室。想嘗試不同的開局時，請選擇**開始新聊天**。

## 1. 尋找想聊天的作品

你可以使用首頁的以下分頁：

- **推薦：** 瀏覽個人化推薦、新作品及熱門作品。
- **排行榜：** 從即時、每日、每週或每月排名尋找作品。
- **標籤：** 組合最多 3 個類型、關係、設定、性格或種族等標籤。
- **搜尋：** 以關鍵字搜尋作品，或輸入 **@創作者名稱**尋找創作者；也可依相關程度、最新、熱門等方式排序。

使用**所有性別 / 女性／其他 / 男性／其他**篩選條件，可縮小顯示的作品範圍。如果找不到作品，請換個關鍵字、標籤組合或性別篩選條件。

成人作品是否顯示及能否使用，會受到安全篩選與帳號驗證狀態影響。若畫面顯示存取限制，請參閱[成人與身分驗證](/account/adult-verification.md)。

## 2. 在作品詳情確認起點

點選作品卡片後，可在詳情頁閱讀介紹、登場角色及創作者提供的資訊。若畫面顯示**開場白**，請先閱讀目前選取的開頭場景。如果有多個開場白，可開啟選單，改選其他起始場景。未自行切換時，會使用一開始顯示的開場白。

| 選擇項目 | 決定什麼 |
| --- | --- |
| **開場白** | 新聊天的起始場景及最先顯示的內容 |
| **Persona** | 與角色對話時，**你的名稱和身分** |

開場白決定作品從哪裡開始，Persona 決定你的角色身分。選好兩者後按**開始新聊天**，即可用這些設定建立新聊天室。

## 3. 選擇自己的身分（Persona）

1. 在作品詳情頁底部，按下**聊天按鈕旁的小型個人檔案按鈕**。
2. 從**我的 Persona**選擇要使用的身分。若創作者有提供，也可以選擇**推薦 Persona**。
3. 按下**確認選擇**，確認聊天按鈕旁顯示的身分。

如有主要 Persona，系統會優先預選。沒有推薦 Persona 的作品可能不會顯示該選項。若要新增身分，或修改既有聊天室的身分，請參閱[Persona 設定](/account/persona.md)。

## 4. 開始第一次聊天

1. 在作品詳情頁確認想用的**開場白**和**Persona**。
2. 按下底部的**開始聊天**。
3. 確認新聊天室顯示所選開場白的起始場景。
4. 在畫面下方輸入自己的動作或台詞，然後按下**傳送**按鈕。

例如，你可以寫「我打開門走進去」，或問「這裡發生了什麼事？」先閱讀作品設定與開頭場景，會更容易接著當下情境聊天。

> 成人作品可能需要登入或完成年齡驗證。如果傳送訊息時，畫面顯示所選模型、可用次數或持有 Spark 餘額的提示，請依畫面說明操作。

## 5. 繼續先前聊天，還是開始新聊天？

如果你曾與該作品聊天，詳情頁會顯示兩個按鈕：

- **繼續先前聊天：** 返回既有聊天室，延續儲存的聊天紀錄與 Persona。
- **開始新聊天：** 為同一部作品建立另一個聊天室，並使用目前選擇的開場白與 Persona 開始。

想從其他開場或身分重新體驗同一作品時，請按**開始新聊天**。先前的聊天室可透過**繼續先前聊天**重新開啟。若要修改既有聊天室的 Persona，請到該聊天室內編輯並儲存。

## 6. 閱讀與操作聊天畫面

在聊天畫面的 UI 設定（調色盤圖示）切換顯示方式，即可以不同形式閱讀同一份聊天紀錄。

| 顯示方式 | 畫面特點 |
| --- | --- |
| **聊天** | 以對話氣泡閱讀訊息 |
| **1:1** | 一次突出顯示一則訊息，可前後切換 |
| **小說** | 將敘述與台詞當作連續文章閱讀 |

可操作的訊息可能顯示**重新生成**、**編輯**和**刪除**等功能。重新生成可要求另一則回覆；若有多個候選回覆，可用箭頭查看。編輯後需儲存，刪除則需先確認。起始場景或受保護的訊息可能不會顯示部分功能。

顯示方式、模型、Persona 等聊天室設定的詳細操作，請參閱[聊天室設定](/chatting/chat-room-settings.md)。

## 如果無法開始聊天

| 狀況 | 請確認 |
| --- | --- |
| 無法按下開始按鈕 | 確認 Persona 是否仍在載入，並嘗試從個人檔案按鈕選擇身分 |
| 無法開啟成人作品 | 確認登入狀態及[成人與身分驗證](/account/adult-verification.md)狀態 |
| 訊息無法送出 | 確認網路連線、輸入內容，以及畫面上的模型、可用次數或 Spark 餘額提示 |
| 找不到作品 | 更換搜尋字詞，並確認標籤、性別和安全篩選條件 |
