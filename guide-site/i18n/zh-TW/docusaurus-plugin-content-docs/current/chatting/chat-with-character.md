# 聊天

依序說明如何選擇作品並開始第一次聊天、不滿意回覆時重新取得，以及之後繼續聊天的方法。

:::info[聊天會使用 Spark]
每收到一次 AI 回覆，就會依所選模型的價格扣除 Spark。一開始選的是 **Gemini 3.1 Pro**，可以用輸入框左側的 ⚡ 按鈕換成其他模型。各模型的價格請見 [AI 模型指南](/chatting/ai-models.md)。

未登入時無法選擇模型，會用固定的試用模型，最多試聊 5 次。
:::

## 選擇作品

用**首頁**上方的分頁尋找作品。

| 分頁 | 尋找方式 |
| --- | --- |
| **推薦** | 瀏覽推薦的作品合集 |
| **排行** | 從即時、每日、每週、每月排名中挑選 |
| **類型** | 從浪漫、奇幻、武俠等 13 種類型中選一種或**全部**，依熱門、每週熱門、最新排序瀏覽 |
| **搜尋** | 用氛圍或關鍵字尋找。準確輸入 `@暱稱` 或 `@ID`，就會顯示該創作者的作品 |

- 第一次進入時，會出現「選擇你最想看的角色」視窗。從**女性角色**、**男性角色**、**全部都想看**中選一個，就會優先顯示有該類角色登場的作品。之後隨時可以在各分頁的性別篩選中更改。
- 開啟安全篩選時，不會顯示成人作品。安全篩選是首頁分頁列最右側的盾牌形狀開關。要關閉它，必須完成年齡確認（年滿 18 歲）。請參閱[年齡確認與手機號碼驗證](/account/adult-verification.md)。

## 決定開場場景與你的角色

點選作品卡片會開啟作品詳情。

1. 閱讀介紹與登場角色。
2. 在**開場白**中選擇要開始的場景。如果有多個開場白，點選即可切換成其他場景。沒有選擇時，會從第一個開場白開始。
3. 點選畫面下方**開始聊天**右側的小型個人檔案圖示。
4. 從**我的人設**或創作者準備的**推薦人設**中選一個，再點選**確認選擇**。圖示會換成所選人設的圖片（沒有圖片時顯示名稱的第一個字）。

人設是你在作品中使用的名字與身分。一開始選的是你的主要人設。新增或修改的方法請見 [人設設定](/account/persona.md)。

## 傳送第一則訊息

1. 點選**開始聊天**，會開啟新的聊天室並顯示開場場景。
2. 在畫面下方的輸入框寫下你的台詞或動作。一次最多可以寫 1,000 字。
3. 點選輸入框最右側的 ↑ 按鈕送出。在電腦上按 Enter 送出，按 Shift+Enter 換行。
4. 稍等一下，角色就會回覆。

用星號（`*`）把動作包起來，就會以和台詞不同的顏色顯示。點選輸入框右側的 ✱ 按鈕會自動加入星號。

```text
*打開門走進去* 這裡發生了什麼事？
```

:::tip[想不到要說什麼時]
輸入框留空時，↑ 按鈕會變成 ≫ 按鈕。點選 ≫ 按鈕會開啟**繼續推進**視窗。

- **直接繼續**：角色會照目前的走向繼續故事。
- **時間流逝**、**場景轉換**、**事件發生**、**新角色登場**：把選項下方寫的方向只加在這一輪，繼續推進故事。

不論選哪一項，都會扣除一次回覆的 Spark。
:::

## 不滿意回覆時

用最後一則 AI 回覆下方的按鈕，重新取得或修改回覆。

| 按鈕 | 作用 |
| --- | --- |
| 圓形箭頭（**重新生成**） | 開啟**重新生成**視窗。依你的選擇取得新的回覆，會再扣一次 Spark |
| 鉛筆（**編輯訊息**） | 自己修改回覆內容後**儲存** |
| 垃圾桶（**刪除訊息**） | 刪除這則回覆。引發這則回覆的你的訊息也會一起刪除 |

在**重新生成**視窗中，選擇你希望新回覆怎麼寫。選的內容只會用在這次重新生成。

| 選項 | 新的回覆 |
| --- | --- |
| **直接重新生成** | 不加其他指示，重新取得 |
| **依照角色設定**、**依照使用者備註**、**不要重複**、**不寫我的行動** | 加上選項下方寫的指示，再重新取得 |
| 最下方的輸入框 | 自己寫下希望的內容（最多 150 字）再送出 |

- 用 ≫ 按鈕選擇方向取得的回覆，重新生成時也會再加上當初選的方向。
- 重新生成後有多則回覆時，可以用 ‹ › 切換，留下喜歡的那一則。切換查看不會扣 Spark。
- 這些按鈕只出現在最後一則 AI 回覆。更早的回覆和你送出的訊息都無法修改，想改變劇情走向時，請在下一則訊息中說明。
- 已加入書籤的回覆也無法修改。詳情請見[書籤與分支](/chatting/chat-room-settings.md#書籤與分支)。
- 在 **1:1** 顯示中，翻到最後一則回覆的結尾，就會出現同樣的圖示按鈕。在電腦上把滑鼠移到按鈕上，會顯示**重新生成**、**編輯內容**、**刪除**等名稱。

:::warning[刪除後無法復原]
刪除回覆時，引發這則回覆的你的訊息也會一起刪除，而且無法復原。只想換一則回覆時，請使用**重新生成**。
:::

## 切換顯示方式

一開始會以**小說**顯示開啟。點選聊天室右上角的調色盤圖示，在 **UI 設定**的 **UI 模式**中切換。不論選哪一種，都是同一段對話。

| 顯示 | 呈現方式 |
| --- | --- |
| **小說** | 把敘述和台詞當作連續的文章閱讀 |
| **聊天** | 以對話氣泡一來一往 |
| **1:1** | 以圖片為背景，一次看一段（**上一個**・**下一個**） |
| **故事** | 以圖片作為整個畫面的背景，只連續閱讀文字；文字進行到圖片的位置時，背景就會換成那張圖片 |

字體大小和顏色請在[聊天室設定](/chatting/chat-room-settings.md#調整文字與畫面顯示)中更改。

## 之後繼續聊天

- 點選下方選單的**聊天**，會顯示你聊過的作品。點選作品會開啟最近一次聊天的聊天室。
- 作品詳情的**繼續先前聊天**也會開啟最近一次聊天的聊天室。
- 想從頭開始時，在作品詳情選好開場白和人設，再點選**開始新聊天**。會建立新的聊天室，原本的聊天室會保留下來。
- 同一部作品先前的聊天室，可以從聊天室右上角 ⋮ 選單的**查看先前聊天**中選擇。方法請見[找到先前的聊天室](/chatting/chat-room-settings.md#找到先前的聊天室)。

## 遇到問題時

<details>
<summary>輸入框被鎖住，顯示「Spark 不足」</summary>

剩餘的 Spark 比目前模型的價格少。點選畫面上的**儲值**，或用輸入框左側的 ⚡ 按鈕換成較便宜的模型。免費獲得的方法請見[儲值 Spark](/payment/payment-methods.md#免費領取-spark)。

</details>

<details>
<summary>顯示「點數不足」，訊息送不出去</summary>

如果把最大輸出量設得比基本高，送出時會先扣除那部分。把 ⋮ 選單的**最大輸出量**調回**基本**就能送出。詳情請見[取得更長的回覆](/chatting/ai-models.md#取得更長的回覆)。

</details>

<details>
<summary>顯示「免費試用已結束！」</summary>

未登入可使用的 5 次已經用完。用 ≫ 按鈕繼續推進的回覆、重新生成的回覆，以及被模型拒絕的回覆，都各算一次。登入後就能繼續聊天。在試用的畫面直接註冊新帳號，就能在新帳號中接續試用時的對話。

</details>

<details>
<summary>顯示「模型拒絕回覆」</summary>

先前的對話或記憶累積了不適當的內容時，即使剛送出的訊息沒有問題，模型也可能拒絕回覆。點選**刪除並繼續**後，換個說法或降低尺度再送出。被拒絕的回覆只會扣除基本價格的 20%。

</details>

<details>
<summary>顯示「目前選取的模型暫時無法使用。」</summary>

點選**選擇模型**換成其他模型，就能繼續聊天。

</details>

<details>
<summary>開始聊天按鈕按不下去</summary>

還沒有選擇人設。點選按鈕右側的個人檔案圖示，選擇一個人設。

</details>

<details>
<summary>進不去成人作品</summary>

需要登入並完成年齡確認（年滿 18 歲）。只完成手機號碼驗證無法開啟成人作品。請參閱[年齡確認與手機號碼驗證](/account/adult-verification.md)。

</details>

如果還是無法解決，請用聊天室 ⋮ 選單的**複製房間 ID** 複製 ID，連同發生的狀況，從**個人檔案 → Discord** 前往 Discord 的詢問頻道告訴我們，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
