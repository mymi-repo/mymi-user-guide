# 聊天室設定

按下聊天畫面右上角的 **⋮ 按鈕**，即可開啟房間管理與對話設定。按下旁邊的**調色盤圖示**，即可調整文字、顏色及閱讀模式。

## 1. 開啟房間管理

聊天時按下右上角的 **⋮**，側邊會開啟**房間管理**。頂部會顯示已登入帳號的 Spark 餘額，或訪客體驗的剩餘次數。按下此區域後，會依帳號狀態前往儲值畫面或顯示登入提示。

**對話管理**提供以下功能：

- **開始新聊天：** 前往目前作品的詳情頁。在詳情頁選擇開場白與 Persona，再按**開始新聊天**，即可建立另一個聊天室。
- **查看先前聊天：** 開啟同一作品的聊天室清單。選取一個聊天室後，可以預覽最後一則訊息，再按**繼續**。你也可以在清單中選擇**隱藏**或**刪除**。
- **複製房間 ID：** 將目前聊天室的 ID 複製到剪貼簿。詢問特定聊天室的問題時可以提供此 ID。
- **擷取聊天：** 將選取的訊息範圍製作成圖片。操作步驟見下方第 6 節。
- **書籤：** 查看已儲存的書籤，建立分支或刪除書籤。

**隱藏**聊天室後，可從隱藏聊天清單重新顯示。**刪除**會永久移除對話；請在確認畫面核對目標聊天室。

## 2. 更改對話設定

開啟 **⋮ → 聊天設定**並調整項目，變更就會套用到後續對話。

### 使用者備註與 Persona

- **使用者備註：** 輸入你與角色的關係、背景、說話方式，或希望 AI 持續參考的情境，最多 **2,000 字**，然後按**儲存**。AI 會在目前聊天室參考這些內容。
- **我的資訊：** 編輯此聊天室使用的名稱與身分。若要使用個人清單中的 Persona，請依序按**載入 → 選擇 Persona → 儲存**，即可套用到目前聊天室。詳見[Persona 設定](/account/persona.md)。

### 寫作風格與回覆方式

- **寫作風格：** **小說**使用較豐富的描寫與敘事；**輕小說**語氣較輕鬆、對話較多。下方的**小說 UI 模式**只改變訊息的顯示方式，與寫作風格是兩項設定。
- **Story Booster：** 開啟後，AI 會更積極推動事件與情節。
- **允許 God Modding：** 開啟後，AI 也可以描寫你的行動或台詞。若希望自己決定行動，可以關閉。
- **One Cut：** 開啟後，每次回覆以一個場景推進。
- **最大輸出量：** 已登入帳號可以為每個模型選擇回覆的最大長度。如果選項顯示額外用量或費用資訊，選擇前請先閱讀畫面條件。


## 3. 查看長期記憶與記憶片段

**⋮ → 記憶管理**下有兩種不同的畫面：

- **長期記憶：** 查看對話整體脈絡的摘要。如果對話尚未累積足夠內容，可能會顯示目前沒有記憶。
- **記憶片段：** 瀏覽或搜尋對話中記錄的重要時刻。在此畫面頂部使用**使用記憶片段**開關，選擇往後的回覆是否使用記憶片段。

## 4. 更改文字與畫面顯示

按下聊天畫面右上角的**調色盤圖示 → UI 設定**。

- **UI 模式：** 選擇**聊天 / 1:1 / 小說**。三種模式以不同形式呈現同一份聊天紀錄。
- **閱讀版面：** 調整字體大小、行高、聊天高度、聊天透明度與串流速度。只有控制項可用時，才能調整串流速度。
- **字體與顏色：** 選擇字體，以及角色／使用者對白和敘事文字的顏色。**顯示角色名稱**只在聊天模式提供，**圖片高度**只在小說模式提供。
- **影片設定：** 選擇**循環播放影片**，或開啟以圖片取代影片的**圖片模式**。
- **重設：** 將目前選取的 UI 模式恢復預設顯示設定。

UI 設定會**儲存在目前使用的瀏覽器或 App 裝置上**，並套用到其他聊天室。在其他裝置上，請重新選擇顯示設定。

## 5. 新增書籤並建立分支

1. 聊天時，在想保留的訊息操作中按下**書籤圖示**。
2. 視需要輸入最多 **50 字**的書籤名稱；名稱可以留空。
3. 閱讀警告後按**儲存**。
4. 之後開啟「⋮ → 書籤」，找到儲存的時間點。
5. 想嘗試不同劇情時，按該書籤的**分支圖示 → 確認**。系統會從此處開啟新的聊天室，原本的對話仍會保留。

> **儲存書籤前請先確認。** 儲存後，**此時間點之前的訊息**將無法編輯、刪除或重新生成。如果還有內容要修改，請先完成修改。

書籤清單中的刪除圖示是**刪除書籤**。操作前請確認你要的是刪除書籤，還是從書籤建立分支。

## 6. 擷取對話

1. 選擇 **⋮ → 擷取聊天**。
2. 點選要擷取的第一則訊息。若要包含一段範圍，再點選最後一則訊息。只擷取一則時，選取一次即可。
3. 若不想包含自己的訊息，可開啟畫面下方的**排除我的訊息**（網頁）或**排除我的台詞**（App）。
4. 確認選取的訊息數量。網頁按**下載圖片**，App 按**儲存圖片**。

網頁會下載圖片檔案。App 可能因作業系統而要求照片存取權限，或開啟分享畫面；請依畫面提示操作。請至少選取一則訊息來擷取，若要中止則按**取消**。

## 結果與預期不同時

- 若要建立另一個聊天室，請依序按**開始新聊天 → 在作品詳情選擇開場白與 Persona → 開始新聊天**。
- 若要將載入的 Persona 套用到目前聊天室，請按**儲存**。
- 記憶畫面空白時，可以繼續聊天，稍後再查看。
- 若要改變回覆的寫作風格，請選擇 **⋮ → 寫作風格**。
- 找不到先前的聊天室時，也請查看**查看先前聊天**中的隱藏聊天清單。

開始第一次聊天的步驟請參閱[聊天](/chatting/chat-with-character.md)。
