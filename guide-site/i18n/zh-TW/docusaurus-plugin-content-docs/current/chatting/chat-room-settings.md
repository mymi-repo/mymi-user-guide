# 聊天室設定

說明如何在聊天室調整 AI 的回覆方式與畫面顯示，以及重讀或找到過去的對話。

## 按鈕位置

聊天室右上角有三個圖示。

| 圖示 | 點選後 |
| --- | --- |
| 眼睛 | 隱藏對話文字，只看圖片。再點一次就會恢復 |
| 調色盤 | 開啟 **UI 設定**，調整顯示方式、字體大小與顏色 |
| ⋮ | 開啟**房間管理**。本頁的設定大多在這裡 |

**房間管理**最上方會顯示剩餘的 Spark。未登入時則顯示**剩餘免費試用**。點選後會前往儲值畫面或登入視窗。

## 調整 AI 的回覆方式

在 ⋮ 選單的**聊天設定**中調整。調整後的設定從下一則回覆開始套用。

| 設定 | 作用 |
| --- | --- |
| **寫作風格** | **小說**的描寫與敘述較豐富，**輕小說**較輕快、以台詞為主 |
| **Story Booster** | 開啟後，AI 會主動製造事件，劇情推進得更快 |
| **允許 God Modding** | 開啟後，AI 連你的動作和台詞也會寫。想自己寫動作時請關閉 |
| **One Cut** | 開啟後，在會出現圖片的作品中，每則回覆只出現一張圖片。文字分量不變 |
| **最大輸出量** | 可以取得更長的回覆。可能會多扣 Spark，所以另外整理在[取得更長的回覆](/chatting/ai-models.md#取得更長的回覆) |

:::info[這些設定會套用到所有聊天室]
上面五項會儲存在你目前使用的瀏覽器或 App 中，其他聊天室也會套用相同設定。在其他裝置上需要重新選擇。每個聊天室分開儲存的是下方的**使用者備註**和**我的資訊**。
:::

## 使用者備註與 Persona

這些設定只會儲存在這個聊天室，在其他裝置開啟也不會改變。

**使用者備註**可以寫下你與角色的關係、背景，以及希望對方一定要記住的設定，最多 2,000 字。在 ⋮ 選單的**聊天設定 → 使用者備註**中寫好並點選**儲存**，AI 在這個聊天室每次回覆時都會參考。

```text
我是書妍的青梅竹馬，我們說話很隨意。
上週大吵一架，現在還有點尷尬。
```

**Persona** 是你在這個聊天室使用的名字與身分。在 ⋮ 選單的**聊天設定 → 我的資訊**中直接修改，或點選**載入**從你的 Persona 清單中選一個，再點選**儲存**。

在清單中修改 Persona 後，已經存在的聊天室不會跟著更新。請在該聊天室重新載入並**儲存**。建立 Persona 的方法請見 [Persona 設定](/account/persona.md)。

## 從頭重讀

1. 在 ⋮ 選單點選**從頭閱讀**。
2. 從第一個場景依序閱讀。閱讀期間，輸入框的位置會顯示**從頭閱讀中**，無法傳送或修改訊息。
3. 讀完後點選**返回對話**。原本寫到一半的文字仍會保留。

## 找到先前的聊天室

如果你在同一部作品開始了新的聊天，先前的聊天室都在這裡。

1. 在 ⋮ 選單點選**查看先前聊天**。
2. 點選聊天室後，會顯示**最後訊息**以及**繼續**、**隱藏**、**刪除**。
3. 點選**繼續**就會前往該聊天室。

隱藏的聊天室，請點選**先前聊天**視窗右上角的眼睛圖示，在**已隱藏聊天**中尋找。點選聊天室再點選**取消隱藏**，就會重新顯示。

:::danger[刪除的聊天室無法復原]
刪除前，請先用視窗中的**最後訊息**確認是哪一個聊天室。
:::

## 書籤與分支

可以把喜歡的時間點存起來，之後在新的聊天室從那個時間點嘗試不同的劇情。

1. 點選 AI 回覆下方的書籤圖示（**新增書籤**）。
2. 需要的話輸入名稱並點選**儲存**。名稱最多 50 字，也可以留空。
3. 之後在 ⋮ 選單的**書籤**中找到儲存的時間點。
4. 想從那個時間點重來時，點選分支圖示（**從這裡建立分支**）再點選**確認**。會開啟包含到那個時間點為止對話的新聊天室，原本的聊天室會保留下來。使用者備註與 Persona 也會帶到新的聊天室。

:::warning[加入書籤的回覆將無法再修改]
儲存書籤後，那則回覆和它之前的訊息都無法再重新生成、編輯或刪除。刪除書籤也不會解除。如果打算修改最後一則回覆，請先改好再加入書籤。
:::

書籤清單中的垃圾桶圖示（**刪除書籤**）只會刪除書籤。刪除的書籤無法復原。

## 擷取對話

1. 在 ⋮ 選單點選**擷取聊天**。
2. 點選要擷取的第一則訊息。要擷取多則時，再點選最後一則訊息決定範圍。
3. 想排除自己的訊息時，開啟**排除我的訊息**（App 為**排除我的台詞**）。
4. 網頁點選**下載圖片**，App 點選**儲存圖片**。

在 App 中，可能會詢問照片存取權限或開啟分享畫面。請依畫面指示選擇儲存位置。想中止時點選**取消**。

## 調整文字與畫面顯示

點選聊天室右上角的調色盤圖示，會開啟 **UI 設定**。

| 分類 | 可以調整的項目 |
| --- | --- |
| 顯示 | **UI 模式**：**小說**、**聊天**、**1:1** |
| 閱讀 | **字體大小**、**行高**、**字體**、**串流速度**（文字出現的速度） |
| 顏色 | **文字顏色**：角色對白、使用者對白、角色敘事、使用者敘事 |
| 畫面 | **聊天高度**、**聊天透明度**、**圖片高度**（小說）、**顯示角色名稱**（聊天） |
| 影片 | **循環播放影片**，以及用圖片取代影片的**圖片模式** |

- 每種顯示方式的設定分開儲存。**重設**只會把目前的顯示方式恢復成預設值。
- 設定會儲存在你目前使用的瀏覽器或 App 中，並套用到所有聊天室。

## 遇到問題時

<details>
<summary>對話文字不見了，只看得到圖片</summary>

再點一次聊天室右上角的眼睛圖示，文字就會恢復。

</details>

<details>
<summary>改了設定之後，其他聊天室也跟著變了</summary>

**聊天設定**中的寫作風格、Story Booster、允許 God Modding、One Cut、最大輸出量，以及 **UI 設定**，會套用到這台裝置上的所有聊天室。想讓每個聊天室不同的內容，請寫在**使用者備註**中。

</details>

<details>
<summary>載入的 Persona 沒有套用</summary>

用**載入**選好 Persona 後，還要點選**儲存**，才會套用到這個聊天室。

</details>

<details>
<summary>無法重新生成或修改回覆</summary>

按鈕只出現在最後一則 AI 回覆。已加入書籤的回覆和它之前的訊息也無法修改。如果出現「此訊息已被分支對話引用，無法編輯或刪除。」，原因就是書籤。

</details>

<details>
<summary>找不到先前的聊天室</summary>

請到 ⋮ 選單的**查看先前聊天**中尋找。隱藏的聊天室，請點選該視窗右上角的眼睛圖示，在**已隱藏聊天**中尋找。如果隱藏的是整部作品，請查看[常見問題](/faq/faq.md)中的「聊天室不見了」。

</details>

<details>
<summary>想詢問這個聊天室的問題</summary>

點選 ⋮ 選單的**複製房間 ID** 複製 ID，再連同發生的狀況寄到 [contact@mymi.live](mailto:contact@mymi.live)。

</details>
