# 長期記憶與記憶片段

對話變長後，MYMI 會將過去的內容整理成**長期記憶**，並將重要事件記錄成**記憶片段**。你可以在聊天室的「⋮ → 記憶管理」分別查看。

## 三者有什麼不同？

- **長期記憶：** 簡短整理對話的整體脈絡、人物關係與事件。
- **記憶片段：** 將重要時刻整理成獨立卡片。卡片可能顯示標題、相關角色與對話輪次範圍。點選卡片即可展開詳細內容。
- **使用者備註：** **由你親自撰寫並儲存**的備註。若有希望 AI 持續參考的名稱、關係、約定或說話方式，可以在此明確寫下。

長期記憶與記憶片段會隨著對話自動建立。若目前還沒有內容，請繼續聊天，稍後再查看。

## 1. 查看長期記憶

1. 按下聊天畫面右上角的 ⋮。
2. 選擇**記憶管理 → 長期記憶**。
3. 閱讀對話摘要。如果顯示**尚無長期記憶**，請繼續聊天，稍後再查看。

## 2. 尋找記憶片段

1. 按下聊天畫面右上角的 ⋮，選擇**記憶管理 → 記憶片段**。
2. 依標題、相關角色和輪次範圍尋找卡片。像 **T10–T20** 這樣的數字代表對話輪次範圍。
3. 點選卡片展開內容；再點一次即可收合。
4. 在頂部搜尋欄輸入事件、角色或情境，尋找**相關片段**。清除搜尋文字後會回到完整清單。
5. 向下捲動查看更多片段；在 App 中看到**載入更多**時可以點選。

搜尋也會找出語意相近的內容。若想找不同結果，請換個角色或事件再次搜尋，或繼續聊天後再試。

## 3. 開啟或關閉片段引用

登入後，開啟記憶片段畫面上方的**使用記憶片段**，之後的回覆便會參考相關片段。App 中同一開關標為**使用記憶**。關閉後，回覆會以不引用片段的方式產生。

- 已建立的片段會留在清單中，重新開啟開關即可使用。
- 長期記憶會另外整理對話的整體脈絡。
- 重新開啟聊天室、瀏覽器或 App 時，請確認開關狀態。

## 讓重要設定更容易延續

例如，**兩人和好的整體經過**可能出現在長期記憶，**和好時說好的某個約定**則可能成為記憶片段。如果之後的回覆一定要遵守該約定，建議直接寫在**使用者備註**中。你可以從[聊天室設定](/chatting/chat-room-settings.md)開啟並儲存備註。

如果 AI 說錯先前發生的事，先查看目前聊天室的長期記憶和記憶片段。重要設定請寫進使用者備註，或在下一則訊息清楚說明。
