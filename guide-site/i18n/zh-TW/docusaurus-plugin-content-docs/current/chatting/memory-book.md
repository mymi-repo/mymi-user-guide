# 長期記憶與記憶片段

對話變長後，MYMI 會將過去的內容整理成**長期記憶**，並將重要事件記錄成**記憶片段**。你可以在聊天室的「⋮ → 記憶管理」分別查看。V1 與 V2 作品使用相同的聊天記憶功能。

> **這與作品設定不同。** 創作者在作品編輯器中管理 V1 的世界觀、角色設定，或 V2 的提示詞與 Lorebook。本頁的記憶來自讀者在作品中進行的**對話內容**。

## 三者有什麼不同？

- **長期記憶：** 簡短整理對話的整體脈絡、人物關係與事件；不會逐字保存過去每一則訊息。
- **記憶片段：** 將重要時刻整理成獨立卡片。卡片可能顯示標題、相關角色與對話輪次範圍。點選卡片即可展開詳細內容。
- **使用者備註：** 與上面兩者不同，這是**由你親自撰寫並儲存**的備註。若有希望 AI 持續參考的名稱、關係、約定或說話方式，可以在此明確寫下。

長期記憶與記憶片段會自動建立。對話還很短或內容仍在整理時，畫面可能是空的。自動記憶也無法完整重現很久以前的每句話和所有細節。

## 1. 查看長期記憶

1. 按下聊天畫面右上角的 ⋮。
2. 選擇**記憶管理 → 長期記憶**。
3. 閱讀對話摘要。如果顯示**尚無長期記憶**，請繼續聊天，稍後再查看。

此畫面僅供閱讀，沒有直接編輯摘要的輸入欄或儲存按鈕。新摘要若未立即出現，可以繼續對話後重新進入聊天室確認。

> **關於「延伸記憶」：** 畫面會顯示**延伸記憶 · 500 → 2,000 字**開關。目前網頁與 App 的開關尚未連接實際的摘要長度或儲存設定。即使開啟，也不能據此認定摘要已延伸至 2,000 字。

## 2. 尋找記憶片段

1. 按下聊天畫面右上角的 ⋮，選擇**記憶管理 → 記憶片段**。
2. 依標題、相關角色和輪次範圍尋找卡片。像 **T10–T20** 這樣的數字代表對話輪次範圍。
3. 點選卡片展開內容；再點一次即可收合。
4. 在頂部搜尋欄輸入事件、角色或情境，尋找**相關片段**。清除搜尋文字後會回到完整清單。
5. 向下捲動查看更多片段；在 App 中看到**載入更多**時可以點選。

搜尋會尋找語意相近的內容，因此卡片即使沒有出現完全相同的字詞，也可能列入結果；想找的片段也可能找不到。如果顯示**沒有記憶片段**，請繼續聊天，稍後再查看。

## 3. 開啟或關閉片段引用

記憶片段畫面上方的開關，在網頁中標為**使用記憶片段**，在 App 中標為**使用記憶**。開啟後，往後生成回覆時會搜尋並參考相關片段。關閉後，往後的回覆不會加入片段搜尋結果。

- 關閉開關**不會刪除已建立的片段**；之後可以重新開啟。
- 此開關**不會關閉或刪除長期記憶**。對話摘要會另外處理。
- 開關狀態不會永久儲存在帳號中。重新開啟聊天室、瀏覽器或 App 時，請再確認狀態。
- 訪客體驗期間，即使開關顯示為開啟，伺服器也不會引用記憶片段。請登入後使用。

## 讓重要設定更容易延續

例如，**兩人和好的整體經過**可能出現在長期記憶，**和好時說好的某個約定**則可能成為記憶片段。如果之後的回覆一定要遵守該約定，建議直接寫在**使用者備註**中。你可以從[聊天室設定](/chatting/chat-room-settings.md)開啟並儲存備註。

如果 AI 說錯先前發生的事，先查看目前聊天室的長期記憶和記憶片段。這兩個畫面無法直接編輯內容；重要設定請寫進使用者備註，或在下一則訊息清楚說明。
