## 不能做的事

以下是[作品生成政策](https://www.mymi.live/zh-TW/legal/content-creation-policy)和[服務條款](https://www.mymi.live/zh-TW/legal/terms-of-service)禁止的主要行為。

- **未成年人相關的性內容**：對未滿 18 歲的人物，或看起來未滿 18 歲的人物、角色進行性化描寫。任何情況下都禁止
- **真人的性化描寫**：把真人性化、做成 deepfake，或製作、散布未經同意的性影像
- **違法內容**：違反法令的內容、教唆犯罪手法、鼓勵自傷自殺或毒品濫用的內容
- **仇恨與騷擾**：歧視、威脅、騷擾
- **侵害個資**：未經許可公開他人的個人資料
- **侵害權利**：未經許可使用他人的作品或肖像
- **露骨的性表現**：性器官露出，或露骨性行為的詳細描寫
- **公開範圍設定錯誤**：敏感內容的作品沒有正確設定就公開
- **在 MYMI 之外使用生成圖片**：下載或截圖 MYMI 生成的圖片，拿到 MYMI 之外發布或販售
- **規避安全機制**：規避年齡確認或安全篩選等，使用 Bot、自動化或大量生成

## 違規的話會怎麼樣？

依違規的內容和次數等，可能被警告、作品被設為不公開或刪除、功能被限制、帳號被暫停或永久停權。

- 未成年人相關的性內容、性剝削、真人色情 deepfake、重大權利侵害、付款盜用、惡意規避安全機制，可能不經事前警告就永久停權。
- 圖片生成功能的目的外使用、生成圖片的外部使用或銷售、自動化或大量生成，可能導致圖片生成功能被限制、Spark 使用被限制，或帳號被暫停。
- 詳細的處理方式請看[作品生成政策](https://www.mymi.live/zh-TW/legal/content-creation-policy)的「違規處理」。

:::warning[可能不事先通知就被刪除]
違反政策的作品或內容，可能不經事前通知就被刪除或設為不公開。
:::

## 檢舉

1. 開啟要檢舉的作品的詳細畫面。
2. 點選右上角的盾牌圖示，選擇**檢舉**。檢舉需要先登入。
3. 選擇檢舉原因，需要的話補充說明，再點選**提交檢舉**。

在同一個選單選擇**封鎖創作者**或**封鎖內容**，該創作者或作品就不會再出現在你的首頁和推薦中。

也可以用電子郵件檢舉或詢問。

| 這種情況 | 寄到 |
| --- | --- |
| 要檢舉有害內容 | [safety@mymi.live](mailto:safety@mymi.live) |
| 你的著作或肖像被未經許可使用 | [copyright@mymi.live](mailto:copyright@mymi.live) |
| 對收到的處分有異議 | [safety_appeal@mymi.live](mailto:safety_appeal@mymi.live) |
| 想詢問個人資料相關問題 | [privacy@mymi.live](mailto:privacy@mymi.live) |
| 其他問題 | [contact@mymi.live](mailto:contact@mymi.live) |

## 遇到問題時

<details>
<summary>我的作品突然被設為不公開，或被刪除了</summary>

被判斷違反作品生成政策的作品，可能不經事先通知就被設為不公開或刪除。對處分有異議的話，請寄信到 [safety_appeal@mymi.live](mailto:safety_appeal@mymi.live)，附上作品標題和你的 MYMI ID。審核被退回的作品，請看[公開與修改](/create/start/publish.md)。

</details>

<details>
<summary>想再看到我封鎖的作品或創作者</summary>

在**個人檔案 → 封鎖管理**可以解除封鎖。

</details>

<details>
<summary>找不到檢舉選單</summary>

點選作品詳細畫面右上角的盾牌圖示，才會開啟選單。還沒登入的話，點選檢舉時會先出現登入視窗。

</details>
