# 儲值 Spark

**Spark** 是與作品角色對話時使用的點數。每次傳送訊息時，會依選擇的 AI 模型與回覆長度扣除 Spark。各模型的扣除量請參考 [AI 模型指南](/chatting/ai-models.md)。

| 種類 | 說明 |
| --- | --- |
| Spark | 用於對話。可以儲值，或透過簽到、邀請朋友、活動取得 |
| Leaf | 創作者依作品使用情況獲得的獎勵，可以轉換為 Spark 使用。請參考[支持創作者](/creator-support/support.md) |

依服務條款，Spark 僅限年滿 18 歲的會員購買。

## 1. 開啟儲值畫面

1. 在**個人檔案**點選**我的 Spark**。
2. 在 **Spark 管理**點選**儲值 Sparks**。

對話中出現 Spark 不足的提示，或點選聊天室 **⋮** 選單最上方的餘額時，也會前往儲值畫面。儲值前需要登入。

## 2. 在網頁版儲值

網頁版以 **PayPal** 付款，幣別為新台幣（TWD）。也可以使用 PayPal 支援的信用卡等付款方式。

1. 在儲值畫面選擇方案。
2. 確認方案下方顯示的**商品**、**總金額**與**付款前確認**（販售業者、價格、付款時間、提供時間、退貨・退款）。
3. 若尚未完成年齡確認，請點選**驗證年齡**，確認已年滿 18 歲。
4. 點選畫面上出現的 PayPal 按鈕，在 PayPal 畫面完成付款。
5. 返回 MYMI，確認儲值完成的提示。

| 價格 | 獲得的 Spark | 說明 |
| ---: | ---: | --- |
| NT$120 | 5,000 | |
| NT$240 | 10,000 | |
| NT$700 | 31,500 | 含加碼 1,500 |
| NT$1,160 | 55,000 | 含加碼 5,000 |
| NT$2,320 | 115,000 | 含加碼 15,000 |

依你使用的付款方式條款，可能會產生匯率換算或跨境交易手續費。販售業者與退款條件請參考[交易資訊與退款政策](https://www.mymi.live/zh-TW/legal/transaction-info-refund-policy)。

## 3. 在 App 儲值

App 使用 **App Store**（iOS）或 **Google Play**（Android）的應用程式內購買儲值。

1. 在儲值畫面選擇方案，點選**購買**。
2. 在商店的付款畫面完成付款。
3. 確認儲值完成的提示。

App 的價格為商店登錄的價格，與網頁版不同。以下為 2026 年 9 月的價格，可能因商店情況變動，付款前請確認畫面與商店付款畫面上的金額。

| 獲得的 Spark | App Store・Google Play |
| ---: | ---: |
| 5,000（首次購買） | NT$80 |
| 5,000 | NT$150 |
| 10,000 | NT$290 |
| 31,500 | NT$840 |
| 55,000 | NT$1,400 |
| 115,000 | NT$2,790 |

標示**首次購買**的方案僅限 App 購買，需完成[手機號碼驗證](/account/adult-verification.md)，每個帳號限購一次。

## 4. 免費獲得 Spark

### 簽到

在**個人檔案 → 簽到**點選**簽到並領取 Sparks**，每天可領取一次 Spark。僅限已完成手機號碼驗證的帳號。

| 連續簽到 | 獲得的 Spark |
| --- | --- |
| 1～9 天 | 從 200 開始，每天增加 20（200、220、240、260、280、300、320、340、360） |
| 10 天 | 400 |

- 連續 10 天共可獲得 2,920 Spark。第 11 天起會重新從第 1 天的獎勵開始。
- 只要有一天沒有簽到，就會從第 1 天重新開始。
- 每天於台灣時間晚上 11 點換日。

### 邀請朋友

在**個人檔案 → 邀請朋友**，將**我的推薦碼**傳給朋友，或點選**分享給朋友**傳送邀請連結。

1. 朋友需在註冊後 **7 天內**完成手機號碼驗證，並登錄推薦碼。若透過邀請連結註冊，完成手機號碼驗證後推薦碼會自動登錄。
2. 朋友從登錄推薦碼當天起 **30 天內**完成首次付費購買時，你和朋友各可獲得 **1,500 Spark**。

只登錄推薦碼而沒有付款，不會發放獎勵。無法登錄自己的推薦碼。

### 活動

也可能透過官方活動或比賽獲得 Spark。條件請參考各活動公告。

## 5. 確認有效期間

Spark 依取得方式有不同的有效期間，到期後會自動失效。對話時會**先扣除較早到期的 Spark**。

| 取得方式 | 有效期間 |
| --- | --- |
| 儲值（購買）、由 Leaf 轉換 | 取得日起 1 年 |
| 簽到、活動 | 取得日起 14 天 |
| 邀請朋友獎勵 | 取得日起 30 天 |
| 比賽獎勵 | 取得日起 180 天 |

在 **Spark 管理**可以分開查看**付費 Spark** 與**免費 Spark**。若有 24 小時內到期的 Spark，會顯示 ⏰ 與「即將到期」。

## 6. 查看使用紀錄

點選**個人檔案 → 我的 Spark → 查看使用紀錄**，即可開啟 **Spark 使用紀錄**。

- **使用**分頁：對話使用的 Spark，以及到期失效的 Spark
- **儲值**分頁：購買、簽到、邀請朋友、由 Leaf 轉換取得的 Spark。回覆產生失敗而退回的 Spark 也會顯示在這裡

## 儲值遇到問題時

| 狀況 | 請確認 |
| --- | --- |
| 沒有出現 PayPal 按鈕 | 確認是否已完成年齡確認。若畫面顯示**驗證年齡**，請先完成年齡確認 |
| 無法購買首次購買方案 | 此方案僅限 App。確認是否已完成手機號碼驗證，以及是否已購買過 |
| 付款後 Spark 沒有增加 | 網頁版請重新整理儲值畫面，App 請重新啟動。仍未入帳時，請不要再次付款，並依[取消與退款](/payment/refund.md)的說明聯絡我們 |
| 付款畫面無法開啟，或付款後沒有返回 MYMI | 若在其他 App 內建的瀏覽器開啟，請改用平常使用的瀏覽器 |
| App 與網頁版價格不同 | App 以商店登錄的價格付款 |
| 無法領取簽到獎勵 | 確認登入狀態與手機號碼驗證。每天只能領取一次 |
| 沒有收到邀請朋友的獎勵 | 確認朋友是否在註冊後 7 天內登錄推薦碼，並在登錄後 30 天內完成首次付費購買 |

## 需要協助時

付款相關問題請寄信至 [contact@mymi.live](mailto:contact@mymi.live)。附上付款日期、付款方式、付款金額、帳號 ID、PayPal 交易 ID（App 請附上商店與訂單編號），可加快確認。
