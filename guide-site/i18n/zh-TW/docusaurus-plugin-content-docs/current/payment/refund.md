# 取消與退款

要向哪裡申請退款，取決於你**在哪裡付款**。

| 付款的地方 | 申請的地方 |
| --- | --- |
| 網頁版（PayPal） | MYMI 信箱 [contact@mymi.live](mailto:contact@mymi.live) |
| iPhone App | Apple（App Store） |
| Android App | Google Play |

付款後沒收到 Spark 的話，在申請退款或再次付款之前，請先照[這些步驟](#付款後沒收到-spark-時)確認。

## 在網頁版付款時

### 可以退款的情況

網頁版的購買，依照[交易資訊與退款政策](https://www.mymi.live/zh-TW/legal/transaction-info-refund-policy)和[服務條款](https://www.mymi.live/zh-TW/legal/terms-of-service)第 7 條。

Spark 在付款後會立即入帳，而且馬上就能使用，所以**購買完成後，原則上不接受取消、退貨或退款**。不過，下列情況請聯絡我們，我們會確認你的申請：

- 已經付款，但 Spark 沒有入帳
- 因為 MYMI 的重大故障，無法使用你買的 Spark
- 購買畫面上的內容，和實際收到的內容有很大差異
- 被重複扣款，或有人未經你同意就購買
- 依法令或 PayPal 的規則需要退款

是否退款，以及退款的方式和時間，會依付款紀錄、使用紀錄、錯誤紀錄、PayPal 的規則和適用法令來判斷。如果那筆購買的 Spark 已經用了一部分，可能只有沒用到的部分能退。用簽到、活動或邀請朋友免費獲得的 Spark 不能退款。

台灣消費者保護法對網路購物設有解除契約的規定。數位內容和線上服務是否適用，要看交易性質、法令上的例外，以及你的同意。你依適用法令享有的權利，不會因為這份指南的說明而受到限制。

### 申請退款

1. 寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
2. 寫上你的 MYMI ID（**個人檔案**暱稱下方的 `@ID`）、付款日期與金額、PayPal 交易 ID，以及發生了什麼事。交易 ID 可以在 PayPal 寄來的收據信，或 PayPal 活動紀錄裡該筆付款的詳細資料中找到。
3. 我們會確認你的申請並用電子郵件回覆。如果核准退款，款項會退回你付款時使用的方式。需要多久，取決於 PayPal 和發卡銀行。

## 在 App 付款時

App 內的付款，要在商店的購買紀錄申請退款。這要依商店的退款政策和審核，MYMI 無法決定商店是否核准。

- **iPhone**：依照 Apple 支援的[針對向 Apple 購買的 App 或內容要求退款](https://support.apple.com/zh-tw/118223)操作。
- **Android**：依照 Google Play 說明中心的[退款政策](https://support.google.com/googleplay/answer/2479637?hl=zh-Hant)操作。

商店核准退款後，那筆付款獲得的 Spark 可能會被收回。

## 付款後沒收到 Spark 時

再次付款之前，請依序確認。

1. 網頁版請重新整理儲值畫面；App 請完全關閉後再重新開啟。Android App 會重新確認未完成的付款，Spark 入帳後會顯示「已復原先前的購買」。
2. 在**個人檔案 → 我的 Spark → 查看使用紀錄**的**儲值**分頁，看有沒有這筆購買紀錄。
3. 還是沒有的話，請附上下列資料，寄信到 [contact@mymi.live](mailto:contact@mymi.live)。iPhone App 重新開啟後仍沒入帳的話，請不要等待，直接聯絡我們。

| 付款的地方 | 要提供的資料 |
| --- | --- |
| 網頁版 | 付款日期、付款金額、MYMI ID、PayPal 交易 ID |
| App | 商店（App Store 或 Google Play）、付款日期、訂單編號或交易 ID、MYMI ID |

## 遇到問題時

<details>
<summary>我在 App 付款的，可以向 MYMI 申請退款嗎？</summary>

App 內付款的退款，MYMI 無法處理。請在 App Store 或 Google Play 的購買紀錄申請。如果已經付款但 Spark 沒有入帳，請聯絡 MYMI。

</details>

<details>
<summary>我用掉一部分 Spark 了，還能退款嗎？</summary>

網頁版的購買，可能只有沒用到的 Spark 能退款。如果是 MYMI 這邊的問題，讓你沒辦法正常使用，請寄信到 [contact@mymi.live](mailto:contact@mymi.live) 說明狀況。

</details>

<details>
<summary>我向 PayPal 或銀行提出了付款爭議</summary>

爭議審查期間，我們可能會先保留那筆購買的 Spark。如果款項被撤銷，這些 Spark 會從你的帳號收回。可以的話，提出爭議之前請先聯絡我們。

</details>

<details>
<summary>我想在刪除帳號之前先退款</summary>

刪除帳號後，剩下的 Spark 會消失，所以要退款請在刪除之前申請。如果已經刪除帳號，請寄信到 [contact@mymi.live](mailto:contact@mymi.live)，附上已刪除帳號的 MYMI ID 和付款資料。

</details>
