# 取消與退款

退款窗口依**付款的地方**而不同。在網頁版付款請聯絡 MYMI，在 App 付款請向 App Store 或 Google Play 申請。

| 付款的地方 | 聯絡對象 |
| --- | --- |
| 網頁版（PayPal） | MYMI（[contact@mymi.live](mailto:contact@mymi.live)） |
| iOS App | Apple（App Store） |
| Android App | Google Play |

## 1. 在網頁版購買的 Spark

網頁版的購買依[交易資訊與退款政策](https://www.mymi.live/zh-TW/legal/transaction-info-refund-policy)及[服務條款](https://www.mymi.live/zh-TW/legal/terms-of-service)第 7 條處理。

Spark 是數位服務使用權，付款完成後會立即發放。依其性質，**購買完成後原則上不接受取消、退貨或退款**。

但以下情形請聯絡我們：

- 付款完成，Spark 卻沒有正常入帳
- 因 MYMI 重大故障，無法使用購買的 Spark
- 購買頁面顯示的內容與實際提供內容重大不符
- 發生重複扣款、未授權付款或付款異常
- 依法令或付款服務提供者規則需要退款

是否退款、退款方式與處理期間，將依本公司的確認結果，以及 PayPal 等付款業者的規定判斷。免費發放的 Spark、加碼、簽到與活動獎勵不在退款範圍內。

台灣消費者保護法對通訊交易設有解除契約的規定。但數位服務於付款後立即提供並開始使用，是否適用及實際能否退款，依適用法令、購買內容、使用狀態與付款服務規則判斷。

經確認為未滿 18 歲者付款時，將依法令與付款業者規定採取必要措施。

### 聯絡方式

請寄信至 [contact@mymi.live](mailto:contact@mymi.live)，並附上以下資訊：

- 付款日期
- 付款方式
- 付款金額
- 帳號 ID
- PayPal 交易 ID

## 2. App 內購買的退款

在 App 購買時，請從你使用的商店購買紀錄申請退款。退款依商店的退款政策與審核流程處理，MYMI 無法決定是否核准。

- **iOS**：Apple 支援的[申請退款](https://support.apple.com/zh-tw/118223)
- **Android**：Google Play 說明中心的[退款政策](https://support.google.com/googleplay/answer/2479637?hl=zh-Hant)

商店核准退款後，該筆購買發放的 Spark 可能會被收回。

## 3. 付款後 Spark 未入帳時

申請退款或再次付款前，請先確認：

1. 網頁版請重新整理儲值畫面，App 請完全關閉後重新開啟。
2. 在**個人檔案 → 我的 Spark → 查看使用紀錄**的**儲值**分頁，確認是否有紀錄。
3. 若仍未入帳，請寄信至 [contact@mymi.live](mailto:contact@mymi.live)。

| 付款的地方 | 聯絡時請附上 |
| --- | --- |
| 網頁版 | 付款日期、付款方式、付款金額、帳號 ID、PayPal 交易 ID |
| App | 商店（App Store・Google Play）、付款日期、訂單編號或交易 ID、帳號 ID |

## 需要協助時

付款與退款問題請寄信至 [contact@mymi.live](mailto:contact@mymi.live)。方案與價格請參考[儲值 Spark](/payment/payment-methods.md)。
