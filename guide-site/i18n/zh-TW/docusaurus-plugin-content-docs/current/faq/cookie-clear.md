# 清除 Cookie

在網頁版看不到個人檔案或登出按鈕，或驗證無法進行時，請依以下順序嘗試。

## 1. 重新登入

點選**個人檔案 → 設定與支援 → 登出**，再以註冊時使用的社群帳號重新登入。

若問題仍未解決，請在使用的瀏覽器中清除 MYMI（mymi.live）的 Cookie 與網站資料。

## 2. 清除瀏覽器 Cookie

步驟依瀏覽器與版本而不同，請參考各瀏覽器的官方說明。如果可以只刪除單一網站的資料，請只刪除 mymi.live 的資料。

| 瀏覽器 | 官方說明 |
| --- | --- |
| Chrome（電腦・Android・iPhone） | [Google Chrome 說明：刪除及管理 Cookie](https://support.google.com/chrome/answer/95647?hl=zh-Hant) |
| Safari（iPhone・iPad） | [Apple 支援：清除 iPhone 上 Safari 的記錄、快取與 Cookie](https://support.apple.com/zh-tw/105082) |
| Safari（Mac） | [Apple 支援：清除 Mac 上 Safari 的快取與 Cookie](https://support.apple.com/zh-tw/guide/safari/sfri11471/mac) |
| Microsoft Edge | [Microsoft 支援：在 Microsoft Edge 中管理 Cookie](https://support.microsoft.com/zh-tw/microsoft-edge/delete-cookies-in-microsoft-edge-63947406-40ac-c3b8-57b9-2a946a29ae09) |

:::warning
清除所有 Cookie 後，除了 MYMI，其他網站也可能會被登出。
:::

## 需要協助時

若仍無法解決，請透過**個人檔案 → Discord → 聯絡我們**，或寄信至 [contact@mymi.live](mailto:contact@mymi.live)。附上使用的裝置與瀏覽器，有助於確認問題。
