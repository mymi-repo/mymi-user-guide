# 清除 Cookie

在網頁版一直被登出、登入後又出現登入畫面，或**個人檔案**打不開時，請依下面的順序嘗試。

App 不需要清除 Cookie。請點選**個人檔案 → 設定與支援 → 登出**，再用註冊時的社群帳號重新登入。

## 先重新登入

如果在**個人檔案**看得到登出按鈕，請點選**個人檔案 → 設定與支援 → 登出**，再用註冊時的社群帳號重新登入。

如果看不到登出按鈕，或重新登入後還是出現同樣的問題，請在你使用的瀏覽器中，清除 MYMI（mymi.live）的 Cookie 與網站資料。清除之後需要重新登入。

## 清除瀏覽器的 Cookie

步驟會依瀏覽器和版本而不同，請參考你使用的瀏覽器的官方說明。如果可以只刪除單一網站的資料，請只刪除 mymi.live 的資料。

| 瀏覽器 | 官方說明 |
| --- | --- |
| Chrome（電腦・Android・iPhone） | [Google Chrome 說明：刪除及管理 Cookie](https://support.google.com/chrome/answer/95647?hl=zh-Hant) |
| Safari（iPhone・iPad） | [Apple 支援：清除 iPhone 上 Safari 的記錄、快取與 Cookie](https://support.apple.com/zh-tw/105082) |
| Safari（Mac） | [Apple 支援：清除 Mac 上 Safari 的快取與 Cookie](https://support.apple.com/zh-tw/guide/safari/sfri11471/mac) |
| Microsoft Edge | [Microsoft 支援：在 Microsoft Edge 中管理 Cookie](https://support.microsoft.com/zh-tw/microsoft-edge/delete-cookies-in-microsoft-edge-63947406-40ac-c3b8-57b9-2a946a29ae09) |

:::warning[其他網站也可能被登出]
清除所有 Cookie 後，除了 MYMI，其他網站也可能會被登出。
:::

## 遇到問題時

<details>
<summary>清除了 Cookie，還是無法登入</summary>

- 如果你是在 LINE 或 Instagram 等 App 裡開啟 MYMI，請改用 Chrome 或 Safari 直接開啟 [www.mymi.live](https://www.mymi.live)。
- 也請用其他瀏覽器登入看看。如果其他瀏覽器可以，問題可能出在你原本使用的瀏覽器的設定。

</details>

<details>
<summary>其他網站也被登出了</summary>

從瀏覽器的整個瀏覽紀錄清除 Cookie，其他網站的登入也會被登出。請重新登入那些網站。

</details>

<details>
<summary>登入了，卻看不到之前的聊天或 Spark</summary>

這不是 Cookie 的問題，可能是你用了不同的社群帳號登入。每個社群帳號都有各自的 MYMI 帳號。請先登出，再用最初註冊的社群帳號重新登入。

</details>

如果還是沒有解決，請附上你使用的裝置和瀏覽器，從[聯絡我們](/faq/faq.md#聯絡我們)告訴我們。
