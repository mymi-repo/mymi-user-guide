# MYMI 使用指南

MYMI 是一款 AI 服務，讓你**透過與作品中的角色對話參與故事，也能創作自己的作品**。你可以使用網頁版或手機 App。

初次使用時，可先了解連線方式與帳號設定；已經在使用的讀者，可以直接查看需要的功能。

## 第一次使用 MYMI？

1. **[什麼是 MYMI？](getting-started/what-is-mymi.md)** — 了解你能在故事中做什麼。
2. **[如何使用 MYMI](getting-started/how-to-access.md)** — 開啟網站，或安裝 Android、iOS App。
3. **[註冊](account/sign-up.md)** — 建立帳號並設定個人檔案。
4. **[開始聊天](chatting/chat-with-character.md)** — 挑選喜歡的作品，開始第一段對話。

## 想創作自己的作品

創作時，先準備世界觀、登場人物，以及使用者最初會遇到的場景。之後可以加入聊天圖片、在特定情況下提供設定的 Lorebook，以及狀態欄等元件。

目前從底部選單的**建立**新增作品，會開啟**作品創作 2.0（V2）** 編輯器。在 V2 中，你會將作品設定寫入提示詞，並設定圖片與元件的使用規則。V1 中分別填在世界觀、登場人物、秘密欄位的內容，也改由這份提示詞來組織。

現有 V1 作品可從作品管理中選取並**編輯**，回到該作品的 V1 編輯器。操作方式請參考[現有 V1 作品創作指南](character-creation/create-character.md)。
