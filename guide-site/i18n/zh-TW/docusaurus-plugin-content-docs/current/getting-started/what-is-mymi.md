# 什麼是 MYMI？

MYMI 讓你**與 AI 扮演的作品角色對話，一起推進故事**。選擇喜歡的作品後，可以向角色說話，也能輸入符合情境的行動。

例如，在「只在午夜開門的書庫」中，你可以扮演新來的夜班助手，與館員交談、調查可疑的還書紀錄。你說了什麼、調查了什麼，都會影響接下來的場景。

## 作品、登場人物與人設有什麼不同？

| 名稱 | 意思 | 書庫作品的例子 |
| --- | --- | --- |
| 作品 | 包含世界觀、人物及起始情境的故事 | 只在午夜開門的書庫故事 |
| 登場人物 | AI 按照作品設定扮演的人物 | 管理書庫的館員徐妍 |
| 人設（Persona） | 你在故事中使用的名字、身分等資料 | 第一天上班的夜班助手 |
| 開場 | 開始對話時最先出現的訊息 | 徐妍遞給你還書紀錄的第一幕 |

一部作品可以有多位登場人物。你可以將兩者理解為：**登場人物由 AI 扮演，人設則是你扮演的身分。**

詳細說明請參考[人設設定](/account/persona.md)。

## 在其他創作者的作品中聊天

1. 在**首頁**尋找作品。
2. 閱讀作品介紹，在喜歡的作品中開始聊天。
3. 讀完開場後，輸入想對角色說的話或自己要做的事。
4. 進行中的對話可以從**聊天**列表重新開啟。

你也可以更換 AI 模型或調整聊天室設定。如果創作者準備了圖片與元件，對話中可能會出現人物圖片或狀態欄。

剛開始只說一句簡短的話也可以。操作方式請參考[開始聊天](/chatting/chat-with-character.md)。

## 創作自己的作品

從底部選單的**建立**進入**作品創作 2.0（V2）** 編輯器，便能新增作品。你可以自由切換分頁，從需要的部分開始填寫。

| 要準備的內容 | 用途 |
| --- | --- |
| 作品介紹與封面 | 讓讀者了解作品的內容 |
| 提示詞 | 告訴 AI 世界觀、人物個性與語氣、秘密，以及故事推進規則 |
| 開場 | 撰寫使用者最初會遇到的場景 |
| 圖片與元件 | 準備聊天時顯示的圖片和畫面元素，並設定使用條件 |
| Lorebook | 撰寫對話出現特定詞語時可參考的額外設定 |

不用一開始就使用所有功能。先決定一位人物和起始場景，再陸續加入需要的圖片與設定。

如果你曾使用 V1，最大的差異是：原本分別填在世界觀、人物、秘密欄位的內容，現在都由**提示詞**來組織。上傳圖片後，也要設定在對話中何時使用。現有 V1 作品仍可從作品管理進入原本的 V1 編輯器。

## 可以在哪裡使用？

MYMI 提供電腦與手機網頁版，以及 Android、iOS App。網址與安裝連結請參考[如何使用 MYMI](/getting-started/how-to-access.md)。
