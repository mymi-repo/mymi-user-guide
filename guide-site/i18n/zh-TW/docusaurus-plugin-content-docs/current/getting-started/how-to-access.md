# 如何使用 MYMI

MYMI 可透過**網頁瀏覽器及 Android、iOS App**使用。電腦使用者可開啟網站，手機使用者可選擇 App 或手機網頁版。

## 使用網頁版

1. 在電腦或手機上開啟瀏覽器。
2. 前往 [**MYMI 網站**](https://www.mymi.live)。
3. 瀏覽作品，想開始聊天時，依畫面指示登入。

不需要另外安裝程式，就能使用網頁版。

## 使用 App

| 裝置 | 安裝連結 |
| --- | --- |
| Android | [從 Google Play 安裝 MYMI](https://play.google.com/store/apps/details?id=live.mymi.app) |
| iOS | [從 App Store 安裝 MYMI](https://apps.apple.com/app/id6794338974) |

1. 開啟符合裝置的商店連結。
2. 安裝並開啟 MYMI。
3. 初次使用請註冊；已有帳號則使用原本的帳號登入。

網頁版和 App 都是同一個 MYMI 服務。換裝置繼續使用時，請選擇**原本使用的登入方式與帳號**。詳情請參考[註冊](/account/sign-up.md)與[登入及個人檔案設定](/account/login-profile.md)。

## 底部選單

| 選單 | 可以做什麼 |
| --- | --- |
| 首頁 | 瀏覽並尋找感興趣的作品 |
| 聊天 | 尋找已開始的對話，繼續聊天 |
| 建立 | 創作新的作品 |
| 個人檔案 | 查看個人資料、帳號、作品管理等功能 |

作品製作畫面和聊天室會顯示該畫面需要的選單。剛開始可以先從首頁挑一部喜歡的作品。

## 開啟連結後，無法登入或畫面異常

在 KakaoTalk、Instagram 等 App 中開啟連結時，可能會使用 App 內建的瀏覽器。如果無法登入或畫面卡住，可選擇選單中的**使用外部瀏覽器開啟**，或複製網址，貼到平常使用的瀏覽器。

不同 App 的選單名稱與位置可能不同。

## 無法連線時

1. 檢查網路連線，重新整理網頁或重新開啟 App。
2. 檢查瀏覽器或 MYMI App 是否有更新。
3. 使用網頁版時，試試其他瀏覽器。
4. 如果只有特定瀏覽器持續出問題，請參考[清除 Cookie](/faq/cookie-clear.md)。清除後可能需要重新登入。

若問題持續，請查看[常見問題](/faq/faq.md)，或聯絡客服並附上出問題的畫面及使用環境。
