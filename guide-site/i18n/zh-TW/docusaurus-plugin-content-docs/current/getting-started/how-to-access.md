# 如何使用 MYMI

MYMI 的網頁版與 Android、iPhone App 使用同一個帳號。在電腦上請從網頁版開始，在手機上可以用 App 或手機瀏覽器。

## 用網頁版開啟

1. 用 Chrome 或 Safari 等瀏覽器開啟 [www.mymi.live/zh-TW](https://www.mymi.live/zh-TW)。不需要安裝任何東西。
2. 第一次進入時，會出現「選擇你最想看的角色」視窗。從**女性角色**、**男性角色**、**全部都想看**中選一個，首頁就會優先顯示有該類角色登場的作品。之後可以在首頁的篩選中更改。
3. 開啟喜歡的作品聊聊看。不登入也能免費聊 5 次。

免費試用用完後會出現登入視窗。直接在那裡註冊新帳號，就能在新帳號中接續試用時的對話。註冊方法請見[註冊](/account/sign-up.md)。成人作品需要登入並完成年齡確認（年滿 18 歲）才能開啟。

## 安裝 App

| 裝置 | 安裝 |
| --- | --- |
| Android | [在 Google Play 安裝 MYMI](https://play.google.com/store/apps/details?id=live.mymi.app) |
| iPhone | [在 App Store 安裝 MYMI](https://apps.apple.com/app/id6794338974) |

如果是用手機瀏覽器開啟 MYMI，也可以點選首頁右上角的**安裝 App**前往商店。開啟安裝好的 App 後，從下方選單的**個人檔案**登入或註冊。

## 同時使用網頁版與 App

網頁版與 App 使用同一個帳號。用註冊時的社群帳號登入，聊天紀錄和 Spark 都會一樣。

:::warning[如果你是用 LINE、X 或 Apple 註冊]
App 沒有 LINE 和 X 登入，Android App 也沒有 Apple 登入。這種情況請在網頁版登入：在手機上也可以用 Chrome 或 Safari 開啟 [www.mymi.live/zh-TW](https://www.mymi.live/zh-TW)，點選和註冊時相同的按鈕。
:::

## 畫面下方的選單

| 選單 | 可以做的事 |
| --- | --- |
| **首頁** | 尋找作品 |
| **聊天** | 開啟聊過的作品，接著聊下去 |
| **建立** | 創作自己的作品 |
| **個人檔案** | 登入、查看個人資訊與 Spark、簽到、內容管理 |

## 遇到問題時

<details>
<summary>在 LINE 或 Instagram 開啟連結後無法登入</summary>

在其他 App 裡開啟連結時，會用該 App 內建的瀏覽器開啟，可能因此無法登入。請從畫面上方或下方的選單（⋮ 或 …）選擇「用瀏覽器開啟」之類的項目，改用 Chrome 或 Safari 開啟。如果沒有這種選單，請複製網址貼到瀏覽器。

</details>

<details>
<summary>出現「試試更好的瀏覽體驗！」視窗</summary>

這是在 TikTok App 裡開啟連結時出現的提示。請從 TikTok 畫面右上角的「…」選單選擇「在瀏覽器中開啟」。也可以點選視窗中的**複製連結**，再貼到瀏覽器。

</details>

<details>
<summary>畫面打不開，或一直在載入</summary>

1. 確認網路連線後重新整理，或關閉 App 再重新開啟。
2. 如果瀏覽器或 MYMI App 有更新，請先安裝。
3. 改用其他瀏覽器開啟看看。
4. 只有某個瀏覽器有問題時，請照著[清除 Cookie](/faq/cookie-clear.md) 操作。清除後需要重新登入。

</details>

<details>
<summary>在 App 登入後，先前的對話不見了</summary>

可能是用了和網頁版註冊時不同的社群帳號登入。每個社群帳號都有各自的 MYMI 帳號。請點選**個人檔案 → 設定與支援 → 登出**，再用最初註冊的社群帳號重新登入。

</details>

如果還是無法解決，請從**個人檔案 → Discord** 前往 Discord 的詢問頻道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。在 App 中，可以用**個人檔案 → 設定與支援 → 版本資訊**的**複製客服資訊**複製使用環境，一併提供給我們。
