# 支持創作者

你可以透過追蹤與留言，支持喜歡作品的創作者。如果你也在製作作品，可以申請成為創作者並獲得 **Leaf**。

## 1. 查看創作者的個人檔案

在作品詳情點選創作者名稱，就會開啟創作者的個人檔案。你可以在這裡查看該創作者的作品、**公告**與**留言**。

## 2. 追蹤創作者

點選個人檔案上的**追蹤**，創作者公開新作品時就能收到通知。再點一次即可取消追蹤。追蹤中的創作者可在**個人檔案 → 我的活動 → 追蹤中**查看。

## 3. 留言

在創作者個人檔案的**留言**分頁，可以留下支持的留言。

- 自己的留言可以編輯或刪除，也可以回覆其他留言。
- 選擇**秘密留言**後，只有你和創作者能看到。秘密回覆也能讓被回覆的人看到。
- 創作者可以刪除自己個人檔案上的留言。原留言被刪除後，底下的回覆也不會再顯示。

自己寫過的留言可在**個人檔案 → 我的活動 → 留言**查看。

## 4. 申請成為創作者

在**個人檔案 → 創作者**確認申請條件的達成狀況。

| 條件 | 標準 |
| --- | --- |
| 聊天量 | 其他使用者在你的作品中進行的聊天達 5,000 次以上 |
| 作品數 | 已通過審核的作品達 3 個以上 |

1. 兩項條件都達成後，勾選**我同意創作者條款**。
2. 點選**申請成為創作者**。
3. 確認符合條件後，就會成為創作者。

你自己在自己作品中的聊天不計入聊天量。條款請參考 [MYMI 創作者條款](https://www.mymi.live/zh-TW/legal/creator-terms)。

## 5. 累積 Leaf

成為創作者後，其他使用者在你已公開並通過審核的作品中使用**付費 Spark** 對話時，使用的 Spark 會有一部分累積為 Leaf。使用免費 Spark 的對話不會累積。

比例依作品**其他設定**中選擇的**作品公開範圍**與**圖片來源**而不同。

| 作品公開範圍 | 圖片來源 | Leaf 比例 |
| --- | --- | ---: |
| 原創 | 不限 | 5% |
| 一般 | 外部製作 | 3% |
| 一般 | MYMI 生成 | 不累積 |

- 官方創作者的原創作品比例為 7%，其他比例相同。
- 例如，原創作品中使用了 100 付費 Spark，就會累積 5 Leaf。
- 你自己在自己作品中的對話不會累積 Leaf。官方創作者在自己作品中的對話也會累積。
- 在製作畫面選擇**限制收益**的作品，會被標示為無法獲得 Leaf 的作品。
- 獲得的 Leaf 需在 **30 天內**使用。請在到期前轉換為 Spark。

## 6. 將 Leaf 轉換為 Spark

1. 在**個人檔案 → 創作者**確認**目前 Leaf**，點選**轉換為 Spark**。
2. 輸入**轉換數量（以 100 為單位）**。點選**全部**會自動填入可轉換的數量。
3. 確認將獲得的 Spark 後，點選**轉換**。

| 等級 | 轉換比例 |
| --- | --- |
| 創作者 | 100 Leaf = 80 Spark |
| 官方創作者 | 100 Leaf = 100 Spark |

- 需有 100 Leaf 以上，並只能以 100 為單位轉換。
- 轉換會立即處理，不收取手續費，轉換後無法復原。
- 由 Leaf 轉換的 Spark 自取得日起 1 年內有效。

## 7. 查看創作者儀表板

點選**個人檔案 → 內容管理 → 儀表板**，即可開啟**創作者儀表板**。

- 一次查看**總訊息數**、**我的訊息**與**已獲得 Leaf**。
- 將期間切換為**今天**或 **7 天**，查看每日趨勢與熱門作品排名。
- 在**作品表現**點選作品，即可查看詳細數據。

儀表板的訊息數與申請條件中的聊天量，計算範圍不同。申請條件請在**個人檔案 → 創作者**確認。

## 8. 官方創作者

聊天量超過 **50,000 次**後，即可使用**個人檔案 → 創作者**中的**申請官方創作者**。點選**提交申請**後會前往申請表，經營運團隊審查後即可成為官方創作者。

官方創作者有以下不同：

- 原創作品的 Leaf 比例為 7%。
- 自己作品中的對話也會累積 Leaf。
- 100 Leaf 可轉換為 100 Spark。
- 收益分配依 [MYMI 創作者條款](https://www.mymi.live/zh-TW/legal/creator-terms)及個別提供的條件辦理，僅限年滿 18 歲的使用者。
