# 登入與個人檔案設定

你可以在**個人檔案**登入並管理自己的資訊。編輯前，先確認要調整的是**對話中使用的資訊**，還是**顯示給其他使用者的資訊**。

## 1. 登入既有帳號

1. 開啟 [MYMI 網站](https://www.mymi.live/zh-TW)或 MYMI App。
2. 選擇底部導覽列的**個人檔案**。尚未登入時，畫面會顯示社群登入按鈕。
3. 選擇註冊時使用的登入方式與社群帳號。
4. 登入後，確認上方的暱稱與 `@ID` 是否為自己的帳號。

若要在網頁與 App 使用同一個 MYMI 帳號，請選擇註冊時使用的社群帳號。例如，透過 Google 註冊時，請用同一個 Google 帳號登入。

登入按鈕會依網站語言與使用環境而有所不同。支援的登入方式可參考[註冊說明](/account/sign-up.md)。

> **已經註冊，卻看到註冊畫面？**
>
> 再次填寫基本資料前，請先確認登入方式與社群帳號。如果有多個 Google 帳號，可能選到了不同帳號。若透過 Apple 註冊，但 Android App 沒有 Apple 按鈕，可以在行動版網站使用 Apple 登入。

## 2. 找到要修改的項目

點選個人檔案頁面上方顯示**個人檔案圖片、暱稱與 ID 的區域**，即可開啟**編輯個人檔案**。畫面分為**我的資訊**與**創作者**兩個分頁。

| 想修改的內容 | 操作位置 |
| --- | --- |
| 名稱、性別、出生日期、詳細資訊 | 編輯個人檔案 → **我的資訊** |
| 顯示給其他使用者的暱稱與 `@ID` | 編輯個人檔案 → **我的資訊** |
| 個人檔案圖片、網站、公開介紹 | 編輯個人檔案 → **創作者 → 編輯個人檔案** |
| 在作品中使用的其他名稱或角色定位 | 個人檔案 → **Persona 設定** |

個人檔案圖片需在**創作者**分頁變更。即使尚未創作作品，也能在這裡編輯公開個人檔案。

## 3. 編輯我的資訊

在**我的資訊**分頁修改項目，然後點選分頁上方的**儲存變更**，即可更新個人檔案。

| 項目 | 用途與注意事項 |
| --- | --- |
| 名稱 | 預設 Persona 在對話中使用的名稱 |
| 性別 | 也會反映在預設 Persona。已完成身分驗證的帳號無法修改 |
| 暱稱 | 顯示給其他使用者的名稱，也會用作創作者名稱 |
| ID | 用來識別帳號，例如 `@moon_reader`，也會用於公開個人檔案網址 |
| 出生日期 | 也會反映在預設 Persona。已完成身分驗證的帳號無法修改 |
| 詳細資訊 | 使用預設 Persona 對話時，角色可參考的資訊。最多 **1,000 字** |

例如，將**名稱**設為 `小春`、**暱稱**設為 `月光讀者`，預設 Persona 就會使用「小春」這個名字，而其他使用者會看到「月光讀者」。

### 變更 ID 時

ID 長度為 **3～20 個字元**，可使用小寫英文字母、數字、底線（`_`）與連字號（`-`）。開頭與結尾不可使用底線或連字號，這兩種符號也不能連續使用，包括混合使用的情況。

輸入後會自動檢查是否重複。確認顯示**可使用**後再儲存。如果檢查失敗，可點選輸入欄旁的**檢查**重試。變更 ID 後，也請確認先前分享的個人檔案連結。

### 詳細資訊與 Persona 的關係

在我的資訊儲存名稱、性別、出生日期或詳細資訊時，會更新**帳號資訊與預設 Persona**。若要編輯另外建立的 Persona，請到 [Persona 設定](/account/persona.md)選取該項目。

若變更預設名稱後，對話仍使用其他名字，請確認目前使用哪個 Persona。想在不同作品中扮演不同角色時，可以使用 [Persona 設定](/account/persona.md)。

## 4. 變更個人檔案圖片與公開介紹

1. 前往**個人檔案 → 上方個人檔案區域 → 創作者**分頁。
2. 點選**編輯個人檔案**。
3. 修改下列項目。
4. 若選擇了圖片，請等上傳完成後再點選**儲存**。
5. 儲存後，回到創作者分頁確認圖片與介紹是否已更新。

| 項目 | 設定方式 |
| --- | --- |
| 個人檔案圖片 | 點選圖片區域的**新增**或**變更**，再從裝置選擇圖片 |
| 網站 | 輸入想顯示給其他使用者的網站網址 |
| 介紹 | 撰寫公開個人檔案上的自我介紹或創作介紹，最多 **10,000 字** |

圖片上傳完成後，點選**儲存**即可更新公開個人檔案。如果 App 要求照片存取權限，請允許存取要使用的照片。

**創作者**分頁也能查看自己的公開介紹、公告、留言與作品清單。若要繼續編輯製作中的作品，請前往個人檔案頁面的**內容管理**。

### 其他人看得到哪些資訊？

公開創作者個人檔案會顯示**暱稱、ID、個人檔案圖片、網站、介紹**等資訊。**我的資訊中的詳細資訊**不會顯示在這個公開介紹欄位，而是提供預設 Persona 在對話中使用的資訊。

想讓角色參考的設定，請填在**詳細資訊或 Persona**；想向讀者介紹自己，請填在**創作者 → 編輯個人檔案 → 介紹**。

## 5. 個人檔案頁面的其他功能

| 選單 | 可以做什麼 |
| --- | --- |
| 我的 Spark | 查看餘額與即將到期的 Spark、儲值，以及查看使用紀錄 |
| 內容管理 | 查看自己作品的狀態並編輯 |
| 封鎖管理 | 查看已封鎖的作品與創作者，或解除封鎖 |
| Persona 設定 | 新增、編輯與選擇對話使用的角色定位 |
| 我的活動 | 查看追蹤中的創作者與自己發表的留言 |
| 簽到 | 查看簽到狀態與獎勵 |

敏感內容相關設定請參考[成人驗證說明](/account/adult-verification.md)。顯示的選單與使用條件可能依使用環境或帳號狀態而有所不同。

## 6. 登出

點選**個人檔案 → 設定與支援 → 登出**。下次使用時，請以註冊時的社群帳號登入。

登出會結束目前裝置的登入狀態。若要刪除帳號，請參考另一項程序：[刪除帳號](/account/delete-account.md)。

## 變更未如預期時

| 狀況 | 請確認 |
| --- | --- |
| 無法點選「儲存變更」 | 確認是否修改了項目、必填欄位是否完整且沒有錯誤，以及新 ID 是否可使用 |
| ID 一直顯示檢查中，或出現錯誤 | 等待檢查完成；若失敗，請確認網路連線，再點選「檢查」重試 |
| 無法修改性別或出生日期 | 已完成身分驗證的帳號無法修改這些項目 |
| 我的資訊沒有變更圖片的按鈕 | 請到創作者分頁的「編輯個人檔案」變更 |
| 選擇照片後，個人檔案圖片沒有更新 | 確認上傳錯誤或權限提示，並確認上傳完成後已點選「儲存」 |
| 修改詳細資訊後，公開介紹沒有改變 | 公開介紹需在「創作者 → 編輯個人檔案 → 介紹」另外修改 |
| 改了名稱，對話卻仍使用其他名字 | 確認目前使用的 Persona。我的資訊變更會反映在預設 Persona |
| 儲存失敗或修改的內容消失 | 確認網路連線，重新開啟畫面查看已儲存的內容。若問題持續，請提供錯誤訊息與裝置或瀏覽器資訊聯絡客服 |
