# 登入與個人檔案設定

說明如何用註冊的帳號重新登入、修改個人資訊與個人檔案照片，以及登出。

## 登入

1. 點選下方選單的**個人檔案**。在網頁版，也可以點選首頁右上角的**登入**。
2. 點選註冊時使用的社群帳號按鈕（**使用 LINE 繼續**、**使用 Google 繼續**、**使用 X 繼續**、**使用 Apple 繼續**）並完成登入。
3. 在網頁版，登入完成後會前往首頁。請用**個人檔案**最上方的暱稱和 `@ID` 確認是不是自己的帳號。

:::warning[請用註冊時的社群帳號登入]
每個社群帳號都有各自的 MYMI 帳號。用其他社群帳號登入時，會出現**註冊**畫面。在這裡註冊會建立一個沒有聊天紀錄和 Spark 的新帳號，請返回並用最初註冊的社群帳號登入。
:::

## 找到要修改的項目

點選**個人檔案**最上方有個人檔案照片和暱稱的那一列，會開啟**編輯個人檔案**。這裡有**我的資訊**和**創作者**兩個分頁。

| 要修改的內容 | 前往的位置 |
| --- | --- |
| 角色稱呼你的名稱、性別、出生日期、詳細資訊 | **編輯個人檔案 → 我的資訊** |
| 暱稱、`@ID` | **編輯個人檔案 → 我的資訊** |
| 個人檔案照片、網站、公開介紹 | **編輯個人檔案 → 創作者 → 編輯個人檔案** |
| 每部作品不同的名字或身分 | **個人檔案 → Persona 設定** |
| 顯示語言 | **個人檔案**最下方的**語言設定** |

## 修改名稱、暱稱與 ID

1. 開啟**編輯個人檔案**的**我的資訊**分頁。
2. 修改想改的項目。
3. 點選上方的**儲存變更**。按下這個按鈕，修改的內容才會儲存。

| 項目 | 用途 |
| --- | --- |
| **名稱** | 角色會這樣稱呼你 |
| **性別**、**出生日期** | 角色會參考的你的資訊。完成手機號碼驗證後就無法修改 |
| **暱稱** | 其他使用者看到的名字，也是作品的創作者名稱 |
| **ID** | 你的 `@ID`，用在公開個人檔案的網址 |
| **詳細資訊** | 角色在聊天中會參考的你的資訊，最多 1,000 字 |

性別和出生日期請在手機號碼驗證前設定好。驗證後就無法再修改。

ID 規則和[註冊](/account/sign-up.md#id-規則)相同。輸入後會立即檢查是否重複，請在看到**可使用**後再儲存。修改 ID 後，公開個人檔案的網址也會改變。如果之前分享過個人檔案連結，請重新分享新的網址。

## 修改個人檔案照片與公開介紹

1. 在**編輯個人檔案**中點選**創作者**分頁。
2. 點選**編輯個人檔案**。
3. 點選個人檔案照片的位置，從裝置中選擇照片。等待上傳完成。
4. 需要的話，修改**網站**和**介紹**（最多 10,000 字）。
5. 點選**儲存**。

即使沒有製作作品，也可以編輯公開個人檔案。公開個人檔案會顯示暱稱、ID、個人檔案照片、網站和介紹。**我的資訊**中的詳細資訊只會用在聊天中。

:::tip[這和個人檔案的創作者按鈕不同]
**個人檔案**首頁中位於**我的 Spark** 下方的**創作者**按鈕，會開啟創作者申請與儀表板。個人檔案照片要在**編輯個人檔案**裡的**創作者**分頁修改。
:::

## 切換顯示語言

點選**個人檔案**最下方的**語言設定**，從**한국어**、**日本語**、**繁體中文**中選擇，再點選**確認**。

切換語言後，畫面上的文字會改變。手機號碼驗證、年齡確認的方式與付款方式，仍會維持註冊時的設定。

## 登出

點選**個人檔案 → 設定與支援 → 登出**。要再次使用時，請用註冊時的社群帳號登入。如果想刪除整個帳號，請參閱[刪除帳號](/account/delete-account.md)。

## 在個人檔案中找到選單

| 想做的事 | 開啟的選單 |
| --- | --- |
| 查看剩餘的 Spark 和到期日，或儲值 | **我的 Spark** |
| 查看創作者申請條件與進度 | **創作者** |
| 繼續修改製作中的作品 | **內容管理** |
| 重新查看封鎖的作品或創作者 | **封鎖管理** |
| 在每部作品用不同的名字與身分聊天 | **Persona 設定** |
| 查看追蹤的創作者或自己寫的留言 | **我的活動** |
| 每天免費領取 Spark | **簽到** |
| 邀請朋友，或輸入收到的推薦碼 | **邀請朋友** |
| 查看消息或詢問問題 | **Discord** |
| 也想看到被歸類為敏感內容的作品 | **設定與支援 → 顯示敏感內容**。請參閱[年齡確認與手機號碼驗證](/account/adult-verification.md) |
| 在 App 中詢問時想提供使用環境 | **設定與支援 → 版本資訊 → 複製客服資訊** |

## 遇到問題時

<details>
<summary>找不到 LINE 按鈕</summary>

在網頁版，只有畫面是日本語或繁體中文時才會顯示 LINE 按鈕。請點選登入按鈕下方的語言連結（언어 설정、Language Settings、言語設定），切換成**繁體中文**。App 沒有 LINE 按鈕，用 LINE 註冊的話請在網頁版登入。

</details>

<details>
<summary>登入後出現了註冊畫面</summary>

你用了和最初註冊時不同的社群帳號登入。請不要註冊，返回後用最初註冊的社群帳號登入。如果有多個 Google 帳號，請確認選的是註冊 MYMI 時用的那一個。

</details>

<details>
<summary>看不到先前的聊天紀錄和 Spark</summary>

可能是用其他社群帳號登入，建立了新帳號。請點選**個人檔案 → 設定與支援 → 登出**，再用最初註冊的社群帳號重新登入。

</details>

<details>
<summary>App 沒有 X 按鈕，或 Android App 沒有 Apple 按鈕</summary>

App 沒有 LINE 和 X 登入，Android App 也沒有 Apple 登入。請用 Chrome 或 Safari 開啟 [www.mymi.live/zh-TW](https://www.mymi.live/zh-TW)，用註冊時的按鈕登入。

</details>

<details>
<summary>儲存變更按不下去</summary>

沒有修改任何項目，或輸入內容有錯誤。請看欄位下方的提示修正。如果修改了 ID，請確認是否顯示**可使用**。

</details>

<details>
<summary>無法修改性別或出生日期</summary>

完成手機號碼驗證的帳號無法修改性別和出生日期。想在不同作品用不同設定聊天的話，請到 [Persona 設定](/account/persona.md)建立 Persona。每個 Persona 都可以分別設定性別和出生日期。

</details>

<details>
<summary>改了名稱，角色卻還用舊名字叫我</summary>

修改後的名稱會從新開始的聊天起使用。已經在聊天中的聊天室，請在右上角 ⋮ 選單的**聊天設定 → 我的資訊**中，用**載入**選擇預設 Persona 後點選**儲存**。

</details>

<details>
<summary>個人檔案照片沒有改變</summary>

選好照片後，要等上傳完成並點選**儲存**才會改變。App 詢問照片存取權限時，請允許。

</details>

如果還是無法解決，請從**個人檔案 → Discord** 前往 Discord 的詢問頻道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
