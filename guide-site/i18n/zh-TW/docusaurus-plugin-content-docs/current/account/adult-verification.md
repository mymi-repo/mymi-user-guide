# 年齡確認與身分驗證

MYMI 的**身分或手機號碼驗證**與**年齡確認**有不同用途。使用功能時若出現驗證提示，請依該畫面的說明完成程序。

| 類型 | 確認什麼？ | 何時會出現？ |
| --- | --- | --- |
| 身分或手機號碼驗證 | 本人資料，或是否能使用該手機號碼 | 使用簽到、邀請朋友等需要驗證的功能時 |
| 年齡確認 | 帳號是否符合成人內容的使用條件 | 關閉安全篩選或開啟顯示敏感內容時 |

韓國的身分驗證也會依已驗證的出生日期判斷成人資格。海外帳號請依提示分別完成**手機號碼驗證**與**年齡自行確認**。

## 1. 確認帳號適用的驗證方式

驗證方式依帳號適用的政策與既有驗證紀錄決定。請依目前帳號顯示的驗證畫面操作。

目前提供的基本流程如下。請依實際開啟的驗證畫面操作。

| 帳號適用的驗證政策 | 身分或手機號碼確認 | 年齡確認 |
| --- | --- | --- |
| 韓國服務 | 手機身分驗證 | 依身分驗證取得的出生日期判定 |
| 日本、台灣、英語服務 | 以支援的手機號碼接收簡訊驗證 | 自行確認已達畫面顯示的年齡 |

若畫面與預期不同，或出現帳號國家／地區相關錯誤，請參考[需要協助時](#需要協助時)。

## 2. 從哪裡開始驗證？

先[登入 MYMI](/account/login-profile.md)，再開啟想使用的功能。若需要驗證，畫面會顯示說明。

- **簽到、邀請朋友**：在個人檔案頁面開啟對應選單，依驗證提示操作。
- **安全篩選**：嘗試關閉篩選時，若需要年齡確認，就會出現提示。
- **顯示敏感內容**：在**個人檔案 → 設定與支援**開啟此項目時，可能需要年齡確認。

網站的安全篩選位於首頁。App 會依目前的介面配置，顯示在**首頁**或**個人檔案 → 設定與支援**。若個人檔案頁面有**安全篩選**項目，請使用該設定。

**關閉篩選（OFF）**與**開啟顯示敏感內容（ON）**的切換方向不同。請先確認項目名稱與目前狀態。

## 3. 進行韓國身分驗證

若帳號收到韓國身分驗證的提示，請依下列步驟操作。

1. 點選提示中的**立即驗證**或**驗證年齡**。
2. 在身分驗證畫面輸入要求的資料。
3. 使用**登記在本人名下的手機**完成驗證。
4. 返回 MYMI，確認驗證完成提示。
5. 回到原本想使用的功能，例如簽到或篩選設定。

| 使用環境 | 驗證畫面的開啟方式 |
| --- | --- |
| 電腦網頁 | 在彈出視窗中進行 |
| 行動版網頁 | 前往驗證頁面，完成後返回 MYMI |
| Android、iOS App | 在 App 內的驗證畫面進行 |

### 韓國政策的年齡標準

適用韓國政策的帳號，從**滿 19 歲當年的 1 月 1 日起**符合成人內容的年齡條件。例如，**2026 年適用於 2007 年或更早出生的人**，不必等到該年的生日。

MYMI 依**身分驗證確認的出生日期**判斷成人資格。驗證後的年齡符合標準時，即可關閉篩選。

## 4. 驗證海外手機號碼

若出現**手機號碼驗證**畫面，請輸入簡訊收到的驗證碼。此程序用來確認你能使用該號碼。

1. 選擇號碼所屬的國家／地區。目前可選擇**日本（+81）、台灣（+886）、美國（+1）**。
2. 輸入該國家／地區的本人手機號碼。選擇的國家／地區必須與號碼一致。
3. 點選**取得驗證碼**。
4. 確認畫面顯示的接收號碼，並輸入簡訊中的驗證碼。
5. 在畫面顯示的有效時間內點選**驗證**。
6. 確認完成提示後，返回原本使用的功能。

若未收到簡訊，可在畫面上的等待時間結束後**重新發送驗證碼**。若輸入錯誤的號碼，請選擇**更換號碼**。驗證碼過期或輸入次數達上限時，請依提示重新開始。

選擇號碼的國家／地區後，即可以該地區的號碼接收驗證簡訊。若號碼所屬地區未受支援，或畫面顯示驗證服務準備中，請確認錯誤訊息並聯絡客服。

## 5. 自行確認年齡

若**年齡確認**畫面顯示年齡勾選項目，請依下列步驟操作。日本、台灣與英語服務目前的自行確認標準為**年滿 18 歲**。

1. 閱讀畫面上的年齡標準與說明。
2. 僅在確實符合條件時，勾選**本人確認已年滿 18 歲。**
3. 點選**確認**。
4. 出現年齡確認完成提示後，返回原本的畫面。

這項確認可與手機號碼驗證分開進行。完成年齡確認後，簽到等其他功能仍可能要求手機號碼驗證。

若不符合條件，或暫時不想進行確認，請選擇**下次再說**。符合條件並完成年齡確認後，請接著依第 6 節調整篩選設定。

## 6. 驗證後確認篩選設定

完成驗證後，請返回首頁或個人檔案頁面，**自行調整篩選設定**。

1. 返回開始驗證的首頁或個人檔案頁面。
2. 再次確認設定。若要關閉安全篩選，設為 **OFF**；若要顯示敏感內容，將對應項目設為 **ON**。
3. 若持續出現驗證提示，請重新整理網頁或重新開啟 App。

若要使用成人功能，請完成帳號所需的年齡確認，並符合驗證後的年齡標準。

## 7. 已在其他帳號完成驗證時

若畫面顯示相同身分資料或手機號碼已綁定其他帳號，請先確認是否[以原本註冊的社群帳號登入](/account/login-profile.md)。

最近刪除帳號所使用的驗證資料，可能受到**刪除帳號後 30 天的重新使用限制**。若出現重複綁定或等待期間提示，請確認原帳號與錯誤內容後聯絡客服。

## 驗證遇到問題時

| 狀況 | 請確認 |
| --- | --- |
| 顯示需要登入 | 以註冊時的社群帳號登入，再次開啟該功能 |
| 電腦無法開啟身分驗證視窗 | 確認瀏覽器是否封鎖彈出視窗，並允許 MYMI 的驗證視窗 |
| 行動版網頁驗證後沒有返回 MYMI | 返回原頁面並重新整理。若原本使用其他 App 內的瀏覽器，請改用外部瀏覽器重試 |
| 收不到簡訊驗證碼 | 確認國家／地區、號碼、簡訊接收與垃圾訊息封鎖設定，等待時間結束後再重新發送 |
| 驗證碼錯誤或已過期 | 確認收到的代碼與有效時間。若已過期，請重新發送或從輸入號碼開始重試 |
| 請求過於頻繁或輸入次數達上限 | 不要持續重複送出，請依畫面上的等待時間或重新開始提示操作 |
| 顯示已綁定其他帳號 | 確認是否登入原本完成驗證的帳號；仍無法解決時，請聯絡客服 |
| 顯示資料曾用於最近刪除的帳號 | 確認刪除帳號後 30 天的重新使用限制提示 |
| 切換語言後，驗證方式沒有改變 | 變更顯示語言不會改變帳號的驗證政策 |
| 住在海外，卻看到韓國身分驗證 | 畫面依帳號適用的政策顯示；若無法完成，請聯絡客服 |
| 無法點選年齡確認按鈕 | 僅在符合年齡條件時勾選確認項目 |
| 驗證完成後，仍無法關閉篩選 | 確認年齡確認也已完成，再於原畫面操作篩選設定 |
| 出現不支援國家／地區、帳號地區錯誤或服務準備中提示 | 記錄錯誤訊息，稍後重試或聯絡客服 |

## 需要協助時

請使用**個人檔案 → Discord → 聯絡我們**，或[寄信聯絡客服](mailto:contact@mymi.live)。提供 MYMI ID、開始驗證的功能、錯誤訊息，以及使用網頁、Android 或 iOS，會有助於確認問題。

若因居住海外等原因無法完成畫面指定的驗證，也請先聯絡客服。**不要事先傳送身分證件副本或驗證碼**，請依客服提供的程序進行。
