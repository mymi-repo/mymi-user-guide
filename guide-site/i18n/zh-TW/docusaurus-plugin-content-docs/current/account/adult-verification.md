# 年齡確認與手機號碼驗證

MYMI 的**手機號碼驗證**與**年齡確認**需要分別完成。使用功能時若出現提示，請依該畫面的說明操作。

| 類型 | 確認什麼？ | 何時會出現？ |
| --- | --- | --- |
| 手機號碼驗證 | 能以自己的手機號碼接收簡訊 | 簽到、邀請朋友、建立作品時生成 AI 圖片、在 App 購買首次購買方案 |
| 年齡確認 | 已年滿 18 歲（自行確認） | 關閉安全篩選、開啟顯示敏感內容、在網站購買 Spark |

完成其中一項，不代表另一項也已完成。例如完成手機號碼驗證後，若要關閉安全篩選，仍需要年齡確認。

## 1. 從哪裡開始驗證？

先[登入 MYMI](/account/login-profile.md)，再開啟想使用的功能。若需要驗證，畫面會顯示說明。

- **簽到、邀請朋友**：在個人檔案頁面開啟對應選單，依手機號碼驗證的提示操作。
- **生成 AI 圖片**：建立作品時生成或重新生成圖片，會提示手機號碼驗證。只上傳自己的圖片則不需要驗證。
- **購買 Spark**：在網站購買任何方案都需要年齡確認。在 App 選擇標示**首次購買**的方案時，會提示手機號碼驗證。
- **安全篩選**：關閉篩選時，會提示年齡確認。
- **顯示敏感內容**：在**個人檔案 → 設定與支援**開啟此項目時，會提示年齡確認。

即使提示中顯示「身分驗證」，也是在手機號碼驗證畫面完成。

安全篩選是**首頁**的**推薦、排行榜、標籤、搜尋**分頁列最右側、沒有文字只有盾牌圖示的小開關，網站與 App 都在同一個位置。綠色代表開啟，成人作品不會顯示；灰色代表關閉。此設定會分別儲存在每台裝置上，因此在新的裝置或瀏覽器第一次開啟時，或登出後，會再次變成開啟。

**顯示敏感內容**（**個人檔案 → 設定與支援**）是另一個設定。開啟後，被歸類為敏感內容的作品也會顯示。此設定會儲存在帳號中，在任何裝置上都相同。如果已關閉安全篩選仍找不到想看的作品，請一併開啟此項目。

## 2. 進行手機號碼驗證

出現**手機號碼驗證**畫面時，請輸入簡訊收到的驗證碼。

1. 確認號碼所屬的國家／地區。畫面一開始會選取**台灣 (+886)**。若要使用其他國家／地區的號碼，請點選該國家／地區的按鈕。
2. 輸入自己的手機號碼。選擇的國家／地區必須與號碼一致。
3. 點選**取得驗證碼**。
4. 確認畫面顯示的接收號碼，並輸入簡訊中的驗證碼。
5. 在畫面顯示的時間內點選**驗證**。
6. 出現「手機號碼驗證完成。」後，返回原本使用的功能。

若未收到簡訊，請在等待時間結束後點選**重新發送驗證碼**。若輸入錯誤的號碼，請選擇**更換號碼**。驗證碼過期或輸入次數達上限時，請從輸入號碼開始重試。

## 3. 進行年齡確認

在**年齡確認**畫面，請自行確認已年滿 18 歲。

1. 閱讀畫面上的年齡標準與注意事項。
2. 僅在確實年滿 18 歲時，勾選**本人確認已年滿 18 歲。**
3. 點選**確認**。
4. 出現「年齡確認完成。」後，返回原本的畫面。

如有不實申告，可能會被限制使用服務。若不符合條件，或暫時不想確認，請選擇**下次再說**。

## 4. 驗證後確認篩選設定

完成年齡確認後，請返回首頁或個人檔案頁面，**自行調整篩選設定**。

1. 返回開始驗證的首頁或個人檔案頁面。
2. 再次確認設定。若要關閉安全篩選，設為 **OFF**；若要顯示敏感內容，將對應項目設為 **ON**。
3. 若持續出現驗證提示，請重新整理網頁或重新開啟 App。

## 5. 已在其他帳號完成驗證時

若畫面顯示手機號碼已綁定其他帳號，請先確認是否[以原本註冊的社群帳號登入](/account/login-profile.md)。

最近因刪除帳號等原因解除綁定的號碼，需在 **30 天後**才能重新綁定。如有急需或無法解決，請附上錯誤內容聯絡客服。

## 驗證遇到問題時

| 狀況 | 請確認 |
| --- | --- |
| 顯示需要登入 | 以註冊時的社群帳號登入，再次開啟該功能 |
| 收不到簡訊 | 確認選擇的國家／地區與號碼、簡訊接收與垃圾訊息封鎖設定。等待時間結束後再重新發送 |
| 顯示驗證碼不符 | 確認輸入的是最後收到的驗證碼 |
| 驗證碼已過期 | 重新發送，或從輸入號碼開始重試 |
| 請求過於頻繁，或輸入次數達上限 | 不要持續重複送出，稍待一段時間後從頭開始 |
| 顯示已有進行中的驗證 | 稍候片刻再重試 |
| 顯示號碼已綁定其他帳號 | 確認是否登入原本完成驗證的帳號；仍無法解決時，請聯絡客服 |
| 顯示需於 30 天後才能重新綁定 | 這是最近解除綁定的號碼。請在 30 天後重試，或聯絡客服 |
| 顯示目前不支援此國家／地區 | 確認點選的國家／地區按鈕與輸入的號碼是否一致；仍無法解決時，請聯絡客服 |
| 顯示驗證服務準備中 | 稍後再試 |
| 點選年齡確認的「確認」後沒有反應 | 確認已勾選**本人確認已年滿 18 歲。** |
| 已完成手機號碼驗證，卻無法關閉篩選 | 除了手機號碼驗證，還需要年齡確認 |
| 已完成年齡確認，簽到時仍要求驗證 | 除了年齡確認，還需要手機號碼驗證 |
| 以前完成過年齡確認，卻再次被要求確認 | 同意條款更新等情況下，需要再次確認 |
| 切換語言後驗證方式沒有改變，或出現與本頁不同的驗證畫面 | 驗證方式依註冊時的顯示語言決定，之後變更顯示語言也不會改變。若無法完成，請聯絡客服 |
| 出現其他錯誤 | 記錄錯誤訊息，稍後重試；若持續發生，請聯絡客服 |

## 需要協助時

請使用**個人檔案 → Discord → 聯絡我們**，或[寄信聯絡客服](mailto:contact@mymi.live)。提供 MYMI ID、開始驗證的功能、錯誤訊息，以及使用網頁、Android 或 iOS，會有助於確認問題。

**請勿事先傳送驗證碼或身分證件副本。** 需要的程序將由客服說明。
