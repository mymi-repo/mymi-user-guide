# 註冊

加入 MYMI 時，先**使用社群帳號登入，再填寫基本資料**。

如果已經註冊，請選擇當初使用的登入方式與社群帳號。從網頁版切換到 App 時，也使用同一個帳號登入。

## 1. 選擇社群帳號

1. 開啟 [MYMI 網站](https://www.mymi.live)或 App。
2. 從底部選單的**個人檔案**開啟登入畫面。使用服務時出現的登入提示也可以作為入口。
3. 選擇社群帳號，完成該服務的登入流程。
4. 首次使用的帳號會進入 MYMI 註冊表單。

登入按鈕會依網站語言與 App 平台而有所不同。

| 使用環境 | 登入方式 |
| --- | --- |
| 繁體中文、日文網頁版 | LINE、Google、X、Apple |
| 韓文網頁版 | Kakao、Google、Apple |
| 英文網頁版 | Google、X、Apple |
| Android App | Kakao、Google |
| iOS App | Apple、Kakao、Google |

請從畫面上顯示的按鈕中選擇。如果 App 沒有你原本使用的方式，可在對應語言的網頁版登入。

> **繼續使用原本的帳號**
>
> 已有帳號卻看到註冊表單時，請確認登入方式與社群帳號是否正確。例如，你有多個 Google 帳號時，應選擇當初註冊 MYMI 的那一個。

## 2. 填寫基本資料

請填寫以下四個欄位。若欄位已有預填內容，也請確認是否為你想使用的資料。

| 欄位 | 用途 | 填寫條件 |
| --- | --- | --- |
| 顯示名稱 | 作品角色對你的稱呼，會用於註冊後建立的預設人設 | 最多 20 個字元 |
| 性別設定 | 預設人設使用的性別 | 選擇女性、男性或其他 |
| 使用者 ID | 用來識別帳號，例如 `@moon_reader` | 3～20 個字元，須確認格式與是否重複 |
| 暱稱 | 顯示給其他使用者的名稱 | 最多 30 個字元 |

例如，顯示名稱可填`小晴`、使用者 ID 填 `moon_reader`、暱稱填`月光讀者`。在作品中，角色會稱呼你為「小晴」，其他使用者則會看到「月光讀者」這個暱稱。

下次使用時，請以註冊時的社群帳號登入。

註冊後，若某項功能需要身分或年齡驗證，請依該功能顯示的指示辦理。

### 使用者 ID 規則

- 可使用小寫英文字母、數字、連字號（`-`）及底線（`_`）。
- 長度為 **3～20 個字元**。
- 不能以連字號或底線開頭或結尾。
- 連字號與底線不能連續出現兩個以上，也不能混合後連續使用。
- 不能使用其他使用者已占用的 ID。

| 範例 | 格式檢查 |
| --- | --- |
| `moon_reader`、`reader-123` | 格式有效，仍須檢查是否已被使用 |
| `ab` | 少於 3 個字元 |
| `_reader`、`reader-` | 以底線或連字號開頭或結尾 |
| `moon__reader`、`moon-_reader` | 底線或連字號連續出現 |

輸入後會自動檢查是否重複。請確認出現**可使用**再繼續。若檢查失敗，可按欄位旁的**檢查**重試。

## 3. 閱讀同意項目

閱讀各項內容，再選擇是否同意。

| 項目 | 註冊時是否必須同意？ |
| --- | --- |
| 同意服務條款 | 必須 |
| 同意蒐集與使用個人資料 | 必須 |
| 服務準則 | 必須 |
| 同意接收行銷資訊 | 選擇性 |

**不同意接收行銷資訊，也可以註冊。** 選擇「全部同意」時，這個選擇性項目也會被勾選，請確認符合自己的意願。

## 4. 完成註冊

填妥顯示名稱、性別設定、使用者 ID 與暱稱，確認 ID 可使用，並勾選三個必要的同意項目後，即可按**完成註冊**。

MYMI 會依填寫的名稱與性別建立預設人設。你可以從首頁挑選作品開始聊天，也可以在[人設設定](/account/persona.md)中更詳細地描述自己在故事中的身分。

## 無法註冊時

| 情況 | 檢查方式 |
| --- | --- |
| 無法按完成註冊 | 確認四個欄位已填妥、ID 顯示「可使用」，且已勾選三個必要項目 |
| ID 顯示格式無效 | 檢查長度、開頭與結尾，以及連字號和底線是否連續 |
| ID 已被使用 | 改用其他 ID 並重新檢查 |
| 重複檢查失敗 | 確認網路連線，再按「檢查」 |
| 社群登入失敗或未返回 MYMI | 回到登入畫面重試；若從其他 App 內開啟 MYMI，請改用外部瀏覽器 |
| App 沒有原本使用的登入方式 | 改用網頁版；即使是 Android 裝置，網頁版仍可使用 Apple 登入 |
| 已註冊卻再次要求填寫基本資料 | 確認是否選用了原本的登入方式與社群帳號 |

連線環境的問題請參考[如何使用 MYMI](/getting-started/how-to-access.md)。若問題持續，聯絡客服時請附上錯誤訊息與使用環境。
