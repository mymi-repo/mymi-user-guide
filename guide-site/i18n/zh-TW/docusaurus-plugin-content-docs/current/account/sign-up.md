# 註冊

用 LINE、Google、X、Apple 其中一個帳號登入後，設定名稱、ID 與暱稱就完成註冊了。MYMI 提供給年滿 14 歲的使用者使用。

:::warning[註冊前，請確認畫面是繁體中文]
註冊時的顯示語言會決定帳號的國家，並影響手機號碼驗證、年齡確認的方式與付款方式。註冊後就無法更改。

如果畫面不是繁體中文，請依下列步驟切換後再註冊。

1. 點選下方選單最右邊（個人檔案）。
2. 點選登入按鈕下方的語言連結（언어 설정、Language Settings、言語設定）。
3. 選擇**繁體中文**，再點選確認按鈕（확인、Confirm、確認）。
:::

## 選擇登入按鈕

1. 開啟 [www.mymi.live/zh-TW](https://www.mymi.live/zh-TW) 或 MYMI App，點選下方選單的**個人檔案**。也可以從聊天時出現的登入視窗開始。
2. 點選要用來註冊的社群帳號按鈕。依使用環境，看到的按鈕如下表。
3. 在該服務完成登入後，會開啟 MYMI 的**註冊**畫面。

| 使用環境 | 登入按鈕 |
| --- | --- |
| 電腦・手機網頁版 | **使用 LINE 繼續**、**使用 Google 繼續**、**使用 X 繼續**、**使用 Apple 繼續** |
| Android App | **使用 Kakao 繼續**、**使用 Google 繼續** |
| iPhone App | **使用 Apple 繼續**、**使用 Kakao 繼續**、**使用 Google 繼續** |

:::tip[先決定要用哪個社群帳號註冊]
每個社群帳號都會建立各自的 MYMI 帳號。之後也必須用註冊時的社群帳號登入，聊天紀錄和 Spark 才會接續。如果也要使用 App，請用 Google（只用 iPhone 的話也可以用 Apple）註冊。LINE 和 X 只能在網頁版使用，Android App 也沒有 Apple 登入。
:::

## 設定名稱、ID 與暱稱

| 項目 | 用途 | 輸入 |
| --- | --- | --- |
| **顯示名稱** | 角色稱呼你的名字 | 最多 20 字 |
| **性別設定** | 角色會參考的你的性別 | 從**女性**、**男性**、**其他**中選一個 |
| **使用者 ID** | 像 `@moon_reader` 這樣用來辨識你的位址 | 3～20 字，需符合下方規則 |
| **暱稱** | 其他使用者看到的名字 | 最多 30 字 |

例如把顯示名稱設為 `小晴`、暱稱設為 `月光讀者`，角色會叫你「小晴」，其他使用者則會看到「月光讀者」。想在不同作品中用不同名字聊天，註冊後可以在 [Persona 設定](/account/persona.md)中新增。顯示名稱、ID 與暱稱在註冊後也能到[登入與個人檔案設定](/account/login-profile.md)中修改。

在 App 中，**顯示名稱**欄位可能已經預先填入社群帳號的名字。可以改成你希望在聊天中被稱呼的名字。

### ID 規則

- 只能使用英文小寫字母、數字、底線（`_`）和連字號（`-`）。大寫字母會變成小寫，其他字元無法輸入。
- 長度為 3～20 字。
- 不能以 `_` 或 `-` 開頭或結尾。
- `_` 和 `-` 不能連續使用。`__`、`--`、`_-` 都不行。

| 例子 | 結果 |
| --- | --- |
| `moon_reader`、`reader-123` | 可以使用 |
| `ab` | 少於 3 個字 |
| `_reader`、`reader-` | 以 `_` 或 `-` 開頭或結尾 |
| `moon__reader`、`moon-_reader` | `_` 和 `-` 連續使用 |

輸入 ID 後，欄位右側會立即顯示結果。看到**可使用**就能繼續下一步。顯示**不可使用**表示已經有人在用，請換一個 ID；顯示**格式無效**時，請再確認上方的規則。

## 同意條款

| 項目 | 是否必要 |
| --- | --- |
| **同意服務條款** | 必要 |
| **同意蒐集與使用個人資料** | 必要 |
| **服務準則** | 必要 |
| **同意接收行銷資訊** | 選填 |

- 點選各項目**左側的方框**即可勾選同意。點選項目名稱會開啟全文。
- 點選**全部同意**，連選填的行銷資訊也會一起勾選。不想收到的話，再點一次那個方框取消勾選。

## 完成註冊

在條件全部滿足前，畫面下方的按鈕會顯示為灰色箭頭。填好四個項目、ID 顯示**可使用**，並勾選三個必要項目後，按鈕就會變成**完成註冊**。點選後就完成註冊並前往首頁。

聊天需要 Spark。完成手機號碼驗證後，就能在**個人檔案 → 簽到**每天免費領取。方法請見[年齡確認與手機號碼驗證](/account/adult-verification.md)與[儲值 Spark](/payment/payment-methods.md#簽到)。

## 遇到問題時

<details>
<summary>完成註冊按鈕一直是灰色箭頭</summary>

還有沒完成的條件。

- 顯示名稱、性別設定、使用者 ID、暱稱都填好了嗎？
- 使用者 ID 欄位右側有顯示**可使用**嗎？
- 三個必要項目都勾選了嗎？要點選左側的方框，不是點項目名稱。

</details>

<details>
<summary>點選項目後開啟了條款頁面</summary>

點選項目名稱會開啟全文。讀完後請回到註冊畫面，點選名稱左側的方框勾選。

</details>

<details>
<summary>顯示「此 ID 已被使用。」</summary>

這個 ID 已經有人在用。請加上數字或 `_`，換一個 ID 試試。

</details>

<details>
<summary>顯示「檢查時發生錯誤，請再試一次。」</summary>

請確認網路連線，再點選使用者 ID 欄位右側的**檢查**重新確認。

</details>

<details>
<summary>顯示「重新加入受限」與「刪除帳號後 30 天內無法重新加入。」</summary>

用這個社群帳號建立的 MYMI 帳號刪除後還不到 30 天。30 天後就能用同一個社群帳號重新註冊，並以新帳號開始。現在也可以改用其他社群帳號註冊，但在刪除的帳號中驗證過的手機號碼，要等刪除後滿 30 天才能再次使用。

</details>

<details>
<summary>顯示「註冊期間發生問題。」或「登入期間發生問題。」</summary>

點選<strong>請再試一次！</strong>按鈕會回到首頁。請從頭重新登入。如果是在 LINE、Instagram 等 App 裡開啟，請改用 Chrome 或 Safari 開啟 [www.mymi.live/zh-TW](https://www.mymi.live/zh-TW) 再試一次。

</details>

<details>
<summary>明明註冊過了，卻出現註冊畫面</summary>

你用了和最初註冊時不同的社群帳號登入。在這裡註冊會建立新帳號，請返回並用最初註冊的社群帳號登入。如果有多個 Google 帳號，請確認選的是註冊 MYMI 時用的那一個。

</details>

<details>
<summary>用 LINE 或 X 註冊的帳號無法登入 App</summary>

App 沒有 LINE 和 X 登入，Android App 也沒有 Apple 登入。請在網頁版登入：在手機上也可以用 Chrome 或 Safari 開啟 [www.mymi.live/zh-TW](https://www.mymi.live/zh-TW)，點選和註冊時相同的按鈕。

</details>

如果還是無法解決，請附上畫面上出現的文字，從**個人檔案 → Discord** 前往 Discord 的詢問頻道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
