# Persona 設定

Persona 用來設定**你在作品中以什麼身分與角色對話**。你可以透過名稱、性別、出生日期及詳細資訊，提供角色在對話時參考的資訊。

例如，在同一部作品中，你可以分別扮演「初次來到小鎮的旅人」或「與主角相識已久的夥伴」。**創作者名稱及公開個人檔案使用的是預設個人檔案的暱稱**。

> **想更改正在聊天的身分：** 請在該聊天室依序選擇 **選單 → 我的資訊 → 載入 → 選擇 Persona → 儲存**。

## 1. 預設、主要與推薦 Persona 有什麼不同？

| 類型 | 意義 | 需要知道的事 |
| --- | --- | --- |
| 預設 Persona | 根據帳號資訊自動準備的 Persona | 從清單編輯時會開啟 **編輯個人檔案**。清單中沒有刪除選項 |
| 主要 Persona | 準備開始新聊天時，優先選用的一個 Persona | 卡片會顯示 **主要** 標記。預設 Persona 也可以設為主要 |
| 推薦 Persona | 創作者為該作品準備的使用者身分設定 | 在作品詳情的 Persona 選擇畫面中選取。部分作品沒有推薦設定 |
| 聊天室的 Persona | 建立聊天室時選擇並儲存在該聊天室的身分設定 | 若要更改，請在該聊天室編輯並儲存 |

**預設**代表與帳號資訊連動的 Persona；**主要**代表開始新聊天時優先選用的 Persona。同一張卡片可能同時顯示兩個標記。

不另外新增 Persona，也可以使用預設 Persona 開始聊天。想依作品或身分分開設定時，再新增即可。

## 2. 新增自己的 Persona

1. 登入後，開啟 **我的頁面 → Persona 設定**。
2. 選擇 **新增 Persona**。
3. 輸入名稱及需要的資訊。
4. 按下畫面上方的 **儲存**，確認 Persona 已加入清單。

| 欄位 | 是否必填 | 輸入方式 |
| --- | --- | --- |
| 名稱 | 必填 | 角色稱呼你的名字，最多 **20 字** |
| 出生日期 | 選填 | 如要填寫，請完整輸入年、月、日。目前輸入畫面只接受**換算為年滿 14 歲的有效日期** |
| 性別 | 選填 | 新增與編輯畫面提供 **女性 / 男性** 選項 |
| 詳細資訊 | 選填 | 以 **1,000 字以內**描述身分、性格、說話方式、職業或與登場角色的關係 |

只填名稱也能儲存。若要加入出生日期，請完整填寫年、月、日，並選擇換算為年滿 14 歲的有效日期。

Persona 的出生日期用於角色設定。若要使用成人內容，請依照[年齡確認與身分驗證](/account/adult-verification.md)完成帳號驗證。

## 3. 設定主要 Persona

1. 在 **我的頁面 → Persona 設定** 中，**點選想使用的卡片本身**。
2. 確認卡片上出現 **主要** 標記。
3. 重新開啟作品詳情，透過聊天按鈕旁的 Persona 選擇按鈕，確認目前選用的身分。

**新增或編輯後儲存，與設定為主要 Persona，是不同的操作。** 如果希望經常使用剛新增的 Persona，請在清單中點選該卡片。

更換主要 Persona 後，準備新聊天時會優先選用該身分。若要更改既有聊天室的身分，請在該聊天室編輯並儲存。

## 4. 開始聊天前，在作品中選擇 Persona

1. 開啟想聊天的作品詳情。
2. 點選底部 **聊天按鈕旁的小型個人檔案圖示**。
3. 從 **我的 Persona** 或 **推薦 Persona** 中選擇卡片。
4. 按下 **確認選擇**。
5. 選擇 **開始聊天** 或 **開始新聊天**，建立新的聊天室。

創作者為作品準備推薦身分時，可以從 **推薦 Persona** 分頁選擇。經常使用的身分可在「我的頁面」設為 **主要 Persona**。

### 使用選擇畫面的鉛筆按鈕編輯時

- 編輯並儲存 **我的 Persona**，會更新「我的頁面」清單中的同一個 Persona。若要在既有聊天室使用，請在該聊天室載入並儲存。
- 編輯 **推薦 Persona**，可調整這次選擇要使用的內容。若想在其他作品重複使用，請到「我的頁面」新增為自己的 Persona。
- 選好編輯後的身分，再按 **確認選擇 → 開始新聊天**，即可用該身分建立聊天室。

> 按下 **繼續先前聊天**，即可使用該聊天室已儲存的身分繼續對話。若要更改身分，請依照下列步驟操作。

## 5. 更改既有聊天室的 Persona

1. **開啟要更改的聊天室**。
2. 在聊天室上方的選單中，選擇 **我的資訊**。
3. 在 **編輯 Persona** 畫面確認該聊天室目前使用的名稱及詳細資訊。
4. 直接編輯，或按下 **載入**，從自己的 Persona 清單選擇一個。
5. 確認載入的資訊，如有只想在此聊天室使用的內容，可以再編輯。
6. 按下 **儲存**。

確認載入的內容，再按 **儲存**，即可套用到目前的聊天室。

在這裡儲存的內容會**套用到目前的聊天室**。若希望多個聊天室使用相同變更，請分別載入並儲存。

在目前聊天室更換 Persona 後，可以用新身分延續聊天紀錄。若想以新身分從頭開始故事，請在作品詳情選擇 Persona，再按下 **開始新聊天**。

## 6. 編輯或刪除清單中的 Persona

在 **我的頁面 → Persona 設定** 中，開啟卡片的 **更多選單（⋮）**。

- **編輯自行新增的 Persona：** 選擇 **編輯**，修改內容後按下 **儲存**。
- **編輯預設 Persona：** 選擇 **編輯** 會開啟 **編輯個人檔案**。名稱、性別、出生日期及詳細資訊與預設 Persona 的關係，請參閱 [登入與個人檔案設定](/account/login-profile.md)。
- **刪除自行新增的 Persona：** 選擇 **刪除** 後，會從自己的清單中移除。若刪除的是目前的主要 Persona，預設 Persona 會成為主要。
- **刪除預設 Persona：** 無法從清單中刪除。

若要更改既有聊天室的身分，請在該聊天室載入想使用的 Persona 並儲存。

## 7. 修改會套用到哪裡？

| 操作 | 套用範圍 |
| --- | --- |
| 在個人檔案中儲存名稱、性別、出生日期及詳細資訊 | 帳號資訊及預設 Persona |
| 在「我的頁面」編輯自行新增的 Persona | 自己的 Persona 清單中對應的項目 |
| 更換主要 Persona | 準備新聊天時優先選用的身分 |
| 在作品詳情選擇 Persona 並開始新聊天 | 新建立的聊天室 |
| 在聊天室中載入 Persona 並儲存 | 目前設定中的聊天室 |

## 8. 詳細資訊可以怎麼寫？

簡短、具體地描述**自己的身分及關係**，讓角色在對話時參考。先決定這次對話需要的背景，比一次列出所有設定更容易開始。

**範例 — 初次來到小鎮的旅人**

> 我叫小晴，是一位成年的地圖製作者，為了尋找一張古老地圖而來到這座小鎮。面對陌生人時會使用禮貌的語氣，並謹慎地提問。今天是第一次見到主角，想先請對方帶我認識小鎮。

這個範例包含背景、說話方式、關係及第一個目標。若想改變劇情方向，可以編輯該聊天室的詳細資訊。
