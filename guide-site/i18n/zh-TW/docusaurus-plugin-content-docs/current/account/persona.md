# Persona 設定

Persona 是**你在作品中使用的名字與身分**。同一部作品也可以用「失去記憶的倖存者」或「敏宇的老朋友」等不同身分聊天。Persona 只會用在聊天中。作品的創作者名稱和公開個人檔案顯示的是你的暱稱。

:::tip[想更換已經在聊天中的聊天室的身分時]
請在聊天室右上角 ⋮ 選單的**聊天設定 → 我的資訊**中更換。步驟請見[在聊天中的聊天室更換](#在聊天中的聊天室更換)。
:::

## 預設、主要、推薦是什麼意思？

| 種類 | 意思 |
| --- | --- |
| **預設** | 用註冊時設定的名稱和性別建立。修改**編輯個人檔案 → 我的資訊**時會一起改變，而且無法刪除 |
| **主要** | 開始新聊天時一開始就選好的 Persona。一開始預設 Persona 就是主要 Persona |
| **推薦 Persona** | 創作者為該作品準備的身分。在作品詳情中選擇 |

**個人檔案 → Persona 設定**的卡片上會標示**預設**、**主要**。一張卡片也可能同時有兩個標示。

## 建立 Persona

1. 開啟**個人檔案 → Persona 設定**。
2. 點選**新增 Persona**。
3. 填好下列項目後，點選上方的**儲存**。

| 項目 | 填寫方式 |
| --- | --- |
| **名稱** | 角色稱呼你的名字。必填，最多 20 字 |
| **出生日期** | 要填的話，請填完年、月、日。只能儲存年滿 14 歲的日期 |
| **性別** | 從**女性**、**男性**中選擇 |
| **詳細資訊** | 你的身分、個性、說話方式、與角色的關係，最多 1,000 字 |

只填名稱也可以儲存。如果主要會使用新建立的 Persona，請[設為主要 Persona](#設定主要-persona)。

### 詳細資訊範例

> 我叫小晴，25 歲。在地下都市的檢疫站醒來，只記得自己在地面上做過送貨的工作。對陌生人說話會用敬語，有疑問就會立刻問。今天第一次見到敏宇。

簡短寫下你的身分、說話方式、與角色的關係，以及現在想做的事，角色會比較容易理解。

## 設定主要 Persona

在**個人檔案 → Persona 設定**中，點選要使用的 Persona 卡片。卡片上出現**主要**標示後，下次開始新聊天時就會選好這個 Persona。

## 開始聊天時選擇

1. 點選作品詳情畫面下方**開始聊天**右側的小型個人檔案圖示。
2. 在**我的 Persona** 或**推薦 Persona** 分頁中選一個，再點選**確認選擇**。
3. 點選**開始聊天**。如果這部作品已經聊過，請點選**開始新聊天**。

在選擇視窗中，也可以用卡片上的鉛筆按鈕修改內容。

- 修改並儲存**我的 Persona** 後，你清單中的那個 Persona 也會改變。
- 修改**推薦 Persona** 的內容只會用在這次聊天。想繼續使用的話，請另外建立成自己的 Persona。

點選**繼續先前聊天**時，會沿用該聊天室中使用的 Persona。

## 在聊天中的聊天室更換

在清單中修改 Persona 後，會從新開始的聊天起生效。已經在聊天中的聊天室，請在該聊天室中更換。

1. 點選聊天室右上角的 ⋮ 按鈕。
2. 點選**聊天設定**中的**我的資訊**。
3. 在**編輯 Persona** 視窗中直接修改名稱和詳細資訊，或用**載入**選擇一個自己的 Persona。
4. 點選**儲存**。從下一則回覆開始，就會用更換後的 Persona 聊天。

聊天紀錄會照原樣延續。想用新身分從頭開始的話，請在作品詳情選好 Persona 後點選**開始新聊天**。

## 修改與刪除

在**個人檔案 → Persona 設定**中，點選卡片右側的 ⋮ 按鈕。

- **編輯**：修改內容後點選**儲存**。預設 Persona 的**編輯**會開啟**編輯個人檔案**畫面。
- **刪除**：只能刪除自己新增的 Persona。

:::danger[刪除不會再次確認]
點選**刪除**會立刻刪除，不會出現確認視窗，而且無法復原。刪除主要 Persona 後，預設 Persona 會成為主要 Persona。用那個 Persona 聊天的聊天室仍然可以繼續使用。
:::

## 要在哪裡更換？

| 想更換的內容 | 更換的位置 |
| --- | --- |
| 之後開始的聊天要用的名字與身分 | 在 **Persona 設定**中修改，或設為主要 |
| 目前聊天中的聊天室的名字與身分 | 聊天室 ⋮ 選單的**聊天設定 → 我的資訊** |
| 只用在這次要開始的聊天的身分 | 開始聊天前，用個人檔案圖示選擇 |
| 註冊時設定的名稱和性別（預設 Persona） | **編輯個人檔案 → 我的資訊** |

## 遇到問題時

<details>
<summary>改了名稱，角色卻還用舊名字叫我</summary>

已經在聊天中的聊天室，必須在該聊天室中更換。請在聊天室 ⋮ 選單的**聊天設定 → 我的資訊**中，用**載入**選擇修改後的 Persona，再點選**儲存**。

</details>

<details>
<summary>新建立的 Persona 沒有用在聊天中</summary>

新建立的 Persona 不是主要 Persona。請在清單中點選那張卡片設為主要，或在開始聊天時用個人檔案圖示選擇。

</details>

<details>
<summary>填了出生日期後無法儲存</summary>

請確認年、月、日都已填寫，而且是實際存在的日期。顯示「需滿14歲才能儲存。」時，請改成年滿 14 歲的日期。出生日期也可以留空直接儲存。

</details>

<details>
<summary>預設 Persona 沒有刪除選項</summary>

預設 Persona 無法刪除。點選**編輯**會開啟**編輯個人檔案**，可以在那裡修改名稱和詳細資訊。

</details>

<details>
<summary>看不到推薦 Persona 分頁</summary>

這是創作者沒有準備推薦 Persona 的作品。請從**我的 Persona** 中選擇。

</details>

<details>
<summary>不小心刪除了 Persona</summary>

刪除的 Persona 無法復原。請用相同內容重新建立。用那個 Persona 聊天的聊天室都還在。

</details>

如果還是無法解決，請從**個人檔案 → Discord** 前往 Discord 的詢問頻道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。
