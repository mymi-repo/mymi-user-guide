# Persona 設定

Persona 用來設定**你在作品中以什麼身分與角色對話**。你可以透過名稱、性別、出生日期及詳細資訊，提供角色在對話時參考的資訊。

例如，在同一部作品中，你可以分別扮演「初次來到小鎮的旅人」或「與主角相識已久的夥伴」。這與建立作品中的登場角色是不同的設定；**創作者名稱及公開個人檔案使用的是預設個人檔案的暱稱**。

> **想更改正在聊天的身分：** 請在該聊天室依序選擇 **選單 → 我的資訊 → 載入 → 選擇 Persona → 儲存**。只在「我的頁面」更換主要 Persona，不會套用到既有聊天室。

## 1. 預設、主要與推薦 Persona 有什麼不同？

| 類型 | 意義 | 需要知道的事 |
| --- | --- | --- |
| 預設 Persona | 根據帳號資訊自動準備的 Persona | 從清單編輯時會開啟 **編輯個人檔案**。清單中沒有刪除選項 |
| 主要 Persona | 準備開始新聊天時，優先選用的一個 Persona | 卡片會顯示 **主要** 標記。預設 Persona 也可以設為主要 |
| 推薦 Persona | 創作者為該作品準備的使用者身分設定 | 在作品詳情的 Persona 選擇畫面中選取。部分作品沒有推薦設定 |
| 聊天室的 Persona | 建立聊天室時選擇並儲存在該聊天室的身分設定 | 在聊天室內個別編輯，不會與「我的頁面」的清單自動同步 |

**「預設」與「主要」的意思不同。** 預設代表與帳號資訊連動的 Persona；主要代表目前優先用於新聊天的 Persona。同一張卡片可能同時顯示兩個標記。

不另外新增 Persona，也可以使用預設 Persona 開始聊天。想依作品或身分分開設定時，再新增即可。

## 2. 新增自己的 Persona

1. 登入後，開啟 **我的頁面 → Persona 設定**。
2. 選擇 **新增 Persona**。
3. 輸入名稱及需要的資訊。
4. 按下畫面上方的 **儲存**，確認 Persona 已加入清單。

| 欄位 | 是否必填 | 輸入方式 |
| --- | --- | --- |
| 名稱 | 必填 | 角色稱呼你的名字，最多 **20 字** |
| 出生日期 | 選填 | 如要填寫，請完整輸入年、月、日。目前輸入畫面只接受**換算為年滿 14 歲的有效日期** |
| 性別 | 選填 | 新增與編輯畫面提供 **女性 / 男性** 選項 |
| 詳細資訊 | 選填 | 以 **1,000 字以內**描述身分、性格、說話方式、職業或與登場角色的關係 |

只填名稱也能儲存。出生日期不可使用未來或不存在的日期；若只填年、月、日的一部分，出生日期不會儲存。

Persona 的出生日期屬於角色設定，修改後不會改變帳號的年齡確認狀態。成人內容的使用條件請參閱 [年齡確認與身分驗證](/account/adult-verification.md)。

## 3. 設定主要 Persona

1. 在 **我的頁面 → Persona 設定** 中，**點選想使用的卡片本身**。
2. 確認卡片上出現 **主要** 標記。
3. 重新開啟作品詳情，透過聊天按鈕旁的 Persona 選擇按鈕，確認目前選用的身分。

**新增或編輯後儲存，與設定為主要 Persona，是不同的操作。** 如果希望經常使用剛新增的 Persona，請在清單中點選該卡片。

更換主要 Persona 會影響準備新聊天時的預先選擇，不會更換已開啟的作品詳情中自行選定的身分，也不會修改既有聊天室的設定。

## 4. 開始聊天前，在作品中選擇 Persona

1. 開啟想聊天的作品詳情。
2. 點選底部 **聊天按鈕旁的小型個人檔案圖示**。
3. 從 **我的 Persona** 或 **推薦 Persona** 中選擇卡片。
4. 按下 **確認選擇**。
5. 選擇 **開始聊天** 或 **開始新聊天**，建立新的聊天室。

只有創作者為作品提供推薦身分時，才會顯示 **推薦 Persona** 分頁。選擇推薦 Persona，不會改變「我的頁面」中的主要 Persona。

### 使用選擇畫面的鉛筆按鈕編輯時

- 編輯並儲存 **我的 Persona**，也會更新「我的頁面」清單中的同一個 Persona，但不會自動套用到既有聊天室。
- 編輯 **推薦 Persona**，是調整該選擇畫面中使用的內容。創作者的原始推薦設定不會改變，也不會自動加入「我的 Persona」。
- 編輯後仍需完成 **確認選擇 → 開始新聊天**，才會以選定的身分建立聊天室。若想在其他作品重複使用推薦身分，請到「我的頁面」另外新增為自己的 Persona。

> **繼續先前聊天** 會開啟既有聊天室。即使在作品詳情選了不同 Persona，該聊天室仍保留原本的設定。若要更改既有聊天室的身分，請依照下列步驟操作。

## 5. 更改既有聊天室的 Persona

1. **開啟要更改的聊天室**。
2. 在聊天室上方的選單中，選擇 **我的資訊**。
3. 在 **編輯 Persona** 畫面確認該聊天室目前使用的名稱及詳細資訊。
4. 直接編輯，或按下 **載入**，從自己的 Persona 清單選擇一個。
5. 確認載入的資訊，如有只想在此聊天室使用的內容，可以再編輯。
6. 按下 **儲存**。

**「Persona 已載入」表示資訊已帶入輸入欄位。** 最後按下儲存，才會套用到聊天室。

在這裡儲存的內容**只套用到目前的聊天室**，不會同時修改「我的頁面」中的原始 Persona 或其他聊天室的設定。若希望多個聊天室使用相同變更，請分別載入並儲存。

更換 Persona 不會重設聊天紀錄。若想以新身分從頭開始故事，請在作品詳情選擇 Persona，再按下 **開始新聊天**。

## 6. 編輯或刪除清單中的 Persona

在 **我的頁面 → Persona 設定** 中，開啟卡片的 **更多選單（⋮）**。

- **編輯自行新增的 Persona：** 選擇 **編輯**，修改內容後按下 **儲存**。
- **編輯預設 Persona：** 選擇 **編輯** 會開啟 **編輯個人檔案**。名稱、性別、出生日期及詳細資訊與預設 Persona 的關係，請參閱 [登入與個人檔案設定](/account/login-profile.md)。
- **刪除自行新增的 Persona：** 選擇 **刪除** 後，會從自己的清單中移除。若刪除的是目前的主要 Persona，預設 Persona 會成為主要。
- **刪除預設 Persona：** 無法從清單中刪除。

在清單中編輯或刪除 Persona，不會更動已儲存在聊天室中的 Persona 或聊天紀錄。若要更改既有聊天室，請進入該聊天室編輯其 Persona。

## 7. 修改會套用到哪裡？

| 操作 | 套用範圍 | 是否自動套用到既有聊天室？ |
| --- | --- | --- |
| 在個人檔案中儲存名稱、性別、出生日期及詳細資訊 | 帳號資訊及預設 Persona | 否 |
| 在「我的頁面」編輯自行新增的 Persona | 自己的 Persona 清單中對應的項目 | 否 |
| 更換主要 Persona | 準備新聊天時的預先選擇 | 否 |
| 在作品詳情選擇 Persona 並開始新聊天 | 新建立的聊天室 | 不會套用到既有聊天室 |
| 在聊天室中載入 Persona 並儲存 | 目前設定中的聊天室 | 直接套用到該聊天室 |

## 8. 詳細資訊可以怎麼寫？

簡短、具體地描述**自己的身分及關係**，讓角色在對話時參考。先決定這次對話需要的背景，比一次列出所有設定更容易開始。

**範例 — 初次來到小鎮的旅人**

> 我叫小晴，是一位成年的地圖製作者，為了尋找一張古老地圖而來到這座小鎮。面對陌生人時會使用禮貌的語氣，並謹慎地提問。今天是第一次見到主角，想先請對方帶我認識小鎮。

這個範例包含背景、說話方式、關係及第一個目標。想要的劇情方向改變時，可以編輯該聊天室的詳細資訊。Persona 是 AI 參考的資訊，無法保證每一次回應或劇情發展都完全符合設定。

## 常見問題

| 情況 | 請確認 |
| --- | --- |
| 更換主要 Persona 後，既有聊天室仍使用舊名字 | 是否在該聊天室完成 **我的資訊 → 載入 → 選擇 → 儲存** |
| 已載入 Persona，卻沒有套用 | 帶入輸入欄位後，是否按下 **儲存** |
| 在作品詳情更換了 Persona，聊天卻沒有改變 | 是否選了 **繼續先前聊天**。想用新身分從頭開始，請選 **開始新聊天** |
| 沒有推薦 Persona 分頁 | 創作者可能未提供推薦身分，請從「我的 Persona」選擇 |
| 無法刪除預設 Persona | 預設 Persona 無法從清單刪除，可以新增其他 Persona 並設為主要 |
| 無法儲存出生日期 | 請檢查年、月、日是否完整、日期是否存在、是否為未來日期，以及是否符合年滿 14 歲的條件 |
| 修改 Persona 名稱後，創作者名稱沒有改變 | 創作者名稱使用預設個人檔案的 **暱稱**，請在 [登入與個人檔案設定](/account/login-profile.md) 中修改 |
