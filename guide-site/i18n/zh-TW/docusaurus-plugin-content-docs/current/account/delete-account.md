# 刪除帳號

刪除帳號是**結束使用 MYMI 帳號的程序**，與登出或移除 App 不同。刪除後，你將無法繼續使用原帳號的對話、作品管理與剩餘餘額；重新註冊也不會將舊帳號的資料帶到新帳號。

> **按下最後的確認按鈕前，請先確認。** 畫面雖然使用 **停用帳號** 這個名稱，但這不是暫時停用。服務未提供取消已完成的刪除或復原帳號的功能。若只是想暫停使用，可以選擇[登出](/account/login-profile.md)。

## 1. 刪除帳號前，先確認這些項目

| 確認項目 | 請先完成 |
| --- | --- |
| 目前登入的帳號 | 確認「我的頁面」中的暱稱、MYMI ID 及註冊時使用的社群帳號，避免登入到另一個帳號 |
| Spark 等剩餘餘額 | 確認餘額與使用紀錄。刪除帳號不會將餘額移轉到新帳號，也不會自動退款 |
| 取消付款與退款需求 | 確認購買管道、收據及訂單編號，如有待處理的交易，請在刪除帳號前聯絡客服 |
| 自己製作的作品與需要的內容 | 確認是否還有需要管理的作品，並事先保留想留下的本人創作內容 |
| 創作者結算與處理中的客服案件 | 如有結算、付款或爭議尚待確認，請先取得相關處理指引 |
| 想刪除的留言與公開貼文 | 刪除帳號不代表所有公開貼文都會立即移除。請事先確認，必要時聯絡客服 |

如果是登入錯誤的帳號，或只是想更改個人檔案，請先參閱[登入與個人檔案設定](/account/login-profile.md)。

## 2. 在網頁版或 App 刪除帳號

網頁版及 Android、iOS App 的操作入口相同。

1. 登入你想刪除的 MYMI 帳號。
2. 開啟 **我的頁面**。
3. 點選上方顯示**個人檔案圖片、暱稱與 MYMI ID 的區域**，進入 **編輯個人檔案**。
4. 選擇 **我的資訊** 分頁，而非 **創作者**。
5. 向下捲動，按下**詳細資訊輸入欄位下方的「停用帳號」**。
6. 閱讀 **確認停用帳號** 視窗，確認這是你要刪除的帳號。
7. 若要繼續，按下表列的最後確認按鈕。
8. 等待處理完成。成功後會登出並回到首頁。

| 使用環境 | 確認視窗的最後按鈕 | 送出前不想繼續 |
| --- | --- | --- |
| 電腦或手機網頁版 | **刪除** | **取消** |
| Android 或 iOS App | **停用帳號** | **取消** |

**只開啟確認視窗，不會刪除帳號。** 按下最後按鈕前仍可取消；送出最後的請求後，關閉畫面並不能取消刪除。

## 3. 刪除帳號後會如何處理？

| 項目 | 刪除後的處理 |
| --- | --- |
| MYMI 帳號 | 原帳號停止使用。即使用同一個社群帳號重新註冊，也會從新帳號開始 |
| 對話、Persona 與個人使用資料 | 無法透過原帳號存取或繼續使用，也不會移轉到重新註冊的帳號 |
| 自己製作的作品 | 會列入刪除處理，無法再透過原帳號管理。相關資料的整理可能會陸續反映 |
| 剩餘餘額 | 無法繼續使用已刪除帳號的 Spark 等餘額，也不會自動移轉到新帳號。退款需另行確認程序 |
| 身分與電話號碼驗證 | 新帳號不會繼承原帳號的驗證狀態，驗證資料的重複使用限制也會適用 |
| 留言與公開貼文 | 刪除帳號不代表每篇貼文都會立即移除。若有仍保留的貼文需要處理或刪除，請聯絡客服 |

帳號刪除完成，與所有相關紀錄立即清除，是不同的事。為付款、退款、爭議處理或防止不正使用等目的所需的紀錄，可能依規定的標準保留。資料保存、刪除及個人資料刪除請求方式，請參閱[隱私權政策](https://mymi.live/zh-TW/legal/privacy-policy)。

這是**刪除 MYMI 帳號**的程序，不會刪除你用來登入的 Google、Apple 等外部社群服務帳號。

## 4. 重新註冊與驗證資料重複使用的 30 天限制

| 類型 | 目前適用的限制 |
| --- | --- |
| 使用相同社群帳號重新註冊 | 刪除後 **30 天內**受限制。例如，無法立即用原本註冊的同一個 Google 帳號重新註冊 |
| 曾連結至已刪除帳號的身分驗證資料或電話號碼 | 刪除後 **30 天內**，無法在其他帳號重複使用 |

重新註冊與驗證資料重複使用會分別檢查。即使選擇不同的登入方式，也不代表能立即移轉最近刪除帳號的身分驗證資料或電話號碼。

**這 30 天不是可以復原帳號的寬限期。** 限制結束後重新註冊，也不會自動復原以前的對話、作品、餘額或驗證狀態。

若限制期間已過，卻仍收到限制訊息，請提供刪除時間、登入方式及錯誤訊息，聯絡客服。驗證程序可參閱[年齡確認與身分驗證](/account/adult-verification.md)。

## 5. 還有付款或退款需要處理時

**刪除帳號不會代替取消付款或申請退款。** 剩餘餘額也不會自動以現金退還。

- **在網頁版購買：** 確認購買紀錄、收據及訂單編號後，聯絡 MYMI。
- **在 App 內購買：** 從收據確認 App Store、Google Play 等實際購買管道，並依該管道的退款程序辦理。不確定購買管道時，請聯絡 MYMI。
- **退款或創作者結算仍在進行：** 請在刪除帳號前聯絡客服，方便確認帳號與交易。
- **已經刪除帳號：** 仍可透過電子郵件詢問付款或帳號相關問題。請準備原 MYMI ID、登入方式，以及相關交易的訂單編號與付款日期。

退款資格及處理方式會依購買條件、使用情況與付款管道確認。請參閱[服務條款](https://mymi.live/zh-TW/legal/terms-of-service)及購買當時的說明。

## 6. 無法順利刪除帳號時

| 情況 | 請確認 |
| --- | --- |
| 找不到刪除帳號按鈕 | 查看 **編輯個人檔案 → 我的資訊** 分頁最下方；創作者個人檔案編輯畫面不會顯示 |
| 按下按鈕後，只開啟確認視窗 | 尚未送出最後的請求。確定要繼續時，才按網頁版的 **刪除** 或 App 的 **停用帳號** |
| 處理中的畫面持續很久 | 稍候並確認連線狀態。若畫面沒有回應，重新開啟頁面或 App；帳號狀態不明時，請聯絡客服 |
| 發生錯誤，不知道是否已刪除成功 | 記錄錯誤訊息與發生時間。不要只依錯誤訊息判定結果，請確認是否已登出，再聯絡客服確認帳號狀態 |
| 刪除後再次登入，出現重新註冊限制 | 相同社群帳號適用刪除後 30 天的重新註冊限制 |
| 無法在其他帳號驗證電話號碼或身分資料 | 若資料曾用於最近刪除的帳號，請確認 30 天的重複使用限制 |
| 移除 App 後，帳號仍然存在 | 移除 App 不等於刪除帳號，請在網頁版或 App 依上述步驟辦理 |
| 想回到已刪除的帳號 | 服務畫面未提供取消刪除或復原功能；重新註冊也不會帶回原本的資料 |

## 需要協助時

刪除帳號前，可使用 **我的頁面 → Discord → 客服**，或寄信至 [contact@mymi.live](mailto:contact@mymi.live)。刪除後仍可透過電子郵件聯絡客服。

請提供 **MYMI ID、註冊時使用的登入方式、嘗試刪除的時間、使用網頁版或 Android／iOS App，以及錯誤訊息**。若與付款有關，也請準備該交易的訂單編號及付款日期。

如需另外申請查閱或刪除個人資料，請依[隱私權政策中的聯絡說明](https://mymi.live/zh-TW/legal/privacy-policy)辦理。
