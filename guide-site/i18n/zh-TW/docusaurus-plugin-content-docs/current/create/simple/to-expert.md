# 移到專家模式

沒有把用簡易模式建立的作品改成專家模式的功能。兩種模式的內容也不會自動轉移。如果想在專家模式自己寫寫看提示詞，請建立**新作品**，再把設定抄過去。

## 移動之前要知道的事

- 新作品是**另一部作品**。原本作品的對話、按讚、留言，都不會轉移到新作品。
- 建立新作品之後，**原本的作品會保留**。如果不想再讓人看到，請從**個人檔案 → 內容管理 → 編輯**開啟，把**設定 → 公開設定**改成**不公開**，再按下一步按鈕儲存。
- 移動的過程中需要原本作品的文字。先把世界觀、角色描述、秘密、情境說明複製到記事本之類的地方，或是在另一台裝置上開著原本的作品，邊看邊抄會比較方便。

## 移動的順序

1. 先把原本作品的文字複製起來。
2. 點選下方選單的**建立**。如果編輯畫面開著從內容管理開啟的作品，請點選 <strong>↺</strong> 清空編輯畫面。內容管理中的原本作品會保留。
3. 在**基本資訊**分頁最上方的**創作模式**，點選**專家模式**。如果是第一次，請在視窗中點選**切換到專家模式**。
4. 對照下面的表格抄寫。
5. 點選**完成製作**。

## 各項目要抄到哪裡

| 在簡易模式寫的地方 | 在專家模式要寫的地方 | 抄的時候要做什麼 |
| --- | --- | --- |
| 基本資訊 → 作品標題 · 一句話簡介 | 基本資訊 → 作品標題 · 一句話簡介 | 原樣抄過去 |
| 基本資訊 → 世界觀 | 提示詞 → 作品資訊（基本型）或本文（自行撰寫） | 抄寫時代、地點、規則 |
| 基本資訊 → 角色 | 提示詞 → 作品資訊的角色 | 在名稱那一行下面，寫下定位、個性、說話方式、關係 |
| 基本資訊 → 秘密 | 提示詞 → 作品資訊的隱藏設定 | 也要一併寫下揭露的條件。不要抄到詳細說明 |
| 素材 → 角色連結 | 素材的角色資料夾 + 提示詞中角色代碼的含義 | 為每個角色建立資料夾，並讓資料夾代碼和名稱對應 |
| 素材 → 情境說明 | 素材的圖片代碼 + 提示詞中情境代碼、其他代碼的含義 | 相同的情境，所有角色都用相同的代碼 |
| 素材 → 個人檔案圖片（★） | 基本資訊 → 封面 | 封面是 1～10 張。可以從素材帶入 |
| 開場的 `img:[名稱]` | 開場的 `![]({{URL}}/A/1.webp)` | 用**插入素材圖片**重新放入 |
| 設定 → 類型 · 標籤 | 基本資訊 → 類型 · 標籤 | 專家模式在基本資訊分頁 |
| 設定 → 其餘卡片 | 其他設定 | 卡片和選項都相同。重新選擇 |
| 元件 → 使用描述 | 提示詞 → 元件輸出規則（基本型）或本文（自行撰寫） | 抄寫何時、用什麼值來呼叫 |
| 選填 → 詳細說明（HTML） | 基本資訊 → 詳細說明 | 詳細說明是必填。也可以使用 HTML |
| 選填 → 創作者備註 | 基本資訊 → 創作者指南 | 原樣抄過去 |
| 選填 → 推薦人設 | 其他設定 → 推薦人設 | 原樣抄過去 |
| 設定集 | 設定集 | 原樣抄過去名稱、關鍵字、內容 |

## 容易漏掉的東西

不要只抄世界觀和角色描述就結束。下面這些也要一併處理。

1. **圖片的情境說明** → 素材的代碼與提示詞中代碼的含義。在簡易模式，是 MYMI 彙整情境說明傳給 AI，但在專家模式，必須自己在提示詞中寫下何時放圖片。
2. **元件的使用描述** → 提示詞的元件輸出規則。
3. **開場的 `img:[名稱]`** → 用新的素材代碼放入的圖片那一行。專家模式不會讀 `img:[…]`。
4. **詳細說明（HTML）與創作者備註** → 詳細說明、創作者指南。
5. **以前放入的對話範例** → 提示詞。現在的簡易模式畫面看不到，但以前放過對話範例的作品，那些範例仍然會傳給 AI。它們不會轉移到新作品，所以需要的說話方式或範例，請自己寫進提示詞。

### 範例：移動一張圖片

假設在簡易模式有一張連結到角色**姜民宇**、情境說明寫「姜民宇笑得很開朗。」的圖片（`img:[AB3K9X]`），在專家模式要這樣移。

1. 在**提示詞**的作品資訊中，寫下民宇的定位、個性、說話方式。
2. 在**素材**建立角色資料夾 `A`，並以代碼 `1` 放入那張圖片。
3. 如果是基本型，在**圖片輸出規則**寫下角色代碼 `A` = `姜民宇`、情境代碼 `1` = `笑`。
4. 如果是自行撰寫，請在本文中寫下圖片的含義，以及何時、以什麼形式放入。
5. 刪除開場裡用的 `img:[AB3K9X]`，再用**插入素材圖片**放入 `A/1`。

專家模式的圖片架構，在[準備圖片](/create/images)和[在對話中顯示圖片](/create/images-in-chat)有詳細說明。

## 遇到問題時

<details>
<summary>開啟簡易模式的作品後，專家模式按鈕按不下去</summary>

從內容管理開啟的作品，會鎖定在建立時的模式。點選 <strong>↺</strong> 清空編輯畫面，鎖定就會解除，可以重新選擇模式。內容管理中的原本作品不會被刪除。（[開始之前](/create/before-you-start#從內容管理開啟的作品模式會被鎖定)）

</details>

<details>
<summary>把簡易模式的開場貼到專家模式，圖片卻沒有顯示</summary>

專家模式不會讀 `img:[…]`。開場預覽在那個位置也會顯示「無法載入圖片」。請刪掉那一行，再用第一則訊息欄位的**插入素材圖片**重新放入。

</details>

<details>
<summary>移過去的作品，聊天中沒有顯示圖片</summary>

在簡易模式，是 MYMI 彙整情境說明傳給 AI，但在專家模式，必須在提示詞中寫下何時放圖片。如果是基本型，請填好**圖片輸出規則**中代碼的含義；如果是自行撰寫，請把圖片規則寫在本文。做法請見[在對話中顯示圖片](/create/images-in-chat)。

</details>

<details>
<summary>在簡易模式寫的內容，專家模式的畫面上沒有</summary>

兩種模式的草稿是分開的。簡易模式的內容不會轉移到專家模式。請對照上面的表格，自己抄寫過去。

</details>
