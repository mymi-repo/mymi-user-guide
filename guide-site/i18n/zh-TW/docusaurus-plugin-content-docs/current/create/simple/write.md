# 撰寫設定與介紹

在簡易模式中，AI 每次聊天都會讀取的文字，是**基本資訊**步驟的世界觀、角色、秘密。對話的第一個場景，則在**介紹**步驟決定。這一頁說明這些文字該怎麼寫比較好。

## 作品標題與一句話簡介

- **作品標題**最多 30 字。AI 也會把它當作作品的名稱來讀。開場中的 `{{char}}` 在聊天時會換成這個標題。
- **一句話簡介**最多 40 字。這是和標題一起顯示在作品卡片上的句子。AI 不會讀。

## 世界觀

在**世界觀**寫下作品的背景與規則，以及故事如何開始。簡易模式沒有另外寫進行規則的欄位，所以故事的開始與方向也寫在世界觀裡。

```md
2031 年，地表受到污染而遭棄置。人們搬進了由地鐵站與地下商街相連而成的地下城市首爾生活。
城市由管理局控管，通往地表的通道已被封鎖。新進入的人會先在檢疫所停留。

使用者失去所有記憶，在檢疫所的病床上醒來。故事從民宇帶使用者走出檢疫所開始，當使用者試圖找回記憶時，書妍會一次給一條線索。
```

- **只寫使用者可以知道的內容。** 沒有寫詳細說明的話，世界觀會原封不動顯示在作品介紹畫面。反轉或隱藏的內情請寫在**秘密**。
- **寫得簡短明確。** AI 每次聊天都會讀世界觀。不是越長越好。
- **只在出現特定詞語時才需要的設定，交給 Lorebook。** 組織名稱、地點、用語這類不必隨時知道的設定，寫在 [Lorebook](/create/simple/extras#lorebook) 裡，只有那個詞語出現時才會傳給 AI。
- **可以使用 Markdown。** `##` 標題、`-` 清單、`**粗體**` 會在作品介紹畫面以那樣的樣式顯示。

## 角色

<ScreenStep src="/img/screens/zh-TW/simple-basic-characters.webp" device="part" alt="角色欄位中有姜民宇與李書妍兩張角色卡片，每張都寫著名稱和描述" caption="角色">

點選**新增角色**來增加角色。為每個角色寫下**名稱**（最多 50 字）和**描述**。角色卡片上的**收合**與**編輯**可以收起、展開卡片，**刪除**可以移除。

至少要有 1 個，而且名稱不能重複。名稱重複時，會跳出「發現重複的角色名稱」的提示。

</ScreenStep>

- **為每個角色寫下定位、個性、說話方式、關係。** 說話方式 AI 會原樣模仿，所以寫得具體一點比較好，例如「不用敬語」、「簡短的敬語」。
- **描述也會顯示在作品介紹畫面。** 角色有兩個以上時，名稱與描述會出現在**角色**清單中。不能讓使用者知道的內情，寫在**秘密**。
- **名稱在素材步驟也會用到。** 每張圖片都要連結到某個角色，所以先寫好角色，再進入素材步驟。

這是範例角色的描述。

| 名稱 | 描述 |
| --- | --- |
| 姜民宇 | `地下城市的引路人，32 歲。總愛開玩笑、個性悠哉，說話不用敬語，句尾拖長。似乎知道一些關於使用者的事。` |
| 李書妍 | `檢疫所醫師，28 歲。公事公辦、冷靜，說話用簡短的敬語。懷疑使用者的失憶並非意外。` |

## 秘密

**秘密**是 AI 知道、但使用者看不到的設定。這是選填欄位，不會顯示在作品介紹畫面。

```md
- 民宇接到監視使用者的命令。在使用者主動追問之前，不會透露。
- 使用者的記憶是管理局抹除的。
```

**也要一併寫下何時揭露。** 如果沒有條件，只寫「民宇正在監視」，AI 可能太早就揭露。像「在使用者主動追問之前，不會透露」這樣寫下條件，AI 比較容易遵守。

## 字數總計

世界觀、角色描述、秘密**合計最多 10,000 字**。世界觀欄位上方的**世界觀 + 角色描述 + 秘密總用量**，會用數字和進度條顯示已經用了多少、還剩幾字。字數越多顏色越會改變，到了 10,000 字就無法再輸入。角色名稱不計入這個總計。

## 介紹

介紹是聊天開始時 AI 先傳出的第一則訊息。它是使用者最先遇到的場景，決定了作品給人的第一印象。至少要有 1 個開場。

<ScreenStep src="/img/screens/zh-TW/simple-intro.webp" alt="介紹步驟。可以看到開場 1 標籤與新增按鈕、標題輸入欄、圖片按鈕、第一則訊息欄位與預覽" caption="介紹步驟">

1. 寫下**開場標題**。這是使用者挑選開始場景時看到的名稱。
2. 在下方欄位寫下第一則訊息。最多 2,000 字。欄位下方的數字是已經寫的字數。
3. 點選**清除**，會清掉這個開場的文字。其他開場與標題維持原樣。
4. 在**預覽**確認在聊天中會是什麼樣子。

點選開場標籤旁的**新增**，可以再建立開場。建立多個的話，使用者開始聊天時會選其中一個。可以用標籤上的垃圾桶圖示刪除，但只剩一個開場時不能刪除。

</ScreenStep>

第一則訊息要用和聊天相同的格式來寫。

| 寫法 | 顯示的樣子 |
| --- | --- |
| `*日光燈閃爍的檢疫所。*` | 動作與敘述（斜體） |
| `"哦，終於醒了～"` | 對話（強調色） |
| `{{user}}` | 聊天時會換成使用者的名稱 |
| `{{char}}` | 聊天時會換成**作品標題**。不是角色的名稱 |

```md
*日光燈閃爍的檢疫所。消毒水的氣味之中，有人拉開了簾子。*

"哦，終於醒了～你整整睡了三天耶？"

*一名穿著舊軍裝外套的男子轉著手電筒笑了起來。他自稱是引路人姜民宇。*

"這裡是首爾。更正確地說，是首爾的地底～所以，{{user}}。除了名字，你還記得什麼嗎？"
```

:::tip[角色名稱請直接寫出來]
在角色很多的作品裡使用 `{{char}}`，放進去的會是作品標題，而不是角色名稱。開場中請直接寫下「姜民宇」這樣的名稱。
:::

在開場放入素材圖片的方法，請見[素材與 AI 圖片](/create/simple/assets#在開場放入圖片)。

### 寫出好的第一個場景的訣竅

- **在第一則訊息的結尾，把要做的事交給使用者。** 範例以「除了名字，你還記得什麼嗎？」這個問題結尾，使用者可以馬上回答。
- **讓角色的說話方式和描述一致。** 如果角色描述寫了「不用敬語、句尾拖長」，開場的對話也要那樣寫。AI 比較容易從第一則訊息延續說話方式。
- **試著建立多個開始場景。** 在同一個世界裡，放入起點不同的開場，使用者就能挑選後開始。

## 遇到問題時

<details>
<summary>想在世界觀或角色描述多寫一點，卻打不進去</summary>

世界觀、角色描述、秘密加起來已經到 10,000 字了。請刪減不是必要的部分，或是把只在出現特定詞語時才需要的設定移到 **Lorebook**。

</details>

<details>
<summary>跳出「發現重複的角色名稱」</summary>

有兩個以上的角色名稱相同。英文名稱不區分大小寫與前後空格，會視為相同的名稱。請把名稱改成互不相同。

</details>

<details>
<summary>顯示開場的標題或內容是空的</summary>

你建立的開場中，有標題或內容是空的。請逐一點選開場標籤來確認。不打算使用的開場，請用標籤上的垃圾桶圖示刪除。

</details>

<details>
<summary>預覽中 `{{user}}` 原樣顯示</summary>

預覽中不會替換，在實際聊天時才會換成使用者的名稱。

</details>
