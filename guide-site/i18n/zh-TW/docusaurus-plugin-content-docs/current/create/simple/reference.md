# 輸入項目與限制

這裡整理了簡易模式畫面的限制與規則。詳細的使用方法，請見各項目的說明頁面。

## 字數與數量

| 步驟 | 項目 | 限制 |
| --- | --- | --- |
| 基本資訊 | 作品標題 | 必填 · 30 字 |
| | 一句話簡介 | 必填 · 40 字 |
| | 世界觀 · 角色描述 · 秘密 | 三個欄位合計 10,000 字。世界觀與至少 1 個角色（名稱與描述）為必填，秘密為選填 |
| | 角色名稱 | 50 字。角色之間不能重複 |
| 素材 | 圖片 | 必填 · 1～200 張。JPG、PNG、WEBP、GIF、HEIC · 最大 5MB |
| | 情境說明 | 每張圖片都必填 · 60 字 |
| | 個人檔案圖片 | 必填 · 用 ★ 選一張 |
| | 一次製作的 AI 圖片 | 基礎圖片 2 張、變體圖片 1 張 |
| 介紹 | 開場 | 必填 · 至少 1 個，標題和內容都要有 |
| | 內容 | 2,000 字 |
| 設定 | 類型 | 必填 · 1～2 個 |
| | Hashtag | 必填 · 至少 1 個（不含讀者群） |
| | 作品公開範圍 · 收益限制 · 圖片來源 · 讀者群 · 同意行銷使用 | 必填 |
| Lorebook | 條目 | 最多 100 個 |
| | 名稱 | 50 字 |
| | 關鍵字 | 每個條目 5 個，每個 10 字 |
| | 內容 | 400 字 |
| | 一次傳出的量 | 從最近 10 則訊息中尋找，最多 3 個 · 1,500 字 |
| Components | 使用描述 | 每個元件都必填 · 500 字 |
| | JSX 程式碼 | 必填 · 10,000 字。需要函式名稱與至少 1 個變數 |
| 選填 | 詳細說明（HTML） | 選填 · 50,000 字 |
| | 推薦人設 | 選填。建立的話，名稱（20 字）、性別、出生日期（滿 14 歲）、詳細資訊（1,000 字）都要有 |
| | 創作者備註 | 選填 · 3,000 字 |

**公開設定**（公開）、**內容分級**（全年齡）、**圖片輸出指示**（內部圖片）一開始就選好了。

## 下一步與完成時會檢查的項目

按下一步按鈕或**完成**按鈕時，會依照下列順序檢查，並顯示第一個被攔下的項目的提示。**完成**會再檢查全部七個步驟。

| 順序 | 步驟 | 檢查的項目 |
| --- | --- | --- |
| 1 | 基本資訊 | 作品標題、一句話簡介、世界觀、至少 1 個角色、角色的名稱與描述、名稱是否重複 |
| 2 | 素材 | 至少 1 張圖片、個人檔案圖片、所有圖片的情境說明 |
| 3 | 介紹 | 至少 1 個，且每一個都有標題和內容 |
| 4 | 設定 | 依照 類型 → Hashtag → 作品公開範圍 → 收益限制 → 圖片來源 → 讀者群 → 內容分級 → 同意行銷使用 的順序 |
| 5 | Lorebook | 每個新增的條目的名稱、關鍵字、內容 |
| 6 | Components | 每個新增的元件的使用描述、程式碼、函式名稱、至少 1 個變數 |
| 7 | 選填 | 每個新增的推薦人設的名稱、性別、出生日期、詳細資訊 |

## 圖片語法

簡易模式會用你在**設定 → 圖片輸出指示**選的方式輸出圖片。只能使用一種方式。

| 方式 | 語法 | 使用的地方 |
| --- | --- | --- |
| 內部圖片 | `img:[名稱]` | 上傳到素材的圖片。素材卡片上會顯示像 `img:AB3K9X` 這樣的名稱 |
| 外部圖片 | `![](圖片網址)` | 寫在設定裡的外部圖片網址 |

在開場中要寫成像 `img:[AB3K9X]` 這樣。名稱是 MYMI 決定的 6 個英文大寫字母與數字。使用內部圖片時，AI 會依據你為每個素材寫的**情境說明**與連結的角色，決定要放哪張圖片。使用外部圖片時，情境說明不會傳給 AI，它會依據設定裡寫的圖片網址或網址規則來放圖片。如果不知道網址，就不會放圖片。

:::warning[專家模式不使用]
`img:[名稱]` 是簡易模式的語法。專家模式的作品，請使用素材分頁的代碼和 `![]({{URL}}/A/1.webp)`。
:::

## `{{user}}` 與 `{{char}}`

| 使用的地方 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 開場 | 聊天時會換成使用者的名稱 | 聊天時會換成**作品標題** |

開場的預覽中不會替換，會原樣顯示。`{{char}}` 放進去的是作品標題，而不是角色名稱，所以角色名稱要自己寫出來。

## 儲存

| 情況 | 何時儲存 |
| --- | --- |
| 所有作品 | 按下一步按鈕時、點選分頁往前走時、按**完成**時。在那之前修改的內容會一併儲存 |
| 素材 | 上傳、刪除圖片、**儲存**情境說明、更換 ★ 個人檔案圖片，會立刻反映到作品 |
| 已公開的作品 | 儲存的那一刻，其他使用者也會看到改過的內容 |

## 免費與驗證

- 作品製作中的圖片生成與重新生成是免費的。要生成的話，需要手機號碼驗證。
- 成人限定的作品，只有完成成人驗證的使用者才能使用。
- 圖片生成的標籤步驟中的安全過濾器，只有完成成人驗證的帳號才能關閉。

## 遇到問題時

<details>
<summary>顯示「儲存失敗。」</summary>

可能是儲存時連線中斷，或伺服器暫時忙碌。請稍後再按一次下一步按鈕。如果一直出現相同的提示，請從**個人檔案 → Discord** 前往詢問頻道，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)，告訴我們是在哪個作品的哪個步驟發生的。

</details>

<details>
<summary>字打不進去了</summary>

超過各欄位規定的字數就無法輸入。基本資訊步驟的上限是世界觀、角色描述、秘密合計 10,000 字，所以也請確認其他欄位寫了多少。

</details>
