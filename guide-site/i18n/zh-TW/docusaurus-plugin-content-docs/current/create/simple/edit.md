# 編輯作品

用簡易模式建立的作品，在和建立時相同的七步驟畫面中修改。作品會以建立時的模式開啟，所以用專家模式建立的作品要怎麼修改，請見[公開與修改](/create/publish#修改已公開的作品)。

## 開啟方式與移動

1. 在**個人檔案 → 內容管理**，點選作品的**編輯**。
2. 會以簡易模式開啟。最上方的**創作模式**欄位是鎖定的，而且會先顯示**基本資訊**步驟。
3. 前往要修改的步驟並修改。可以點選上方的分頁直接移動。
4. 都改好之後，用下一步按鈕走到最後的**選填**步驟，點選**完成**。會再檢查所有步驟，並前往**作品製作完成**畫面。

移動與儲存是這樣運作的。

| 移動 | 檢查 | 儲存 |
| --- | --- | --- |
| 下一步按鈕 | 目前步驟的必填項目 | 到目前為止修改的內容 |
| 點選分頁**往前** | 到那個步驟之前的所有步驟 | 到目前為止修改的內容 |
| 點選分頁**往回** | 不檢查 | 不儲存。下次往前走時會一併儲存 |
| **完成** | 所有步驟 | 到目前為止修改的內容 |

在素材中上傳、刪除圖片、**儲存**情境說明、更換 ★ 個人檔案圖片，不必按下一步按鈕就會立刻反映到作品。

:::warning[已公開的作品，每次往下走都會立刻改變]
簡易模式每次按下一步按鈕，或用分頁往前走，都會把改過的內容儲存到作品。如果作品已經公開，從那一刻起其他使用者也會看到改過的內容。它不會像專家模式的**套用變更**那樣等你確認。要大幅修改時，請先把要改的文字寫在記事本之類的地方，貼上之後再往下走。
:::

:::warning[刪除圖片時要小心]
在已公開的作品刪除素材圖片，會立刻從作品中消失。如果你把那張圖片放在開場，或是對話中正在使用，可能就不會再顯示了。刪除之前，請一併確認開場裡的圖片那一行。
:::

## 第一次開啟以前做的作品時

以前做的作品沒有的欄位增加了。第一次開啟時，下列欄位可能是空的，要選好才能從**設定**步驟往下走。

- **類型** 1～2 個
- **標籤**至少 1 個（**讀者群**不是標籤，要在讀者群卡片中選擇）
- **收益限制**
- **同意行銷使用**

設定步驟的卡片樣式和文字，已經和專家模式相同。每張卡片代表什麼，請見[選擇作品設定](/create/settings)。作品標題最多 30 字。

## 各步驟可以修改的內容

各步驟的寫法和建立時相同。

| 步驟 | 可以修改的內容 | 說明 |
| --- | --- | --- |
| **基本資訊** | 標題、一句話簡介、世界觀、角色、秘密 | [撰寫設定與介紹](/create/simple/write) |
| **素材** | 新增、刪除圖片，情境說明，角色連結，個人檔案圖片，需要解鎖 | [素材與 AI 圖片](/create/simple/assets) |
| **介紹** | 新增、刪除開場，標題，第一則訊息 | [撰寫設定與介紹](/create/simple/write#介紹) |
| **設定** | 類型、標籤、公開設定、作品公開範圍等 | [選擇作品設定](/create/settings) |
| **設定集 · 元件 · 選填** | 條目、元件、詳細說明、推薦人設、創作者備註 | [設定集、元件與選填](/create/simple/extras) |

## 更改公開設定

- **想暫時下架作品**，請在**設定 → 公開設定**選**不公開**，再按下一步按鈕儲存。
- **想把不公開的作品改成公開**，請在同一張卡片選**公開**並儲存。改成公開的作品要經過審查，其他使用者才看得到。（[公開與修改](/create/publish#把不公開的作品改成公開)）
- **作品公開範圍**設為原創的作品，3 個月內無法更改。剩餘天數會顯示在卡片上。

## 遇到問題時

<details>
<summary>點選編輯後，創作模式欄位出現鎖頭</summary>

從內容管理開啟的作品，會以建立時的模式開啟，而且無法更改模式。想建立新作品，請點選 <strong>↺</strong> 清空編輯畫面，再選擇模式。（[開始之前](/create/before-you-start#從內容管理開啟的作品模式會被鎖定)）

</details>

<details>
<summary>無法前往下一步</summary>

前面的步驟有缺少的必填項目。請確認上方跳出的提示。如果是素材步驟，請看是否至少有 1 張圖片、每張圖片都有情境說明，以及有沒有設定個人檔案圖片。如果是設定步驟，請看是否選了類型、標籤、**讀者群**、**作品公開範圍**、**收益限制**、**圖片來源**、**同意行銷使用**。

</details>

<details>
<summary>跳出「有尚未儲存的內容」視窗</summary>

簡易模式的編輯畫面還留著其他作品或新作品尚未儲存的內容。點選**開啟**，那些內容會消失，並開啟你選的作品。想保留的話，請點選**取消**，先在編輯畫面用下一步按鈕儲存。

</details>

<details>
<summary>顯示「找不到作品。」</summary>

這是在其他裝置上刪除的作品，或不是你的作品。編輯畫面會被清空，請在**內容管理**確認作品是否還在。

</details>

<details>
<summary>沒有提示詞分頁</summary>

簡易模式沒有提示詞分頁。想自己撰寫提示詞，就必須用專家模式建立新作品。沒有把既有作品改成專家模式的按鈕。（[移到專家模式](/create/simple/to-expert)）

</details>

<details>
<summary>想把改錯的內容還原</summary>

沒有還原按鈕。請把改變的欄位再改一次，用下一步按鈕儲存。已公開的作品，儲存過的內容會立刻被看到，所以大幅修改前請先做筆記。

</details>

<details>
<summary>同一部作品在電腦和手機上同時開著修改</summary>

會保留後儲存的那一邊的內容。想換到另一台裝置繼續修改，請先在原本的裝置按下一步按鈕儲存，再到另一台裝置的**內容管理**點選**編輯**開啟。離開編輯畫面超過 5 分鐘再回來時，如果這台裝置沒有尚未儲存的內容，畫面會換成伺服器上的最新內容。

</details>
