# 設定集、元件與選填

**設定集**、**元件**、**選填**是選填步驟。空著也可以完成作品，想加入時再填寫即可。如果加入了，裡面的必填欄位都要填好，才能用下一步按鈕往下走。

## 設定集 {/* #lorebook */}

設定集是**對話中出現關鍵字時，才把該條目的內容傳給 AI 的設定**。寫下不必隨時知道、但名稱一出現就必須知道的內容，例如世界觀的用語、地點、組織、角色的秘密。

寫在世界觀的文字，AI 每次都會讀，但條目只有在關鍵字出現時才會讀。把每次都需要的設定放在基本資訊步驟的世界觀和角色，偶爾才出現的設定放在設定集，就能讓世界觀保持簡短。

<ScreenStep src="/img/screens/zh-TW/simple-lorebook.webp" alt="設定集步驟。2/100 的顯示與說明文字下方，管理局和 7 號出口兩個條目呈收合狀態，並有新增設定按鈕" caption="設定集步驟">

1. 點選**新增設定**。最多可以建立 100 個。
2. 展開卡片，填寫**名稱**、**關鍵字**、**內容**。
3. 再點一次卡片就會收合，只顯示名稱和關鍵字。卡片上的垃圾桶圖示可以刪除。

</ScreenStep>

- **名稱**：條目的名稱。最多 50 字。會和內容一起傳給 AI。
- **關鍵字**：對話中出現這些詞語時，就會傳出內容。最多 5 個，每個最多 10 字。寫好後按 Enter 或逗號加入。不區分大小寫。
- **內容**：只寫關鍵字出現時 AI 必須知道的事。最多 400 字。

這是範例作品的條目。

| 名稱 | 關鍵字 | 內容 |
| --- | --- | --- |
| 管理局 | 管理局、局長 | 統治地下城市的機關。管理檢疫所與出入口，傳聞會抹除從地表下來的人的紀錄。民宇是接到管理局的命令才行動的。 |
| 7號出口 | 7號出口、七號出口 | 通往地表的唯一出口。自 2031 年封鎖後一直關閉，沒有管理局的許可證就無法靠近。 |

**怎麼找出並傳出**

- 會在使用者傳的訊息，以及**最近 10 則訊息**中尋找關鍵字。
- 關鍵字即使出現在其他詞語裡面也找得到。關鍵字 `管理局` 在「管理局長來了」中也找得到。空格有區別，所以 `7號出口` 在「7 號出口」中找不到。
- 符合的條目有好幾個時，會從最近出現的開始挑，一次最多傳出 **3 個，合計 1,500 字**。

**挑選關鍵字的訣竅**

- 寫對話中真的會出現的詞語。縮寫和暱稱也一併放入。可以空格也可以不空格的名稱，兩種都放入。
- 避免太常見的詞。幾乎每次對話都會符合，真正需要的條目反而可能擠不進那 3 個。
- 內容簡短，只寫事實。說話方式與進行方向，寫在世界觀和角色描述裡。

## 元件 {/* #components */}

元件是 **AI 在聊天中顯示的 UI**。把想顯示的東西做好，例如狀態視窗、道具欄、選項，AI 就會在需要時呼叫。不懂程式碼，也可以用 Gem 來做。

<ScreenStep src="/img/screens/zh-TW/simple-components.webp" alt="元件步驟。上方有指南與複製作品上下文按鈕，StatusWindow 元件卡片與預覽，以及新增元件按鈕" caption="元件步驟">

1. 點選**新增元件**，建立卡片。
2. 展開卡片，把程式碼貼到 **JSX 程式碼**欄位。函式名稱和變數會自動從程式碼讀取。
3. 在**使用描述**寫下何時使用這個元件。
4. 在卡片裡的預覽確認在聊天中會是什麼樣子。卡片上的眼睛圖示可以收合、展開預覽。

</ScreenStep>

- **JSX 程式碼**：`function 名稱({ 變數 = 預設值 })` 形式的程式碼。最多可以寫 10,000 字。程式碼圍欄和 import 語句會自動整理。
- **變數預設值**：顯示從程式碼讀到的變數與預設值。預設值會用在預覽，也會成為 AI 填入值的範例。
- **使用描述**：最多 500 字。這是 AI 判斷何時使用這個元件的依據。

這是範例作品的狀態視窗程式碼。必須有函式名稱（`StatusWindow`）和至少一個變數（`hp`、`mp`）。

```jsx
function StatusWindow({ hp = 100, mp = 40 }) {
  const bar = (value, color) => (
    <div className="h-2 w-full rounded-full bg-slate-700">
      <div className={`h-2 rounded-full ${color}`} style={{ width: `${Math.max(0, Math.min(100, value))}%` }} />
    </div>
  );
  return (
    <div className="my-2 w-full max-w-sm rounded-xl border border-cyan-400/40 bg-slate-900/90 p-3 text-slate-100">
      <div className="mb-2 flex items-center justify-between text-[11px] font-bold tracking-widest text-cyan-300">
        <span>STATUS</span>
        <span>檢疫所 B-3</span>
      </div>
      <div className="space-y-2 text-sm">
        <div>
          <div className="mb-1 flex justify-between"><span>體力</span><span>{hp}/100</span></div>
          {bar(hp, "bg-rose-400")}
        </div>
        <div>
          <div className="mb-1 flex justify-between"><span>魔力</span><span>{mp}/100</span></div>
          {bar(mp, "bg-sky-400")}
        </div>
      </div>
    </div>
  );
}
```

> 範例 — 使用描述：`戰鬥開始時與體力變化時顯示。hp = 體力，mp = 魔力。`

AI 會讀取元件的名稱、使用描述、變數與預設值，並在適當的時機，把像 `<StatusWindow hp={100} mp={40} />` 這樣的標記放進回覆。如果在使用描述中寫下**何時使用**和**變數的意思**，AI 就會把值填得比較恰當。

:::info[元件是用來顯示的工具]
元件只是把 AI 放入的值畫得好看。像體力計算這樣，值對不對要看 AI 的回覆。就算寫了說明，AI 偶爾也可能漏掉標記，或是放入不同的值。
:::

**用 Gem 製作**

不必自己寫程式碼。使用步驟上方的兩個按鈕。

1. 點選**指南**查看 Gem 說明。第一次開啟這個步驟時會自動跳出。
2. 點選**複製作品上下文**。作品介紹會被複製，並出現**開啟 Gemini Gem**。
3. 開啟 Gem，貼上複製的作品資訊，寫下想做的 UI。回答 Gem 的提問，它就會幫你做出程式碼。
4. 把完成的程式碼貼到元件卡片的 **JSX 程式碼**欄位。

## 選填

**選填**步驟有詳細說明、推薦人設、創作者備註。因為是最後一個步驟，按鈕會變成**完成**。

### 詳細說明

用 HTML 美化要顯示在作品介紹畫面的文字。不使用的話，作品介紹會原封不動顯示世界觀和角色描述。

<ScreenStep src="/img/screens/zh-TW/simple-optional.webp" alt="選填步驟。詳細說明的使用與不使用中選了使用，可以看到 HTML 輸入欄與預覽" caption="選填步驟 · 詳細說明">

1. 在**使用**與**不使用**之間選擇。**不使用**是只使用標準檔案。
2. 選了**使用**，就會出現 HTML 輸入欄。最多 50,000 字。
3. 輸入欄下方會顯示檢查結果。顯示「安全 HTML」就可以直接使用。點選「包含不安全標籤」旁邊的**自動清理**，就會去除那些標籤。「非 HTML 文字」表示那不是 HTML 程式碼的文字。
4. 如果是 HTML，下方會出現**預覽**。確認使用者看到的樣子。

</ScreenStep>

不懂程式碼也沒關係。點選**複製作品資訊**，再用**開啟 Gemini Gem** 請 Gem 幫你做介紹頁。點選**指南**可以看到使用方法。

:::info[AI 不會讀詳細說明]
詳細說明是顯示在作品介紹畫面的文字。AI 需要知道的設定，請寫在基本資訊步驟。
:::

### 推薦人設

這個功能讓你事先做好使用者開始聊天時可以選擇的人設。想提出適合作品世界的主角時使用。不做也可以。

點選**新增人設**來建立。如果建立了，四個欄位都要填好，才能用下一步按鈕或**完成**按鈕往下走。

- **名稱**：最多 20 字
- **性別**：女性・男性
- **出生日期**：寫下年、月、日。必須年滿 14 歲。
- **詳細資訊**：寫下個性、背景、說話方式，讓 AI 知道該如何對待扮演這個人設的使用者。最多 1,000 字

### 創作者備註

留下關於作品的訊息。最多 3,000 字。會顯示在作品介紹畫面，AI 不會讀。點選**清除**會清掉文字。

## 遇到問題時

<details>
<summary>顯示「有設定條目沒有關鍵字。」</summary>

請確認有沒有寫下關鍵字並按 Enter 或逗號加入。卡片上看得到關鍵字才算加入。做到一半的條目，用垃圾桶圖示刪除。名稱或內容是空的條目，也會出現同樣的提示。

</details>

<details>
<summary>顯示「請將元件程式碼撰寫為 function component。」</summary>

請確認程式碼是不是以 `function 名稱(...)` 的形式開頭。箭頭函式或沒有名稱的函式，讀不到名稱。

</details>

<details>
<summary>顯示「請至少新增一個元件變數名稱。」</summary>

函式必須宣告至少一個接收的變數。例：`function StatusWindow({ hp = 100 })`

</details>

<details>
<summary>顯示「請輸入元件使用描述。」</summary>

展開元件卡片，寫下**使用描述**。請確認有沒有元件的卡片上出現紅字標示，例如「需要使用描述」、「需要 JSX 程式碼」。

</details>

<details>
<summary>顯示「請完成推薦人設資訊。」</summary>

你建立的人設中，名稱、性別、出生日期、詳細資訊有空的欄位。出生日期不能是不存在的日期、未來的日期，或未滿 14 歲。不打算使用的人設，請刪除。

</details>

<details>
<summary>作品介紹沒有顯示世界觀，只顯示 HTML 文字</summary>

因為你把**詳細說明**選成了**使用**。寫了 HTML 介紹的話，會顯示那段文字，而不是世界觀和角色。想顯示世界觀和角色描述的話，請改成**不使用**。

</details>
