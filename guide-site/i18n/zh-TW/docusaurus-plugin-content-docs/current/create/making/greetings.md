# 撰寫開場

開場是開始聊天時 AI 先傳出的第一則訊息。這是使用者最先遇到的場景，決定了作品的第一印象。開場至少要有 1 個。

:::info
這是專家模式的說明。簡易模式請見[撰寫設定與介紹](/create/simple/write#介紹)。
:::

## 建立開場

<ScreenStep src="/img/screens/zh-TW/first-greeting.webp" alt="開場分頁。有開場清單、標題欄與第一則訊息欄" caption="開場分頁">

1. 寫下**開場標題**。這是使用者選擇開始場景時看到的名稱。最多可寫 100 字。
2. 在下方欄位寫下第一則訊息。最多 2,000 字。

點選開場清單那一列的**新增**，可以再建立開場。建立多個時，使用者開始對話時可以選其中一個。要刪除的話，先在清單中選取該開場，再點選名稱旁的<strong>×</strong>。只有一個開場時無法刪除。

</ScreenStep>

第一則訊息要寫成與聊天相同的樣式。

| 寫法 | 顯示的樣子 |
| --- | --- |
| `*日光燈閃爍的檢疫所。*` | 動作與敘述（斜體） |
| `"哦，終於醒了～"` | 對話（強調色） |
| `{{user}}` | 對話時會換成使用者的名字 |
| `{{char}}` | 對話時會換成**作品標題**。不是人物名稱 |

:::tip[人物名稱請直接寫]
在有多位登場人物的作品裡使用 `{{char}}`，放進去的是作品標題，而不是人物名稱。開場裡請直接寫出「民宇」這樣的名字。
:::

## 插入圖片

素材分頁有圖片的話，就可以插入開場。在聊天中，插入的位置會顯示圖片。

<ScreenStep src="/img/screens/zh-TW/greeting-insert-image.webp" alt="插入素材圖片視窗。素材圖片與代碼一起以格狀顯示" caption="插入素材圖片">

1. 在第一則訊息欄，點選想插入圖片的位置，放置游標。
2. 點選**插入素材圖片**。
3. 點選要插入的圖片，游標位置就會加入像 `![]({{URL}}/A/1.webp)` 這樣的一行。

要在素材分頁上傳圖片並設定代碼，才會出現在清單裡。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/greeting-preview-images.webp" device="part" alt="開場預覽。走廊背景與姜民宇的圖片顯示在敘述和對白之間" caption="放入圖片的開場預覽">

在**預覽**確認圖片會顯示在哪裡。如果沒有符合代碼的圖片，該處會出現「素材分頁沒有這個代碼的圖片」的提示。

範例把走廊背景放在最上面，把民宇微笑的圖片放在民宇第一句對話之前。

</ScreenStep>

```md
![]({{URL}}/BG1.webp)
*日光燈閃爍的檢疫所。消毒水的氣味之中，有人拉開了簾子。*

![]({{URL}}/A/1.webp)
"哦，終於醒了～你整整睡了三天耶？"
```

:::info[鎖定的圖片在開場也看得到]
在素材中開啟**需要解鎖**的圖片，在開場和封面裡一開始也看得到。因為那是使用者一開始就會看到的地方。想隱藏的圖片，請不要放進開場。
:::

## 寫出好的第一個場景的訣竅

- <strong>在第一則訊息的結尾，把事情交給使用者。</strong>範例以「除了名字，你還記得什麼嗎？」這個問題結尾，使用者可以馬上回答。
- <strong>讓開場的語氣和提示詞一致。</strong>如果提示詞寫了「不用敬語，句尾拖長」，開場的對話也要這樣寫。AI 比較容易延續第一則訊息的語氣。
- <strong>試著做出多個開始場景。</strong>在同一個世界觀中準備起點不同的開場，使用者就能挑選開始。例：「在檢疫所醒來」、「在 7 號出口前」

## 遇到問題時

<details>
<summary>顯示「有開場沒有標題。」或「有開場沒有內容。」</summary>

建立好的開場中，有標題或內容是空的。請在開場清單中一個一個點開確認。不會用到的開場，先選取再點選名稱旁的<strong>×</strong>刪除。

</details>

<details>
<summary>點選插入素材圖片後顯示「在素材分頁上傳圖片並設定代碼後即可插入。」</summary>

目前還沒有可以插入的圖片。在素材分頁上傳或生成圖片並完成，再為該圖片設定代碼，就會出現在清單裡。

</details>

<details>
<summary>預覽裡的 `{{user}}` 沒有被替換</summary>

預覽不會替換，實際對話時才會換成使用者的名字。

</details>
