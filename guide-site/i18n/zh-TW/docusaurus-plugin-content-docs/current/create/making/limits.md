# 限制與規則一覽

這裡整理了專家模式作品製作畫面的限制與規則。詳細的用法，請見各項目的說明頁面。

:::info
這是專家模式的說明。簡易模式請見[輸入項目與限制](/create/simple/reference)。
:::

## 字數與數量

| 分頁 | 項目 | 限制 |
| --- | --- | --- |
| 基本資訊 | 作品標題 | 必填 · 30 字 |
| | 一句話簡介 | 必填 · 40 字 |
| | 封面 | 必填 · 1～10 張。檔案為 JPG、PNG、WEBP、GIF、HEIC · 最大 5MB。切換間隔為 0.5～60 秒（每按一次按鈕 0.5 秒） |
| | 詳細說明 | 必填 · 50,000 字 |
| | 類型 | 必填 · 1～2 個 |
| | 標籤 | 必填 · 至少 1 個，每個 30 字。與讀者群合計最多 30 個 |
| | 創作者指南 | 選填 · 每則 5,000 字 |
| | 推薦模型 | 選填 · 最多 5 個 |
| 素材 | 圖片檔 | JPG、PNG、WEBP、GIF、HEIC · 最大 5MB |
| | 代碼・資料夾名稱 | 英文與數字，最多 30 字 |
| | 一次生成要求 | 最多 50 張 |
| 元件 | JSX 程式碼 | 20,000 字。需要函式名稱與至少 1 個變數 |
| 提示詞 | 自行撰寫 | 必填 · 10,000 字 |
| | 基本型 | 必填 · 作品資訊・代碼含義・例外・元件規則所寫的文字合計 10,000 字 |
| 開場 | 開場 | 必填 · 至少 1 個，標題與內容都要有 |
| | 標題 | 100 字 |
| | 內容 | 2,000 字 |
| 設定集 | 設定 | 最多 100 條 |
| | 名稱 | 50 字 |
| | 關鍵字 | 每條設定 5 個，每個 10 字 |
| | 內容 | 400 字 |
| | 一次傳送的量 | 從最近 10 則訊息中搜尋，最多 3 條 · 1,500 字 |
| 其他設定 | 推薦人設 | 選填。建立的話，名稱（20 字）・性別・出生日期（年滿 14 歲）・詳細資訊（1,000 字）都要有 |

## 完成製作時檢查的項目

點選**完成製作**（已公開的作品是**套用變更**）後，會依照下面的順序檢查，並切換到第一個被攔下的項目所在的分頁顯示說明。

| 順序 | 分頁 | 檢查的內容 |
| --- | --- | --- |
| 1 | 基本資訊 | 作品標題、一句話簡介、至少 1 張封面、詳細說明、1～2 個類型、至少 1 個標籤 |
| 2 | 素材 | 所有圖片是否都有代碼、代碼是否為英文與數字、同一個資料夾內是否沒有相同代碼、是否沒有空白格與等待生成的列、基本形象是否已完成 |
| 3 | 元件 | 程式碼、函式名稱、至少 1 個變數 |
| 4 | 提示詞 | 自行撰寫：提示詞。基本型：作品資訊、角色・情境・其他代碼的含義、元件出現的時機、合計 10,000 字以下 |
| 5 | 開場 | 是否至少有 1 個，且全部都有標題與內容 |
| 6 | 設定集 | 每條新增的設定的關鍵字・內容・名稱 |
| 7 | 其他設定 | 作品公開範圍、收益限制、圖片來源、讀者群、同意行銷使用，以及新增的推薦人設的四個欄位 |

公開設定（公開）和內容分級（全年齡）一開始就已選好。

## 代碼規則

- 圖片代碼與角色資料夾名稱，只能使用**英文與數字**。不能有空格或特殊符號。
- 同一個資料夾內，代碼不能重複。不同資料夾之間可以使用相同的代碼（`A/1`、`B/1`）。
- 資料夾只能建立一層。
- 路徑在資料夾內是 `資料夾/代碼`，在資料夾外是 `代碼`。在對話和開場中，要寫成 `![]({{URL}}/A/1.webp)`、`![]({{URL}}/BG1.webp)` 這樣。
- 圖片無法移到其他角色資料夾。可以移出資料夾。
- 已完成製作的作品無法更改資料夾名稱。

## `{{user}}` 與 `{{char}}`

| 使用的地方 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 開場 | 對話時會換成使用者的名字 | 對話時會換成**作品標題** |
| 提示詞 | 用來指稱使用者 | 不會自動替換。請直接寫出人物名稱 |
| 設定集 | 用來指稱使用者 | 請直接寫出人物名稱 |

## 儲存

| 情況 | 儲存的時機 |
| --- | --- |
| 製作中的作品 | 有變更時切換分頁會自動儲存；第一次上傳或生成封面、素材圖片時；點選**儲存草稿**時。草稿建立之後，素材分頁的變更會立刻儲存 |
| 已完成製作的作品 | 文字與設定在點選**套用變更**時儲存。素材的變更會立刻反映 |

## 免費與驗證

- 作品製作中的圖片生成、重新生成是免費的。要生成的話，需要手機號碼驗證。
- 成人限定的作品，只有完成年齡確認的使用者才能使用。
- 圖片生成標籤步驟中的安全篩選，只有完成年齡確認的帳號才能關閉。

## 遇到問題時

<details>
<summary>點了完成製作，卻跳到其他分頁</summary>

這表示系統切換到有缺漏項目的分頁，並告訴你是哪個項目。請把說明中提到的欄位填好，再點選一次**完成製作**。每個分頁檢查什麼，請見[完成製作時檢查的項目](#完成製作時檢查的項目)。

</details>

<details>
<summary>儲存或完成製作出現錯誤，但看起來都已經填好了</summary>

可能有欄位超過了「輸入時不會擋，儲存時才會被攔下」的限制。請先確認這些欄位：

- **基本資訊**的標籤：每個 30 字，與讀者群合計最多 30 個
- **基本資訊**的封面切換間隔：最多 60 秒
- **開場**標題：最多 100 字
- **素材**的代碼與資料夾名稱：最多 30 字

修改後再儲存一次。如果仍然出現相同的錯誤，請附上是哪個作品的哪個欄位，從**個人檔案 → Discord** 前往 Discord 的詢問頻道告訴我們，或寄信到 [contact@mymi.live](mailto:contact@mymi.live)。

</details>
