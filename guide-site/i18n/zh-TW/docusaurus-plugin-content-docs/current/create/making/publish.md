# 公開與修改

點選**完成製作**後，作品就會建立，設為公開的作品會經過審查後，才向其他使用者公開。做好的作品隨時都可以在**個人檔案 → 內容管理**修改。

## 從完成製作到公開

| 階段 | 會發生什麼 |
| --- | --- |
| 完成製作 | 檢查必填項目並儲存作品。如果有缺漏，會切換到該分頁告訴你。 |
| 審查 | 檢查安全規範與作品品質。完成後會通知你。 |
| 公開 | 其他使用者可以找到作品並開始聊天。 |

審查期間，作者本人也可以直接聊天。審查所需的時間會因作品而異。**成人限定**的作品，只會顯示給完成年齡確認的使用者。

完成畫面會依作品的狀態顯示不同的說明。

<ScreenStep src="/img/screens/zh-TW/complete-private.webp" alt="不公開作品的完成畫面。有不公開標示與公開方法的說明" caption="設為不公開的作品">

- 設為**公開**的新作品：會顯示為**審查中**，審查完成後向其他使用者公開。（[建立第一個作品](/create/first-work#5-完成製作)的完成畫面）
- 設為**不公開**的作品：只有你自己看得到。要公開的話，請在內容管理變更公開設定，審查會從那時開始。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/complete-approved.webp" alt="修改已公開作品後的完成畫面。有已通過標示與修改內容已套用的說明" caption="修改已公開的作品時">

- 如果修改的是**已通過**的作品：修改的內容會立刻顯示給其他使用者。不會每次修改都重新接受審查。
- 不過，如果把**內容分級**從成人限定改成全年齡，就會重新接受審查。

</ScreenStep>

## 內容管理

<ScreenStep src="/img/screens/zh-TW/manage-list.webp" alt="內容管理畫面。四個作品以卡片顯示，編輯按鈕、⋮ 選單、審查中標示上標有編號" caption="個人檔案 → 內容管理">

你做的作品都集中在**個人檔案 → 內容管理**。

1. **編輯**：在作品製作畫面開啟作品。
2. **⋮**：開啟選單。有**刪除**，如果是被退回的作品，還有**申請重新審查**。
3. 公開的作品會顯示**審查中**・**已通過**・**已退回**。

還沒完成製作的草稿會顯示為**製作中**。點選**個人檔案**，會開啟作品介紹畫面。

</ScreenStep>

可以用上方的搜尋欄和**篩選**（排序・公開狀態・審核狀態）來找作品。在**儀表板**可以查看訊息數、已獲得 Leaf 這類作品的成績。

## 修改已公開的作品

<ScreenStep src="/img/screens/zh-TW/released-header.webp" alt="開啟已完成製作作品的製作畫面。標頭有套用變更而不是儲存草稿，素材分頁顯示無法變更資料夾名稱的說明" caption="已完成製作作品的製作畫面">

1. 在**內容管理**點選**編輯**。
2. 修改想改的地方。
3. 點選畫面上方的**套用變更**。

已完成製作的作品沒有**儲存草稿**。為了避免改到一半的狀態被公開，文字和設定要點選**套用變更**才會生效。

</ScreenStep>

:::warning[素材會立刻反映]
在素材分頁新增、替換、刪除圖片和更改代碼，不必等**套用變更**，會立刻反映到作品上。

- 更改代碼或刪除圖片後，使用過那張圖片的既有對話也會無法顯示該圖片。要替換圖片時，請保留代碼，只替換圖片。
- 已完成製作的作品無法更改資料夾名稱（角色代碼）。
- 圖片無法移到其他角色資料夾。可以移出資料夾。
:::

:::tip[關閉畫面前先套用變更]
已公開的作品就算切換分頁也不會自動儲存。修改之後，關閉畫面前請先點選**套用變更**。
:::

## 被退回的作品申請重新審查

<ScreenStep src="/img/screens/zh-TW/manage-menu.webp" device="part" alt="有已退回標示的兩張作品卡片。上方卡片的 ⋮ 按鈕標有 1 號，下方卡片按下 ⋮ 開啟的選單中，申請重新審查標有 2 號" caption="⋮ → 申請重新審查">

審查被退回時，作品卡片會顯示**已退回**。

1. 點選該作品的 **⋮** 按鈕。選單開啟後，已退回的標示會被選單遮住。
2. 點選**申請重新審查**。
3. 確認**退回原因**。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/manage-appeal.webp" alt="退回原因視窗。退回原因下方有要傳給審查團隊的訊息欄與提交按鈕" caption="退回原因與重新審查申請（網頁）">

4. 依照原因修改作品，並點選**套用變更**。修改的方法和[修改已公開的作品](#修改已公開的作品)相同。
5. 再次點選 **⋮ → 申請重新審查**。
6. 需要的話，在訊息欄寫下修改的內容並送出申請。網頁版是在退回原因視窗點選**申請重新審查**後，再點選**提交**；App 則是點選視窗下方的**申請重新審查**。重新審查由管理員檢視後處理。

</ScreenStep>

## 把不公開的作品改成公開

1. 在**內容管理**點選**編輯**。
2. 在**其他設定 → 公開設定**選擇**公開**。
3. 點選**套用變更**，審查就會開始。

## 刪除作品

在**內容管理**點選作品的 **⋮ → 刪除**，並在確認視窗再點選一次**刪除**，就會刪掉。刪除的作品會從內容管理和作品列表消失。

:::danger[刪除後無法復原]
沒有讓已刪除作品復活的選單。如果只是想暫時下架，請用**編輯**開啟，把**其他設定 → 公開設定**改成**不公開**，再點選**套用變更**。
:::

:::info
作品製作畫面的 **↺**（重設建立內容）只會清空正在輸入的畫面。已儲存的草稿會留在內容管理。
:::

## 推薦人設

<ScreenStep src="/img/screens/zh-TW/settings-persona.webp" device="part" alt="其他設定中的推薦人設。已填入名稱韓智宇、性別、生日與詳細資訊" caption="其他設定 → 推薦人設">

**推薦人設**是事先建立使用者開始對話時可以選擇的人設的功能。想提議適合作品世界的主角時使用。不建立也沒關係。

如果建立了，四個欄位都要填滿才能完成製作。

- **名稱**：最多 20 字
- **性別**：女性、男性
- **出生日期**：必須年滿 14 歲
- **詳細資訊**：寫下性格、背景、說話方式，讓 AI 知道如何對待使用這個人設對話的使用者。最多 1,000 字

</ScreenStep>

## 遇到問題時

<details>
<summary>點了套用變更，其他人的畫面卻沒有馬上更新</summary>

如果作品還在審查中，要等審查完成後才會公開。如果是已經通過的作品，套用變更後會立刻生效。請試著重新整理作品畫面。

</details>

<details>
<summary>已公開的作品裡，儲存草稿按鈕不見了</summary>

已完成製作的作品只用**套用變更**一個按鈕來儲存。這是為了避免修改到一半的內容被公開。

</details>

<details>
<summary>內容管理裡有兩個相同的作品</summary>

如果重設作品製作畫面後又重新做了一次，先前做的草稿會以**製作中**的狀態留著。用**編輯**開啟確認，不需要的草稿用 **⋮ → 刪除**刪掉。

</details>
