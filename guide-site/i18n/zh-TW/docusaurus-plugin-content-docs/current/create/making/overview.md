# 認識專家模式

專家模式是**自己撰寫 AI 讀取的設定與輸出規則**的方式。作品製作畫面的七個分頁，分別負責 **AI 讀取的設定**和**使用者看到的畫面**。先在這一頁掌握整體樣貌，再前往[建立第一個作品](/create/first-work)。

和簡易模式有什麼不同、該選哪一種，請見[開始之前](/create/before-you-start)。

## 用專家模式開啟

點選下方選單的**建立**，再在**基本資訊**分頁最上方的**創作模式**點選**專家模式**。第一次選擇時會跳出說明視窗。網頁版與 App 的畫面配置相同。

<ScreenStep src="/img/screens/zh-TW/create-overview.webp" alt="作品製作畫面的上方。分頁列與重設、儲存草稿、完成製作按鈕上標有編號" caption="作品製作畫面的上方">

1. **分頁列**：基本資訊 · 素材 · 元件 · 提示詞 · 開場 · 設定集 · 其他設定。順序沒有限制，想從哪個分頁開始寫都可以。
2. **↺（重設建立內容）**：清空正在輸入的內容，從頭重新開始。已經儲存的草稿會留在**內容管理**。
3. **儲存草稿**：把目前寫的內容存成草稿。
4. **完成製作**：檢查有沒有缺漏的項目，完成作品。如果有缺漏，會切換到該分頁告訴你。

</ScreenStep>

## 七個分頁的作用

| 分頁 | 要寫什麼 | 誰會讀 |
| --- | --- | --- |
| **基本資訊** | 作品標題、一句話簡介、封面、詳細說明、類型、標籤 | 使用者（作品介紹畫面） |
| **素材** | 要顯示在對話中的圖片，以及為每張圖片加上的代碼 | 使用者（對話畫面） |
| **元件** | 狀態視窗、選項等在對話中彈出的 UI | 使用者（對話畫面） |
| **提示詞** | 世界觀、角色、隱藏設定、進行規則，以及何時使用圖片與元件 | AI（每次回覆時） |
| **開場** | 對話開始時 AI 先傳出的第一則訊息 | 使用者與 AI（對話的第一個場景） |
| **設定集** | 只在對話中出現特定詞語時才傳給 AI 的設定 | AI（出現關鍵字時） |
| **其他設定** | 公開設定、作品公開範圍、讀者群、內容分級等管理項目 | MYMI（分類與公開範圍） |

:::info[寫在基本資訊的文字不會傳給 AI]
就算在詳細說明裡把角色介紹寫得很仔細，AI 也不會讀。AI 需要知道的設定，請寫在**提示詞**分頁。可以把「給作品介紹畫面看的文字」和「給 AI 的文字」想成分開準備的兩份內容。
:::

## 最小的作品需要什麼

沒有圖片、元件、設定集，也可以完成作品。必要的只有下面這些。

- **基本資訊**：作品標題、一句話簡介、1 張封面、詳細說明、1～2 個類型、至少 1 個標籤
- **提示詞**：基本型的作品資訊，或自行撰寫的提示詞
- **開場**：1 個有標題和內容的開場
- **其他設定**：作品公開範圍、收益限制、圖片來源、讀者群、同意行銷使用。公開設定和內容分級一開始就選好了公開與全年齡。

封面可以上傳你已有的圖片，或是把在**素材**分頁做好的圖片帶過來使用。素材之後再加也可以。

## 何時會儲存

- 草稿有變更時，會在**切換分頁時**自動儲存。
- 第一次上傳或生成封面、素材圖片時，會先儲存需要的草稿。不必先點選**儲存草稿**。
- 草稿儲存過一次之後，在**素材**分頁新增、刪除、移動圖片或更改代碼，都會立刻儲存。
- 打字時不會每打一個字就儲存。在同一個分頁寫很久的話，請點選**儲存草稿**。
- 如果同一部作品同時在電腦和手機兩個地方開啟並修改，會保留後儲存的那一邊的內容。想換到其他裝置繼續修改，請先在原本的裝置點選**儲存草稿**（已完成製作的作品是**套用變更**），再到另一台裝置的**個人檔案 → 內容管理**點選**編輯**開啟。
- 已完成製作的作品沒有**儲存草稿**。修改的內容必須點選**套用變更**才會生效。詳情請見[公開與修改](/create/publish)。

:::warning[關閉畫面之前]
自動儲存會在切換分頁和開始處理圖片時進行。如果在同一個分頁寫到一半就關閉畫面，最後寫的內容可能不會保留。登出或改用其他帳號登入時，尚未儲存的內容會被清除。
:::

## 如果你有用簡易模式建立的作品

用簡易模式建立的作品，從**內容管理 → 編輯**開啟時，會以簡易模式開啟。作品建立時的模式無法更改，所以不會變成專家模式。想把設定移到新作品，請見[移到專家模式](/create/simple/to-expert)。

## 本指南的範例作品

專家模式的說明會跟著範例作品**地下城市首爾**進行。它的設定與作品製作畫面中的作品資訊範例相同。作品的介紹和圖片在[開始之前](/create/before-you-start#本指南的範例作品)。範例圖片的製作方法請見[準備圖片](/create/images)。

## 遇到問題時

<details>
<summary>要生成圖片時顯示「需要身分驗證才能生成 AI 圖片。」</summary>

作品製作的圖片生成是免費的，但只有完成手機號碼驗證的帳號才能使用。無法在作品製作畫面開始驗證，請這樣做：

1. 點選右上角的**儲存草稿**（已完成製作的作品是**套用變更**）儲存作業。
2. 在**個人檔案 → 簽到**點選**簽到並領取 Sparks**，完成手機號碼驗證。
3. 從**個人檔案 → 內容管理**重新開啟作品，再生成圖片。

只是上傳自己已有的圖片，不需要驗證。驗證方法請見[年齡確認與手機號碼驗證](/account/adult-verification)。

</details>

<details>
<summary>一定要依序把每個分頁都填完嗎？</summary>

不用。分頁想從哪個開始寫都可以，必填項目會在你點選**完成製作**時一次檢查。

</details>

<details>
<summary>用專家模式建立的作品，可以改成簡易模式嗎？</summary>

沒有這個功能。作品建立時的模式不會改變。想用簡易模式重做，請把創作模式選為**簡易模式**並建立新作品，再把寫在提示詞裡的設定抄到世界觀、角色、秘密欄位。圖片也需要重新用情境說明整理。（[認識簡易模式](/create/simple/overview)）

</details>

<details>
<summary>提示詞分頁的「基本型」與「自行撰寫」，和創作模式不一樣嗎？</summary>

不一樣。**基本型**與**自行撰寫**是在提示詞分頁裡選擇的撰寫方式，而**簡易模式**與**專家模式**是製作作品的整體方式。在專家模式中，兩種撰寫方式都可以使用。（[撰寫提示詞](/create/prompt)）

</details>
