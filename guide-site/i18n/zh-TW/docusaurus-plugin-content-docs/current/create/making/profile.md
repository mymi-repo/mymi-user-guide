# 美化作品介紹

使用者在挑選作品前看到的，是**基本資訊**分頁的內容。填好封面、詳細說明、創作者指南和推薦模型，就能完成作品介紹畫面。寫在這裡的文字不會傳給 AI。

## 封面

封面可以放 1～10 張。有多張時，會依設定的間隔切換到下一張。

<ScreenStep>

- **上傳圖片**：上傳你已有的圖片。可使用 JPG、PNG、WEBP、GIF、HEIC 檔案，最大 5MB。
- **從素材選取**：把在**素材**分頁做好的圖片當作封面。
- **切換間隔**：切換到下一張的時間。每點一次按鈕會增減 0.5 秒，直接輸入時請輸入 0.5 秒到 60 秒之間的值。

點選縮圖上的 **×** 按鈕，就會移除該封面。

</ScreenStep>

<ScreenStep>

點選**從素材選取**，會顯示素材分頁中所有已完成的圖片。選好要當封面的圖片，點選**將 N 張加入封面**。

素材分頁還沒有圖片的話，清單是空的。請先到[準備圖片](/create/images)製作。

</ScreenStep>

:::tip[挑選封面]
封面是作品列表中最先看到的圖片。第一張請放能清楚看到主角臉部的直式圖片。有多張時，也可以為每個人物各放一張來介紹登場人物。
:::

## 詳細說明

**詳細說明**是作品介紹畫面的本文。最多 50,000 字，可以混用一般文字、Markdown、HTML。

<ScreenStep>

1. **預覽**：確認使用者看到的樣子。
2. **複製素材資訊**：複製素材分頁圖片的實際網址。貼到 Gem 裡，就能做出使用那些圖片的介紹。
3. **開啟 Gem**：在 Google Gemini 開啟 MYMI 準備的 Gem。

</ScreenStep>

<ScreenStep>

在預覽中，Markdown 的標題、清單、粗體會依格式顯示。

介紹依照這個順序寫，讀起來會比較順。

1. 一兩句話的作品摘要
2. 世界觀與開場狀況
3. 登場人物介紹
4. 玩法（可以試著做什麼）

</ScreenStep>

### 用 Gem 製作介紹頁

不懂 HTML 也沒關係，可以一邊和 Gem 對話，一邊做出美化過的介紹頁。

1. 如果素材分頁有圖片，先點選**複製素材資訊**。完全沒有完成的圖片時，這個按鈕無法點選。
2. 點選**開啟 Gem**，在第一則訊息簡單介紹作品，並貼上複製的素材資訊後送出。
3. Gem 會用編號詢問你想要的氣氛、結構，以及作品使用的語言等。可以從範例答案中挑選，也可以自己回答。
4. Gem 整理出規格後，確認無誤再請它製作。完成的程式碼請整個程式碼區塊一起複製。
5. 把複製的程式碼貼到**詳細說明**欄，用**預覽**確認。有想修改的地方就告訴 Gem，再把整段重新貼上。

:::tip[使用 Gem 時]
- 如果 Gem 在第一次回覆時，請你把模型換成 **Gemini Flash** 或 **Pro**，請照做。用其他模型時，結果常常會跑掉。
- 想一邊看結果一邊修改，請在 Gemini 輸入框下方開啟 **＋ → Canvas** 再提出要求。
- 不貼素材資訊也能製作。貼上的話，會做出放入實際圖片的介紹。
:::

:::info
Gem 是 MYMI 之外的 Google 服務。使用時可能需要 Google 帳號，結果會依你和 Gem 的對話而不同。
:::

:::warning[刪除圖片之前]
用素材資訊做出的 HTML 會包含圖片的實際網址。如果在素材分頁刪除那張圖片，介紹頁上的圖片也會無法顯示。
:::

## 創作者指南

<ScreenStep>

**創作者指南**要寫作品的玩法或新增的內容。它會另外顯示在作品介紹畫面。一則內容最多可寫 5,000 字。

修改目前的內容，就是修改那一則。點選**寫新內容**，目前的內容會加上版本號（V1、V2…）和日期移到下方清單，並可以寫新的內容。

</ScreenStep>

> 範例：一開始先問民宇「這裡是哪裡？」。有關記憶的問題問書妍，就能一條一條獲得線索。

## 推薦模型

<ScreenStep>

可以先選好最多 5 個適合這部作品的聊天模型。它們在作品介紹畫面和聊天的模型清單中會標示為**推薦**，使用者仍然可以選擇其他模型。

點選**選擇**，會開啟與聊天畫面相同的模型清單。

</ScreenStep>

## 類型與標籤

- **類型**：選 1～2 個。從浪漫、BL、GL、奇幻、武俠、科幻、動作・冒險、日常、劇情、喜劇、懸疑・驚悚、恐怖、歷史・古裝中挑選。
- **標籤**：至少加入 1 個。簡短寫下作品的題材或氣氛。例：`地下城市`、`失憶`、`反烏托邦`
- **讀者群**（男性向、女性向）要在**其他設定**分頁另外選擇。

## 遇到問題時

<details>
<summary>無法點選複製素材資訊按鈕</summary>

素材分頁要有完成的圖片才能複製。請先上傳或生成圖片，再點選一次。

</details>

<details>
<summary>貼上 HTML 之後，預覽和我想的不一樣</summary>

請確認 Gem 做的程式碼區塊是否從頭到尾完整複製。只貼上一部分，版面可能會跑掉。請再請 Gem 修改，然後把整段貼上。

</details>

<details>
<summary>封面最多可以放幾張？</summary>

最多 10 張。想再放的話，請先移除一張。

</details>
