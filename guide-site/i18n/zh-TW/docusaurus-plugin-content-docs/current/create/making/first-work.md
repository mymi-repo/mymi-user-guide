# 用專家模式建立第一個作品

沒有圖片或元件，也可以完成作品。這一頁會用**專家模式**跟著範例作品**地下城市首爾**，只填必要的欄位，一路做到**完成製作**。如果想要只填寫欄位的方式，請見[用簡易模式建立第一個作品](/create/simple/first-work)。

:::tip[事前準備]
- 要當封面的圖片 1 張（JPG、PNG、WEBP、GIF、HEIC · 最大 5MB）
- 寫有世界觀與角色的筆記。沒有的話，照著下面的範例寫也可以。
:::

| 順序 | 分頁 | 要填的內容 |
| --- | --- | --- |
| 1 | **基本資訊** | 作品標題、一句話簡介、封面、詳細說明、類型、標籤 |
| 2 | **提示詞** | 選擇基本型並寫作品資訊 |
| 3 | **開場** | 開場標題與第一則訊息 |
| 4 | **其他設定** | 選好五個必填項目 |
| 5 | 畫面上方 | **完成製作** |

## 1. 填寫基本資訊

點選下方選單的**建立**，會先開啟**基本資訊**分頁。在最上方的**創作模式**點選**專家模式**。第一次選擇時會跳出視窗，請點選**切換到專家模式**。（[開始之前](/create/before-you-start#選擇創作模式)）

<ScreenStep src="/img/screens/zh-TW/first-basic-top.webp" alt="基本資訊分頁填入作品標題與一行簡介，並放上一張封面的畫面" caption="基本資訊分頁上方">

1. 寫下**作品標題**。最多 30 字。
2. 寫下**一句話簡介**。這是和標題一起顯示在作品卡片上的句子。最多 40 字。
3. 點選**封面**的**上傳圖片**，放入一張圖片。至少要有 1 張封面。

</ScreenStep>

> 範例 — 作品標題：`地下城市首爾` · 一句話簡介：`失去記憶後醒來的地方，是被封鎖的地下城市的檢疫所。`

<ScreenStep src="/img/screens/zh-TW/first-basic-description.webp" device="part" alt="詳細說明欄以 Markdown 寫成的作品介紹" caption="詳細說明">

**詳細說明**要寫會顯示在作品介紹畫面上的內容。寫劇情、登場人物和玩法就可以了。可以使用一般文字、Markdown、HTML，最多 50,000 字。

點選右上角的**預覽**，可以確認使用者看到的樣子。

</ScreenStep>

這是詳細說明的範例。`##` 是大標題，`-` 是清單，用 `**` 包起來的文字會以粗體顯示。

```md
## 2031 年，被封鎖的地下城市首爾

地表受到污染後，人們搬進了由地鐵站與地下商街相連而成的地下城市。
你失去了所有記憶，在檢疫所的病床上睜開眼睛。

### 登場人物
- **姜民宇** — 地下城市的引路人。總愛開玩笑，卻像是知道一些關於你的事。
- **李書妍** — 檢疫所醫師。她懷疑你的失憶不是意外。

### 建議這樣玩
- 跟著民宇走出檢疫所，逛逛地下城市。
- 想找回記憶的話，就向書妍詢問線索。
```

<ScreenStep src="/img/screens/zh-TW/first-basic-genres.webp" device="part" alt="類型選了「科幻」與「懸疑、驚悚」，並加入三個標籤的畫面" caption="類型與標籤">

**類型**選 1～2 個。範例選的是**科幻**和**懸疑、驚悚**。

**標籤**至少加入 1 個。在欄位中輸入後點選**新增**，或按 Enter 就會加入。也可以用空格或逗號分隔，一次加入好幾個。

</ScreenStep>

**創作者指南**和**推薦模型**可以先空著。填寫方法請見[美化作品介紹](/create/profile)。

## 2. 撰寫提示詞

寫在**提示詞**分頁的文字，是 AI 每次產生回覆時都會讀取的設定。一開始用只要填欄位的**基本型**最輕鬆。

<ScreenStep src="/img/screens/zh-TW/first-prompt.webp" alt="在提示詞預設選擇基本型，並在作品資訊欄寫下世界觀與登場人物的畫面" caption="提示詞分頁 · 基本型">

1. 點選**提示詞預設**，選擇**基本型**。一開始選的是**自行撰寫**。
2. 在**作品資訊**欄寫下世界觀、登場人物、隱藏設定與進行規則。欄位空白時會顯示灰色範例，照著相同的樣式寫就可以。

右側的**合計 N / 10,000**，是這個分頁所寫文字的總和。

</ScreenStep>

這是作品資訊的範例。用 `####` 區分主題，項目寫成 `- **項目**: 值`。要指稱使用者時，寫 `{{user}}`。

```md
#### 世界觀
- **背景**: 2031 年，被封鎖的地下城市首爾。地表已受污染而遭棄置。
- **開場**: {{user}}失去記憶，在檢疫所醒來。

#### 登場人物
**姜民宇**
- **角色**: 地下城市的引路人，32 歲
- **性格**: 悠哉，愛開玩笑
- **語氣**: 不用敬語，句尾拖長
- **關係**: 知道{{user}}的真實身分，卻裝作不知道

**李書妍**
- **角色**: 檢疫所醫師，28 歲
- **性格**: 公事公辦、冷靜
- **語氣**: 簡短的敬語
- **關係**: 懷疑{{user}}的失憶並非意外

#### 隱藏設定
- 民宇接到監視{{user}}的命令，不會主動向使用者透露。
- {{user}}的記憶是管理局抹除的。

#### 進行規則
- 第一次對話時，民宇帶{{user}}走出檢疫所。
- 當{{user}}試圖找回記憶時，書妍會一次給一條線索。
```

<ScreenStep src="/img/screens/zh-TW/first-prompt-composed.webp" device="part" alt="組合後的提示詞欄，作品資訊已整合在一起的畫面" caption="分頁下方組合後的提示詞">

分頁最下方的**組合後的提示詞**，會顯示把欄位內容合併後傳給 AI 的樣子。修改欄位，這裡也會跟著改變。

加入素材與元件之後，**圖片輸出規則**與**元件輸出規則**會出現可以寫含義的欄位，寫的內容也會合併到這裡。

</ScreenStep>

:::tip[設定要簡短、清楚]
為每個人物各用一行分開寫角色、性格、語氣、關係，AI 就不容易搞混人物。不能主動告訴使用者的事放在**隱藏設定**，故事要怎麼帶領則寫在**進行規則**。更詳細的方法請見[撰寫提示詞](/create/prompt)。
:::

## 3. 撰寫開場

開場是對話開始時 AI 先傳出的第一則訊息。

<ScreenStep src="/img/screens/zh-TW/first-greeting.webp" alt="在開場分頁寫下標題與第一則訊息的畫面" caption="開場分頁">

1. 寫下**開場標題**。這是使用者選擇開始場景時看到的名稱。
2. 在下方欄位寫下第一則訊息。最多 2,000 字。動作與敘述放在 `*星號*` 之間，對話放在 `"雙引號"` 內，就會以與聊天相同的樣式顯示。

</ScreenStep>

```md
*日光燈閃爍的檢疫所。消毒水的氣味之中，有人拉開了簾子。*

"哦，終於醒了～你整整睡了三天耶？"

*一名穿著舊軍裝外套的男子轉著手電筒笑了起來。他自稱是引路人姜民宇。*

"這裡是首爾。更正確地說，是首爾的地底～所以，{{user}}。除了名字，你還記得什麼嗎？"
```

<ScreenStep src="/img/screens/zh-TW/first-greeting-preview.webp" device="part" alt="開場預覽。敘述以斜體、對白以強調色顯示" caption="開場預覽">

在欄位下方的**預覽**確認聊天中的樣子。

開場裡的 `{{user}}`，在對話時會換成使用者的名字。預覽中則會照原樣顯示。

</ScreenStep>

## 4. 選擇其他設定

在**其他設定**分頁，把標有紅色 `*` 的項目全部選好。**公開設定**（公開）和**內容分級**（全年齡）一開始就已選好。

<ScreenStep src="/img/screens/zh-TW/first-settings-1.webp" alt="其他設定分頁上方。公開設定、作品公開範圍、收益限制" caption="其他設定分頁上方">

- **公開設定**：**公開**是所有使用者都能看到，**不公開**是只有自己能看到。
- **作品公開範圍**：**原創**是只在 MYMI 公開的作品。如果也要上傳到其他平台，就選**一般**。選擇原創時會顯示「設定為原創後，3個月內無法解除。」的提示。
- **收益限制**：使用其他作品角色或世界觀的二次創作等，權利不屬於自己的作品，請選**限制收益**。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/first-settings-2.webp" alt="其他設定分頁下方。圖片來源、讀者群、內容分級、同意行銷使用" caption="其他設定分頁下方">

- **圖片來源**：圖片是在 MYMI 做的就選 **MYMI 生成**，用其他 AI 製作或親自繪製的就選**外部製作**。
- **讀者群**：從**男性向**、**女性向**中選出作品主要面向的讀者。
- **內容分級**：**成人限定**只有完成年齡確認的使用者才能使用。它也會影響對話內容與生成的圖片。
- **同意行銷使用**：同意的話，MYMI 可以把這部作品用在廣告、社群等行銷素材上。

</ScreenStep>

每個選項代表什麼意思，請見[選擇作品設定](/create/settings)的詳細說明。

最下方的**推薦人設**是選填。在[公開與修改](/create/publish#推薦人設)中說明。

## 5. 完成製作

點選畫面上方的**完成製作**。如果有缺漏的項目，會切換到該分頁，並在上方顯示提示。

<ScreenStep src="/img/screens/zh-TW/create-publish-check.webp" alt="因為作品標題是空的，畫面上方出現‘請輸入作品標題。’提示" caption="有欄位缺漏時">

提示一次只會顯示一個。照著提示補齊後，再次點選**完成製作**。

檢查的順序是基本資訊 → 素材 → 元件 → 提示詞 → 開場 → 設定集 → 其他設定。完整清單請見[限制與規則一覽](/create/limits#完成製作時檢查的項目)。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/first-complete.webp" alt="作品製作完成畫面。作品卡片下方有審查中標示，以及查看作品與作品管理按鈕" caption="作品製作完成畫面">

全部填好之後，會開啟**作品製作完成**畫面。

- 設為公開的作品會是**審查中**。你現在就可以直接聊天，其他使用者則要等審查完成後才看得到。
- 點選**查看作品**直接試著聊聊，看到想修改的地方，就在**內容管理**點選**編輯**。

</ScreenStep>

## 遇到問題時

<details>
<summary>點了完成製作，卻跳到其他分頁</summary>

這表示系統切換到有缺漏項目的分頁了。請看上方顯示的提示並補齊。基本資訊常漏掉封面、詳細說明、標籤，其他設定則常漏掉**作品公開範圍**、**收益限制**、**圖片來源**、**讀者群**、**同意行銷使用**。

</details>

<details>
<summary>我已經輸入標籤，卻顯示「請新增至少一個標籤。」</summary>

只在欄位中輸入並不會加入。請點選**新增**或按 Enter，讓標籤顯示在欄位下方。

</details>

<details>
<summary>顯示「請輸入作品資訊。」</summary>

基本型的**作品資訊**欄是空的。灰色的範例不是你輸入的內容，請直接在欄位中寫。

</details>

<details>
<summary>AI 不知道我寫在詳細說明裡的角色設定</summary>

詳細說明是給使用者看的介紹，不會傳給 AI。AI 需要知道的設定，請寫在**提示詞**分頁的作品資訊中。

</details>
