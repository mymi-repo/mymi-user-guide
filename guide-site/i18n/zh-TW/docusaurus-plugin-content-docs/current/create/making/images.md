# 準備圖片

要顯示在對話中的圖片，在**素材**分頁準備。可以上傳你已有的圖片，也可以在 MYMI 免費生成。為每張圖片加上代碼之後，就能在提示詞和開場中用那個代碼叫出圖片。

:::info[圖片生成免費，但需要手機號碼驗證]
作品製作中的圖片生成與重新生成都是免費的。要生成的話，帳號必須已完成[手機號碼驗證](/account/adult-verification)。只是上傳圖片的話，不需要驗證。
:::

:::info
這是專家模式的說明。簡易模式請見[素材與 AI 圖片](/create/simple/assets)。
:::

## 素材分頁的樣子

<ScreenStep src="/img/screens/zh-TW/assets-overview.webp" alt="素材分頁。資料夾外的圖片 BG1，以及角色資料夾 A 內的圖片 1・2・3" caption="素材分頁">

- **一個資料夾就是一個角色**。資料夾名稱（例：`A`）就是**角色代碼**。
- 資料夾裡圖片的代碼（例：`1`）是**情境代碼**。這張圖片的路徑是 `A/1`。
- 資料夾外的圖片（例：背景 `BG1`）用**其他代碼**叫出。
- 指定代碼後，列的下方會顯示像 `![]({{URL}}/A/1.webp)` 這樣的一行。把這一行寫進提示詞或開場，該位置就會顯示圖片。

</ScreenStep>

代碼只能使用英文與數字，同一個資料夾內不能重複。資料夾只能建立一層。

<ScreenStep src="/img/screens/zh-TW/assets-help.webp" device="part" alt="展開素材是如何運作的？說明的畫面" caption="素材是如何運作的？">

點選分頁上方的<strong>素材是如何運作的？</strong>，可以展開閱讀代碼與路徑、角色資料夾與基本形象、生成與等待、共用情境代碼、鎖定與解鎖的說明。

</ScreenStep>

範例作品是這樣準備的。

| 路徑 | 圖片 | 代碼的含義 |
| --- | --- | --- |
| `A` 資料夾 | 姜民宇 | 角色代碼 A |
| `A/1`、`A/2`、`A/3` | 民宇的笑、悲傷、憤怒 | 情境代碼 1・2・3 |
| `B` 資料夾 | 李書妍 | 角色代碼 B |
| `B/1`、`B/2` | 書妍的笑、悲傷 | 情境代碼 1・2（沒有 B/3） |
| `BG1` | 檢疫所走廊 | 其他代碼 BG1 |

## 上傳你已有的圖片

1. 要放在資料夾外的圖片，點選分頁下方的**上傳圖片**；要放進角色資料夾的圖片，點選該資料夾裡的**上傳圖片**。
2. 選擇圖片。可以一次上傳多張。可使用 JPG、PNG、WEBP、GIF、HEIC 檔案，最大 5MB。
3. 在上傳好的每一列填寫**代碼**。

## 建立角色資料夾與基本形象

要為同一個人物製作多張圖片時，先建立**基本形象**。基本形象是資料夾的臉。在該資料夾生成的圖片，會繼承基本形象的畫風與印象。

<ScreenStep src="/img/screens/zh-TW/assets-folder-empty.webp" alt="剛建立角色資料夾 A 的畫面。資料夾名稱旁有生成角色按鈕" caption="新的角色資料夾">

1. 點選**新增角色資料夾**，寫下角色代碼（例：`A`）。
2. 點選資料夾名稱旁的 **✦ 生成角色**。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/assets-gen-kind.webp" alt="建立基本形象的第 1 步。圖片種類選了角色，性別選了男性" caption="第 1 步 · 種類與性別">

3. 在<strong>是什麼樣的圖片？</strong>選擇**角色**。沒有人物的地點是**背景**。
4. 如果是角色，從**女性**、**男性**選擇性別後，點選**下一步**。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/assets-gen-style.webp" alt="選擇畫風的步驟。在推薦風格清單中選了第一個" caption="第 2 步 · 畫風">

5. 選擇**畫風**。
   - **推薦風格**：MYMI 準備好的畫風。第一次的話，從這裡選。
   - **我的風格**：你先前儲存的畫風。
   - **直接撰寫**：用提示詞直接寫出畫風。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/assets-gen-tags.webp" alt="在頭髮步驟選了短髮（黑色）與凌亂頭髮的畫面。上方聚集了所選的標籤" caption="第 3 步起 · 選擇標籤">

6. 依照**背景** → **身體 - 髮型** → **身體 - 眼睛** → **身體 - 臉部特徵** → **身體 - 膚色** → **身體 - 體型** → **服裝** → **道具** → **其他**的順序選擇標籤。選好的標籤會聚集顯示在上方。不需要的步驟用**下一步**跳過。
   - 髮型、眼睛、服裝的標籤中，還沒決定顏色的（例：短髮），點選後會開啟選擇顏色的視窗。點選顏色，不想指定顏色的話，就點選**已包含此顏色**。
   - 可以在<strong>搜尋標籤...</strong>欄找想要的標籤。

</ScreenStep>

:::info[標籤名稱可能顯示為英文]
搜尋到的標籤等，沒有繁體中文名稱的標籤可能會以英文顯示。選擇方式不變，標籤會轉換成英文提示詞。
:::

<ScreenStep src="/img/screens/zh-TW/assets-gen-confirm.webp" alt="確認並生成步驟。指定角色、畫風、所選標籤與 char_prompt 欄，以及生成基本形象按鈕" caption="最後一步 · 確認並生成">

7. 在**確認並生成**檢查選好的標籤。標籤會轉成英文提示詞，放進 **char_prompt - 最終編輯**欄。這個欄位也可以直接修改。
8. 點選**生成基本形象**。生成完成後，資料夾名稱旁會顯示基本形象。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/assets-gen-expert.webp" alt="展開專家模式的畫面。negative_prompt、guidance、steps、sampler、noise_schedule、圖片尺寸" caption="專家模式">

展開**專家模式**，可以更改不要出現的元素（`negative_prompt`）、生成設定（guidance、steps、sampler、noise_schedule）和圖片尺寸。不確定的話，保持原樣就好。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/assets-base-sheet.webp" alt="A 的基本形象視窗。基本形象圖片與標籤，以及編輯提示詞、加為圖片、重新生成按鈕" caption="基本形象視窗">

點選資料夾的基本形象，就會開啟這個視窗。

- **編輯提示詞**：修改標籤與提示詞。
- **重新生成**：用相同設定重新製作。
- **加為圖片**：把基本形象本身也加成資料夾內的圖片。加上代碼，在對話中也能使用。

</ScreenStep>

:::tip[範例作品的標籤]
民宇是用男性推薦風格，加上棕色凌亂短髮、垂眼、軍裝外套、手電筒這類標籤做成的。書妍是用女性推薦風格，再加上醫院・室內・地下的背景標籤，並在專家模式的 `negative_prompt` 填入 `simple background, white background`。這是某些畫風的背景只會出現純白時使用的方法。
:::

## 在資料夾裡製作更多圖片

<ScreenStep src="/img/screens/zh-TW/assets-mode.webp" alt="角色資料夾 A 的生成圖片視窗。有繼承基本形象（推薦）與從頭製作" caption="資料夾的 ✦ 生成">

點選資料夾裡的 **✦ 生成**，選擇製作方式。

- **繼承基本形象**（推薦）：畫風與樣貌維持不變，只選表情・姿勢・背景。
- **從頭製作**：重新選擇種類、性別、畫風、標籤。

沒有基本形象的資料夾，則從**先生成角色**和**只生成這張圖片**中選擇。

</ScreenStep>

在最後一步點選**立即生成**會馬上製作，點選**加入等待清單**則之後再一次製作。代碼可以在生成前先決定。

## 為多個人物製作相同的情境：共用情境代碼

像「笑」、「悲傷」這種所有人物都需要的情境，用**共用情境代碼**一次準備好。

<ScreenStep src="/img/screens/zh-TW/assets-situations.webp" alt="共用情境代碼視窗。列出代碼 1、2、3（微笑・上半身、悲傷・上半身、生氣・上半身），各有套用按鈕" caption="✦ 情境代碼">

1. 點選分頁右上角的 **✦ 情境代碼**。
2. 用**新增情境代碼**決定代碼（例：`1`）和表情、姿勢等標籤。
3. 點選做好的情境代碼旁的**套用**。

</ScreenStep>

<ScreenStep src="/img/screens/zh-TW/assets-situation-apply.webp" alt="套用情境代碼 3 的視窗。資料夾 A 已經有 3 所以顯示為淡色，選了資料夾 B" caption="套用情境代碼">

4. 選擇要套用的角色資料夾。已經有相同代碼的資料夾無法選擇。
5. 點選**套用到 N 個角色**，每個資料夾就會產生像 `A/3`、`B/3` 這樣的**空白格**。

空白格要上傳圖片或生成來填入。生成時，會在各資料夾的基本形象上疊加情境標籤來製作。基本形象也可以在套用之後再建立。

</ScreenStep>

## 一次生成：等待清單

<ScreenStep src="/img/screens/zh-TW/assets-queue.webp" alt="生成圖片視窗。勾選了等待中的 A/4，並有生成已選的 1 張按鈕" caption="生成等待清單">

如果有加入等待清單的圖片或空白格，分頁上會顯示**查看等待生成的 N 張**（有空白格的話，會一起顯示**空白格 N 個**）。

1. 點選後開啟**生成圖片**視窗。
2. 勾選要製作的圖片，點選**生成已選的 N 張**。一次最多可以要求 50 張。
3. 生成中的列會顯示狀態，完成後各列就會填入圖片。

</ScreenStep>

## 管理單張圖片

<ScreenStep src="/img/screens/zh-TW/assets-image-sheet.webp" alt="圖片設定視窗。預覽、編輯提示詞・重新生成、位置、Markdown、需要解鎖開關、儲存・刪除圖片" caption="圖片設定視窗">

點選圖片縮圖，會開啟設定視窗。

- **編輯提示詞** / **重新生成**：如果是生成的圖片，可以修改後重新製作。
- **位置**：移出資料夾，或放進資料夾。無法從一個角色資料夾移到另一個角色資料夾。
- **需要解鎖**：開啟並點選**儲存**後，在作品介紹畫面的圖片清單中會被模糊遮住，等聊天中出現這張圖片時，才會為該使用者解鎖。
- **刪除圖片**：從作品中刪除這張圖片。

</ScreenStep>

## 完成製作前要確認的事

- 所有圖片都要有代碼。代碼只能用英文與數字，同一個資料夾內不能重複。
- 沒有圖片的空白格和等待生成的列，要填好或刪除。
- 決定要建立基本形象的資料夾，基本形象圖片也必須完成。
- 如果用基本型提示詞，要為每個代碼寫下含義。接下來在[在對話中顯示圖片](/create/images-in-chat)繼續說明。

:::warning[公開後修改素材時]
已完成製作的作品無法更改資料夾名稱（角色代碼）。可以更改代碼、新增代碼、替換圖片。素材的變更不必等**套用變更**，會立刻反映到作品上。

在已公開的作品中更改代碼或刪除圖片，使用過那張圖片的既有對話也會無法顯示該圖片。要替換圖片時，請保留代碼，只替換圖片。寫在提示詞和開場的路徑不會自動修正，請一併確認。
:::

## 遇到問題時

<details>
<summary>顯示「需要身分驗證才能生成 AI 圖片。」</summary>

只有完成手機號碼驗證的帳號才能生成。無法在作品製作畫面開始驗證，請這樣做：

1. 點選右上角的**儲存草稿**（已完成製作的作品是**套用變更**）儲存作業。
2. 在**個人檔案 → 簽到**點選**簽到並領取 Sparks**，完成手機號碼驗證。
3. 從**個人檔案 → 內容管理**重新開啟作品，再生成圖片。

只是上傳圖片，不需要驗證。

</details>

<details>
<summary>顯示「有代碼還沒有圖片。」</summary>

還留有用共用情境代碼做出的空白格，或等待生成的列。用**查看 N 個空白格**確認後，生成或刪除。如果某個人物不需要那個情境，就刪除那一格，並寫在基本型提示詞的**例外**（例：`無 B/3`）。

</details>

<details>
<summary>想把圖片移到其他角色資料夾</summary>

角色資料夾之間無法移動。移出資料夾的圖片，可以再放回資料夾。有需要的話，在想移過去的資料夾重新上傳或生成圖片。

</details>

<details>
<summary>無法關閉安全篩選開關</summary>

標籤步驟右上角的安全篩選，只有完成年齡確認的帳號才能關閉。

</details>
