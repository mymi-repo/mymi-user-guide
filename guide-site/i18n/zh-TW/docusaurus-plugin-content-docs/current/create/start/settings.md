# 選擇作品設定

這些設定決定作品如何公開，以及獲得 Leaf 的條件。在**其他設定**中選擇，簡易模式與專家模式使用相同的卡片。

- 簡易模式：**設定**步驟。上方有**類型**與 **Hashtag**，下方接著本頁的卡片。
- 專家模式：**其他設定**分頁。**類型**與**標籤**在**基本資訊**分頁。

標有紅色 `*` 的卡片一定要選。**公開設定**與**內容分級**一開始就選好了，其餘的要自己選，才能完成作品。

## 一覽

| 卡片 | 選項 | 初始值 |
| --- | --- | --- |
| **公開設定** | 公開 · 不公開 | 公開 |
| **作品公開範圍** | 原創 · 一般 | 未選擇 |
| **收益限制** | 無限制 · 限制收益 | 未選擇 |
| **圖片來源** | MYMI 生成 · 外部製作 | 未選擇 |
| **讀者群** | 男性向 · 女性向 | 未選擇 |
| **內容分級** | 全年齡 · 成人限定 | 全年齡 |
| **同意行銷使用** | 同意 · 不同意 | 未選擇 |

## 公開設定

決定要讓誰看到作品。

- **公開**：所有使用者都能看到。設為公開的新作品，要經過審查，其他使用者才看得到。
- **不公開**：只有你自己能看到。公開之前，想先試聊時使用。

之後可以在**個人檔案 → 內容管理 → 編輯**的**其他設定**中更改。把不公開的作品改成公開，從那時起開始審查。（[公開與修改](/create/publish#把不公開的作品改成公開)）

## 作品公開範圍

- **原創**：僅在 MYMI 公開的作品。可以獲得較高的 Leaf 比率。
- **一般**：也可以在其他平台公開的作品。

:::warning[原創在 3 個月內無法解除]
選擇原創時，會出現「設定為原創後，3個月內無法解除。」的提示。規則是從設定的那天起 3 個月內，不能改回**一般**。如果打算也在其他平台發布，請選擇**一般**。

在簡易模式中，設定後的 3 個月內卡片會被鎖定，並顯示距離解除還剩幾天。
:::

## 收益限制

- **無限制**：你擁有權利的創作。
- **限制收益**：像使用其他作品的角色或世界觀的二次創作這樣，權利不屬於你的作品。

選了**限制收益**的作品，不會累積 Leaf。就算是原創作品，或官方創作者的作品也一樣。更改後，從下一次聊天開始套用。

## 圖片來源

選擇作品的圖片是怎麼製作的。

- **MYMI 生成**：用 MYMI 的圖片生成製作的圖片。
- **外部製作**：用其他 AI 製作，或親自繪製的圖片。

**一般**作品的 Leaf 比率，會依圖片來源而不同。比率請見[成為創作者與 Leaf](/creator-support/support#獲得-leaf)。如果作品不使用圖片，請選擇實際使用的那一種。

## 讀者群

選擇作品主要面向哪種讀者，**男性向**或**女性向**。

## 內容分級

會影響對話內容與生成的圖片。

- **全年齡**：任何人都可以使用。
- **成人限定**：只有完成成人驗證的使用者才能使用。（[年齡確認與手機號碼驗證](/account/adult-verification)）

已經公開的作品，如果把分級從成人限定改成全年齡，會再次接受審查。

## 同意行銷使用

- **同意**：MYMI 可以把這部作品用於廣告、社群等行銷。曝光增加，對話量自然增加，Leaf 收益也可能增加。
- **不同意**：不會用於行銷。

## 只有簡易模式才有的卡片：圖片輸出指示

簡易模式的**設定**步驟裡還有一張**圖片輸出指示**卡片。它決定 AI 在對話中如何輸出圖片。

- **內部圖片**：使用上傳到素材的圖片。一開始就選好了。
- **外部圖片**：使用你寫在設定裡的圖片網址（URL）。

只能使用其中一種。詳情請見[素材與 AI 圖片](/create/simple/assets#圖片輸出指示)。專家模式沒有這張卡片，圖片規則要自己寫在提示詞裡。

## 遇到問題時

<details>
<summary>選了原創，現在想改成一般</summary>

規則是設定為原創之後，3 個月內無法解除。在簡易模式中，卡片會被鎖定，並顯示距離解除還剩幾天。3 個月過後就能改成**一般**。

</details>

<details>
<summary>不知道該不該選限制收益</summary>

如果作品是用你自己創作的角色與世界觀寫成，請選**無限制**。如果像拿其他作品的角色或世界觀來寫的二次創作這樣，權利不在你身上，請選**限制收益**。難以判斷時，請透過[聯絡我們](/faq#聯絡我們)詢問。

</details>

<details>
<summary>出現「請選擇作品公開範圍。」之類的提示</summary>

表示有卡片還沒選。提示一次只會出現一個，簡易模式在按下一步按鈕或**完成**按鈕時檢查，專家模式在點選**完成製作**時檢查。請選擇提示文字裡寫到的卡片。可能還有其他卡片沒選。

</details>

<details>
<summary>設成成人限定，其他使用者卻看不到</summary>

成人限定的作品，只會顯示給完成成人驗證的使用者。也請確認自己的帳號是否已通過驗證。（[年齡確認與手機號碼驗證](/account/adult-verification)）

</details>
