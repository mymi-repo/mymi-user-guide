# 開始之前

MYMI 的作品由 **AI 讀取的設定**和**使用者看到的畫面**組成。製作這兩部分的方式有兩種。只要填寫欄位就能完成的**簡易模式**，以及由你自己撰寫 AI 讀取設定的**專家模式**。新作品會從簡易模式開始。

## 選擇創作模式

點選下方選單的**建立**，就會開啟**建立作品**畫面。第一個分頁**基本資訊**的最上方，就是**創作模式**欄位。網頁版與 App 的畫面配置相同。

<ScreenStep src="/img/screens/zh-TW/mode-card.webp" alt="基本資訊分頁最上方的創作模式欄位。有簡易模式與專家模式兩個按鈕，目前選的是簡易模式" caption="創作模式欄位">

1. **簡易模式**：填好欄位，AI 設定就會自動產生。
2. **專家模式**：自己撰寫 AI 讀取的設定與輸出規則。

點選後模式會切換，並開啟所選模式的**基本資訊**分頁。第一次會選在簡易模式，之後則會以這台裝置上最後使用的模式開啟。

</ScreenStep>

## 兩種模式有什麼不同

| | 簡易模式 | 專家模式 |
| --- | --- | --- |
| 撰寫 AI 設定的地方 | **基本資訊**裡的世界觀、角色、秘密欄位。MYMI 會彙整後交給 AI | **提示詞**分頁。分欄撰寫的**基本型**，或整段寫下的**自行撰寫** |
| 圖片 | 為每張圖片寫下**情境說明**，並連結角色。AI 會看說明挑選合適的圖片 | 用資料夾與代碼整理，並在提示詞中寫下何時顯示 |
| 狀態視窗等元件 | 在每個元件的**使用描述**中寫下何時使用 | 寫在提示詞的**元件輸出規則**中 |
| 畫面 | 七個步驟。按下一步按鈕依序前進 | 七個分頁。想從哪個分頁開始寫都可以 |
| 儲存 | 每按一次下一步按鈕，就會儲存到作品 | 切換分頁時會自動儲存。有**儲存草稿**與**完成製作** |
| 修改已公開的作品 | 修改的內容在用下一步按鈕前往下一步的瞬間生效 | 要點選**套用變更**才會生效 |
| 一定要有的圖片 | 至少 1 張**素材**，以及用 ★ 選好的個人檔案圖片 1 張 | **封面** 1～10 張。素材可以沒有 |

兩種模式也有相同的地方。公開前的審查和內容管理都一樣，決定 Leaf 比率的**作品公開範圍**、**圖片來源**、**收益限制**等設定也一樣。選擇設定的方法請見[選擇作品設定](/create/settings)。

## 該選哪一種模式

適合**簡易模式**的情況：

- 第一次製作作品。
- 想從只把世界觀和角色寫進欄位開始。
- 圖片只要告訴 AI「這個場景用這張圖片」就夠了。

適合**專家模式**的情況：

- 想自己設計要交給 AI 的設定和進行規則。
- 想用規則精確決定圖片與元件何時出現。
- 想放入多張封面，或想在分頁之間自由來回作業。

這並不是說哪一種比較好。請依照你想怎麼製作作品來選擇。作品介紹畫面的配置會依模式而略有不同。

## 切換模式後，寫過的內容會怎麼樣

- 兩種模式的**草稿是分開的**。切換模式後，寫過的內容會留在原本的模式，不會移到另一個模式。再切換回來就能接著寫。
- **↺**（重設建立內容）只會清空目前模式的草稿。確認視窗會寫明要清空的是哪一個模式的草稿。
- 已儲存到伺服器的草稿，會以**製作中**的狀態留在**個人檔案 → 內容管理**。重設也不會刪除。

<ScreenStep src="/img/screens/zh-TW/mode-intro.webp" alt="要切換到專家模式嗎？視窗。列出自己撰寫提示詞、用代碼呼叫圖片、自由切換分頁三項，並有取消與切換到專家模式按鈕" caption="第一次選擇專家模式時">

**第一次**選擇專家模式時，會跳出一個視窗。閱讀說明後點選**切換到專家模式**就會切換。點選**取消**，模式維持不變。這個視窗只會看到一次。

視窗下方寫著「在簡易模式寫的內容會保留，不會移到專家模式。」

</ScreenStep>

:::tip[想保住寫過的內容，先儲存]
正在輸入的內容，在儲存到伺服器之前只存在這台裝置上。登出或改用其他帳號登入時，尚未儲存的內容會被清除。簡易模式請按下一步按鈕，專家模式請切換分頁或點選**儲存草稿**。儲存的時機依模式而不同，各模式的說明會再詳細介紹。
:::

## 從內容管理開啟的作品，模式會被鎖定

在**個人檔案 → 內容管理**點選作品的**編輯**，會以建立該作品時的模式開啟。這時創作模式欄位是鎖定的。

<ScreenStep src="/img/screens/zh-TW/mode-locked.webp" device="part" alt="被鎖定的創作模式欄位。專家模式按鈕上有鎖頭圖示，下方說明從內容管理開啟的作品無法切換模式" caption="從內容管理開啟的作品的創作模式欄位">

- 沒有更改已建立作品模式的功能。想用另一種模式重做，請建立新作品，再把設定抄過去。簡易模式的作品，可以參考[移到專家模式](/create/simple/to-expert)的做法。
- 想建立新作品時，點選 <strong>↺</strong> 清空編輯畫面。鎖定就會解除，可以重新選擇模式。內容管理中的作品會保留。

</ScreenStep>

如果目前模式的編輯畫面有**尚未儲存的內容**，又從內容管理開啟其他作品，會跳出確認視窗。點選**開啟**，尚未儲存的內容會消失，並開啟該作品。點選**取消**則什麼都不會改變。

## 遇到問題時

<details>
<summary>創作模式欄位的另一個按鈕出現鎖頭，按不下去</summary>

因為這是從內容管理開啟的作品。已建立作品的模式無法更改。想建立新作品，請點選 <strong>↺</strong> 清空編輯畫面，再選擇模式。內容管理中的作品不會被刪除。

</details>

<details>
<summary>切換到專家模式後，寫過的內容不見了</summary>

兩種模式的草稿是分開的。在簡易模式寫的內容不會移到專家模式，但也沒有消失。在創作模式欄位再點選一次**簡易模式**，內容還在。想把內容帶過去，請依照[移到專家模式](/create/simple/to-expert)自己抄寫過去。

</details>

<details>
<summary>跳出「要切換到專家模式嗎？」的視窗</summary>

這是第一次選擇專家模式時，只會出現一次的說明視窗。閱讀說明後點選**切換到專家模式**即可。如果還沒決定，點選**取消**，模式維持不變。

</details>

<details>
<summary>在內容管理點選編輯後，顯示「有尚未儲存的內容」</summary>

因為該模式的編輯畫面還留著其他作品或新作品尚未儲存的內容。點選**開啟**，那些內容會消失，並開啟你選的作品。想保留的話，請點選**取消**回到編輯畫面，先儲存。已儲存的草稿會以**製作中**的狀態在內容管理裡。

</details>

<details>
<summary>圖片建立視窗裡也有「專家模式」</summary>

生成圖片最後一步展開的**專家模式**，和創作模式是不同的功能。那是用來更改圖片生成設定（`negative_prompt`、guidance 等）的欄位，與作品的製作方式無關。兩種模式用的是同一個圖片生成視窗。

</details>

<details>
<summary>「基本型」與「自行撰寫」和簡易模式、專家模式不一樣嗎？</summary>

不一樣。**基本型**與**自行撰寫**是在專家模式的**提示詞**分頁中選擇的兩種撰寫方式。簡易模式沒有提示詞分頁。詳情請見[撰寫提示詞](/create/prompt)。

</details>

<details>
<summary>點了重設，製作到一半的作品不見了</summary>

重設只會清空作品製作畫面。已儲存的草稿會以**製作中**的狀態留在**個人檔案 → 內容管理**。點選**編輯**就能重新開啟。

</details>
