# 認識舊版製作方式（1.0）

以前作品是用七步驟的製作畫面建立的。這種方式稱為<strong>舊版製作方式（1.0）</strong>。新作品請從下方選單的**建立**，在目前的作品製作畫面建立。用 1.0 建立的作品，編輯時會開啟舊版畫面。

## 辨認你的作品是不是 1.0

<ScreenStep src="/img/screens/zh-TW/legacy-editor.webp" alt="舊版製作畫面。分頁列有基本資訊、素材、介紹、設定、Lorebook、Components，右下角有下一步按鈕" caption="修改 1.0 作品時開啟的畫面">

請在**個人檔案 → 內容管理**點選作品的**編輯**看看。

- 如果分頁列是**基本資訊 · 素材 · 介紹 · 設定 · Lorebook · Components · 選填**，且右下角有 **>**（下一步）按鈕，就是 1.0 作品。
- 如果分頁有**提示詞**，且上方有**儲存草稿**・**完成製作**（或**套用變更**），就是目前方式的作品。

</ScreenStep>

1.0 作品不會自動改成目前的方式。編輯的方法請見[編輯 1.0 作品](/create/legacy/edit)。

## 有哪些不同

最大的差異是**寫給 AI 的設定要寫在哪裡**。1.0 是在各欄位分開寫，再由 MYMI 彙整後傳出；現在則是在**提示詞**分頁自己組織。

| | 1.0 | 現在 |
| --- | --- | --- |
| 世界觀・角色・秘密 | 分別寫在**基本資訊**的欄位 | **提示詞**的作品資訊（基本型）或提示詞本文（自行撰寫） |
| 圖片代表的情境 | 每個素材的**描述**、連結角色 | 素材的資料夾・代碼 + 提示詞中的代碼含義（基本型）或圖片規則（自行撰寫） |
| 在對話中放圖片 | `img:[slug]` | `![]({{URL}}/A/1.webp)` |
| 作品代表圖片 | 在素材用 ★ 選一張 | **基本資訊**的**封面** 1～10 張 |
| 作品介紹 | **選填**的 HTML 檔案 | **基本資訊**的**詳細說明**（必填） |
| 創作者留下的話 | **選填**的創作者備註 | **基本資訊**的**創作者指南** |
| 何時使用元件 | 元件的**使用描述** | 提示詞的元件輸出規則（基本型）或本文（自行撰寫） |
| 分類 | **設定**的 **Hashtag**（含目標受眾） | **基本資訊**的類型・標籤 + **其他設定**的讀者群 |
| 推薦人設 | **選填** | **其他設定** |
| 步驟移動 | 填好前一步的必填項目才能進下一步 | 想從哪個分頁開始都行。必填項目在**完成製作**時檢查 |

開場與設定集，兩種方式都有。

## 想把 1.0 作品改用目前的方式重做

沒有轉換既有作品的功能。請從下方選單的**建立**建立新作品，再把設定重新寫過去。新作品是另一個作品，所以既有作品的對話、按讚、留言都不會移過去。

就算建立了新作品，既有的 1.0 作品也會保留。如果不想再顯示既有的作品，請用**編輯**開啟，在**設定**步驟把**公開範圍**改成**私人**，再點選 **>**（下一步）儲存。

搬移時，不要只搬世界觀和人物說明就結束。下面這些也要一併處理。

1. **圖片的描述** → 素材的代碼，以及提示詞中的代碼含義
2. **元件的使用描述** → 提示詞的元件輸出規則
3. **開場的 `img:[slug]`** → 用新素材代碼放入圖片的那一行
4. **HTML 檔案、創作者備註** → 詳細說明、創作者指南
5. **以前放的對話範例** → 提示詞。現在的 1.0 畫面上看不到，但其實一直有傳給 AI。新作品不會帶過去，所以需要的語氣或範例，請直接寫進提示詞。

每個項目要搬到哪裡，整理在[1.0 的欄位與寫法](/create/legacy/reference#搬到目前的方式)的表格裡。

## 遇到問題時

<details>
<summary>想建立新作品，卻開啟了舊版七步驟畫面</summary>

**內容管理**的**編輯**，會用建立該作品時的方式所對應的畫面開啟。新作品請從下方選單的**建立**來建立。

</details>

<details>
<summary>找不到把 1.0 作品改成目前方式的按鈕</summary>

沒有這個按鈕。需要建立新作品，再把設定重新寫過去。請依照[想把 1.0 作品改用目前的方式重做](#想把-10-作品改用目前的方式重做)操作。

</details>
