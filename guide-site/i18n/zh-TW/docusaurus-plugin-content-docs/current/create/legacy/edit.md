# 編輯 1.0 作品

用舊版製作方式（1.0）建立的作品，要在舊版的七步驟畫面中修改。各項目所在的位置與目前的作品製作畫面不同，請依照這一頁修改。

## 開啟方式與移動

1. 在**個人檔案 → 內容管理**點選作品的**編輯**。
2. 依照**基本資訊 → 素材 → 介紹 → 設定 → Lorebook → Components → 選填**的順序進行。
3. 點選右下角的 **>**（下一步）按鈕，會檢查前面步驟的必填項目。如果有缺漏會顯示提示；沒有的話，就會把目前修改的內容儲存，再前往下一步。
4. 也可以直接點選分頁跳過去。往前進時，會檢查並儲存到該步驟的前一步；往回退時，不會檢查也不會儲存。修改的內容會在下次往前進時一起儲存。
5. 在最後的**選填**步驟點選**完成**，會重新檢查所有步驟，然後前往完成畫面。

:::warning[已公開的 1.0 作品，每次往前進就會立刻改變]
1.0 畫面每次用 **>**（下一步）或分頁往前面的步驟移動時，都會把修改的內容儲存到作品。如果是已經公開的作品，從那一刻起，其他使用者看到的也會是修改後的內容。它不會像目前的方式那樣，等你點選**套用變更**才生效。大幅修改時，請先把要改的文字寫在記事本之類的地方，貼上之後再往下一步。
:::

## 各步驟要修改的內容

### 1. 基本資訊

<ScreenStep>

| 項目 | 寫法 |
| --- | --- |
| 內容名稱 | 最多 50 字 |
| 簡短描述 | 最多 40 字 |
| 世界觀 | 時代、地點、情況等背景 |
| 角色 | 至少 1 位。名稱與描述。名稱彼此不能相同 |
| 秘密 | 人物需要知道的隱藏設定（選填） |

世界觀、角色描述、秘密合計最多可寫 10,000 字。這些欄位就是 AI 讀取的設定。

</ScreenStep>

### 2. 素材

<ScreenStep src="/img/screens/zh-TW/legacy-assets.webp" alt="舊版製作畫面的素材步驟。每張圖片都有像 img:AB3K9X 的名稱與描述，姜民宇圖片上的星號已開啟為代表圖片" caption="1.0 · 素材">

- 上傳圖片，或用 **AI 圖片**製作。要進入下一步，至少要有 1 張圖片。最多可放 200 張。
- 點選圖片，會開啟**輸入描述**視窗。在**選擇角色**選出圖片中的人物（沒有人物的背景之類的圖片選**共用**），寫入該人物的名稱並把描述寫在 60 字以內，再點選**儲存**。這是 AI 判斷要在哪個場面使用這張圖片的依據。
- 用圖片左上角的 **★** 按鈕，選出作品的代表圖片一張。
- 圖片上標示的 `img:AB3K9X` 就是那張圖片的名稱。名稱由 MYMI 以英文大寫字母與數字 6 碼決定，無法更改。

</ScreenStep>

### 3. 介紹

建立至少一個介紹，寫下介紹標題與第一則訊息。要放入圖片的話，在第一則訊息欄把游標放在想放的位置，點選**圖片**按鈕。在**插入素材圖片**視窗選擇圖片，游標位置就會加入像 `img:[AB3K9X]` 這樣的標示。用**介紹預覽**確認圖片有沒有顯示在正確的位置。

### 4. 設定

- **Hashtag**：選擇描述作品的標籤。視窗中的**目標受眾**（男性向、女性向）一定要選。
- **公開範圍**：選擇公開或私人。
- **作品公開範圍**：一定要選**原創**（MYMI 專屬）或**一般**。設為原創的作品，這個項目會鎖定 3 個月，並顯示還要幾天才能解除。
- **圖片來源**：一定要選 **MYMI 生成**或**外部**。
- **圖片輸出指示**：**內部圖片**是用 `img:[slug]` 輸出上傳的圖片，**外部圖片**是用設定中寫入的圖片網址輸出。照畫面說明，只使用其中一種方式。
- **內容分級**：選擇**成人**或**全年齡**。

### 5～7. Lorebook · Components · 選填

| 步驟 | 寫法 |
| --- | --- |
| **Lorebook** | 用**新增項目**填寫項目名稱、觸發關鍵字、內容。搜尋與傳送的方式和目前方式的[設定集](/create/lorebook)相同。 |
| **Components** | 填寫程式碼與**使用描述**。在使用描述寫下何時、用什麼值呼叫。 |
| **選填** | 設定檔案設計（HTML）、推薦 Persona、創作者備註。如果新增了推薦 Persona，要填寫**暱稱**（20 字）・**性別**・**出生日期**・**詳細資訊**（1,000 字）。 |

## 遇到問題時

<details>
<summary>無法前往下一步</summary>

前面的步驟有缺漏的必填項目。請確認上方顯示的提示。如果是素材步驟，請看是否至少有 1 張圖片，以及每張圖片是否都有描述。如果是設定步驟，請看是否已選**目標受眾**・**作品公開範圍**・**圖片來源**。

</details>

<details>
<summary>介紹預覽顯示「找不到圖片」</summary>

素材中沒有和 `img:[…]` 括號內名稱相同的圖片。請確認是否在素材步驟刪掉了那張圖片，以及括號內的名稱是否和圖片上標示的一致。不要自己輸入名稱，而是刪掉那一行後，用**圖片**按鈕重新放入，就不會打錯。

</details>

<details>
<summary>編輯畫面沒有提示詞分頁</summary>

因為這是 1.0 作品。1.0 作品不會用目前方式的畫面開啟。想用目前的方式製作的話，請閱讀[認識舊版製作方式（1.0）](/create/legacy/overview#想把-10-作品改用目前的方式重做)。

</details>
