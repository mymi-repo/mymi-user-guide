# 1.0 的欄位與寫法

整理了舊版製作方式（1.0）畫面的項目、限制與圖片寫法。也附上把 1.0 作品搬到目前方式的新作品時使用的對照表。

## 1.0 的項目與限制

| 步驟 | 項目 | 限制 |
| --- | --- | --- |
| 基本資訊 | 內容名稱 | 必填 · 50 字（現在的作品標題是 30 字） |
| | 簡短描述 | 必填 · 40 字 |
| | 世界觀 · 角色描述 · 秘密 | 三個欄位合計 10,000 字。世界觀與至少 1 位角色為必填 |
| | 角色名稱 | 50 字。人物之間不能重複 |
| 素材 | 圖片 | 1～200 張 |
| | 描述 | 每張圖片必填 · 60 字 |
| | 代表圖片 | 用 ★ 選一張 |
| 介紹 | 介紹 | 至少 1 個，標題與內容 |
| 設定 | 目標受眾 | 必填 · 在 **Hashtag** 視窗選男性向、女性向其中之一 |
| | 作品公開範圍 · 圖片來源 | 必填 |
| Lorebook | 項目 | 最多 100 個。項目名稱 50 字、觸發關鍵字 5 個（各 10 字）、內容 400 字 |
| Components | 使用描述 | 每個元件必填 · 500 字 |
| | 程式碼 | 10,000 字（現在是 20,000 字） |
| 選填 | 創作者備註 | 3,000 字（現在是創作者指南每則 5,000 字） |
| | 推薦 Persona | 選填 · 暱稱 20 字、詳細資訊 1,000 字 |

## 1.0 的圖片寫法

1.0 是用**設定 → 圖片輸出指示**所選的方式放入圖片。照畫面的說明，只使用其中一種方式。

| 方式 | 寫法 | 使用的地方 |
| --- | --- | --- |
| 內部圖片 | `img:[slug]` | 上傳到素材的圖片。素材卡片上會像 `img:AB3K9X` 這樣顯示名稱 |
| 外部圖片 | `![](圖片網址)` | 寫在設定中的外部圖片網址 |

在介紹裡要寫成 `img:[AB3K9X]` 這樣。名稱是 MYMI 決定的英文大寫字母與數字 6 碼。使用內部圖片的方式時，AI 會看每個素材所寫的**描述**和連結的角色，選擇要放哪張圖片。使用外部圖片的方式時，描述不會傳給 AI。

:::warning[目前的方式不使用]
`img:[slug]` 是只用在 1.0 作品的寫法。目前方式的作品，請使用素材分頁的代碼和 `![]({{URL}}/A/1.webp)`。
:::

## 搬到目前的方式

把 1.0 作品用目前的方式重做時，各項目要搬到的地方。這不是讓既有作品自動改變，而是自己把內容重新寫到新作品裡。

| 1.0 使用的地方 | 現在使用的地方 | 搬移時要做的事 |
| --- | --- | --- |
| 基本資訊 → 世界觀 | 提示詞 → 作品資訊（基本型）或本文（自行撰寫） | 把時代、地點、規則重新寫過去 |
| 基本資訊 → 角色 | 提示詞 → 作品資訊的登場人物 | 在名字那一行下方寫角色、性格、語氣、關係 |
| 基本資訊 → 秘密 | 提示詞 → 作品資訊的隱藏設定 | 連同揭露的條件一起寫。不要搬到詳細說明 |
| 素材 → 連結角色 | 素材的角色資料夾 + 提示詞的角色代碼含義 | 為每個人物建立資料夾，並讓資料夾代碼和名字對得上 |
| 素材 → 描述 | 素材的圖片代碼 + 提示詞的情境代碼・其他代碼含義 | 相同的情境，要讓所有人物都使用相同的代碼 |
| 素材 → 代表圖片 | 基本資訊 → 封面 | 封面可放 1～10 張。可以從素材選取 |
| 介紹的 `img:[slug]` | 開場的 `![]({{URL}}/A/1.webp)` | 用**插入素材圖片**重新放入 |
| 設定 → Hashtag（含目標受眾） | 基本資訊 → 類型・標籤、其他設定 → 讀者群 | 重新選 1～2 個類型並寫標籤 |
| Components → 使用描述 | 提示詞 → 元件輸出規則（基本型）或本文（自行撰寫） | 把何時、用什麼值呼叫重新寫過去 |
| 選填 → HTML 檔案 | 基本資訊 → 詳細說明 | 詳細說明是必填。用預覽確認 |
| 選填 → 創作者備註 | 基本資訊 → 創作者指南 | |
| 選填 → 推薦 Persona | 其他設定 → 推薦人設 | |
| Lorebook | 設定集 | 名稱・關鍵字・內容照樣搬過去 |

### 範例：搬移一張圖片

在 1.0 中，有一張圖片連結到角色**姜民宇**，描述寫的是「民宇微笑的模樣」（`img:[AB3K9X]`），在目前的方式要這樣搬。

1. 在**提示詞**的作品資訊寫下民宇的角色、性格、語氣。
2. 在**素材**建立角色資料夾 `A`，並以代碼 `1` 放入那張圖片。
3. 如果是基本型，在**圖片輸出規則**寫下角色代碼 `A` = `姜民宇`、情境代碼 `1` = `笑`。
4. 如果是自行撰寫，除了圖片的含義，也要在本文寫下何時用什麼格式放入。
5. 刪掉開場中原本寫的 `img:[AB3K9X]`，改用**插入素材圖片**放入 `A/1`。

## 遇到問題時

<details>
<summary>把 1.0 的介紹貼到新作品，圖片卻沒有出現</summary>

目前的方式不會讀取 `img:[…]`。開場預覽中，該位置也會顯示「無法載入圖片」。請刪掉那一行，再用第一則訊息欄的**插入素材圖片**重新放入。

</details>

<details>
<summary>搬過去的作品在對話中沒有出現圖片</summary>

1.0 是由 MYMI 彙整描述後傳給 AI，但現在必須在提示詞裡寫下何時放圖片。基本型請把**圖片輸出規則**的代碼含義填好；自行撰寫則要把圖片規則寫在本文。方法請見[在對話中顯示圖片](/create/images-in-chat)。

</details>
