# 建立新作品

登入後，點選底部的 **建立** 分頁。分頁依序為 **基本資訊 → 素材 → 元件 → 提示詞 → 開場 → 設定集 → 其他設定**，你可以從任一分頁開始編輯。

第一次建立作品時，可依照 **填寫基本資訊 → 儲存草稿 → 加入封面 → 撰寫提示詞與開場 → 選擇其他設定 → 完成製作** 的順序操作。作品需要圖片、介面元件或補充設定時，再加入素材、元件與設定集。

## 1. 基本資訊與封面

**基本資訊**是讀者尋找及開啟作品時看見的內容。

| 項目 | 填寫方式 |
| --- | --- |
| 作品標題 | 最多 30 字。 |
| 簡短介紹 | 用最多 40 字介紹作品氛圍。 |
| 封面 | 上傳或從素材選取 1～10 張。多張封面可設定切換間隔。 |
| 詳細說明 | 向讀者介紹劇情、角色與玩法。 |
| 類型 | 選擇 1～2 個。 |
| 標籤 | 加入至少 1 個描述作品的標籤。 |

填寫標題和簡短介紹後，點選右上方的 **儲存草稿**。建立草稿後，即可上傳封面和素材圖片，或生成素材圖片。**創作者指南**可提供玩法提示；**推薦模型**可推薦最多 5 個適合本作品的聊天模型。這兩項可自行選填。

**給讀者看的介紹寫在基本資訊；AI 回覆時讀取的設定寫在提示詞。**

## 2. 在提示詞撰寫作品規則

在 **提示詞**中設定 AI 如何運用世界觀、角色及劇情規則。可以選擇兩種寫法：

| 寫法 | 填寫方式 |
| --- | --- |
| **自行撰寫** | 在同一篇文字中寫下世界觀、角色、隱藏設定及進行規則。使用圖片時，也說明各情境應使用的圖片代碼。 |
| **基本型** | 在 **作品資訊**填寫世界觀、角色及進行規則。加入素材或元件後，補上畫面列出的代碼含義和使用時機。可在下方檢查組合完成的提示詞。 |

將角色名稱、關係、說話方式、讀者的身分與劇情規則分開撰寫，日後會更容易修改。

例如可以把 **作品資訊**分成以下小節，再換成自己作品的設定：

```text
#### 世界觀
- **地點**：藏著祕密的圖書館
#### 角色
- **姓名**：允書
- **身分**：迎接讀者的圖書館員
#### 進行規則
- **讀者身分**：新上任的圖書館員
- **起始情境**：在上鎖書架前遇見允書
```

## 3. 在開場建立第一則訊息

在 **開場**至少建立 1 個開場，並填寫每個開場的 **標題** 和 **內容**。建立多個開場後，讀者可選擇起始情境。使用 **預覽**查看聊天畫面中的呈現方式。

若要插入素材圖片，先在 **素材**加入圖片並設定代碼，再使用開場中的 **插入素材圖片**。

## 4. 使用素材、元件與設定集

| 分頁 | 適用情況 | 填寫方式 |
| --- | --- | --- |
| **素材** | 在聊天中顯示符合情境的圖片 | 上傳或生成圖片，為每張圖片設定英數代碼。可建立資料夾管理各角色。將畫面顯示的圖片 Markdown 放入提示詞或開場。 |
| **元件** | 顯示狀態、背包等介面元素 | 加入元件程式碼；使用基本型提示詞時，也要寫明元件出現的時機。 |
| **設定集** | 提到特定關鍵字時提供補充設定 | 填寫項目名稱、觸發關鍵字，以及要提供給 AI 的內容。 |

例如將角色資料夾命名為 `A`，資料夾內的圖片代碼設為 `1`，圖片路徑就是 `A/1`。複製 **素材**中顯示的 Markdown，放入提示詞或開場即可使用該圖片。

這三個分頁可依需要使用。新增項目後，完成製作前請檢查必填欄位、圖片生成狀態與代碼。

## 5. 選擇其他設定

在 **其他設定**選擇公開狀態、作品發布範圍（原創或一般）、營利限制、圖片來源、目標讀者、內容分級及行銷使用同意。選擇 **原創**代表只在 MYMI 發布，並維持該設定 3 個月。

想向讀者推薦聊天時可使用的身分，可加入 **推薦人設**，並填寫姓名、性別、出生日期及詳細資料。

## 儲存並完成製作

編輯過程中點選右上方的 **儲存草稿**。之後可從 **我的頁面 → 作品管理**再次開啟草稿繼續編輯。

準備好後點選 **完成製作**。若有必填項目尚未完成，畫面會切換到對應分頁並顯示提示。填好後再次點選，即可前往完成畫面。

修改已完成的作品時，從 **我的頁面 → 作品管理 → 編輯** 開啟，完成修改後點選 **套用變更**。
