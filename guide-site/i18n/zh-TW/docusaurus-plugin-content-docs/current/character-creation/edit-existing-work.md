# 舊版製作方式（1.0）：編輯既有作品

**舊版製作方式已停止建立新作品。** 前往 **我的頁面 → 作品管理**，點選以此方式建立的作品的 **編輯**，即可開啟七步驟製作畫面。建立新作品時，請使用底部 **建立** 分頁並參考[建立新作品](create-work.md)。

步驟依序為 **基本資訊 → 素材 → 開場 → 其他設定 → 設定集 → 元件 → 選填項目**。往下一步時，系統會檢查先前步驟的必填項目。

## 1. 基本資訊：AI 會讀取的作品設定

| 項目 | 填寫方式 |
| --- | --- |
| 作品名稱 | 最多 50 字。 |
| 簡短介紹 | 最多 40 字。 |
| 世界觀 | 時代、地點和情境等故事背景。 |
| 角色 | 至少加入 1 位，為每位角色填寫不同的名稱和描述。 |
| 秘密 | 視需要填寫角色應知道的隱藏設定。 |

世界觀、角色描述和秘密合計須在 **10,000 字**以內。AI 會在聊天中運用世界觀與角色資訊。在目前的作品製作畫面中，這些內容寫在 **提示詞**。

## 2. 素材：圖片與代表圖片

在 **素材**上傳或生成聊天中使用的圖片。為每張圖片填寫 **情境說明**，讓 AI 知道何時使用。也要選擇作品的 **代表圖片**。至少加入 1 張圖片，才能前往下一步。

## 3. 開場：第一個情境

至少建立 1 個 **開場**，為每個開場填寫 **標題** 和 **內容**。建立多個開場後，讀者可選擇起始情境。已加入的素材圖片可用畫面顯示的 `img:[slug]` 格式放入內容，並在 **預覽**中查看。

## 4. 其他設定：分類與公開

選擇目標讀者（**男性向或女性向**），再設定公開狀態、原創、圖片來源與內容分級。也可在這裡加入描述作品的其他標籤。選擇 **原創**代表只在 MYMI 發布，並維持該設定 3 個月。

## 5～7. 依需要加入設定

| 步驟 | 填寫方式 |
| --- | --- |
| **設定集** | 設定提到特定關鍵字時提供的補充資訊。新增項目後填寫名稱、關鍵字與內容。 |
| **元件** | 建立狀態、背包等介面元素。新增後填寫用途說明與可執行的程式碼。 |
| **選填項目** | 設定個人檔案設計、推薦人設與創作者留言。新增推薦人設後，填寫姓名、性別、出生日期與詳細資料。 |

確認修改後，在最後一步點選 **完成**，即可套用修改。

## 這些欄位在目前的作品製作畫面中在哪裡？

| 舊版製作畫面 | 目前的作品製作畫面 |
| --- | --- |
| 基本資訊的 **世界觀、角色、秘密** | **提示詞**的自行撰寫，或基本型的作品資訊 |
| 素材的 **代表圖片** | 基本資訊的 **封面** |
| 圖片的 **情境說明** | 素材的 **圖片代碼**與提示詞的圖片使用規則 |
| 開場的第一則訊息 | **開場**的標題與內容 |
| 其他設定的目標讀者與標籤 | **其他設定**的目標讀者、**基本資訊**的標籤 |
| 選填項目的個人檔案設計與創作者留言 | **基本資訊**的詳細說明與創作者指南 |

建立新作品時，請依照[建立新作品](create-work.md)操作。
