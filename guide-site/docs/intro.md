# MYMI 유저가이드

MYMI는 **작품 속 인물과 대화하며 이야기에 참여하고, 나만의 작품을 만들 수 있는 AI 서비스**입니다. 웹과 모바일 앱에서 이용할 수 있습니다.

처음 이용한다면 접속과 계정 설정부터, 이미 이용 중이라면 필요한 기능부터 살펴보세요.

## 처음 이용하시나요?

1. **[MYMI란?](getting-started/what-is-mymi.md)** — 작품 속에서 무엇을 할 수 있는지 알아봅니다.
2. **[접속 방법](getting-started/how-to-access.md)** — 웹으로 접속하거나 Android·iOS 앱을 설치합니다.
3. **[회원가입](account/sign-up.md)** — 계정을 만들고 내 프로필을 설정합니다.
4. **[대화하기](chatting/chat-with-character.md)** — 마음에 드는 작품을 골라 첫 대화를 시작합니다.

## 대화를 내 취향에 맞추고 싶어요

| 하고 싶은 일 | 살펴볼 가이드 |
| --- | --- |
| 작품 속에서 사용할 내 이름과 역할 정하기 | [페르소나 설정](account/persona.md) |
| 대화 방식과 화면 설정 바꾸기 | [채팅방 설정](chatting/chat-room-settings.md) |
| 이전 사건과 중요한 설정 관리하기 | [장기기억과 기억 조각](chatting/memory-book.md) |
| 대화에 사용할 AI 모델 알아보기 | [AI 모델 안내](chatting/ai-models.md) |

## 나만의 작품을 만들고 싶어요

작품을 만들 때는 세계관과 등장인물, 유저가 처음 만날 장면을 준비합니다. 여기에 대화용 이미지, 특정 설정을 불러오는 로어북, 상태창 같은 컴포넌트를 더할 수 있습니다.

하단 **제작**에서 새 작품을 만듭니다. 세계관·등장인물·비밀 같은 작품 설정은 **프롬프트**에 쓰고, 이미지와 컴포넌트를 대화에서 언제 사용할지도 정합니다.
