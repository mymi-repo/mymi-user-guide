# 로그인 없이 AI 채팅할 수 있나요?

네. MYMI는 가입하지 않아도 AI 캐릭터와 최대 5번까지 대화할 수 있어요.

작품을 열고 **대화 시작하기**를 누르면 로그인 화면을 거치지 않고 바로 채팅방이 열려요. 로그인해야 열리는 작품은 성인 작품뿐이에요. 2026년 11월 4일에 확인한 내용이에요.

## 체험 5번은 이렇게 세요

- AI 답 하나가 한 번이에요. 작품을 바꿔도 처음부터 다시 세지 않고, 모든 작품을 합쳐 5번이에요.
- 남은 횟수는 채팅방 오른쪽 위 ⋮ 메뉴의 맨 위에 나와요.

:::info[처음부터 남은 횟수가 없을 수 있어요]
같은 인터넷 연결(같은 와이파이 등)에서 최근 7일 안에 체험을 쓴 기록이 있으면, 처음 연 브라우저나 앱도 남은 횟수 없이 시작할 수 있어요. 회사·학교·카페 와이파이처럼 여러 사람이 함께 쓰는 연결이면 다른 사람이 체험한 기록 때문에도 그럴 수 있어요. 로그인해서 쓰다가 로그아웃한 브라우저나 앱, 그 밖에 체험을 되풀이해 쓰는 것을 막는 조건에 걸린 경우도 마찬가지예요. 이때는 가입하거나 로그인해서 대화하세요.
:::

## 로그인하면 달라지는 것

| | 로그인 없이 | 가입하고 로그인하면 |
| --- | --- | --- |
| 캐릭터와 대화 | 최대 5번 | 스파크로 대화해요. 답 한 번에 드는 스파크는 모델마다 달라요 |
| 모델 고르기 | 고를 수 없어요. 체험 모델(지금은 **Gemini 3.8 Flash**)이 답해요 | 입력창 왼쪽 ⚡ 버튼에서 골라요 |
| 유저 노트·페르소나 | 유저 노트는 쓸 수 없어요. 페르소나는 작품 화면에서 제작자가 준비한 **추천 페르소나**를 고르는 것만 돼요 | 채팅방마다 정해 둘 수 있어요 |
| 성인 작품 | 열리지 않아요 | 본인인증으로 성인 확인을 마치면 열려요 |
| 작품 만들기 | 로그인 안내만 나와요 | 하단 **제작**에서 만들어요 |
| 체험한 대화 | 5번을 다 쓰면 입력창이 잠기고 가입이나 로그인을 안내해요 | 체험하던 브라우저나 앱에서 새로 가입하면 새 계정으로 넘어가요 |

로그인한 뒤 쓸 스파크는 충전하거나, 본인인증을 마치고 출석 체크로 하루에 한 번 받을 수 있어요. 충전과 출석 체크는 [스파크 충전하기](/payment/payment-methods.md)에 정리돼 있어요. 채팅방에서 답을 다시 받거나 고치는 방법은 [대화하기](/chatting/chat-with-character.md)에 있어요.

## 자주 막히는 곳

<details>

<summary>5번을 다 쓰면 어떻게 되나요?</summary>

입력창이 잠기고, 채팅방 위쪽에 체험이 끝났다는 안내가 떠요. 마지막 답이 다 나오면 잠시 뒤 로그인 창도 열려요. 창을 닫았다면 안내의 **로그인하기**를 눌러 다시 열 수 있어요. 가입하거나 로그인한 뒤에는 스파크로 이어서 대화해요. 새 계정은 스파크 없이 시작하니, 먼저 충전하거나 본인인증을 마치고 출석 체크로 받으세요.

</details>

<details>

<summary>다시 생성이나 이어서 진행도 횟수에 드나요?</summary>

네. 입력창을 비운 채 ≫ 버튼으로 받은 답, **다시 생성하기**로 새로 받은 답, 모델이 응답을 거부한 답도 한 번씩 세요. ‹ › 로 지난 답을 넘겨 보는 것은 세지 않아요.

</details>

<details>

<summary>앱에서도 로그인 없이 대화할 수 있나요?</summary>

네. Android·iPhone 앱도 처음 열 때부터 로그인하지 않은 채 작품을 골라 대화할 수 있어요. 횟수를 세는 방법과 다 쓴 뒤 뜨는 안내도 웹과 같아요. 다만 같은 인터넷 연결(같은 와이파이 등)에서 최근 7일 안에 웹으로 체험했다면, 앱은 남은 횟수 없이 시작할 수 있어요.

</details>

<details>

<summary>가입하면 체험한 대화가 남나요?</summary>

체험하던 브라우저나 앱에서 로그인 버튼을 눌러, MYMI에서 처음 쓰는 소셜 계정으로 가입하면 남아요. 체험하던 채팅방이 모두 새 계정으로 넘어가고, 채팅방에서 연 로그인 창으로 가입했다면 가입을 마친 뒤 그 채팅방으로 돌아와요. 이미 가입한 계정으로 로그인하거나, 다른 브라우저나 앱에서 가입하면 넘어가지 않아요. 가입 방법은 [회원가입](/account/sign-up.md)에 있어요.

</details>
