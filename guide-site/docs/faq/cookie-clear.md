# 쿠키 삭제하기

웹에서 로그인이 계속 풀리거나, 로그인했는데도 로그인 화면이 다시 나오거나, 마이페이지가 열리지 않을 때 아래 순서대로 해 보세요.

앱에서는 쿠키를 지울 필요가 없어요. **마이페이지 → 설정 및 지원 → 로그아웃**을 누르고 가입한 소셜 계정으로 다시 로그인하세요.

## 먼저 다시 로그인하기

**마이페이지**에 로그아웃 버튼이 보이면 **마이페이지 → 설정 및 지원 → 로그아웃**을 누르고, 가입한 소셜 계정으로 다시 로그인해요.

로그아웃 버튼이 보이지 않거나 다시 로그인해도 같은 문제가 생기면, 쓰는 브라우저에서 아래처럼 MYMI(mymi.live)의 쿠키와 사이트 데이터를 지워요. 지운 뒤에는 다시 로그인해야 해요.

## Android

### Chrome

1. 주소창 왼쪽의 설정 버튼을 눌러요.
2. **쿠키 및 사이트 데이터**를 열어요.
3. MYMI 쿠키를 삭제해요.

### 삼성 인터넷

1. 주소창 왼쪽의 자물쇠 버튼을 눌러요.
2. **쿠키 00개 사용 중** 항목을 찾아요.
3. 옆의 휴지통 버튼을 눌러 삭제해요.

## iPhone·iPad

### Safari

1. 기기의 **설정 → 앱 → Safari → 고급 → 웹사이트 데이터**로 가요.
2. **편집**을 눌러 mymi.live 데이터를 삭제해요.

### Chrome

:::warning[다른 사이트에서도 로그아웃돼요]
이 방법은 MYMI뿐 아니라 다른 사이트의 쿠키도 함께 지워요.
:::

1. 아래쪽의 … 버튼을 눌러요.
2. **인터넷 사용 기록 삭제**를 골라요.
3. **쿠키, 사이트 데이터**를 체크해요.
4. **인터넷 사용 기록 삭제**를 눌러요.

## PC

### Chrome

1. 주소창 왼쪽의 설정 버튼을 눌러요.
2. **쿠키 및 사이트 데이터 → 기기 내 사이트 데이터 관리**를 골라요.
3. 보이는 사이트 데이터를 모두 삭제해요.

### Edge

1. 주소창 왼쪽의 자물쇠 버튼을 눌러요.
2. **쿠키 및 사이트 데이터 → 쿠키 → 허용됨**에서 mymi.live 항목을 골라 제거해요.

### 웨일

1. 주소창 왼쪽의 자물쇠 버튼을 눌러요.
2. **쿠키 및 사이트 데이터 → 기기 내 사이트 데이터 관리**를 골라요.
3. 보이는 사이트 데이터를 모두 삭제해요.

브라우저 버전에 따라 메뉴 이름과 위치가 조금 다를 수 있어요.

## 자주 막히는 곳

<details>
<summary>쿠키를 지웠는데도 로그인이 안 돼요</summary>

- 카카오톡·인스타그램 같은 앱 안에서 열었다면 Chrome이나 Safari에서 [www.mymi.live](https://www.mymi.live)를 직접 열어요.
- 다른 브라우저로도 로그인해 봐요. 다른 브라우저에서는 된다면 쓰던 브라우저의 설정 문제일 수 있어요.

</details>

<details>
<summary>다른 사이트에서도 로그아웃됐어요</summary>

브라우저 전체 기록에서 쿠키를 지우면 다른 사이트의 로그인도 풀려요. 그 사이트들에 다시 로그인하세요.

</details>

<details>
<summary>로그인했는데 예전 대화나 스파크가 안 보여요</summary>

쿠키 문제가 아니라 다른 소셜 계정으로 로그인했을 수 있어요. 소셜 계정마다 MYMI 계정이 따로 있어요. 로그아웃한 뒤 처음 가입한 소셜 계정으로 다시 로그인하세요.

</details>

그래도 해결되지 않으면 쓰는 기기와 브라우저를 적어 [문의하기](/faq/faq.md#문의하기)로 알려 주세요.
