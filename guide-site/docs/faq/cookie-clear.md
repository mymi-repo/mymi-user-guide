# 쿠키 삭제하기

웹에서 마이페이지나 로그아웃 버튼이 보이지 않거나 인증이 진행되지 않으면 아래 순서로 시도해 보세요.

## 1. 다시 로그인하기

**마이페이지 → 설정 및 지원 → 로그아웃**을 누른 뒤, 가입했던 소셜 계정으로 다시 로그인합니다.

해결되지 않으면 사용하는 브라우저에서 MYMI(mymi.live)의 쿠키와 사이트 데이터를 삭제합니다.

## 2. Android에서 삭제하기

### Chrome

1. 주소창 왼쪽의 **설정 버튼**을 누릅니다.
2. **쿠키 및 사이트 데이터**를 엽니다.
3. MYMI 관련 쿠키를 삭제합니다.

### 삼성 인터넷

1. 주소창 왼쪽의 **자물쇠 버튼**을 누릅니다.
2. **쿠키 00개 사용 중** 항목을 확인합니다.
3. 옆의 **휴지통 버튼**을 눌러 삭제합니다.

## 3. iPhone·iPad에서 삭제하기

### Safari

1. **설정 → 앱 → Safari → 고급 → 웹사이트 데이터**로 이동합니다.
2. **편집**을 눌러 mymi.live 데이터를 삭제합니다.

### Chrome

1. 아래쪽의 **… 버튼**을 누릅니다.
2. **인터넷 사용 기록 삭제**를 선택합니다.
3. **쿠키, 사이트 데이터**를 선택합니다.
4. **인터넷 사용 기록 삭제**를 누릅니다.

## 4. PC에서 삭제하기

### Chrome

1. 주소창 왼쪽의 **설정 버튼**을 누릅니다.
2. **쿠키 및 사이트 데이터 → 기기 내 사이트 데이터 관리**를 선택합니다.
3. 방문 중인 사이트의 데이터를 모두 삭제합니다.

### Edge

1. 주소창 왼쪽의 **자물쇠 버튼**을 누릅니다.
2. **쿠키 및 사이트 데이터 → 쿠키 → 허용됨**에서 mymi.live 항목을 선택해 제거합니다.

### 웨일

1. 주소창 왼쪽의 **자물쇠 버튼**을 누릅니다.
2. **쿠키 및 사이트 데이터 → 기기 내 사이트 데이터 관리**를 선택합니다.
3. 방문 중인 사이트의 데이터를 모두 삭제합니다.

브라우저 버전에 따라 메뉴 이름이나 위치가 다를 수 있습니다.

:::warning
쿠키를 모두 삭제하면 MYMI 외의 다른 사이트에서도 로그아웃될 수 있습니다.
:::

## 도움이 필요할 때

위 방법으로도 해결되지 않으면 **마이페이지 → 디스코드 → 문의하기** 또는 [contact@mymi.live](mailto:contact@mymi.live)로 문의해 주세요. 사용하는 기기와 브라우저를 함께 알려 주면 확인에 도움이 됩니다.
