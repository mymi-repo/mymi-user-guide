# 스파크 충전하기

**스파크**는 작품 속 인물과 대화할 때 쓰는 재화입니다. 메시지를 보낼 때마다 선택한 AI 모델과 답변 길이에 따라 스파크가 차감됩니다. 모델별 차감량은 [AI 모델 안내](/chatting/ai-models.md)에서 확인하세요.

| 재화 | 설명 |
| --- | --- |
| 스파크 | 대화에 쓰는 재화입니다. 충전하거나 출석 체크·친구 초대·이벤트로 받습니다 |
| 리프 | 크리에이터가 작품 이용에 따라 받는 보상입니다. 스파크로 전환해 쓸 수 있습니다. [크리에이터 응원하기](/creator-support/support.md)를 참고하세요 |

## 1. 충전 화면 열기

1. **마이페이지**에서 **내 스파크**를 누릅니다.
2. **스파크 관리** 창에서 **스파크 충전하기**를 누릅니다.

대화 중에 스파크가 부족하다는 안내가 나오거나, 채팅방 **⋮** 메뉴 맨 위의 잔액을 눌러도 충전 화면으로 이동합니다. 충전하려면 로그인해야 합니다.

## 2. 웹에서 충전하기

1. 충전 화면에서 상품을 고릅니다.
2. 상품 목록 아래에 나오는 **상품**과 **총 결제금액**을 확인합니다.
3. **구매하기**를 누르면 카드 결제창이 열립니다. 결제창의 안내에 따라 결제를 마칩니다.
4. MYMI로 돌아와 충전 완료 안내를 확인합니다.

| 가격 | 받는 스파크 | 안내 |
| --- | ---: | --- |
| 2,500원 | 5,000 | **첫 충전 상품**(**초회할인** 표시). 본인인증을 마친 계정에서 한 번만 살 수 있습니다 |
| 5,000원 | 5,000 | |
| 10,000원 | 10,000 | |
| 30,000원 | 31,500 | 보너스 1,500 포함 |
| 50,000원 | 55,000 | 보너스 5,000 포함 |
| 100,000원 | 115,000 | 보너스 15,000 포함 |

첫 충전 상품은 **웹과 앱을 합쳐 계정당 한 번** 살 수 있습니다. 본인인증 방법은 [성인·본인인증](/account/adult-verification.md)을 참고하세요.

:::info[Gemini 패스 판매 종료]
Gemini 패스는 2026년 6월 22일에 판매를 마쳤습니다. 지금은 스파크 패키지만 판매합니다.
:::

## 3. 앱에서 충전하기

앱에서는 **App Store**(iOS)나 **Google Play**(Android)의 인앱결제로 충전합니다.

1. 충전 화면에서 상품을 고르고 **구매하기**를 누릅니다.
2. 스토어 결제창에서 결제를 마칩니다.
3. 충전 완료 안내를 확인합니다.

앱 가격은 스토어에 등록된 가격이라 웹 가격과 다릅니다. 2026년 9월 기준 가격은 다음과 같습니다. 스토어 사정에 따라 바뀔 수 있으니 결제 전 화면과 스토어 결제창의 금액을 확인하세요.

| 받는 스파크 | Google Play | App Store |
| ---: | ---: | ---: |
| 5,000 (첫 충전 상품) | 3,300원 | 3,300원 |
| 5,000 | 5,900원 | 6,000원 |
| 10,000 | 12,000원 | 12,000원 |
| 31,500 | 36,000원 | 36,000원 |
| 55,000 | 60,000원 | 60,000원 |
| 115,000 | 120,000원 | 120,000원 |

앱의 첫 충전 상품도 본인인증을 마친 계정에서만 살 수 있습니다.

## 4. 무료로 스파크 받기

### 출석 체크

**마이페이지 → 출석 체크**에서 **오늘의 보상 받기**를 누르면 하루에 한 번 스파크를 받습니다. 본인인증을 마친 계정만 받을 수 있습니다.

| 연속 출석 | 받는 스파크 |
| --- | --- |
| 1~9일째 | 200부터 하루에 20씩 늘어납니다(200, 220, 240, 260, 280, 300, 320, 340, 360) |
| 10일째 | 400 |

- 10일을 모두 채우면 2,920 스파크를 받습니다. 11일째부터는 다시 1일차 보상이 지급됩니다.
- 하루를 건너뛰면 1일차부터 다시 시작합니다.
- 출석 날짜는 매일 자정에 바뀝니다.

### 친구 초대

**마이페이지 → 친구 초대**에서 **내 추천 코드**를 친구에게 보내거나 **친구에게 공유하기**로 초대 링크를 보냅니다.

1. 친구는 가입한 뒤 **7일 안에** 본인인증을 마치고 추천 코드를 등록합니다. 초대 링크로 가입했다면 본인인증을 마칠 때 코드가 자동으로 등록됩니다.
2. 친구가 코드를 등록한 날부터 **30일 안에** 처음 유료 결제를 하면, 나와 친구가 각각 **1,500 스파크**를 받습니다.

코드만 등록하고 결제하지 않으면 보상이 지급되지 않습니다. 본인 코드는 등록할 수 없습니다.

### 이벤트

운영 이벤트나 공모전으로 스파크를 받을 수도 있습니다. 지급 조건은 각 이벤트 공지를 확인하세요.

## 5. 유효기간 확인하기

스파크는 받은 방법에 따라 쓸 수 있는 기간이 다르고, 기간이 지나면 자동으로 사라집니다. 대화할 때는 **사용 기간이 먼저 끝나는 스파크부터** 차감됩니다.

| 받은 방법 | 쓸 수 있는 기간 |
| --- | --- |
| 충전(결제), 리프 전환 | 받은 날부터 1년 |
| 출석 체크, 이벤트 | 받은 날부터 14일 |
| 친구 초대 보상 | 받은 날부터 30일 |
| 공모전 보상 | 받은 날부터 180일 |

**스파크 관리** 창에서 **유료 스파크**와 **무료 스파크**를 나눠 볼 수 있습니다. 24시간 안에 사라지는 스파크가 있으면 **⏰ 곧 만료** 표시가 나옵니다.

## 6. 충전·사용 내역 보기

**마이페이지 → 내 스파크 → 사용내역 보기**를 누르면 **스파크 사용내역**이 열립니다.

- **사용** 탭: 대화에 쓴 스파크와 유효기간이 지나 사라진 스파크
- **충전** 탭: 결제, 출석 체크, 친구 초대, 리프 전환으로 받은 스파크. 답변 생성에 실패해 돌려받은 스파크도 여기에 표시됩니다

## 충전이 잘되지 않을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 첫 충전 상품을 살 수 없어요 | 본인인증을 마쳤는지, 웹이나 앱에서 이미 산 적이 있는지 확인합니다 |
| 결제했는데 스파크가 들어오지 않았어요 | 웹은 충전 화면을 새로고침하고, 앱은 앱을 다시 실행합니다. 그래도 없으면 다시 결제하지 말고 [결제 취소와 환불](/payment/refund.md)의 안내대로 문의합니다 |
| 결제창이 열리지 않거나 결제 뒤 MYMI로 돌아오지 않아요 | 다른 앱 안의 브라우저로 열었다면 기본 브라우저에서 다시 시도합니다 |
| 앱과 웹의 가격이 달라요 | 앱은 스토어에 등록된 가격으로 결제합니다 |
| 출석 보상을 받을 수 없어요 | 로그인과 본인인증을 확인합니다. 출석은 하루에 한 번만 받을 수 있습니다 |
| 친구 초대 보상이 들어오지 않았어요 | 친구가 가입 7일 안에 코드를 등록했는지, 등록 후 30일 안에 첫 유료 결제를 했는지 확인합니다 |

## 도움이 필요할 때

결제 문의는 [contact@mymi.live](mailto:contact@mymi.live)로 보내 주세요. 결제일, 결제 방법, 결제 금액, MYMI 아이디, 주문번호를 함께 알려 주면 빨리 확인할 수 있습니다. 취소와 환불은 [결제 취소와 환불](/payment/refund.md)을 참고하세요.
