# 스파크 충전하기

**스파크**는 AI 답변을 받을 때 쓰는 MYMI 재화예요. 답변을 한 번 받을 때마다 고른 AI 모델의 가격만큼 차감돼요. 모델별 가격은 [AI 모델 안내](/chatting/ai-models.md)에 있어요.

스파크가 모자라면 충전하거나, 출석 체크와 친구 초대로 무료로 받을 수 있어요.

## 충전 화면 열기

1. 로그인한 뒤 **마이페이지**에서 **내 스파크**를 눌러요.
2. **스파크 관리** 창에서 **스파크 충전하기**를 눌러요.

대화하다가 스파크가 부족하다는 안내가 뜨면 그 안내의 **충전하기**를 눌러도 돼요. 채팅방 오른쪽 위 ⋮ 메뉴 맨 위에 보이는 남은 스파크를 눌러도 충전 화면이 열려요.

## 웹에서 충전하기

1. 충전 화면에서 상품을 골라요.
2. 아래에 나오는 **상품**과 **총 결제금액**을 확인해요.
3. **구매하기**를 누르고, 열린 결제창의 안내에 따라 결제를 마쳐요.
4. MYMI로 돌아와 충전이 끝났다는 안내를 확인해요.

2026년 10월 2일 기준 웹 상품이에요.

| 가격 | 받는 스파크 | 참고 |
| --- | ---: | --- |
| 2,500원 | 5,000 | **초회할인** 표시가 붙은 첫 충전 상품이에요. 본인인증을 마친 계정만, 웹과 앱을 합쳐 한 번 살 수 있어요 |
| 5,000원 | 5,000 | |
| 10,000원 | 10,000 | |
| 30,000원 | 31,500 | 보너스 1,500 포함 |
| 50,000원 | 55,000 | 보너스 5,000 포함 |
| 100,000원 | 115,000 | 보너스 15,000 포함 |

첫 충전 상품을 고르고 **구매하기**를 눌렀을 때 "본인인증이 필요해요" 창이 뜨면 **본인인증하기**를 눌러 인증을 마친 뒤 다시 사세요. 인증 방법은 [성인·본인인증](/account/adult-verification.md)에 있어요.

## 앱에서 충전하기

앱에서는 iPhone은 App Store, Android는 Google Play로 결제해요.

1. 충전 화면에서 상품을 고르고 **구매하기**를 눌러요.
2. 스토어 결제창에서 결제를 마쳐요.
3. 충전 완료 안내를 확인해요.

앱 가격은 스토어에 등록된 가격이라 웹과 달라요. 2026년 9월 기준 가격이에요. 결제하기 전에 화면과 스토어 결제창의 금액을 확인하세요.

| 받는 스파크 | Google Play | App Store |
| ---: | ---: | ---: |
| 5,000 (첫 충전 상품) | 3,300원 | 3,300원 |
| 5,000 | 5,900원 | 6,000원 |
| 10,000 | 12,000원 | 12,000원 |
| 31,500 | 36,000원 | 36,000원 |
| 55,000 | 60,000원 | 60,000원 |
| 115,000 | 120,000원 | 120,000원 |

앱의 첫 충전 상품도 본인인증을 마친 계정만 살 수 있고, 웹에서 이미 샀다면 앱에서는 살 수 없어요.

## 무료로 스파크 받기

### 출석 체크

**마이페이지 → 출석 체크**에서 **오늘의 보상 받기**를 누르면 하루에 한 번 스파크를 받아요. 본인인증을 마친 계정만 받을 수 있어요. 아직 인증하지 않았다면 버튼을 누를 때 인증 창이 열려요.

| 연속 출석 | 받는 스파크 |
| --- | --- |
| 1~9일째 | 200부터 하루에 20씩 늘어요(200, 220, 240, 260, 280, 300, 320, 340, 360) |
| 10일째 | 400 |

- 10일을 다 채우면 모두 2,920 스파크를 받고, 다음 날부터 1일째로 다시 시작해요.
- 하루를 건너뛰면 1일째부터 다시 시작해요.
- 출석은 매일 자정에 바뀌어요.

### 친구 초대

1. **마이페이지 → 친구 초대**에서 **내 추천 코드**를 복사해 보내거나, **친구에게 공유하기**로 초대 링크를 보내요.
2. 친구는 가입한 뒤 **7일 안에** 본인인증을 마치고, 친구의 **마이페이지 → 친구 초대**에 있는 **추천인 입력** 칸에 코드를 넣고 **추천 코드 등록**을 눌러요. 초대 링크로 가입했다면 본인인증을 마칠 때 코드가 자동으로 등록돼요.
3. 코드를 등록한 날부터 **30일 안에** 친구가 처음으로 유료 결제를 하면, 나와 친구가 각각 **1,500 스파크**를 받아요.

:::info[친구가 MYMI에서 처음 하는 결제여야 해요]
보상은 친구 계정의 첫 유료 결제에만 나가요. 웹과 앱을 합쳐 한 번이라도 결제한 적이 있는 친구를 초대하면 두 사람 모두 보상을 받지 못해요. 내 추천 코드는 내가 등록할 수 없어요.
:::

### 이벤트

운영 이벤트나 공모전으로 스파크를 받을 수도 있어요. 받는 조건과 쓸 수 있는 기간은 각 이벤트 공지를 확인하세요.

## 스파크는 언제 사라지나요?

스파크는 받은 방법에 따라 쓸 수 있는 기간이 달라요. 기간이 지나면 자동으로 사라져요. 대화할 때는 **기간이 먼저 끝나는 스파크부터** 쓰여요.

| 받은 방법 | 쓸 수 있는 기간 |
| --- | --- |
| 충전(결제), 리프 전환 | 받은 날부터 1년 |
| 출석 체크 | 받은 날부터 14일 |
| 친구 초대 보상 | 받은 날부터 30일 |
| 이벤트 | 공지에 적힌 기간(따로 없으면 14일) |
| 공모전 보상 | 받은 날부터 180일 |

**마이페이지 → 내 스파크**를 누르면 **스파크 관리** 창에서 **유료 스파크**와 **무료 스파크**를 나눠 볼 수 있어요. 24시간 안에 사라지는 스파크가 있으면 "⏰ 300개 곧 만료"처럼 표시돼요.

## 충전·사용 내역 보기

**마이페이지 → 내 스파크 → 사용내역 보기**를 누르면 **스파크 사용내역**이 열려요.

- **사용** 탭: 대화에 쓴 스파크와 기간이 지나 사라진 스파크
- **충전** 탭: 결제, 출석 체크, 친구 초대, 리프 전환으로 받은 스파크. 답변을 만들지 못해 돌려받은 스파크도 여기에 있어요

## 자주 막히는 곳

<details>
<summary>첫 충전 상품을 살 수 없어요</summary>

- "본인인증이 필요해요" 창이 뜨면 **본인인증하기**로 먼저 인증하세요.
- "이미 이용한 프로모션 상품이에요" 또는 "해당 프로모션 상품은 이미 사용했습니다"가 뜨면 웹이나 앱에서 이미 산 거예요. 첫 충전 상품은 계정당 한 번만 살 수 있어요.

</details>

<details>
<summary>결제했는데 스파크가 들어오지 않았어요</summary>

다시 결제하지 마세요. 웹은 충전 화면을 새로고침하고, 앱은 완전히 껐다가 다시 열어요. 그래도 없으면 [결제했는데 스파크가 들어오지 않았다면](/payment/refund.md#결제했는데-스파크가-들어오지-않았다면)을 따라 문의해 주세요.

</details>

<details>
<summary>"결제가 취소되었습니다"라고 나와요</summary>

결제창을 끝까지 마치기 전에 닫으면 이렇게 떠요. **구매하기**부터 다시 하세요. 이 안내가 떴는데 카드 결제 알림을 받았다면 [결제했는데 스파크가 들어오지 않았다면](/payment/refund.md#결제했는데-스파크가-들어오지-않았다면)을 따라 문의해 주세요.

</details>

<details>
<summary>결제창이 열리지 않거나 결제한 뒤 MYMI로 돌아오지 않아요</summary>

카카오톡·인스타그램 같은 앱 안에서 MYMI를 열었다면 Chrome이나 Safari에서 [www.mymi.live](https://www.mymi.live)를 열고 다시 해 보세요.

</details>

<details>
<summary>앱과 웹의 가격이 달라요</summary>

앱은 스토어에 등록된 가격으로 결제해서 웹 가격과 달라요. 웹과 앱은 같은 계정이라 어디서 산 스파크든 함께 쓸 수 있어요.

</details>

<details>
<summary>출석 보상을 받을 수 없어요</summary>

- 본인인증을 마친 계정만 받을 수 있어요. **오늘의 보상 받기**를 누르면 인증 창이 열려요.
- "이미 출석체크를 했습니다"가 뜨면 오늘은 이미 받은 거예요. 자정이 지나면 다시 받을 수 있어요.

</details>

<details>
<summary>친구 초대 보상이 들어오지 않았어요</summary>

- 친구가 가입하고 7일 안에 본인인증을 마치고 코드를 등록했는지 확인하세요. "추천 코드 입력 기한이 지났어요"가 뜨면 7일이 지난 거예요.
- 코드를 등록한 날부터 30일 안에 친구가 처음 유료 결제를 해야 해요. 코드를 등록하기 전에 결제한 적이 있다면 보상이 나가지 않아요.

</details>

<details>
<summary>스파크가 줄었어요</summary>

기간이 지난 스파크는 자동으로 사라져요. **스파크 사용내역**의 **사용** 탭에서 대화에 쓴 스파크와 사라진 스파크를 볼 수 있어요.

</details>

결제 문의는 [contact@mymi.live](mailto:contact@mymi.live)로 보내 주세요. 결제일, 결제 방법, 결제 금액, MYMI 아이디(**마이페이지** 닉네임 아래의 `@아이디`)를 함께 적어 주면 빨리 확인할 수 있어요.
