# 약관과 정책

MYMI를 쓸 때 지켜야 할 것과 신고하는 방법을 정리했어요. 이 페이지는 요약이라, 내용이 다르면 각 약관·정책 원문이 우선해요.

## 약관 원문 보기

| 문서 | 이런 내용이 있어요 |
| --- | --- |
| [서비스 이용약관](https://www.mymi.live/ko/legal/terms-of-service) | 회원 가입, 스파크 구매와 환불, 연령 확인, 이용 제한 |
| [개인정보처리방침](https://www.mymi.live/ko/legal/privacy-policy) | 모으는 개인정보와 쓰고 보관하고 지우는 기준 |
| [청소년 보호 정책](https://www.mymi.live/ko/legal/youth-protection-policy) | 청소년 보호 원칙, 성인 콘텐츠 접근 제한, 신고 |
| [작품 생성 정책](https://www.mymi.live/ko/legal/content-creation-policy) | 작품·AI 대화·이미지 생성 기준과 위반 유형별 제재 |
| [MYMI 크리에이터 약관](https://www.mymi.live/ko/legal/creator-terms) | 크리에이터 자격, 리프와 수익 배분, 공식 크리에이터 |

웹에서는 MYMI 홈 화면 맨 아래에서도 이용약관과 정책 문서를 열 수 있어요.

## 하면 안 되는 것

아래는 [작품 생성 정책](https://www.mymi.live/ko/legal/content-creation-policy)의 주요 금지 사항이에요.

- **불법 콘텐츠**: 법을 어기는 콘텐츠를 만들거나 퍼뜨리기
- **혐오 표현**: 인종, 성별, 종교 등을 차별하거나 비하하는 표현
- **개인정보 침해**: 다른 사람의 개인정보를 허락 없이 쓰거나 공개하기
- **권리 침해**: 다른 사람의 저작물이나 초상을 허락 없이 쓰기
- **실존 인물의 성적 묘사**: 실존 인물을 성적으로 묘사하거나 비방하기
- **미성년자 관련 성적 콘텐츠**: 미성년자이거나 미성년자로 보이는 인물의 성적 묘사(엄격히 금지)
- **등급 잘못 정하기**: 성인 콘텐츠가 있는 작품을 일반 작품으로 등록하기
- **생성 이미지 밖에서 쓰기**: MYMI에서 만든 이미지를 다운로드·캡처해 MYMI 밖에 올리거나 팔기

## 위반하면 어떻게 되나요?

위반 유형과 횟수에 따라 경고, 작품 비공개·삭제, 기능 제한, 서비스 이용 정지, 영구 정지를 받아요.

- 미성년자 관련 성적 콘텐츠는 첫 위반에 바로 삭제되고 영구 정지돼요.
- 그 밖에도 중대한 위반은 횟수와 관계없이 바로 영구 정지될 수 있어요.
- 유형별 기준은 [작품 생성 정책](https://www.mymi.live/ko/legal/content-creation-policy)의 제재 기준표에 있어요.

:::warning[미리 알리지 않고 삭제될 수 있어요]
정책을 어긴 작품이나 콘텐츠는 사전 통보 없이 삭제되거나 비공개될 수 있어요.
:::

## 신고하기

1. 신고할 작품의 상세 화면을 열어요.
2. 오른쪽 위의 방패 아이콘을 누르고 **신고하기**를 골라요. 로그인해야 신고할 수 있어요.
3. 신고 사유를 고르고, 필요하면 추가 설명을 적은 뒤 **신고 제출**을 눌러요.

접수된 신고는 24시간 안에 먼저 확인하고, 72시간 안에 조치하는 것을 원칙으로 해요. 같은 메뉴에서 **작가 차단**이나 **콘텐츠 차단**을 고르면 그 작가나 작품이 내 홈과 추천에 나오지 않아요.

메일로도 신고하거나 문의할 수 있어요.

| 이럴 때 | 보내는 곳 |
| --- | --- |
| 유해한 콘텐츠를 신고할 때 | [safety@mymi.live](mailto:safety@mymi.live) |
| 내 저작물·초상이 무단으로 쓰였을 때 | [copyright@mymi.live](mailto:copyright@mymi.live) |
| 받은 제재에 이의가 있을 때 | [safety_appeal@mymi.live](mailto:safety_appeal@mymi.live) |
| 개인정보에 대해 묻고 싶을 때 | [privacy@mymi.live](mailto:privacy@mymi.live) |
| 그 밖의 문의 | [contact@mymi.live](mailto:contact@mymi.live) |

## 자주 막히는 곳

<details>
<summary>내 작품이 갑자기 비공개되거나 삭제됐어요</summary>

작품 생성 정책을 어긴 것으로 판단된 작품은 미리 알리지 않고 비공개되거나 삭제될 수 있어요. 제재에 이의가 있다면 [safety_appeal@mymi.live](mailto:safety_appeal@mymi.live)로 작품 제목과 MYMI 아이디를 적어 보내 주세요. 검토에서 거절된 작품은 [공개하고 고치기](/create/making/publish.md)를 보세요.

</details>

<details>
<summary>차단한 작품이나 작가를 다시 보고 싶어요</summary>

**마이페이지 → 차단 관리**에서 차단을 풀 수 있어요.

</details>

<details>
<summary>신고하기 메뉴가 보이지 않아요</summary>

작품 상세 화면 오른쪽 위의 방패 아이콘을 눌러야 메뉴가 열려요. 로그인하지 않았다면 신고하기를 누를 때 로그인 창이 먼저 떠요.

</details>
