# 채팅방 설정하기

채팅방에서 AI가 답하는 방식과 화면 표시를 바꾸고, 지난 대화를 다시 읽거나 찾는 방법을 알려 드려요.

## 버튼 위치

채팅방 오른쪽 위에 아이콘이 세 개 있어요.

| 아이콘 | 누르면 |
| --- | --- |
| 눈 | 대화 글을 가리고 그림만 봐요. 다시 누르면 돌아와요 |
| 팔레트 | **UI 설정**이 열려요. 보기 방식, 글자 크기, 색을 바꿔요 |
| ⋮ | **채팅방 관리**가 열려요. 이 페이지의 설정은 대부분 여기 있어요 |

**채팅방 관리** 맨 위에는 남은 스파크가 보여요. 로그인하지 않았다면 **남은 무료 체험 횟수**가 보여요. 누르면 충전 화면이나 로그인 창으로 가요.

## AI가 답하는 방식 바꾸기

⋮ 메뉴의 **채팅 설정**에서 바꿔요. 바꾼 설정은 다음 답변부터 적용돼요.

| 설정 | 하는 일 |
| --- | --- |
| **문체 스타일** | **소설형**은 묘사와 서술이 풍부하고, **라노벨형**은 가볍고 대사가 중심이에요 |
| **스토리 부스터** | 켜면 AI가 사건을 적극적으로 만들어 전개가 빨라져요 |
| **사칭 허용** | 켜면 AI가 내 행동과 대사까지 써요. 내 행동은 직접 쓰고 싶다면 꺼 두세요 |
| **한 컷** | 켜면 그림이 나오는 작품에서 답변마다 그림이 한 장만 나와요. 글 분량은 그대로예요 |
| **최대 출력량** | 더 긴 답변을 받을 수 있어요. 스파크가 더 들 수 있어서 [더 긴 답변 받기](/chatting/ai-models.md#더-긴-답변-받기)에 따로 정리했어요 |

:::info[이 설정은 모든 채팅방에 적용돼요]
위 다섯 가지는 지금 쓰는 브라우저나 앱에 저장돼서 다른 채팅방에도 똑같이 적용돼요. 다른 기기에서는 다시 골라야 해요. 채팅방마다 따로 저장되는 것은 아래 **유저 노트**와 **페르소나**예요.
:::

## 유저 노트와 페르소나

이 채팅방에만 저장되는 설정이에요. 다른 기기에서 열어도 그대로예요.

**유저 노트**에는 캐릭터와의 관계, 배경, 꼭 기억했으면 하는 설정을 2,000자까지 적어요. ⋮ 메뉴의 **채팅 설정 → 유저 노트**에서 적고 **저장**을 누르면, AI가 이 채팅방에서 답할 때마다 참고해요.

```text
나는 서연의 소꿉친구고, 서로 반말을 쓴다.
지난주에 크게 다퉈서 아직 어색하다.
```

**페르소나**는 이 채팅방에서 쓰는 내 이름과 역할이에요. ⋮ 메뉴의 **채팅 설정 → 페르소나**에서 바로 고치거나, **불러오기**로 내 페르소나 목록에서 하나를 골라 **저장**해요.

목록에서 페르소나를 고쳤다면, 이미 있는 채팅방에는 그 방에서 다시 불러와 **저장**해야 반영돼요. 페르소나를 만드는 방법은 [페르소나 설정](/account/persona.md)에 있어요.

## 처음부터 다시 읽기

1. ⋮ 메뉴에서 **처음부터 보기**를 눌러요.
2. 첫 장면부터 차례로 읽어요. 읽는 동안 입력창 자리에 **처음부터 보는 중**이 보이고, 메시지를 보내거나 고칠 수는 없어요.
3. 다 읽었으면 **대화로 돌아가기**를 눌러요. 쓰던 글은 그대로 남아 있어요.

## 예전 채팅방 찾기

같은 작품에서 새 대화를 시작했다면 예전 채팅방은 여기 있어요.

1. ⋮ 메뉴에서 **이전 채팅 보기**를 눌러요.
2. 채팅방을 누르면 **마지막 대화**와 함께 **이어하기**, **숨기기**, **삭제**가 나와요.
3. **이어하기**를 누르면 그 채팅방으로 가요.

숨긴 채팅방은 **이전 채팅** 창 오른쪽 위의 눈 모양 아이콘을 눌러 **숨긴 채팅**에서 찾아요. 채팅방을 누르고 **숨김 해제**를 누르면 다시 보여요.

:::danger[삭제한 채팅방은 되돌릴 수 없어요]
삭제하기 전에 창에 보이는 **마지막 대화**로 어느 방인지 확인하세요.
:::

## 북마크와 분기 만들기

마음에 드는 지점을 저장해 두고, 나중에 그 지점부터 다른 전개를 새 채팅방에서 해 볼 수 있어요.

1. AI 답변 아래의 책갈피 아이콘(**북마크 추가**)을 눌러요.
2. 필요하면 이름을 적고 **저장**해요. 이름은 50자까지 쓸 수 있고, 비워 둬도 돼요.
3. 나중에 ⋮ 메뉴의 **북마크 목록**에서 저장한 지점을 찾아요.
4. 그 지점부터 다시 해 보려면 갈래 모양 아이콘(**이 시점으로 분기하기**)을 누르고 **확인**을 눌러요. 그 지점까지의 대화가 담긴 새 채팅방이 열리고, 원래 채팅방은 그대로 남아요. 유저 노트와 페르소나도 새 채팅방으로 옮겨 가요.

:::warning[북마크한 답변은 더 고칠 수 없어요]
북마크를 저장하면 그 답변과 그 앞의 메시지는 다시 생성·수정·삭제할 수 없어요. 북마크를 지워도 풀리지 않아요. 마지막 답변을 고칠 생각이라면 먼저 고친 뒤에 북마크하세요.
:::

북마크 목록의 휴지통 아이콘(**북마크 삭제**)은 북마크만 지워요. 지운 북마크는 되돌릴 수 없어요.

## 대화 캡처하기

1. ⋮ 메뉴에서 **대화 캡쳐**를 눌러요.
2. 담을 첫 메시지를 누르고, 여러 개를 담으려면 마지막 메시지도 눌러 범위를 정해요.
3. 내 메시지를 빼려면 **내 대사 제외하고 캡쳐**(앱은 **내 대사 제외**)를 켜요.
4. 웹은 **이미지 다운로드**, 앱은 **이미지 저장**을 눌러요.

앱에서는 사진 접근 권한을 묻거나 공유 화면이 열릴 수 있어요. 화면 안내에 따라 저장할 곳을 고르세요. 그만두려면 **취소**를 눌러요.

## 글자와 화면 표시 바꾸기

채팅방 오른쪽 위의 팔레트 아이콘을 누르면 **UI 설정**이 열려요.

| 묶음 | 바꿀 수 있는 것 |
| --- | --- |
| 보기 | **UI 모드**: **소설**, **채팅**, **1:1** |
| 읽기 | **글자 크기**, **줄 간격**, **글꼴**, **스트리밍 속도**(글이 나타나는 속도) |
| 색 | **글자 색상**: 캐릭터 대사, 사용자 대사, 캐릭터 지문, 사용자 지문 |
| 화면 | **채팅 높이**, **채팅창 투명도**, **이미지 높이**(소설), **캐릭터 이름 표시**(채팅) |
| 영상 | **영상 반복 재생**, 영상 대신 그림을 보여 주는 **이미지 모드** |

- 보기 방식마다 설정이 따로 저장돼요. **초기화**는 지금 보기 방식만 기본값으로 되돌려요.
- 지금 쓰는 브라우저나 앱에 저장돼서 모든 채팅방에 적용돼요.

## 자주 막히는 곳

<details>
<summary>대화 글이 사라지고 그림만 보여요</summary>

채팅방 오른쪽 위의 눈 아이콘을 다시 누르면 글이 돌아와요.

</details>

<details>
<summary>설정을 바꿨더니 다른 채팅방도 바뀌었어요</summary>

**채팅 설정**의 문체 스타일·스토리 부스터·사칭 허용·한 컷·최대 출력량과 **UI 설정**은 이 기기의 모든 채팅방에 적용돼요. 채팅방마다 다르게 하고 싶은 내용은 **유저 노트**에 적으세요.

</details>

<details>
<summary>불러온 페르소나가 적용되지 않아요</summary>

**불러오기**로 페르소나를 고른 뒤 **저장**까지 눌러야 이 채팅방에 적용돼요.

</details>

<details>
<summary>답변을 다시 생성하거나 고칠 수 없어요</summary>

버튼은 가장 마지막 AI 답변에만 있어요. 북마크한 답변과 그 앞의 메시지도 고칠 수 없어요. "분기된 대화가 참조하고 있어 수정하거나 삭제할 수 없습니다"가 뜨면 북마크 때문이에요.

</details>

<details>
<summary>예전 채팅방이 안 보여요</summary>

⋮ 메뉴의 **이전 채팅 보기**에서 찾아요. 숨긴 채팅방은 그 창 오른쪽 위의 눈 모양 아이콘을 눌러 **숨긴 채팅**에서 찾아요. 작품 전체를 숨겼다면 [자주 묻는 질문](/faq/faq.md#대화)의 "채팅방이 사라졌어요"를 확인하세요.

</details>

<details>
<summary>이 채팅방의 문제를 문의하고 싶어요</summary>

⋮ 메뉴의 **채팅방 ID 복사**를 눌러 ID를 복사한 뒤, [문의하기](/faq/faq.md#문의하기)로 무슨 일이 있었는지와 함께 보내 주세요.

</details>
