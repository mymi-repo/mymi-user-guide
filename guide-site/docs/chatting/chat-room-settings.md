# 채팅방 설정하기

V1 방식으로 만든 작품과 V2 방식으로 만든 작품 모두 채팅방에서 같은 기본 설정 메뉴를 사용합니다. 다만 작품이 제공하는 도입부와 추천 페르소나는 다를 수 있습니다.

> **먼저 구분하세요.** 채팅 화면 **오른쪽 위 ⋮ 버튼**은 채팅방 관리·대화 설정 메뉴를 엽니다. 그 옆 **팔레트 아이콘**은 글자·색상·보기 방식 등을 바꾸는 UI 설정을 엽니다. 아래쪽의 입력창 주변에서 메뉴를 찾을 필요는 없습니다.

## 1. 채팅방 관리 메뉴 열기

대화 중 화면 오른쪽 위의 ⋮를 누르면 **채팅방 관리** 메뉴가 옆에서 열립니다. 맨 위에는 로그인한 계정의 스파크 잔액 또는 게스트 체험 잔여 횟수가 표시됩니다. 이 영역을 누르면 계정 상태에 따라 충전 화면이나 로그인 안내로 이동합니다.

**채팅 관리** 영역에서 다음 기능을 사용할 수 있습니다.

- **새 채팅 시작:** 현재 작품의 상세 화면을 다시 엽니다. 원하는 도입부와 페르소나를 선택한 뒤 **새 대화 시작**을 눌러 별도의 방을 만듭니다. 이 메뉴 항목을 누르는 즉시 새 방이 생성되는 것은 아닙니다.
- **이전 채팅 보기:** 같은 작품의 대화방 목록을 엽니다. 방을 선택하면 마지막 메시지를 확인하고 **이어하기**를 누를 수 있습니다. 목록에서 **숨기기**와 **삭제**도 선택할 수 있습니다.
- **채팅방 ID 복사:** 현재 방의 ID를 클립보드에 복사합니다. 특정 방의 문제를 문의할 때 사용하세요.
- **대화 캡쳐:** 선택한 메시지 범위를 이미지로 만듭니다. 절차는 아래 6번에서 설명합니다.
- **북마크 목록:** 저장한 북마크를 보고 분기를 만들거나 북마크를 삭제합니다.

**숨기기와 삭제는 다릅니다.** 숨긴 방은 숨긴 채팅 목록에서 다시 표시할 수 있습니다. 삭제한 대화는 복구할 수 없으므로, 삭제 확인창의 대상을 반드시 확인하세요.

## 2. 대화 설정 바꾸기

**⋮ → 채팅 설정**에서 다음 항목을 조정합니다. 대화에 반영되는 항목은 변경 전 메시지를 다시 쓰는 기능이 아니라, 이후 대화를 이어갈 때 참고할 설정입니다.

### 유저 노트와 페르소나

- **유저 노트:** 캐릭터와의 관계, 배경, 말투, 계속 기억했으면 하는 상황 등을 최대 **2,000자**로 적고 **저장**합니다. 이 내용은 대화 중 AI가 참고합니다. 작품의 공개 설정이나 다른 방의 노트를 편집하는 기능은 아닙니다.
- **페르소나:** 이 방에서 사용할 나의 이름과 역할을 수정합니다. 내 목록의 역할을 쓰려면 **불러오기 → 페르소나 선택 → 저장** 순서로 진행하세요. 불러오기만 해서는 이 방에 적용되지 않습니다. 자세한 방법은 [페르소나 설정](/account/persona.md)을 참고하세요.

### 문체와 응답 방식

- **문체 스타일:** **소설형**은 묘사와 서술이 풍부한 문체, **라노벨형**은 대화가 중심인 가벼운 문체입니다. 아래의 **UI 소설 모드**는 화면 표시 방식이므로 문체 스타일과 다른 설정입니다.
- **스토리 부스터:** 켜면 AI가 사건과 전개를 더 적극적으로 제안하도록 합니다.
- **사칭 허용:** 켜면 AI가 내 행동이나 대사도 서술할 수 있습니다. 내 행동은 직접 쓰고 싶다면 꺼두세요.
- **한 컷:** 켜면 한 번의 응답에서 한 장면씩 진행하도록 합니다.
- **최대 출력량:** 로그인한 계정에서 모델별 응답 최대 길이를 선택합니다. 선택에 따라 추가 사용량 안내가 표시될 수 있으니 화면에 제시된 조건을 확인하세요. 게스트에게는 이 항목이 보이지 않습니다.

토글이나 문체를 바꿔도 이미 표시된 메시지는 다시 생성되지 않습니다.

## 3. 장기 기억과 기억 조각 보기

**⋮ → 기억 관리**에는 성격이 다른 두 화면이 있습니다.

- **장기 기억:** 대화의 전체 흐름을 정리한 내용을 확인합니다. 대화가 충분히 쌓이지 않았다면 아직 내용이 없다는 안내가 나올 수 있습니다.
- **기억 조각:** 대화에서 기록된 중요한 순간을 목록으로 보고 검색합니다. 이 화면 위쪽의 **기억 조각 사용** 스위치로 이후 대화에 기억 조각을 사용할지 선택합니다.

**기억 사용 스위치는 채팅 설정의 메인 목록이 아니라 기억 조각 화면 안**에 있습니다. 두 화면 모두 자동으로 만들어진 내용을 확인하는 곳이며, 유저 노트처럼 직접 내용을 작성하는 입력란은 아닙니다.

## 4. 글자와 화면 표시 바꾸기

채팅 화면 오른쪽 위의 **팔레트 아이콘 → UI 설정**을 엽니다.

- **UI 모드:** **채팅 / 1:1 / 소설** 중 선택합니다. 모드가 달라도 같은 대화 기록을 다른 방식으로 읽습니다.
- **읽기 환경:** 글자 크기, 줄 간격, 채팅 높이, 채팅창 투명도, 스트리밍 속도를 조절합니다. 스트리밍 속도는 화면에서 활성화된 경우에만 바꿀 수 있습니다.
- **글꼴·색상:** 글꼴과 캐릭터/사용자 대사·지문의 색을 선택합니다. **캐릭터 이름 표시**는 채팅 모드에서, **이미지 높이**는 소설 모드에서 조절합니다.
- **영상 설정:** 영상 반복 재생과, 영상 대신 이미지를 표시하는 **이미지 모드**를 선택합니다. 작품에 해당 미디어가 없으면 화면 변화가 없을 수 있습니다.
- **초기화:** 지금 선택한 UI 모드의 표시 설정을 기본값으로 되돌립니다. 대화 메시지나 방 설정을 삭제하지 않습니다.

UI 설정은 **현재 웹 브라우저 또는 앱에 로컬 저장**됩니다. 다른 채팅방에서도 같은 표시 설정이 보일 수 있으며, 웹과 앱 사이에 자동으로 동기화되는 방별 설정은 아닙니다.

## 5. 북마크와 분기 만들기

1. 대화 중 보관할 지점의 메시지 동작에서 **북마크 아이콘**을 누릅니다.
2. 필요한 경우 북마크 이름을 입력합니다. 이름은 선택 사항이며 **50자 이내**입니다.
3. 경고문을 읽고 **저장**합니다.
4. 나중에 **⋮ → 북마크 목록**을 열어 저장한 지점을 찾습니다.
5. 다른 전개를 시도하려면 해당 북마크의 **분기 아이콘 → 확인**을 누릅니다. 그 지점에서 새 채팅방이 열리고, 원래 대화는 유지됩니다.

> **북마크 전에 꼭 확인하세요.** 북마크를 저장하면 **그 지점 이전의 메시지**는 수정·삭제·재생성할 수 없게 됩니다. 내용을 고칠 계획이 있다면 저장하기 전에 먼저 수정하세요.

북마크 목록의 삭제 아이콘은 **북마크를 지우는 동작**입니다. 북마크에서 분기하는 동작과 구분해서 확인하세요.

## 6. 대화 캡처하기

1. **⋮ → 대화 캡쳐**를 선택합니다.
2. 캡처할 첫 메시지를 누릅니다. 여러 메시지를 담으려면 마지막 메시지도 눌러 범위를 지정합니다. 한 메시지만 담을 때는 한 번 선택하면 됩니다.
3. 내 메시지를 빼고 싶으면 아래쪽의 **내 대사 제외하고 캡쳐**를 켭니다.
4. 선택된 메시지 수를 확인하고, 웹에서는 **이미지 다운로드**, 앱에서는 **이미지 저장**을 누릅니다.

웹은 이미지 파일을 다운로드합니다. 앱은 운영체제에 따라 사진 저장 권한이나 공유 화면이 나타날 수 있으므로 그 화면의 안내를 따르세요. 선택 범위에 저장할 메시지가 없으면 버튼이 비활성화됩니다. 진행하지 않으려면 **취소**를 누르세요.

## 설정이 적용되지 않는 것처럼 보일 때

- **새 채팅 시작**을 눌렀는데 방이 그대로라면 작품 상세에서 도입부·페르소나를 정한 뒤 **새 대화 시작**까지 진행했는지 확인하세요.
- 페르소나를 **불러오기**만 했다면 마지막 **저장**을 누르세요.
- 장기 기억이나 기억 조각이 비어 있다면 대화를 더 진행한 뒤 다시 확인하세요.
- UI 모드를 바꿨는데 문체가 그대로라면 **⋮ → 문체 스타일**을 따로 선택하세요.
- 이전 방을 찾지 못하면 **이전 채팅 보기**의 숨긴 채팅 목록도 확인하세요.

처음 대화를 여는 방법은 [대화하기](/chatting/chat-with-character.md)를 참고하세요.
