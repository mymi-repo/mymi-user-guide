# AI 모델 안내

AI 모델은 **채팅에서 다음 답변을 생성할 엔진**입니다. 작품의 세계관이나 등장인물을 바꾸는 설정이 아니며, 대화 중 모델을 바꿔도 이전 메시지는 그대로 남습니다.

## V1 작품과 V2 작품에서 무엇이 다른가요?

**채팅에서 고를 수 있는 모델과 차감 방식은 V1·V2 작품에 공통**입니다. V2 제작자는 기본 정보에서 작품에 어울리는 모델을 최대 5개까지 **추천**할 수 있고, 선택한 모델은 작품 상세의 **크리에이터 추천 모델**로 표시됩니다. 이는 독자를 위한 안내입니다. 추천 모델이 자동으로 선택되거나 다른 모델의 사용이 막히지는 않습니다. V1 작품에는 이 추천 칩이 없습니다.

**MYMI Plus v2 / MYMI Lite v2의 ‘v2’는 AI 모델의 버전**입니다. 작품을 V1 편집기로 만들었는지 V2 편집기로 만들었는지와 관계없이 사용할 수 있습니다.

## 1. 채팅에서 모델 바꾸기

1. 로그인한 뒤 채팅방 **입력창 왼쪽의 ⚡ 버튼**을 누릅니다.
2. **모델 선택** 창에서 MYMI·Gemini·Claude·xAI·OpenAI 제공사 묶음을 펼칩니다.
3. 모델의 소개 문구와 표시 가격, 할인 배지가 있다면 할인가를 확인하고 원하는 모델을 누릅니다.
4. 선택한 모델은 **다음 답변부터** 사용됩니다. 이미 받은 답변이나 대화 기록은 바뀌지 않습니다.

선택한 모델은 **현재 브라우저 또는 앱 기기에 저장되어 다른 채팅방에서도 이어집니다.** 방마다 독립적으로 고정하거나 웹·앱 사이에 자동 동기화되는 설정은 아닙니다. 이전에 선택한 **MYMI Plus/Lite v1은 같은 등급의 v2로**, **Gemini 3.5/3.6 Flash는 3.8 Flash로** 전환됩니다. 그 밖에 선택했던 모델이 제공 종료되면 다시 고르라는 안내가 나올 수 있습니다.

게스트 체험에서는 모델 선택 버튼이 보이지 않고 **Gemini 3.8 Flash**가 고정으로 사용됩니다. 로그인 후에는 직접 고를 수 있습니다.

## 2. 현재 제공 모델과 기본 정가

아래는 **2026년 9월 23일 기준 정가**입니다. ‘기본가’는 메시지 한 번의 기본 출력량까지 포함하며, ‘추가 단가’는 그 양을 넘긴 **실제 출력·추론 합계 100토큰당** 적용됩니다. 모두 스파크 상당의 수치입니다. 기간 한정 할인 중에는 **기본가와 추가 단가가 함께 달라질 수 있으므로**, 전송 전 모델 선택 창과 최대 출력량 화면에 표시된 가격을 확인하세요.

### MYMI 모델

- **MYMI Plus v2:** 기본 60 · 추가 100토큰당 4. 풍부한 묘사와 깊이 있는 대화에 맞춘 상위 모델입니다.
- **MYMI Lite v2:** 기본 20 · 추가 100토큰당 1. 가벼운 일상 대화에 맞춘 기본 모델입니다.

### Gemini 모델

- **Gemini 3.1 Pro:** 기본 120 · 추가 100토큰당 8. 맥락 파악을 중시할 때 살펴보세요.
- **Gemini 2.5 Pro:** 기본 80 · 추가 100토큰당 5. 섬세한 표현과 몰입감을 중시할 때 살펴보세요.
- **Gemini 3.8 Flash:** 기본 100 · 추가 100토큰당 6. 이야기의 흐름을 이어가는 최신 Flash 모델입니다.
- **Gemini 3.7 Flash:** 기본 100 · 추가 100토큰당 6. 작품 설정을 꼼꼼히 따르는 Flash 모델입니다.
- **Gemini 3 Flash:** 기본 50 · 추가 100토큰당 3. 속도와 표현의 균형을 원할 때 살펴보세요.
- **Gemini 2.5 Flash:** 기본 40 · 추가 100토큰당 2. 빠른 응답을 비교적 가볍게 이용할 때 살펴보세요.

### Claude 모델

- **Claude Opus 4.6 / Opus 4.5:** 각각 기본 300 · 추가 100토큰당 20. 깊은 추론이나 창의적인 글쓰기를 중시할 때 살펴보세요.
- **Claude Sonnet 4.6 / Sonnet 4.5:** 각각 기본 100 · 추가 100토큰당 6. 섬세한 감정 표현이나 균형 잡힌 대화를 원할 때 살펴보세요.

### xAI·OpenAI 모델

- **Grok 4.3 / Grok 4.20:** 각각 기본 60 · 추가 100토큰당 4. 빠른 대화나 창의적인 답변을 비교해 볼 수 있습니다.
- **GPT-5.4:** 기본 120 · 추가 100토큰당 8. 정확한 이해와 안정적인 답변을 중시할 때 살펴보세요.

모델 소개는 **선택 화면의 안내를 요약**한 것이며, 실제 답변의 길이와 느낌은 작품·대화·설정에 따라 달라집니다. 모델 목록과 정가는 바뀔 수 있습니다.

## 3. 최대 출력량과 실제 차감

로그인한 계정이라면 **채팅방 오른쪽 위 ⋮ → 채팅 설정 → 최대 출력량**에서 모델마다 답변 길이의 상한을 고를 수 있습니다. 설정 방법은 [채팅방 설정하기](/chatting/chat-room-settings.md)에도 나옵니다.

- 기본 포함량은 대부분 **1,500토큰**, **MYMI Plus v2는 3,000토큰**입니다. 기본값을 유지하면 추가 출력 비용은 없습니다.
- 선택지는 **1,500 / 2,000 / 3,000 / 4,500 / 6,000토큰** 중 해당 모델의 기본 포함량 이상입니다. 높은 값을 고르면 더 긴 답변을 받을 **상한**이 늘어나는 것이지, 항상 그만큼 길게 쓰는 것은 아닙니다.
- 기본 포함량을 넘은 **실제 출력 토큰과 추론 토큰의 합계**를 100토큰 단위로 올림해 추가 비용을 계산합니다.
- 메시지를 보낼 때는 선택한 상한을 기준으로 먼저 차감하고, 정상 응답이 끝나면 실제 사용량에 맞춰 정산하여 남은 금액을 돌려줍니다. 응답 거부나 생성 실패는 별도 정산 규칙을 따릅니다.
- 최대 출력량은 **모델별로 따로 기억**되지만 현재 브라우저·앱의 로컬 설정입니다. 다른 기기와 자동 동기화되지 않습니다.

**정가 계산 예:** MYMI Plus v2의 최대 출력량을 4,500토큰으로 골랐다면 기본 3,000토큰을 넘는 1,500토큰분까지 고려해 **120 스파크를 선차감**합니다. 정상 답변의 실제 출력·추론 합계가 3,240토큰이라면 초과 240토큰을 3단위로 올림해 **60 + 3 × 4 = 72 스파크**가 최종 차감되고, **48 스파크가 반환**됩니다. 할인 중이라면 화면에 표시된 할인가와 단가로 계산됩니다.

Gemini 모델은 **Gemini 전용 스파크가 먼저** 차감되고 부족한 부분은 일반 스파크로 보충할 수 있습니다. 다른 제공사 모델에는 일반 스파크를 사용합니다. 최종 이용 내역은 프로필의 **스파크 이용 내역**에서 확인하세요.

답변이 길이 한도에 걸려 끊기면 안내 창에서 **최대 출력량 조절**로 이동할 수 있습니다. 현재 선택한 모델이 목록에서 사라져 대화를 보낼 수 없다면 입력창 왼쪽 ⚡를 눌러 제공 중인 모델을 다시 선택하세요.
