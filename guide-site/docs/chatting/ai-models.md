# AI 모델 안내

채팅 답변을 만드는 AI 모델을 고르는 방법과 모델별 스파크 가격, 더 긴 답변을 받을 때 드는 스파크를 알려 드려요.

## 모델 바꾸기

1. 채팅방 입력창 왼쪽의 ⚡ 버튼을 눌러요. 로그인했을 때만 보여요.
2. **모델 선택** 창에서 **MYMI 모델**, **Gemini 모델**, **Claude 모델**, **xAI 모델**, **OpenAI 모델** 중 하나를 펼쳐요. 지금 쓰는 모델은 제공사 이름 옆에 표시돼요.
3. 소개와 가격을 보고 원하는 모델을 눌러요. 다음 답변부터 그 모델로 대화해요.

- 처음에는 **Gemini 3.1 Pro**가 골라져 있어요.
- 모델 이름 앞의 점은 지금 상태예요. 초록은 **원활**, 주황은 **보통**(답변이 느린 편), 빨강은 **혼잡**(실패가 잦은 편)이에요. 답변이 자꾸 실패하면 초록 점 모델로 바꿔 보세요.
- **50% 할인** 배지가 있는 모델은 할인된 가격이 보여요. **임시 비활성화**로 표시된 모델은 지금 고를 수 없어요.
- 고른 모델은 지금 쓰는 브라우저나 앱에 저장돼서 다른 채팅방에서도 그대로 써요. 다른 기기에서는 다시 골라요.
- 작품 상세의 **크리에이터 추천 모델**은 제작자의 추천이에요. 대화에 쓸 모델은 ⚡ 버튼에서 골라요.
- 로그인하지 않으면 **Gemini 3.8 Flash**로 5번까지 체험할 수 있어요.

## 모델별 가격

**2026년 10월 1일 기준 정가**예요. 단위는 스파크예요.

- **기본가**: 답변 한 번의 가격이에요. 기본 길이까지 포함해요.
- **추가 100토큰당**: 최대 출력량을 높여 기본 길이를 넘긴 만큼 더 드는 가격이에요. 토큰은 AI가 글의 양을 세는 단위예요.

할인 중인 모델은 모델 선택 창에 할인된 가격이 보이니, 보내기 전에 확인하세요.

## 더 긴 답변 받기

답변 길이에는 모델마다 상한이 있어요. 더 긴 답변을 받고 싶으면 최대 출력량을 높여요.

1. ⋮ 메뉴의 **채팅 설정**에서 **최대 출력량**을 눌러요. 로그인했을 때만 보여요.
2. **최대 출력량 조절** 창에서 모델별로 길이를 골라요. **기본**보다 높이면 "메시지당 최대 +N 스파크"가 함께 보여요.
3. 고른 길이는 지금 쓰는 브라우저나 앱에 저장돼요.

- 고를 수 있는 길이는 1,500 / 2,000 / 3,000 / 4,500 / 6,000토큰이에요. 기본은 대부분 1,500토큰이고, MYMI Plus v2는 3,000토큰이에요.
- 높여도 실제로 쓴 만큼만 차감돼요. 보낼 때 고른 길이만큼 먼저 차감하고, 답변이 끝나면 실제 길이로 다시 계산해 남은 스파크를 돌려줘요.

**계산 예:** MYMI Plus v2를 4,500토큰으로 골랐다면 보낼 때 **120 스파크**를 먼저 차감해요. 실제 답변이 3,240토큰이면 기본 3,000토큰을 넘은 240토큰을 100토큰 단위로 올려 3단위가 되고, **60 + 3 × 4 = 72 스파크**만 차감돼요. 나머지 **48 스파크**는 돌려받아요.

:::warning[먼저 차감할 스파크가 있어야 보낼 수 있어요]
최대 출력량을 높게 두면 보낼 때 그만큼을 먼저 차감해요. 남은 스파크가 그보다 적으면 "크레딧이 부족합니다"가 뜨고 보내지지 않아요. 최대 출력량을 **기본**으로 낮추거나 충전하세요.
:::

답변이 길이 한도에서 끊기면 "최대 출력량 한도에 도달했어요" 창이 떠요. **조절하기**를 눌러 더 긴 길이를 고르세요.

## 답변이 실패하거나 거부되면

| 상황 | 차감되는 스파크 |
| --- | --- |
| 답변을 정상적으로 받았어요 | 실제 답변 길이로 계산해요 |
| "모델이 응답을 거부했습니다" | 기본가의 20%만 차감하고 나머지는 돌려줘요 |
| 답변을 만들다 오류가 났어요 | 먼저 차감한 스파크를 모두 돌려줘요 |
| "추론에 출력량을 모두 사용했어요" | 모두 돌려줘요. 보낸 글은 입력창에 남아 있으니 다시 보내세요 |

차감된 스파크는 **마이페이지 → 내 스파크 → 사용내역 보기**의 **사용** 탭에서 볼 수 있어요.

## 자주 막히는 곳

<details>
<summary>⚡ 버튼이 보이지 않아요</summary>

로그인하지 않으면 모델을 고를 수 없고, 체험용 모델인 **Gemini 3.8 Flash**로 대화해요. 로그인하면 ⚡ 버튼이 나와요.

</details>

<details>
<summary>"현재 선택된 모델은 지금 사용할 수 없어요"라고 나와요</summary>

고른 모델을 지금 쓸 수 없는 상태예요. **모델 선택하기**를 눌러 다른 모델을 고르세요.

</details>

<details>
<summary>답변이 자꾸 느리거나 실패해요</summary>

모델 선택 창에서 모델 이름 앞의 점을 확인하세요. 주황(**보통**)이나 빨강(**혼잡**)이면 초록(**원활**) 점 모델로 바꿔 보세요.

</details>

<details>
<summary>"크레딧이 부족합니다"라고 나오며 보내지지 않아요</summary>

최대 출력량을 높여 두었다면 보낼 때 그만큼을 먼저 차감해요. **최대 출력량**을 **기본**으로 낮추거나 충전하세요.

</details>

<details>
<summary>다른 기기에서는 모델이 달라요</summary>

모델과 최대 출력량은 기기마다 따로 저장돼요. 그 기기에서 다시 골라 주세요.

</details>
