# MYMI에서 사용할 수 있는 AI 모델 안내

## AI 모델이란?

MYMI에서는 여러 종류의 AI 모델을 제공합니다. 각 모델마다 특성이 다르며, 대화 스타일이나 목적에 맞게 선택하여 사용할 수 있습니다. 메시지 전송 시 **스파크**가 소비됩니다.

아래 표의 스파크는 **정가 기준**입니다. 출시 기념 할인 같은 이벤트가 진행 중이면 모델 선택 화면에 할인가가 함께 표시됩니다.

## 모델 변경 방법

1. 채팅방 하단 입력창 옆의 **모델 선택 버튼**을 클릭합니다.
2. 원하는 모델을 선택합니다.
3. 선택 즉시 적용됩니다.

## 답변 길이와 추가 차감

모델마다 **기본 출력량**이 정해져 있고, 여기까지는 위 표의 스파크에 모두 포함됩니다. 기본값은 **1,500토큰**이며 MYMI Plus v1만 **3,000토큰**입니다.

더 긴 답변을 원하면 **채팅방 메뉴 → 채팅 설정 → 최대 출력량**에서 올릴 수 있습니다.

* 선택할 수 있는 값은 **1,500 / 2,000 / 3,000 / 4,500 / 6,000토큰**입니다. 모델의 기본 출력량보다 낮은 값은 표시되지 않습니다.
* 기본 출력량을 넘는 분량은 **100토큰 단위로 모델별 단가만큼** 스파크가 추가 차감됩니다.
* 메시지를 보낼 때 선택한 최대치 기준으로 먼저 차감되고, 답변이 끝나면 **실제로 생성된 만큼만** 최종 차감됩니다. 짧게 나오면 그만큼 돌려받습니다.
* 차감 내역은 **프로필 → 스파크 이용 내역**에서 확인할 수 있습니다.

:::tip

답변이 길이 한도에 걸려 중간에 끊기면 안내 창이 뜹니다. 거기서 바로 최대 출력량을 조절할 수 있습니다.

:::

## 모델 선택 팁

* **빠른 응답**이 필요하면 Flash 계열 모델을 선택하세요.
* **품질 높은 대화**가 필요하면 Opus나 Pro 계열 모델을 선택하세요.
* 모델을 변경해도 기존 대화 기록은 유지되며, 채팅방마다 다른 모델을 설정할 수 있습니다.
* 최대 출력량은 모델별로 따로 기억됩니다.

:::warning

제공되는 모델의 종류와 사양은 업데이트에 따라 변경될 수 있습니다. 최신 정보는 앱 내 모델 선택 화면을 참고해 주세요.

:::
