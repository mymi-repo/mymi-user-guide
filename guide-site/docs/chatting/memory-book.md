# 장기기억 & 기억 조각

대화가 길어지면 MYMI는 지난 내용을 **장기 기억**으로 요약하고, 중요한 사건을 **기억 조각**으로 정리합니다. 두 기능은 채팅방의 ⋮ 메뉴에 있는 **기억 관리**에서 따로 확인합니다.

## 무엇이 다른가요?

- **장기 기억:** 대화의 전체 흐름과 관계·사건을 짧게 정리한 내용입니다.
- **기억 조각:** 대화에서 중요한 순간을 별도 카드로 정리한 내용입니다. 카드에 제목, 관련 인물, 대화 턴 범위가 표시될 수 있습니다. 카드를 누르면 자세한 내용을 펼쳐 볼 수 있습니다.
- **유저 노트:** **직접 작성하고 저장**하는 메모입니다. AI가 계속 참고해야 할 이름, 관계, 약속, 말투 등을 적어 두세요.

장기 기억과 기억 조각은 대화가 쌓이며 자동으로 만들어집니다. 아직 내용이 없다면 대화를 더 진행한 뒤 다시 확인하세요.

## 1. 장기 기억 확인하기

1. 채팅 화면 오른쪽 위의 ⋮를 누릅니다.
2. **기억 관리 → 장기 기억**을 선택합니다.
3. 요약된 대화 흐름을 읽습니다. **아직 장기 기억이 없어요**라고 나오면 대화를 더 진행한 뒤 다시 확인하세요.

## 2. 기억 조각 찾기

1. 채팅 화면 오른쪽 위의 ⋮를 누르고 **기억 관리 → 기억 조각**을 선택합니다.
2. 제목과 관련 인물, 턴 범위를 보며 원하는 카드를 찾습니다. **T10–T20**처럼 표시된 숫자는 대화의 턴 범위입니다.
3. 카드를 누르면 내용을 펼치고, 다시 누르면 접습니다.
4. 상단 검색창에 사건·인물·상황을 입력하면 **관련된 기억 조각**을 찾을 수 있습니다. 검색어를 지우면 전체 목록으로 돌아갑니다.
5. 조각이 많으면 아래로 내려 더 확인합니다. 앱에서는 **더 불러오기**를 누를 수 있습니다.

검색은 의미가 비슷한 내용도 찾습니다. 원하는 결과가 나오지 않으면 다른 인물이나 사건으로 다시 검색하거나 대화를 더 진행하세요.

## 3. 기억 조각 사용 켜고 끄기

로그인한 뒤 기억 조각 화면 맨 위의 **기억 조각 사용** 스위치를 켜면 이후 답변을 만들 때 관련 조각을 참고합니다. 앱에서는 같은 스위치가 **기억 사용**으로 표시됩니다. 스위치를 끄면 기억 조각을 제외하고 답변을 만듭니다.

- 기존 기억 조각은 목록에 남아 있어 다시 켜서 사용할 수 있습니다.
- 장기 기억은 별도로 대화의 흐름을 요약합니다.
- 채팅방이나 앱·브라우저를 다시 열면 스위치 상태를 확인하세요.

## 기억을 더 안정적으로 활용하려면

예를 들어 **두 인물이 화해했다는 큰 흐름**은 장기 기억에서, **화해할 때 나눈 특정 약속**은 기억 조각에서 찾아볼 수 있습니다. 그 약속을 앞으로 반드시 지켜야 한다면 **유저 노트**에 직접 적어 두는 편이 명확합니다. [채팅방 설정하기](/chatting/chat-room-settings.md)에서 유저 노트를 열고 저장할 수 있습니다.

AI가 지난 내용을 잘못 짚는다면 현재 채팅방의 장기 기억과 기억 조각을 확인하세요. 중요한 설정은 유저 노트에 적거나 다음 메시지에서 분명하게 알려 주세요.
