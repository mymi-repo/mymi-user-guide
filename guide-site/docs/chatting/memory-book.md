# 장기 기억과 기억 조각

대화가 길어지면 AI가 앞부분을 놓칠 수 있어요. 캐릭터가 지난 일을 잊었을 때 확인할 곳과 바로잡는 방법을 알려 드려요.

## 캐릭터가 지난 일을 잊었을 때

1. ⋮ 메뉴의 **기억 관리 → 기억 조각**에서 **기억 조각 사용**(앱은 **기억 사용**)이 켜져 있는지 확인해요.
2. **기억 관리 → 장기 기억**에서 지금까지의 흐름이 어떻게 정리됐는지 봐요.
3. 틀리게 기억하거나 빠진 내용은 ⋮ 메뉴의 **채팅 설정 → 유저 노트**에 바른 내용을 적고 **저장**해요.
4. 다음 메시지에서 한 번 짚어 줘도 좋아요. 예: "지난번에 약속한 장소 기억나?"

:::info[기억은 직접 고칠 수 없어요]
장기 기억과 기억 조각은 대화에서 자동으로 만들어지고, 직접 고치거나 지울 수는 없어요. 바로잡을 내용은 유저 노트에 적으세요.
:::

## 세 가지 기억

| 구분 | 무엇인가요 | 누가 만드나요 |
| --- | --- | --- |
| **장기 기억** | 지금까지 대화의 큰 흐름을 짧게 정리한 글 | 대화가 쌓이면 자동으로 |
| **기억 조각** | 중요한 순간을 하나씩 정리한 카드 | 대화가 쌓이면 자동으로 |
| **유저 노트** | 꼭 기억했으면 하는 설정을 적은 메모 | 내가 직접 |

예를 들어 두 인물이 화해했다는 큰 흐름은 장기 기억에, 화해하며 한 약속은 기억 조각에 남아요. 그 약속을 꼭 지키게 하고 싶다면 유저 노트에 적어 두세요.

## 장기 기억 보기

1. ⋮ 메뉴에서 **기억 관리 → 장기 기억**을 눌러요.
2. 정리된 흐름을 읽어요.

"아직 장기 기억이 없어요"가 나오면 대화를 더 나눠 보세요. 메시지가 20개쯤 쌓이면 처음 만들어지고, 그 뒤로도 대화가 쌓이면 새로 정리돼요.

## 기억 조각 찾기

1. ⋮ 메뉴에서 **기억 관리 → 기억 조각**을 눌러요.
2. 카드에는 제목, 관련 인물, 대화 위치(**T10-20**처럼)가 보여요. 카드를 누르면 펼쳐지고, 다시 누르면 접혀요.
3. 위쪽 검색창에 사건·인물·장소를 적으면 관련된 조각을 찾아요. 뜻이 비슷한 내용도 찾아 줘요.
4. 조각이 많으면 아래로 내려 더 봐요. 앱은 **더 불러오기**를 눌러요.

## 기억 조각 사용 끄기

**기억 조각 사용**(앱은 **기억 사용**)은 처음부터 켜져 있어요. 끄면 그 채팅방에 있는 동안 기억 조각을 빼고 답해요. 장기 기억과 유저 노트는 계속 참고해요.

- AI가 엉뚱한 기억 조각을 자꾸 꺼낼 때 잠시 꺼 보세요.
- 채팅방을 나갔다가 다시 들어오면 다시 켜져 있어요.
- 로그인하지 않은 체험 중에는 기억 조각을 쓰지 않아요.

## 자주 막히는 곳

<details>
<summary>"아직 장기 기억이 없어요"라고 나와요</summary>

아직 대화가 적어서 그래요. 메시지가 20개쯤 쌓이면 처음 만들어져요.

</details>

<details>
<summary>기억 조각을 검색해도 나오지 않아요</summary>

다른 인물 이름이나 사건으로 다시 검색해 보세요. 최근 대화는 아직 조각으로 정리되지 않았을 수 있어요.

</details>

<details>
<summary>잘못된 기억을 지우고 싶어요</summary>

기억은 지울 수 없어요. 바른 내용을 **유저 노트**에 적고 **저장**하세요. 잘못된 기억 조각을 AI가 자꾸 꺼낸다면 **기억 조각 사용**을 잠시 꺼 보세요.

</details>

<details>
<summary>꺼 둔 기억 조각 사용이 다시 켜져 있어요</summary>

채팅방에 들어올 때마다 다시 켜져요. 필요할 때마다 꺼 주세요.

</details>
