# 장기기억 & 기억 조각

대화가 길어지면 MYMI는 지난 내용을 **장기 기억**으로 요약하고, 중요한 사건을 **기억 조각**으로 정리합니다. 두 기능은 채팅방의 ⋮ 메뉴에 있는 **기억 관리**에서 따로 확인합니다. V1 작품과 V2 작품 모두 같은 채팅 기능을 사용합니다.

> **작품 설정과는 별개예요.** V1의 세계관·캐릭터 설정이나 V2의 프롬프트·로어북은 제작자가 작품을 편집하는 곳에서 관리합니다. 이 페이지의 기억은 독자가 작품 안에서 진행한 **대화 내용**을 바탕으로 만들어집니다.

## 무엇이 다른가요?

- **장기 기억:** 대화의 전체 흐름과 관계·사건을 짧게 정리한 내용입니다. 지난 메시지를 한 문장씩 그대로 보관한 기록은 아닙니다.
- **기억 조각:** 대화에서 중요한 순간을 별도 카드로 정리한 내용입니다. 카드에 제목, 관련 인물, 대화 턴 범위가 표시될 수 있습니다. 카드를 누르면 자세한 내용을 펼쳐 볼 수 있습니다.
- **유저 노트:** 위 두 기능과 달리 **직접 작성하고 저장**하는 메모입니다. AI가 계속 참고해야 할 이름, 관계, 약속, 말투 등을 명시하고 싶을 때 사용하세요.

장기 기억과 기억 조각은 자동으로 만들어지므로, 대화가 짧거나 정리가 아직 진행 중이면 비어 있을 수 있습니다. 자동 기억이 오래전의 모든 문장과 세부 사항을 완벽하게 재현하는 것은 아닙니다.

## 1. 장기 기억 확인하기

1. 채팅 화면 오른쪽 위의 ⋮를 누릅니다.
2. **기억 관리 → 장기 기억**을 선택합니다.
3. 요약된 대화 흐름을 읽습니다. **아직 장기 기억이 없어요**라고 나오면 대화를 더 진행한 뒤 다시 확인하세요.

이 화면의 내용은 읽기용입니다. 직접 고치는 입력창이나 저장 버튼은 없습니다. 새 요약이 바로 보이지 않으면 대화를 더 진행하고 채팅방을 다시 열어 확인해 보세요.

> **장기 기억 늘리기 안내:** 화면에는 **장기 기억 늘리기 · 500자 → 2,000자** 스위치가 표시됩니다. 현재 웹·앱에서는 이 스위치가 실제 요약 길이 변경이나 저장에 연결되어 있지 않습니다. 켰다는 이유만으로 요약이 2,000자로 늘어났다고 판단하지 마세요.

## 2. 기억 조각 찾기

1. 채팅 화면 오른쪽 위의 ⋮를 누르고 **기억 관리 → 기억 조각**을 선택합니다.
2. 제목과 관련 인물, 턴 범위를 보며 원하는 카드를 찾습니다. **T10–T20**처럼 표시된 숫자는 대화의 턴 범위입니다.
3. 카드를 누르면 내용을 펼치고, 다시 누르면 접습니다.
4. 상단 검색창에 사건·인물·상황을 입력하면 **관련된 기억 조각**을 찾을 수 있습니다. 검색어를 지우면 전체 목록으로 돌아갑니다.
5. 조각이 많으면 아래로 내려 더 확인합니다. 앱에서는 **더 불러오기**를 누를 수 있습니다.

검색은 의미가 비슷한 내용을 찾는 방식이라, 입력한 단어가 카드에 그대로 적혀 있지 않아도 결과가 나올 수 있습니다. 반대로 원하는 조각이 없을 수도 있습니다. 목록에 **기억 조각이 없습니다**라고 나오면 대화를 더 진행한 뒤 다시 확인하세요.

## 3. 기억 조각 사용 켜고 끄기

기억 조각 화면 맨 위의 **기억 조각 사용** 스위치를 켜면 이후 응답을 만들 때 관련 조각을 찾아 참고합니다. 앱에서는 같은 스위치가 **기억 사용**으로 표시됩니다. 끄면 이후 응답에 이 조각 검색 결과를 넣지 않습니다.

- 스위치를 꺼도 **이미 만들어진 기억 조각은 삭제되지 않습니다.** 다시 켜서 사용할 수 있습니다.
- 이 스위치는 **장기 기억 요약을 끄거나 삭제하는 기능이 아닙니다.** 장기 기억은 별도로 대화의 흐름을 정리합니다.
- 스위치 상태는 계정에 영구 저장되는 설정이 아니므로, 채팅방이나 앱·브라우저를 다시 열었을 때 상태를 확인하세요.
- 게스트 체험에서는 스위치가 켜져 보여도 서버가 기억 조각 참조를 사용하지 않습니다. 로그인한 계정에서 이용하세요.

## 기억을 더 안정적으로 활용하려면

예를 들어 **두 인물이 화해했다는 큰 흐름**은 장기 기억에서, **화해할 때 나눈 특정 약속**은 기억 조각에서 찾아볼 수 있습니다. 그 약속을 앞으로 반드시 지켜야 한다면 **유저 노트**에 직접 적어 두는 편이 명확합니다. [채팅방 설정하기](/chatting/chat-room-settings.md)에서 유저 노트를 열고 저장할 수 있습니다.

AI가 지난 내용을 잘못 짚는다면 먼저 현재 채팅방의 장기 기억과 기억 조각을 확인하세요. 이 두 화면에서 내용을 직접 수정할 수는 없으므로, 필요한 설정은 유저 노트에 적거나 다음 메시지에서 분명하게 알려 주세요.
