# 대화하기

MYMI에서는 마음에 드는 작품을 찾은 뒤, 대화를 시작할 장면(도입부)과 작품 속 내 역할(페르소나)을 정할 수 있습니다. 한 명의 캐릭터와 대화하는 작품이든 여러 인물이 등장하는 작품이든, 대화를 시작하는 기본 순서는 같습니다.

> **이전에 대화한 작품이라면:** 상세 화면의 **이전 대화 이어하기**는 기존 방으로 돌아가고, **새 대화 시작**은 선택한 도입부와 페르소나로 별도의 방을 만듭니다. 다른 시작점을 시험해 보고 싶을 때는 **새 대화 시작**을 선택하세요.

## 1. 대화할 작품 찾기

홈에서 다음 탭을 이용해 작품을 찾을 수 있습니다.

- **추천:** 맞춤 추천, 신작 추천, 인기 작품 등을 둘러봅니다.
- **랭킹:** 실시간·일간·주간·월간 순위에서 작품을 찾습니다.
- **태그:** 장르·관계·설정·성향·종족 등의 태그를 최대 3개 조합해 찾습니다.
- **검색:** 키워드로 작품을 찾거나 **@제작자명**을 입력해 제작자를 검색합니다. 결과는 관련도·최신·인기 등으로 정렬할 수 있습니다.

작품의 성별 필터에는 **전체 성별 / 여성·기타 / 남성·기타**가 표시됩니다. 이는 작품을 좁혀 보는 필터입니다. 원하는 작품이 보이지 않으면 검색어·태그·성별 필터를 바꿔 보세요.

성인 작품의 표시와 이용 가능 여부는 세이프티 필터와 계정의 확인 상태에 따라 달라집니다. 접근 안내가 나오면 [성인·본인인증](/account/adult-verification.md)을 확인하세요.

## 2. 작품 상세에서 시작점 확인하기

작품 카드를 누르면 상세 화면에서 소개, 등장인물, 제작자가 제공한 정보 등을 볼 수 있습니다. **도입부** 항목이 보이면 현재 선택된 첫 장면을 읽어 보세요. 여러 도입부가 있으면 항목을 눌러 다른 시작 장면을 선택할 수 있습니다. 별도로 고르지 않으면 처음 표시된 도입부가 사용됩니다.

| 선택 항목 | 무엇을 정하나요? |
| --- | --- |
| **도입부** | 새 대화의 시작 장면과 처음 표시될 내용 |
| **페르소나** | 그 장면에서 캐릭터와 대화할 **나의 이름과 역할** |

도입부는 작품의 시작점을, 페르소나는 이용자의 역할을 정합니다. 둘 다 **새 대화방을 만들 때** 적용되며, 상세 화면에서 선택만 바꿔도 이미 만들어진 대화방이 바뀌지는 않습니다.

## 3. 내 역할(페르소나) 고르기

1. 상세 화면 아래의 **대화 시작 버튼 옆 작은 프로필 아이콘**을 누릅니다.
2. **내 페르소나**에서 사용할 역할을 고릅니다. 제작자가 준비했다면 **추천 페르소나**도 선택할 수 있습니다.
3. **선택 완료**를 누르고, 대화 시작 버튼 옆의 역할을 확인합니다.

대표 페르소나가 있으면 처음에 우선 선택됩니다. 추천 페르소나가 없는 작품에는 해당 선택지가 나타나지 않을 수 있습니다. 새 역할을 만들거나 기존 방의 역할을 바꾸는 방법은 [페르소나 설정](/account/persona.md)을 참고하세요.

## 4. 첫 대화 시작하기

1. 작품 상세에서 원하는 **도입부**와 **페르소나**를 확인합니다.
2. 아래의 **대화 시작하기**를 누릅니다.
3. 새 채팅방에 선택한 도입부의 첫 장면이 표시되는지 확인합니다.
4. 화면 아래 입력창에 내 행동이나 대사를 적고 **전송** 버튼을 누릅니다.

예를 들어 “문을 열고 안으로 들어간다”처럼 행동을 쓰거나, “여기서 무슨 일이 있었나요?”처럼 말을 건넬 수 있습니다. 작품의 설정과 첫 장면을 읽고 시작하면 상황에 맞는 대화를 이어가기 쉽습니다.

> 성인 작품은 로그인이나 성인 확인이 필요할 수 있습니다. 메시지를 보낼 때 선택한 모델, 이용 가능 횟수 또는 보유 스파크에 관한 안내가 나오면 화면의 안내를 확인하세요.

## 5. 이전 대화를 이어갈지, 새로 시작할지 선택하기

이미 대화한 작품의 상세 화면에는 두 버튼이 표시됩니다.

- **이전 대화 이어하기:** 기존 채팅방으로 돌아가 그 기록을 계속 사용합니다. 상세 화면에서 새로 고른 도입부나 페르소나로 기존 방이 바뀌지 않습니다.
- **새 대화 시작:** 같은 작품에 별도의 채팅방을 만듭니다. 지금 고른 도입부와 페르소나로 시작합니다.

**새 대화 시작은 이전 기록을 지우는 버튼이 아닙니다.** 다른 도입부나 역할로 같은 작품을 다시 경험하고 싶을 때 사용하세요. 기존 방의 페르소나만 바꾸려면 그 방 안에서 수정하고 저장해야 합니다.

## 6. 채팅 화면 읽고 조작하기

채팅 화면의 UI 설정(팔레트 아이콘)에서 보기 방식을 전환할 수 있습니다. 방식을 바꿔도 대화 기록은 그대로입니다.

| 보기 방식 | 화면의 특징 |
| --- | --- |
| **채팅** | 메시지를 말풍선 형태로 읽습니다 |
| **1:1** | 장면을 한 메시지씩 크게 보고 앞뒤로 이동합니다 |
| **소설** | 서술과 대사를 이어지는 글처럼 읽습니다 |

이용 가능한 메시지에는 **재생성**, **편집**, **삭제** 등의 동작이 표시됩니다. 재생성으로 답변을 다시 요청하고, 후보가 여러 개면 화살표로 후보를 살펴볼 수 있습니다. 편집은 내용을 고친 뒤 저장하며, 삭제는 확인 후 진행합니다. 첫 장면이나 보호된 메시지에는 일부 동작이 표시되지 않을 수 있습니다.

보기 방식, 모델, 페르소나 등 대화방 안의 설정을 더 자세히 바꾸려면 [채팅방 설정하기](/chatting/chat-room-settings.md)를 참고하세요.

## 대화가 시작되지 않을 때

| 상황 | 확인할 것 |
| --- | --- |
| 대화 시작 버튼이 비활성화되어 있어요 | 페르소나를 불러오는 중인지 확인하고, 프로필 아이콘에서 역할을 선택해 보세요 |
| 성인 작품에 들어갈 수 없어요 | 로그인 상태와 [성인·본인인증](/account/adult-verification.md) 상태를 확인하세요 |
| 메시지가 전송되지 않아요 | 연결 상태와 입력 내용, 화면에 표시된 모델·이용 가능 횟수·스파크 안내를 확인하세요 |
| 원하는 작품이 검색되지 않아요 | 검색어를 바꾸고 태그·성별·세이프티 필터 설정을 확인하세요 |
