# 1.0 작품 수정하기

구버전 제작 방식(1.0)으로 만든 작품은 예전의 일곱 단계 화면에서 고쳐요. 지금의 작품 제작 화면과 쓰는 곳이 다르니, 이 페이지를 따라 고쳐 주세요.

## 여는 방법과 이동

1. **마이페이지 → 작품 관리**에서 작품의 **수정**을 눌러요.
2. **기본 정보 → 에셋 → 도입부 → 기타 설정 → 로어북 → 컴포넌트 → 선택사항** 순서로 진행해요.
3. 오른쪽 아래 **>**(다음) 버튼을 누르면 다음 단계로 가요. 이때 앞 단계의 필수 항목을 확인하고, 빠진 것이 있으면 안내가 떠요. 확인이 끝나면 저장하고 넘어가요.
4. 탭을 눌러 바로 옮겨 갈 수도 있어요. 앞으로 갈 때는 그 단계 앞까지 확인하고 저장해요. 뒤로 갈 때는 확인하지 않아요.
5. 마지막 **선택사항** 단계의 **완료**를 누르면 수정한 내용이 작품에 반영돼요.

## 단계별로 고칠 것

### 1. 기본 정보

<ScreenStep src="/img/screens/ko/legacy-editor.webp" alt="구버전 제작 화면의 기본 정보 단계. 작품 이름, 한 줄 소개, 글자 수 합계, 세계관 칸" caption="1.0 · 기본 정보">

| 항목 | 쓰는 법 |
| --- | --- |
| 작품 이름 | 50자까지 |
| 한 줄 소개 | 40자까지 |
| 세계관 | 시대·장소·상황 같은 배경 |
| 등장인물 | 1명 이상. 이름과 설명. 이름은 서로 다르게 |
| 비밀 | 인물이 알아야 하는 숨긴 설정(선택) |

세계관·등장인물 설명·비밀을 합쳐 10,000자까지 쓸 수 있어요. 이 칸들이 AI가 읽는 설정이에요.

</ScreenStep>

### 2. 에셋

<ScreenStep src="/img/screens/ko/legacy-assets.webp" alt="구버전 제작 화면의 에셋 단계. 이미지마다 img:코드와 상황 설명, 별 아이콘이 있다" caption="1.0 · 에셋">

- 이미지를 올리거나 **AI 이미지**로 만들어요. 다음 단계로 가려면 이미지가 1장 이상 있어야 해요.
- 이미지마다 **상황 설명**(60자)을 적어요. AI가 어떤 장면에 이 이미지를 쓸지 판단하는 기준이에요.
- 이미지 왼쪽 위 **★** 버튼으로 작품의 대표 이미지를 한 장 골라요.
- 이미지에 붙은 `img:minwoo_smile` 같은 표시가 도입부에서 쓰는 이름이에요.

</ScreenStep>

### 3. 도입부

도입부를 1개 이상 만들고 **제목**과 **내용**을 적어요. 에셋 이미지는 `img:[minwoo_smile]`처럼 넣고 **미리보기**로 확인해요.

### 4. 기타 설정

독자층(남성향·여성향)과 태그, 공개 여부, 오리지널 여부, 이미지 출처, **이미지 출력 지침**, 콘텐츠 등급을 골라요.

- **이미지 출력 지침**: **내부 이미지**는 올린 이미지를 `img:[slug]`로, **외부 이미지**는 설정에 적은 이미지 주소로 출력해요. 화면 안내대로 한 가지 방식만 써요.
- **오리지널**로 정한 작품은 1.0 화면에서 3개월 동안 이 항목이 잠기고, 풀리기까지 남은 날이 표시돼요.

### 5~7. 로어북 · 컴포넌트 · 선택사항

| 단계 | 쓰는 법 |
| --- | --- |
| **로어북** | **엔트리 추가**로 엔트리 이름·트리거 키워드·내용을 채워요. 지금 방식의 [로어북](/create/lorebook)과 같은 방식으로 찾아서 전해요. |
| **컴포넌트** | 코드와 **용도 설명**을 채워요. 용도 설명에 언제 어떤 값으로 부를지 적어요. |
| **선택사항** | 프로필 디자인(HTML), 추천 페르소나, 제작자의 한 마디를 설정해요. 추천 페르소나를 추가했다면 이름·성별·생년월일·상세 정보를 채워요. |

## 자주 막히는 곳

<details>
<summary>다음 단계로 넘어가지 않아요</summary>

앞 단계에 빠진 필수 항목이 있어요. 위쪽에 뜬 안내를 확인해요. 에셋 단계라면 이미지가 1장 이상 있는지, 이미지마다 상황 설명이 있는지 봐요.

</details>

<details>
<summary>도입부의 `img:[slug]`가 이미지로 보이지 않아요</summary>

괄호 안 이름이 에셋 이미지에 표시된 이름과 같은지 확인해요. 에셋에서 그 이미지를 지웠다면 미리보기에 이미지가 없다는 안내가 떠요.

</details>

<details>
<summary>수정 화면에 프롬프트 탭이 없어요</summary>

1.0 작품이라서 그래요. 1.0 작품은 지금 방식의 화면으로 열리지 않아요. 지금 방식으로 만들고 싶다면 [구버전 제작 방식(1.0) 알아보기](/create/legacy/overview#10-작품을-지금-방식으로-만들고-싶다면)를 읽어 보세요.

</details>
