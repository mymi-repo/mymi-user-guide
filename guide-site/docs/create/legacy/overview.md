# 구버전 제작 방식(1.0) 알아보기

예전에는 작품을 일곱 단계의 제작 화면으로 만들었어요. 이 방식을 <strong>구버전 제작 방식(1.0)</strong>이라고 불러요. 새 작품은 하단 메뉴의 **제작**에서 지금의 작품 제작 화면으로 만들어요. 1.0으로 만든 작품은 수정할 때 예전 화면이 열려요.

## 내 작품이 1.0인지 알아보기

<ScreenStep src="/img/screens/ko/legacy-editor.webp" alt="구버전 제작 화면. 탭 줄에 기본 정보·에셋·도입부·기타 설정·로어북·컴포넌트가 보이고 오른쪽 아래에 다음 버튼이 있다" caption="1.0 작품을 수정할 때 열리는 화면">

**마이페이지 → 작품 관리**에서 작품의 **수정**을 눌러 보세요.

- 탭 줄(①)이 **기본 정보 · 에셋 · 도입부 · 기타 설정 · 로어북 · 컴포넌트 · 선택사항**이고, 오른쪽 아래에 **>**(다음) 버튼이 있으면 1.0 작품이에요.
- 탭에 **프롬프트**가 있고 위쪽에 **임시저장**·**제작 완료**(또는 **수정 반영**)가 있으면 지금 방식의 작품이에요.

</ScreenStep>

1.0 작품은 지금 방식으로 자동으로 바뀌지 않아요. 수정하는 방법은 [1.0 작품 수정하기](/create/legacy/edit)에 있어요.

## 무엇이 달라졌나요

가장 큰 차이는 **AI에게 줄 설정을 쓰는 곳**이에요. 1.0에서는 칸마다 나눠 적으면 MYMI가 모아서 전했고, 지금은 **프롬프트** 탭에 직접 구성해요.

| | 1.0 | 지금 |
| --- | --- | --- |
| 세계관·등장인물·비밀 | **기본 정보**의 칸에 각각 | **프롬프트**의 작품 정보(기본형) 또는 프롬프트 본문(직접 작성) |
| 이미지가 뜻하는 상황 | 에셋마다 **상황 설명**, 인물 연결 | 에셋의 폴더·코드 + 프롬프트의 코드 뜻(기본형) 또는 이미지 규칙(직접 작성) |
| 대화에 이미지 넣기 | `img:[slug]` | `![]({{URL}}/A/1.webp)` |
| 작품 대표 이미지 | 에셋에서 ★로 한 장 | **기본 정보**의 **표지** 1~10장 |
| 작품 소개 | **선택사항**의 HTML 프로필 | **기본 정보**의 **상세 설명**(필수) |
| 제작자가 남기는 글 | **선택사항**의 제작자의 한 마디 | **기본 정보**의 **크리에이터 가이드** |
| 컴포넌트를 언제 쓸지 | 컴포넌트의 **용도 설명** | 프롬프트의 컴포넌트 출력 규칙(기본형) 또는 본문(직접 작성) |
| 분류 | **기타 설정**의 **해시태그**(타겟 독자층 포함) | **기본 정보**의 장르·해시태그 + **기타 설정**의 독자층 |
| 추천 페르소나 | **선택사항** | **기타 설정** |
| 단계 이동 | 앞 단계의 필수 항목을 채워야 다음으로 | 원하는 탭부터. 필수 항목은 **제작 완료** 때 확인 |

도입부와 로어북은 두 방식에 모두 있어요.

## 1.0 작품을 지금 방식으로 만들고 싶다면

기존 작품을 바꾸는 기능은 없어요. 하단 메뉴의 **제작**에서 새 작품을 만들고 설정을 옮겨 적어요. 새 작품은 별개의 작품이라 기존 작품의 대화·좋아요·댓글은 옮겨지지 않아요.

새 작품을 만들어도 기존 1.0 작품은 그대로 남아요. 기존 작품을 더 보여 주고 싶지 않다면 **수정**으로 열어 **기타 설정** 단계의 **공개 설정**을 **비공개**로 바꾼 뒤 **>**(다음)를 눌러 저장해요.

옮길 때는 세계관·인물 설명만 옮기고 끝내지 마세요. 아래도 함께 챙겨야 해요.

1. **이미지의 상황 설명** → 에셋의 코드와 프롬프트의 코드 뜻
2. **컴포넌트의 용도 설명** → 프롬프트의 컴포넌트 출력 규칙
3. **도입부의 `img:[slug]`** → 새 에셋 코드로 넣은 이미지 줄
4. **HTML 프로필, 제작자의 한 마디** → 상세 설명, 크리에이터 가이드
5. **예전에 넣은 대화 예시** → 프롬프트. 지금 1.0 화면에는 보이지 않지만 AI에게는 전해지고 있어요. 새 작품으로는 옮겨지지 않으니, 필요한 말투나 예시를 프롬프트에 직접 적어요.

항목별로 어디로 옮기는지는 [1.0 입력 항목과 문법](/create/legacy/reference#지금-방식으로-옮기기)에 표로 정리했어요.

## 자주 막히는 곳

<summary>새 작품을 만들려는데 예전 일곱 단계 화면이 열려요</summary>

**작품 관리**의 **수정**은 그 작품을 만든 방식의 화면으로 열려요. 새 작품은 하단 메뉴의 **제작**에서 만들어요.

</details>

<details>
<summary>1.0 작품을 지금 방식으로 바꾸는 버튼을 못 찾겠어요</summary>

바꾸는 버튼은 없어요. 새 작품을 만들어 설정을 옮겨 적어야 해요. [1.0 작품을 지금 방식으로 만들고 싶다면](#10-작품을-지금-방식으로-만들고-싶다면)을 따라 해요.

</details>
