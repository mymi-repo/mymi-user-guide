# 1.0 입력 항목과 문법

구버전 제작 방식(1.0) 화면의 항목과 제한, 이미지 문법을 모았어요. 1.0 작품을 지금 방식의 새 작품으로 옮길 때 쓰는 대응표도 함께 있어요.

## 1.0의 항목과 제한

| 단계 | 항목 | 제한 |
| --- | --- | --- |
| 기본 정보 | 작품 이름 | 필수 · 50자 (지금은 작품 제목 30자) |
| | 한 줄 소개 | 필수 · 40자 |
| | 세계관 · 등장인물 설명 · 비밀 | 세 칸을 합쳐 10,000자. 세계관과 등장인물 1명 이상은 필수 |
| | 등장인물 이름 | 50자. 인물끼리 겹치지 않게 |
| 에셋 | 이미지 | 1장 이상 |
| | 상황 설명 | 이미지마다 필수 · 60자 |
| | 대표 이미지 | ★로 한 장 |
| 도입부 | 도입부 | 1개 이상, 제목과 내용 |
| 기타 설정 | 독자층 | 필수 · 남성향·여성향 |
| 로어북 | 엔트리 | 100개까지. 엔트리 이름 50자, 트리거 키워드 5개(각 10자), 내용 400자 |
| 컴포넌트 | 용도 설명 | 컴포넌트마다 필수 · 500자 |
| | 코드 | 10,000자 (지금은 20,000자) |
| 선택사항 | 제작자의 한 마디 | 3,000자 (지금은 크리에이터 가이드 글 하나에 5,000자) |

## 1.0의 이미지 문법

1.0은 **기타 설정 → 이미지 출력 지침**에서 고른 방식으로 이미지를 넣어요. 화면 안내대로 한 가지 방식만 써요.

| 방식 | 문법 | 쓰는 곳 |
| --- | --- | --- |
| 내부 이미지 | `img:[slug]` | 에셋에 올린 이미지. 에셋 카드에 `img:minwoo_smile`처럼 이름이 표시돼요 |
| 외부 이미지 | `![](이미지 주소)` | 설정에 적어 둔 외부 이미지 주소 |

도입부에서는 `img:[minwoo_smile]`처럼 써요. AI는 에셋마다 적은 **상황 설명**을 보고 어떤 이미지를 넣을지 골라요.

:::warning[지금 방식에서는 쓰지 않아요]
`img:[slug]`는 1.0 작품에서만 쓰는 문법이에요. 지금 방식의 작품에는 에셋 탭의 코드와 `![]({{URL}}/A/1.webp)`를 써요.
:::

## 지금 방식으로 옮기기

1.0 작품을 지금 방식으로 다시 만들 때 항목별로 옮기는 곳이에요. 기존 작품이 자동으로 바뀌는 것이 아니라, 새 작품에 직접 옮겨 적는 작업이에요.

| 1.0에서 쓰던 곳 | 지금 쓰는 곳 | 옮길 때 할 일 |
| --- | --- | --- |
| 기본 정보 → 세계관 | 프롬프트 → 작품 정보(기본형) 또는 본문(직접 작성) | 시대·장소·규칙을 옮겨 적어요 |
| 기본 정보 → 등장인물 | 프롬프트 → 작품 정보의 등장인물 | 이름 줄 아래에 역할·성격·말투·관계를 적어요 |
| 기본 정보 → 비밀 | 프롬프트 → 작품 정보의 숨긴 설정 | 밝히는 조건도 함께 적어요. 상세 설명에는 옮기지 않아요 |
| 에셋 → 인물 연결 | 에셋의 캐릭터 폴더 + 프롬프트의 캐릭터코드 뜻 | 인물마다 폴더를 만들고 폴더 코드와 이름을 맞춰요 |
| 에셋 → 상황 설명 | 에셋의 이미지 코드 + 프롬프트의 상황코드·기타코드 뜻 | 같은 상황은 모든 인물에게 같은 코드로 맞춰요 |
| 에셋 → 대표 이미지 | 기본 정보 → 표지 | 표지는 1~10장. 에셋에서 가져올 수 있어요 |
| 도입부의 `img:[slug]` | 도입부의 `![]({{URL}}/A/1.webp)` | **에셋 이미지 넣기**로 다시 넣어요 |
| 기타 설정 → 독자층·태그 | 기본 정보 → 장르·해시태그, 기타 설정 → 독자층 | 장르 1~2개와 해시태그를 새로 적어요 |
| 컴포넌트 → 용도 설명 | 프롬프트 → 컴포넌트 출력 규칙(기본형) 또는 본문(직접 작성) | 언제 어떤 값으로 부를지 옮겨 적어요 |
| 선택사항 → HTML 프로필 | 기본 정보 → 상세 설명 | 상세 설명은 필수예요. 미리보기로 확인해요 |
| 선택사항 → 제작자의 한 마디 | 기본 정보 → 크리에이터 가이드 | |
| 선택사항 → 추천 페르소나 | 기타 설정 → 추천 페르소나 | |
| 로어북 | 로어북 | 이름·키워드·내용을 그대로 옮겨요 |

### 예: 이미지 한 장 옮기기

1.0에서 인물 **강민우**에 연결하고 상황 설명을 "민우가 웃는 모습"으로 적은 이미지(`img:[minwoo_smile]`)가 있다면, 지금 방식에서는 이렇게 옮겨요.

1. **프롬프트**의 작품 정보에 민우의 역할·성격·말투를 적어요.
2. **에셋**에 캐릭터 폴더 `A`를 만들고 그 이미지를 코드 `1`로 넣어요.
3. 기본형이라면 **이미지 출력 규칙**에 캐릭터코드 `A` = `강민우`, 상황코드 `1` = `웃음`을 적어요.
4. 직접 작성이라면 이미지의 뜻과 함께 언제 어떤 형식으로 넣을지도 본문에 적어요.
5. 도입부에 쓰던 `img:[minwoo_smile]`은 지우고 **에셋 이미지 넣기**로 `A/1`을 넣어요.
