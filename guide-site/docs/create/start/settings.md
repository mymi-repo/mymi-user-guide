# 작품 설정 고르기

작품을 공개하는 방법과 리프를 받는 조건을 정하는 설정이에요. **기타 설정**에서 고르고, 간편 모드와 전문가 모드가 같은 카드를 써요.

- 간편 모드: **기타 설정** 단계. 위쪽에 **장르**와 **해시태그**가 있고, 그 아래에 이 페이지의 카드가 이어져요.
- 전문가 모드: **기타 설정** 탭. **장르**와 **해시태그**는 **기본 정보** 탭에 있어요.

빨간 `*`가 붙은 카드는 꼭 골라야 해요. **공개 설정**과 **콘텐츠 등급**은 처음부터 골라져 있고, 나머지는 직접 골라야 작품을 완성할 수 있어요.

## 한눈에 보기

| 카드 | 선택지 | 처음 값 |
| --- | --- | --- |
| **공개 설정** | 공개 · 비공개 | 공개 |
| **작품 공개 범위** | 오리지널 · 일반 | 고르지 않음 |
| **수익화 제한** | 제한 없음 · 수익화 제한 | 고르지 않음 |
| **이미지 출처** | MYMI 생성 · 외부 제작 | 고르지 않음 |
| **독자층** | 남성향 · 여성향 | 고르지 않음 |
| **콘텐츠 등급** | 전체 이용가 · 성인용 | 전체 이용가 |
| **마케팅 활용 동의** | 동의 · 동의하지 않음 | 고르지 않음 |

## 공개 설정

작품을 누구에게 보여 줄지 정해요.

- **공개**: 모든 유저가 볼 수 있어요. 공개로 만든 새 작품은 검토를 거쳐 다른 유저에게 보여요.
- **비공개**: 나만 볼 수 있어요. 공개하기 전에 대화를 시험해 볼 때 써요.

나중에 **마이페이지 → 작품 관리 → 수정**의 **기타 설정**에서 바꿀 수 있어요. 비공개 작품을 공개로 바꾸면 그때부터 검토가 시작돼요. ([공개하고 고치기](/create/publish#비공개로-만든-작품을-공개하기))

## 작품 공개 범위

- **오리지널**: MYMI에서만 공개하는 작품이에요. 더 높은 리프 비율을 받아요.
- **일반**: 다른 플랫폼에도 공개할 수 있는 작품이에요.

:::warning[오리지널은 3개월간 해제할 수 없어요]
오리지널을 고르면 "오리지널로 설정하면 3개월간 해제할 수 없어요."라는 안내가 나와요. 설정한 날부터 3개월 동안은 **일반**으로 되돌리지 않는 규칙이에요. 다른 플랫폼에도 올릴 계획이 있다면 **일반**을 고르세요.

간편 모드에서는 설정한 뒤 3개월 동안 카드가 잠기고 풀리기까지 남은 날이 표시돼요.
:::

## 수익화 제한

- **제한 없음**: 내가 권리를 가진 창작물이에요.
- **수익화 제한**: 다른 작품의 캐릭터나 세계관을 쓴 2차 창작물처럼 권리가 내 것이 아닌 작품이에요.

**수익화 제한**을 고른 작품은 리프가 쌓이지 않아요. 오리지널이어도, 공식 크리에이터여도 마찬가지예요. 바꾸면 그다음 대화부터 적용돼요.

## 이미지 출처

작품의 이미지를 어떻게 만들었는지 골라요.

- **MYMI 생성**: MYMI의 이미지 생성으로 만든 이미지예요.
- **외부 제작**: 다른 AI로 만들었거나 직접 그린 이미지예요.

**일반** 작품이라면 리프 비율이 이미지 출처에 따라 달라져요. 비율은 [크리에이터 되기와 리프](/creator-support/support#리프-받기)에 있어요. 이미지를 쓰지 않는 작품이라면 실제 쓰는 쪽을 골라요.

## 독자층

작품이 주로 어떤 독자를 향하는지 **남성향**이나 **여성향**으로 골라요.

## 콘텐츠 등급

대화 내용과 생성되는 이미지에 영향을 줘요.

- **전체 이용가**: 누구나 이용할 수 있어요.
- **성인용**: 성인 인증을 한 유저만 이용할 수 있어요. ([성인·본인인증](/account/adult-verification))

이미 공개된 작품의 등급을 성인용에서 전체 이용가로 바꾸면 다시 검토를 받아요.

## 마케팅 활용 동의

- **동의**: MYMI가 이 작품을 광고·SNS 같은 마케팅 소재로 쓸 수 있어요. 노출이 늘면 대화량이 자연스럽게 늘어 리프 획득도 늘 수 있어요.
- **동의하지 않음**: 마케팅에 쓰지 않아요.

## 간편 모드에만 있는 카드: 이미지 출력 지침

간편 모드의 **기타 설정**에는 **이미지 출력 지침** 카드가 하나 더 있어요. AI가 대화에서 이미지를 어떻게 내보낼지 정해요.

- **내부 이미지**: 에셋에 올린 이미지를 써요. 처음부터 골라져 있어요.
- **외부 이미지**: 설정에 적은 이미지 주소(URL)를 써요.

한 가지 방식만 써요. 자세한 내용은 [에셋과 AI 이미지](/create/simple/assets#이미지-출력-지침)에 있어요. 전문가 모드에는 이 카드가 없고, 프롬프트에 이미지 규칙을 직접 적어요.

## 자주 막히는 곳

<details>
<summary>오리지널을 골랐는데 일반으로 바꾸고 싶어요</summary>

오리지널로 설정한 뒤 3개월 동안은 해제할 수 없는 규칙이에요. 간편 모드에서는 카드가 잠기고 풀리기까지 남은 날이 표시돼요. 3개월이 지나면 **일반**으로 바꿀 수 있어요.

</details>

<details>
<summary>수익화 제한을 골라야 하는지 모르겠어요</summary>

내가 만든 인물과 세계관으로 쓴 작품이라면 **제한 없음**이에요. 다른 작품의 캐릭터나 세계관을 가져다 쓴 2차 창작물처럼 권리가 내게 없다면 **수익화 제한**을 골라요. 판단하기 어렵다면 [문의하기](/faq#문의하기)로 물어보세요.

</details>

<details>
<summary>‘작품 공개 범위를 골라 주세요.’ 같은 안내가 떠요</summary>

고르지 않은 카드가 있다는 뜻이에요. 안내는 한 번에 하나씩 뜨고, 간편 모드는 다음 버튼이나 **완료** 버튼을, 전문가 모드는 **제작 완료**를 눌렀을 때 확인해요. 안내 문장에 적힌 카드를 골라요. 다른 카드가 더 남아 있을 수 있어요.

</details>

<details>
<summary>성인용으로 만들었는데 다른 유저에게 안 보여요</summary>

성인용 작품은 성인 인증을 마친 유저에게만 보여요. 내 계정이 인증되어 있는지도 확인해 보세요. ([성인·본인인증](/account/adult-verification))

</details>
