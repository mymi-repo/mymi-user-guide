# 제한과 규칙 한눈에

작품 제작 화면의 제한과 규칙을 모았어요. 자세한 사용법은 각 항목의 안내 페이지에 있어요.

## 글자 수와 개수

| 탭 | 항목 | 제한 |
| --- | --- | --- |
| 기본 정보 | 작품 제목 | 필수 · 30자 |
| | 한 줄 소개 | 필수 · 40자 |
| | 표지 | 필수 · 1~10장. 파일은 JPG, PNG, WEBP, GIF, HEIC · 5MB까지. 전환 간격은 0.5초 단위 |
| | 상세 설명 | 필수 · 50,000자 |
| | 장르 | 필수 · 1~2개 |
| | 해시태그 | 필수 · 1개 이상 |
| | 크리에이터 가이드 | 선택 · 글 하나에 5,000자 |
| | 추천 모델 | 선택 · 5개까지 |
| 에셋 | 이미지 파일 | JPG, PNG, WEBP, GIF, HEIC · 5MB까지 |
| | 한 번에 생성 요청 | 50장까지 |
| 컴포넌트 | JSX 코드 | 20,000자. 함수 이름과 변수 1개 이상 필요 |
| 프롬프트 | 직접 작성 | 필수 · 10,000자 |
| | 기본형 | 필수 · 작품 정보·코드 뜻·예외·컴포넌트 규칙에 적은 글의 합계 10,000자 |
| 도입부 | 도입부 | 필수 · 1개 이상, 제목과 내용 모두 |
| | 내용 | 2,000자 |
| 로어북 | 로어 | 100개까지 |
| | 이름 | 50자 |
| | 키워드 | 로어 하나에 5개, 하나에 10자 |
| | 내용 | 400자 |
| | 한 번에 전해지는 양 | 최근 10개 메시지에서 찾아 최대 3개 · 1,500자 |
| 기타 설정 | 추천 페르소나 | 선택. 만들면 이름(20자)·성별·생년월일(14세 이상)·상세 정보(1,000자) 모두 필요 |

## 제작 완료 때 확인하는 것

**제작 완료**(공개한 작품은 **수정 반영**)를 누르면 아래 순서로 확인하고, 처음 걸린 항목의 탭으로 옮겨 안내를 띄워요.

| 순서 | 탭 | 확인하는 것 |
| --- | --- | --- |
| 1 | 기본 정보 | 작품 제목, 한 줄 소개, 표지 1장 이상, 상세 설명, 장르 1~2개, 해시태그 1개 이상 |
| 2 | 에셋 | 모든 이미지에 코드가 있는지, 코드가 영문·숫자인지, 같은 폴더에 같은 코드가 없는지, 빈 칸·생성 대기 행이 없는지, 기본 모습이 완성됐는지 |
| 3 | 컴포넌트 | 코드, 함수 이름, 변수 1개 이상 |
| 4 | 프롬프트 | 직접 작성: 프롬프트. 기본형: 작품 정보, 캐릭터·상황·기타 코드의 뜻, 컴포넌트가 등장하는 때, 합계 10,000자 이하 |
| 5 | 도입부 | 1개 이상, 모두 제목과 내용이 있는지 |
| 6 | 로어북 | 추가한 로어마다 키워드·내용·이름 |
| 7 | 기타 설정 | 작품 공개 범위, 수익화 제한, 이미지 출처, 독자층, 마케팅 활용 동의, 추가한 추천 페르소나의 네 칸 |

공개 설정(공개)과 콘텐츠 등급(전체 이용가)은 처음부터 골라져 있어요.

## 코드 규칙

- 이미지 코드와 캐릭터 폴더 이름은 **영문과 숫자만** 쓸 수 있어요. 공백·특수문자는 안 돼요.
- 같은 폴더 안에서 코드가 겹치면 안 돼요. 다른 폴더끼리는 같은 코드를 써도 돼요(`A/1`, `B/1`).
- 폴더는 한 단계만 만들 수 있어요.
- 경로는 폴더 안이면 `폴더/코드`, 폴더 밖이면 `코드`예요. 대화와 도입부에서는 `![]({{URL}}/A/1.webp)`, `![]({{URL}}/BG1.webp)`처럼 써요.
- 제작 완료한 작품은 폴더 이름을 바꿀 수 없고, 이미지를 다른 캐릭터 폴더로 옮길 수 없어요.

## `{{user}}`와 `{{char}}`

| 쓰는 곳 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 도입부 | 대화할 때 유저의 이름으로 바뀌어요 | 대화할 때 **작품 제목**으로 바뀌어요 |
| 프롬프트 | 유저를 가리키는 자리로 써요 | 자동으로 바뀌지 않아요. 인물 이름을 직접 써요 |
| 로어북 | 유저를 가리키는 자리로 써요 | 인물 이름을 직접 써요 |

## 저장

| 상황 | 저장되는 때 |
| --- | --- |
| 제작 중인 작품 | 바뀐 내용이 있을 때 탭을 옮기면 자동 저장, 표지·에셋 이미지를 처음 올리거나 생성할 때, **임시저장**을 누를 때 |
| 제작 완료한 작품 | 글과 설정은 **수정 반영**을 누를 때. 에셋 변경은 바로 반영 |

## 무료와 인증

- 작품 제작의 이미지 생성·다시 생성은 무료예요. 생성하려면 본인인증이 필요해요.
- 성인용 작품은 성인 인증을 한 유저만 이용할 수 있어요.
- 이미지 생성 태그 단계의 세이프티 필터는 성인 인증을 한 계정만 끌 수 있어요.
