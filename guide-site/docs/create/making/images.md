# 이미지 준비하기

대화에 띄울 이미지는 **에셋** 탭에서 준비해요. 가지고 있는 이미지를 올리거나 MYMI에서 무료로 생성할 수 있어요. 이미지마다 코드를 붙여 두면 프롬프트와 도입부에서 그 코드로 이미지를 불러요.

:::info[이미지 생성은 무료, 본인인증이 필요해요]
작품 제작의 이미지 생성과 다시 생성은 무료예요. 생성하려면 [본인인증](/account/adult-verification)을 마친 계정이어야 해요. 이미지를 올리는 것은 인증 없이도 돼요.
:::

## 에셋 탭은 이렇게 생겼어요

<ScreenStep src="/img/screens/ko/assets-overview.webp" alt="에셋 탭. 폴더 밖 이미지 BG1과 캐릭터 폴더 A 안의 이미지 1·2·3이 보인다" caption="에셋 탭">

- **폴더 하나가 캐릭터 하나**예요. 폴더 이름(예: `A`)이 **캐릭터 코드**가 돼요.
- 폴더 안 이미지의 코드(예: `1`)는 **상황 코드**예요. 이 이미지의 경로는 `A/1`이에요.
- 폴더 밖 이미지(예: 배경 `BG1`)는 **기타 코드**로 불러요.
- 코드를 정하면 행 아래에 `![]({{URL}}/A/1.webp)` 같은 줄이 떠요. 이 줄을 프롬프트나 도입부에 쓰면 그 자리에 이미지가 보여요.

</ScreenStep>

코드는 영문과 숫자만 쓸 수 있고, 같은 폴더 안에서 겹치면 안 돼요. 폴더는 한 단계만 만들 수 있어요.

<ScreenStep src="/img/screens/ko/assets-help.webp" device="part" alt="에셋은 어떻게 동작하나요? 안내를 펼친 모습" caption="에셋은 어떻게 동작하나요?">

탭 위쪽 <strong>에셋은 어떻게 동작하나요?</strong>를 누르면 코드와 경로, 캐릭터 폴더와 기본 모습, 생성과 대기, 공통 상황 코드, 잠금과 해금 안내를 펼쳐 볼 수 있어요.

</ScreenStep>

예시 작품은 이렇게 준비했어요.

| 경로 | 이미지 | 코드의 뜻 |
| --- | --- | --- |
| `A` 폴더 | 강민우 | 캐릭터코드 A |
| `A/1`, `A/2`, `A/3` | 민우의 웃음·슬픔·분노 | 상황코드 1·2·3 |
| `B` 폴더 | 이서연 | 캐릭터코드 B |
| `B/1`, `B/2` | 서연의 웃음·슬픔 | 상황코드 1·2 (B/3은 없음) |
| `BG1` | 검역소 복도 | 기타코드 BG1 |

## 가지고 있는 이미지 올리기

1. 폴더 밖에 둘 이미지는 탭 아래쪽 **이미지 업로드**를, 캐릭터 폴더에 넣을 이미지는 그 폴더 안의 **이미지 업로드**를 눌러요.
2. 이미지를 골라요. 여러 장을 한 번에 올릴 수 있어요. JPG, PNG, WEBP, GIF, HEIC 파일을 5MB까지 쓸 수 있어요.
3. 올라간 행마다 **코드**를 적어요.

## 캐릭터 폴더와 기본 모습 만들기

같은 인물의 이미지를 여러 장 만들 때는 먼저 **기본 모습**을 만들어요. 기본 모습은 폴더의 얼굴이에요. 그 폴더에서 생성하는 이미지가 기본 모습의 그림체와 인상을 이어받아요.

<ScreenStep src="/img/screens/ko/assets-folder-empty.webp" alt="캐릭터 폴더 A를 만든 모습. 폴더 이름 옆에 캐릭터 생성 버튼이 있다" caption="새 캐릭터 폴더">

1. **캐릭터 폴더 추가**를 누르고 캐릭터 코드(예: `A`)를 적어요.
2. 폴더 이름 옆 **✦ 캐릭터 생성**을 눌러요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/assets-gen-kind.webp" alt="기본 모습 만들기 1단계. 이미지 종류에서 캐릭터, 성별에서 남성을 고른 모습" caption="1단계 · 종류와 성별">

3. <strong>어떤 이미지인가요?</strong>에서 **캐릭터**를 골라요. 인물 없는 장소는 **배경**이에요.
4. 캐릭터라면 **여성**·**남성** 중에서 성별을 고르고 **다음**을 눌러요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/assets-gen-style.webp" alt="그림체 선택 단계. 추천 그림체 목록에서 첫 번째를 고른 모습" caption="2단계 · 그림체">

5. **그림체**를 골라요.
   - **추천 그림체**: MYMI가 준비한 그림체예요. 처음이라면 여기서 골라요.
   - **내 그림체**: 저장해 둔 그림체예요.
   - **직접 작성**: 그림체를 프롬프트로 직접 적어요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/assets-gen-tags.webp" alt="머리카락 단계에서 짧은 머리(검정)와 헝클어진 머리를 고른 모습. 위쪽에 고른 태그가 모여 있다" caption="3단계부터 · 태그 고르기">

6. **배경** → **신체 - 머리카락** → **신체 - 눈** → **신체 - 얼굴 특징** → **신체 - 피부** → **신체 - 체형** → **의상** → **소품** → **기타등등** 순서로 태그를 골라요. 고른 태그는 위쪽에 모여 보여요. 필요 없는 단계는 **다음**으로 넘어가요.
   - 머리카락·눈·의상 태그 가운데 색이 정해지지 않은 것(예: 짧은 머리)은 누르면 색을 고르는 창이 떠요. 색을 누르거나, 색을 따로 넣지 않으려면 **이미 색상이 포함돼있음**을 눌러요.
   - **태그 검색...** 칸에서 원하는 태그를 찾을 수 있어요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/assets-gen-confirm.webp" alt="태그 확인 & 생성 단계. 소속 캐릭터, 그림체, 고른 태그와 char_prompt 칸, 기본 모습 생성 버튼" caption="마지막 단계 · 태그 확인 & 생성">

7. **태그 확인 & 생성**에서 고른 태그를 확인해요. 태그는 영어 프롬프트로 바뀌어 **char_prompt - 최종 편집** 칸에 들어가요. 이 칸을 직접 고쳐도 돼요.
8. **기본 모습 생성**을 눌러요. 생성이 끝나면 폴더 이름 옆에 기본 모습이 보여요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/assets-gen-expert.webp" alt="전문가 모드를 펼친 모습. negative_prompt, guidance, steps, sampler, noise_schedule, 이미지 크기" caption="전문가 모드">

**전문가 모드**를 펼치면 넣지 않을 요소(`negative_prompt`), 생성 설정(guidance, steps, sampler, noise_schedule), 이미지 크기를 바꿀 수 있어요. 잘 모르겠다면 그대로 두세요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/assets-base-sheet.webp" alt="A 기본 모습 창. 기본 모습 이미지와 태그, 프롬프트 수정·이미지로 추가·다시 생성 버튼" caption="기본 모습 창">

폴더의 기본 모습을 누르면 이 창이 열려요.

- **프롬프트 수정**: 태그와 프롬프트를 고쳐요.
- **다시 생성**: 같은 설정으로 새로 만들어요.
- **이미지로 추가**: 기본 모습 자체를 폴더 안 이미지로도 넣어요. 코드를 붙이면 대화에서도 쓸 수 있어요.

</ScreenStep>

:::tip[예시 작품의 태그]
민우는 남성 추천 그림체에 갈색 헝클어진 짧은 머리, 처진 눈, 밀리터리 재킷, 손전등 같은 태그로 만들었어요. 서연은 여성 추천 그림체에 병원·실내·지하 배경 태그를 더하고, 전문가 모드의 `negative_prompt`에 `simple background, white background`를 넣었어요. 그림체에 따라 배경이 흰색으로만 나올 때 쓰는 방법이에요.
:::

## 폴더에 이미지 더 만들기

<ScreenStep src="/img/screens/ko/assets-mode.webp" alt="A 캐릭터 폴더의 이미지 생성 창. 기본 모습 이어받기(추천)와 처음부터 만들기" caption="폴더에서 ✦ 생성">

폴더 안의 **✦ 생성**을 누르면 만드는 방식을 골라요.

- **기본 모습 이어받기**(추천): 그림체와 모습은 그대로 두고 표정·포즈·배경만 골라요.
- **처음부터 만들기**: 종류·성별·그림체·태그를 새로 골라요.

기본 모습이 없는 폴더에서는 **캐릭터 먼저 생성**과 **이 이미지만 생성** 중에서 골라요.

</ScreenStep>

마지막 단계에서 **지금 생성**을 누르면 바로 만들고, **대기 목록에 추가**를 누르면 나중에 한꺼번에 만들어요. 코드는 생성 전에 미리 정해 둘 수 있어요.

## 여러 인물에 같은 상황 만들기: 공통 상황 코드

"웃음", "슬픔"처럼 모든 인물에게 필요한 상황은 **공통 상황 코드**로 한 번에 준비해요.

<ScreenStep src="/img/screens/ko/assets-situations.webp" alt="공통 상황 코드 창. 1 미소·상반신, 2 슬픔·상반신, 3 화난·상반신과 적용 버튼" caption="✦ 상황 코드">

1. 탭 오른쪽 위 **✦ 상황 코드**를 눌러요.
2. **상황 코드 추가**로 코드(예: `1`)와 표정·포즈 같은 태그를 정해요.
3. 만든 상황 코드 옆 **적용**을 눌러요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/assets-situation-apply.webp" alt="상황 코드 3 적용 창. 폴더 A는 이미 3이 있어 흐리고, 폴더 B를 고른 모습" caption="상황 코드 적용">

4. 적용할 캐릭터 폴더를 골라요. 이미 같은 코드가 있는 폴더는 고를 수 없어요.
5. **캐릭터 N개에 적용**을 누르면 폴더마다 `A/3`, `B/3` 같은 **빈 칸**이 생겨요.

빈 칸은 이미지를 올리거나 생성해서 채워요. 생성하면 각 폴더의 기본 모습 위에 상황 태그를 얹어 만들어요. 기본 모습은 적용한 뒤에 만들어도 돼요.

</ScreenStep>

## 한꺼번에 생성하기: 생성 대기 목록

<ScreenStep src="/img/screens/ko/assets-queue.webp" alt="이미지 생성 창. 대기 중인 A/4를 체크하고 선택한 1장 생성 버튼이 보인다" caption="생성 대기 목록">

대기 목록에 넣은 이미지와 빈 칸이 있으면 탭에 **생성 대기 N장 보기**(빈 칸이 있으면 **빈 칸 N개**도 함께)가 보여요.

1. 눌러서 **이미지 생성** 창을 열어요.
2. 만들 이미지를 체크하고 **선택한 N장 생성**을 눌러요. 한 번에 최대 50장까지 요청할 수 있어요.
3. 생성 중인 행에는 상태가 보이고, 끝나면 각 행에 이미지가 채워져요.

</ScreenStep>

## 이미지 하나 관리하기

<ScreenStep src="/img/screens/ko/assets-image-sheet.webp" alt="이미지 설정 창. 미리보기, 프롬프트 수정·다시 생성, 위치, 마크다운, 해금 필요 스위치, 저장·이미지 삭제" caption="이미지 설정 창">

이미지 썸네일을 누르면 설정 창이 열려요.

- **프롬프트 수정** / **다시 생성**: 생성한 이미지라면 고쳐 다시 만들 수 있어요.
- **위치**: 폴더 밖으로 빼거나 폴더 안으로 넣어요. 한 캐릭터 폴더에서 다른 캐릭터 폴더로는 옮길 수 없어요.
- **해금 필요**: 켜면 유저에게 흐리게 가려져 있다가, 채팅에 이 이미지가 나오면 그 유저에게 풀려요.
- **이미지 삭제**: 작품에서 이 이미지를 지워요.

</ScreenStep>

## 제작 완료 전에 확인할 것

- 모든 이미지에 코드가 있어야 해요. 코드는 영문·숫자만, 같은 폴더 안에서 겹치지 않게요.
- 이미지가 없는 빈 칸과 생성 대기 행은 채우거나 지워요.
- 기본 모습을 만들기로 한 폴더는 기본 모습 이미지도 완성돼 있어야 해요.
- 기본형 프롬프트라면 코드마다 뜻을 적어요. [대화에 이미지 띄우기](/create/images-in-chat)에서 이어서 설명해요.

:::warning[공개한 뒤 에셋을 고칠 때]
제작 완료한 작품은 폴더 이름(캐릭터 코드)을 바꿀 수 없어요. 코드 변경, 새 코드, 이미지 교체는 할 수 있어요. 에셋의 변경은 **수정 반영**을 기다리지 않고 바로 작품에 반영돼요. 프롬프트와 도입부에 쓴 경로가 자동으로 고쳐지지는 않으니 함께 확인해요.
:::

## 자주 막히는 곳

<details>
<summary>‘AI 이미지 생성에는 본인 인증이 필요해요.’라고 떠요</summary>

생성은 본인인증을 마친 계정만 쓸 수 있어요. [성인·본인인증](/account/adult-verification)을 확인해요. 이미지를 올리는 것은 인증 없이도 돼요.

</details>

<details>
<summary>‘이미지가 아직 없는 칸이 있어요.’라고 떠요</summary>

공통 상황 코드로 만든 빈 칸이나 생성 대기 행이 남아 있어요. **빈 칸 N개 보기**로 확인하고 생성하거나 지워요. 어떤 인물에게 그 상황이 필요 없다면 그 칸을 지우고, 기본형 프롬프트의 **예외**에 적어요(예: `B/3 없음`).

</details>

<details>
<summary>이미지를 다른 캐릭터 폴더로 옮기고 싶어요</summary>

캐릭터 폴더끼리는 옮길 수 없어요. 폴더 밖으로 뺀 이미지는 다시 폴더에 넣을 수 있어요. 필요하면 옮길 폴더에서 이미지를 새로 올리거나 생성해요.

</details>

<details>
