# 대화에 이미지 띄우기

대화 속 이미지는 AI가 답을 쓰면서 `![]({{URL}}/A/1.webp)` 같은 줄을 넣을 때 보여요. AI가 어떤 장면에 어떤 이미지를 넣을지는 **프롬프트**에 적은 규칙을 보고 정해요. 이 페이지는 [이미지 준비하기](/create/images)로 에셋을 만든 다음 단계예요.

:::info
전문가 모드 안내예요. 간편 모드는 상황 설명으로 이미지를 고르게 해요. [에셋과 AI 이미지](/create/simple/assets)와 [입력 항목과 제한](/create/simple/reference#이미지-문법)을 보세요.
:::

## 어떻게 이어지나요

| 어디서 | 무엇을 | 예시 |
| --- | --- | --- |
| **에셋** 탭 | 폴더와 코드로 이미지의 경로를 정해요 | 폴더 `A` + 코드 `1` → `A/1` |
| **프롬프트** 탭 | 코드마다 뜻을 적고, 언제 이미지를 넣을지 알려 줘요 | `A`=강민우, `1`=웃음 |
| 채팅 | AI가 장면에 맞는 코드를 골라 답에 넣어요 | 민우가 웃으며 말할 때 `A/1` |

`{{URL}}`은 실제 이미지 주소로 바뀌는 자리예요. 직접 주소를 적지 않아도 돼요.

## 기본형: 코드마다 뜻 적기

<ScreenStep src="/img/screens/ko/prompt-basic-codes.webp" device="part" alt="기본형의 이미지 출력 규칙. 캐릭터코드 A=강민우, B=이서연, 상황코드 1=웃음·2=슬픔·3=분노, 기타코드 BG1=검역소 복도, 예외 B/3 없음" caption="기본형 · 이미지 출력 규칙">

기본형이라면 에셋 탭의 코드가 **이미지 출력 규칙**에 표로 나타나요. 뜻만 짧게 적으면 돼요.

- **캐릭터코드**: 인물의 이름. 예: `강민우`
- **상황코드**: 언제 나오는 이미지인지. 예: `웃음`
- **기타코드**: 무엇인지. 예: `검역소 복도`
- **예외**: 어떤 인물에게 없는 상황. 예: `B/3 없음`

</ScreenStep>

적은 뜻은 아래와 같은 규칙 문장과 코드표로 합쳐져 AI에게 전해져요. 탭 맨 아래 **조립된 프롬프트**에서 확인할 수 있어요.

```text
### 이미지 출력 규칙
장면에 실제로 등장하는 인물·배경을 아래 코드표에서 골라 이미지로 보인다. 응답마다 한 장 이상 — …
형식: `![]({{URL}}/캐릭터코드/상황코드.webp)`, 기타코드는 `![]({{URL}}/기타코드.webp)`. …
캐릭터코드:
A=강민우
B=이서연
상황코드:
1=웃음
2=슬픔
3=분노
기타코드:
BG1=검역소 복도
예외: B/3 없음
예시: 캐릭터코드 A + 상황코드 1 → `![]({{URL}}/A/1.webp)`
```

:::tip[뜻을 적을 때]
- **캐릭터코드의 뜻은 이름만 짧게 적어요.** 기본형에서는 이 뜻이 채팅 화면에서 인물의 이름으로도 쓰여요. 성격·관계 같은 설명은 작품 정보에 적어요.
- **상황코드는 모든 인물에게 같은 뜻으로 써요.** `1`이 민우에게는 웃음, 서연에게는 분노가 되면 AI가 헷갈려요. 인물마다 같은 코드에 같은 상황의 이미지를 넣어요.
- **없는 조합은 예외에 적어요.** 서연에게 분노 이미지가 없다면 `B/3 없음`처럼 적어 AI가 없는 경로를 부르지 않게 해요.
:::

## 직접 작성: 규칙을 직접 쓰기

직접 작성에서는 규칙 문장이 자동으로 붙지 않아요. 아래 세 가지를 프롬프트에 직접 적어요.

1. **어떤 이미지가 있는지**: 코드와 뜻의 목록
2. **언제 넣는지**: 어떤 장면에서 어떤 코드를 쓰는지
3. **어떤 형식으로 넣는지**: `![]({{URL}}/A/1.webp)`처럼 한 줄로, 없는 경로는 만들지 않기

가장 짧게 쓰면 이래요.

```text
서연이 웃으며 인사할 때 아래 이미지를 독립된 한 줄로 출력한다.
![]({{URL}}/B/1.webp)
등록되지 않은 이미지 경로는 만들지 않는다.
```

기본형이 만드는 규칙 전체를 따라 써도 돼요. [프롬프트 쓰기](/create/prompt#직접-작성으로-쓰기)의 **직접 작성 예시 전체 보기**를 참고하세요.

## 도입부에 넣기

도입부는 내가 미리 써 두는 첫 메시지라, 이미지를 넣을 자리도 직접 정해요. **에셋 이미지 넣기**로 넣고 미리보기로 확인해요. 방법은 [도입부 쓰기](/create/greetings#이미지-넣기)에 있어요.

<Screenshot src="/img/screens/ko/greeting-preview-images.webp" device="part" alt="도입부 미리보기. 검역소 복도 이미지와 강민우 이미지가 서술과 대사 사이에 보인다" caption="이미지를 넣은 도입부" />

## 잠가 두고 대화에서 풀기: 해금 필요

<ScreenStep src="/img/screens/ko/assets-image-sheet.webp" alt="이미지 설정 창의 해금 필요 스위치" caption="이미지 설정 창 · 해금 필요">

1. 에셋 탭에서 잠글 이미지의 썸네일을 눌러요.
2. 설정 창에서 **해금 필요**를 켜요.
3. **저장**을 눌러요. 저장해야 잠겨요.

잠근 이미지는 작품 소개 화면의 이미지 목록에서 흐리게 가려져 있어요. 대화에 그 이미지가 나오면 그 유저에게만 풀려요.

특별한 장면의 이미지를 아껴 두고 싶을 때 써요. 표지와 도입부는 처음부터 보이는 자리라, 거기에 쓴 이미지는 잠가도 그대로 보여요.

</ScreenStep>

## 자주 막히는 곳

<details>
<summary>AI가 이미지를 넣지 않거나 가끔만 넣어요</summary>

- 기본형: 코드마다 뜻이 있는지, 이미지가 완성됐는지 확인해요. 뜻이 없는 코드는 AI가 쓸 수 없어요.
- 직접 작성: 이미지 출력 규칙을 프롬프트에 적었는지 확인해요.
- AI의 답은 매번 달라서 규칙을 적어도 가끔 빠질 수 있어요. 대화해 보며 규칙 문장을 다듬어요.

</details>

<details>
<summary>대화에서 이미지가 보이지 않거나 깨져 보여요</summary>

AI가 없는 경로를 불렀을 수 있어요. 에셋 탭의 코드와 프롬프트에 적은 코드가 같은지, 없는 조합을 **예외**에 적었는지 확인해요. 폴더 이름이나 코드를 바꿨다면 프롬프트와 도입부의 경로도 함께 고쳐요.

</details>

<details>
<summary>인물 이름이 이상하게 보여요</summary>

기본형에서는 캐릭터코드의 뜻이 채팅 화면의 인물 이름으로 쓰여요. 뜻에 긴 설명을 적었다면 이름만 남기고, 설명은 작품 정보로 옮겨요.

</details>
