# 공개하고 고치기

**제작 완료**를 누르면 작품이 만들어지고, 공개로 둔 작품은 검토를 거쳐 다른 유저에게 공개돼요. 만든 작품은 **마이페이지 → 작품 관리**에서 언제든 고칠 수 있어요.

## 제작 완료부터 공개까지

| 단계 | 무엇이 일어나나요 |
| --- | --- |
| 제작 완료 | 필수 항목을 확인하고 작품을 저장해요. 빠진 항목이 있으면 그 탭으로 옮겨 알려 줘요. |
| 검토 | 세이프티 규정과 작품 품질을 확인해요. 끝나면 알림을 보내요. |
| 공개 | 다른 유저가 작품을 찾아 대화할 수 있어요. |

검토 중에도 만든 사람은 바로 대화할 수 있어요. 검토에 걸리는 시간은 작품마다 다를 수 있어요.

완료 화면은 작품 상태에 따라 안내가 달라요.

<ScreenStep src="/img/screens/ko/complete-private.webp" alt="비공개 작품의 제작 완료 화면. 비공개 표시와 공개하려면 안내" caption="비공개로 만든 작품">

- **공개**로 만든 새 작품: **검토 중**으로 표시되고, 검토가 끝나면 다른 유저에게 공개돼요. ([첫 작품 만들기](/create/first-work#5-제작-완료)의 완료 화면)
- **비공개**로 만든 작품: 나만 볼 수 있어요. 공개하려면 작품 관리에서 공개 설정을 바꿔요. 그때부터 검토가 시작돼요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/complete-approved.webp" alt="이미 공개된 작품을 고친 뒤의 완료 화면. 승인됨 표시와 수정한 내용이 반영됐어요 안내" caption="이미 공개된 작품을 고쳤을 때">

- 이미 **승인된** 작품을 고쳤다면: 수정한 내용이 바로 다른 유저에게도 보여요. 고칠 때마다 검토를 다시 받지는 않아요.
- 단, **콘텐츠 등급**을 성인용에서 전체 이용가로 바꾸면 다시 검토를 받아요.

</ScreenStep>

## 작품 관리

<ScreenStep src="/img/screens/ko/manage-list.webp" alt="작품 관리 화면. 작품 네 개가 카드로 보이고 수정 버튼, ⋮ 메뉴, 검토 중 표시에 번호가 붙어 있다" caption="마이페이지 → 작품 관리">

**마이페이지 → 작품 관리**에 내가 만든 작품이 모여 있어요.

1. **수정**: 작품을 제작 화면에서 열어요.
2. **⋮**: 메뉴를 열어요. **삭제**와, 거절된 작품이라면 **재심사 요청**이 있어요.
3. 공개한 작품에는 **검토 중** · **승인됨** · **거절됨**이 표시돼요.

아직 제작 완료하지 않은 초안은 **제작 중**으로 보여요. **프로필**을 누르면 작품 소개 화면이 열려요.

</ScreenStep>

위쪽 검색 칸과 **필터**(정렬·공개 상태·승인 상태)로 작품을 찾을 수 있어요. **대시보드**에서는 메시지 수와 획득 리프 같은 작품의 성과를 확인해요.

## 공개한 작품 고치기

<ScreenStep src="/img/screens/ko/released-header.webp" alt="제작 완료한 작품을 연 제작 화면. 헤더에 임시저장 대신 수정 반영 버튼이 있고, 에셋 탭에 폴더 이름을 바꿀 수 없다는 안내가 보인다" caption="제작 완료한 작품의 제작 화면">

1. **작품 관리**에서 **수정**을 눌러요.
2. 고칠 곳을 고쳐요.
3. 헤더의 **수정 반영**을 눌러요.

제작 완료한 작품에는 **임시저장**이 없어요. 반쯤 고친 상태가 공개되지 않도록, 글과 설정은 **수정 반영**을 눌러야 적용돼요.

</ScreenStep>

:::warning[에셋은 바로 반영돼요]
에셋 탭의 이미지 추가·교체·삭제와 코드 변경은 **수정 반영**을 기다리지 않고 바로 작품에 반영돼요. 제작 완료한 작품은 폴더 이름(캐릭터 코드)을 바꿀 수 없고, 이미지를 다른 캐릭터 폴더로 옮길 수도 없어요.
:::

:::tip[창을 닫기 전에 수정 반영]
공개한 작품은 탭을 옮겨도 자동으로 저장되지 않아요. 고친 뒤에는 창을 닫기 전에 **수정 반영**을 눌러요.
:::

## 거절된 작품의 재심사 요청

<ScreenStep src="/img/screens/ko/manage-menu.webp" alt="거절됨 표시가 있는 작품의 ⋮ 메뉴를 연 모습. 재심사 요청과 삭제" caption="⋮ → 재심사 요청">

검토에서 거절되면 작품 카드에 **거절됨**이 표시돼요.

1. 그 작품의 **⋮** 버튼을 누르고 **재심사 요청**을 눌러요.
2. **거절 사유**를 확인해요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/manage-appeal.webp" alt="거절 사유 창. 거절 사유 아래에 심사팀에 전달할 메시지 칸과 제출하기 버튼" caption="거절 사유와 재심사 요청">

3. 사유에 맞게 작품을 고치고 **수정 반영**을 눌러요. 고치는 방법은 [공개한 작품 고치기](#공개한-작품-고치기)와 같아요.
4. 다시 **⋮ → 재심사 요청**을 누르고, 거절 사유 창의 **재심사 요청**을 눌러요.
5. 필요하면 <strong>심사팀에 전달할 메시지 (선택)</strong>에 고친 내용을 적고 **제출하기**를 눌러요. 재심사는 관리자가 검토한 뒤 처리해요.

</ScreenStep>

## 비공개로 만든 작품을 공개하기

1. **작품 관리**에서 **수정**을 눌러요.
2. **기타 설정 → 공개 설정**에서 **공개**를 골라요.
3. **수정 반영**을 누르면 검토가 시작돼요.

## 작품 삭제

**작품 관리**에서 작품의 **⋮ → 삭제**를 눌러요. 삭제한 작품은 작품 관리와 작품 목록에서 사라져요. 되돌리는 메뉴는 없으니 신중하게 눌러요.

:::info
제작 화면의 **↻**(제작 내용 초기화) 버튼은 작품을 지우지 않아요. 입력 중인 화면만 비우고, 저장된 초안은 작품 관리에 남아요.
:::

## 추천 페르소나

<ScreenStep src="/img/screens/ko/settings-persona.webp" device="part" alt="기타 설정의 추천 페르소나. 이름 한지우, 성별 여성, 생년월일, 상세 정보가 채워져 있다" caption="기타 설정 → 추천 페르소나">

**추천 페르소나**는 유저가 대화를 시작할 때 고를 수 있는 페르소나를 미리 만들어 두는 기능이에요. 작품 세계에 어울리는 주인공을 제안할 때 써요. 만들지 않아도 돼요.

만들었다면 네 칸을 모두 채워야 제작 완료할 수 있어요.

- **이름**: 20자까지
- **성별**: 여성·남성
- **생년월일**: 14세 이상이어야 해요
- **상세 정보**: AI가 이 페르소나로 대화하는 유저를 어떻게 대할지 알 수 있게 성격·배경·말투를 적어요. 1,000자까지

</ScreenStep>

## 자주 막히는 곳

<details>
<summary>수정 반영을 눌렀는데 다른 사람 화면에 바로 안 보여요</summary>

아직 검토 중인 작품이라면 검토가 끝난 뒤에 공개돼요. 이미 승인된 작품이라면 수정 반영 즉시 적용돼요. 작품 화면을 새로 고쳐 보세요.

</details>

<details>
<summary>공개한 작품에서 임시저장 버튼이 사라졌어요</summary>

제작 완료한 작품은 **수정 반영** 하나로 저장해요. 고친 내용이 반쯤 공개되지 않게 하려는 거예요.

</details>

<details>
<summary>작품 관리에 같은 작품이 두 개 있어요</summary>

제작 화면을 초기화한 뒤 다시 만들었다면, 먼저 만든 초안이 **제작 중**으로 남아 있어요. **수정**으로 열어 확인하고, 필요 없는 초안은 **⋮ → 삭제**로 지워요.

</details>
