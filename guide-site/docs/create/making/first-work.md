# 첫 작품 만들기

이미지나 컴포넌트 없이도 작품을 완성할 수 있어요. 이 페이지는 예시 작품 **지하 도시 서울**을 따라 꼭 필요한 칸만 채워 **제작 완료**까지 가요.

:::tip[준비물]
- 표지로 쓸 이미지 1장(JPG, PNG, WEBP, GIF, HEIC · 최대 5MB)
- 세계관과 등장인물을 적은 메모. 없으면 아래 예시를 그대로 따라 써도 돼요.
:::

| 순서 | 탭 | 채울 것 |
| --- | --- | --- |
| 1 | **기본 정보** | 작품 제목, 한 줄 소개, 표지, 상세 설명, 장르, 해시태그 |
| 2 | **프롬프트** | 기본형을 고르고 작품 정보 쓰기 |
| 3 | **도입부** | 도입부 제목과 첫 메시지 |
| 4 | **기타 설정** | 필수 항목 다섯 개 고르기 |
| 5 | 헤더 | **제작 완료** |

## 1. 기본 정보 채우기

하단 메뉴의 **제작**을 누르면 **기본 정보** 탭이 먼저 열려요.

<ScreenStep src="/img/screens/ko/first-basic-top.webp" alt="기본 정보 탭에 작품 제목, 한 줄 소개를 적고 표지 한 장을 올린 모습" caption="기본 정보 탭 위쪽">

1. **작품 제목**을 적어요. 최대 30자예요.
2. **한 줄 소개**를 적어요. 작품 카드에 제목과 함께 보이는 문장이에요. 최대 40자예요.
3. **표지**의 **이미지 올리기**를 눌러 이미지를 한 장 넣어요. 표지는 1장 이상 있어야 해요.

</ScreenStep>

> 예시 — 작품 제목: `지하 도시 서울` · 한 줄 소개: `기억을 잃고 깨어난 곳은 봉쇄된 지하 도시의 검역소였다.`

<ScreenStep src="/img/screens/ko/first-basic-description.webp" device="part" alt="상세 설명 칸에 마크다운으로 쓴 작품 소개" caption="상세 설명">

**상세 설명**에는 작품 소개 화면에 보일 글을 적어요. 줄거리, 등장인물, 즐기는 방법을 적으면 돼요. 일반 글·마크다운·HTML을 쓸 수 있고 최대 50,000자예요.

오른쪽 위 **미리보기**를 누르면 유저에게 보일 모양을 확인할 수 있어요.

</ScreenStep>

예시로 쓴 상세 설명이에요. `##`은 큰 제목, `-`는 목록, `**`로 감싼 글은 굵게 보여요.

```md
## 2031년, 봉쇄된 지하 도시 서울

지상이 오염된 뒤 사람들은 지하철역과 지하상가를 이어 만든 도시로 내려왔다.
당신은 기억을 모두 잃은 채 검역소 침대에서 눈을 뜬다.

### 등장인물
- **강민우** — 지하 도시의 안내인. 늘 농담을 던지지만 당신에 대해 무언가 아는 눈치다.
- **이서연** — 검역소 의사. 당신의 기억 상실이 사고가 아니라고 의심한다.

### 이렇게 즐겨 보세요
- 민우를 따라 검역소 밖으로 나가 지하 도시를 둘러보세요.
- 기억을 되찾고 싶다면 서연에게 단서를 물어보세요.
```

<ScreenStep src="/img/screens/ko/first-basic-genres.webp" device="part" alt="장르에서 SF와 미스터리·스릴러를 고르고 해시태그 세 개를 넣은 모습" caption="장르와 해시태그">

**장르**는 1~2개를 골라요. 예시는 **SF**와 **미스터리·스릴러**예요.

**해시태그**는 1개 이상 넣어요. 칸에 적고 **추가**를 누르거나 Enter를 누르면 들어가요. 공백이나 쉼표로 나눠 여러 개를 한 번에 넣을 수도 있어요.

</ScreenStep>

**크리에이터 가이드**와 **추천 모델**은 비워 둬도 돼요. 채우는 방법은 [작품 소개 꾸미기](/create/profile)에 있어요.

## 2. 프롬프트 쓰기

**프롬프트** 탭에 적은 글은 AI가 답을 만들 때마다 읽는 설정이에요. 처음에는 칸을 채우기만 하면 되는 **기본형**이 편해요.

<ScreenStep src="/img/screens/ko/first-prompt.webp" alt="프롬프트 프리셋에서 기본형을 고르고 작품 정보 칸에 세계관과 등장인물을 적은 모습" caption="프롬프트 탭 · 기본형">

1. **프롬프트 프리셋**을 눌러 **기본형**을 골라요. 처음에는 **직접 작성**이 골라져 있어요.
2. **작품 정보** 칸에 세계관, 등장인물, 숨긴 설정, 진행 규칙을 적어요. 칸이 비어 있을 때 보이는 회색 예시와 같은 모양으로 쓰면 돼요.

오른쪽의 **전체 N / 10,000**은 이 탭에 적은 글의 합계예요.

</ScreenStep>

예시로 쓴 작품 정보예요. `####`로 주제를 나누고, 항목은 `- **항목**: 값`으로 적어요. 유저를 가리킬 때는 `{{user}}`라고 써요.

```md
#### 세계관
- **배경**: 2031년, 봉쇄된 지하 도시 서울. 지상은 오염돼 버려졌다.
- **시작**: {{user}}는 기억을 잃은 채 검역소에서 깨어난다.

#### 등장인물
**강민우**
- **역할**: 지하 도시의 안내인, 32세
- **성격**: 느긋하고 농담이 많다
- **말투**: 반말. 문장 끝을 늘인다
- **관계**: {{user}}의 정체를 알지만 모르는 척한다

**이서연**
- **역할**: 검역소 의사, 28세
- **성격**: 사무적이고 냉정하다
- **말투**: 짧은 존댓말
- **관계**: {{user}}의 기억 상실이 사고가 아니라고 의심한다

#### 숨긴 설정
- 민우는 {{user}}를 감시하라는 명령을 받았다. 유저에게 먼저 밝히지 않는다.
- {{user}}의 기억은 관리국이 지웠다.

#### 진행 규칙
- 첫 대화에서 민우가 {{user}}를 검역소 밖으로 안내한다.
- {{user}}가 기억을 되찾으려 하면 서연이 단서를 하나씩 준다.
```

<ScreenStep src="/img/screens/ko/first-prompt-composed.webp" device="part" alt="조립된 프롬프트 칸에 작품 정보가 합쳐져 보이는 모습" caption="탭 아래쪽의 조립된 프롬프트">

탭 맨 아래 **조립된 프롬프트**에는 칸에 적은 글을 합쳐 AI에게 전하는 모습이 보여요. 칸을 고치면 따라 바뀌어요.

에셋과 컴포넌트를 더하면 **이미지 출력 규칙**과 **컴포넌트 출력 규칙**에 뜻을 적는 칸이 생기고, 적은 내용도 여기에 합쳐져요.

</ScreenStep>

:::tip[설정은 짧고 분명하게]
인물마다 역할·성격·말투·관계를 한 줄씩 나눠 적으면 AI가 인물을 헷갈리지 않아요. 유저에게 먼저 밝히면 안 되는 것은 **숨긴 설정**에 두고, 이야기를 어떻게 이끌지는 **진행 규칙**에 적어요. 더 자세한 방법은 [프롬프트 쓰기](/create/prompt)에 있어요.
:::

## 3. 도입부 쓰기

도입부는 대화를 시작할 때 AI가 먼저 보내는 첫 메시지예요.

<ScreenStep src="/img/screens/ko/first-greeting.webp" alt="도입부 탭에 제목과 첫 메시지를 적은 모습" caption="도입부 탭">

1. **도입부 제목**을 적어요. 유저가 시작 장면을 고를 때 보는 이름이에요.
2. 아래 칸에 첫 메시지를 적어요. 최대 2,000자예요. 행동과 서술은 `*별표*` 사이에, 대사는 `"큰따옴표"` 안에 쓰면 채팅과 같은 모양으로 보여요.

</ScreenStep>

```md
*형광등이 깜빡이는 검역소. 소독약 냄새 사이로 누군가 커튼을 걷는다.*

"오, 드디어 깼네~ 사흘 내내 잠만 자더라?"

*낡은 밀리터리 재킷을 걸친 남자가 손전등을 빙글 돌리며 웃는다. 그는 자기를 안내인 강민우라고 소개했다.*

"여긴 서울이야. 정확히는 서울 밑이지~ 그래서, {{user}}. 이름 말고 기억나는 거 있어?"
```

<ScreenStep src="/img/screens/ko/first-greeting-preview.webp" device="part" alt="도입부 미리보기. 서술은 기울임체, 대사는 강조색으로 보인다" caption="도입부 미리보기">

칸 아래 **미리보기**에서 채팅에 보일 모양을 확인해요.

도입부의 `{{user}}`는 대화할 때 유저의 이름으로 바뀌어요. 미리보기에서는 그대로 보여요.

</ScreenStep>

## 4. 기타 설정 고르기

**기타 설정** 탭에서 빨간 `*`가 붙은 항목을 모두 골라요. **공개 설정**(공개)과 **콘텐츠 등급**(전체 이용가)은 처음부터 골라져 있어요.

<ScreenStep src="/img/screens/ko/first-settings-1.webp" alt="기타 설정 탭 위쪽. 공개 설정, 작품 공개 범위, 수익화 제한" caption="기타 설정 탭 위쪽">

- **공개 설정**: **공개**는 모든 유저가, **비공개**는 나만 볼 수 있어요.
- **작품 공개 범위**: **오리지널**은 MYMI에서만 공개하는 작품이에요. 다른 플랫폼에도 올린다면 **일반**을 골라요. 오리지널을 고르면 ‘오리지널로 설정하면 3개월간 해제할 수 없어요.’라는 안내가 나와요.
- **수익화 제한**: 다른 작품의 캐릭터나 세계관을 쓴 2차 창작물처럼 권리가 내 것이 아닌 작품이면 **수익화 제한**을 골라요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/first-settings-2.webp" alt="기타 설정 탭 아래쪽. 이미지 출처, 독자층, 콘텐츠 등급, 마케팅 활용 동의" caption="기타 설정 탭 아래쪽">

- **이미지 출처**: MYMI에서 만든 이미지면 **MYMI 생성**, 다른 AI로 만들었거나 직접 그렸다면 **외부 제작**이에요.
- **독자층**: 작품이 주로 향하는 독자를 **남성향**·**여성향** 중에서 골라요.
- **콘텐츠 등급**: **성인용**은 성인 인증을 한 유저만 이용할 수 있어요. 대화 내용과 생성되는 이미지에도 영향을 줘요.
- **마케팅 활용 동의**: 동의하면 MYMI가 이 작품을 광고·SNS 소재로 쓸 수 있어요.

</ScreenStep>

맨 아래 **추천 페르소나**는 선택이에요. [공개하고 고치기](/create/publish#추천-페르소나)에서 설명해요.

## 5. 제작 완료

헤더의 **제작 완료**를 눌러요. 빠진 항목이 있으면 그 탭으로 옮겨 가고 위쪽에 안내가 떠요.

<ScreenStep src="/img/screens/ko/create-publish-check.webp" alt="작품 제목이 비어 있어 ‘작품 제목을 입력해 주세요.’ 안내가 뜬 모습" caption="빠진 항목이 있을 때">

안내는 한 번에 하나씩 떠요. 안내대로 채운 뒤 다시 **제작 완료**를 눌러요.

확인하는 순서는 기본 정보 → 에셋 → 컴포넌트 → 프롬프트 → 도입부 → 로어북 → 기타 설정이에요. 전체 목록은 [제한과 규칙 한눈에](/create/limits#제작-완료-때-확인하는-것)에 있어요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/first-complete.webp" alt="작품 제작 완료 화면. 작품 카드 아래에 검토 중 표시와 작품 보기·작품 관리 버튼이 있다" caption="작품 제작 완료 화면">

모두 채웠다면 **작품 제작 완료** 화면이 열려요.

- 공개로 만든 작품은 **검토 중**이에요. 나는 지금 바로 대화할 수 있고, 다른 유저에게는 검토가 끝나면 공개돼요.
- **작품 보기**로 바로 대화해 보고, 고칠 곳이 보이면 **작품 관리**에서 **수정**을 눌러요.

</ScreenStep>

## 자주 막히는 곳

<details>
<summary>제작 완료를 눌렀더니 다른 탭으로 넘어가요</summary>

빠진 항목이 있는 탭으로 옮겨 간 거예요. 위쪽에 뜬 안내를 확인하고 채워요. 기본 정보에서는 표지·상세 설명·해시태그가, 기타 설정에서는 **작품 공개 범위**·**수익화 제한**·**이미지 출처**·**독자층**·**마케팅 활용 동의**를 자주 빠뜨려요.

</details>

<details>
<summary>해시태그를 적었는데 ‘해시태그를 1개 이상 추가해 주세요.’라고 떠요</summary>

칸에 적기만 하면 들어가지 않아요. **추가**를 누르거나 Enter를 눌러 태그가 칸 아래에 보이게 해요.

</details>

<details>
<summary>‘작품 정보를 입력해 주세요.’라고 떠요</summary>

기본형의 **작품 정보** 칸이 비어 있어요. 회색 예시는 입력한 글이 아니에요. 칸에 직접 적어요.

</details>

<details>
<summary>AI가 상세 설명에 적은 인물 설정을 몰라요</summary>

상세 설명은 유저에게 보여 주는 소개라 AI에게 전달되지 않아요. AI가 알아야 하는 설정은 **프롬프트** 탭의 작품 정보에 적어요.

</details>
