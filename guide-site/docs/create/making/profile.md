# 작품 소개 꾸미기

유저가 작품을 고르기 전에 보는 것은 **기본 정보** 탭의 내용이에요. 표지, 상세 설명, 크리에이터 가이드, 추천 모델을 채워 작품 소개 화면을 완성해요. 여기 적은 글은 AI에게 전달되지 않아요.

:::info
전문가 모드 안내예요. 간편 모드는 [에셋과 AI 이미지](/create/simple/assets#대표-이미지-정하기)와 [선택사항](/create/simple/extras#선택사항)을 보세요.
:::

## 표지

표지는 1~10장 넣을 수 있어요. 여러 장이면 정한 간격마다 다음 장으로 넘어가요.

<ScreenStep src="/img/screens/ko/profile-cover.webp" device="part" alt="표지 두 장을 넣고 전환 간격을 2초로 정한 모습" caption="표지 두 장과 전환 간격">

- **이미지 올리기**: 가지고 있는 이미지를 올려요. JPG, PNG, WEBP, GIF, HEIC 파일을 5MB까지 쓸 수 있어요.
- **에셋에서 가져오기**: **에셋** 탭에서 만든 이미지를 표지로 써요.
- **전환 간격**: 다음 장으로 넘어가는 시간이에요. 버튼을 누를 때마다 0.5초씩 바뀌고, 직접 적을 때는 0.5초에서 60초 사이로 적어요.

썸네일의 **×** 버튼을 누르면 그 표지를 빼요.

</ScreenStep>

<ScreenStep src="/img/screens/ko/profile-cover-picker.webp" alt="에셋에서 가져오기 창. 에셋 탭의 이미지가 격자로 보인다" caption="에셋에서 가져오기">

**에셋에서 가져오기**를 누르면 에셋 탭에서 완성된 이미지가 모두 보여요. 표지로 쓸 이미지를 고르고 **N장 표지에 추가**를 눌러요.

에셋 탭에 이미지가 아직 없으면 목록이 비어 있어요. [이미지 준비하기](/create/images)에서 먼저 만들어요.

</ScreenStep>

:::tip[표지 고르기]
표지는 작품 목록에서 가장 먼저 보이는 이미지예요. 주인공의 얼굴이 잘 보이는 세로 이미지를 첫 장에 두세요. 여러 장이면 인물마다 한 장씩 넣어 등장인물을 소개하는 방법도 있어요.
:::

## 상세 설명

**상세 설명**은 작품 소개 화면의 본문이에요. 최대 50,000자이고 일반 글, 마크다운, HTML을 섞어 쓸 수 있어요.

1. **미리보기**: 유저에게 보이는 모양을 확인해요.
2. **에셋 정보 복사**: 이미지의 실제 주소를 복사해요. 내 작업실의 Gemini 입력창에 함께 붙여 넣어요.
3. **AI Studio 열기**: MYMI가 준비한 작업실 템플릿을 새 탭으로 열어요.

<ScreenStep src="/img/screens/ko/profile-description-preview.webp" alt="상세 설명 미리보기 창에 제목·등장인물·즐기는 방법이 서식대로 보인다" caption="상세 설명 미리보기">

미리보기에서는 마크다운의 제목·목록·굵은 글씨가 서식대로 보여요.

소개는 이 순서로 쓰면 읽기 편해요.

1. 한두 문장의 작품 요약
2. 세계관과 시작 상황
3. 등장인물 소개
4. 즐기는 방법(무엇을 해 보면 좋은지)

</ScreenStep>

### AI Studio로 소개 페이지 만들기

[AI Studio 열기](https://aistudio.google.com/apps/5e37a6ef-b980-4613-9c34-38b888e1bd1e?showPreview=true&showAssistant=true)

에셋 이미지를 쓰려면 **에셋 정보 복사**를 눌러요. 완성된 이미지가 없어도 제작을 시작할 수 있어요.

1. **작업실 템플릿 열기** — AI Studio 열기를 눌러 Google 계정으로 로그인해요. 다른 개발자가 만든 앱이라는 안내가 나오면 Continue to the app을 눌러요. 앱에서는 외부 브라우저로 열려요.
2. **Remix로 내 작업실 만들기** — 템플릿 로딩이 끝나면 상단 Remix(Copy app)를 누르고 이름을 정한 뒤 Remix app을 눌러요. 내 작업실이 열리면 제작을 시작해요.
3. **Gemini에게 원하는 모습 요청하기** — 왼쪽 Gemini 입력창에 “프로필 HTML로 이 작품의 소개 페이지를 만들어 줘”처럼 요청해요. 복사한 작품·에셋 정보가 있다면 함께 붙여 넣어요.
4. **Preview에서 확인하고 수정하기** — 빌드가 끝나면 오른쪽 Preview에서 커스텀 컴포넌트 또는 프로필 HTML 탭을 선택해요. Launch가 보이면 눌러 작업실을 실행해요. 마음에 들 때까지 Gemini에게 색상·내용·배치를 고쳐 달라고 요청해요.
5. **완성된 코드 복사하기** — 작업실의 프로필 HTML 탭에서 검증 결과를 확인한 뒤 MYMI에 붙여넣을 코드 복사를 눌러요. 자동 복사가 막히면 표시된 HTML 전체를 직접 선택해 복사해요.
6. **MYMI로 돌아와 붙여넣기** — 기본 정보 → 상세 설명에 HTML을 붙여 넣어요. MYMI 미리보기에서도 확인한 뒤 작품을 저장해요.

:::info
Google 계정으로 무료 요청 한도 내에서 만들 수 있어요. 이 제작에는 유료 API 키 연결이나 배포가 필요하지 않아요.
:::

:::tip
복사 중 권한 오류가 나면 Google 계정을 확인하고 새로고침 후 Remix를 다시 눌러 주세요. 미리보기가 비어 있으면 빌드가 끝난 뒤 새로고침해 주세요. 무료 요청을 다 썼다면 한도가 갱신된 뒤 이어서 만들어요.
:::

:::warning[이미지를 지우기 전에]
에셋 정보로 만든 HTML에는 이미지의 실제 주소가 들어가요. 에셋 탭에서 그 이미지를 지우면 소개 페이지의 이미지도 보이지 않게 돼요.
:::

## 크리에이터 가이드

<ScreenStep src="/img/screens/ko/profile-guide.webp" device="part" alt="크리에이터 가이드 칸에 이용 팁을 적은 모습" caption="크리에이터 가이드">

**크리에이터 가이드**에는 작품을 즐기는 방법이나 새로 더한 내용을 적어요. 작품 소개 화면에 따로 보여요. 글 하나에 5,000자까지 쓸 수 있어요.

지금 글을 고치면 그 글이 바뀌어요. **새 글 쓰기**를 누르면 지금 글은 버전 번호(V1, V2…)와 날짜를 달고 아래 목록으로 내려가고, 새 글을 쓸 수 있어요.

</ScreenStep>

> 예시: 처음에는 민우에게 "여기가 어디야?"라고 물어보세요. 기억에 관한 질문은 서연에게 하면 단서를 하나씩 얻을 수 있어요.

## 추천 모델

<ScreenStep src="/img/screens/ko/profile-models.webp" device="part" alt="추천 모델 0/5와 선택하기 버튼" caption="추천 모델">

작품과 잘 맞는 채팅 모델을 최대 5개 골라 둘 수 있어요. 작품 소개 화면과 채팅의 모델 목록에 **추천**으로 표시되고, 유저는 다른 모델도 고를 수 있어요.

**선택하기**를 누르면 채팅 화면과 같은 모델 목록이 열려요.

</ScreenStep>

## 장르와 해시태그

- **장르**: 1~2개를 골라요. 로맨스, BL, GL, 판타지, 무협, SF, 액션·모험, 일상, 드라마, 코미디, 미스터리·스릴러, 공포, 역사·시대극 중에서 골라요.
- **해시태그**: 1개 이상 넣어요. 작품의 소재나 분위기를 짧게 적어요. 예: `지하도시`, `기억상실`, `디스토피아`
- **독자층**(남성향·여성향)은 **기타 설정** 탭에서 따로 골라요.

## 자주 막히는 곳

<details>
<summary>에셋 정보 복사 버튼이 눌리지 않아요</summary>

에셋 탭에 완성된 이미지가 있어야 복사할 수 있어요. 이미지를 올리거나 생성한 뒤 다시 눌러요.

</details>

<details>
<summary>HTML을 붙여 넣었는데 미리보기가 생각과 달라요</summary>

작업실의 **프로필 HTML** 탭에서 **MYMI에 붙여넣을 코드 복사**를 눌러 전체를 다시 붙여 넣어 보세요. 그래도 모양이 깨지면 Gemini에게 수정해 달라고 요청해요.

</details>

<details>
<summary>표지를 몇 장까지 넣을 수 있나요?</summary>

10장까지예요. 더 넣으려면 먼저 한 장을 빼요.

</details>
