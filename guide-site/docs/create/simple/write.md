# 설정과 도입부 쓰기

간편 모드에서 AI가 대화할 때마다 읽는 글은 **기본 정보** 단계의 세계관·등장인물·비밀이에요. 대화의 첫 장면은 **도입부** 단계에서 정해요. 이 페이지는 이 글들을 어떻게 쓰면 좋은지 알려 드려요.

## 작품 제목과 한 줄 소개

- **작품 제목**은 30자까지예요. AI도 작품의 이름으로 읽어요. 도입부의 `{{char}}`는 대화할 때 이 제목으로 바뀌어요.
- **한 줄 소개**는 40자까지예요. 작품 카드에 제목과 함께 보이는 문장이에요. AI는 읽지 않아요.

## 세계관

**세계관**에는 작품의 배경과 규칙, 이야기가 어떻게 시작되는지를 적어요. 간편 모드에는 진행 규칙을 따로 적는 칸이 없어서, 이야기의 시작과 방향도 세계관에 적으면 돼요.

```md
2031년, 지상은 오염돼 버려졌다. 사람들은 지하철역과 지하상가를 이어 만든 지하 도시 서울로 내려와 산다.
도시는 관리국이 통제하고, 지상으로 나가는 통로는 봉쇄돼 있다. 새로 들어온 사람은 먼저 검역소에 머문다.

유저는 기억을 모두 잃은 채 검역소 침대에서 깨어난다. 이야기는 민우가 유저를 검역소 밖으로 안내하면서 시작하고, 유저가 기억을 되찾으려 하면 서연이 단서를 하나씩 건넨다.
```

- **유저가 알아도 되는 내용만 적어요.** 상세 설명을 쓰지 않으면 세계관이 작품 소개 화면에 그대로 보여요. 반전이나 숨긴 사정은 **비밀**에 적어요.
- **짧고 분명하게 적어요.** AI는 대화마다 세계관을 읽어요. 길수록 좋은 것은 아니에요.
- **특정 낱말이 나올 때만 필요한 설정은 로어북으로 보내요.** 조직 이름, 장소, 용어처럼 늘 알 필요는 없는 설정은 [로어북](/create/simple/extras#로어북)에 적으면 그 낱말이 나올 때만 AI에게 전해져요.
- **마크다운을 쓸 수 있어요.** `##` 제목, `-` 목록, `**굵게**`가 작품 소개 화면에서 그 모양으로 보여요.

## 등장인물

<ScreenStep src="/img/screens/ko/simple-basic-characters.webp" device="part" alt="등장인물 칸에 강민우와 이서연 두 인물 카드가 있고 각 카드에 이름과 설명이 적혀 있다" caption="등장인물">

**등장인물 추가**를 눌러 인물을 더해요. 인물마다 **이름**(50자까지)과 **설명**을 적어요. 인물 카드의 **접기**와 **편집**으로 카드를 접고 펼칠 수 있고, **삭제**로 지울 수 있어요.

1명 이상 필요하고, 이름은 서로 달라야 해요. 이름이 겹치면 ‘중복된 등장인물 이름이 있습니다’라는 안내가 떠요.

</ScreenStep>

- **인물마다 역할·성격·말투·관계를 적어요.** 말투는 AI가 그대로 따라 하니 "반말", "짧은 존댓말"처럼 구체적으로 적는 게 좋아요.
- **설명도 작품 소개 화면에 보여요.** 인물이 둘 이상이면 **등장인물** 목록으로 이름과 설명이 나와요. 유저에게 숨겨야 하는 사정은 **비밀**에 적어요.
- **이름은 에셋 단계에서도 써요.** 이미지마다 어느 인물의 이미지인지 연결하니, 인물을 먼저 적어 두고 에셋 단계로 넘어가세요.

예시의 인물 설명이에요.

| 이름 | 설명 |
| --- | --- |
| 강민우 | `지하 도시의 안내인, 32세. 늘 농담을 던지는 느긋한 성격이고, 반말을 쓰며 문장 끝을 늘인다. 유저에 대해 무언가 아는 눈치다.` |
| 이서연 | `검역소 의사, 28세. 사무적이고 냉정하며 짧은 존댓말을 쓴다. 유저의 기억 상실이 사고가 아니라고 의심한다.` |

## 비밀

**비밀**은 AI는 알고 있지만 유저에게는 보이지 않는 설정이에요. 선택 칸이고, 작품 소개 화면에 나오지 않아요.

```md
- 민우는 유저를 감시하라는 명령을 받았다. 유저가 먼저 캐묻기 전에는 밝히지 않는다.
- 유저의 기억은 관리국이 지웠다.
```

**언제 밝히는지도 함께 적어요.** 조건 없이 "민우는 감시 중이다"라고만 적으면 AI가 너무 일찍 밝힐 수 있어요. "유저가 먼저 캐묻기 전에는 밝히지 않는다"처럼 조건을 적으면 AI가 따르기 쉬워요.

## 글자 수 합계

세계관, 등장인물 설명, 비밀을 **합쳐서 10,000자**까지 쓸 수 있어요. 세계관 칸 위의 **세계관 + 등장인물 설명 + 비밀 총 사용량**에 쓴 양과 남은 글자 수가 숫자와 막대로 보여요. 글자 수가 늘수록 색이 바뀌고, 10,000자가 되면 더 입력되지 않아요. 등장인물 이름은 이 합계에 들어가지 않아요.

## 도입부

도입부는 채팅을 시작할 때 AI가 먼저 보내는 첫 메시지예요. 유저가 처음 만나는 장면이라 작품의 첫인상을 정해요. 도입부는 1개 이상 있어야 해요.

<ScreenStep src="/img/screens/ko/simple-intro.webp" alt="도입부 단계. 도입부 1 칩과 추가 버튼, 제목 입력, 이미지 버튼, 첫 메시지 칸과 미리보기가 보인다" caption="도입부 단계">

1. **도입부 제목**을 적어요. 유저가 시작 장면을 고를 때 보는 이름이에요.
2. 아래 칸에 첫 메시지를 적어요. 2,000자까지예요. 칸 아래 숫자가 쓴 글자 수예요.
3. **초기화**를 누르면 이 도입부의 글이 지워져요. 다른 도입부와 제목은 그대로예요.
4. **미리보기**에서 채팅에 보일 모양을 확인해요.

도입부 칩 옆 **추가**를 누르면 도입부를 더 만들 수 있어요. 여러 개를 만들면 유저가 대화를 시작할 때 하나를 골라요. 칩의 휴지통 아이콘으로 지울 수 있고, 도입부가 하나뿐이면 지울 수 없어요.

</ScreenStep>

첫 메시지는 채팅과 같은 모양으로 써요.

| 쓰는 법 | 보이는 모양 |
| --- | --- |
| `*형광등이 깜빡이는 검역소.*` | 행동과 서술(기울임) |
| `"오, 드디어 깼네~"` | 대사(강조색) |
| `{{user}}` | 대화할 때 유저의 이름으로 바뀌어요 |
| `{{char}}` | 대화할 때 **작품 제목**으로 바뀌어요. 인물 이름이 아니에요 |

```md
*형광등이 깜빡이는 검역소. 소독약 냄새 사이로 누군가 커튼을 걷는다.*

"오, 드디어 깼네~ 사흘 내내 잠만 자더라?"

*낡은 밀리터리 재킷을 걸친 남자가 손전등을 빙글 돌리며 웃는다. 그는 자기를 안내인 강민우라고 소개했다.*

"여긴 서울이야. 정확히는 서울 밑이지~ 그래서, {{user}}. 이름 말고 기억나는 거 있어?"
```

:::tip[인물 이름은 직접 쓰세요]
등장인물이 여럿인 작품에서 `{{char}}`를 쓰면 인물 이름 대신 작품 제목이 들어가요. 도입부에는 "강민우"처럼 이름을 직접 써요.
:::

도입부에 에셋 이미지를 넣는 방법은 [에셋과 AI 이미지](/create/simple/assets#도입부에-이미지-넣기)에 있어요.

### 좋은 첫 장면을 쓰는 요령

- **첫 메시지의 끝에서 유저에게 할 일을 건네요.** 예시는 "이름 말고 기억나는 거 있어?"라는 질문으로 끝나서 유저가 바로 답할 수 있어요.
- **인물의 말투를 설명과 맞춰요.** 등장인물 설명에 "반말, 문장 끝을 늘인다"라고 적었다면 도입부의 대사도 그렇게 써요. AI는 첫 메시지의 말투를 이어 가기 쉬워요.
- **시작 장면을 여러 개 만들어 보세요.** 같은 세계에서 출발점이 다른 도입부를 두면 유저가 골라 시작해요.

## 자주 막히는 곳

<details>
<summary>세계관이나 등장인물 설명을 더 쓰려는데 입력되지 않아요</summary>

세계관, 등장인물 설명, 비밀을 합쳐 10,000자에 다다랐어요. 꼭 필요한 설정이 아닌 부분을 줄이거나, 특정 낱말이 나올 때만 필요한 설정은 **로어북**으로 옮겨요.

</details>

<details>
<summary>‘중복된 등장인물 이름이 있습니다’라고 떠요</summary>

같은 이름의 인물이 둘 이상이에요. 영문은 대소문자, 앞뒤 공백을 구분하지 않고 같은 이름으로 봐요. 이름을 서로 다르게 고쳐요.

</details>

<details>
<summary>도입부 제목이나 내용이 비었다고 떠요</summary>

만들어 둔 도입부 중 제목이나 내용이 빈 것이 있어요. 도입부 칩을 하나씩 눌러 확인해요. 쓰지 않을 도입부는 칩의 휴지통 아이콘으로 지워요.

</details>

<details>
<summary>미리보기에 `{{user}}`가 그대로 보여요</summary>

미리보기에서는 바뀌지 않고, 실제 대화에서 유저의 이름으로 바뀌어요.

</details>
