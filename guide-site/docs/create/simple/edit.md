# 작품 수정하기

간편 모드로 만든 작품은 만들 때와 같은 일곱 단계 화면에서 고쳐요. 작품을 만든 모드로 열리기 때문에, 전문가 모드로 만든 작품의 수정은 [공개하고 고치기](/create/publish#공개한-작품-고치기)에 있어요.

## 여는 방법과 이동

1. **마이페이지 → 작품 관리**에서 작품의 **수정**을 눌러요.
2. 간편 모드로 열려요. 맨 위 **제작 모드** 칸은 잠겨 있고, **기본 정보** 단계부터 보여요.
3. 고칠 단계로 가서 고쳐요. 위쪽 탭을 눌러 바로 옮겨 갈 수 있어요.
4. 다 고쳤다면 마지막 **선택사항** 단계까지 다음 버튼으로 가서 **완료**를 눌러요. 모든 단계를 다시 확인하고 **작품 제작 완료** 화면으로 가요.

이동과 저장은 이렇게 돼요.

| 이동 | 확인 | 저장 |
| --- | --- | --- |
| 다음 버튼 | 지금 단계의 필수 항목 | 지금까지 고친 내용 |
| 탭을 눌러 **앞으로** | 그 앞 단계까지 | 지금까지 고친 내용 |
| 탭을 눌러 **뒤로** | 하지 않아요 | 하지 않아요. 다음에 앞으로 넘어갈 때 함께 저장돼요 |
| **완료** | 모든 단계 | 지금까지 고친 내용 |

에셋의 이미지 올리기·지우기, 상황 설명 **저장**, ★ 대표 이미지 바꾸기는 다음 버튼을 누르지 않아도 바로 작품에 반영돼요.

:::warning[공개된 작품은 넘어갈 때마다 바로 바뀌어요]
간편 모드는 다음 버튼이나 탭으로 앞 단계에 넘어갈 때마다 고친 내용을 작품에 저장해요. 이미 공개된 작품이라면 그 순간부터 다른 유저에게도 바뀐 내용이 보여요. 전문가 모드의 **수정 반영**처럼 기다려 주지 않아요. 크게 고칠 때는 바꿀 글을 메모장 같은 곳에 먼저 써 두고, 붙여 넣은 뒤 넘어가세요.
:::

:::warning[이미지를 지울 때 조심하세요]
공개한 작품에서 에셋 이미지를 지우면 그 즉시 작품에서 사라져요. 그 이미지를 도입부에 넣어 두었거나 대화에서 쓰던 중이라면 더는 보이지 않을 수 있어요. 지우기 전에 도입부의 이미지 줄도 함께 확인하세요.
:::

## 예전에 만든 작품을 처음 열 때

예전에 만든 작품에는 없던 칸이 생겼어요. 처음 열면 아래 칸이 비어 있을 수 있고, 골라야 **기타 설정**에서 넘어갈 수 있어요.

- **장르** 1~2개
- **해시태그** 1개 이상 (**독자층**은 해시태그가 아니라 독자층 카드에서 골라요)
- **수익화 제한**
- **마케팅 활용 동의**

기타 설정의 카드 모양과 문구가 전문가 모드와 같아졌어요. 카드마다 무엇을 뜻하는지는 [작품 설정 고르기](/create/settings)에 있어요. 작품 제목은 30자까지예요.

## 단계별로 고칠 것

각 단계에서 쓰는 법은 만들 때와 같아요.

| 단계 | 고칠 수 있는 것 | 안내 |
| --- | --- | --- |
| **기본 정보** | 제목, 한 줄 소개, 세계관, 등장인물, 비밀 | [설정과 도입부 쓰기](/create/simple/write) |
| **에셋** | 이미지 더하기·지우기, 상황 설명, 인물 연결, 대표 이미지, 해금 필요 | [에셋과 AI 이미지](/create/simple/assets) |
| **도입부** | 도입부 더하기·지우기, 제목, 첫 메시지 | [설정과 도입부 쓰기](/create/simple/write#도입부) |
| **기타 설정** | 장르, 해시태그, 공개 설정, 작품 공개 범위 등 | [작품 설정 고르기](/create/settings) |
| **로어북 · 컴포넌트 · 선택사항** | 로어, 컴포넌트, 상세 설명, 추천 페르소나, 제작자의 한 마디 | [로어북·컴포넌트·선택사항](/create/simple/extras) |

## 공개 범위 바꾸기

- **작품을 잠시 숨기려면** **기타 설정 → 공개 설정**에서 **비공개**를 고르고 다음 버튼을 눌러 저장해요.
- **비공개 작품을 공개하려면** 같은 카드에서 **공개**를 골라 저장해요. 공개로 바꾼 작품은 검토를 거쳐 다른 유저에게 보여요. ([공개하고 고치기](/create/publish#비공개로-만든-작품을-공개하기))
- **작품 공개 범위**를 오리지널로 정한 작품은 3개월 동안 바꿀 수 없어요. 남은 날이 카드에 표시돼요.

## 자주 막히는 곳

<details>
<summary>수정을 눌렀더니 제작 모드 칸에 자물쇠가 떠요</summary>

작품 관리에서 연 작품은 만든 모드로 열리고 모드를 바꿀 수 없어요. 새 작품을 만들려면 <strong>↺</strong>를 눌러 편집 화면을 비운 뒤 모드를 고르세요. ([시작하기 전에](/create/before-you-start#작품-관리에서-연-작품은-모드가-잠겨요))

</details>

<details>
<summary>다음 단계로 넘어가지 않아요</summary>

앞 단계에 빠진 필수 항목이 있어요. 위쪽에 뜬 안내를 확인해요. 에셋 단계라면 이미지가 1장 이상 있는지, 이미지마다 상황 설명이 있는지, 대표 이미지가 정해져 있는지 봐요. 기타 설정이라면 장르, 해시태그, **독자층**, **작품 공개 범위**, **수익화 제한**, **이미지 출처**, **마케팅 활용 동의**를 골랐는지 봐요.

</details>

<details>
<summary>‘저장하지 않은 내용이 있어요’라는 창이 떠요</summary>

간편 모드 편집 화면에 다른 작품이나 새 작품의 저장하지 않은 내용이 남아 있어요. **열기**를 누르면 그 내용은 사라지고 고르신 작품이 열려요. 남겨 두려면 **취소**를 누르고 편집 화면에서 먼저 다음 버튼으로 저장하세요.

</details>

<details>
<summary>‘작품을 찾을 수 없습니다.’라고 떠요</summary>

다른 기기에서 삭제한 작품이거나 내 작품이 아니에요. 편집 화면이 비워지니 **작품 관리**에서 작품이 남아 있는지 확인하세요.

</details>

<details>
<summary>프롬프트 탭이 없어요</summary>

간편 모드에는 프롬프트 탭이 없어요. 프롬프트를 직접 쓰고 싶다면 전문가 모드로 새 작품을 만들어야 해요. 기존 작품을 전문가 모드로 바꾸는 버튼은 없어요. ([전문가 모드로 옮기기](/create/simple/to-expert))

</details>

<details>
<summary>잘못 고친 내용을 되돌리고 싶어요</summary>

되돌리는 버튼은 없어요. 바뀐 칸을 다시 고쳐 다음 버튼으로 저장해요. 이미 저장한 뒤에 바뀐 내용은 공개 작품이라면 바로 보이니, 크게 고칠 때는 미리 메모해 두세요.

</details>

<details>
<summary>같은 작품을 PC와 휴대폰에서 함께 열어 놓고 고쳐요</summary>

나중에 저장한 쪽 내용이 남아요. 다른 기기에서 이어서 고치려면 쓰던 곳에서 다음 버튼을 눌러 저장한 뒤 다른 기기의 **작품 관리**에서 **수정**으로 열어요. 편집 화면을 5분 넘게 떠났다 돌아왔을 때 이 기기에 저장하지 않은 내용이 없으면, 서버의 최신 내용으로 바뀌어요.

</details>
