# 입력 항목과 제한

간편 모드 화면의 제한과 규칙을 모았어요. 자세한 사용법은 각 항목의 안내 페이지에 있어요.

## 글자 수와 개수

| 단계 | 항목 | 제한 |
| --- | --- | --- |
| 기본 정보 | 작품 제목 | 필수 · 30자 |
| | 한 줄 소개 | 필수 · 40자 |
| | 세계관 · 등장인물 설명 · 비밀 | 세 칸을 합쳐 10,000자. 세계관과 등장인물 1명 이상(이름과 설명)은 필수, 비밀은 선택 |
| | 등장인물 이름 | 50자. 인물끼리 겹치지 않게 |
| 에셋 | 이미지 | 필수 · 1~200장. JPG, PNG, WEBP, GIF, HEIC · 5MB까지 |
| | 상황 설명 | 이미지마다 필수 · 60자 |
| | 대표 이미지 | 필수 · ★로 한 장 |
| | 한 번에 만드는 AI 이미지 | 베이스 이미지 2장, 상황 이미지 1장까지 |
| 도입부 | 도입부 | 필수 · 1개 이상, 제목과 내용 모두 |
| | 내용 | 2,000자 |
| 기타 설정 | 장르 | 필수 · 1~2개 |
| | 해시태그 | 필수 · 1개 이상(독자층 제외) |
| | 작품 공개 범위 · 수익화 제한 · 이미지 출처 · 독자층 · 마케팅 활용 동의 | 필수 |
| 로어북 | 로어 | 100개까지 |
| | 이름 | 50자 |
| | 키워드 | 로어 하나에 5개, 하나에 10자 |
| | 내용 | 400자 |
| | 한 번에 전해지는 양 | 최근 10개 메시지에서 찾아 최대 3개 · 1,500자 |
| 컴포넌트 | 용도 설명 | 컴포넌트마다 필수 · 500자 |
| | JSX 코드 | 필수 · 10,000자. 함수 이름과 변수 1개 이상 필요 |
| 선택사항 | 상세 설명(HTML) | 선택 · 50,000자 |
| | 추천 페르소나 | 선택. 만들면 이름(20자)·성별·생년월일(14세 이상)·상세 정보(1,000자) 모두 필요 |
| | 제작자의 한 마디 | 선택 · 3,000자 |

공개 설정(공개), 콘텐츠 등급(전체 이용가), 이미지 출력 지침(내부 이미지)은 처음부터 골라져 있어요.

## 다음·완료 때 확인하는 것

다음 버튼이나 **완료** 버튼을 누르면 아래 순서로 확인하고, 처음 걸린 항목의 안내를 띄워요. **완료**는 일곱 단계를 모두 다시 확인해요.

| 순서 | 단계 | 확인하는 것 |
| --- | --- | --- |
| 1 | 기본 정보 | 작품 제목, 한 줄 소개, 세계관, 등장인물 1명 이상, 인물의 이름과 설명, 이름 중복 |
| 2 | 에셋 | 이미지 1장 이상, 대표 이미지, 모든 이미지의 상황 설명 |
| 3 | 도입부 | 1개 이상, 모두 제목과 내용이 있는지 |
| 4 | 기타 설정 | 장르 → 해시태그 → 작품 공개 범위 → 수익화 제한 → 이미지 출처 → 독자층 → 콘텐츠 등급 → 마케팅 활용 동의 순서 |
| 5 | 로어북 | 추가한 로어마다 이름·키워드·내용 |
| 6 | 컴포넌트 | 추가한 컴포넌트마다 용도 설명·코드·함수 이름·변수 1개 이상 |
| 7 | 선택사항 | 추가한 추천 페르소나마다 이름·성별·생년월일·상세 정보 |

## 이미지 문법

간편 모드는 **기타 설정 → 이미지 출력 지침**에서 고른 방식으로 이미지를 내보내요. 한 가지 방식만 써요.

| 방식 | 문법 | 쓰는 곳 |
| --- | --- | --- |
| 내부 이미지 | `img:[이름]` | 에셋에 올린 이미지. 에셋 카드에 `img:AB3K9X`처럼 이름이 표시돼요 |
| 외부 이미지 | `![](이미지 주소)` | 설정에 적어 둔 외부 이미지 주소 |

도입부에서는 `img:[AB3K9X]`처럼 써요. 이름은 MYMI가 정한 영문 대문자·숫자 6자예요. 내부 이미지 방식이면 AI는 에셋마다 적은 **상황 설명**과 연결한 인물을 보고 어떤 이미지를 넣을지 골라요. 외부 이미지 방식에서는 상황 설명이 AI에게 전해지지 않고, 설정에 적은 이미지 주소나 주소 규칙을 보고 이미지를 넣어요. 주소를 알 수 없으면 이미지를 넣지 않아요.

:::warning[전문가 모드에서는 쓰지 않아요]
`img:[이름]`은 간편 모드의 문법이에요. 전문가 모드의 작품에는 에셋 탭의 코드와 `![]({{URL}}/A/1.webp)`를 써요.
:::

## `{{user}}`와 `{{char}}`

| 쓰는 곳 | `{{user}}` | `{{char}}` |
| --- | --- | --- |
| 도입부 | 대화할 때 유저의 이름으로 바뀌어요 | 대화할 때 **작품 제목**으로 바뀌어요 |

도입부의 미리보기에서는 바뀌지 않고 그대로 보여요. `{{char}}`는 인물 이름이 아니라 작품 제목이 들어가므로, 인물 이름은 직접 써요.

## 저장

| 상황 | 저장되는 때 |
| --- | --- |
| 모든 작품 | 다음 버튼을 누를 때, 탭을 눌러 앞으로 넘어갈 때, **완료**를 누를 때. 그 전까지 고친 내용이 함께 저장돼요 |
| 에셋 | 이미지 올리기·지우기, 상황 설명 **저장**, ★ 대표 이미지 바꾸기는 바로 반영돼요 |
| 공개한 작품 | 저장되는 순간 다른 유저에게도 바뀐 내용이 보여요 |

## 무료와 인증

- 작품 제작의 이미지 생성·다시 생성은 무료예요. 생성하려면 본인인증이 필요해요.
- 성인용 작품은 성인 인증을 한 유저만 이용할 수 있어요.
- 이미지 생성 태그 단계의 세이프티 필터는 성인 인증을 한 계정만 끌 수 있어요.

## 자주 막히는 곳

<details>
<summary>‘저장에 실패했습니다’라고 떠요</summary>

저장 중에 연결이 끊겼거나 서버가 잠시 바빴을 수 있어요. 잠시 뒤 다음 버튼을 다시 눌러요. 계속 같은 안내가 뜨면 **마이페이지 → 디스코드**의 문의 채널이나 [contact@mymi.live](mailto:contact@mymi.live)로, 어떤 작품의 어느 단계에서 생겼는지 알려 주세요.

</details>

<details>
<summary>글자가 더 입력되지 않아요</summary>

칸마다 정해진 글자 수를 넘으면 입력되지 않아요. 기본 정보 단계는 세계관, 등장인물 설명, 비밀을 합쳐 10,000자가 한도이니, 다른 칸에서 쓴 양도 확인해요.

</details>
