# 에셋과 AI 이미지

대화에 띄울 이미지는 **에셋** 단계에서 준비해요. 가지고 있는 이미지를 올리거나 MYMI에서 무료로 만들 수 있어요. 이미지마다 **상황 설명**을 적으면 AI가 그 설명을 보고 어떤 장면에 어떤 이미지를 보여 줄지 골라요.

:::info[이미지 생성은 무료, 본인인증이 필요해요]
작품 제작의 이미지 생성과 다시 생성은 무료예요. 생성하려면 [본인인증](/account/adult-verification)을 마친 계정이어야 해요. 이미지를 올리는 것은 인증 없이도 돼요.
:::

## 에셋 단계는 이렇게 생겼어요

<ScreenStep src="/img/screens/ko/simple-assets-overview.webp" alt="에셋 단계. 위에 안내 문구와 AI 이미지 버튼, 아래에 에셋 추가 칸과 이미지 카드들이 두 줄로 보인다. 카드마다 별, 삭제 버튼, 이미지 이름, 인물 이름, 상황 설명이 있다" caption="에셋 단계">

1. **AI 이미지**: MYMI에서 이미지를 만드는 창을 열어요.
2. **에셋 추가**: 이미지를 올리거나 AI로 만든 이미지를 가져와요.
3. 이미지 카드: 왼쪽 위 <strong>★</strong>는 대표 이미지, 오른쪽 위 <strong>×</strong>는 삭제예요. 아래쪽에 이미지 이름(`img:AB3K9X`)과 연결한 인물 이름, 상황 설명이 보여요.

</ScreenStep>

- 이미지는 200장까지 넣을 수 있어요.
- 이미지 이름(`img:AB3K9X`)은 MYMI가 영문 대문자와 숫자 6자로 정해 줘요. 바꿀 수 없어요.
- 상황 설명이 비어 있는 카드는 설명 칸이 빨간 테두리로 보여요.

## 가지고 있는 이미지 올리기

1. **에셋 추가**를 눌러요.
2. **파일 업로드**를 누르고 이미지를 골라요. JPG, PNG, WEBP, GIF, HEIC 파일을 5MB까지 쓸 수 있어요.
3. 올라간 카드를 눌러 상황 설명을 적어요.

이미지는 한 번에 한 장씩 올라가요. 올리는 동안 카드에 돌아가는 표시가 보이고, 끝나면 이미지가 나와요. 처음 올린 이미지는 자동으로 작품의 대표 이미지가 돼요.

## 상황 설명 쓰기

상황 설명은 **AI가 이미지를 고르는 기준**이에요. 유저에게는 보이지 않아요.

<ScreenStep src="/img/screens/ko/simple-asset-sheet.webp" alt="상황 설명 입력 창. 이미지 미리보기 옆에 캐릭터 선택 목록이 있고 아래에 해금 필요 스위치와 설명 칸, 저장 버튼이 있다" caption="상황 설명 입력">

1. 이미지를 눌러 **상황 설명 입력** 창을 열어요.
2. **캐릭터 선택**에서 이미지 속 인물을 골라요. 기본 정보 단계에 적은 등장인물이 목록에 나와요. 인물이 없는 배경이나 모두에게 쓸 이미지는 **공용**이에요.
3. 설명 칸에 어떤 장면인지 60자까지 적어요.
4. **저장**을 눌러요. 눌러야 설명과 인물 연결이 저장돼요.

</ScreenStep>

설명 칸에는 인물 이름을 넣으라는 안내가 있어요. 이름이 없으면 AI가 이미지를 올바르게 보여 줄 수 없어요. 예시 이미지는 이렇게 적었어요.

| 이미지 | 캐릭터 | 상황 설명 |
| --- | --- | --- |
| 민우 웃음 | 강민우 | `강민우가 밝게 웃고 있다.` |
| 민우 슬픔 | 강민우 | `강민우가 슬픈 표정으로 고개를 숙인다.` |
| 민우 분노 | 강민우 | `강민우가 화가 나 미간을 찌푸린다.` |
| 서연 웃음 | 이서연 | `이서연이 옅게 미소 짓는다.` |
| 서연 슬픔 | 이서연 | `이서연이 슬픈 표정으로 시선을 떨군다.` |
| 복도 | 공용 | `푸른 조명이 켜진 검역소 복도.` |

민우의 이미지가 여러 장이라면 "웃고 있다", "고개를 숙인다"처럼 표정이나 행동이 드러나게 적어요. 설명이 비슷하면 AI가 어느 이미지를 골라야 할지 헷갈려요. 반대로 설명이 없거나 너무 짧으면 그 이미지를 고를 이유가 없어요.
:::

이미지 이름(`img:AB3K9X`)은 상황 설명과 함께 AI에게 전해져서, AI가 답에 그 이름을 넣으면 그 자리에 이미지가 보여요.

## 대화에서 이미지는 이렇게 나와요

**내부 이미지**(처음 값)에서는 AI가 답을 쓸 때 **말하는 인물마다** 그 인물에 연결한 이미지 중에서 지금 장면과 가장 가까운 것을 골라요. 고르는 기준이 상황 설명이에요. 다른 인물의 이미지를 빌려 쓰지는 않아요.

- **채팅**과 **1:1** 보기에서는 답의 각 부분이 그 인물의 이미지로 시작해요.
- **소설** 보기에서는 장면에 나오는 인물의 이미지를 글 사이에 자연스럽게 끼워 넣어요.

(채팅방의 보기는 채팅방 오른쪽 위 팔레트 아이콘의 **UI 설정 → UI 모드**에서 바꿔요. ([대화하기](/chatting/chat-with-character.md)))

그래서 이렇게 준비하면 좋아요.

- **인물마다 이미지를 한 장 이상 연결해요.** 이미지를 연결하지 않은 인물은 말할 때 보여 줄 이미지가 없어요.
- **같은 인물의 이미지는 표정과 행동이 다르게 여러 장 준비해요.** 장면에 따라 알맞은 것을 골라요.
- **배경처럼 특정 인물에 속하지 않는 이미지는 공용으로 둬요.**

## 대표 이미지 정하기

대표 이미지는 작품을 대표하는 한 장이에요. 이미지 카드 왼쪽 위 <strong>★</strong>를 누르면 그 이미지가 대표가 돼요. 지금 대표인 이미지는 ★가 노랗게 켜져 있어요. 대표 이미지는 꼭 있어야 해요.

- 처음 올리거나 가져온 이미지는 자동으로 대표가 돼요.
- 대표 이미지를 지우면 남은 이미지 중 가장 먼저 추가한 것이 대표가 돼요.
- 전문가 모드처럼 표지를 여러 장 넣는 기능은 없어요.

## AI로 이미지 만들기

<ScreenStep src="/img/screens/ko/simple-ai-panel.webp" alt="AI 이미지 생성 창. 새 베이스 이미지 만들기 칸과 배경·인물별 베이스 이미지 카드들이 보이고, 인물 카드마다 상황 이미지 만들기 버튼이 있다" caption="AI 이미지 생성 창">

에셋 단계 오른쪽 위 **AI 이미지**를 누르면 **AI 이미지 생성** 창이 열려요. AI로 **베이스 이미지**를 만들고, 그 위에 **상황 이미지**를 이어서 만들 수 있어요.

- **베이스 이미지**: 한 인물(또는 배경)의 기본이 되는 이미지예요.
- **상황 이미지**: 베이스의 그림체와 인상은 그대로 두고 표정, 동작, 배경, 의상, 소품, 구도만 바꾼 이미지예요.

</ScreenStep>

### 베이스 이미지 만들기

1. 창에서 **새 베이스 이미지 만들기**를 눌러요.
2. 첫 화면에서 **이미지 종류 선택**의 **인물**이나 **배경**을 골라요. 배경은 인물 없이 장소 중심의 이미지예요.
3. 인물을 골랐다면 **소속 캐릭터 선택**과 **성별 선택**이 이어서 나와요. 소속 캐릭터는 기본 정보 단계에 적은 등장인물 중에서 골라요. 고르지 않으면 공용 이미지로 저장돼요. 성별은 **여성**이나 **남성**을 골라요. **다음**을 눌러요.
4. **그림체 선택**에서 그림체를 골라요. **추천 그림체**는 MYMI가 준비한 그림체라서 처음에는 여기서 골라요. 저장해 둔 **내 그림체**나 **직접 작성**도 있어요.
5. **배경 → 신체 - 머리카락 → 신체 - 눈 → 신체 - 얼굴 특징 → 신체 - 피부 → 신체 - 체형 → 의상 → 소품 → 기타등등** 순서로 태그를 골라요. 필요 없는 단계는 **다음**으로 넘어가요. 배경 이미지라면 배경 태그만 고르면 돼요.
6. **태그 확인 & 생성**에서 고른 태그를 확인하고 **이미지 생성**을 눌러요.

마지막 단계에서 **전문가 모드**를 펼치면 넣지 않을 요소와 생성 설정을 바꿀 수 있어요. 이 **전문가 모드**는 작품을 만드는 제작 모드와는 다른 것이에요. 잘 모르겠다면 그대로 두세요.

만드는 동안 카드에 **요청 중…**, **대기 중…**, <strong>생성 중…</strong>이 차례로 보여요. 베이스 이미지는 동시에 2장까지, 상황 이미지는 한 번에 1장씩 만들 수 있어요. 가득 찼을 때는 **베이스 생성 대기 중**, **상황 이미지 생성 대기 중**으로 바뀌어요. 실패하면 카드에 **생성 실패**가 나와요. 잠시 뒤 다시 하거나 **실패한 이미지 카드 삭제**로 치워요.

### 상황 이미지 만들기

1. 베이스 이미지 카드를 눌러요. 그 베이스에서 만든 상황 이미지 목록이 열려요.
2. **새 상황 이미지 만들기**를 눌러요.
3. **어떤 표정을 지을까요?**, **어떤 포즈를 취할까요?** 같은 단계에서 **표정**, **동작**, 그리고 바꿀 **배경**, **의상**, **소품**, **구도**를 골라요. 고르지 않은 것은 베이스와 같아요. (**베이스와 동일**)
4. **이미지 생성**을 눌러요.

이미지 카드에서 **프롬프트 수정 후 재생성**으로 다시 만들거나 **AI 이미지 삭제**로 지울 수 있어요. 베이스 이미지를 지우면 그 아래 상황 이미지도 함께 지워져요.

### 만든 이미지를 에셋으로 가져오기

AI로 만든 이미지는 바로 에셋이 되지 않아요. 가져와야 해요.

<ScreenStep src="/img/screens/ko/simple-ai-picker.webp" alt="AI 이미지에서 선택 창. 베이스 이미지와 상황 이미지가 격자로 보이고 아래에 N개 선택 완료 버튼이 있다" caption="AI 이미지에서 선택">

1. 에셋 단계에서 **에셋 추가**를 누르고 **AI 이미지에서 선택**을 눌러요.
2. 베이스 이미지를 누르면 그 상황 이미지 목록이 보여요.
3. 에셋으로 가져올 이미지를 골라요. 여러 장을 한 번에 고를 수 있어요.
4. 아래 **N개 선택 완료**를 눌러요.

</ScreenStep>

가져온 이미지에는 AI 이미지를 만들 때 고른 소속 캐릭터가 이어져요. 상황 설명이 비어 있다면 카드를 눌러 적어요. 에셋은 200장까지라서, 남은 자리보다 많이 고를 수는 없어요.

## 해금 필요: 잠가 두고 대화에서 풀기

특별한 장면의 이미지를 아껴 두고 싶을 때 써요.

1. 이미지를 눌러 **상황 설명 입력** 창을 열어요.
2. **해금 필요** 스위치를 켜요.
3. **저장**을 눌러요. 저장해야 잠겨요.

잠근 이미지는 유저에게 가려져 있다가, 대화에 그 이미지가 나오면 그 유저에게만 풀려요. 잠긴 이미지 카드에는 자물쇠 표시가 보여요.

## 도입부에 이미지 넣기

도입부는 내가 미리 써 두는 첫 메시지라서 이미지를 넣을 자리도 직접 정해요.

<ScreenStep src="/img/screens/ko/simple-intro-insert.webp" alt="도입부 단계의 에셋 이미지 삽입 창. 에셋 이미지들이 격자로 보인다" caption="에셋 이미지 삽입">

1. 도입부의 첫 메시지 칸에서 이미지를 넣을 자리를 눌러 커서를 둬요.
2. 위쪽의 **이미지** 버튼을 눌러요. 에셋이 하나도 없으면 이 버튼이 보이지 않아요.
3. **에셋 이미지 삽입** 창에서 넣을 이미지를 누르면 커서 자리에 `img:[AB3K9X]` 같은 줄이 들어가요.

</ScreenStep>

**미리보기**에서 이미지가 제자리에 보이는지 확인해요. 이미지 줄의 이름에 맞는 에셋이 없으면 ‘이미지를 찾을 수 없음’이라고 떠요. 이름을 직접 치지 말고, 그 줄을 지운 뒤 **이미지** 버튼으로 다시 넣으면 틀리지 않아요.

```md
*형광등이 깜빡이는 검역소. 소독약 냄새 사이로 누군가 커튼을 걷는다.*

img:[AB3K9X]
"오, 드디어 깼네~ 사흘 내내 잠만 자더라?"
```

## 이미지 출력 지침

**기타 설정** 단계의 **이미지 출력 지침** 카드가 AI가 이미지를 어떻게 내보낼지 정해요. 한 가지 방식만 써요.

| 방식 | 뜻 | AI가 이미지를 고르는 기준 |
| --- | --- | --- |
| **내부 이미지** | 에셋에 올린 이미지를 `img:[이름]`으로 내보내요. 처음부터 골라져 있어요 | 에셋마다 적은 상황 설명과 연결한 인물 |
| **외부 이미지** | 설정에 적어 둔 이미지 주소(URL)를 `![](주소)`로 내보내요 | 세계관·등장인물 설명 같은 설정에 적은 주소나 주소 규칙. 주소를 알 수 없으면 이미지를 넣지 않아요. 상황 설명은 AI에게 전해지지 않아요 |

에셋 단계에서 올린 이미지를 쓰는 작품이라면 **내부 이미지**를 그대로 두세요.

## 자주 막히는 곳

<details>
<summary>이미지를 만들려고 하니 ‘AI 이미지 생성에는 본인 인증이 필요해요.’라고 떠요</summary>

작품 제작의 이미지 생성은 무료지만 본인인증을 마친 계정만 쓸 수 있어요. 제작 화면에서는 인증을 시작할 수 없으니 이렇게 해요.

1. 쓰던 내용을 다음 버튼으로 저장해 두세요.
2. **마이페이지 → 출석 체크**에서 **오늘의 보상 받기**를 눌러 본인인증을 마쳐요.
3. **마이페이지 → 작품 관리**에서 작품을 다시 열고 이미지를 만들어요.

가지고 있는 이미지를 올리는 것은 본인인증 없이도 돼요. 인증 방법은 [성인·본인인증](/account/adult-verification)에 있어요.

</details>

<details>
<summary>AI 이미지로 만든 이미지가 에셋에 없어요</summary>

만든 이미지는 자동으로 에셋에 들어가지 않아요. 에셋 단계의 **에셋 추가 → AI 이미지에서 선택**에서 골라 가져와요.

</details>

<details>
<summary>‘에셋 설명을 입력해주세요.’라고 떠요</summary>

상황 설명이 비어 있는 이미지가 있어요. 설명 칸이 빨간 테두리인 카드를 눌러 적고 **저장**을 눌러요.

</details>

<details>
<summary>대화에서 AI가 이미지를 거의 안 보여 줘요</summary>

**기타 설정**의 **이미지 출력 지침**이 **내부 이미지**인지 확인해요. **외부 이미지**이면 상황 설명이 AI에게 전해지지 않고, 설정에 이미지 주소가 없으면 이미지를 넣지 않아요.

내부 이미지인데도 적게 나온다면 이렇게 확인해요.

1. 말하는 인물에게 이미지가 **연결**되어 있는지 봐요. AI는 그 인물에 연결한 이미지만 골라요.
2. 같은 인물의 이미지가 한 장뿐이면 늘 같은 이미지가 나와요. 표정이 다른 이미지를 더하고 상황 설명을 분명하게 적어요.
3. 채팅방의 UI 모드에 따라 이미지가 나오는 모양이 달라요. ([대화하기](/chatting/chat-with-character.md))

AI의 답은 매번 달라서 가끔 알맞은 이미지를 고르지 못할 수 있어요.

</details>

<details>
<summary>iPhone 앱에서 ‘갤러리 접근 권한이 필요합니다.’라고 떠요</summary>

이미지를 올리려면 MYMI가 사진에 접근할 수 있어야 해요. iPhone의 **설정 → MYMI**에서 사진 접근을 허용한 뒤 다시 **파일 업로드**를 눌러요.

</details>

<details>
<summary>업로드가 실패했다고 떠요</summary>

파일 형식(JPG, PNG, WEBP, GIF, HEIC)과 크기(5MB)를 확인해요. 그래도 안 되면 잠시 뒤 다시 올려 보세요.

</details>

<details>
<summary>도입부 미리보기에 ‘이미지를 찾을 수 없음’이라고 떠요</summary>

`img:[…]`의 괄호 안 이름과 같은 이미지가 에셋에 없어요. 에셋 단계에서 그 이미지를 지우지 않았는지, 괄호 안 이름이 이미지 카드에 붙은 이름과 같은지 확인해요. 이름을 직접 치지 말고 그 줄을 지운 뒤 **이미지** 버튼으로 다시 넣으면 틀리지 않아요.

</details>
