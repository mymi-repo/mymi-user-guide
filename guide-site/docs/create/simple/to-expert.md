# 전문가 모드로 옮기기

간편 모드로 만든 작품을 전문가 모드로 바꾸는 기능은 없어요. 두 모드의 내용은 자동으로 옮겨지지도 않아요. 전문가 모드의 프롬프트를 직접 써 보고 싶다면 **새 작품**을 만들고 설정을 옮겨 적어요.

## 옮기기 전에 알아 둘 것

- 새 작품은 **별개의 작품**이에요. 기존 작품의 대화, 좋아요, 댓글은 새 작품으로 옮겨지지 않아요.
- 새 작품을 만들어도 **기존 작품은 그대로** 남아요. 더 보여 주고 싶지 않다면 **마이페이지 → 작품 관리 → 수정**으로 열어 **기타 설정 → 공개 설정**을 **비공개**로 바꾸고 다음 버튼을 눌러 저장해요.
- 옮기는 동안 기존 작품의 글이 필요해요. 세계관, 등장인물 설명, 비밀, 상황 설명을 메모장 같은 곳에 복사해 두거나, 다른 기기에서 기존 작품을 열어 두고 보면서 옮기면 편해요.

## 옮기는 순서

1. 기존 작품의 글을 복사해 둬요.
2. 하단 메뉴의 **제작**을 눌러요. 작품 관리에서 연 작품이 편집 화면에 열려 있다면 <strong>↺</strong>를 눌러 편집 화면을 비워요. 작품 관리의 기존 작품은 그대로 남아요.
3. **기본 정보** 탭 맨 위 **제작 모드**에서 **전문가 모드**를 눌러요. 처음이라면 안내 창에서 **전문가 모드로 전환**을 눌러요.
4. 아래 표를 보면서 옮겨 적어요.
5. **제작 완료**를 눌러요.

## 항목별로 어디로 옮기나요

| 간편 모드에서 쓰던 곳 | 전문가 모드에서 쓰는 곳 | 옮길 때 할 일 |
| --- | --- | --- |
| 기본 정보 → 작품 제목 · 한 줄 소개 | 기본 정보 → 작품 제목 · 한 줄 소개 | 그대로 옮겨요 |
| 기본 정보 → 세계관 | 프롬프트 → 작품 정보(기본형) 또는 본문(직접 작성) | 시대·장소·규칙을 옮겨 적어요 |
| 기본 정보 → 등장인물 | 프롬프트 → 작품 정보의 등장인물 | 이름 줄 아래에 역할·성격·말투·관계를 적어요 |
| 기본 정보 → 비밀 | 프롬프트 → 작품 정보의 숨긴 설정 | 밝히는 조건도 함께 적어요. 상세 설명에는 옮기지 않아요 |
| 에셋 → 인물 연결 | 에셋의 캐릭터 폴더 + 프롬프트의 캐릭터코드 뜻 | 인물마다 폴더를 만들고 폴더 코드와 이름을 맞춰요 |
| 에셋 → 상황 설명 | 에셋의 이미지 코드 + 프롬프트의 상황코드·기타코드 뜻 | 같은 상황은 모든 인물에게 같은 코드로 맞춰요 |
| 에셋 → 대표 이미지(★) | 기본 정보 → 표지 | 표지는 1~10장이에요. 에셋에서 가져올 수 있어요 |
| 도입부의 `img:[이름]` | 도입부의 `![]({{URL}}/A/1.webp)` | **에셋 이미지 넣기**로 다시 넣어요 |
| 기타 설정 → 장르 · 해시태그 | 기본 정보 → 장르 · 해시태그 | 전문가 모드는 기본 정보 탭에 있어요 |
| 기타 설정 → 나머지 카드 | 기타 설정 | 카드와 선택지가 같아요. 다시 골라요 |
| 컴포넌트 → 용도 설명 | 프롬프트 → 컴포넌트 출력 규칙(기본형) 또는 본문(직접 작성) | 언제 어떤 값으로 부를지 옮겨 적어요 |
| 선택사항 → 상세 설명(HTML) | 기본 정보 → 상세 설명 | 상세 설명은 필수예요. HTML도 쓸 수 있어요 |
| 선택사항 → 제작자의 한 마디 | 기본 정보 → 크리에이터 가이드 | 그대로 옮겨요 |
| 선택사항 → 추천 페르소나 | 기타 설정 → 추천 페르소나 | 그대로 옮겨요 |
| 로어북 | 로어북 | 이름·키워드·내용을 그대로 옮겨요 |

## 빠뜨리기 쉬운 것

세계관과 인물 설명만 옮기고 끝내지 마세요. 아래도 함께 챙겨야 해요.

1. **이미지의 상황 설명** → 에셋의 코드와 프롬프트의 코드 뜻. 간편 모드는 MYMI가 상황 설명을 모아 AI에게 전했지만, 전문가 모드는 이미지를 언제 넣을지 프롬프트에 직접 적어야 해요.
2. **컴포넌트의 용도 설명** → 프롬프트의 컴포넌트 출력 규칙.
3. **도입부의 `img:[이름]`** → 새 에셋 코드로 넣은 이미지 줄. 전문가 모드는 `img:[…]`를 읽지 않아요.
4. **상세 설명(HTML)과 제작자의 한 마디** → 상세 설명, 크리에이터 가이드.
5. **예전에 넣은 대화 예시** → 프롬프트. 지금 간편 모드 화면에는 보이지 않지만, 예전에 넣은 대화 예시가 있는 작품은 AI에게 전해지고 있어요. 새 작품으로는 옮겨지지 않으니 필요한 말투나 예시를 프롬프트에 직접 적어요.

### 예: 이미지 한 장 옮기기

간편 모드에서 인물 **강민우**에 연결하고 상황 설명을 "강민우가 밝게 웃고 있다."로 적은 이미지(`img:[AB3K9X]`)가 있다면, 전문가 모드에서는 이렇게 옮겨요.

1. **프롬프트**의 작품 정보에 민우의 역할·성격·말투를 적어요.
2. **에셋**에 캐릭터 폴더 `A`를 만들고 그 이미지를 코드 `1`로 넣어요.
3. 기본형이라면 **이미지 출력 규칙**에 캐릭터코드 `A` = `강민우`, 상황코드 `1` = `웃음`을 적어요.
4. 직접 작성이라면 이미지의 뜻과 함께 언제 어떤 형식으로 넣을지도 본문에 적어요.
5. 도입부에 쓰던 `img:[AB3K9X]`는 지우고 **에셋 이미지 넣기**로 `A/1`을 넣어요.

전문가 모드의 이미지 체계는 [이미지 준비하기](/create/images)와 [대화에 이미지 띄우기](/create/images-in-chat)에 자세히 있어요.

## 자주 막히는 곳

<details>
<summary>간편 모드 작품을 열었는데 전문가 모드 버튼을 누를 수 없어요</summary>

작품 관리에서 연 작품은 만든 모드로 잠겨요. <strong>↺</strong>를 눌러 편집 화면을 비우면 잠금이 풀리고, 모드를 다시 고를 수 있어요. 작품 관리의 기존 작품은 지워지지 않아요. ([시작하기 전에](/create/before-you-start#작품-관리에서-연-작품은-모드가-잠겨요))

</details>

<details>
<summary>간편 모드 도입부를 전문가 모드에 붙였더니 이미지가 나오지 않아요</summary>

전문가 모드는 `img:[…]`를 읽지 않아요. 도입부 미리보기에도 그 자리에 ‘이미지를 불러올 수 없어요’가 떠요. 그 줄을 지우고 첫 메시지 칸의 **에셋 이미지 넣기**로 다시 넣어요.

</details>

<details>
<summary>옮긴 작품의 대화에 이미지가 나오지 않아요</summary>

간편 모드에서는 MYMI가 상황 설명을 모아 AI에게 전했지만, 전문가 모드는 이미지를 언제 넣을지 프롬프트에 적어야 해요. 기본형이라면 **이미지 출력 규칙**의 코드 뜻을 채우고, 직접 작성이라면 이미지 규칙을 본문에 적어요. 방법은 [대화에 이미지 띄우기](/create/images-in-chat)에 있어요.

</details>

<details>
<summary>간편 모드에서 쓰던 내용이 전문가 모드 화면에 없어요</summary>

두 모드는 초안이 따로예요. 간편 모드의 내용은 전문가 모드로 옮겨지지 않아요. 위 표를 보면서 직접 옮겨 적어요.

</details>
