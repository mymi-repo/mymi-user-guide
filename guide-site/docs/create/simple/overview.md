# 간편 모드 알아보기

간편 모드는 **칸을 채우면 MYMI가 그 내용을 모아 AI 설정으로 만들어 주는** 방식이에요. 일곱 단계를 오른쪽 아래의 **>**(다음) 버튼으로 차례로 넘어가며 만들어요. 처음 만든다면 [첫 작품 만들기](/create/simple/first-work)부터 따라 해 보세요.

## 간편 모드로 열기

- 새 작품은 간편 모드가 기본이에요. 하단 메뉴의 **제작**을 누르면 돼요. 다른 모드로 열려 있다면 **기본 정보** 탭 맨 위의 **제작 모드**에서 **간편 모드**를 눌러요. ([시작하기 전에](/create/before-you-start#제작-모드-고르기))
- **마이페이지 → 작품 관리**에서 간편 모드로 만든 작품의 **수정**을 누르면 간편 모드로 열려요.

## 화면과 일곱 단계

<ScreenStep src="/img/screens/ko/simple-overview.webp" alt="간편 모드 화면 위쪽과 아래쪽. 위에 작품 제작 제목과 초기화 버튼, 탭 줄에 기본 정보·에셋·도입부·기타 설정·로어북·컴포넌트·선택사항이 있고 아래에 다음 버튼이 있다" caption="간편 모드 화면">

1. **↺**(제작 내용 초기화): 입력 중인 화면을 비우고 처음부터 다시 시작해요. 저장된 초안은 **작품 관리**에 남아요.
2. **탭 줄**: 기본 정보 · 에셋 · 도입부 · 기타 설정 · 로어북 · 컴포넌트 · 선택사항. 지금 단계가 보라색으로 표시돼요.
3. **>**(다음) 버튼: 이 단계를 확인하고 저장한 뒤 다음 단계로 가요. 마지막 단계에서는 **완료**로 바뀌어요.

</ScreenStep>

| 단계 | 무엇을 적나요 | 꼭 필요한가요 |
| --- | --- | --- |
| **기본 정보** | 작품 제목, 한 줄 소개, 세계관, 등장인물, 비밀 | 비밀만 선택이에요 |
| **에셋** | 대화에 띄울 이미지, 이미지마다 상황 설명, 대표 이미지 | 필수 |
| **도입부** | 대화를 시작할 때 AI가 먼저 보내는 첫 메시지 | 필수 |
| **기타 설정** | 장르, 해시태그, 공개 설정, 작품 공개 범위 같은 운영 항목 | 필수 |
| **로어북** | 특정 낱말이 나올 때만 AI에게 전하는 설정 | 선택 |
| **컴포넌트** | 상태창·선택지처럼 대화 속에 뜨는 UI | 선택 |
| **선택사항** | 상세 설명, 추천 페르소나, 제작자의 한 마디 | 선택 |

로어북·컴포넌트·선택사항은 비워 둬도 작품을 완성할 수 있어요. 각 단계에서 쓰는 법은 [설정과 도입부 쓰기](/create/simple/write), [에셋과 AI 이미지](/create/simple/assets), [로어북·컴포넌트·선택사항](/create/simple/extras)에 있어요.

## AI가 읽는 것과 유저가 보는 것

간편 모드에서는 어느 칸의 글을 AI가 읽고, 어느 칸의 글을 유저가 보는지 알고 쓰는 게 중요해요.

| 칸 | AI가 대화할 때 | 유저가 보는 곳 |
| --- | --- | --- |
| 작품 제목 | 읽어요 | 작품 카드, 작품 소개 |
| 한 줄 소개 | 읽지 않아요 | 작품 카드 |
| 세계관 | 읽어요 | 작품 소개(상세 설명을 쓰지 않았을 때) |
| 등장인물 이름·설명 | 읽어요 | 작품 소개(상세 설명을 쓰지 않았을 때) |
| 비밀 | 읽어요 | 보이지 않아요 |
| 에셋의 상황 설명 | 읽어요(이미지 출력 지침이 **내부 이미지**일 때) | 보이지 않아요 |
| 컴포넌트의 용도 설명·변수 | 읽어요 | 보이지 않아요 |
| 로어북 | 키워드가 나올 때만 읽어요 | 보이지 않아요 |
| 상세 설명(선택사항) | 읽지 않아요 | 작품 소개 |
| 제작자의 한 마디 | 읽지 않아요 | 작품 소개 |

:::warning[세계관과 등장인물 설명은 유저에게도 보여요]
**상세 설명**을 쓰지 않으면 작품 소개 화면의 **상세 설명** 영역에 세계관과 등장인물의 이름·설명이 그대로 나와요. 유저가 몰라야 하는 설정은 세계관이나 등장인물 설명이 아니라 **비밀** 칸에 적어요. 비밀은 AI만 읽고 유저에게는 보이지 않아요.
:::

## 저장은 언제 되나요

- 다음 버튼을 누르면 그 단계의 필수 항목을 확인하고, 모두 채웠다면 지금까지 쓴 내용을 작품에 저장한 뒤 다음 단계로 가요. 처음 **기본 정보**에서 다음 버튼을 누를 때 작품이 만들어지고, **마이페이지 → 작품 관리**에 **제작 중**으로 보여요.
- 위쪽 탭을 눌러 **앞으로** 갈 때도 같아요. 그 앞 단계까지 확인하고 저장해요. **뒤로** 갈 때는 확인도 저장도 하지 않고, 고친 내용은 다음에 앞으로 넘어갈 때 함께 저장돼요.
- 에셋은 달라요. 이미지를 올리고 지우기, 상황 설명 **저장**, ★ 대표 이미지 바꾸기는 다음 버튼을 누르지 않아도 바로 작품에 반영돼요.
- 마지막 단계에서 **완료**를 누르면 모든 단계를 다시 확인하고 작품을 만들어요. 그러면 **작품 제작 완료** 화면이 열려요.

:::warning[공개한 작품은 넘어갈 때마다 바로 바뀌어요]
간편 모드는 다음 버튼을 누르거나 탭으로 앞 단계에 넘어갈 때마다 고친 내용을 작품에 저장해요. 이미 공개된 작품이라면 그 순간부터 다른 유저에게도 바뀐 내용이 보여요. 전문가 모드의 **수정 반영**처럼 기다려 주지 않아요. 크게 고칠 때는 바꿀 글을 메모장 같은 곳에 먼저 써 두고, 붙여 넣은 뒤 넘어가세요.
:::

:::tip[창을 닫기 전에]
다음 버튼을 누르기 전에 창을 닫으면 그 단계에서 고친 내용은 서버에 저장되지 않아요. 로그아웃하거나 다른 계정으로 로그인해도 저장하지 않은 내용은 지워져요. 쓰던 중에 멈춘다면 다음 버튼을 눌러 저장해 두세요.
:::

## 꼭 채워야 하는 것

다음 버튼을 눌렀을 때 아래 항목이 비어 있으면 안내가 뜨고 넘어가지 않아요. 안내는 한 번에 하나씩 떠요.

| 단계 | 확인하는 것 |
| --- | --- |
| 기본 정보 | 작품 제목, 한 줄 소개, 세계관, 등장인물 1명 이상(이름과 설명), 이름이 서로 다른지 |
| 에셋 | 이미지 1장 이상, 대표 이미지, 모든 이미지의 상황 설명 |
| 도입부 | 도입부 1개 이상, 모두 제목과 내용이 있는지 |
| 기타 설정 | 장르 1~2개, 해시태그 1개 이상, 작품 공개 범위, 수익화 제한, 이미지 출처, 독자층, 마케팅 활용 동의 |
| 로어북 | 추가한 로어마다 이름·키워드·내용 |
| 컴포넌트 | 추가한 컴포넌트마다 용도 설명·코드·함수 이름·변수 1개 이상 |
| 선택사항 | 추가한 추천 페르소나마다 이름·성별·생년월일·상세 정보 |

**공개 설정**(공개)과 **콘텐츠 등급**(전체 이용가), **이미지 출력 지침**(내부 이미지)은 처음부터 골라져 있어요. 각 칸의 글자 수 제한은 [입력 항목과 제한](/create/simple/reference)에 모아 뒀어요.

## 자주 막히는 곳

<details>
<summary>다음을 눌렀는데 넘어가지 않고 안내만 떠요</summary>

그 단계 또는 앞 단계에 빠진 필수 항목이 있다는 뜻이에요. 안내 문장이 어느 칸인지 알려 줘요.

- 기본 정보: ‘작품 제목을 입력해 주세요.’, ‘세계관을 입력해주세요.’, ‘등장인물을 1명 이상 추가해주세요.’
- 에셋: ‘에셋을 1개 이상 추가해주세요.’, ‘대표 이미지를 선택해주세요.’, ‘에셋 설명을 입력해주세요.’
- 도입부: ‘도입부 제목을 입력해주세요.’, ‘도입부 내용을 입력해주세요.’
- 기타 설정: ‘장르를 1~2개 선택해 주세요.’, ‘해시태그를 1개 이상 추가해 주세요.’, ‘독자층을 골라 주세요.’

안내대로 채운 뒤 다시 다음 버튼을 눌러요.

</details>

<details>
<summary>세계관에 쓴 내용이 작품 소개 화면에 그대로 보여요</summary>

상세 설명을 쓰지 않으면 세계관과 등장인물 설명이 작품 소개에 보이는 게 원래 동작이에요. 유저에게 숨겨야 하는 설정은 **비밀** 칸으로 옮기세요. 작품 소개를 직접 꾸미고 싶다면 **선택사항**의 **상세 설명**을 **사용**으로 바꾸고 HTML로 소개 글을 써요. 그러면 세계관과 등장인물 대신 그 글이 보여요. ([로어북·컴포넌트·선택사항](/create/simple/extras#상세-설명))

</details>

<details>
<summary>프롬프트 탭이 없어요</summary>

간편 모드에는 프롬프트 탭이 없어요. 세계관·등장인물·비밀 칸에 적은 내용을 MYMI가 모아서 AI에게 전해요. 프롬프트를 직접 쓰고 싶다면 제작 모드를 **전문가 모드**로 바꾸고 새 작품을 만들어요. ([전문가 모드로 옮기기](/create/simple/to-expert))

</details>

<details>
<summary>같은 작품을 두 기기에서 열어 놓고 고쳐요</summary>

나중에 저장한 쪽 내용이 남아요. 다른 기기에서 이어서 고치려면, 쓰던 곳에서 다음 버튼을 눌러 저장한 뒤 다른 기기의 **마이페이지 → 작품 관리**에서 **수정**으로 열어요. 편집 화면을 5분 넘게 떠났다 돌아왔을 때 이 기기에 저장하지 않은 내용이 없다면, 서버에 있는 최신 내용으로 바뀌어요.

</details>
