# 계정 탈퇴

계정 탈퇴는 **MYMI 계정의 이용을 종료하는 절차**입니다. 로그아웃하거나 앱을 삭제하는 것과는 다릅니다. 탈퇴하면 기존 계정의 대화, 작품 관리, 보유 잔액 등을 계속 이용할 수 없으며, 재가입해도 이전 계정의 데이터가 새 계정으로 이어지지 않습니다.

> **최종 확인 전에 확인하세요.** 탈퇴를 취소하거나 기존 계정으로 되돌리는 기능은 제공되지 않습니다. 잠시 이용을 쉬려는 경우에는 [로그아웃](/account/login-profile.md)을 이용할 수 있습니다.

## 1. 탈퇴 전에 확인할 것

| 확인할 항목 | 먼저 할 일 |
| --- | --- |
| 지금 로그인한 계정 | 마이페이지의 닉네임·아이디와 가입에 사용한 소셜 계정을 확인합니다. 여러 계정 중 다른 계정에 로그인하지 않았는지 확인하세요 |
| 남은 스파크 등 보유 잔액 | 잔액과 사용 내역을 확인합니다. 탈퇴는 잔액을 새 계정으로 옮기거나 자동으로 환불하는 절차가 아닙니다 |
| 결제취소·환불 문의 | 결제 경로와 영수증·주문번호를 확인하고, 처리할 건이 있다면 탈퇴 전에 문의합니다 |
| 제작한 작품·필요한 내용 | 계속 관리할 작품이 있는지 확인하고, 필요한 본인 작성 내용은 미리 보관합니다 |
| 제작자 정산·진행 중인 문의 | 정산이나 결제·분쟁 관련 확인이 남아 있다면 먼저 담당 안내를 받습니다 |
| 삭제하고 싶은 댓글·공개 글 | 탈퇴만으로 모든 공개 글이 즉시 삭제되는 것은 아닙니다. 탈퇴 전에 확인하고 필요한 경우 문의합니다 |

로그인 계정을 잘못 선택했거나 계정 정보만 바꾸려는 경우에는 [로그인·프로필 설정](/account/login-profile.md)을 먼저 확인하세요.

## 2. 웹·앱에서 탈퇴하기

웹과 Android·iOS 앱의 진입 경로는 같습니다.

1. 탈퇴할 MYMI 계정으로 로그인합니다.
2. **마이페이지**를 엽니다.
3. 상단의 **프로필 이미지·닉네임·아이디가 있는 영역**을 눌러 **내 정보 수정**으로 이동합니다.
4. **내 정보** 탭을 선택합니다. **크리에이터** 탭이 아닙니다.
5. 아래로 내려 **상세 정보 입력란 아래의 회원탈퇴**를 누릅니다.
6. **정말 탈퇴하시겠습니까?** 확인창에서 내용을 읽고, 탈퇴하려는 계정이 맞는지 확인합니다.
7. 진행하려면 아래 표의 최종 확인 버튼을 누릅니다.
8. 처리가 끝날 때까지 기다립니다. 성공하면 로그아웃되고 홈 화면으로 이동합니다.

| 이용 환경 | 확인창의 최종 버튼 | 진행하지 않으려면 |
| --- | --- | --- |
| PC·모바일 웹 | **삭제** | **취소** |
| Android·iOS 앱 | **회원탈퇴** | **취소** |

**회원탈퇴 안내창을 여는 것만으로는 탈퇴되지 않습니다.** 최종 버튼을 누르기 전에는 취소할 수 있습니다. 최종 요청을 보낸 뒤에는 화면을 닫는 것으로 탈퇴를 취소할 수 없습니다.

## 3. 탈퇴하면 무엇이 달라지나요?

| 항목 | 탈퇴 후 처리 |
| --- | --- |
| MYMI 계정 | 기존 계정의 이용이 종료됩니다. 같은 소셜 계정으로 다시 가입해도 새 계정으로 시작합니다 |
| 대화·페르소나·개인 이용 정보 | 기존 계정으로 접근하거나 계속 사용할 수 없습니다. 재가입한 계정으로 이전되지 않습니다 |
| 제작한 작품 | 삭제 처리 대상이 되어 기존 계정으로 관리할 수 없습니다. 관련 정보 정리는 순차적으로 반영될 수 있습니다 |
| 보유 잔액 | 탈퇴한 계정의 스파크 등 잔액을 계속 이용할 수 없으며, 새 계정으로 자동 이전되지 않습니다. 환불이 필요하면 별도 절차를 확인해야 합니다 |
| 본인·휴대폰 인증 | 기존 계정의 인증 상태를 새 계정에서 그대로 사용할 수 없습니다. 인증정보 재사용 제한도 적용됩니다 |
| 댓글·공개 게시물 | 계정 탈퇴만으로 모든 게시물이 즉시 삭제되는 것은 아닙니다. 남아 있는 글의 처리나 삭제가 필요하면 문의하세요 |

탈퇴 처리가 완료되는 것과 모든 관련 기록이 즉시 지워지는 것은 다릅니다. 결제·환불·분쟁 대응이나 부정 이용 방지 등에 필요한 기록은 정해진 기준에 따라 보관될 수 있습니다. 개인정보의 보관·파기 기준과 삭제 요청 방법은 [개인정보처리방침](https://mymi.live/ko/legal/privacy-policy)을 확인하세요.

계정 탈퇴는 **MYMI에서의 탈퇴**입니다. 로그인에 사용한 Google·Apple 등 외부 소셜 서비스의 계정 자체를 삭제하는 절차는 아닙니다.

## 4. 재가입과 인증정보 재사용의 30일 제한

| 구분 | 현재 적용되는 제한 |
| --- | --- |
| 같은 소셜 계정으로 재가입 | 탈퇴 후 **30일 동안** 제한됩니다. 예를 들어 가입에 사용했던 동일한 Google 계정으로 바로 다시 가입할 수 없습니다 |
| 탈퇴 계정에 연결됐던 본인인증 정보·휴대폰 번호 | 탈퇴 후 **30일 동안** 다른 계정에서의 재사용이 제한됩니다 |

재가입 제한과 인증정보 재사용 제한은 별도로 확인합니다. 다른 로그인 수단을 선택했더라도, 최근 탈퇴한 계정의 본인인증 정보나 휴대폰 번호를 바로 옮길 수 있는 것은 아닙니다.

**30일은 탈퇴를 되돌릴 수 있는 유예기간이 아닙니다.** 제한 기간이 지나 새로 가입해도 이전 대화, 작품, 잔액, 인증 상태가 자동으로 복구되지는 않습니다.

제한 기간이 지났는데도 안내가 계속 나온다면 탈퇴 시점, 로그인 수단, 오류 문구를 확인해 문의하세요. 인증 절차는 [성인·본인인증](/account/adult-verification.md)을 참고할 수 있습니다.

## 5. 결제나 환불이 남아 있다면

**회원탈퇴는 결제취소·환불 신청을 대신하지 않습니다.** 남은 잔액이 자동으로 현금 환급되는 것도 아닙니다.

- **웹에서 결제한 경우:** 구매 내역과 영수증·주문번호를 확인하고 MYMI에 문의하세요.
- **앱에서 결제한 경우:** 영수증에서 App Store·Google Play 등 실제 결제 경로를 확인하고, 해당 결제 경로의 환불 절차를 따르세요. 경로를 모르겠다면 MYMI에 문의하세요.
- **진행 중인 환불·정산이 있는 경우:** 계정과 거래를 확인하기 쉽도록 탈퇴 전에 문의하고 안내를 받으세요.
- **이미 탈퇴한 경우:** 이메일로 결제·계정 관련 문의를 할 수 있습니다. 당시 MYMI 아이디, 로그인 수단, 확인이 필요한 거래의 주문번호와 결제일을 준비하세요.

환불 가능 여부와 처리 방식은 구매 조건, 사용 내역, 결제 경로에 따라 확인합니다. 자세한 조건은 [이용약관](https://mymi.live/ko/legal/terms-of-service)과 구매 당시 안내를 참고하세요.

## 6. 탈퇴가 잘되지 않을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 회원탈퇴 버튼을 찾을 수 없어요 | **내 정보 수정 → 내 정보** 탭의 맨 아래를 확인하세요. 크리에이터 프로필 편집 화면에서는 보이지 않습니다 |
| 버튼을 눌렀는데 확인창만 열렸어요 | 아직 최종 요청 전입니다. 탈퇴를 원할 때만 웹의 **삭제**, 앱의 **회원탈퇴**를 누르세요 |
| 처리 중 표시가 오래 지속돼요 | 잠시 기다린 뒤 연결 상태를 확인하세요. 화면이 응답하지 않으면 페이지나 앱을 다시 열고, 상태가 불분명하면 문의하세요 |
| 오류가 나서 탈퇴됐는지 모르겠어요 | 오류 문구와 발생 시점을 기록하세요. 오류만으로 완료 여부를 단정하지 말고, 로그아웃 여부와 계정 상태를 확인해 문의하세요 |
| 탈퇴 후 다시 로그인하려니 재가입 제한이 나와요 | 같은 소셜 계정에는 탈퇴 후 30일 재가입 제한이 적용됩니다 |
| 다른 계정에서 번호·본인정보를 인증할 수 없어요 | 최근 탈퇴 계정의 인증정보라면 30일 재사용 제한을 확인하세요 |
| 앱을 지웠는데 계정이 남아 있어요 | 앱 삭제는 회원탈퇴가 아닙니다. 웹이나 앱에서 위의 탈퇴 절차를 진행해야 합니다 |
| 탈퇴한 계정으로 되돌아가고 싶어요 | 서비스 화면에서 탈퇴 취소·복구 기능은 제공되지 않습니다. 다시 가입해도 이전 정보는 이어지지 않습니다 |

## 도움이 필요할 때

탈퇴 전에는 **마이페이지 → Discord → 문의**를 이용하거나 [contact@mymi.live](mailto:contact@mymi.live)로 연락하세요. 탈퇴 후에도 이메일로 문의할 수 있습니다.

**MYMI 아이디, 가입에 사용한 로그인 수단, 탈퇴를 시도한 시점, 웹·Android·iOS 중 이용 환경, 오류 문구**를 함께 알려주면 확인에 도움이 됩니다. 결제 관련 문의라면 해당 거래의 주문번호와 결제일도 준비하세요.

개인정보의 열람·삭제 등 별도 요청은 [개인정보처리방침의 문의 안내](https://mymi.live/ko/legal/privacy-policy)를 따르세요.
