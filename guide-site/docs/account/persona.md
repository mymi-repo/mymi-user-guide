# 페르소나 설정

페르소나는 **작품 속에서 내가 어떤 사람으로 대화할지 정하는 역할 설정**입니다. 이름, 성별, 생년월일, 상세정보를 통해 캐릭터가 참고할 내 정보를 정할 수 있습니다.

예를 들어 같은 작품에서도 ‘처음 마을에 온 여행자’와 ‘주인공을 오래 알고 지낸 동료’로 각각 대화할 수 있습니다. 작품의 등장인물을 만드는 설정과는 별개이며, **제작자명과 공개 프로필에는 기본 프로필의 닉네임**이 사용됩니다.

> **이미 대화 중인 방의 설정을 바꾸고 싶다면:** 그 방의 **메뉴 → 페르소나 → 불러오기 → 원하는 페르소나 선택 → 저장** 순서로 진행하세요. 마이페이지에서 대표 페르소나를 바꾸는 것만으로는 기존 대화방에 적용되지 않습니다.

## 1. 기본·대표·추천 페르소나는 무엇이 다른가요?

| 구분 | 의미 | 알아둘 점 |
| --- | --- | --- |
| 기본 페르소나 | 계정 정보를 바탕으로 자동으로 준비되는 페르소나 | 목록에서 수정하면 **내 정보 수정** 화면으로 이동합니다. 목록에는 삭제 메뉴가 없습니다 |
| 대표 페르소나 | 내 페르소나 중 새 대화를 시작할 때 우선 선택할 하나 | 카드에 **대표** 표시가 붙습니다. 기본 페르소나도 대표로 지정할 수 있습니다 |
| 추천 페르소나 | 제작자가 해당 작품에 어울리도록 준비한 이용자 역할 | 작품 상세의 페르소나 선택 화면에서 고릅니다. 추천이 없는 작품도 있습니다 |
| 대화방의 페르소나 | 방을 만들 때 선택해 그 방에 저장한 역할 설정 | 대화방 안에서 따로 수정합니다. 마이페이지의 목록과 자동으로 동기화되지 않습니다 |

**‘기본’과 ‘대표’는 같은 뜻이 아닙니다.** 기본은 계정 정보와 연결된 페르소나이고, 대표는 지금 우선 사용할 페르소나입니다. 한 카드에 두 표시가 함께 붙을 수도 있습니다.

별도 페르소나를 만들지 않아도 기본 페르소나로 시작할 수 있습니다. 작품이나 역할에 따라 구분하고 싶을 때 추가하세요.

## 2. 내 페르소나 추가하기

1. 로그인한 뒤 **마이페이지 → 페르소나 설정**을 엽니다.
2. **페르소나 추가**를 누릅니다.
3. 이름과 필요한 정보를 입력합니다.
4. 화면 상단의 **저장**을 누르고 목록에 추가됐는지 확인합니다.

| 항목 | 필수 여부 | 입력 방법 |
| --- | --- | --- |
| 이름 | 필수 | 캐릭터가 나를 부르는 이름입니다. **20자 이내**로 입력합니다 |
| 생년월일 | 선택 | 입력하려면 연·월·일을 모두 채웁니다. 현재 입력 화면에서는 **만 14세 이상에 해당하는 유효한 날짜**만 저장할 수 있습니다 |
| 성별 | 선택 | 추가·수정 화면에서 **여성 / 남성** 중 선택할 수 있습니다 |
| 상세정보 | 선택 | 역할, 성격, 말투, 직업, 등장인물과의 관계 등을 **1,000자 이내**로 적습니다 |

이름만으로도 저장할 수 있습니다. 생년월일은 미래 날짜나 존재하지 않는 날짜를 사용할 수 없으며, 연·월·일 중 일부만 입력하면 생년월일 정보가 저장되지 않습니다.

페르소나의 생년월일은 역할 설정입니다. 이를 바꿔도 계정의 성인 확인 상태가 바뀌지 않습니다. 성인 콘텐츠 이용 조건은 [성인·본인인증](/account/adult-verification.md)을 확인하세요.

## 3. 대표 페르소나 지정하기

1. **마이페이지 → 페르소나 설정**에서 사용할 **카드 자체를 누릅니다**.
2. 해당 카드에 **대표** 표시가 붙었는지 확인합니다.
3. 작품 상세 화면을 새로 열고, 대화 시작 버튼 옆의 페르소나 선택 버튼에서 선택된 역할을 확인합니다.

**추가하거나 수정해 저장하는 것과 대표로 지정하는 것은 별도 동작**입니다. 새 페르소나를 추가한 뒤 주로 사용할 예정이라면 목록에서 그 카드를 눌러 주세요.

대표 변경은 새 대화를 준비할 때의 기본 선택에 사용됩니다. 이미 열어 둔 작품 상세에서 직접 고른 역할이나 기존 대화방의 설정까지 바꾸는 기능은 아닙니다.

## 4. 작품에서 대화를 시작하기 전에 선택하기

1. 원하는 작품의 상세 화면을 엽니다.
2. 하단 **대화 시작 버튼 옆의 작은 프로필 아이콘**을 누릅니다.
3. **내 페르소나** 또는 **추천 페르소나**에서 사용할 카드를 선택합니다.
4. **선택 완료**를 누릅니다.
5. **대화 시작하기** 또는 **새 대화 시작**으로 새 대화방을 만듭니다.

**추천 페르소나** 탭은 제작자가 추천 역할을 준비한 작품에서만 나타납니다. 추천 역할을 선택해도 마이페이지의 대표 페르소나가 바뀌지는 않습니다.

### 선택 화면의 연필 버튼으로 수정할 때

- **내 페르소나**를 수정하고 저장하면, 마이페이지에 보관된 해당 페르소나도 바뀝니다. 이미 만들어진 대화방에는 자동 반영되지 않습니다.
- **추천 페르소나**를 수정하면, 그 선택 화면에서 사용할 내용을 조정합니다. 제작자의 원본 추천 설정은 바뀌지 않으며 내 페르소나 목록에도 자동 추가되지 않습니다.
- 수정 후에도 **선택 완료 → 새 대화 시작**까지 진행해야 선택한 역할로 새 방이 만들어집니다. 추천 역할을 다른 작품에서도 재사용하려면 마이페이지에서 내 페르소나로 따로 추가하세요.

> **이전 대화 이어하기**는 기존 방을 엽니다. 작품 상세에서 다른 페르소나를 골랐더라도 이어서 연 방에는 기존 설정이 유지됩니다. 기존 방의 역할을 바꾸려면 아래 절차를 이용하세요.

## 5. 이미 대화 중인 방의 페르소나 바꾸기

1. 변경하려는 **대화방을 엽니다**.
2. 대화방 상단의 메뉴에서 **페르소나**를 누릅니다.
3. **페르소나 수정** 화면에서 현재 방의 이름과 상세정보를 확인합니다.
4. 직접 수정하거나 **불러오기**를 눌러 내 페르소나 목록에서 하나를 고릅니다.
5. 불러온 내용을 확인하고, 이 방에서만 필요한 내용이 있으면 수정합니다.
6. **저장**을 누릅니다.

**‘페르소나를 불러왔습니다’는 입력란에 내용을 가져왔다는 뜻입니다.** 마지막에 저장해야 그 대화방에 적용됩니다.

이 화면에서 저장한 내용은 **현재 대화방에만** 적용됩니다. 마이페이지의 원본 페르소나나 다른 방의 설정을 함께 수정하지 않습니다. 여러 방에서 같은 변경을 쓰려면 각 방에서 불러오고 저장하세요.

페르소나를 바꿔도 기존 대화 기록이 초기화되지는 않습니다. 새로운 역할로 이야기를 처음부터 시작하고 싶다면 작품 상세에서 페르소나를 선택한 뒤 **새 대화 시작**을 이용하세요.

## 6. 목록의 페르소나 수정·삭제하기

**마이페이지 → 페르소나 설정**에서 카드의 **더보기(⋮)** 메뉴를 엽니다.

- **추가한 페르소나 수정**: **수정**을 선택하고 내용을 바꾼 뒤 **저장**합니다.
- **기본 페르소나 수정**: **수정**을 누르면 **내 정보 수정** 화면으로 이동합니다. 이름·성별·생년월일·상세정보와 기본 페르소나의 관계는 [로그인·프로필 설정](/account/login-profile.md)을 참고하세요.
- **추가한 페르소나 삭제**: **삭제**를 선택하면 내 목록에서 제거됩니다. 현재 대표인 페르소나를 삭제하면 기본 페르소나가 대표로 지정됩니다.
- **기본 페르소나 삭제**: 목록에서 삭제할 수 없습니다.

목록에서 수정하거나 삭제해도 이미 대화방에 저장된 페르소나와 대화 기록은 그대로 남습니다. 기존 방을 바꾸려면 그 방의 페르소나 설정을 직접 수정하세요.

## 7. 어디를 바꾸면 어디에 적용되나요?

| 한 작업 | 적용되는 곳 | 기존 대화방에 자동 반영되나요? |
| --- | --- | --- |
| 내 정보에서 이름·성별·생년월일·상세정보 저장 | 계정 정보와 기본 페르소나 | 아니요 |
| 마이페이지에서 추가한 페르소나 수정 | 내 페르소나 목록의 해당 항목 | 아니요 |
| 대표 페르소나 변경 | 새 대화를 준비할 때의 기본 선택 | 아니요 |
| 작품 상세에서 페르소나 선택 후 새 대화 시작 | 새로 만든 대화방 | 기존 방에는 반영되지 않습니다 |
| 대화방에서 페르소나 불러오기 후 저장 | 지금 설정 중인 대화방 | 그 방에 직접 적용됩니다 |

## 8. 상세정보는 어떻게 쓰면 좋을까요?

캐릭터가 참고할 **나의 역할과 관계**를 짧고 구체적으로 적어 보세요. 여러 설정을 나열하기보다 이번 대화에 필요한 배경을 먼저 정하면 시작하기 쉽습니다.

**예시 — 마을에 처음 온 여행자**

> 이름은 하루. 성인인 지도 제작자이며 오래된 지도를 찾으러 마을에 왔다. 낯선 사람에게는 존댓말을 쓰고 조심스럽게 질문한다. 주인공과는 오늘 처음 만났으며, 먼저 마을 길을 안내해 달라고 부탁하려 한다.

이 예시는 역할의 배경, 말투, 관계, 첫 목표를 담고 있습니다. 원하는 전개가 달라졌다면 해당 방의 상세정보를 수정할 수 있습니다. 다만 페르소나는 AI가 참고하는 정보이므로 모든 응답이나 전개를 그대로 보장하지는 않습니다.

## 자주 막히는 상황

| 상황 | 확인할 내용 |
| --- | --- |
| 대표를 바꿨는데 기존 방에서는 옛 이름으로 불러요 | 그 방의 **페르소나 → 불러오기 → 선택 → 저장**까지 진행했는지 확인하세요 |
| 불러오기를 했는데 적용되지 않아요 | 입력란에 가져온 뒤 **저장**을 눌렀는지 확인하세요 |
| 작품 상세에서 바꿨는데 대화가 그대로예요 | **이전 대화 이어하기**를 눌렀는지 확인하세요. 새 역할로 처음부터 시작하려면 **새 대화 시작**을 선택합니다 |
| 추천 페르소나 탭이 없어요 | 제작자가 추천 역할을 등록하지 않은 작품일 수 있습니다. 내 페르소나를 선택하세요 |
| 기본 페르소나를 지울 수 없어요 | 기본 페르소나는 목록에서 삭제할 수 없습니다. 다른 페르소나를 추가하고 대표로 지정할 수 있습니다 |
| 생년월일을 저장할 수 없어요 | 연·월·일, 실제로 존재하는 날짜, 미래 날짜 여부, 만 14세 이상 조건을 확인하세요 |
| 페르소나 이름을 바꿨는데 제작자명이 그대로예요 | 제작자명에는 기본 프로필의 **닉네임**이 사용됩니다. [로그인·프로필 설정](/account/login-profile.md)에서 변경하세요 |
