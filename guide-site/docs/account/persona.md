# 페르소나 설정

페르소나는 **작품 속에서 내가 쓰는 이름과 역할**이에요. 같은 작품도 ‘기억을 잃은 생존자’와 ‘민우의 오랜 친구’처럼 다른 역할로 대화할 수 있어요. 페르소나는 대화에만 쓰여요. 작품의 제작자명과 공개 프로필에는 내 닉네임이 보여요.

:::tip[이미 대화 중인 채팅방의 역할을 바꾸려면]
채팅방 오른쪽 위 ⋮ 메뉴의 **채팅 설정 → 페르소나**에서 바꿔요. 순서는 [이미 대화 중인 채팅방에서 바꾸기](#이미-대화-중인-채팅방에서-바꾸기)에 있어요.
:::

## 기본·대표·추천은 무슨 뜻인가요?

| 구분 | 뜻 |
| --- | --- |
| **기본** | 가입할 때 정한 이름과 성별로 만들어져요. **내 정보 수정 → 내 정보**를 고치면 함께 바뀌고, 지울 수 없어요 |
| **대표** | 새 대화를 시작할 때 처음 골라져 있는 페르소나예요. 처음에는 기본 페르소나가 대표예요 |
| **추천 페르소나** | 제작자가 그 작품에 맞게 준비한 역할이에요. 작품 상세에서 골라요 |

**마이페이지 → 페르소나 설정**의 카드에 **기본**·**대표** 표시가 붙어 있어요. 한 카드에 둘 다 붙을 수도 있어요.

## 페르소나 만들기

1. **마이페이지 → 페르소나 설정**을 열어요.
2. **페르소나 추가**를 눌러요.
3. 아래 항목을 채우고 위쪽 **저장**을 눌러요.

| 항목 | 이렇게 써요 |
| --- | --- |
| **이름** | 캐릭터가 나를 부르는 이름이에요. 꼭 적어야 하고, 20자까지 써요 |
| **생년월일** | 적으려면 연·월·일을 모두 채워요. 만 14세 이상인 날짜만 저장돼요 |
| **성별** | **여성**·**남성** 중에서 골라요 |
| **상세정보** | 내 역할, 성격, 말투, 등장인물과의 관계를 1,000자까지 써요 |

이름만 적어도 저장돼요. 새로 만든 페르소나를 주로 쓸 거라면 [대표로 정하세요](#대표-페르소나-정하기).

### 상세정보 예시

> 이름은 하루. 스물다섯 살. 지하 도시 검역소에서 깨어났고, 지상에서 배달 일을 했다는 것만 기억난다. 낯선 사람에게는 존댓말을 쓰고 궁금한 건 바로 묻는다. 민우와는 오늘 처음 만났다.

역할, 말투, 등장인물과의 관계, 지금 하려는 일을 짧게 적으면 캐릭터가 알아듣기 쉬워요.

## 대표 페르소나 정하기

**마이페이지 → 페르소나 설정**에서 쓸 페르소나의 카드를 눌러요. 카드에 **대표** 표시가 붙으면, 다음에 새 대화를 시작할 때 이 페르소나가 골라져 있어요.

## 대화를 시작할 때 고르기

1. 작품 상세 화면 아래 **대화 시작하기** 오른쪽의 작은 프로필 아이콘을 눌러요.
2. **내 페르소나**나 **추천 페르소나** 탭에서 하나를 고르고 **선택 완료**를 눌러요.
3. **대화 시작하기**를 눌러요. 이미 대화한 작품이면 **새 대화 시작**을 눌러요.

고르는 창에서 카드의 연필 버튼으로 내용을 고칠 수도 있어요.

- **내 페르소나**를 고쳐 저장하면 내 목록의 그 페르소나가 바뀌어요.
- **추천 페르소나**를 고치면 이번 대화에만 쓰여요. 계속 쓰고 싶다면 내 페르소나로 따로 만들어 두세요.

**이전 대화 이어하기**를 누르면 그 채팅방에서 쓰던 페르소나로 이어져요.

## 이미 대화 중인 채팅방에서 바꾸기

목록에서 페르소나를 고치면 새로 시작하는 대화부터 바뀌어요. 이미 대화 중인 채팅방은 그 방에서 바꿔요.

1. 채팅방 오른쪽 위 ⋮ 버튼을 눌러요.
2. **채팅 설정**의 **페르소나**를 눌러요.
3. **페르소나 수정** 창에서 이름과 상세정보를 직접 고치거나, **불러오기**로 내 페르소나 하나를 골라요.
4. **저장**을 눌러요. 다음 답변부터 바뀐 페르소나로 대화해요.

대화 기록은 그대로 이어져요. 새 역할로 처음부터 하고 싶다면 작품 상세에서 페르소나를 고른 뒤 **새 대화 시작**을 눌러요.

## 고치기와 지우기

**마이페이지 → 페르소나 설정**에서 카드 오른쪽의 ⋮ 버튼을 눌러요.

- **수정**: 내용을 바꾸고 **저장**을 눌러요. 기본 페르소나의 **수정**은 **내 정보 수정** 화면을 열어요.
- **삭제**: 추가한 페르소나만 지울 수 있어요.

:::danger[삭제는 묻지 않고 바로 돼요]
**삭제**를 누르면 확인 창 없이 바로 지워지고, 되돌릴 수 없어요. 대표 페르소나를 지우면 기본 페르소나가 대표가 돼요. 그 페르소나로 대화하던 채팅방은 그대로 이어서 쓸 수 있어요.
:::

## 어디서 바꿔야 하나요?

| 바꾸고 싶은 것 | 바꾸는 곳 |
| --- | --- |
| 앞으로 시작할 대화에서 쓸 이름과 역할 | **페르소나 설정**에서 고치거나 대표로 정하기 |
| 지금 대화 중인 채팅방의 이름과 역할 | 채팅방 ⋮ 메뉴의 **채팅 설정 → 페르소나** |
| 이번에 시작할 대화에만 쓸 역할 | 대화를 시작하기 전 프로필 아이콘에서 고르기 |
| 가입할 때 정한 이름과 성별(기본 페르소나) | **내 정보 수정 → 내 정보** |

## 자주 막히는 곳

<details>
<summary>이름을 바꿨는데 캐릭터가 예전 이름으로 불러요</summary>

이미 대화 중인 채팅방은 그 방에서 바꿔야 해요. 채팅방 ⋮ 메뉴의 **채팅 설정 → 페르소나**에서 **불러오기**로 바꾼 페르소나를 골라 **저장**하세요.

</details>

<details>
<summary>새로 만든 페르소나로 대화가 시작되지 않아요</summary>

새로 만든 페르소나는 대표가 아니에요. 목록에서 그 카드를 눌러 대표로 정하거나, 대화를 시작할 때 프로필 아이콘을 눌러 고르세요.

</details>

<details>
<summary>생년월일을 넣었더니 저장되지 않아요</summary>

연·월·일을 모두 채웠는지, 실제로 있는 날짜인지 확인하세요. "만 14세 미만은 저장할 수 없습니다"가 뜨면 만 14세 이상인 날짜로 바꿔요. 생년월일은 비워 두고 저장해도 돼요.

</details>

<details>
<summary>기본 페르소나에 삭제가 없어요</summary>

기본 페르소나는 지울 수 없어요. **수정**을 누르면 **내 정보 수정**이 열리고, 거기서 이름과 상세 정보를 바꿀 수 있어요.

</details>

<details>
<summary>추천 페르소나 탭이 보이지 않아요</summary>

제작자가 추천 페르소나를 준비하지 않은 작품이에요. **내 페르소나**에서 고르세요.

</details>

<details>
<summary>페르소나를 실수로 지웠어요</summary>

지운 페르소나는 되돌릴 수 없어요. 같은 내용으로 다시 만들어 주세요. 그 페르소나로 대화하던 채팅방은 그대로 남아 있어요.

</details>

그래도 해결되지 않으면 [문의하기](/faq/faq.md#문의하기)로 알려 주세요.
