# 로그인·프로필 설정

**마이페이지**에서 로그인하고 내 정보를 관리할 수 있습니다. 프로필을 바꿀 때는 먼저 **대화에 사용할 정보**와 **다른 이용자에게 보여 줄 정보**를 구분해 주세요.

## 1. 기존 계정으로 로그인하기

1. [MYMI 웹사이트](https://www.mymi.live) 또는 MYMI 앱을 엽니다.
2. 하단 **마이페이지**를 선택합니다. 로그인하지 않은 상태라면 소셜 로그인 버튼이 표시됩니다.
3. 처음 가입할 때 사용한 로그인 방식과 소셜 계정을 선택합니다.
4. 로그인 후 상단의 닉네임과 `@아이디`가 내 계정인지 확인합니다.

웹과 앱에서도 같은 MYMI 계정을 이용할 수 있습니다. 예를 들어 Google로 가입했다면 같은 Google 계정을 선택하세요. MYMI 아이디를 입력해 로그인하거나 MYMI용 비밀번호를 따로 만들지는 않습니다.

로그인 버튼은 웹사이트의 언어와 이용 환경에 따라 달라집니다. 지원하는 로그인 방식은 [회원가입 안내](/account/sign-up.md)에서 확인할 수 있습니다.

> **이미 가입했는데 회원가입 화면이 나오나요?**
>
> 기본 정보를 다시 입력하기 전에 로그인 방식과 소셜 계정을 확인하세요. Google 계정이 여러 개라면 다른 계정을 선택했을 수 있습니다. Apple로 가입했는데 Android 앱에 버튼이 없다면 모바일 웹에서 Apple 로그인을 이용할 수 있습니다.

## 2. 바꾸려는 항목 찾기

마이페이지 상단에서 **프로필 이미지·닉네임·아이디가 있는 영역**을 누르면 **내 정보 수정** 화면이 열립니다. 이 화면에는 **내 정보**와 **크리에이터** 두 탭이 있습니다.

| 바꾸려는 내용 | 이동할 곳 |
| --- | --- |
| 이름, 성별, 생년월일, 상세 정보 | 내 정보 수정 → **내 정보** |
| 다른 사람에게 보이는 닉네임과 `@아이디` | 내 정보 수정 → **내 정보** |
| 프로필 이미지, 웹사이트, 공개 소개 | 내 정보 수정 → **크리에이터 → 프로필 수정** |
| 작품 속에서 사용할 다른 이름이나 역할 | 마이페이지 → **페르소나 설정** |

프로필 이미지 변경은 **크리에이터** 탭에서 진행합니다. 작품을 만들지 않은 이용자도 이곳에서 공개 프로필을 수정할 수 있습니다.

## 3. 내 정보 수정하기

**내 정보** 탭에서 원하는 항목을 수정한 뒤, 탭 상단의 **변경사항 저장**을 누릅니다. 입력만 하고 화면을 나가면 저장되지 않습니다.

| 항목 | 용도와 확인할 점 |
| --- | --- |
| 이름 | 기본 페르소나가 대화에서 사용하는 이름입니다 |
| 성별 | 기본 페르소나에 반영됩니다. 본인인증이 완료된 계정은 수정할 수 없습니다 |
| 닉네임 | 다른 이용자에게 표시되는 이름이며, 제작자명에도 사용됩니다 |
| 아이디 | `@moon_reader`처럼 계정을 구분하며, 공개 프로필 주소에도 사용됩니다 |
| 생년월일 | 기본 페르소나에 반영됩니다. 본인인증이 완료된 계정은 수정할 수 없습니다 |
| 상세 정보 | 캐릭터가 대화에서 참고할 기본 페르소나의 정보입니다. **1,000자 이내**로 입력합니다 |

예를 들어 **이름**을 `하루`, **닉네임**을 `달빛독자`로 설정하면 기본 페르소나는 ‘하루’라는 이름을 사용하고, 다른 이용자는 ‘달빛독자’라는 닉네임을 보게 됩니다.

### 아이디를 변경할 때

아이디는 **3~20자**이며 영문 소문자, 숫자, 밑줄(`_`), 하이픈(`-`)을 사용할 수 있습니다. 밑줄·하이픈으로 시작하거나 끝날 수 없고, 두 문자를 섞은 경우를 포함해 연속으로 사용할 수 없습니다.

입력하면 자동으로 중복을 확인합니다. **사용 가능** 표시를 확인한 후 저장하세요. 중복 확인에 실패하면 입력 칸 옆의 **확인** 버튼으로 다시 시도할 수 있습니다. 아이디를 바꿨다면 이전에 공유한 프로필 링크도 확인해 주세요.

### 상세 정보와 페르소나의 관계

내 정보에서 이름·성별·생년월일·상세 정보를 저장하면 **기본 페르소나**에도 반영됩니다. 별도로 만든 다른 페르소나의 설정까지 함께 바뀌지는 않습니다.

예를 들어 기본 이름을 바꿨는데도 다른 이름으로 대화한다면, 사용 중인 페르소나가 무엇인지 확인하세요. 작품마다 다른 역할로 대화하고 싶다면 [페르소나 설정](/account/persona.md)을 이용합니다.

## 4. 프로필 이미지와 공개 소개 바꾸기

1. **마이페이지 → 상단 프로필 영역 → 크리에이터** 탭으로 이동합니다.
2. **프로필 수정**을 누릅니다.
3. 아래 항목을 수정합니다.
4. 이미지를 선택했다면 업로드가 끝날 때까지 기다린 뒤 **저장**을 누릅니다.
5. 저장 후 크리에이터 탭에서 변경된 이미지와 소개를 확인합니다.

| 항목 | 설정 방법 |
| --- | --- |
| 프로필 이미지 | 이미지 영역의 **추가하기** 또는 **변경하기**를 눌러 기기의 이미지를 선택합니다 |
| 웹사이트 | 다른 이용자에게 보여 줄 웹사이트 주소를 입력합니다 |
| 소개 | 공개 프로필에 표시할 자기소개나 창작 활동 소개를 **10,000자 이내**로 작성합니다 |

이미지를 고른 것만으로 프로필 저장이 끝나지는 않습니다. 업로드 후 **저장**까지 눌러 주세요. 앱에서 사진 접근 권한을 요청하면 사용할 사진에 접근할 수 있도록 허용해야 합니다.

**크리에이터** 탭에서는 자신의 공개 소개, 공지·댓글, 작품 목록도 확인할 수 있습니다. 제작 중인 작품을 이어서 수정하려면 마이페이지의 **작품 관리**로 이동합니다.

### 다른 사람에게 보이는 정보

공개 크리에이터 프로필에는 **닉네임, 아이디, 프로필 이미지, 웹사이트, 소개** 등이 표시됩니다. **내 정보의 상세 정보**는 이 공개 소개란에 표시되지 않으며, 기본 페르소나가 대화에서 참고할 정보로 사용됩니다.

예를 들어 캐릭터가 기억했으면 하는 설정은 **상세 정보 또는 페르소나**에, 독자에게 전할 자기소개는 **크리에이터 → 프로필 수정 → 소개**에 작성하세요.

## 5. 마이페이지에서 이어서 할 수 있는 일

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| 내 스파크 | 보유 스파크와 만료 예정 수량 확인, 충전 및 사용내역 보기 |
| 작품 관리 | 제작한 작품의 상태 확인과 편집 |
| 차단 관리 | 차단한 작품·크리에이터 확인과 차단 해제 |
| 페르소나 설정 | 대화에 사용할 역할 추가·수정·선택 |
| 내 활동 | 팔로우한 크리에이터와 내가 작성한 댓글 확인 |
| 출석 체크 | 출석 상태와 보상 확인 |

민감한 콘텐츠 관련 설정은 [성인인증 안내](/account/adult-verification.md)를 참고하세요. 표시되는 메뉴와 이용 조건은 이용 환경이나 계정 상태에 따라 달라질 수 있습니다.

## 6. 로그아웃하기

**마이페이지 → 설정 및 지원 → 로그아웃**을 누릅니다. 다시 이용할 때는 가입했던 소셜 계정으로 로그인하세요.

로그아웃은 현재 기기의 로그인 상태를 종료하는 기능입니다. 계정을 삭제하려는 경우에는 별도 절차인 [회원탈퇴](/account/delete-account.md)를 확인하세요.

## 원하는 대로 바뀌지 않을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 변경사항 저장 버튼을 누를 수 없어요 | 변경한 항목이 있는지, 필수 항목에 빈칸이나 오류가 없는지, 변경한 아이디가 사용 가능한지 확인합니다 |
| 아이디가 ‘확인 중’이거나 오류가 나와요 | 확인이 끝날 때까지 기다립니다. 실패했다면 인터넷 연결을 확인하고 ‘확인’ 버튼으로 다시 시도합니다 |
| 성별이나 생년월일을 수정할 수 없어요 | 본인인증이 완료된 계정에서는 이 항목을 수정할 수 없습니다 |
| 내 정보에 프로필 이미지 변경 버튼이 없어요 | 크리에이터 탭의 ‘프로필 수정’에서 변경합니다 |
| 사진을 선택했는데 프로필에 반영되지 않아요 | 업로드 오류나 권한 안내를 확인하고, 업로드가 끝난 뒤 ‘저장’까지 눌렀는지 확인합니다 |
| 상세 정보를 바꿨는데 공개 소개가 그대로예요 | 공개 소개는 크리에이터 탭의 ‘프로필 수정 → 소개’에서 별도로 수정합니다 |
| 이름을 바꿨는데 대화에서는 다른 이름을 사용해요 | 사용 중인 페르소나를 확인합니다. 내 정보 변경은 기본 페르소나에 반영됩니다 |
| 저장 오류가 나거나 수정한 내용이 사라져요 | 인터넷 연결을 확인하고 화면을 다시 열어 저장된 값을 확인합니다. 문제가 계속되면 오류 메시지와 이용 환경을 함께 적어 문의해 주세요 |
