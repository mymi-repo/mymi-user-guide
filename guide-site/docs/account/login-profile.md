# 로그인·프로필 설정

가입한 계정으로 다시 로그인하고, 내 정보와 프로필 사진을 바꾸고, 로그아웃하는 방법이에요.

## 로그인하기

1. 하단 **마이페이지**를 눌러요. 웹은 홈 오른쪽 위 **로그인**을 눌러도 돼요.
2. 가입할 때 쓴 소셜 계정의 버튼(**카카오로 계속하기**, **Google로 계속하기**, **Apple로 계속하기**)을 누르고 로그인을 마쳐요.
3. 웹은 로그인이 끝나면 홈으로 가요. **마이페이지** 맨 위의 닉네임과 `@아이디`로 내 계정이 맞는지 확인하세요.

:::warning[가입한 소셜 계정으로 로그인하세요]
소셜 계정마다 MYMI 계정이 따로 있어요. 다른 소셜 계정으로 로그인하면 **회원가입** 화면이 나와요. 여기서 가입하면 대화와 스파크가 없는 새 계정이 만들어지니, 뒤로 가서 처음 가입한 소셜 계정으로 로그인하세요.
:::

## 바꾸려는 항목 찾기

**마이페이지** 맨 위 프로필 사진과 닉네임이 있는 줄을 누르면 **내 정보 수정**이 열려요. 여기에 **내 정보**와 **크리에이터** 탭이 있어요.

| 바꾸려는 것 | 가는 곳 |
| --- | --- |
| 캐릭터가 부르는 이름, 성별, 생년월일, 상세 정보 | **내 정보 수정 → 내 정보** |
| 닉네임, `@아이디` | **내 정보 수정 → 내 정보** |
| 프로필 사진, 웹사이트, 공개 소개 | **내 정보 수정 → 크리에이터 → 프로필 수정** |
| 작품마다 다른 이름이나 역할 | **마이페이지 → 페르소나 설정** |
| 화면 언어 | **마이페이지** 맨 아래 **언어 설정** |

## 이름·닉네임·아이디 바꾸기

1. **내 정보 수정**의 **내 정보** 탭을 열어요.
2. 고칠 항목을 바꿔요.
3. 위쪽의 **변경사항 저장**을 눌러요. 이 버튼을 눌러야 고친 내용이 저장돼요.

| 항목 | 어디에 쓰이나요 |
| --- | --- |
| **이름** | 캐릭터가 나를 이렇게 불러요 |
| **성별**, **생년월일** | 캐릭터가 참고하는 내 정보예요. 본인인증을 마치면 바꿀 수 없어요 |
| **닉네임** | 다른 이용자에게 보이는 이름이자 작품의 제작자명이에요 |
| **아이디** | `@아이디`예요. 공개 프로필 주소에 쓰여요 |
| **상세 정보** | 캐릭터가 대화에서 참고할 내 정보예요. 1,000자까지 써요 |

아이디 규칙은 [회원가입](/account/sign-up.md#아이디-규칙)과 같아요. 입력하면 바로 중복을 확인하니, **사용 가능**이 보인 뒤에 저장하세요. 아이디를 바꾸면 공개 프로필 주소도 바뀌어요. 예전에 공유한 프로필 링크가 있다면 새 주소로 다시 공유하세요.

## 프로필 사진과 공개 소개 바꾸기

1. **내 정보 수정**에서 **크리에이터** 탭을 눌러요.
2. **프로필 수정**을 눌러요.
3. 프로필 사진 자리를 눌러 기기에서 사진을 골라요. 업로드가 끝날 때까지 기다려요.
4. 필요하면 **웹사이트**와 **소개**(10,000자까지)를 고쳐요.
5. **저장**을 눌러요.

작품을 만들지 않았어도 공개 프로필을 고칠 수 있어요. 공개 프로필에는 닉네임, 아이디, 프로필 사진, 웹사이트, 소개가 보여요. **내 정보**의 상세 정보는 대화에만 쓰여요.

:::tip[마이페이지의 크리에이터 버튼과는 달라요]
**마이페이지** 첫 화면에서 **내 스파크** 아래에 있는 **크리에이터** 버튼은 크리에이터 지원과 대시보드를 열어요. 프로필 사진은 **내 정보 수정** 안의 **크리에이터** 탭에서 바꿔요.
:::

## 화면 언어 바꾸기

**마이페이지** 맨 아래 **언어 설정**을 누르고 **한국어**·**日本語**·**English**·**繁體中文** 중에서 골라 **확인**을 눌러요.

언어를 바꾸면 화면 글자가 바뀌어요. 본인인증 방식은 가입할 때 정해진 그대로예요.

## 로그아웃하기

**마이페이지 → 설정 및 지원 → 로그아웃**을 눌러요. 다시 쓸 때는 가입한 소셜 계정으로 로그인하세요. 계정을 아예 없애려면 [계정 탈퇴](/account/delete-account.md)를 보세요.

## 마이페이지에서 메뉴 찾기

| 이럴 때 | 여는 메뉴 |
| --- | --- |
| 남은 스파크와 사라질 날짜를 보거나 충전하고 싶어요 | **내 스파크** |
| 크리에이터 지원 조건과 진행 상황을 보고 싶어요 | **크리에이터** |
| 만들던 작품을 이어서 고치고 싶어요 | **작품 관리** |
| 차단한 작품이나 작가를 다시 보고 싶어요 | **차단 관리** |
| 작품마다 다른 이름과 역할로 대화하고 싶어요 | **페르소나 설정** |
| 팔로우한 크리에이터나 내가 쓴 댓글을 보고 싶어요 | **내 활동** |
| 매일 무료 스파크를 받고 싶어요 | **출석 체크** |
| 친구를 초대하거나 받은 추천 코드를 넣고 싶어요 | **친구 초대** |
| 소식을 보거나 문의하고 싶어요 | **디스코드** |
| 민감한 콘텐츠로 분류된 작품도 보고 싶어요 | **설정 및 지원 → 민감한 콘텐츠 표시**. [성인·본인인증](/account/adult-verification.md) 참고 |
| 앱에서 문의할 때 이용 환경을 보내고 싶어요 | **설정 및 지원 → 버전 정보 → 문의 정보 복사** |

## 자주 막히는 곳

<details>
<summary>카카오 로그인 버튼이 보이지 않아요</summary>

웹은 화면 언어가 한국어일 때만 카카오 버튼이 나와요. 로그인 버튼 아래의 언어 링크(Language Settings, 言語設定, 語言設定)를 눌러 **한국어**로 바꾸세요. 앱에는 언어와 관계없이 카카오 버튼이 있어요.

</details>

<details>
<summary>로그인했더니 회원가입 화면이 나와요</summary>

처음 가입할 때와 다른 소셜 계정으로 로그인했어요. 가입하지 말고 뒤로 가서 처음 가입한 소셜 계정으로 로그인하세요. Google 계정이 여러 개라면 MYMI에 가입한 Google 계정을 골랐는지 확인하세요.

</details>

<details>
<summary>예전 대화와 스파크가 보이지 않아요</summary>

다른 소셜 계정으로 로그인해 새 계정이 만들어졌을 수 있어요. **마이페이지 → 설정 및 지원 → 로그아웃**을 누른 뒤 처음 가입한 소셜 계정으로 다시 로그인하세요.

</details>

<details>
<summary>Apple로 가입했는데 Android 앱에 Apple 버튼이 없어요</summary>

Android 앱에는 Apple 로그인이 없어요. Chrome으로 [www.mymi.live](https://www.mymi.live)를 열고 **Apple로 계속하기**로 로그인하세요.

</details>

<details>
<summary>변경사항 저장이 눌리지 않아요</summary>

고친 항목이 없거나 입력에 오류가 있어요. 칸 아래의 안내 문구를 보고 고치세요. 아이디를 바꿨다면 **사용 가능**이 보이는지 확인하세요.

</details>

<details>
<summary>성별이나 생년월일을 바꿀 수 없어요</summary>

본인인증을 마친 계정은 성별과 생년월일을 바꿀 수 없어요. 작품마다 다른 설정으로 대화하고 싶다면 [페르소나 설정](/account/persona.md)에서 페르소나를 만들어 쓰세요. 페르소나마다 성별과 생년월일을 따로 정할 수 있어요.

</details>

<details>
<summary>이름을 바꿨는데 캐릭터가 예전 이름으로 불러요</summary>

바꾼 이름은 새로 시작하는 대화부터 쓰여요. 이미 대화 중인 채팅방에서는 오른쪽 위 ⋮ 메뉴의 **채팅 설정 → 페르소나**에서 **불러오기**로 기본 페르소나를 골라 **저장**하세요.

</details>

<details>
<summary>프로필 사진이 바뀌지 않아요</summary>

사진을 고른 뒤 업로드가 끝나고 **저장**까지 눌러야 바뀌어요. 앱이 사진 접근 권한을 물으면 허용하세요.

</details>

그래도 해결되지 않으면 [문의하기](/faq/faq.md#문의하기)로 알려 주세요.
