# 회원가입

카카오·Google·Apple 중 한 계정으로 로그인한 뒤 이름·아이디·닉네임을 정하면 가입이 끝나요. MYMI는 만 14세 이상이 이용할 수 있는 서비스예요.

:::warning[가입하기 전에 화면이 한국어인지 확인하세요]
한국어가 아닌 화면에서 가입하면 한국 휴대폰으로 본인인증을 할 수 없어요. 그러면 출석 체크처럼 본인인증이 필요한 기능을 쓸 수 없고, 가입한 뒤에는 바꿀 수 없어요.

화면이 한국어가 아니라면 이렇게 바꾼 뒤 가입하세요.

1. 하단 메뉴 맨 오른쪽(마이페이지)을 눌러요.
2. 로그인 버튼 아래의 언어 링크(Language Settings, 言語設定, 語言設定)를 눌러요.
3. **한국어**를 고르고 확인(Confirm, 確認)을 눌러요.
:::

## 로그인 버튼 고르기

1. [MYMI 웹사이트](https://www.mymi.live)나 MYMI 앱을 열고 하단 **마이페이지**를 눌러요. 대화하다가 뜨는 로그인 창에서 시작해도 돼요.
2. 가입할 소셜 계정의 버튼을 눌러요. 이용 환경마다 보이는 버튼은 아래 표와 같아요.
3. 그 서비스의 로그인을 마치면 MYMI **회원가입** 화면이 열려요.

| 이용 환경 | 로그인 버튼 |
| --- | --- |
| PC·모바일 웹 | **카카오로 계속하기**, **Google로 계속하기**, **Apple로 계속하기** |
| Android 앱 | **카카오로 계속하기**, **Google로 계속하기** |
| iPhone 앱 | **Apple로 계속하기**, **카카오로 계속하기**, **Google로 계속하기** |

:::tip[어느 소셜 계정으로 가입할지 먼저 정하세요]
소셜 계정마다 MYMI 계정이 따로 만들어져요. 다음부터는 가입한 소셜 계정으로 로그인해야 대화와 스파크가 이어져요. Android 앱에는 Apple 로그인이 없으니, Android 휴대폰에서도 앱을 쓸 생각이라면 카카오나 Google로 가입하세요.
:::

## 이름·아이디·닉네임 정하기

| 항목 | 어디에 쓰이나요 | 입력 |
| --- | --- | --- |
| **이름** | 캐릭터가 나를 부르는 이름이에요 | 20자까지 |
| **성별** | 캐릭터가 참고하는 내 성별이에요 | **여성**·**남성**·**기타** 중 하나 |
| **아이디** | `@moon_reader`처럼 나를 구분하는 주소예요 | 3~20자. 아래 규칙을 따라요 |
| **닉네임** | 다른 이용자에게 보이는 이름이에요 | 30자까지 |

예를 들어 이름을 `하루`, 닉네임을 `달빛독자`로 정하면 캐릭터는 나를 ‘하루’라고 부르고, 다른 이용자에게는 ‘달빛독자’로 보여요. 작품마다 다른 이름으로 대화하고 싶다면 가입한 뒤 [페르소나 설정](/account/persona.md)에서 더 만들 수 있어요. 이름·아이디·닉네임은 가입한 뒤에도 [로그인·프로필 설정](/account/login-profile.md)에서 바꿀 수 있어요.

앱에서는 소셜 계정의 이름이 **이름** 칸에 미리 들어가 있을 수 있어요. 대화에서 불리고 싶은 이름으로 고쳐도 돼요.

### 아이디 규칙

- 영문 소문자, 숫자, 밑줄(`_`), 하이픈(`-`)만 쓸 수 있어요. 대문자는 소문자로 바뀌고, 그 밖의 글자는 입력되지 않아요.
- 3~20자로 써요.
- `_`나 `-`로 시작하거나 끝날 수 없어요.
- `_`와 `-`는 이어 쓸 수 없어요. `__`, `--`, `_-` 모두 안 돼요.

| 예 | 결과 |
| --- | --- |
| `moon_reader`, `reader-123` | 쓸 수 있어요 |
| `ab` | 3자보다 짧아요 |
| `_reader`, `reader-` | `_`나 `-`로 시작하거나 끝나요 |
| `moon__reader`, `moon-_reader` | `_`와 `-`를 이어 썼어요 |

아이디를 입력하면 칸 오른쪽에 바로 결과가 떠요. **사용 가능**이 보이면 다음으로 넘어가요. **사용 불가**면 다른 사람이 쓰는 아이디이니 다른 아이디로 바꾸고, **형식 오류**면 위 규칙을 다시 확인하세요.

## 약관에 동의하기

| 항목 | 필수 여부 |
| --- | --- |
| **이용약관 동의** | 필수 |
| **개인정보 수집 및 이용 동의** | 필수 |
| **서비스 유의사항** | 필수 |
| **마케팅 정보 수신 동의** | 선택 |

- 동의는 항목 **왼쪽의 네모 칸**을 눌러 체크해요. 항목 이름을 누르면 약관 전문이 열려요.
- **전체 동의**를 누르면 선택 항목인 마케팅 정보 수신 동의까지 체크돼요. 받고 싶지 않으면 그 칸만 다시 눌러 해제하세요.

## 가입 완료하기

화면 아래 버튼은 조건을 다 채우기 전까지 회색 화살표로 보여요. 네 항목을 채우고, 아이디가 **사용 가능**이고, 필수 동의 세 개를 체크하면 버튼이 **회원가입 완료**로 바뀌어요. 누르면 가입이 끝나고 홈으로 가요.

대화하려면 스파크가 필요해요. 본인인증을 마치면 **마이페이지 → 출석 체크**에서 매일 무료로 받을 수 있어요. 방법은 [성인·본인인증](/account/adult-verification.md)과 [스파크 충전하기](/payment/payment-methods.md#출석-체크)에 있어요.

## 자주 막히는 곳

<details>
<summary>회원가입 완료 버튼이 회색 화살표로만 보여요</summary>

아직 채우지 않은 조건이 있어요.

- 이름·성별·아이디·닉네임을 모두 입력했나요?
- 아이디 칸 오른쪽에 **사용 가능**이 보이나요?
- 필수 동의 세 항목을 체크했나요? 항목 이름이 아니라 왼쪽 네모 칸을 눌러야 체크돼요.

</details>

<details>
<summary>약관 항목을 눌렀더니 약관 페이지가 열려요</summary>

항목 이름을 누르면 전문이 열려요. 다 읽었으면 가입 화면으로 돌아와 이름 왼쪽의 네모 칸을 눌러 체크하세요.

</details>

<details>
<summary>"이미 사용 중인 아이디입니다"라고 나와요</summary>

다른 사람이 쓰는 아이디예요. 숫자나 `_`를 붙여 다른 아이디로 바꿔 보세요.

</details>

<details>
<summary>"중복 확인 중 오류가 발생했습니다"라고 나와요</summary>

인터넷 연결을 확인하고 아이디 칸 오른쪽의 **확인**을 눌러 다시 확인하세요.

</details>

<details>
<summary>"재가입 제한"이라며 "탈퇴 후 30일 동안 재가입할 수 없습니다"가 떠요</summary>

이 소셜 계정으로 만든 MYMI 계정을 탈퇴한 지 30일이 지나지 않았어요. 30일이 지나면 같은 소셜 계정으로 다시 가입할 수 있고, 새 계정으로 시작해요. 다른 소셜 계정으로는 지금 가입할 수 있지만, 탈퇴한 계정에서 쓴 본인인증 정보는 탈퇴하고 30일이 지나야 다시 쓸 수 있어요.

</details>

<details>
<summary>"회원가입 중 문제가 발생했습니다" 또는 "로그인 중 문제가 발생했습니다"가 떠요</summary>

**다시 시도해주세요!** 버튼을 누르면 홈으로 돌아가요. 처음부터 다시 로그인해 보세요. 카카오톡·인스타그램 같은 앱 안에서 열었다면 Chrome이나 Safari에서 [www.mymi.live](https://www.mymi.live)를 열고 다시 해 보세요.

</details>

<details>
<summary>이미 가입했는데 회원가입 화면이 나와요</summary>

처음 가입할 때와 다른 소셜 계정으로 로그인했어요. 여기서 가입하면 새 계정이 만들어지니, 뒤로 가서 처음 가입한 소셜 계정으로 로그인하세요. Google 계정이 여러 개라면 MYMI에 가입한 Google 계정을 골랐는지 확인하세요.

</details>

<details>
<summary>Apple로 가입했는데 Android 앱에서 로그인할 수 없어요</summary>

Android 앱에는 Apple 로그인이 없어요. Android 휴대폰에서는 Chrome으로 [www.mymi.live](https://www.mymi.live)를 열고 **Apple로 계속하기**로 로그인하세요.

</details>

그래도 해결되지 않으면 화면에 뜬 문구와 함께 [문의하기](/faq/faq.md#문의하기)로 알려 주세요.
