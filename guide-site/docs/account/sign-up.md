# 회원가입

MYMI는 **소셜 계정으로 로그인한 뒤 기본 정보를 입력하는 방식**으로 가입합니다. MYMI에서 사용할 비밀번호를 따로 만들 필요는 없습니다.

이미 가입했다면 처음 사용한 로그인 방식과 계정을 선택하세요. 웹에서 가입한 계정으로 앱을 이용할 때도 같은 계정으로 로그인하면 됩니다.

## 1. 소셜 계정 선택하기

1. [MYMI 웹사이트](https://www.mymi.live) 또는 MYMI 앱을 엽니다.
2. 하단 **마이페이지**에서 로그인 화면을 엽니다. 서비스를 이용하다가 표시되는 로그인 안내에서도 시작할 수 있습니다.
3. 사용할 소셜 계정을 선택하고 해당 서비스의 로그인을 진행합니다.
4. 처음 가입하는 계정이라면 MYMI 회원가입 화면으로 이어집니다.

한국어 화면에서 선택할 수 있는 로그인 방식은 다음과 같습니다.

| 이용 환경 | 로그인 방식 |
| --- | --- |
| PC·모바일 웹 | 카카오, Google, Apple |
| Android 앱 | 카카오, Google |
| iOS 앱 | Apple, 카카오, Google |

웹사이트의 언어를 바꾸면 표시되는 로그인 방식도 달라질 수 있습니다. 화면에 표시되는 버튼 중에서 선택하세요.

> **기존 계정으로 이어서 이용하려면**
>
> 기존 계정이 있는데 회원가입 화면이 나온다면, 처음 가입할 때와 같은 로그인 방식·소셜 계정을 선택했는지 확인하세요. 예를 들어 Google 계정이 여러 개라면 MYMI에 가입했던 Google 계정을 골라야 합니다.

## 2. 기본 정보 입력하기

회원가입 화면의 아래 네 항목을 채웁니다. 이름이나 다른 항목에 값이 미리 들어 있다면 사용할 내용인지 확인하세요.

| 항목 | 어디에 쓰이나요? | 입력 기준 |
| --- | --- | --- |
| 이름 | 작품 속 인물이 나를 부르는 이름입니다. 가입 후 만들어지는 기본 페르소나에 사용됩니다 | 20자 이내 |
| 성별 | 기본 페르소나에 사용할 성별입니다 | 여성·남성·기타 중 선택 |
| 아이디 | `@moon_reader`처럼 계정을 구분하는 아이디입니다 | 3~20자, 형식 및 중복 확인 필요 |
| 닉네임 | 다른 이용자에게 표시되는 이름입니다 | 30자 이내 |

예를 들어 이름은 `하루`, 아이디는 `moon_reader`, 닉네임은 `달빛독자`로 정할 수 있습니다. 작품 속에서는 ‘하루’라는 이름으로 대화하고, 다른 이용자에게는 ‘달빛독자’라는 닉네임을 사용합니다.

아이디는 소셜 로그인을 대신하는 로그인 정보가 아닙니다. 다음에 접속할 때도 가입한 소셜 계정으로 로그인합니다.

현재 회원가입 화면에서는 생년월일을 입력하지 않습니다. 본인인증이나 성인 확인이 필요한 기능은 가입 후 해당 기능의 안내에 따라 별도로 진행합니다.

### 아이디 작성 규칙

- 영문 소문자, 숫자, 하이픈(`-`), 밑줄(`_`)을 사용할 수 있습니다.
- 길이는 **3~20자**입니다.
- 하이픈이나 밑줄로 시작하거나 끝날 수 없습니다.
- 하이픈과 밑줄을 두 개 이상 연속으로 사용할 수 없습니다. 서로 섞어서 연속으로 쓰는 것도 불가능합니다.
- 다른 이용자가 사용 중인 아이디는 사용할 수 없습니다.

| 입력 예시 | 형식 확인 |
| --- | --- |
| `moon_reader`, `reader-123` | 사용 가능한 형식입니다. 실제 사용 가능 여부는 중복 확인이 필요합니다 |
| `ab` | 3자보다 짧습니다 |
| `_reader`, `reader-` | 밑줄이나 하이픈으로 시작하거나 끝납니다 |
| `moon__reader`, `moon-_reader` | 밑줄·하이픈이 연속으로 들어갑니다 |

아이디를 입력하면 자동으로 중복을 확인합니다. **사용 가능** 표시를 확인한 뒤 다음으로 진행하세요. 확인이 실패했다면 입력 칸 옆의 **확인** 버튼으로 다시 확인할 수 있습니다.

## 3. 약관 확인하기

각 항목의 내용을 읽고 동의 여부를 선택합니다.

| 항목 | 가입에 필요한가요? |
| --- | --- |
| 이용약관 동의 | 필수 |
| 개인정보 수집 및 이용 동의 | 필수 |
| 서비스 유의사항 | 필수 |
| 마케팅 정보 수신 동의 | 선택 |

**마케팅 정보 수신에 동의하지 않아도 가입할 수 있습니다.** 전체 동의를 선택하면 이 선택 항목도 함께 체크되므로, 원하는 동의 상태인지 확인하세요.

## 4. 회원가입 완료하기

이름·성별·아이디·닉네임을 입력하고, 아이디가 사용 가능한 상태이며 필수 동의 세 항목을 체크하면 **회원가입 완료** 버튼을 누를 수 있습니다.

가입이 완료되면 입력한 이름과 성별을 바탕으로 기본 페르소나가 만들어집니다. 홈에서 작품을 골라 대화를 시작하거나, [페르소나 설정](persona.md)에서 작품 속 역할을 더 자세히 정해 보세요.

## 가입이 안 될 때

| 상황 | 확인할 내용 |
| --- | --- |
| 회원가입 완료 버튼을 누를 수 없어요 | 이름·성별·아이디·닉네임을 모두 입력했는지, 아이디가 ‘사용 가능’인지, 필수 동의 세 항목을 체크했는지 확인합니다 |
| 아이디에 형식 오류가 나와요 | 길이, 시작·끝 문자, 하이픈·밑줄의 연속 사용 여부를 확인합니다 |
| 아이디가 이미 사용 중이라고 나와요 | 다른 아이디로 바꾸고 다시 중복 확인을 합니다 |
| 아이디 중복 확인 중 오류가 나와요 | 인터넷 연결을 확인한 뒤 ‘확인’ 버튼으로 다시 시도합니다 |
| 소셜 로그인 뒤 오류가 나거나 가입 화면으로 돌아오지 않아요 | 로그인 화면으로 돌아가 다시 시작합니다. 다른 앱 안에서 웹사이트를 열었다면 외부 브라우저로 접속해 봅니다 |
| Apple로 가입했는데 Android 앱에서 버튼을 찾을 수 없어요 | 모바일 웹에서 Apple 로그인을 이용할 수 있습니다 |
| 이미 가입했는데 다시 기본 정보를 입력하라고 나와요 | 기존에 사용한 로그인 방식과 소셜 계정이 맞는지 확인합니다 |

접속 환경에 관한 문제는 [MYMI 접속 방법](../getting-started/how-to-access.md)을 참고하세요. 문제가 계속되면 발생한 오류 메시지와 이용 환경을 함께 적어 문의해 주세요.
