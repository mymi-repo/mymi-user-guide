# 성인·본인인증

MYMI의 **본인·휴대폰 인증**과 **성인 확인**은 목적이 다릅니다. 이용하려는 기능에서 인증 안내가 나오면, 해당 화면에 맞는 절차를 진행하세요.

| 구분 | 무엇을 확인하나요? | 안내가 나오는 경우 |
| --- | --- | --- |
| 본인·휴대폰 인증 | 본인 정보 또는 휴대폰 번호의 사용 여부 | 출석 체크, 친구 초대 등 인증이 필요한 기능을 이용할 때 |
| 성인 확인 | 계정에 적용되는 성인 콘텐츠 이용 조건을 충족하는지 | 세이프티 필터를 해제하거나 민감한 콘텐츠 표시를 켤 때 |

한국 본인인증에서는 인증된 생년월일을 바탕으로 성인 여부도 확인합니다. 해외 휴대폰 번호 인증과 성인 자기확인은 별도 절차입니다. **문자 인증을 마쳤다고 성인 확인까지 완료되는 것은 아닙니다.**

## 1. 내 계정에 맞는 인증 방식 확인하기

인증 방식은 계정에 적용된 정책과 기존 인증 이력에 따라 결정됩니다. **화면 언어를 바꿔도 계정의 인증 정책은 바뀌지 않습니다.** 일본어 화면을 보고 있어도 기존 계정에 한국 본인인증이 안내될 수 있습니다.

현재 제공하는 기본 절차는 다음과 같습니다. 실제로 열린 인증 화면의 안내를 따라 주세요.

| 계정에 적용되는 인증 정책 | 본인·휴대폰 확인 | 성인 확인 |
| --- | --- | --- |
| 한국 | PortOne을 통한 휴대폰 본인인증 | 본인인증으로 확인된 생년월일을 바탕으로 판정 |
| 일본·대만·영어 서비스 | 지원하는 휴대폰 번호로 문자 인증 | 화면에 표시된 연령 이상임을 직접 확인하는 자기확인 |

여행 중인 국가나 지금 보는 언어만으로 인증 방식을 선택하는 것은 아닙니다. 예상과 다른 화면이 나오거나 계정 국가 관련 오류가 발생하면 [아래 문의 안내](#도움이-필요할-때)를 참고하세요.

## 2. 인증은 어디서 시작하나요?

먼저 MYMI에 [로그인](/account/login-profile.md)합니다. 그다음 이용하려던 기능으로 이동하면 필요한 인증이 안내됩니다.

- **출석 체크·친구 초대**: 마이페이지에서 해당 메뉴를 열고 인증 안내를 따릅니다.
- **세이프티 필터**: 필터를 끄려고 할 때 성인 확인이 필요하면 안내가 나타납니다.
- **민감한 콘텐츠 표시**: 마이페이지의 **설정 및 지원**에서 이 항목을 켤 때 성인 확인이 필요할 수 있습니다.

웹의 세이프티 필터는 홈 화면에서 찾을 수 있습니다. 앱에서는 이용 중인 화면 구성에 따라 **홈** 또는 **마이페이지 → 설정 및 지원**에 표시됩니다. 앱의 마이페이지에 **세이프티 필터**가 있다면 그 항목을 사용하세요.

**필터를 끄는 것(OFF)**과 **민감한 콘텐츠 표시를 켜는 것(ON)**은 조작 방향이 다릅니다. 화면에 표시된 항목 이름과 현재 상태를 확인해 주세요.

## 3. 한국 본인인증 진행하기

한국 본인인증이 안내되는 계정은 다음 순서로 진행합니다.

1. 안내창의 **지금 바로 인증하기** 또는 **성인 인증하기**를 누릅니다.
2. PortOne 본인인증 화면에서 안내하는 정보를 입력합니다.
3. **본인 명의의 휴대폰**으로 인증을 완료합니다.
4. MYMI로 돌아와 인증 완료 안내를 확인합니다.
5. 출석 체크나 필터 설정 등 원래 이용하려던 기능을 다시 확인합니다.

| 이용 환경 | 인증 화면이 열리는 방식 |
| --- | --- |
| PC 웹 | 팝업 창에서 진행 |
| 모바일 웹 | 인증 페이지로 이동한 뒤 MYMI로 복귀 |
| Android·iOS 앱 | 앱 안에 열리는 인증 화면에서 진행 |

### 한국 정책의 성인 기준

한국 정책을 적용받는 계정은 **만 19세가 되는 해의 1월 1일부터** 성인 콘텐츠 이용 대상이 됩니다. 예를 들어 **2026년에는 2007년생부터** 해당하며, 그해 생일이 지났는지는 따로 기다리지 않습니다.

MYMI가 본인인증으로 확인한 생년월일을 기준으로 판단합니다. **내 정보나 페르소나의 생년월일을 직접 수정해도 성인 인증을 대신할 수 없습니다.** 본인인증이 완료되어도 성인 기준에 도달하지 않은 계정은 필터를 해제할 수 없습니다.

## 4. 해외 휴대폰 번호 인증하기

**휴대폰 번호 인증** 화면이 나오면 문자로 받은 인증번호를 입력합니다. 이 절차는 번호를 사용할 수 있는지 확인하는 과정입니다.

1. 번호의 국가를 선택합니다. 현재 선택지는 **일본(+81)·대만(+886)·미국(+1)**입니다.
2. 해당 국가의 본인 휴대폰 번호를 입력합니다. 선택한 국가와 번호가 일치해야 합니다.
3. **인증번호 받기**를 누릅니다.
4. 화면에 표시된 수신 번호가 맞는지 확인하고, 문자로 받은 인증번호를 입력합니다.
5. 표시된 유효시간 안에 **인증하기**를 누릅니다.
6. 완료 안내를 확인한 뒤, 원래 이용하려던 기능으로 돌아갑니다.

문자를 받지 못했다면 화면의 대기시간이 지난 후 **인증번호 재전송**을 사용할 수 있습니다. 번호를 잘못 입력했다면 **번호 변경**을 선택하세요. 인증번호가 만료되거나 입력 횟수를 초과했다는 안내가 나오면 화면 안내에 따라 다시 시작합니다.

번호 국가를 선택하는 것은 문자를 받을 번호를 지정하는 과정이며, 계정의 성인 확인 정책을 바꾸지는 않습니다. 지원하지 않는 국가의 번호이거나 인증 서비스가 준비 중이라는 안내가 나오면 해당 오류를 확인하고 문의해 주세요.

## 5. 성인 자기확인 진행하기

**성인 확인** 화면에 연령 확인 체크 항목이 나온다면 다음 순서로 진행합니다. 현재 일본·대만·영어 서비스의 자기확인 기준은 **만 18세 이상**입니다.

1. 화면에 표시된 연령 기준과 안내문을 읽습니다.
2. 실제로 기준을 충족하는 경우에만 **본인은 만 18세 이상의 성인입니다.** 항목에 체크합니다.
3. **확인하기**를 누릅니다.
4. 성인 확인 완료 안내가 나오면 원래 화면으로 돌아갑니다.

이 자기확인은 휴대폰 번호 인증과 별도로 진행할 수 있습니다. 성인 확인을 마친 뒤에도 출석 체크 등 다른 기능에서 번호 인증을 요청할 수 있습니다.

기준을 충족하지 않거나 확인을 진행하지 않으려면 **다음에 할게요**를 선택하세요. 성인 확인을 하지 않은 상태에서는 필터를 해제할 수 없습니다.

## 6. 인증 후 필터 설정 확인하기

**인증 완료와 필터 설정 변경은 별개입니다.** 인증창이 닫혀도 기존 필터 상태가 유지될 수 있습니다.

1. 인증을 시작했던 홈 또는 마이페이지로 돌아갑니다.
2. 이용하려는 설정을 다시 확인합니다. 세이프티 필터를 해제하려면 **OFF**, 민감한 콘텐츠를 표시하려면 해당 항목을 **ON**으로 변경합니다.
3. 계속 인증 안내가 나온다면 페이지를 새로고침하거나 앱을 다시 열어 확인합니다.

본인·번호 인증은 완료했지만 성인 확인이 남아 있거나, 확인된 나이가 기준에 미달하면 성인 기능은 계속 제한됩니다. 프로필·페르소나의 나이 설정과 성인 이용 자격은 서로 다릅니다.

## 7. 이미 다른 계정에서 인증한 경우

같은 본인인증 정보나 휴대폰 번호가 다른 계정에 연결되어 있으면 새 계정에서 중복 인증할 수 없습니다. 먼저 [처음 가입한 소셜 계정으로 로그인했는지](/account/login-profile.md) 확인하세요.

최근 탈퇴한 계정에서 사용한 인증 정보에는 **탈퇴 후 30일의 재사용 제한**이 적용될 수 있습니다. 계정을 탈퇴해도 즉시 다른 계정으로 인증을 옮길 수 있는 것은 아닙니다. 중복 연결이나 대기기간 안내가 나오면 기존 계정과 표시된 오류를 확인한 뒤 문의하세요.

## 인증이 잘되지 않을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 로그인이 필요하다고 나와요 | 가입한 소셜 계정으로 로그인한 뒤 해당 기능을 다시 엽니다 |
| PC에서 본인인증 창이 열리지 않아요 | 브라우저의 팝업 차단 안내를 확인하고 MYMI의 인증 팝업을 허용합니다 |
| 모바일 웹에서 인증 후 MYMI로 돌아오지 않아요 | 원래 페이지로 돌아와 새로고침합니다. 다른 앱 안의 브라우저였다면 외부 브라우저에서 다시 시도합니다 |
| 문자 인증번호가 오지 않아요 | 선택한 국가와 번호, 문자 수신·스팸 차단 상태를 확인합니다. 재전송 대기시간이 끝나면 재전송합니다 |
| 인증번호가 틀리거나 만료됐다고 나와요 | 받은 번호와 화면의 유효시간을 확인합니다. 만료된 경우 재전송하거나 번호 입력부터 다시 시작합니다 |
| 요청이 너무 많거나 입력 횟수를 초과했어요 | 반복해서 요청하지 말고 화면에 표시된 대기시간·재시작 안내를 따릅니다 |
| 이미 다른 계정에 연결되어 있다고 나와요 | 원래 인증한 계정으로 로그인했는지 확인합니다. 해결이 어려우면 지원팀에 문의합니다 |
| 최근 탈퇴한 계정의 정보라고 나와요 | 탈퇴 후 30일의 재사용 제한 안내를 확인합니다 |
| 언어를 바꿨는데도 인증 방식이 같아요 | 표시 언어를 변경해도 계정에 적용되는 인증 정책은 바뀌지 않습니다 |
| 해외에 거주 중인데 한국 본인인증이 나와요 | 계정에 적용된 인증 정책에 따른 화면입니다. 진행할 수 없다면 지원팀에 문의합니다 |
| 성인 확인 화면에서 확인 버튼을 누를 수 없어요 | 연령 기준을 충족하는 경우에만 확인 항목에 체크합니다 |
| 인증은 끝났는데 필터가 꺼지지 않아요 | 성인 확인까지 완료됐는지 확인한 뒤, 원래 화면에서 필터를 다시 조작합니다 |
| 지원하지 않는 국가·계정 국가 오류·서비스 준비 중 안내가 나와요 | 화면의 오류를 기록하고 잠시 후 다시 시도하거나 지원팀에 문의합니다 |

## 도움이 필요할 때

**마이페이지 → 디스코드 → 문의하기** 또는 [이메일 문의](mailto:contact@mymi.live)를 이용하세요. MYMI 아이디, 인증을 시작한 메뉴, 표시된 오류 문구, 웹·Android·iOS 중 이용 환경을 함께 알려주면 확인에 도움이 됩니다.

해외 거주 등으로 안내된 인증을 진행할 수 없는 경우에도 먼저 지원팀에 문의하세요. **신분증 사본이나 인증번호를 먼저 보내지 말고**, 필요한 절차를 안내받아 진행해 주세요.
