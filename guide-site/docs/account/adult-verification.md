# 성인·본인인증

MYMI는 **휴대폰 본인인증**으로 본인 여부와 생년월일을 확인합니다. 출석 체크처럼 본인인증이 필요한 기능과 세이프티 필터 해제처럼 성인 확인이 필요한 기능 모두 같은 본인인증으로 진행합니다.

| 구분 | 무엇을 확인하나요? | 안내가 나오는 경우 |
| --- | --- | --- |
| 본인인증 | 본인 명의 휴대폰으로 본인 여부와 생년월일 | 출석 체크, 친구 초대, 작품 제작의 AI 이미지 생성, 첫 충전 상품 구매 |
| 성인 확인 | 본인인증으로 확인된 나이가 성인 기준에 해당하는지 | 세이프티 필터를 해제하거나 민감한 콘텐츠 표시를 켤 때 |

본인인증을 한 번 마치면 성인 확인을 위해 따로 절차를 진행하지 않아도 됩니다.

## 1. 인증은 어디서 시작하나요?

먼저 MYMI에 [로그인](/account/login-profile.md)합니다. 그다음 이용하려던 기능으로 이동하면 필요한 인증이 안내됩니다.

- **출석 체크·친구 초대**: 마이페이지에서 해당 메뉴를 열고 인증 안내를 따릅니다.
- **AI 이미지 생성**: 작품 제작에서 이미지를 생성하거나 다시 생성할 때 본인인증이 안내됩니다. 가지고 있는 이미지를 올리는 것은 인증 없이 할 수 있습니다.
- **첫 충전 상품**: 스파크를 충전할 때 **초회할인** 표시가 붙은 첫 충전 상품을 고르면 본인인증이 안내됩니다.
- **세이프티 필터**: 필터를 끄려고 할 때 성인 확인이 필요하면 안내가 나타납니다.
- **민감한 콘텐츠 표시**: 마이페이지의 **설정 및 지원**에서 이 항목을 켤 때 성인 확인이 필요할 수 있습니다.

웹의 세이프티 필터는 홈 화면에서 찾을 수 있습니다. 앱에서는 이용 중인 화면 구성에 따라 **홈** 또는 **마이페이지 → 설정 및 지원**에 표시됩니다. 앱의 마이페이지에 **세이프티 필터**가 있다면 그 항목을 사용하세요.

**필터를 끄는 것**(OFF)과 **민감한 콘텐츠 표시를 켜는 것**(ON)은 조작 방향이 다릅니다. 화면에 표시된 항목 이름과 현재 상태를 확인해 주세요.

## 2. 본인인증 진행하기

다음 순서로 진행합니다.

1. 안내창의 **지금 바로 인증하기** 또는 **성인 인증하기**를 누릅니다.
2. 본인인증 화면에서 안내하는 정보를 입력합니다.
3. **본인 명의의 휴대폰**으로 인증을 완료합니다.
4. MYMI로 돌아와 인증 완료 안내를 확인합니다.
5. 출석 체크나 필터 설정 등 원래 이용하려던 기능을 다시 확인합니다.

| 이용 환경 | 인증 화면이 열리는 방식 |
| --- | --- |
| PC 웹 | 팝업 창에서 진행 |
| 모바일 웹 | 인증 페이지로 이동한 뒤 MYMI로 복귀 |
| Android·iOS 앱 | 앱 안에 열리는 인증 화면에서 진행 |

### 성인 기준

MYMI는 **만 19세가 되는 해의 1월 1일부터** 성인 콘텐츠 이용 대상으로 봅니다. 예를 들어 **2026년에는 2007년생부터** 해당하며, 그해 생일이 지났는지는 따로 기다리지 않습니다.

성인 여부는 **본인인증으로 확인한 생년월일**을 기준으로 판단합니다. 인증된 나이가 기준에 해당하면 필터를 해제할 수 있습니다.

## 3. 인증 후 필터 설정 확인하기

인증을 마친 뒤 홈이나 마이페이지로 돌아가 **필터 설정을 직접 변경**하세요.

1. 인증을 시작했던 홈 또는 마이페이지로 돌아갑니다.
2. 이용하려는 설정을 다시 확인합니다. 세이프티 필터를 해제하려면 **OFF**, 민감한 콘텐츠를 표시하려면 해당 항목을 **ON**으로 변경합니다.
3. 계속 인증 안내가 나온다면 페이지를 새로고침하거나 앱을 다시 열어 확인합니다.

성인 기능을 이용하려면 본인인증을 마치고, 인증된 나이가 성인 기준에 해당해야 합니다.

## 4. 이미 다른 계정에서 인증한 경우

같은 본인인증 정보가 다른 계정에 연결되어 있다는 안내가 나오면 [처음 가입한 소셜 계정으로 로그인했는지](/account/login-profile.md) 확인하세요.

최근 탈퇴한 계정에서 사용한 인증 정보에는 **탈퇴 후 30일의 재사용 제한**이 적용될 수 있습니다. 중복 연결이나 대기기간 안내가 나오면 기존 계정과 표시된 오류를 확인한 뒤 문의하세요.

## 인증이 잘되지 않을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 로그인이 필요하다고 나와요 | 가입한 소셜 계정으로 로그인한 뒤 해당 기능을 다시 엽니다 |
| PC에서 본인인증 창이 열리지 않아요 | 브라우저의 팝업 차단 안내를 확인하고 MYMI의 인증 팝업을 허용합니다 |
| 모바일 웹에서 인증 후 MYMI로 돌아오지 않아요 | 원래 페이지로 돌아와 새로고침합니다. 다른 앱 안의 브라우저였다면 외부 브라우저에서 다시 시도합니다 |
| 인증 문자가 오지 않아요 | 본인인증 화면에 입력한 통신사와 휴대폰 번호, 문자 수신·스팸 차단 상태를 확인합니다 |
| 본인인증 화면에서 인증에 실패해요 | 본인인증 화면의 안내에 따라 처음부터 다시 진행합니다. 계속 실패하면 표시된 오류 문구를 기록해 문의합니다 |
| 이미 다른 계정에 연결되어 있다고 나와요 | 원래 인증한 계정으로 로그인했는지 확인합니다. 해결이 어려우면 지원팀에 문의합니다 |
| 최근 탈퇴한 계정의 정보라고 나와요 | 탈퇴 후 30일의 재사용 제한 안내를 확인합니다 |
| 언어를 바꿨는데도 인증 방식이 같아요 | 인증 방식은 가입할 때 정해지며, 표시 언어를 변경해도 바뀌지 않습니다 |
| 본인 명의 휴대폰이 없어 인증할 수 없어요 | 다른 사람 명의로 인증하지 말고 지원팀에 문의합니다 |
| 인증은 끝났는데 필터가 꺼지지 않아요 | 인증된 나이가 성인 기준에 해당하는지 확인한 뒤, 원래 화면에서 필터를 다시 조작합니다 |
| 그 밖의 오류 안내가 나와요 | 표시된 오류 문구를 기록하고 잠시 후 다시 시도합니다. 계속되면 지원팀에 문의합니다 |

## 도움이 필요할 때

**마이페이지 → 디스코드 → 문의하기** 또는 [이메일 문의](mailto:contact@mymi.live)를 이용하세요. MYMI 아이디, 인증을 시작한 메뉴, 표시된 오류 문구, 웹·Android·iOS 중 이용 환경을 함께 알려주면 확인에 도움이 됩니다.

본인인증을 진행할 수 없는 경우에도 먼저 지원팀에 문의하세요. **신분증 사본이나 인증번호를 먼저 보내지 말고**, 필요한 절차를 안내받아 진행해 주세요.
