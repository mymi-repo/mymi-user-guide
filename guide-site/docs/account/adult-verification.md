# 성인·본인인증

성인 작품을 보거나 출석 체크로 스파크를 받으려면 **휴대폰 본인인증**을 한 번 해야 해요. 한 번 인증하면 성인 확인까지 끝나서 아래 기능을 모두 쓸 수 있어요.

## 인증이 필요한 일

| 하려는 일 | 인증을 시작하는 곳 |
| --- | --- |
| 성인 작품 보기 | 홈의 세이프티 필터 스위치를 끌 때, 또는 성인 작품 화면의 **본인인증하고 계속하기** |
| 민감한 콘텐츠로 분류된 작품 보기 | **마이페이지 → 설정 및 지원 → 민감한 콘텐츠 표시**를 켤 때 |
| 출석 체크로 스파크 받기 | **마이페이지 → 출석 체크**의 **오늘의 보상 받기** |
| 친구 초대 추천 코드 등록 | **마이페이지 → 친구 초대**의 **본인인증하고 등록 완료하기** |
| 첫 충전 상품 사기 | 충전 화면에서 첫 충전 상품을 골라 구매할 때 |
| 작품 제작의 AI 이미지 생성 | 제작 화면에서는 시작할 수 없어요. 출석 체크에서 먼저 인증해요 |

## 본인인증 하기

1. 위 표의 곳에서 인증 안내 창을 열고 인증 버튼을 눌러요. 창마다 버튼 이름이 달라요(**지금 바로 인증하기**, **성인 인증하기**, **본인인증하기**).
2. 본인인증 화면의 안내에 따라 본인 명의 휴대폰으로 인증해요. PC에서는 팝업 창, 휴대폰 웹에서는 인증 페이지, 앱에서는 앱 안 화면으로 열려요.
3. "본인인증이 완료되었습니다" 또는 "성인 인증이 완료되었습니다"가 뜨면 끝이에요. 휴대폰 웹에서는 인증을 마치면 원래 화면으로 돌아와요.
4. 하려던 일을 다시 해요. 세이프티 필터는 인증한 뒤 스위치를 한 번 더 눌러야 꺼져요.

### 몇 살부터 볼 수 있나요?

**만 19세가 되는 해의 1월 1일**부터 성인 작품을 볼 수 있어요. 2026년에는 2007년생부터예요. 미리 인증해 뒀다면 그해 1월 1일부터 생일과 관계없이 바로 볼 수 있어요.

## 성인 작품 보기

1. 하단 **홈**을 열고 **추천·랭킹·태그·검색** 탭 줄의 오른쪽 끝을 봐요. 글자 없이 방패 표시만 있는 작은 스위치가 세이프티 필터예요. 초록이면 켜져 있어서 성인 작품이 보이지 않아요.
2. 스위치를 눌러요. 로그인하지 않았다면 로그인 창이, 본인인증 전이라면 **성인 인증이 필요해요** 창이 떠요.
3. 인증을 마쳤으면 스위치를 한 번 더 눌러 회색으로 바꿔요. 이제 성인 작품이 홈 목록과 검색에 나와요.

:::info[다른 기기에서는 다시 꺼야 해요]
세이프티 필터는 기기마다 따로예요. 다른 기기나 브라우저에서 처음 열 때, 그리고 로그아웃한 뒤에는 다시 켜져 있어요. 그 기기에서 한 번 더 꺼 주세요.
:::

### 민감한 콘텐츠 표시도 켜야 하나요?

세이프티 필터를 껐는데도 찾는 작품이 보이지 않으면 **마이페이지 → 설정 및 지원 → 민감한 콘텐츠 표시**도 켜 보세요. 민감한 콘텐츠로 분류된 작품은 이 설정을 켜야 목록에 나와요.

| 설정 | 켜고 끄면 | 다른 기기에서는 |
| --- | --- | --- |
| **세이프티 필터** (홈 탭 줄 오른쪽 스위치) | 끄면 성인 작품이 보여요 | 기기마다 다시 꺼야 해요 |
| **민감한 콘텐츠 표시** (**마이페이지 → 설정 및 지원**) | 켜면 민감한 콘텐츠로 분류된 작품이 보여요 | 한 번 켜면 어느 기기에서나 켜져 있어요 |

둘 다 성인 확인을 마친 계정만 바꿀 수 있어요.

## 자주 막히는 곳

<details>
<summary>"세이프티 필터는 만 19세 이상인 경우에만 해제할 수 있습니다"라고 나와요</summary>

본인인증은 끝났지만 아직 성인 기준(만 19세가 되는 해의 1월 1일)에 이르지 않았어요. 그해 1월 1일이 되면 다시 인증할 필요 없이 바로 끌 수 있어요. "민감한 콘텐츠는 만 19세 이상인 경우에만 표시할 수 있습니다"도 같은 기준이에요.

</details>

<details>
<summary>"AI 이미지 생성에는 본인 인증이 필요해요"라고 나와요</summary>

작품 제작 화면에서는 인증을 시작할 수 없어요.

1. 오른쪽 위 **임시저장**을 눌러 작업을 저장해요.
2. **마이페이지 → 출석 체크**에서 **오늘의 보상 받기**를 눌러 본인인증을 마쳐요.
3. **마이페이지 → 작품 관리**에서 작품을 다시 열고 이미지를 생성해요.

</details>

<details>
<summary>"해당 실명은 이미 다른 계정으로 인증되어 있습니다"라고 나와요</summary>

한 사람의 본인인증은 한 계정에만 연결돼요. 예전에 다른 소셜 계정으로 가입해 인증한 적이 있을 거예요. 그 계정으로 로그인하세요. 어느 계정인지 모르겠다면 [문의하기](/faq/faq.md#문의하기)로 알려 주세요.

</details>

<details>
<summary>"최근 탈퇴한 계정의 인증 정보입니다"라고 나와요</summary>

탈퇴한 계정에서 쓴 본인인증 정보는 탈퇴하고 30일이 지나야 다른 계정에서 쓸 수 있어요. 30일이 지난 뒤 다시 인증하세요.

</details>

<details>
<summary>"본인인증이 취소되었습니다"라고 나와요</summary>

인증 화면을 끝까지 마치기 전에 닫았어요. 처음부터 다시 진행하세요.

</details>

<details>
<summary>PC에서 인증 창이 열리지 않아요</summary>

브라우저가 팝업을 막았을 수 있어요. 브라우저 설정에서 MYMI 사이트의 팝업을 허용한 뒤 다시 시도하세요.

</details>

<details>
<summary>휴대폰에서 인증한 뒤 MYMI로 돌아오지 않아요</summary>

MYMI 화면으로 돌아가 새로고침해 보세요. 카카오톡·인스타그램 같은 앱 안에서 열었다면 Chrome이나 Safari에서 [www.mymi.live](https://www.mymi.live)를 열고 다시 인증하세요.

</details>

<details>
<summary>휴대폰 본인인증 대신 다른 인증 창이 나와요</summary>

**휴대폰 번호 인증** 창에서 일본·대만·미국 번호만 고를 수 있거나 **성인 확인** 창이 나온다면, 한국어가 아닌 화면에서 가입한 계정이에요. 계정의 본인인증 방식은 가입한 뒤 바꿀 수 없어요. [문의하기](/faq/faq.md#문의하기)로 알려 주세요.

</details>

<details>
<summary>본인 명의 휴대폰이 없어요</summary>

본인인증은 본인 명의 휴대폰으로만 할 수 있어요. 다른 사람 명의로 인증하지 말고 [문의하기](/faq/faq.md#문의하기)로 먼저 알려 주세요. 신분증 사본이나 인증번호는 안내를 받기 전에 보내지 마세요.

</details>

<details>
<summary>인증을 마쳤는지 확인하고 싶어요</summary>

**마이페이지** 맨 위 닉네임 줄을 눌러 **내 정보 수정**을 열어요. **성별**과 **생년월일**이 잠겨 있어 바꿀 수 없으면 인증을 마친 계정이에요.

</details>

그래도 해결되지 않으면 [문의하기](/faq/faq.md#문의하기)로 알려 주세요. MYMI 아이디, 인증을 시작한 곳, 화면에 뜬 문구를 함께 적어 주면 더 빨리 확인할 수 있어요.
