# 구버전 제작 방식(1.0): 기존 작품 수정

**구버전 제작 방식의 신규 작품 제작은 종료됐습니다.** **마이페이지 → 작품 관리**에서 이 방식으로 만든 작품의 **수정**을 누르면 일곱 단계의 제작 화면이 열립니다. 새 작품은 하단 **제작** 탭에서 [새 작품 만들기](create-work.md)를 따라 제작하세요.

구버전 제작 화면은 **기본 정보 → 에셋 → 도입부 → 기타 설정 → 로어북 → 컴포넌트 → 선택사항** 순서로 진행됩니다. 다음 단계로 이동할 때 앞 단계의 필수 항목을 확인합니다.

## 1. 기본 정보: AI가 읽을 작품 설정

| 항목 | 입력 방법 |
| --- | --- |
| 작품 이름 | 50자 이내로 적습니다. |
| 한 줄 소개 | 40자 이내로 적습니다. |
| 세계관 | 시대·장소·상황 등 이야기의 배경을 적습니다. |
| 등장인물 | 1명 이상 추가하고 각각 이름과 설명을 적습니다. 이름은 서로 다르게 정합니다. |
| 비밀 | 이야기 속 인물이 알아야 할 숨긴 설정이 있으면 적습니다. |

세계관·등장인물 설명·비밀의 글자 수를 합쳐 **10,000자 이내**로 작성합니다. 이 화면의 세계관과 인물 설명은 AI가 대화에 활용하는 설정입니다. 현재 작품 제작 화면에서는 **프롬프트** 탭에 적습니다.

## 2. 에셋: 이미지와 대표 이미지

**에셋**에서 대화에 쓸 이미지를 직접 올리거나 AI로 생성합니다. 이미지마다 **상황 설명**을 적어 AI가 어떤 장면에 사용할지 알려 주세요. 작품에 사용할 **대표 이미지**도 지정합니다. 다음 단계로 가려면 이미지가 1장 이상 있어야 합니다.

## 3. 도입부: 채팅의 첫 장면

**도입부**를 1개 이상 만들고 각각 **제목**과 **내용**을 적습니다. 여러 개를 만들면 독자가 시작 장면을 고를 수 있습니다. 등록한 에셋 이미지는 화면에 표시된 `img:[slug]` 형식으로 내용에 넣고 **미리보기**에서 확인하세요.

## 4. 기타 설정: 작품 분류와 공개

독자층을 **남성향·여성향** 중 하나로 고르고, 공개 여부·오리지널 여부·이미지 출처·콘텐츠 등급을 설정합니다. 작품을 설명하는 다른 태그도 여기에서 추가할 수 있습니다. **오리지널**로 설정하면 MYMI에만 공개하며 3개월간 유지됩니다.

## 5~7. 필요에 따라 설정 더하기

| 단계 | 활용 방법 |
| --- | --- |
| **로어북** | 특정 키워드가 대화에 등장할 때 사용할 추가 설정을 만듭니다. 항목을 추가했다면 이름·키워드·내용을 채웁니다. |
| **컴포넌트** | 스탯·인벤토리처럼 대화에 표시할 화면 요소를 만듭니다. 추가한 컴포넌트에는 용도 설명과 작동하는 코드를 채웁니다. |
| **선택사항** | 프로필 디자인, 독자에게 제안할 추천 페르소나, 제작자의 한 마디를 설정합니다. 추천 페르소나를 추가했다면 이름·성별·생년월일·상세 정보를 채웁니다. |

내용을 확인한 뒤 마지막 단계의 **완료**를 누르면 수정 결과가 반영됩니다.

## 현재 작품 제작 화면에서는 어디에 적을까요?

| 구버전 제작 화면에서 쓰던 곳 | 현재 작품 제작 화면에서 쓰는 곳 |
| --- | --- |
| 기본 정보의 **세계관·등장인물·비밀** | **프롬프트**의 직접 작성 또는 기본형 작품 정보 |
| 에셋의 **대표 이미지** | 기본 정보의 **표지** |
| 에셋의 **이미지 상황 설명** | 에셋의 **이미지 코드**와 프롬프트의 이미지 출력 규칙 |
| 도입부의 첫 메시지 | **도입부**의 제목·내용 |
| 기타 설정의 독자층·태그 | **기타 설정**의 독자층, **기본 정보**의 해시태그 |
| 선택사항의 프로필 디자인·제작자의 한 마디 | **기본 정보**의 상세 설명·크리에이터 가이드 |

새 작품을 시작하면 [새 작품 만들기](create-work.md)의 순서대로 작성하세요.
