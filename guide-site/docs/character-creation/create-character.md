# 작품 만들기

로그인한 뒤 하단 **제작** 탭을 누르면 작품 제작 화면이 열립니다. 기본 정보와 표지를 준비하고 프롬프트·도입부·기타 설정을 채운 뒤 **제작 완료**를 누르세요.

처음 시작한다면 [새 작품 만들기](create-work.md)에서 **임시저장 → 표지 추가 → 프롬프트와 도입부 작성 → 기타 설정 → 제작 완료**까지 따라 해보세요.

## 만든 작품 수정하기

**마이페이지 → 작품 관리**에서 작품의 **수정**을 누르면 해당 작품의 제작 화면이 열립니다. 화면에 **수정 반영**이 보이면 이를 누르고, 구버전 제작 화면에서는 마지막 단계의 **완료**를 눌러 변경 내용을 적용하세요.

구버전 제작 방식(1.0)으로 만든 작품의 일곱 단계와 현재 제작 화면에서 달라진 점은 [구버전 제작 방식: 기존 작품 수정](edit-existing-work.md)에서 확인하세요. 구버전 방식의 **신규 작품 제작은 종료됐습니다.**
