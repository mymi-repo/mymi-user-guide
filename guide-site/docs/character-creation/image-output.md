# 이미지 출력 방식

이미지 안내는 **제작 가이드**로 옮겼어요. 간편 모드와 전문가 모드의 이미지 문법이 달라요. 간편 모드 작품이라면 첫 두 카드를, 전문가 모드 작품이라면 나머지 두 카드를 봐요.
