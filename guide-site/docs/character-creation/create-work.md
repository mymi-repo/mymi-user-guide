# 새 작품 만들기

로그인한 뒤 하단의 **제작** 탭을 누르면 작품 제작 화면이 열립니다. 탭은 **기본 정보 → 에셋 → 컴포넌트 → 프롬프트 → 도입부 → 로어북 → 기타 설정** 순서로 보이지만, 원하는 탭부터 작성할 수 있습니다.

처음 만드는 작품이라면 **기본 정보 작성 → 임시저장 → 표지 추가 → 프롬프트와 도입부 작성 → 기타 설정 → 제작 완료** 순서로 진행해 보세요. 에셋·컴포넌트·로어북은 작품에 필요할 때 추가하면 됩니다.

## 1. 기본 정보와 표지

**기본 정보**는 독자가 작품을 찾고 소개 페이지를 읽을 때 보는 내용입니다.

| 항목 | 입력 방법 |
| --- | --- |
| 작품 제목 | 30자 이내로 적습니다. |
| 한 줄 소개 | 40자 이내로 작품의 분위기를 소개합니다. |
| 표지 | 1장 이상, 최대 10장까지 올리거나 에셋에서 가져옵니다. 여러 장이면 전환 간격을 정할 수 있습니다. |
| 상세 설명 | 줄거리·등장인물·플레이 방법 등 독자에게 보여줄 내용을 적습니다. |
| 장르 | 1~2개 고릅니다. |
| 해시태그 | 작품을 설명하는 태그를 1개 이상 추가합니다. |

제목과 한 줄 소개를 적고 오른쪽 위 **임시저장**을 누르세요. 초안이 만들어지면 표지와 에셋 이미지를 올리거나 생성할 수 있습니다. **크리에이터 가이드**에는 독자가 알아두면 좋은 플레이 방법을 적고, **추천 모델**에는 작품과 어울리는 채팅 모델을 최대 5개까지 고를 수 있습니다. 두 항목은 선택사항입니다.

**독자에게 보여줄 소개는 기본 정보에, AI가 답변할 때 읽을 설정은 프롬프트에** 적습니다.

## 2. 프롬프트에 작품의 규칙 쓰기

**프롬프트** 탭에서 AI가 세계관·인물·진행 규칙을 어떻게 반영할지 정합니다. 작성 방식은 두 가지입니다.

| 작성 방식 | 이렇게 쓰세요 |
| --- | --- |
| **직접 작성** | 하나의 글에 세계관, 등장인물, 숨긴 설정, 진행 규칙을 자유롭게 적습니다. 이미지를 쓰면 어느 장면에 어떤 이미지 코드를 넣을지도 적습니다. |
| **기본형** | **작품 정보**에 세계관·등장인물·진행 규칙을 적습니다. 에셋이나 컴포넌트를 추가했다면 화면에 나타나는 코드·출력 규칙에도 뜻과 사용 시점을 채웁니다. 작성한 칸을 합친 결과를 아래에서 확인합니다. |

인물 이름, 관계, 말투, 독자의 역할과 이야기가 진행되는 규칙을 구분해 적으면 수정할 때도 찾기 쉽습니다.

기본형의 **작품 정보**에는 다음처럼 소제목을 나눠 쓸 수 있습니다. 작품에 맞게 내용을 바꿔 넣으세요.

```text
#### 세계관
- **장소**: 비밀을 간직한 도서관
#### 등장인물
- **이름**: 윤서
- **관계**: 독자를 처음 맞이하는 사서
#### 진행 규칙
- **독자 역할**: 새로 부임한 사서
- **첫 장면**: 잠긴 서가 앞에서 윤서를 만난다
```

## 3. 도입부에서 첫 메시지 만들기

**도입부** 탭에서 독자가 채팅을 시작할 때 처음 받을 메시지를 만듭니다. 도입부를 **1개 이상** 추가하고 각각 **제목**과 **내용**을 채우세요. 여러 개를 만들면 독자가 시작 장면을 고를 수 있습니다. **미리보기**로 채팅 화면에서 보일 모습을 확인할 수 있습니다.

에셋 이미지를 넣고 싶다면 먼저 **에셋** 탭에 이미지를 추가하고 코드를 정한 뒤, 도입부의 **에셋 이미지 넣기**를 누르세요.

## 4. 에셋·컴포넌트·로어북 활용하기

| 탭 | 사용할 때 | 작성 방법 |
| --- | --- | --- |
| **에셋** | 대화 중 장면에 맞는 이미지를 보여줄 때 | 이미지를 올리거나 생성하고 영문·숫자로 된 코드를 정합니다. 캐릭터별로 관리하려면 폴더를 만듭니다. 화면에 표시된 이미지 마크다운을 프롬프트나 도입부에 넣습니다. |
| **컴포넌트** | 스탯·인벤토리처럼 화면에 나타나는 요소가 필요할 때 | 컴포넌트 코드를 만들고, 기본형 프롬프트를 쓴다면 그 요소가 등장할 시점도 적습니다. |
| **로어북** | 특정 말이 나왔을 때 추가 설정을 반영할 때 | 항목 이름, 트리거 키워드, AI에게 알려줄 내용을 적습니다. |

예를 들어 캐릭터 폴더를 `A`, 그 안의 이미지 코드를 `1`로 정하면 이미지 경로는 `A/1`입니다. **에셋**에 표시되는 마크다운을 복사해 프롬프트나 도입부에 넣으면 해당 이미지를 사용할 수 있습니다.

이 세 탭은 선택사항입니다. 항목을 추가했다면 **제작 완료** 전에 이미지 생성 상태와 코드, 각 항목의 필수 칸을 확인하세요.

## 5. 기타 설정 고르기

**기타 설정**에서 공개 여부, 작품 공개 범위(오리지널·일반), 수익화 제한 여부, 이미지 출처, 독자층, 콘텐츠 등급, 마케팅 활용 동의 여부를 고릅니다. **오리지널**을 선택하면 MYMI에만 공개하며 설정 후 3개월간 유지됩니다.

독자가 채팅을 시작할 때 쓸 역할을 제안하고 싶다면 **추천 페르소나**를 추가하세요. 추가한 페르소나에는 이름·성별·생년월일·상세 정보를 채웁니다.

## 저장하고 제작 완료하기

작업 중 오른쪽 위 **임시저장**을 누르면 초안을 저장할 수 있습니다. 저장한 초안은 **마이페이지 → 작품 관리**에서 다시 열어 이어서 작성하세요.

모든 내용을 확인한 뒤 **제작 완료**를 누르세요. 빠진 필수 항목이 있으면 해당 탭으로 이동해 안내가 표시됩니다. 항목을 채우고 다시 누르면 완료 화면으로 이동합니다.

이미 제작한 작품을 수정할 때는 **마이페이지 → 작품 관리 → 수정**으로 열고, 변경을 마친 뒤 **수정 반영**을 누르세요.
