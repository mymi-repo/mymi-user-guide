# MYMI 접속 방법

MYMI는 **웹 브라우저와 Android·iOS 앱**에서 이용할 수 있습니다. PC에서는 웹으로, 휴대폰에서는 앱이나 모바일 웹으로 시작하세요.

## 웹으로 접속하기

1. PC나 휴대폰에서 웹 브라우저를 엽니다.
2. [**MYMI 웹사이트**](https://www.mymi.live)에 접속합니다.
3. 작품을 둘러보고, 대화를 시작하려면 화면 안내에 따라 로그인합니다.

별도의 프로그램 설치 없이 웹사이트에서 이용할 수 있습니다.

## 앱으로 접속하기

| 사용하는 기기 | 설치 링크 |
| --- | --- |
| Android | [Google Play에서 MYMI 설치](https://play.google.com/store/apps/details?id=live.mymi.app) |
| iOS | [App Store에서 MYMI 설치](https://apps.apple.com/app/id6794338974) |

1. 기기에 맞는 스토어 링크를 엽니다.
2. MYMI 앱을 설치하고 실행합니다.
3. 처음 이용한다면 회원가입을 진행하고, 기존 이용자라면 사용하던 계정으로 로그인합니다.

웹과 앱은 같은 MYMI 서비스입니다. 다른 기기에서 이어서 이용할 때는 **기존에 사용하던 로그인 방식과 계정**을 선택하세요. 가입과 로그인 방법은 [회원가입](../account/sign-up.md), [로그인·프로필 설정](../account/login-profile.md)에서 안내합니다.

## 화면 아래 메뉴 알아보기

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| 홈 | 작품을 둘러보고 관심 있는 작품 찾기 |
| 채팅 | 이전에 시작한 대화 찾기와 이어서 대화하기 |
| 제작 | 새 작품 만들기 |
| 마이페이지 | 내 프로필과 계정, 작품 관리 등 확인하기 |

작품 제작이나 대화 화면 안에서는 해당 작업에 필요한 메뉴가 표시됩니다. 처음에는 홈에서 마음에 드는 작품을 하나 골라 보세요.

## 링크를 눌렀는데 로그인이나 화면이 제대로 열리지 않아요

카카오톡이나 인스타그램 안에서 링크를 열면 해당 앱의 내장 브라우저가 열릴 수 있습니다. 그 안에서 로그인이 되지 않거나 화면이 멈춘다면, 메뉴에서 **외부 브라우저로 열기**를 선택하거나 주소를 복사해 평소 사용하는 브라우저에서 열어 보세요.

앱에 따라 메뉴 이름과 위치가 다를 수 있습니다.

## 접속이 안 될 때

1. 인터넷 연결을 확인하고 페이지를 새로고침하거나 앱을 다시 실행합니다.
2. 브라우저나 MYMI 앱에 업데이트가 있는지 확인합니다.
3. 웹에서는 다른 브라우저로도 접속해 봅니다.
4. 특정 브라우저에서만 문제가 계속된다면 [쿠키 삭제 안내](../faq/cookie-clear.md)를 확인합니다. 쿠키를 삭제하면 다시 로그인해야 할 수 있습니다.

문제가 계속되면 [FAQ](../faq/faq.md)를 확인하거나, 문제가 발생한 화면과 이용 환경을 함께 적어 문의해 주세요.
