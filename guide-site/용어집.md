# MYMI 유저가이드 용어집

가이드 본문과 번역에서 쓰는 화면 이름·용어의 기준이다. 나무위키(한국어) 원고도 한국어 열을 따른다.
값은 MYMI_frontend `packages/src/i18n/messages/<locale>/*.json`에서 2026-09-28에 확인했다.
앱 문구가 바뀌면 원고보다 이 표를 먼저 고친다.

## 1. 쓰는 법

- 버튼·메뉴·탭·화면 제목은 **굵게** 쓰고 앱 표기를 글자 그대로 옮긴다. 맞춤법이 표준과 달라도(예: **대화 캡쳐**) 앱 표기를 따른다.
- 이동 경로는 `→`로 잇는다. 예: **마이페이지 → 작품 관리 → 수정**
- 화면 이름이 아닌 설명 문장에는 2절의 일반 명사를 쓴다.
- 같은 한국어 문구도 화면에 따라 번역이 다르다(4절). 표의 위치를 보고 그 화면의 표기를 쓴다.
- 표에 없는 문구는 한국어 json에서 화면 문구를 찾고, 같은 키의 en·ja·zh-TW 값을 쓴다. 찾은 값은 이 표에 추가한다.

## 4. 앱 표기끼리 다른 곳

원고를 쓸 때 헷갈리기 쉬운 앱 쪽 표기다. 앱을 고치기 전까지는 화면에 보이는 대로 쓴다.

- 영어·번체중국어는 **내 정보 수정**과 **프로필 수정**이 같은 표기(Edit Profile / 編輯個人檔案)다. 경로에 탭 이름을 넣어 구분한다. 예: **Edit Profile → Creator → Edit Profile**
- 일본어 대표 페르소나 배지는 목록에서 **メイン**, 작품 상세의 선택 창에서 **代表**이다(`common:PersonaModal.representative`).
- 번체중국어 추천 페르소나는 작품 상세에서 **推薦 Persona**, 제작 화면에서 **推薦人設**이다.
- 영어 리프는 화면에 따라 **Leaf**와 **Leaves**가 섞여 있다.
- **제작 완료**는 제작 화면 버튼(Publish / 完成製作)과 크리에이터 대시보드의 상태 표시(Released / 已發布, `profile:CreatorDashboard.statusRelease`)의 번역이 다르다.
- 재화 부족 오류 문구는 한국어·영어·일본어가 '크레딧', 번체가 '點數'라고 쓴다(`errors:INSUFFICIENT_CREDITS`). 오류 문구를 그대로 인용할 때만 쓴다.
- 영어·일본어·번체의 민감한 콘텐츠·세이프티 필터 안내 일부가 '19세 이상'으로 고정돼 있다(`profile:UseProfilePage.nsflAdultOnly` 등). 해외 계정의 기준(18세 자기확인)과 달라 앱 문구 수정이 필요하다. 가이드에는 계정 기준을 쓴다.
- 영어·일본어·번체의 크리에이터 화면에 현금 출금 한도가 원화로 표시된다(`profile:CreatorDashboardView.cashWithdrawOfficial`: Up to 100,000 KRW/month, 月最大100,000ウォン, 每月最高 100,000 韓元). 세 언어판 가이드에는 그 나라 크리에이터 약관 기준을 쓴다.
- 출석 체크 안내(`profile:NewAttendance.notice1`)는 모든 언어에서 '자정(12:00 AM)에 갱신'이라고 쓰지만, 실제 날짜 기준은 UTC+9 자정이다. 대만은 오후 11시, 미국 동부는 오전 10~11시다. 가이드에는 그 나라 시각으로 쓴다.
- 번체 제작 화면은 리프를 **葉子**로(`createV2`), 마이페이지·대시보드는 **Leaf**로 쓴다. 설명문에는 Leaf를 쓰고, 제작 화면 문구를 인용할 때만 葉子를 쓴다.
- 첫 충전 상품 배지는 **초회할인**(`credits:CreditsPage.introBadge`)이다. `introPlanBadge`(첫 충전 전용)는 지금 화면에 쓰이지 않는다.
